## 30 秒認識

- 人類是少數無法自行合成維生素 C 的哺乳動物——我們缺少合成途徑最後一步所需的 L-古洛糖酸內酯氧化酶，所以它必須從飲食取得。 <a href="#ref-1">[1]</a>
- 預防壞血病所需的量其實很低，每日約 10 毫克即足夠；台灣成人的建議攝取量是每日 100 毫克，上限為 2,000 毫克。 <a href="#ref-5">[5]</a>
- 感冒這件事要分兩段講：**規律補充**可縮短病程（成人約 8%、兒童約 14%），但**症狀開始後才吃**，現有試驗沒有一致效果；對一般人也不能降低感冒發生率。 <a href="#ref-2">[2]</a>
- 吸收會飽和。單次劑量越高、吸收比例越低，血漿濃度在每日約 200 至 400 毫克就趨近上限，多吃的部分主要由腎臟排掉。 <a href="#ref-1">[1]</a>
- 高劑量在體內代謝為草酸，有腎結石病史或腎功能不全者需要留意；正在服用 warfarin 的人也應與醫師確認。 <a href="#ref-1">[1]</a>

## 基本介紹

維生素 C 的化學名是抗壞血酸（ascorbic acid），屬水溶性維生素。大多數哺乳動物能在肝臟自行合成它，人類、其他靈長類與天竺鼠則因為基因演化過程中失去 L-古洛糖酸內酯氧化酶而喪失這個能力，因此它對人類屬於「必需營養素」：缺了會生病，不歸類在可有可無的保健成分。 <a href="#ref-1">[1]</a>

這個「必需」的定位很重要，因為它決定了判讀方式：維生素 C 的核心價值在於**把攝取量補到足夠**，而不是越多越好。從缺乏到足夠，效益很明確；從足夠再往上加，證據就迅速變薄。

## 這是什麼？

產品標示上常見的型態包括抗壞血酸（最基本、也最便宜）、抗壞血酸鈉或抗壞血酸鈣（緩衝型，對胃較溫和）、脂質體維生素 C、以及各種標榜「酯化」的專利型態。

有一點值得先釐清：**天然萃取與化學合成的抗壞血酸在化學結構上完全相同**，人體無法分辨。柑橘萃取的產品若標示每份含量與合成品相同，兩者在體內的行為也相同。差別通常在價格、伴隨的其他植化素，以及賦形劑。

## 在身體裡做什麼？／主要作用機制

維生素 C 在體內的角色不只是「抗氧化劑」，它更關鍵的身分是**多種酵素的輔因子**，主要是 2-酮戊二酸依賴型雙加氧酶家族。 <a href="#ref-1">[1]</a> 具體包括：

- **膠原蛋白合成**：脯胺酸羥化酶與離胺酸羥化酶需要維生素 C 維持鐵原子的還原態。羥化步驟做不完全，膠原蛋白的三螺旋結構就不穩定——這正是壞血病出現牙齦出血、傷口難癒、微血管脆弱的直接原因。
- **神經傳導物質合成**：多巴胺 β-羥化酶把多巴胺轉成正腎上腺素，同樣需要它。
- **肉鹼合成**：脂肪酸進入粒線體所需的肉鹼，其合成途徑中有兩個羥化步驟依賴維生素 C，這與壞血病的疲倦感有關。

抗氧化方面，它作為電子供體可清除活性氧物種，並能把氧化態的維生素 E 還原回活性形式，兩者在體內形成互補。 <a href="#ref-3">[3]</a>

免疫方面的機制討論最多的是：它在中性球內濃度極高，參與趨化與吞噬作用，並支持皮膚屏障的完整性。 <a href="#ref-3">[3]</a> 這些是**生理功能**，不等於「吃了就不會感冒」——實際的臨床結果見下一段。

另外一個實用機制：維生素 C 能把三價鐵還原成二價鐵，**顯著提高植物性食物中非血基質鐵的吸收率**。這對素食者或缺鐵族群是有意義的搭配，對鐵過載者則相反。 <a href="#ref-1">[1]</a>

## 食物來源／常見來源

台灣常見且含量高的來源是**芭樂**，每 100 公克的維生素 C 含量明顯高於柑橘類。其他良好來源包括甜椒（尤其紅甜椒）、奇異果、柑橘、花椰菜、番茄與深綠色蔬菜。

要注意的是維生素 C 怕熱、怕氧化、也溶於水。同一份青菜，水煮久煮的流失遠高於快炒或蒸；切好久放、反覆加熱也會降低含量。對多數人而言，**每天有兩份水果加足量蔬菜，就相當容易達到 100 毫克**，不需要另外補充品。

## 建議攝取量／常見攝取建議／研究中常見使用方式

台灣成人的建議攝取量為每日 100 毫克，上限攝取量 2,000 毫克。 <a href="#ref-5">[5]</a> 美國的建議另外指出，**吸菸者因氧化壓力較高，每日應多攝取約 35 毫克**。 <a href="#ref-1">[1]</a>

研究情境的劑量與日常建議量不同，這是最容易誤讀的地方。Cochrane 那批感冒試驗使用的多是每日 200 毫克以上的規律補充，且效果是「縮短病程」而非「預防感冒」。 <a href="#ref-2">[2]</a> 把研究劑量直接當成日常建議，或把「縮短 8%」理解成「不會感冒」，都是過度推論。

## 缺乏風險或攝取不足問題

典型缺乏症是**壞血病**，在現代並未絕跡。早期表現包括疲倦、肌肉痠痛、牙齦腫脹出血、皮膚出現毛囊周圍出血點，後期則有傷口不癒、關節積液與貧血。因為症狀不具特異性，臨床上常被延誤診斷。

較需要留意的族群：飲食極度單一或長期不吃蔬果者、酗酒者、吸菸者、腸道吸收不良（如發炎性腸道疾病、胃腸手術後）、接受透析者，以及某些飲食受限的長者與精神疾病患者。

反過來說，如果你蔬果攝取正常，卻把疲倦、皮膚狀況、免疫力差全歸因於「維生素 C 不足」，通常找錯方向。這類症狀的原因很多，值得先看睡眠、鐵與甲狀腺等更常見的因素。

## 補充品常見形式

- **一般抗壞血酸**：最便宜，研究使用最多，對多數人足夠。
- **緩衝型（抗壞血酸鈉／鈣）**：對胃酸敏感者較舒適，但要把伴隨的鈉或鈣一併算進每日總量。
- **緩釋型與脂質體**：訴求是提高吸收或延長停留。這裡有個生理限制要理解——**血漿維生素 C 濃度由腸道吸收飽和與腎臟排泄共同調控**，超過飽和點之後，劑型帶來的差異在臨床上的意義有限。 <a href="#ref-1">[1]</a>
- **高劑量粉包**：單次幾公克很容易超過腸道吸收上限，未吸收的部分留在腸道造成滲透性腹瀉，這是高劑量最常見的不適來源。

## 安全性與注意事項

一般劑量下維生素 C 的安全性良好，上限攝取量訂在每日 2,000 毫克，主要依據是超過此量後腸胃不適明顯增加。 <a href="#ref-4">[4]</a> 需要特別留意的情況：

- **腎結石與腎功能不全**：維生素 C 代謝終產物之一是草酸，高劑量可能增加草酸鈣結石風險。有結石病史或慢性腎臟病者不宜長期高劑量。
- **鐵過載（如血色素沉著症）**：維生素 C 促進鐵吸收，這類族群應避免高劑量。
- **Warfarin**：高劑量可能影響抗凝血效果，同時使用者應依醫囑監測 INR。
- **檢驗干擾**：高劑量可能影響部分血糖試紙與糞便潛血檢驗結果。若近期要做健檢或相關檢查，值得主動告知。

孕期與哺乳期的建議量略高於一般成人，但一般飲食即可達標，不需要高劑量補充。 <a href="#ref-5">[5]</a>

## 常見迷思

- **「感冒了趕快吞高劑量維生素 C，好得比較快」**：Cochrane 的分析明確區分兩種情形——規律補充可縮短病程，但**症狀出現後才開始吃**的治療性試驗，並未顯示一致的效果。 <a href="#ref-2">[2]</a>
- **「劑量越高效果越好」**：吸收會飽和、腎臟會排掉。超過每日約 200 至 400 毫克後，血漿濃度的增幅就很有限。 <a href="#ref-1">[1]</a>
- **「天然的比合成的好」**：抗壞血酸就是抗壞血酸，人體無法分辨來源。差別在價格與伴隨成分，不在維生素 C 本身。
- **「維生素 C 可以提升免疫力所以不會生病」**：它支持免疫功能的正常運作，這與「增強到不會生病」是兩回事。Cochrane 的結論是：一般人規律補充**無法降低感冒發生率**。 <a href="#ref-2">[2]</a>
