## 30 秒重點

- 牛奶中的蛋白質約八成是酪蛋白，兩成是乳清蛋白。酪蛋白遇胃酸會凝結成塊，胺基酸釋放速度比乳清慢得多，這個特性讓它在運動營養研究裡常被稱為「慢蛋白」。 <a href="#ref-1">[1]</a>
- 一篇納入 16 名男性的隨機對照試驗發現，運動後睡前攝取 40 克酪蛋白，隔夜肌肉蛋白質合成速率比安慰劑組高出約 22%。 <a href="#ref-2">[2]</a>
- 同一研究團隊 2015 年做 12 週訓練追蹤，44 名男性睡前補充酪蛋白搭配阻力訓練，肌肉量與肌力增幅優於單純訓練加安慰劑；但 2025 年一篇針對 30 名高齡男性的隨機對照試驗顯示，只要每日蛋白質總量已達每公斤體重 1.0 克以上，睡前或運動後額外補充並未進一步提升訓練成效。 <a href="#ref-3">[3]</a><a href="#ref-4">[4]</a>
- 2026 年一篇納入 78 篇試驗、4755 人的網絡統合分析比較 13 種蛋白質補充品，乳清蛋白與膠原蛋白在肌力與去脂體重的排名領先，酪蛋白等乳製品蛋白整體優於植物性蛋白，但差距幅度不大。 <a href="#ref-6">[6]</a>
- 酪蛋白是牛奶蛋白過敏最主要的致敏原之一，與乳糖不耐是完全不同的機轉，分不清楚兩者容易誤判自己該避開哪一種乳製品。 <a href="#ref-7">[7]</a>

## 這個成分是什麼

牛奶中的蛋白質分成兩大家族：酪蛋白約占八成，乳清蛋白約占兩成。酪蛋白不是單一分子，是 αs1-、αs2-、β-、κ-酪蛋白等多種次型蛋白質聚集成的「微胞」（micelle）結構，靠磷酸鈣橋鏈與疏水作用力維持穩定，這個結構在牛奶裡呈懸浮狀態，是牛奶看起來呈白色不透明的主要原因之一。 <a href="#ref-1">[1]</a> 進入胃部後，κ-酪蛋白在酸性環境與胃蛋白酶作用下崩解，微胞失去穩定性、彼此聚集形成凝乳塊，這個物理變化讓胺基酸釋放進入血液的速度明顯放慢。相對地，乳清蛋白維持液態、消化吸收快速，運動科學文獻慣稱酪蛋白為「慢蛋白」、乳清蛋白為「快蛋白」。 <a href="#ref-1">[1]</a>

法國學者 Boirie 等人 1997 年發表於《美國國家科學院院刊》（PNAS）的經典交叉試驗，讓健康成人分別攝取酪蛋白與乳清蛋白，追蹤餐後血中胺基酸濃度變化。乳清蛋白讓血中胺基酸濃度急遽上升又快速回落，酪蛋白則造成溫和但持續數小時的平台期；乳清蛋白使餐後蛋白質合成提升 68%，酪蛋白則抑制了 34% 的全身蛋白質分解。兩種蛋白質在急性反應上走的是不同路徑，一個偏向刺激合成、一個偏向抑制分解，不是單純的效果高低之分。 <a href="#ref-1">[1]</a>

## 常見用途與證據怎麼看

睡前補充酪蛋白是這個成分在運動營養圈最常被提到的用法，理論基礎是「訓練後睡眠期間身體處於長時間空腹，慢速釋放胺基酸能延續肌肉蛋白質合成」。馬斯垂克大學 Res 等人 2012 年的隨機對照試驗找來 16 名健康男性，在晚間進行一次阻力運動後，30 分鐘前給予 40 克酪蛋白或安慰劑，追蹤整夜的肌肉蛋白質合成速率，結果酪蛋白組比安慰劑組高出約 22%。 <a href="#ref-2">[2]</a> 同團隊的 Snijders 等人 2015 年把觀察拉長到 12 週規律訓練，44 名健康年輕男性每晚訓練後睡前攝取酪蛋白，肌肉橫斷面積與肌力的增加幅度優於只做訓練、睡前喝安慰劑的對照組。 <a href="#ref-3">[3]</a>

不過這個效果在不同族群不一定同樣明顯。2025 年一篇發表於《國際運動營養學會期刊》的隨機對照試驗，找來 30 名平均 65.7 歲的未訓練高齡男性，分成運動後補充、睡前補充、單純訓練三組，追蹤 12 週阻力訓練後的肌肉厚度與肌力變化，三組進步幅度沒有統計差異。這篇研究的受試者原本每日蛋白質攝取量就已達每公斤體重 1.0 克以上，作者的判讀是：整體飲食蛋白質量已經足夠時，訓練的規律與依從度對成效的影響大於補充時機，時機調整帶來的邊際效益有限。 <a href="#ref-4">[4]</a> 兩篇研究族群不同（年輕受訓練者 vs. 未訓練高齡者），結論落差很可能來自基礎飲食與訓練狀態的差異，不是互相矛盾。

長期訓練下，酪蛋白和其他蛋白質來源的整體效果差異有多大，是另一個常被拿出來討論的問題。2026 年一篇網絡統合分析納入 78 篇隨機對照試驗、4755 名受試者，比較膠原蛋白、乳清、酪蛋白、大豆、肉類等 13 種蛋白質補充品，在肌力與去脂體重兩項結果上，膠原蛋白與乳清蛋白排名靠前，乳製品類蛋白整體優於植物性蛋白，但各類蛋白質之間的效應量差距並不大。 <a href="#ref-6">[6]</a> 這代表急性胺基酸釋放曲線的快慢差異，不必然等比例反映在數週到數月的訓練結果上。

美國國家衛生研究院膳食補充品辦公室（NIH ODS）整理運動營養實證時指出，市售蛋白粉不論來源，實務上每餐 20 到 40 克蛋白質是常見的研究劑量區間，酪蛋白因消化較慢，單次攝取量落在這個區間上緣（30 到 40 克）較常見於研究設計。 <a href="#ref-9">[9]</a> 台灣衛生福利部國民健康署「國人膳食營養素參考攝取量」第八版，將一般健康成人的蛋白質建議攝取量訂在每公斤體重約 1.1 克，這是預防缺乏的一般人口基準，不是針對特定蛋白質來源訂的門檻，酪蛋白、乳清蛋白或其他食物蛋白都可以互相搭配湊到這個總量。 <a href="#ref-10">[10]</a>

## 食物來源與補充品常見形式

不透過補充品，酪蛋白的天然食物來源就是各式乳製品：起司（尤其是硬質與半硬質起司，加工過程會濃縮酪蛋白）、優格、茅屋起司、牛奶本身都含有酪蛋白，只是濃度依產品加工方式而不同。市售酪蛋白補充品主要分三種加工型態，差異在保留多少原始微胞結構：

- **酸式酪蛋白（acid casein）**：以酸沉澱法從牛奶分離出來，保留較完整的凝乳特性，但溶解度較差、口感較粗，市面上較少見。
- **酪蛋白酸鹽（caseinate，如酪蛋白酸鈣、酪蛋白酸鈉）**：以鹼中和後製成鹽類，溶解度提高、口感較滑順，是多數市售「酪蛋白蛋白粉」的主要型態。
- **微胞酪蛋白（micellar casein，MC）**：透過過濾技術保留天然微胞結構未被破壞，理論上消化最慢、胺基酸釋放最持續，常被標榜為「真正慢蛋白」，價格通常也最高。

一篇交叉設計試驗讓 15 名健康年輕男性分別攝取 40 克微胞酪蛋白、酪蛋白酸鈣、交聯酪蛋白酸鈉，追蹤餐後 90 分鐘內的血中總胺基酸濃度變化，結果交聯酪蛋白酸鈉的吸收速度快於微胞酪蛋白與酪蛋白酸鈣，微胞酪蛋白居中。 <a href="#ref-5">[5]</a> 這說明同樣標示「酪蛋白」，加工方式不同會實質改變吸收動力學，「微胞」二字對應的是真實的結構差異。差異幅度落在數十分鐘等級，比較接近吸收曲線的快慢之分，不是「完全不吸收」對「立即吸收」的兩極對比。

## 安全性與注意事項

在腎功能正常的族群，酪蛋白與整體高蛋白飲食的安全性資料和乳清蛋白一致。一篇納入 28 篇隨機對照試驗、1358 名健康成人的統合分析比較高蛋白（平均每公斤 1.81 克）與正常或低蛋白飲食（平均每公斤 0.93 克），介入前後腎絲球過濾率的變化量兩組沒有統計差異，屬健康腎臟的正常生理適應。 <a href="#ref-8">[8]</a> 已被診斷慢性腎臟病者，情況完全不同，國際指引與衛生福利部的建議都是限制蛋白質攝取。 <a href="#ref-10">[10]</a> 這部分判準跟你是不是喝酪蛋白無關，跟你本身腎功能狀態有關。

需要特別留意的是牛奶蛋白過敏。一篇 2019 年發表於《Nutrients》的流行病學回顧指出，牛奶過敏在一歲兒童的盛行率約 0.5% 到 3%，多數兒童會在成長過程中自然耐受，但仍有約 1% 的成人持續過敏，且成人族群中酪蛋白是最常被檢出的致敏原（兒童則以 α-乳白蛋白較常見）。 <a href="#ref-7">[7]</a> 牛奶蛋白過敏與乳糖不耐是兩種不同機轉：乳糖不耐是缺乏乳糖酶、消化乳糖時產生腹脹腹瀉等腸胃症狀；牛奶蛋白過敏則是免疫系統對酪蛋白或乳清蛋白產生 IgE 或非 IgE 反應，嚴重時可能出現蕁麻疹、呼吸道症狀甚至過敏性休克。乳糖不耐者換用低乳糖或無乳糖乳製品通常可以緩解，但這個做法對牛奶蛋白過敏者無效，過敏者必須完全避開酪蛋白與所有乳製品蛋白來源。

## 常見迷思

- **「酪蛋白只能睡前吃，其他時間吃沒有意義」**：睡前補充是研究最集中的情境，但酪蛋白本質上就是一種完整蛋白質來源，白天當一般餐次的蛋白質補充同樣能提供必需胺基酸，只是急性吸收曲線比乳清慢，不是「只有睡前吃才有用」。 <a href="#ref-1">[1]</a>
- **「酪蛋白吸收慢，所以增肌效果比乳清差」**：2026 年的網絡統合分析顯示乳清蛋白在肌力排名略勝一籌，但酪蛋白與其他乳製品蛋白的差距幅度不大，急性吸收曲線的快慢差異，不等於數週到數月訓練結果的優劣差異。 <a href="#ref-6">[6]</a>
- **「植物性蛋白吸收速率一定比酪蛋白慢」**：吸收速度取決於蛋白質的胺基酸組成與物理結構，不是動物性或植物性這個分類本身決定的；不同植物蛋白（如大豆分離蛋白、豌豆蛋白）之間的吸收動力學差異也不小，不能一概而論。
- **「乳糖不耐的人不能吃酪蛋白蛋白粉」**：多數市售酪蛋白蛋白粉經過純化，乳糖殘留量本來就低，乳糖不耐者未必需要完全避開；真正需要完全避開的是牛奶蛋白過敏者，兩者是不同族群、不同機轉。 <a href="#ref-7">[7]</a>

## 常見問題

### 酪蛋白和乳清蛋白可以一起吃嗎？

可以。兩者都是完整蛋白質，實務上部分運動員會在運動後選擇消化快的乳清蛋白，睡前再補充消化慢的酪蛋白，讓一天的胺基酸供應涵蓋「快速啟動」與「持續延續」兩種情境。若飲食中整體蛋白質總量已經足夠，混用與否對長期訓練結果的影響有限，選哪一種更多是個人時間安排與口感偏好的問題。 <a href="#ref-6">[6]</a>

### 高齡者適合用酪蛋白補充蛋白質嗎？

可以作為選項之一，但不必迷信「睡前補充」這個特定形式。2025 年那篇針對高齡男性的隨機對照試驗顯示，只要每日蛋白質總攝取量達到每公斤體重 1.0 克以上，補充時機（運動後 vs. 睡前）對訓練成效沒有額外加分；反而是規律參與阻力訓練、把每日蛋白質總量吃夠，才是影響結果的主要變數。 <a href="#ref-4">[4]</a>

### 哪些人不適合喝酪蛋白蛋白粉？

牛奶蛋白過敏者應完全避免，因為酪蛋白本身就是主要致敏原之一；已被診斷慢性腎臟病者，蛋白質攝取量需依醫師或營養師的建議調整，不適用一般健康成人的安全性資料。若不確定自己屬於哪一種，建議先諮詢醫師或安排相關檢測，再決定是否使用。 <a href="#ref-7">[7]</a><a href="#ref-8">[8]</a>

### 微胞酪蛋白比較貴，值得多花錢買嗎？

取決於你要解決的問題。若目的是延長夜間胺基酸供應，微胞酪蛋白因保留天然微胞結構、消化速度較慢，理論上更貼近這個訴求；若只是想單純補足每日蛋白質總量，酪蛋白酸鹽型態價格較低、溶解度較好，在總攝取量足夠的前提下，長期訓練結果的差異目前沒有一致證據顯示會因型態不同而拉開差距。 <a href="#ref-5">[5]</a><a href="#ref-6">[6]</a>
