## 30 秒認識

- 乳清蛋白（Whey Protein）是牛奶製作起司時分離出的液態副產物，經過濾、乾燥後製成蛋白粉，含完整必需胺基酸，白胺酸比例在常見蛋白質來源中偏高。 <a href="#ref-1">[1]</a>
- 阻力訓練期間補充蛋白質，對去脂體重與肌力有支持證據；統合分析顯示效果隨每日總蛋白攝取量提高而增加，約在每公斤體重 1.6 克處趨於平緩，超過這個量的額外效益在族群層級的資料中不明顯。 <a href="#ref-2">[2]</a>
- 「訓練後 30 分鐘內一定要喝乳清，錯過就沒效」是常見迷思。系統性回顧指出，只要一天中的總蛋白攝取量與分佈足夠，運動前後幾小時內的彈性攝取窗口都能達到相近效果，並非精準卡在半小時。 <a href="#ref-6">[6]</a>
- 腎功能正常者，適量高蛋白飲食的統合分析未見腎絲球過濾率惡化；已被診斷慢性腎臟病者則需依醫囑限制蛋白質攝取，兩者結論不同，不能一概而論。 <a href="#ref-4">[4]</a>
- 乳清蛋白依加工程度分濃縮（WPC）、分離（WPI）、水解（WPH）三種常見型態，乳糖殘留量依序遞減，是挑選時最實際的差異點之一。 <a href="#ref-9">[9]</a>

## 基本介紹

乳清（whey）是牛奶在製作起司過程中，凝乳析出後剩下的淡黃綠色液體，早期是乳製品業的副產物，如今經超濾、奈濾等薄膜分離技術純化後，成為運動營養市場最普及的蛋白質補充品原料之一。 <a href="#ref-9">[9]</a> 它屬於「完整蛋白質」，也就是含有人體無法自行合成的九種必需胺基酸，且消化吸收速度快於多數植物性蛋白，這是它在運動科學文獻中被大量研究的主要原因。 <a href="#ref-1">[1]</a> 乳清蛋白不是維生素或藥品，本質上是一種食品原料。美國國家衛生研究院膳食補充品辦公室（NIH ODS）整理運動營養實證時也指出，市售蛋白粉多數以乳清為主要原料，是牛奶分離出的完整蛋白質之一。 <a href="#ref-7">[7]</a>

## 這是什麼？

牛奶中的蛋白質主要分成兩大類：酪蛋白（casein，約占 80%）與乳清蛋白（約占 20%）。兩者的差異不只在來源，也在消化速度。酪蛋白遇胃酸會凝結成塊，釋放胺基酸的速度較慢；乳清蛋白維持液態、消化吸收快，因此常被稱為「快蛋白」，酪蛋白則被稱為「慢蛋白」。 <a href="#ref-1">[1]</a> 市售乳清蛋白粉依處理程度分為濃縮乳清蛋白（WPC，蛋白質含量約 25–89%）、分離乳清蛋白（WPI，蛋白質含量約 90–95%）與水解乳清蛋白（WPH，經酵素部分水解成更小的胜肽）三種。 <a href="#ref-9">[9]</a>

## 在身體裡做什麼？／主要作用機制

肌肉蛋白質合成（muscle protein synthesis）是肌肉維持與生長的基礎機制，需要足量必需胺基酸與訓練刺激共同啟動。乳清蛋白中白胺酸（leucine）的比例在常見蛋白質來源中相對高，白胺酸被認為是啟動 mTOR 訊息路徑、促進肌肉蛋白質合成的關鍵胺基酸之一。 <a href="#ref-1">[1]</a> 快速消化的特性讓乳清蛋白攝取後，血中胺基酸濃度上升較快、達到峰值的時間較早，這是它在急性研究中常被拿來與酪蛋白、大豆蛋白比較的切入點。不過，急性血中胺基酸反應的差異，不必然等於長期訓練下肌肉量與肌力的差異。 <a href="#ref-5">[5]</a>

## 食物來源／常見來源

乳清蛋白粉本身就是一種加工食品，天然食物來源以乳製品為主。牛奶、優格、茅屋起司（cottage cheese）都含有乳清蛋白，其中液態乳清飲品（部分市售保久乳製品標示「乳清飲」）蛋白質濃度接近純化前的原料型態。若不透過補充品，日常飲食要達到運動研究常用的每日 20–40 克單次蛋白攝取量，可透過雞蛋、雞胸肉、魚肉、黃豆製品、乳製品等多元優質蛋白來源組合達成，乳清蛋白粉的優勢在於濃度高，一份約 30 克的蛋白粉多能提供 20 克以上蛋白質，比多數天然食物更快湊足單餐所需的攝取量。 <a href="#ref-1">[1]</a>

## 建議攝取量／常見攝取建議／研究中常見使用方式

台灣衛生福利部國民健康署「國人膳食營養素參考攝取量」第八版，將一般健康成人的蛋白質建議攝取量訂在每公斤體重約 1.1 克，70 歲以上族群略高，訂在每公斤體重約 1.2 克。 <a href="#ref-8">[8]</a> 這個數字是為了預防缺乏而設的一般人口基準，並非運動員或阻力訓練者的目標值。國際運動營養學會（ISSN）的立場聲明指出，規律從事阻力訓練的族群，每日總蛋白攝取量落在每公斤體重 1.4–2.0 克之間較能支持肌肉適應，實務上常以每餐 20–40 克、平均分散在三到四餐的方式達成。 <a href="#ref-1">[1]</a> Morton 等人 2018 年的統合分析進一步用劑量反應模型估算，蛋白質對去脂體重的助益約在每公斤體重 1.6 克處趨於平緩，這個數字常被引用為「多數人不需要超過的上限參考」，但個別反應仍有差異。 <a href="#ref-2">[2]</a>

「訓練後 30 分鐘內沒喝到乳清就浪費了」是健身圈流傳已久的說法。Aragon 與 Schoenfeld 在 2013 年發表的系統性回顧檢視既有證據後指出，這個「合成代謝窗口」的證據並不明確；訓練前吃的一餐，其胺基酸供應可以延續進入恢復期，只要一天的總蛋白質攝取量與分餐頻率足夠，運動前後數小時內攝取都能達到相近效果，不必精準卡在半小時內。但該篇回顧也指出，如果訓練距離上一餐已經超過 3–4 小時、處於空腹狀態，運動後儘快攝取至少 25 克蛋白質以扭轉分解代謝狀態，仍是合理的做法，並非完全不用在意時機。 <a href="#ref-6">[6]</a>

## 缺乏風險或攝取不足問題

乳清蛋白補充不足本身不會造成特定「缺乏症」，但整體蛋白質攝取長期不足，會影響肌肉量維持、傷口癒合與免疫功能。幾個族群較容易出現蛋白質攝取不足的情況：高齡者常因食慾下降、咀嚼吞嚥能力變化而減少肉魚攝取，長期蛋白質攝取偏低會加速肌肉量流失。一篇納入 7 篇隨機對照試驗、591 名平均 77 歲高齡肌少症患者的統合分析顯示，阻力訓練搭配乳清蛋白對握力有小幅助益（平均差 2.31 公斤，95% 信賴區間 0.01–4.6，p 值恰好落在 0.05 邊界），但這個幅度並未達到臨床上被視為有意義的最小差異（約 6.5 公斤），證據品質也被評為低至極低，不宜過度解讀為「補充就能明顯變有力」。 <a href="#ref-3">[3]</a> 素食與純素者若飲食規劃不當，可能難以單靠植物性來源湊足每餐所需的必需胺基酸密度；有吞嚥困難（吞嚥障礙）的長者，固態肉類蛋白攝取困難，液態或糊狀的乳清蛋白補充品在質地調整後可以是補足蛋白質缺口的選項之一，但仍需先由醫療團隊評估吞嚥安全性再決定形式與濃稠度。牛奶蛋白過敏或嚴重乳糖不耐者則不適合直接使用乳清蛋白粉。

## 補充品常見形式

市售乳清蛋白粉主要分三種型態，差異集中在蛋白質純度與殘留乳糖量： <a href="#ref-9">[9]</a>

- **濃縮乳清蛋白（WPC）**：蛋白質含量約 25–89%（市售產品多落在 70–80% 區間），保留較多乳糖、脂肪與生物活性成分，價格通常最低。
- **分離乳清蛋白（WPI）**：透過進一步過濾，蛋白質含量提高到約 90–95%，乳糖與脂肪含量明顯低於 WPC，對輕度乳糖不耐者較友善。
- **水解乳清蛋白（WPH）**：經酵素部分水解成更小的胜肽，消化吸收更快、腸胃負擔理論上更低，常見於醫療營養品或標榜「好吸收」的產品，但價格也最高。

三種型態在「提升肌肉量與肌力」的長期效果上，目前沒有一致證據顯示彼此有實質差異；三者的實際差異主要落在乳糖殘留量（WPC 最高、WPH 最低）與售價（WPH 常比 WPC 貴上一倍以上），這是選購時更值得參考的判斷點。

## 安全性與注意事項

在腎功能正常的族群，適量乳清蛋白或高蛋白飲食的安全性資料相當一致。一篇納入 28 篇隨機對照試驗、1358 名健康成人的統合分析比較高蛋白（平均每公斤 1.81 克）與正常或低蛋白飲食（平均每公斤 0.93 克），介入前後腎絲球過濾率的變化量兩組沒有統計差異，屬健康腎臟的正常生理適應，並未觀察到腎功能受損。 <a href="#ref-4">[4]</a> 這些試驗多為六個月內的短中期研究，且以健康成人為主，不能直接外推到「任何劑量、無限期都安全」。已被診斷慢性腎臟病者，情況完全不同：國際指引與衛生福利部的建議都是限制蛋白質攝取，這部分證據與族群判準，本站在〈[喝乳清蛋白、高蛋白飲食會洗腎嗎？](/myths/whey-protein-kidney-damage-myth/)〉一文有完整整理，兩篇結論一致，差別只在於「你本身的腎功能狀態」這個前提。

其他需要留意的情況：乳糖不耐者飲用含較多乳糖的濃縮乳清蛋白（WPC）後，可能出現腹脹、腹瀉等症狀，可改選分離（WPI）或水解（WPH）型態，或直接改用大豆、豌豆等植物性蛋白粉；對牛奶蛋白過敏者（與乳糖不耐是不同機轉）應完全避免乳清蛋白，改用非乳製品蛋白來源；正在服用特定藥物或有其他慢性病史者，建議先與醫師或藥師確認是否有交互作用疑慮。整體每日蛋白質總攝取量（食物加補充品）建議維持在合理範圍；如前述統合分析所示，超過每公斤體重 1.6 克後，額外攝取對去脂體重與肌力的助益已趨於平緩。 <a href="#ref-2">[2]</a>

## 常見迷思

- **「蛋白質吃越多、肌肉長越快」**：統合分析顯示效果隨攝取量增加而遞增，但約在每公斤體重 1.6 克處趨於平緩，超過這個量的族群層級效益不明顯，不是無上限的線性關係。 <a href="#ref-2">[2]</a>
- **「錯過訓練後 30 分鐘黃金期，補充就沒用了」**：系統性回顧指出這個窗口的證據並不明確，一天的總攝取量與分佈比精準卡時間更關鍵。 <a href="#ref-6">[6]</a>
- **「植物性蛋白效果一定比乳清差」**：在白胺酸總量相同的前提下，12 週阻力訓練期間補充乳清或大豆蛋白分離物，兩組肌力與去脂體重的增加沒有統計差異，差別出現在急性反應而非長期訓練結果。 <a href="#ref-5">[5]</a>
- **「乳清蛋白會傷腎，喝多了要洗腎」**：腎功能正常者的統合分析未見適量高蛋白造成腎功能惡化；已有慢性腎臟病者才需要依醫囑限制，兩者不能混為一談。 <a href="#ref-4">[4]</a>
- **「劑型越貴、標榜吸收越快就一定比較有效」**：WPC、WPI、WPH 在提升肌肉量與肌力的長期效果上沒有一致的優劣證據，劑型差異主要反映在乳糖殘留量與價格，不是效果高低。 <a href="#ref-9">[9]</a>

## 常見問題

### 沒有運動習慣，只是想補充蛋白質，也適合喝乳清蛋白嗎？

可以，但要先確認自己整體飲食的蛋白質總量是否真的不足。乳清蛋白是一種濃縮、方便的蛋白質來源，不是運動者專屬；高齡者、食慾不佳或咀嚼吞嚥能力下降者，若靠一般飲食難以吃到足夠蛋白質，乳清蛋白粉可以是補足缺口的選項之一。台灣衛生福利部建議一般成人每公斤體重約 1.1 克蛋白質、70 歲以上約 1.2 克，可用這個數字概算自己是否有缺口。 <a href="#ref-8">[8]</a>

### 乳清蛋白和一般乳清飲有什麼不同？

差別主要在蛋白質濃度與加工程度。市售保久乳清飲屬於較低濃度的液態產品，蛋白質含量通常不高；乳清蛋白粉則是經過超濾、乾燥等程序把蛋白質濃縮到 70% 以上（濃縮型）甚至 90% 以上（分離型），同樣一份的蛋白質含量遠高於乳清飲。挑選時建議直接看營養標示上每份的蛋白質公克數，而不是只看「乳清」兩個字。 <a href="#ref-9">[9]</a>

### 一天喝好幾匙乳清蛋白，會不會對腎臟造成負擔？

取決於你本身的腎功能狀態（完整證據見上方「安全性與注意事項」段落）。若不確定自己屬於哪一種，可以在健檢或門診安排肌酸酐、eGFR 血液檢查，以及尿液微量白蛋白檢測；eGFR 低於 60 或報告出現異常時，建議先諮詢醫師或腎臟科門診，再決定是否維持目前的蛋白質攝取量。 <a href="#ref-4">[4]</a>

### 乳糖不耐的人可以喝乳清蛋白嗎？

多數輕度乳糖不耐者可以改選分離乳清蛋白（WPI）或水解乳清蛋白（WPH），這兩種型態的乳糖殘留量明顯低於濃縮乳清蛋白（WPC）。若症狀仍明顯，或屬於對牛奶蛋白過敏（非乳糖不耐），則應完全避免乳清蛋白，改用大豆、豌豆等植物性蛋白粉。 <a href="#ref-9">[9]</a>
