## 30 秒認識

- 靈芝（*Ganoderma lucidum*）是少數有 Cochrane 系統性回顧可查的保健成分，而且有兩篇。癌症那一篇納入 5 篇隨機試驗，作者結論是證據不足以支持把靈芝當成癌症的第一線治療，且沒有任何一篇試驗記錄長期存活率。 <a href="#ref-1">[1]</a>
- 心血管那一篇納入 5 篇試驗、398 人，糖化血色素、總膽固醇、低密度脂蛋白、血壓、三酸甘油酯全部沒有顯著差異，結論是現有證據不支持用靈芝處理糖尿病患者的心血管風險因子。 <a href="#ref-2">[2]</a>
- 2025 年一篇彙整 17 篇隨機試驗、971 人的 GRADE 評級統合分析，只在 BMI、肌酸酐、麩胱甘肽過氧化酶與心率上測到顯著但幅度很小的變化，體脂、腰圍、血壓、空腹血糖、血脂、發炎指標與肝功能皆無效果，且所有結果的證據確定性都評為「非常低」。 <a href="#ref-3">[3]</a>
- 孢子粉的三萜含量遠低於子實體。澳門大學團隊測了 12 批孢子粉，破壁率都在 85% 以上，但三萜的相對峰面積不到子實體的一半，且在人工胃腸液中的溶出比在甲醇中更低。 <a href="#ref-13">[13]</a>
- 市售「靈芝」商品裡的物種常常不是 *Ganoderma lucidum*。佛羅里達大學團隊以 DNA 定序檢驗 20 項市售產品，93% 實際上是 *Ganoderma lingzhi*，沒有一項含有嚴格定義的 *G. lucidum*。 <a href="#ref-14">[14]</a>
- 安全議題是真實存在的。粉狀靈芝製品有致命猛爆性肝炎的個案報告，另有與飲酒併用後急性肝損傷的個案。 <a href="#ref-15">[15]</a><a href="#ref-16">[16]</a> 靈芝也被列為可能增加出血風險的草藥。 <a href="#ref-21">[21]</a>

## 基本介紹

台灣人跟靈芝的關係很特別。它幾乎不會出現在自己買給自己吃的清單裡，卻長年穩坐探病禮盒、年節伴手禮與長輩「別人送的」抽屜第一名。這個位置讓它躲過了大部分的檢視：送的人不會研究成分，收的人多半也不會去查它到底做過哪些試驗。

它的研究處境跟大多數保健成分相反。多數成分是「有很多小型正向試驗、沒有系統性回顧」，靈芝則是「有兩篇 Cochrane 系統性回顧，而兩篇的結論都偏冷」。這種對比反而讓靈芝成為練習讀證據的好教材：一個東西被研究得夠久、夠多，仍然可能得不到支持性的結論，而這個結果本身就是有價值的資訊。

## 這是什麼？

靈芝是靈芝科的木材腐朽菌，子實體表面有漆狀光澤，質地木質、味苦。分類上有一個長期存在的混亂：*Ganoderma lucidum* 這個學名過去被套用在幾乎所有具光澤的靈芝屬物種上，但嚴格定義的 *G. lucidum* 原生分布主要在歐洲與部分中國地區，亞洲栽培與研究使用的多半是 *Ganoderma lingzhi*。Loyd 等人 2018 年以核糖體 ITS 與 tef1α 序列檢驗 20 項市售產品與 17 組自種套組，多數市售產品驗出的是 *G. lingzhi*，沒有一項含嚴格定義的 *G. lucidum*，部分產品還混有 *G. applanatum*、*G. australe*、*G. sinense* 等其他物種。 <a href="#ref-14">[14]</a> 讀文獻時，同一個學名底下的東西未必是同一個生物，這一層要先放進腦袋。

被點名的活性成分主要有兩大類。第一類是多醣體，以 β-葡聚醣為主，被認為與免疫調節有關，這一族成分的通則見〈[β-葡聚醣](/ingredients/beta-glucan/)〉。第二類是羊毛固烷型三萜，也就是靈芝酸（ganoderic acids）與相關結構，是苦味的來源，被認為與抗發炎、護肝訴求相關。市售產品的標示通常會寫「多醣體 X%」與「三萜 Y%」，那兩個百分比指的是同一批材料裡不同類別的粗萃取物含量，不是活性成分的生體可用率。

## 在身體裡做什麼？／主要作用機制

免疫這一條是靈芝最主要的機制假說。β-葡聚醣被腸道免疫細胞的模式辨識受體所辨識，理論上可以活化先天免疫。人體端有兩筆比較具體的資料：Chen 等人 2023 年在台灣做的 84 天雙盲試驗，健康成人服用靈芝來源 β-葡聚醣後，CD3+、CD4+、CD8+ 淋巴球、CD4/CD8 比值、自然殺手細胞數與其毒殺活性、血清 IgA 均優於安慰劑。 <a href="#ref-8">[8]</a> Iser-Bem 等人 2024 年在巴西讓高齡女性每日服用 2000 毫克靈芝乾燥萃取物、為期 8 週，觀察到 T 淋巴球增殖反應與細胞激素基因表現的改變，Th17 下降、Th2 上升。 <a href="#ref-9">[9]</a>

這兩篇量到的都是免疫細胞計數與基因表現，也就是替代終點。免疫細胞數字往哪個方向動，跟「比較不容易感冒」「感染時恢復比較快」之間，還隔著一個沒有人做過的臨床試驗。Cochrane 癌症回顧裡的免疫指標同樣是替代終點，CD3、CD4、CD8 分別上升 3.91%、3.05%、2.02%，幅度都是個位數百分點。 <a href="#ref-1">[1]</a>

肝臟這一條的證據集中在動物。四氯化碳、鎘與酒精誘發的肝損傷模型中，靈芝多醣、孢子粉與純化三萜可降低轉胺酶與氧化壓力指標，這一批文獻的數量遠多於人體試驗。人體端只有 Chiu 等人 2017 年在台灣中山醫學大學做的交叉試驗，42 名健康成人服用三萜與多醣強化的靈芝膠囊六個月，總抗氧化能力與麩胱甘肽上升，GOT 與 GPT 分別下降 42% 與 27%，腹部超音波顯示部分受試者由輕度脂肪肝回到正常。 <a href="#ref-10">[10]</a> 這一篇的樣本 42 人、受試者是健康人而非肝病患者，且 2025 年那篇 GRADE 統合分析在合併多篇試驗後並未看到肝功能指標的整體效果。 <a href="#ref-3">[3]</a> 想比較各種護肝成分的定位，可以看〈[如何選對護肝保健品](/articles/liver-supplement-comparison-silymarin-artichoke-tudca/)〉與〈[水飛薊素](/ingredients/milk-thistle/)〉。

血小板這一條要單獨講，因為它連著安全性。Tao 與 Feng 1990 年在 15 名健康志願者與 33 名動脈粥狀硬化患者上做的研究，體外加入靈芝水溶性萃取物可劑量相關地抑制血小板聚集；患者每次 1 公克、每日三次服用兩週後，ADP 誘發的最大血小板聚集抑制率分別為 31.49% 與 17.7%，體外血栓的長度與重量也下降。 <a href="#ref-17">[17]</a> 同年 Gau 等人在 5 名 HIV 陽性血友病 A 患者身上測，估算每日攝入腺苷約 1.35 毫克，血小板聚集試驗前後沒有顯著變化。 <a href="#ref-18">[18]</a> 兩篇方向不一致、樣本都很小、年代都很久遠，但這是「靈芝可能影響凝血」這個說法的原始出處。

## 食物來源／常見來源

靈芝不是必需營養素，沒有攝取需求，也沒有缺乏症。子實體質地木質、味極苦，一般不當食物直接吃，傳統用法是切片煮水或入藥膳。β-葡聚醣這一類多醣在香菇、金針菇、洋菇、木耳等日常食用菇裡都有，日常飲食中吃菇就會攝取到，只是結構與含量不同。以菇蕈類保健品的角度看，另一個常被拿來比較的是〈[猴頭菇菌絲體](/ingredients/lions-mane/)〉。

## 建議攝取量／研究中常見使用方式

臨床試驗的劑量跨度極大，從每日 200 毫克到 11200 毫克都有，療程從 1 週到 24 週。 <a href="#ref-3">[3]</a> 幾個關鍵試驗的設定如下：

- Klupp 2016（第二型糖尿病加代謝症候群）：每日 3 公克，16 週。 <a href="#ref-5">[5]</a>
- Chu 2012（血壓或膽固醇邊緣偏高者）：每日 1.44 公克，12 週交叉設計。 <a href="#ref-6">[6]</a>
- Tang 2005（神經衰弱）：Ganopoly 多醣萃取物每次 1800 毫克、每日三次，8 週。 <a href="#ref-7">[7]</a>
- Chiu 2017（健康成人）：三萜與多醣強化膠囊 225 毫克，午餐或晚餐後服用，六個月交叉設計。 <a href="#ref-10">[10]</a>
- Iser-Bem 2024（高齡女性）：乾燥萃取物每日 2000 毫克，8 週。 <a href="#ref-9">[9]</a>
- Cochrane 心血管回顧可合併的三篇：每日 1.4 至 3 公克，12 至 16 週。 <a href="#ref-2">[2]</a>

這些數字的問題在於它們互相之間不可換算。每日 3 公克的乾燥子實體粉、每日 3 公克的濃縮萃取物、每日 1800 毫克的純化多醣，三者的活性成分含量可以差一個數量級。看到產品標示「每份 3000 毫克」時，要往下看那 3000 毫克是原料粉還是萃取物、萃取比是多少，這一格通常寫得很小。至於連續吃三個月的說法，〈[廠商說建議連續補充三個月](/articles/supplement-course-myth-continuous-supplementation/)〉裡有比較完整的討論。

## 缺乏風險或攝取不足問題

靈芝沒有缺乏症，不吃它不會缺任何東西。

比較該處理的是「為什麼會想吃靈芝」。台灣人補靈芝的三個常見動機分別是免疫力不好、肝不好、癌症治療期間想多做一點。這三個動機底下各有更該先做的事：反覆感染要看是不是有慢性鼻竇炎、糖尿病控制不佳或睡眠不足；肝指數異常要先分清楚是脂肪肝、病毒性肝炎還是藥物性肝損傷；癌症治療期間的營養與體力維持，主治團隊與營養師能給的建議比任何補充品具體。長輩同時吃中藥與西藥的組合風險，見〈[長輩西藥中藥一起吃，哪些組合真的會出事](/articles/elderly-tcm-western-drug-combos-that-matter/)〉。

## 補充品常見形式

台灣貨架上的靈芝依部位與加工方式分成幾種，價差與成分輪廓都很大：

- **子實體（切片、粉末、萃取物）**：傳統形式，三萜含量最高，苦味明顯。多數探討三萜效果的研究使用這一類材料。
- **菌絲體（液態發酵或固態培養）**：發酵槽或穀物基質培養的菌絲，週期短、成本低，多醣相對容易累積，三萜含量通常低於子實體。產品名稱有時只寫「靈芝」，要看成分欄才知道用的是哪一部位。
- **孢子粉與破壁孢子粉**：孢子有堅硬的雙層外壁，未破壁時消化液難以進入，因此市售品多主打破壁率。但 Liu 等人 2020 年測 12 批孢子粉，破壁率都超過 85%，三萜的相對峰面積仍不到子實體的一半，且在人工胃腸液中的溶出量比在甲醇中更低。 <a href="#ref-13">[13]</a> 若你買孢子粉的理由是三萜，這篇的結果跟預期不符。
- **孢子油**：從孢子萃出的脂溶性部分。Wang 等人 2025 年在中國做的 110 人雙盲交叉試驗，12 週後總膽固醇、三酸甘油酯與低密度脂蛋白下降、高密度脂蛋白上升。 <a href="#ref-11">[11]</a> 單篇試驗、單一地區、單一產品，尚未被獨立重複。
- **複方與禮盒**：常見與冬蟲夏草、人參、樟芝等成分同瓶。複方產品的功效訴求來自整組配方，跟靈芝本體的證據無法對應，選購時要分開評估，也要把交互作用一起算。

## 台灣的法規與市場實況

**小綠人管得到的部分。** 台灣的「健康食品」是《健康食品管理法》定義的法定名詞，走查驗登記雙軌制：第一軌個案審查的字號為「衛部健食字第A00000號」，第二軌規格標準審查為「衛部健食規字第000000號」，102 年 7 月 23 日以前核發的為「衛署」開頭。 <a href="#ref-22">[22]</a><a href="#ref-23">[23]</a> 護肝與免疫調節都在食藥署公告的保健功效項目之列，靈芝類產品最常見的也是這兩項。要確認手上這一盒有沒有領證、領的是哪一項，把產品名稱輸入食藥署的健康食品查驗登記許可證資料查詢逐字核對，不要用品牌印象推論。 <a href="#ref-24">[24]</a>

**法定天花板在哪裡。** 《健康食品管理法》對健康食品的定義本身就排除治療、矯正人類疾病的醫療效能。 <a href="#ref-23">[23]</a> 衛福部另訂有「食品標示宣傳或廣告詞句涉及誇張易生誤解或醫療效能之認定基準」，把哪些句子算誇大、哪些算涉及療效列成可比對的清單。 <a href="#ref-25">[25]</a> 靈芝行銷最常出現的抗癌、修復肝細胞、提升免疫力對抗腫瘤這類敘述，可以直接拿那份基準對照。

**禮盒場景的實際風險。** 靈芝的社會腳本是「送禮不會出錯」，但收禮的人如果正在服用抗凝血或抗血小板藥物、正在做癌症治療、或近期要開刀，靈芝剛好落在需要先問過醫師的清單上。 <a href="#ref-21">[21]</a> 送之前問一句對方有沒有在吃薄血藥，比挑品牌重要。同樣的判斷邏輯在別的食物上也成立，例如〈[在吃抗凝血劑可以吃黑木耳嗎](/articles/black-fungus-anticoagulant-bleeding-risk/)〉。

**標示上真正能查核的欄位。** 部位（子實體、菌絲體、孢子粉、孢子油）、萃取比、多醣與三萜的標示含量、健康食品字號，這四項是可以互相比對的。至於「野生」「古法」「頂級」，在法規上不是有定義的字樣。

## 安全性與注意事項

**肝毒性個案。** 2007 年泰國 Ramathibodi 醫院報告一例與靈芝粉末製品相關的致命猛爆性肝炎，作者同時提到 2004 年香港曾有一例類似案例；兩名患者原本服用傳統水煎的靈芝均無不良反應，改用粉末形式一至兩個月後才發生肝毒性事件，且兩人同時使用其他藥物。 <a href="#ref-15">[15]</a> 2023 年美國另有一例 47 歲男性在同時飲酒與服用靈芝粉後出現急性肝炎與明顯轉胺酶上升，保守治療後兩週完全恢復。 <a href="#ref-16">[16]</a> 這些是個案報告，無法估算發生率，但足以說明「天然」與「無風險」是兩件事，也說明粉末製品與水煎用法可能不能等同看待。

**抗凝血與抗血小板。** 靈芝被整合醫學資料庫列為可能增加出血風險的草藥，靈芝萃取物曾被觀察到延長 INR、凝血酶原時間與活化部分凝血活酶時間。 <a href="#ref-21">[21]</a> 原始的人體資料就是 1990 年那兩篇方向不一致的小型研究。 <a href="#ref-17">[17]</a><a href="#ref-18">[18]</a> 實務判斷上，正在服用 warfarin、新型口服抗凝血劑、阿斯匹靈或其他抗血小板藥物的人，把靈芝當成需要先跟醫師或藥師確認的品項。同時服用抗凝血藥與保健品的一般原則，可以參考〈[在吃抗凝血藥或阿斯匹靈可以補魚油嗎](/articles/fish-oil-blood-thinner-interaction/)〉。

**手術與侵入性檢查前。** 基於上述凝血疑慮，術前應納入停用評估。停用時程與品項清單見〈[開刀前要停哪些保健食品](/articles/stop-supplements-before-surgery/)〉。

**免疫抑制劑使用者。** 靈芝的訴求方向是增強免疫反應，理論上會與器官移植後或自體免疫疾病使用的免疫抑制劑作用相反。 <a href="#ref-21">[21]</a> 這一類藥物的治療窗很窄，自行加上任何免疫訴求的補充品都需要事前討論。

**細胞色素 P450。** 一份大鼠實驗測到靈芝多醣會改變 CYP2E1、CYP1A2 與 CYP3A 的活性。 <a href="#ref-20">[20]</a> CYP3A4 是大量常用藥物的代謝路徑，這條訊號目前只有動物資料，但足以構成「多重用藥者要先問過」的理由，相關原則見〈[慢性病藥和保健食品並用你需要知道的 5 件事](/articles/chronic-disease-drug-supplement-interaction/)〉。

**癌症治療期間。** Cochrane 回顧記錄到的不良事件以噁心與失眠為主，未觀察到明顯的血液學或肝臟毒性。 <a href="#ref-1">[1]</a> 但整合醫學資料庫另外提醒，靈芝孢子粉可能使腫瘤標記 CA72-4 上升而干擾追蹤判讀。 <a href="#ref-21">[21]</a> 治療期間要不要用，屬於必須由主治團隊決定的事。

**常見不良反應。** 口乾、噁心、失眠、便祕、皮膚搔癢與頭暈是被記錄過的反應。 <a href="#ref-21">[21]</a> Cochrane 心血管回顧中，服用四個月者發生不良事件的相對風險為 1.67（95% 信賴區間 0.86 至 3.24），未達顯著且均非嚴重事件。 <a href="#ref-2">[2]</a>

**孕婦、哺乳與兒童。** 現有試驗的受試者為成人，缺乏孕期、哺乳期與兒童的安全性與有效性資料。

## 常見迷思

- **「Cochrane 有收，代表有效」**：Cochrane 收錄的是「這個題目值得系統性檢視」，不是「這個東西有效」。癌症那篇的作者結論是證據不足以支持第一線使用，心血管那篇的結論是不支持用於糖尿病患者的風險因子。 <a href="#ref-1">[1]</a><a href="#ref-2">[2]</a> 引用時把結論句一起看完，落差會很明顯。
- **「破壁孢子粉是精華中的精華」**：破壁解決的是外壁阻隔的問題，不會創造原本不存在的成分。孢子粉的三萜含量本來就遠低於子實體，破壁率超過 85% 之後仍是如此。 <a href="#ref-13">[13]</a> 若買它的理由是三萜，這個推論斷在第一步。
- **「多醣體百分比越高越好」**：沒有任何人體試驗以多醣百分比作為劑量單位設計，因此兩瓶產品的多醣標示互比，比的是規格而不是療效。2025 年那篇 17 篇試驗的統合分析，所有結果的證據確定性都被 GRADE 評為非常低。 <a href="#ref-3">[3]</a>
- **「靈芝可以抗癌」**：一篇納入 23 項試驗、4246 名癌症患者的統合分析確實測到較低的死亡風險（風險比 0.82，95% 信賴區間 0.72 至 0.94），但那份分析把雲芝與靈芝相關製品合併在一起，無法單獨歸因給靈芝。 <a href="#ref-4">[4]</a> MD 安德森團隊 2023 年檢視近十年 39 篇臨床研究後的結論是，證據尚不足以建議癌症患者常規使用菇蕈類補充品。 <a href="#ref-19">[19]</a>
- **「天然的東西不會傷肝」**：粉末形式的靈芝製品有致命猛爆性肝炎個案，也有與酒精併用後急性肝損傷的案例。 <a href="#ref-15">[15]</a><a href="#ref-16">[16]</a> 個案報告不能算出風險機率，但足以推翻「零風險」這個前提。
- **「瓶子上寫 Ganoderma lucidum 就是靈芝」**：DNA 檢驗顯示市售產品裡實際上多為 *Ganoderma lingzhi*，部分還混有其他靈芝屬物種。 <a href="#ref-14">[14]</a> 學名與內容物之間的對應關係，比包裝呈現的樣子鬆散。

## 常見問題

### 在吃抗凝血藥，可以吃靈芝嗎？

先問過開藥的醫師或藥師再決定。靈芝被列為可能增加出血風險的草藥，並有延長 INR 與凝血時間的紀錄。 <a href="#ref-21">[21]</a> 原始人體資料只有 1990 年那兩篇小型研究，方向還不一致。 <a href="#ref-17">[17]</a><a href="#ref-18">[18]</a> 資料不足的時候，抗凝血藥的治療窗窄這件事本身就是保守處理的理由。

### 家人在做化療，送靈芝合適嗎？

送之前先問主治團隊。Cochrane 回顧沒有支持把靈芝當第一線治療，MD 安德森的系統性回顧也認為證據不足以常規建議。 <a href="#ref-1">[1]</a><a href="#ref-19">[19]</a> 另有孢子粉可能干擾 CA72-4 判讀的提醒。 <a href="#ref-21">[21]</a> 治療期間任何額外補充品都應該由主治團隊決定。

### 子實體、菌絲體、孢子粉，哪一種比較值得買？

要看你想要哪一類成分。子實體的三萜最高；菌絲體的成本最低、多醣相對容易累積；孢子粉的三萜含量明確低於子實體。 <a href="#ref-13">[13]</a> 各種形式都缺乏頭對頭的人體比較試驗，所以能做的判斷是「這個部位含哪一類成分」，而不是「哪一種比較有效」。

### 靈芝真的能護肝嗎？

人體資料很有限。台灣一篇 42 人、六個月的交叉試驗在健康成人身上看到 GOT 與 GPT 下降。 <a href="#ref-10">[10]</a> 但 2025 年彙整 17 篇試驗的統合分析在肝功能指標上沒有測到整體效果。 <a href="#ref-3">[3]</a> 同時靈芝粉末製品本身也有肝損傷的個案報告。 <a href="#ref-15">[15]</a><a href="#ref-16">[16]</a> 已經有肝病診斷的人，要把它視為需要先跟醫師確認的品項。

### 每天吃多少？要吃多久？

臨床試驗使用過的範圍是每日 200 至 11200 毫克、1 至 24 週。 <a href="#ref-3">[3]</a> 這個範圍太寬，無法導出建議劑量，而且不同形式的活性成分含量差異極大。實務上以產品標示的建議量為準，並注意標示的是原料粉還是萃取物。

### 吃靈芝會有什麼感覺嗎？

被記錄過的反應包括口乾、噁心、失眠、便祕、搔癢與頭暈。 <a href="#ref-21">[21]</a> 這些屬於不良反應而不是效果指標。多數靈芝試驗量的是抽血數字，那些數字在服用期間不會產生任何可感知的變化。

### 血糖或血壓偏高，靈芝有幫助嗎？

現有的合併證據不支持。Cochrane 心血管回顧在糖化血色素、總膽固醇、低密度脂蛋白、血壓與三酸甘油酯上都沒有測到顯著差異。 <a href="#ref-2">[2]</a> 84 人、16 週、每日 3 公克的隨機試驗同樣是陰性結果。 <a href="#ref-5">[5]</a> 香港一篇 26 人的交叉試驗在胰島素與胰島素阻抗指數上有較低的數值，但作者自己指出交叉設計的殘留效應讓血脂結果無法完整分析。 <a href="#ref-6">[6]</a>
