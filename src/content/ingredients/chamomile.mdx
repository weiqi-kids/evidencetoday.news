## 30 秒認識

- 洋甘菊助眠的人體資料不多。12 篇小型試驗合併後，主觀睡眠品質有改善；唯一一篇以失眠症患者為對象的雙盲試驗，睡眠日誌各項指標都跟安慰劑沒有差別 <a href="#ref-4">[4]</a> <a href="#ref-5">[5]</a>
- 台灣有一篇產後婦女喝洋甘菊茶的試驗，喝 2 週時睡眠與憂鬱分數較好，停喝 4 週後兩組就看不出差別 <a href="#ref-6">[6]</a>
- 食藥署平臺把洋甘菊的花、莖、葉列在「供茶包、膳食調理包或萃取後作為原料」，當食品用沒有問題 <a href="#ref-1">[1]</a>
- 要注意的是三種人：吃 warfarin 的人（有 INR 飆到 7.9 合併內出血的病例）、對菊花或艾草這類菊科植物過敏的人、孕婦 <a href="#ref-2">[2]</a> <a href="#ref-10">[10]</a> <a href="#ref-12">[12]</a>

## 基本介紹

韓國藥妝店的睡眠軟糖，成分表上常在主成分後面接一個「캐모마일」，就是洋甘菊；泰國的晚安軟糖與各種花草茶包也常見它。它在這些產品裡多半是配角，主角是 GABA、乳蛋白水解物、南非醉茄或褪黑激素。

這一頁只處理洋甘菊本身。軟糖能不能帶回台灣、韓國怎麼認定睡眠機能原料，見〈[韓國買的睡眠軟糖，能不能帶回台灣](/articles/korea-sleep-gummies-bring-back-taiwan/)〉與〈[泰國買的睡眠軟糖，能帶回台灣嗎](/articles/thailand-sleep-gummies-bring-back-taiwan/)〉；不想靠褪黑激素時還有哪些選擇，整理在〈[睡不好，但不想靠褪黑激素：先試這些有據的方法](/articles/sleep-without-melatonin-alternatives/)〉。同樣常出現在睡眠軟糖裡的草本，另見〈[纈草](/ingredients/valerian/)〉與〈[酸棗仁](/ingredients/sour-jujube-seed/)〉。

## 這是什麼？

**市面上叫「洋甘菊」的，主要是德國洋甘菊，少數是羅馬洋甘菊，兩者都是菊科。**

食藥署食品原料整合查詢平臺把「甘菊／黃金菊／洋甘菊」放在同一個條目，學名列了三個：德國洋甘菊（*Matricaria chamomilla*，又寫作 *M. recutita*）、羅馬洋甘菊（*Anthemis nobilis*）與摩洛哥洋甘菊（*Ormenis multicaulis*），部位是花、莖、葉 <a href="#ref-1">[1]</a>。研究與藥用最多的是德國洋甘菊的頭狀花序，歐洲藥品管理局的傳統草藥評估就是以它為對象 <a href="#ref-3">[3]</a>。

它和中式菊花茶用的菊花不是同一種植物。菊花（杭菊，*Chrysanthemum morifolium*）在同一份平臺資料裡另立條目，頭狀花序列為可直接食用 <a href="#ref-1">[1]</a>。兩者同屬菊科，這一點在過敏那一節會用到。

Segal 與 Pilote 的病例報告提到，洋甘菊被認為含有香豆素類成分 <a href="#ref-10">[10]</a>，這是它和抗凝血藥扯上關係的原因，後面安全性一節會談。至於喝了能不能睡得比較好，要看人體試驗。

## 睡前一杯洋甘菊，人體試驗看到什麼

**主觀睡眠品質的量表分數有改善的訊號，但每篇試驗都小，以失眠症患者為對象的那一篇是陰性結果。**

| 研究 | 對象與做法 | 結果 | 限制 |
|---|---|---|---|
| Hieu 等 2019 統合分析 <a href="#ref-4">[4]</a> | 12 篇隨機與類隨機試驗 | 睡眠品質標準化平均差 -0.73；焦慮狀態合併三篇無差別 | 失眠症只有一篇試驗；多數試驗規模小 |
| Zick 等 2011，美國 <a href="#ref-5">[5]</a> | 34 名失眠 6 個月以上的成人，萃取 270 毫克每天兩次，28 天 | 睡眠日誌各項與安慰劑無顯著差異；總睡眠時間的效果量偏向安慰劑 | 先導試驗，人數少 |
| Chang 與 Chen 2016，台灣 <a href="#ref-6">[6]</a> | 80 名睡不好的產後婦女，喝洋甘菊茶 2 週 | 身體症狀相關睡眠效率與憂鬱分數較低；4 週後兩組無差別 | 對照組沒有喝安慰劑茶 |
| Adib-Hajbaghery 等 2017，伊朗 <a href="#ref-7">[7]</a> | 60 名安養機構長者，萃取膠囊 200 毫克每天兩次，28 天 | 匹茲堡睡眠品質指數改善較多 | 單盲，安慰劑是麵粉膠囊 |

這張表有三件事要看清楚。

第一，**改善多半出現在「睡眠品質」這種主觀量表，不在失眠症本身。** Hieu 2019 的合併結果來自睡眠品質問卷；以 DSM-IV 原發性失眠症患者為對象、用睡眠日誌測量的 Zick 2011，入睡時間、總睡眠時間、夜醒次數都沒有顯著差異 <a href="#ref-5">[5]</a>。美國 NCCIH 的整理也直接寫，洋甘菊對失眠的資料非常少，2019 年的回顧只找到一篇失眠試驗，而且沒有看到效果 <a href="#ref-2">[2]</a>。

第二，**唯一一篇台灣試驗的效果很短。** Chang 與 Chen 收案的台灣產後婦女，喝茶期間分數較好，停喝之後就和對照組一樣 <a href="#ref-6">[6]</a>。對照組沒有喝任何茶，喝熱飲、睡前多一段固定儀式本身的影響，這個設計分不出來。

第三，**歐洲把洋甘菊列為傳統草藥，但用途裡沒有睡眠。** 歐洲藥品管理局草藥委員會依長期使用經驗認可的用途，是輕微腸胃不適、感冒症狀、口腔與喉嚨的輕微發炎，以及皮膚的輕微發炎與小傷口，清單裡沒有失眠或睡眠 <a href="#ref-3">[3]</a>。

焦慮是另一條線。Amsterdam 等 2009 年的試驗中，輕中度廣泛性焦慮症患者吃 8 週萃取，焦慮量表下降較多 <a href="#ref-8">[8]</a>；延續試驗用到每天 1,500 毫克萃取，預防復發的主要結果沒有達到統計顯著 <a href="#ref-9">[9]</a>。這些試驗用的是標準化萃取膠囊，劑量跟一個茶包或一顆軟糖不能直接比。

失眠超過三個月、每週三晚以上，第一線治療是失眠認知行為治療，做法見〈[失眠的認知行為治療（CBT-I）完整指南](/articles/insomnia-cbti-guide/)〉。

## 台灣怎麼管：茶包和萃取可以，當食品沒有問題

**洋甘菊在台灣是可供食品使用的原料，分類是「供茶包、膳食調理包或萃取後作為原料」，沒有每日限量或警語。**

2026 年 11 月 22 日下載食藥署食品原料整合查詢平臺的開放資料比對，洋甘菊的花、莖、葉列在「草、木本植物類（1）」，分類名稱寫明供茶包、膳食調理包或萃取後作為原料，備註欄空白 <a href="#ref-1">[1]</a>。同一個分類底下的植物，多半是適合沖泡或萃取、不適合整株直接當菜吃的。

拿幾種名字相近、容易被搞混的菊科植物對照，身分差很多：

| 植物 | 食藥署平臺分類 <a href="#ref-1">[1]</a> | 這一頁的評估 |
|---|---|---|
| 洋甘菊（花、莖、葉） | 供茶包、膳食調理包或萃取後作為原料 | 本頁 |
| 菊花／杭菊（頭狀花序） | 可直接食用 | 本頁未評估，與洋甘菊同為菊科 |
| 小白菊（feverfew） | 未確認安全性尚不得使用之原料 | 在台灣不能當食品原料 |
| 紫錐菊（全株） | 可直接食用，每日限量 900 毫克並有標示規定 | 本頁未評估 |

小白菊這一列值得記住。國外複方產品的中文翻譯不一定精準，名字裡有「菊」的成分，看學名比看中文品名可靠：洋甘菊是 *Matricaria* 或 *Anthemis*，小白菊是 *Tanacetum parthenium*。平臺本身也提醒它不是正面表列，資料會不定期更新，以最新法規與函釋為準 <a href="#ref-1">[1]</a>。

## 安全性：哪三種人要多想一下

**一般人喝洋甘菊茶，副作用少見；吃 warfarin、對菊科過敏、懷孕的人是例外。**

Ostovar 等 2025 年整理 72 篇試驗，2,896 名受試者用過洋甘菊，回報的不良反應主要是腸胃不適與嗜睡，都輕微、會自行緩解；試驗中沒有過敏事件，但 11 篇病例報告裡有 6 篇是過敏，其中 3 例是全身性過敏反應 <a href="#ref-13">[13]</a>。作者也提醒，28 篇試驗根本沒有報告不良事件，所以「試驗裡很安全」這句話要打折看。

### 吃 warfarin 的人

**目前唯一詳細記錄的出血病例，是一位每天喝 4 到 5 杯洋甘菊茶的 warfarin 使用者。**

Segal 與 Pilote 2006 年報告的這位 70 歲婦人，因為人工二尖瓣長期吃 warfarin。她為了喉嚨痛，每天用一茶匙乾燥洋甘菊泡 4 到 5 杯茶，腿上也一天塗好幾次洋甘菊乳液。第一次急診時 INR 是 3.6，五天後再回急診，INR 升到 7.9，血紅素從 117 掉到 80 g/L，影像看到腹直肌鞘與骨盆後腹腔血腫，輸了 3 單位紅血球與 2 單位新鮮冷凍血漿 <a href="#ref-10">[10]</a>。作者認為最可能的解釋是洋甘菊的香豆素類成分與 warfarin 產生加成作用，經肝臟酵素的影響則判斷不大 <a href="#ref-10">[10]</a>。

這是單一病例，不能推成「喝一杯就會出血」。可以帶走的是：warfarin 對飲食與補充品的變化很敏感，洋甘菊從偶爾喝變成每天好幾杯，就是一種變化。開始或停止固定喝之前，跟開藥的醫師或藥師說一聲，由他們決定要不要提早驗 INR。抗凝血藥與其他保健品的整體判斷，見〈[在吃抗凝血藥或阿斯匹靈，可以補魚油嗎](/articles/fish-oil-blood-thinner-interaction/)〉。

NCCIH 另外提到，洋甘菊與某些經肝臟代謝的藥物有交互作用，也可能降低口服避孕藥的效果 <a href="#ref-2">[2]</a>。

### 對菊科植物過敏的人

**對豬草、菊花、萬壽菊、雛菊過敏的人，比較容易對洋甘菊過敏** <a href="#ref-2">[2]</a>。歐洲藥品管理局把對洋甘菊或其他菊科植物過敏列為禁忌 <a href="#ref-3">[3]</a>。

德國 2009 年報告一名 38 歲男性喝洋甘菊茶一小時後發生全身蕁麻疹、血管性水腫與嚴重呼吸困難，皮膚測試與抗體檢驗都證實是洋甘菊過敏，作者建議對洋甘菊敏感的人一併評估艾草與花粉相關的食物過敏 <a href="#ref-11">[11]</a>。日本 2019 年也有一例，病人本身有艾草花粉症，喝洋甘菊茶後發生全身性過敏反應 <a href="#ref-12">[12]</a>。喝過菊花茶就起疹子、或已知對艾草過敏的人，第一次喝洋甘菊或吃含洋甘菊的軟糖要格外小心。過敏性鼻炎的檢查與用藥選擇，見〈[過敏性鼻炎完整指南](/articles/allergic-rhinitis-guide/)〉。

### 孕婦與哺乳中的人

**孕期與哺乳期的安全資料不足** <a href="#ref-2">[2]</a> <a href="#ref-13">[13]</a>。2009 年有一篇病例報告，描述孕婦喝洋甘菊花草茶後，胎兒動脈導管提早收縮 <a href="#ref-14">[14]</a>。單一病例無法證明因果，但在資料這麼少的情況下，懷孕期間想用洋甘菊茶助眠，先問產科醫師比較穩當。

### 兒童

歐洲藥品管理局的洋甘菊藥品多半限 12 歲以上使用，只有部分製劑建議用於 12 歲以下兒童 <a href="#ref-3">[3]</a>。給孩子喝花草茶之外的萃取產品，先問兒科醫師。

## 常見迷思

- **「洋甘菊茶是天然安眠藥」**：唯一一篇以失眠症患者為對象的雙盲試驗，睡眠日誌各項都跟安慰劑沒有差別 <a href="#ref-5">[5]</a>
- **「軟糖裡有洋甘菊，所以會比較好睡」**：軟糖通常不標示洋甘菊萃取的毫克數，試驗用的是每天 400 到 1,500 毫克的標準化萃取 <a href="#ref-5">[5]</a> <a href="#ref-7">[7]</a> <a href="#ref-9">[9]</a>，無從比對
- **「花草茶不會跟藥衝突」**：有 warfarin 使用者每天喝 4 到 5 杯後 INR 升到 7.9 的病例 <a href="#ref-10">[10]</a>

## 常見問題

### 吃 warfarin 的人可以喝洋甘菊茶嗎？

先問開藥的醫師或藥師。目前有一例每天喝 4 到 5 杯洋甘菊茶的 warfarin 使用者，INR 從 3.6 升到 7.9 並發生內出血 <a href="#ref-10">[10]</a>。偶爾喝和每天固定喝是兩回事，任何飲食習慣的改變都可能讓 INR 波動，醫師或藥師會判斷需不需要提早抽血。

### 睡前喝洋甘菊茶真的能幫助入睡嗎？

就現有資料看，主觀睡眠品質可能小幅改善，入睡時間與總睡眠時間沒有明確改善。12 篇小型試驗合併後睡眠品質分數較好 <a href="#ref-4">[4]</a>，但以失眠症患者為對象的試驗是陰性結果 <a href="#ref-5">[5]</a>。睡前一杯熱茶如果讓你放鬆，可以當作睡前儀式的一部分；長期失眠則需要找出原因。

### 喝菊花茶會過敏的人，可以喝洋甘菊嗎？

不建議自己試。NCCIH 指出對菊花、豬草等相關植物過敏的人比較容易對洋甘菊過敏 <a href="#ref-2">[2]</a>，國外也有喝洋甘菊茶發生全身性過敏反應的病例 <a href="#ref-11">[11]</a> <a href="#ref-12">[12]</a>。可以先跟過敏科醫師討論。

### 懷孕時睡不好，可以喝洋甘菊茶嗎？

先問產科醫師。孕期安全資料不足 <a href="#ref-2">[2]</a>，有一篇胎兒動脈導管提早收縮的病例報告 <a href="#ref-14">[14]</a>。

### 洋甘菊在台灣可以做成膠囊或軟糖賣嗎？

依食藥署平臺，洋甘菊列在「供茶包、膳食調理包或萃取後作為原料」，以萃取物的形式加進軟糖或膠囊，原料本身可以使用 <a href="#ref-1">[1]</a>。產品其他成分是另一回事，例如同一包軟糖裡如果有纈草或褪黑激素，就不能當食品賣。
