## 30 秒認識

- 酸櫻桃（Tart Cherry，學名 Prunus cerasus）是味道酸澀、不適合直接生食的櫻桃品種，和常見拿來當水果吃的甜櫻桃（Prunus avium）是不同物種，市售多加工成濃縮果汁、果乾或粉末膠囊。 <a href="#ref-4">[4]</a>
- 運動後恢復方面，2021 年一篇統合 14 篇試驗的分析發現酸櫻桃對痠痛與肌力恢復有小到中度助益；2026 年一篇方法學更嚴謹、納入 19 篇試驗的最新統合分析則發現對痠痛本身沒有整體顯著效果，效果較穩定的落在肌力恢復與發炎指標，兩篇結論方向接近但強度不同，證據等級多屬低到中等。 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- Montmorency 這個酸櫻桃品種的褪黑激素含量，實驗室分析約是另一常見品種 Balaton 的 6 倍；2012 年一篇 7 天的交叉試驗發現連續飲用濃縮果汁能讓總睡眠時間增加約 34 分鐘，但 2024 年改用市售常見劑量的粉末膠囊、針對過重族群的試驗未能重現這個效果。 <a href="#ref-4">[4]</a> <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>
- 痛風方面，2012 年一篇追蹤一年的觀察性研究發現攝取櫻桃兩天內痛風發作風險降低 35%，但兩篇獨立的隨機對照試驗都沒有測到酸櫻桃能顯著降低血尿酸濃度本身，美國風濕病學會 2020 年的痛風指引也因證據等級太低，沒有對櫻桃或櫻桃萃取做出正式建議。 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a> <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>
- 酸櫻桃製品幾乎都是還原果汁或濃縮液，天然糖分不低；世界衛生組織的游離糖指引明確把果汁與果汁濃縮液的糖列入計算範圍，長期大量飲用需要納入每日總糖量考量。 <a href="#ref-11">[11]</a>

## 基本介紹

酸櫻桃原生於歐洲與西亞，栽培歷史可追溯到羅馬時期，目前美國密西根州是全球最大的酸櫻桃產區，當地栽培的品種以 Montmorency 為主，也是運動營養與睡眠研究中最常被使用的品種。 <a href="#ref-4">[4]</a> 這種櫻桃果肉偏軟、酸度高，直接生食口感明顯不同於超市常見的甜櫻桃，農民採收後多半立即加工，鮮少以生鮮水果的型態上架販售。因為酸度與色澤特性，加工成濃縮果汁後便於長期保存與標準化劑量，這也是多數臨床試驗選擇用濃縮果汁作為介入形式的實務原因。

## 這是什麼？

植物學上，酸櫻桃（Prunus cerasus）與甜櫻桃（Prunus avium）雖然同屬薔薇科李屬，但是兩個不同物種，果實大小、糖酸比與花青素含量都不同。酸櫻桃果皮與果肉顏色深紅到暗紅，這個色澤主要來自花青素（anthocyanin），其中以矢車菊素葡萄糖芸香苷（cyanidin-3-glucosylrutinoside）最具代表性；此外也含有槲皮素（quercetin）、綠原酸（chlorogenic acid）等多酚類化合物。 <a href="#ref-4">[4]</a> 比較特別的是，酸櫻桃是少數天然含有可偵測濃度褪黑激素的食物之一：2001 年 Burkhardt 等人以高效液相層析法分析新鮮冷凍的酸櫻桃，測得 Montmorency 品種每公克約含 13.46 奈克褪黑激素，是同批測試的 Balaton 品種（每公克約 2.06 奈克）的 6 倍以上。 <a href="#ref-4">[4]</a> 不過這個濃度是食物層級的微量濃度，和一般褪黑激素補充錠常見的每錠 0.5 到 5 毫克劑量，落差有數百倍到數千倍之多，這個尺度差異在後面「常見迷思」段落會進一步說明。

## 在身體裡做什麼？／主要作用機制

酸櫻桃在研究中被討論的作用機制，主要分成兩條互不重疊的路徑。第一條是花青素與其他多酚類的抗氧化、抗發炎作用：這類化合物在體外實驗中能清除自由基、抑制環氧化酶（COX）活性，理論上有助於緩和劇烈運動後的氧化壓力與發炎反應。2026 年 Daab 等人的統合分析支持這條路徑的部分證據——酸櫻桃組在運動後 48 小時內的 C 反應蛋白（一種急性發炎指標）下降幅度顯著大於安慰劑組，但同一批分析在肌肉痠痛的主觀感受上卻沒有測到整體顯著差異，顯示發炎指標的改善不必然直接轉換成使用者能感受到的痠痛減輕。 <a href="#ref-2">[2]</a>

第二條路徑是外源性褪黑激素的直接補充。Howatson 等人 2012 年的試驗測量尿液中的 6-硫酸氧褪黑激素（褪黑激素的主要代謝產物）發現，飲用酸櫻桃濃縮液組比安慰劑組高出約 17%，顯示體內確實吸收了果實所含的褪黑激素並代謝排出，這條機制路徑相對直接、有生化證據支持。 <a href="#ref-5">[5]</a>

至於痛風相關的機制，證據反而比較模糊。Zhang 等人在 2012 年的論文中推測，酸櫻桃可能透過提高腎絲球過濾率、增加尿酸排出，或是抑制黃嘌呤氧化酶與黃嘌呤脫氫酶這兩種與尿酸生成有關的酵素，來降低痛風發作風險；但這只是根據觀察性資料推導出的假說。 <a href="#ref-7">[7]</a> 兩篇後續設計嚴謹、直接測量血尿酸濃度的隨機對照試驗——2020 年的劑量反應試驗與 2026 年的急性交叉試驗——都沒有測到酸櫻桃對血尿酸有統計上顯著的降低效果，這代表如果酸櫻桃真的與較低的痛風發作風險有關，作用機制很可能不是（或不只是）透過降低血尿酸濃度本身，兩者之間的因果路徑目前並不清楚。 <a href="#ref-8">[8]</a> <a href="#ref-9">[9]</a>

## 食物來源／常見來源

酸櫻桃不常見於生鮮蔬果區，市售形式以加工品為主，常見的包括：新鮮或冷凍酸櫻桃（多用於烘焙、果醬）、乾燥酸櫻桃乾（口感類似葡萄乾，常額外加糖以平衡酸度）、酸櫻桃濃縮果汁（Montmorency Tart Cherry Concentrate，這是臨床試驗中使用最多的形式，通常需要加水稀釋後飲用）、還原果汁（已稀釋成可直接飲用的濃度），以及近幾年逐漸普及的酸櫻桃粉末膠囊。研究中使用的劑型與劑量差異相當大：Kuehl 等人 2010 年的跑者試驗使用的是 355 毫升瓶裝果汁，一天兩瓶，直接飲用不稀釋；Howatson 等人 2012 年的睡眠試驗則是 30 毫升濃縮液加水稀釋後飲用，一天兩次。 <a href="#ref-3">[3]</a> <a href="#ref-5">[5]</a> 這代表「酸櫻桃」這個名稱底下，實際攝取到的花青素與褪黑激素總量可能差異很大，不同產品之間的效果不一定能互相類推。

## 建議攝取量／常見攝取建議／研究中常見使用方式

酸櫻桃不是必需營養素，台灣與國際上都沒有針對它訂出每日建議攝取量或上限。運動恢復相關的研究中，比較常見的用法是在賽事或訓練前 4 到 7 天開始攝取，持續到賽後 24 到 48 小時，劑量落在每天兩次、每次 30 毫升濃縮液（加水稀釋）或每天兩瓶 355 毫升果汁；睡眠相關的研究則多採每天兩次、每次 30 毫升濃縮液，連續 7 天。 <a href="#ref-3">[3]</a> <a href="#ref-5">[5]</a> 值得留意的是，劑量與效果不必然成正比：Stamp 等人 2020 年針對痛風患者做的劑量反應試驗，把濃縮液劑量從安慰劑一路拉到每天兩次、每次 30 毫升，結果各劑量組在血尿酸濃度、尿液尿酸排出量上都沒有明顯差異，換算下來這是一份把劑量拉到當時研究中數一數二高的試驗，卻沒有測到劑量遞增帶來的額外效果，說明酸櫻桃（至少在血尿酸這個指標上）不是「喝越多效果越好」的線性關係。 <a href="#ref-8">[8]</a>

## 缺乏風險或攝取不足問題

酸櫻桃不是維生素或礦物質，不攝取不會產生特定的營養缺乏症，這點與多數成分解析頁面討論的「缺乏風險」不同。比較適合的討論角度是「哪些人會考慮把它加進飲食」而非「誰缺了它會生病」。規律訓練、恢復期短、需要頻繁銜接下一場比賽或訓練課表的運動員，是目前研究族群最集中的對象，酸櫻桃在這個情境下被當作恢復輔助手段之一，但不是取代睡眠、營養與訓練量調整的替代方案。年長者隨年齡增長，松果體分泌褪黑激素的量會自然下降，這也是酸櫻桃睡眠相關研究常鎖定中高齡或睡眠品質不佳族群的原因之一，不過如前述，2024 年針對過重族群的粉末膠囊試驗並未重現睡眠效果，顯示「年紀較大、睡得不好」不必然等於「補充酸櫻桃就有感」。 <a href="#ref-6">[6]</a> 痛風患者是另一個常被討論的族群，但需要區分清楚：飲食型態的觀察性關聯（吃櫻桃者發作風險較低）與直接介入是否能降尿酸（隨機對照試驗未測到效果）是兩件不同的事，不應該把前者當成後者的證據。

## 補充品常見形式

- **濃縮果汁（Concentrate）**：多數臨床試驗使用的形式，需要加水稀釋，花青素與褪黑激素濃度相對標準化，是目前證據基礎最厚實的劑型。
- **還原果汁（Juice）**：已稀釋完成、可直接飲用，方便性高，但不同品牌的稀釋比例與是否額外加糖差異大，糖分與有效成分濃度都不一定與試驗中使用的產品一致。
- **粉末膠囊**：近年新興的劑型，優點是不含額外糖分、攜帶方便，但 2024 年一篇針對每日 500 毫克粉末劑量的隨機對照試驗，在睡眠與發炎指標上都沒有測到顯著效果，說明粉末劑型的花青素與褪黑激素釋出、吸收特性可能與濃縮果汁不同，現有證據還不足以直接類推濃縮果汁的研究結果到粉末產品上。 <a href="#ref-6">[6]</a>
- **乾燥果乾**：口感接近葡萄乾，多做為零食或烘焙食材，但加工過程常額外加糖以平衡酸味，糖分來源與果汁不同，且目前沒有以果乾為介入形式的臨床試驗可供參考。

## 安全性與注意事項

在現有的臨床試驗族群中，酸櫻桃整體耐受性良好，多數研究沒有報告嚴重不良反應。Stamp 等人 2020 年針對 50 名痛風患者、連續 28 天給予不同劑量濃縮液的試驗，雖然記錄到 24 起不良事件，但研究者逐一檢視後，只有 1 起（血糖偏高）被判定可能與酸櫻桃濃縮液有關，其餘多半與受試者本身的痛風病史或合併用藥有關；這批受試者本身有慢性病、部分同時服用降尿酸藥物，資料不能直接套用到所有健康成人身上，但至少沒有觀察到明顯的劑量相關毒性訊號。 <a href="#ref-8">[8]</a>

糖分是酸櫻桃製品最容易被忽略的安全性考量。世界衛生組織 2015 年發布的糖攝取指引，把「游離糖」定義為製造與調理過程中額外添加的糖，以及蜂蜜、糖漿、果汁與果汁濃縮液中天然存在的糖，並建議成人與兒童的游離糖攝取量降到總熱量的 10% 以下，理想上進一步降到 5% 以下；這個定義特別把果汁與果汁濃縮液算進「游離糖」，和沒有經過打汁破壞纖維的完整水果是分開處理的。 <a href="#ref-11">[11]</a> 台灣衛生福利部國民健康署 2018 年公告的國民飲食指標，建議每日添加糖攝取量不宜超過總熱量的 10%，並明確說明「添加糖」不包括天然存在於完整水果與牛奶中的糖；但這項排除是針對完整水果，酸櫻桃濃縮果汁已經脫離完整水果的型態，是否適用同一項排除原則，官方說明並未特別區分。 <a href="#ref-12">[12]</a> 實務上，一份還原果汁的天然糖分並不算低，長期大量飲用者、糖尿病或糖尿病前期患者，建議把酸櫻桃果汁或濃縮液的糖分算進每日總攝取量中一併考量，並優先選擇沒有額外加糖的產品。

其他需要留意的情況：長期服用抗凝血劑（如 warfarin）者，因為酸櫻桃含有槲皮素等理論上可能影響凝血功能的多酚類，雖然目前沒有專門的人體交互作用試驗資料，建議計畫大量、長期攝取前先與醫師或藥師確認；已診斷慢性腎臟病、需要限制鉀離子或液體攝取者，因為果汁類製品在單位體積內濃縮了較多的糖分與礦物質，這是所有濃縮果汁的共通特性而非酸櫻桃獨有，飲用前建議先與腎臟科醫師或營養師確認可接受的攝取量；懷孕或哺乳期婦女目前缺乏針對濃縮補充品形式的安全性研究資料，建議先與產科或家庭醫師討論。至於正在服用降尿酸藥物的痛風患者，酸櫻桃與 allopurinol 併用時觀察到痛風發作風險降低的資料屬觀察性關聯，不是可以自行調整或減少藥物劑量的依據，用藥調整仍須由醫師依血尿酸數值決定。 <a href="#ref-7">[7]</a>

## 常見迷思

- **「酸櫻桃汁能像消炎止痛藥一樣馬上消除運動痠痛」**：2026 年方法學更嚴謹、樣本數更大的統合分析發現，酸櫻桃對痠痛本身的整體效果沒有達到統計顯著，效果比較穩定的是肌力恢復與 C 反應蛋白這類客觀發炎指標，兩者不是同一件事，感受到的痠痛程度不一定會因為發炎指標下降而立即改善。 <a href="#ref-2">[2]</a>
- **「痛風患者只要喝酸櫻桃汁就能取代降尿酸藥物」**：2012 年的觀察性研究只顯示攝取型態與發作風險降低有關聯，兩篇直接測量血尿酸濃度的隨機對照試驗都沒有測到顯著降尿酸效果，美國風濕病學會 2020 年的痛風指引也因為證據等級不足，沒有對酸櫻桃或其萃取物做出正式建議，不宜當成藥物的替代品。 <a href="#ref-8">[8]</a> <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>
- **「酸櫻桃含褪黑激素，效果等於吃褪黑激素補充錠」**：Montmorency 酸櫻桃每公克約含 13 奈克褪黑激素，一份 30 毫升的濃縮液換算下來只提供微克等級的攝取量，和市售褪黑激素補充錠常見的每錠 0.5 到 5 毫克（相當於 500 到 5000 微克）相比，劑量差距達到數百倍以上，兩者不能等量齊觀。 <a href="#ref-4">[4]</a>
- **「天然食物就沒有糖分疑慮，酸櫻桃汁可以無限暢飲」**：世界衛生組織的游離糖定義明確把果汁與果汁濃縮液的糖列入計算，一份還原果汁的天然糖分並不算低，長期大量飲用者仍需要把它算進每日總糖量，天然來源不等於沒有攝取上限的考量。 <a href="#ref-11">[11]</a>

## 常見問題

### 酸櫻桃汁要連續喝幾天，才可能對運動恢復有幫助？

目前的研究設計多半是在賽事或高強度訓練前 4 到 7 天開始飲用，並持續到活動結束後 24 到 48 小時，不是單次飲用就能期待效果。即使照這個時程攝取，2026 年最新的統合分析也提醒，對痠痛本身的整體效果證據等級偏低，比較穩定觀察到的是肌力恢復與發炎指標的變化，實際感受因人而異。 <a href="#ref-2">[2]</a>

### 已經在服用降尿酸藥物的痛風患者，可以同時喝酸櫻桃汁嗎？

多數觀察性資料顯示併用時痛風發作風險更低，沒有出現明顯的安全性警訊，但這不代表可以自行減少藥物劑量或用酸櫻桃取代治療。是否調整用藥必須由醫師依定期追蹤的血尿酸數值與臨床狀況決定，酸櫻桃頂多是飲食層面的輔助選項之一。 <a href="#ref-7">[7]</a>

### 想靠酸櫻桃幫助睡眠，該選果汁還是粉末膠囊？

目前證據比較支持的是濃縮果汁形式：連續 7 天、每天兩次 30 毫升濃縮液加水稀釋的用法，在對照試驗中測到睡眠時間與效率的提升。粉末膠囊雖然標榜濃縮方便，但 2024 年一篇每日 500 毫克粉末的試驗沒有測到睡眠或發炎指標的差異，兩種劑型不能直接互相類推效果。 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>

### 糖尿病或血糖偏高的人，適合喝酸櫻桃汁嗎？

需要謹慎看待糖分。酸櫻桃濃縮液與還原果汁的天然糖分並不低，在世界衛生組織的游離糖架構下會被算進每日糖量上限，建議先與醫師或營養師討論攝取的份量與頻率，並優先選擇沒有額外加糖的產品，避免與其他含糖飲食疊加，超出每日糖分建議範圍。 <a href="#ref-11">[11]</a>
