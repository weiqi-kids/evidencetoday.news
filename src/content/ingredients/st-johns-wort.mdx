## 30 秒認識

- 聖約翰草最重要的性質是讓別的藥變弱：成分貫葉金絲桃素活化孕烷 X 受體，誘導肝臟 CYP3A4，也可能誘導藥物外排轉運蛋白，許多藥物因此被更快清除 <a href="#ref-1">[1]</a> <a href="#ref-6">[6]</a>
- 已有人體資料的受害藥物包括口服避孕藥、環孢素、warfarin、digoxin、HIV 蛋白酶抑制劑與部分抗憂鬱藥，後果從突破性出血、移植排斥到病毒抗藥都有 <a href="#ref-4">[4]</a> <a href="#ref-8">[8]</a> <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>
- 交互作用的強度跟產品裡的貫葉金絲桃素量有關，同樣叫聖約翰草，不同產品可以差很多 <a href="#ref-7">[7]</a>
- 治療輕中度憂鬱的證據不算弱，Cochrane 回顧顯示優於安慰劑、與標準抗憂鬱藥相近，但試驗多半只有 4 到 12 週，而且德語系國家的試驗結果明顯較有利 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>
- 在台灣，聖約翰草列在「未確認安全性尚不得使用之原料」，藥品許可證資料中也查不到任何一張含它的藥品 <a href="#ref-17">[17]</a> <a href="#ref-18">[18]</a>

## 基本介紹

在台灣讀到「聖約翰草」這個名字，多半是在三個地方：海外保健品網站的情緒類分區、國外旅遊帶回來的草本膠囊，以及醫師或藥師在問診時那句「有沒有吃什麼草藥」。它在不同國家的身分差異很大。Ng 等 2017 年的統合分析開頭就寫到，它在許多歐洲國家是有藥證、被廣泛處方的抗憂鬱用藥 <a href="#ref-3">[3]</a>；日本厚生省 2000 年的報道發表則把含聖約翰草的產品當成健康食品處理，同時要求業者標示與醫藥品併用的注意事項 <a href="#ref-16">[16]</a>。台灣兩條路都沒有開：不能當食品原料，也沒有藥品許可證 <a href="#ref-17">[17]</a> <a href="#ref-18">[18]</a>。

所以台灣人手上的聖約翰草，實際上幾乎都繞過了台灣的把關系統。這也是這一頁的重點：買的時候沒有人看過它和你的藥合不合，吃的時候也很少有人想到要告訴醫師。

這一頁處理證據與交互作用。正在吃避孕藥的人該加什麼防護、正在吃抗憂鬱藥的人能不能併用，各有專文接續；開刀前要停哪些保健品，〈[開刀前要停哪些保健品](/articles/stop-supplements-before-surgery/)〉已經把聖約翰草列在影響藥物代謝的那一類。

## 這是什麼？

聖約翰草是金絲桃科金絲桃屬的貫葉連翹（*Hypericum perforatum*），中文別名還有金絲桃草；食藥署食品原料平臺把這三個名字列在同一筆，部位寫莖、葉 <a href="#ref-17">[17]</a>。同一屬的植物在平臺上的待遇並不一樣：小連翹（*H. erectum*）同樣不得使用，地耳草（*H. japonicum*）的全草卻列在可供食品使用、可做茶包或萃取原料 <a href="#ref-17">[17]</a>。看到「金絲桃屬」或「Hypericum」不能直接畫等號，要看學名的種小名。

研究最多的兩類成分是貫葉金絲桃素（hyperforin）與金絲桃素（hypericin）。前者是交互作用的主角，後者常被產品拿來當標準化指標。Mueller 等 2004 年的試驗把這個差別量出來了：同樣以 digoxin 測試，富含貫葉金絲桃素的高劑量萃取物讓 digoxin 暴露量下降約四分之一，不含貫葉金絲桃素的萃取物 Ze 117，以及茶、果汁、油萃取物與 0.5 至 1 公克的低劑量粉末，都沒有測到顯著影響；貫葉金絲桃素含量只有一半的 2 公克粉末，降幅介於兩者之間 <a href="#ref-7">[7]</a>。

這個結果有兩層意思。一是交互作用和劑量有關，不是全有全無。二是市售產品常以金絲桃素含量作為標準化指標，而真正和交互作用相關的貫葉金絲桃素含量，不一定會標。海外網站買來的那一罐落在哪一格，消費者無從判斷。

## 在身體裡做什麼？

**第一條路：PXR 與 CYP3A4。** Moore 等 2000 年在 PNAS 發表，貫葉金絲桃素是孕烷 X 受體（PXR）的強效配體，抑制常數 27 nM；以聖約翰草萃取物或純貫葉金絲桃素處理人類初代肝細胞，CYP3A4 表現明顯上升 <a href="#ref-1">[1]</a>。PXR 是調控 CYP3A4 的核受體，而 CYP3A4 參與超過一半藥物的氧化代謝，作者因此推測受影響的藥物會比當時已知的多 <a href="#ref-1">[1]</a>。

**第二條路：P-glycoprotein。** digoxin 幾乎不經 CYP3A4 代謝，卻一樣被聖約翰草拉低。Johne 等 1999 年推測機轉是誘導了藥物外排轉運蛋白 P-glycoprotein <a href="#ref-6">[6]</a>；2002 年同一團隊在 amitriptyline 的試驗中，也把 CYP450 與 P-glycoprotein 的誘導並列為可能解釋 <a href="#ref-11">[11]</a>。

**誘導需要時間。** Johne 1999 年的試驗中，第一次併用聖約翰草時 digoxin 濃度沒有變化，連續 10 天後才看到明顯下降，而且作用隨天數逐漸加強 <a href="#ref-6">[6]</a>。Hall 2003 年的避孕藥試驗，則是讓受試者在連續兩個月經週期併用聖約翰草 <a href="#ref-4">[4]</a>。反過來說，停用後誘導作用也不會立刻消失；英國 FSRH 2022 年的指引對所有酵素誘導劑採用同一個時間框架：短期使用者在使用期間與停用後 28 天內，都要另外使用保險套 <a href="#ref-15">[15]</a>。

**第三條路：血清素系統。** 這一條和代謝無關。NCCIH 指出，聖約翰草和某些抗憂鬱藥或其他影響血清素的藥物併用，可能增加血清素相關副作用，而且可能嚴重 <a href="#ref-13">[13]</a>。Lantz 等 1999 年報告了 5 名年長者在處方抗憂鬱藥之外加服聖約翰草後，臨床診斷為中樞血清素症候群 <a href="#ref-12">[12]</a>。這一條的後果方向跟前兩條相反：前兩條是讓藥變弱，這一條是讓作用疊加。

## 會被聖約翰草降效的藥物

**能在人體上量到降幅的，至少有以下這幾類；後果從「藥效打折」一路排到「移植器官被排斥」。**

| 藥物類別 | 機轉 | 人體資料 | 可能後果 |
|---|---|---|---|
| 複方口服避孕藥 | CYP3A4 誘導 | 炔雌醇半衰期 23.4 → 12.2 小時；突破性出血 2/12 → 7/12 <a href="#ref-4">[4]</a>；荷爾蒙暴露量下降 13% 至 15%，出現濾泡生長與可能排卵 <a href="#ref-5">[5]</a> | 避孕失效、不規則出血 |
| 其他荷爾蒙避孕法（單一黃體素藥丸、皮下植入劑、口服緊急避孕藥） | 酵素誘導 | MHRA 2014 年警示包含植入劑 <a href="#ref-14">[14]</a>；FSRH 2022 年列為可能受影響 <a href="#ref-15">[15]</a> | 避孕失效 |
| 環孢素（抗排斥藥） | 代謝加快（酵素誘導） | 兩名心臟移植病人急性排斥 <a href="#ref-8">[8]</a> | 器官排斥 |
| HIV 蛋白酶抑制劑（indinavir） | 代謝加快（酵素誘導） | AUC 下降 57%、8 小時谷值下降 81% <a href="#ref-9">[9]</a> | 病毒抗藥、治療失敗 |
| warfarin | 清除加快（酵素誘導） | S 型清除率增加約 29%，INR 曲線下面積降為 0.79 倍 <a href="#ref-10">[10]</a> | 抗凝不足、血栓 |
| digoxin | P-glycoprotein 誘導 | 10 天後 AUC 下降 25%，谷值比安慰劑組低 33% <a href="#ref-6">[6]</a> | 心衰竭或心律控制變差 |
| 三環抗憂鬱藥（amitriptyline） | CYP450 與 P-glycoprotein | amitriptyline AUC 下降 22%、nortriptyline 下降 41% <a href="#ref-11">[11]</a> | 憂鬱症狀控制變差 |
| 抗癲癇藥（phenytoin、carbamazepine） | 酵素誘導 | NCCIH 列為會被減弱的藥物 <a href="#ref-13">[13]</a> | 癲癇發作 |
| 部分抗癌藥（irinotecan、imatinib、docetaxel） | 酵素誘導 | 同上 <a href="#ref-13">[13]</a> | 治療效果下降 |
| 部分心臟藥（ivabradine）與 statin（simvastatin） | 酵素誘導 | 同上 <a href="#ref-13">[13]</a> | 心率或血脂控制變差 |

Hall 2003 年的試驗還順手量了 midazolam：口服清除率由每小時 109.2 公升升到 166.7 公升，靜脈注射的清除率則沒變 <a href="#ref-4">[4]</a>。口服變快、靜脈不變，表示變化集中在藥物進入全身循環之前的首渡代謝，口服藥因此最容易受影響。同一篇試驗中，有突破性出血的女性，midazolam 口服清除率比沒有出血的人高出一倍以上 <a href="#ref-4">[4]</a>；誘導得越強的人，避孕藥被削弱得越多。

日本厚生省 2000 年的報道發表列出的受影響藥物，與上表大致重疊：indinavir、digoxin、環孢素、theophylline、warfarin 與口服避孕藥 <a href="#ref-16">[16]</a>。那份文件同時建議，正在服用這些藥的人如果在吃含聖約翰草的產品，應停止食用。

## 證據怎麼看：情緒與憂鬱

聖約翰草在憂鬱症上的研究量，是多數草本補充品比不上的，這一點要誠實交代。

Linde 等 2008 年的 Cochrane 回顧納入 29 篇隨機雙盲試驗、5,489 名重度憂鬱症患者。九篇較大型試驗合併後，聖約翰草相對於安慰劑的反應率比值為 1.28，九篇小型試驗則為 1.87；和三環或四環抗憂鬱藥比較的比值為 1.02，和 SSRI 比較為 1.00，因副作用退出的比例也較低 <a href="#ref-2">[2]</a>。同一篇回顧也點出問題：來自德語系國家的試驗，結果系統性地比其他國家有利，試驗精確度與效果大小也有關聯，這讓結果不容易直接解讀 <a href="#ref-2">[2]</a>。三位作者都揭露曾接受製造商的研究經費、演講費或旅費補助 <a href="#ref-2">[2]</a>。

Ng 等 2017 年的統合分析納入 27 篇與 SSRI 直接比較的試驗、3,808 人，結論是輕中度憂鬱的反應率與緩解率相近、退出率較低；作者同時寫明，所有試驗只有 4 到 12 週，長期療效與安全性資料有限，嚴重憂鬱或高自殺風險者是否適用並不清楚 <a href="#ref-3">[3]</a>。NCCIH 的整理方向相同：對輕度或中度憂鬱似乎比安慰劑有效、與標準抗憂鬱藥相近，但嚴重憂鬱與超過 12 週的使用是否成立並不清楚 <a href="#ref-13">[13]</a>。

這些研究用的是有藥證、劑量標準化的歐洲萃取物，受試者由醫師診斷並追蹤。從海外網站買一罐自己吃，跟試驗情境差了診斷、劑量、產品一致性與追蹤四件事。情緒低落持續兩週以上、睡眠也受影響時，該先做的是讓專業的人評估，〈[情緒低落又睡不好兩週，什麼時候該看身心科](/articles/low-mood-poor-sleep-two-weeks-when-to-see-psychiatry/)〉整理了判斷的時間點。番紅花是另一個常被拿來談情緒的成分，證據與限制寫在〈[番紅花](/ingredients/saffron/)〉。

## 台灣的法規地位

**食品：不得使用。** 2026 年 11 月 21 日下載食藥署食品原料整合查詢平臺開放資料，聖約翰草（貫葉連翹、金絲桃草，*Hypericum perforatum*）莖、葉列在「未確認安全性尚不得使用之原料」，備註為未經確認其食用安全性前，不得供為食品原料使用 <a href="#ref-17">[17]</a>。食品安全衛生管理法第 15 條第 1 項第 9 款規定，從未於國內供作飲食且未經證明為無害人體健康者，不得製造、販賣、輸入，條文列出的動作包含輸入 <a href="#ref-19">[19]</a>。

**藥品：查無許可證。** 同一天下載食藥署全部藥品許可證資料集（2026 年 11 月 20 日版），以 Hypericum、St John、貫葉、聖約翰、金絲桃檢索品名與主成分，包含已註銷的許可證在內，結果是 0 筆 <a href="#ref-18">[18]</a>。也就是說，台灣從來沒有核准過含聖約翰草的西藥。

**結果是一個兩邊都進不來的位置。** 美國以膳食補充品販售、歐洲多國以藥品核准，到了台灣，食品那一側被擋在原料清單外，藥品那一側沒有人申請過查驗登記。台灣藥局與一般通路合法上架的產品裡，不會有它。

**海外網購的處境。** 錠狀、膠囊狀食品寄回台灣的 12 瓶、36 瓶額度，前提是那一瓶在台灣算合法食品；聖約翰草不在這個前提裡。個人包裹實際上被攔的機率與處置方式，我們查不到食藥署或關務署的統一公開說明，不在這裡替讀者下結論。四種身分怎麼分、額度怎麼算，〈[海外網購保健品寄回台灣](/articles/overseas-online-supplements-mail-to-taiwan-rules/)〉有完整拆解。

## 國外買的產品要看什麼

如果手上已經有一罐，或是在國外藥局看到它，能做的檢查其實不多，但有三件事值得做。

- **看學名**：*Hypericum perforatum* 才是本頁討論的植物，地耳草等同屬植物的成分與法規身分都不同 <a href="#ref-17">[17]</a>
- **看標準化標示**：產品常標金絲桃素含量，和交互作用相關的貫葉金絲桃素含量不一定標；Mueller 2004 顯示不含貫葉金絲桃素的萃取物與 digoxin 沒有顯著交互作用 <a href="#ref-7">[7]</a>，但這只測了 digoxin 一種藥，不能推論到避孕藥與抗排斥藥
- **看自己的藥袋**：只要藥袋上有避孕藥、warfarin、digoxin、抗排斥藥、抗癲癇藥、HIV 用藥、抗憂鬱藥或抗癌藥，就把這罐帶去給開藥的醫師或藥師看

同時吃好幾種保健品的人，風險不只來自單一成分，〈[保健品一次吃很多種，風險怎麼疊](/articles/supplement-stacking-risk-guide/)〉講了盤點的順序。想先用 AI 工具查交互作用的人，〈[用 AI 查保健品和藥物會不會衝突](/articles/ai-supplement-medication-check/)〉說明了這類工具能做到哪裡。

## 安全性與注意事項

**避孕這一題最常被低估。** Hall 2003 年的受試者連續服用聖約翰草兩個週期，突破性出血由 12 人中 2 人增加到 7 人 <a href="#ref-4">[4]</a>；Murphy 2005 年更進一步看到濾泡生長與可能排卵 <a href="#ref-5">[5]</a>。英國 MHRA 2014 年的建議很直接：使用荷爾蒙避孕的女性不應服用含聖約翰草的草本產品，範圍包含皮下植入劑，只有子宮內避孕器因為沒有資料而不在範圍內 <a href="#ref-14">[14]</a>。FSRH 2022 年的指引補上了時間：酵素誘導劑會讓荷爾蒙清除率在使用期間與停用後一段時間內都上升，子宮內避孕器與長效黃體素注射不受影響 <a href="#ref-15">[15]</a>。

**血清素症候群。** 正在吃抗憂鬱藥的人再加聖約翰草，問題有兩個方向：一方面部分抗憂鬱藥的濃度被拉低 <a href="#ref-11">[11]</a>，另一方面血清素作用可能疊加 <a href="#ref-12">[12]</a> <a href="#ref-13">[13]</a>。不要自己判斷哪一邊佔上風，也不要為了加聖約翰草自行調整抗憂鬱藥，任何改變都先跟開藥的醫師確認。

**光敏感。** NCCIH 指出，大劑量口服或外用後曝曬陽光，可能出現嚴重的皮膚反應 <a href="#ref-13">[13]</a>。

**孕期與哺乳。** NCCIH 指出孕期使用可能增加出生缺陷風險，哺乳母親服用時，嬰兒可能出現腹絞痛、嗜睡與倦怠 <a href="#ref-13">[13]</a>。

**手術前。** Hall 2003 年測到口服清除率變快的 midazolam，本身就是麻醉與檢查時常用的鎮靜藥 <a href="#ref-4">[4]</a>，術前評估時要主動告知麻醉科，停用時間依〈[開刀前要停哪些保健品](/articles/stop-supplements-before-surgery/)〉的原則跟醫師確認。

## 常見迷思

- **「天然草本，跟藥不會衝突」**：聖約翰草是草本補充品裡交互作用證據最完整的一個，從避孕藥到抗排斥藥都有人體資料 <a href="#ref-4">[4]</a> <a href="#ref-8">[8]</a>，〈[天然草本就一定安全嗎](/myths/natural-herbal-safe-myth/)〉也拿它當例子
- **「吃一兩顆不會怎樣」**：誘導作用需要連續幾天才明顯 <a href="#ref-6">[6]</a>，偶爾一顆影響有限；但持續吃一陣子之後，停掉也還要一段時間才回復 <a href="#ref-15">[15]</a>
- **「研究證明它跟抗憂鬱藥一樣有效，可以拿來取代」**：試驗只到 12 週、對象是輕中度且有醫師診斷的病人，德語系試驗結果偏有利 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>；正在用藥的人改用它，還會同時遇到交互作用
- **「茶包比膠囊安全」**：Mueller 2004 中茶與果汁確實沒有影響 digoxin <a href="#ref-7">[7]</a>，但這是單一藥物、單一研究的結果；在台灣，聖約翰草的莖葉本來就不得作為食品原料，茶包也一樣 <a href="#ref-17">[17]</a>

## 常見問題

### 吃避孕藥的人可以吃聖約翰草嗎？

英國 MHRA 的建議是不要 <a href="#ref-14">[14]</a>。人體試驗看到炔雌醇半衰期縮短、突破性出血增加，以及濾泡生長與可能排卵 <a href="#ref-4">[4]</a> <a href="#ref-5">[5]</a>。如果已經在吃，該加什麼保護、要持續多久，先問開避孕藥的醫師或藥師；FSRH 對酵素誘導劑短期使用者的做法是使用期間與停用後 28 天內另外使用保險套 <a href="#ref-15">[15]</a>。

### 停掉聖約翰草之後，藥效多久會恢復？

沒有精確到個人的數字。酵素誘導需要幾天才建立 <a href="#ref-6">[6]</a>，消退也需要時間；FSRH 對所有酵素誘導劑在避孕上採用 28 天的保護期 <a href="#ref-15">[15]</a>。如果正在吃的是 warfarin、抗排斥藥或抗癲癇藥這類需要驗血監測的藥，停用聖約翰草同樣要告訴醫師，因為藥物濃度會往回升。

### 台灣藥局買得到聖約翰草嗎？

依食藥署公開資料，它不得作為食品原料，藥品許可證也查不到任何一張 <a href="#ref-17">[17]</a> <a href="#ref-18">[18]</a>。台灣合法通路上不會有含它的產品，市面上流通的多半來自海外網購或國外帶回。

### 正在吃抗憂鬱藥，可以加聖約翰草嗎？

不要自己加。部分抗憂鬱藥的濃度會被拉低 <a href="#ref-11">[11]</a>，血清素作用又可能疊加，曾有年長者因此出現血清素症候群 <a href="#ref-12">[12]</a>。想調整治療，跟開藥的醫師討論。

### 日本、美國都能買，為什麼台灣不行？

各國的分類方式不同。日本厚生省 2000 年把它當健康食品處理，同時要求標示併用醫藥品的注意事項 <a href="#ref-16">[16]</a>；歐洲多國以藥品核准 <a href="#ref-3">[3]</a>。台灣的食品原料採個別認定，聖約翰草被列為未確認安全性前不得使用 <a href="#ref-17">[17]</a>，而藥品這條路沒有人申請過。

### 只是要助眠或放鬆，偶爾吃可以嗎？

本頁整理的人體證據集中在憂鬱症，助眠與放鬆不是它被研究的主要用途。偶爾吃的交互作用風險較低，但「偶爾」很容易變成每天；只要有在吃上表任何一類藥，就先問過開藥的醫師或藥師。
