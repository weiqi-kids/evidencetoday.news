## 30 秒認識

- BCAA 是白胺酸（leucine）、異白胺酸（isoleucine）、纈胺酸（valine）三種支鏈胺基酸的合稱，是九種必需胺基酸裡的其中三種，長期與乳清蛋白、肌酸並列為健身圈的「補充品三本柱」。 <a href="#ref-1">[1]</a>
- 核心爭議在於：乳清蛋白等完整蛋白質本身就含有這三種胺基酸，還同時提供其餘六種必需胺基酸；Wolfe 在 2017 年整理既有文獻後指出，目前沒有人體試驗直接量化「單獨口服 BCAA」對肌肉蛋白質合成的長期效果，現有的靜脈輸注數據甚至顯示單獨給予 BCAA 會讓蛋白質合成與分解同步下降。 <a href="#ref-2">[2]</a>
- 另一篇急性訊號研究則得到不同結果：運動後單獨喝下 5.6 公克 BCAA，一小時內肌纖維蛋白質合成速率比安慰劑組高出 22%，mTORC1 路徑相關蛋白磷酸化程度也更高。 <a href="#ref-3">[3]</a> 兩篇文獻看的是不同層次的指標，訊號活化不等於長期練出來的肌肉量差異，這個落差正是「BCAA 到底有沒有用」爭論持續的原因。
- 運動後肌肉痠痛的證據偏初步：系統性回顧發現高劑量、長時間、提前於運動前補充的介入方式，對低到中度肌肉損傷可能有幫助，但納入研究異質性高、偏誤風險中等。 <a href="#ref-4">[4]</a>
- BCAA 補充品原本的臨床用途，是治療肝硬化患者的肝性腦病變，這和健身族群的保健品用法是兩回事；血中 BCAA 濃度與胰島素阻抗的關聯也只是觀察性關聯，不代表補充會造成胰島素阻抗。 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>

## 基本介紹

白胺酸、異白胺酸、纈胺酸這三種胺基酸的化學結構都帶有分支狀的碳鏈，是「支鏈胺基酸」名稱的由來。它們在人體代謝路徑上有一個共同特點：多數胺基酸主要在肝臟代謝，支鏈胺基酸卻優先在骨骼肌進行氧化分解，這讓肌肉組織本身就是調節血中 BCAA 濃度的重要場所。 <a href="#ref-1">[1]</a> 這個代謝特性也是運動科學長期關注 BCAA 的切入點：肌肉是支鏈胺基酸的主要去處，補充後理論上有機會直接影響肌肉代謝，而不必先經過肝臟處理。

BCAA 粉末、膠囊在健身補充品市場的定位，和乳清蛋白長期被放在一起比較，兩者常被當成同一類產品的不同選擇。這個比較本身就有問題：乳清蛋白是含九種必需胺基酸的完整蛋白質，BCAA 只佔其中三種；把兩者當成等價的替代品，是後面會反覆出現的誤解源頭。

## 這是什麼？／常見形式

市售 BCAA 產品常標榜 2:1:1（白胺酸：異白胺酸：纈胺酸）的比例。這個比例源自早期運動營養商品的配方慣例，並非某一篇大型臨床試驗證實的最適組合；後續也有廠商推出 4:1:1、8:1:1 甚至更高白胺酸比例的產品，訴求加強 mTOR 訊息路徑的啟動力道。目前沒有頭對頭比較試驗確認哪個比例在長期訓練成效上更好，選擇哪個比例，目前比較像是行銷主張而非證據分級的結果。

三種胺基酸在人體內的角色也不完全對等。白胺酸被認為是觸發肌肉蛋白質合成訊息路徑最關鍵的一個，異白胺酸與纈胺酸的研究數量相對少，多半是作為白胺酸的「同行者」被納入配方，而不是各自有獨立的核心作用機制被充分驗證。這也是部分產品乾脆主打高比例白胺酸、甚至單方白胺酸粉的原因。

常見劑型包括粉末（沖泡飲用）、膠囊錠劑，以及即飲型的運動飲料；部分產品會添加瓜拿納、電解質或風味劑，定位成訓練中飲用的「intra-workout」飲品。

## 在身體裡做什麼？／主要作用機制

白胺酸活化 mTORC1 訊息路徑，是目前解釋「BCAA 可能促進肌肉生長」最常被引用的機制。mTORC1 一旦被活化，會啟動一連串下游反應，推動核糖體生產新的肌肉蛋白質。問題在於，啟動這個路徑只是生產線的開關，真正把蛋白質「做出來」需要原料，也就是完整的九種必需胺基酸同時到位。 <a href="#ref-2">[2]</a> Wolfe 同一篇整理裡也指出一個關鍵限制：單獨補充 BCAA 時，身體還需要從其他地方（通常是分解自身的肌肉蛋白質）取得缺少的六種必需胺基酸，才能完成新蛋白質的合成；兩篇靜脈輸注研究發現，單獨給予 BCAA 反而讓肌肉蛋白質的合成與分解速率雙雙下降，整體蛋白質周轉量縮小，而不是預期中的淨增加。 <a href="#ref-2">[2]</a>

Jackman 等人 2017 年的研究提供了另一個角度：讓十名有阻力訓練經驗的年輕男性在運動後單獨喝下 5.6 公克 BCAA，一小時後肌纖維蛋白質合成速率比安慰劑組高 22%，S6K1、PRAS40 等 mTORC1 下游訊號蛋白的磷酸化程度也明顯提升。 <a href="#ref-3">[3]</a> 這個結果和 Wolfe 的論點並不互相否定，而是在量測不同層次的現象：Jackman 量的是急性訊號活化與短時間內的合成速率，Wolfe 談的是長期淨蛋白質平衡與實際肌肉量變化。訊號路徑被打開，不保證長期下來真的練出更多肌肉，這個落差是解讀 BCAA 相關研究時最容易被忽略的一步。

運動後肌肉痠痛（DOMS）是另一個常被拿來宣傳的效益。Fouré 與 Bendahan 2017 年的系統性回顧整理既有試驗後發現，高劑量、長時間，且在運動前就提早開始補充的介入方式，對低到中度運動造成的肌肉損傷可能有幫助；但納入研究之間的異質性高，整體偏誤風險也被評為中等，作者自己也提醒這個結論還需要更嚴謹的試驗設計驗證。 <a href="#ref-4">[4]</a> 用白話說，「BCAA 能減緩痠痛」目前比較像是初步、方向性的觀察，還不到可以確定推薦的程度。

## 食物來源／常見來源

支鏈胺基酸不是稀有成分，幾乎所有完整蛋白質食物都含有一定比例的白胺酸、異白胺酸與纈胺酸：雞胸肉、牛肉、豬肉、魚肉、雞蛋、乳製品、黃豆製品都是常見來源。這也是為什麼「該不該額外買 BCAA 補充品」這個問題，答案往往取決於日常飲食的完整蛋白質攝取量是否已經足夠，而不是「吃不吃得到」支鏈胺基酸這三個字。

乳清蛋白是常見蛋白質來源中白胺酸比例相對高的一種，本站在〈[乳清蛋白完整介紹](/ingredients/whey-protein/)〉一文有整理其組成與證據；由於乳清蛋白本身就含有完整的九種必需胺基酸，對飲食蛋白質已經充足的人來說，另外加買純 BCAA 粉末，等於是在重複補充蛋白質裡原本就有的成分，而少了其餘六種必需胺基酸的完整供應。素食者若以黃豆、豆類為主要蛋白質來源，同樣能攝取到三種支鏈胺基酸，不需要額外依賴動物性蛋白或 BCAA 補充品。

## 建議攝取量／研究中常見使用方式

BCAA 不是必需營養素本身的補充對象（必需胺基酸才是），沒有官方訂定的每日建議攝取量。運動營養研究裡最常見的急性劑量落在每次 5 到 20 公克之間，訓練前後各補充一次是常見設計。 <a href="#ref-1">[1]</a> 國際運動營養學會的立場聲明把焦點放在「每餐白胺酸攝取量是否達到觸發閾值」，建議每餐攝取 1.7 到 3.5 公克白胺酸，才比較容易達到刺激肌肉蛋白質合成的效果；這個數字多數人透過一份含 20 到 40 公克蛋白質的完整餐點就能達到，不一定需要額外補充純 BCAA 來湊足。 <a href="#ref-7">[7]</a>

這帶出一個實務上的判斷順序：先確認每餐的完整蛋白質攝取量是否已經達標，再考慮是否要額外補充純 BCAA。對飲食蛋白質攝取量偏低、又不方便吃完整餐點的訓練空檔（例如兩餐間隔過長、訓練後暫時沒有食慾），BCAA 飲品的便利性是它比較合理的使用情境；但這個情境下，選擇完整蛋白質（乳清或大豆分離蛋白）同樣能達到目的，而且多提供六種必需胺基酸。

## 缺乏風險或攝取不足問題

因為支鏈胺基酸普遍存在於各種蛋白質食物中，健康人只要整體蛋白質攝取量足夠，幾乎不會出現「支鏈胺基酸攝取不足」這種獨立問題。真正會造成風險的，反而是整體蛋白質攝取量長期偏低；這個情況下，身體同時缺乏九種必需胺基酸，不是單獨缺少白胺酸、異白胺酸或纈胺酸三種。高齡者、節食中或飲食單一的族群，比較實際的介入方向是檢視整體蛋白質攝取是否達標，而不是鎖定某一種胺基酸去補。

## 補充品常見形式

市售 BCAA 產品主要分三種：

- **純 BCAA 粉末或膠囊**：只含白胺酸、異白胺酸、纈胺酸三種胺基酸，不含其餘六種必需胺基酸，也幾乎不含碳水化合物或脂肪。
- **EAA（必需胺基酸）複方**：涵蓋全部九種必需胺基酸，白胺酸比例通常也拉高，定位介於純 BCAA 與完整蛋白質之間。
- **完整蛋白質（乳清、酪蛋白、大豆分離蛋白等）**：天然含有全部必需胺基酸，也含有非必需胺基酸與部分微量營養素。

挑選時的判斷順序建議反過來想：先問自己「一天總蛋白質攝取量夠不夠」，再問「這一餐方不方便吃到完整蛋白質」，最後才輪到「要不要額外加 BCAA」。對已經規律攝取足量乳清蛋白或完整餐點的訓練者，額外買純 BCAA 粉末，多半只是在花錢重複補充蛋白質裡原本就含有的三種胺基酸；對素食者、正在限制熱量導致整體蛋白質攝取偏低的人，或是訓練空檔真的吃不下一整份蛋白質餐點的情況，選擇 EAA 複方或完整蛋白質，會比純 BCAA 更能補齊缺口。

## 安全性與注意事項

健康成人短期使用純 BCAA 補充品的耐受性大致良好，常見不適是輕微腸胃脹氣，市售劑量下的急性毒性風險低。

需要特別留意的幾個情況：

- **楓糖尿症（MSUD）**：這是一種先天代謝異常，患者體內缺乏分解支鏈胺基酸的酵素複合體（BCKDH），白胺酸、異白胺酸、纈胺酸會在血液中異常堆積，若未治療可能導致癲癇、昏迷甚至死亡。MSUD 患者終身須採低支鏈胺基酸飲食，是 BCAA 補充品明確的禁忌族群。 <a href="#ref-8">[8]</a>
- **血中 BCAA 濃度與胰島素阻抗的關聯**：近年代謝研究的一條重要線索是，肥胖與第二型糖尿病患者的血中 BCAA 濃度，往往比代謝健康的族群更高。但這些資料多半來自觀察性研究與動物模型，反映的是「胰島素阻抗的人代謝 BCAA 的能力下降，導致血中濃度升高」，還是「血中 BCAA 濃度升高本身造成胰島素阻抗」，因果方向目前並未確認。 <a href="#ref-6">[6]</a> 把這個流行病學關聯直接解讀成「吃 BCAA 補充品會讓我得糖尿病」是過度推論，目前沒有證據支持健康成人規律運動並補充 BCAA 會因此出現胰島素阻抗。
- **肝性腦病變的臨床脈絡**：BCAA 處方性配方用於肝硬化患者的肝性腦病變，是一套歷史悠久的臨床營養介入。Cochrane 統合分析納入 16 篇試驗、827 名患者，發現 BCAA 能降低肝性腦病變的發生風險，但對整體死亡率沒有明顯影響。 <a href="#ref-5">[5]</a> 這類配方的劑量、搭配成分與使用情境，由醫療團隊依患者肝功能狀態設計，和健身房買的 BCAA 粉末是完全不同的兩件事，不能把臨床處方的邏輯套用在一般保健品使用上。
- **左多巴（帕金森氏症用藥）**：支鏈胺基酸與左多巴在腸道與血腦屏障共用同一套大型中性胺基酸運輸系統，高劑量補充可能影響左多巴的吸收與進入腦部的效率。服用左多巴的患者若考慮補充 BCAA，建議先與醫師討論服藥與補充的時間間隔。
- **肌萎縮性脊髓側索硬化症（ALS）**：一篇彙整既有試驗的系統性回顧指出，BCAA 對 ALS 患者的存活率沒有觀察到助益；一項更早的小型試驗則在高劑量組觀察到死亡人數偏高，因此提前中止收案。 <a href="#ref-9">[9]</a> 單一小型試驗的訊號需要謹慎解讀，但這個族群補充前，仍建議先與主治醫師討論。
- **孕期、哺乳期與慢性肝腎疾病**：安全性資料有限，不建議在沒有醫療團隊評估下自行補充。

## 常見迷思

- **「BCAA 跟乳清蛋白效果一樣，只是比較濃縮方便」**：乳清蛋白含完整九種必需胺基酸，BCAA 只佔其中三種。單獨補充 BCAA 時，身體還需要從其他管道取得缺少的六種必需胺基酸才能完成蛋白質合成，這個差異讓兩者不是對等的替代品。 <a href="#ref-2">[2]</a>
- **「訓練空檔喝 BCAA，效果一定比完整蛋白質好」**：急性訊號研究確實看到單獨補充 BCAA 能活化合成訊息路徑，但這和長期淨蛋白質平衡、實際肌肉量增加是不同層次的指標，目前沒有證據顯示它在長期效果上優於完整蛋白質。 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>
- **「2:1:1 比例是經過證實的黃金比例」**：這個比例源自早期配方慣例，並非特定大型試驗證實的最適組合，市面上同時存在多種比例的產品，目前沒有頭對頭比較試驗確認哪個比例效果最好。
- **「BCAA 是保健食品，吃多安全無虞」**：楓糖尿症患者是明確禁忌族群，服用左多巴者需留意吸收干擾，ALS 患者的高劑量安全性也曾出現疑慮信號，這些都不是「保健食品」三個字就能一概而論的情況。 <a href="#ref-8">[8]</a> <a href="#ref-9">[9]</a>
- **「血中 BCAA 偏高，代表吃了 BCAA 補充品就會得糖尿病」**：血中 BCAA 濃度與胰島素阻抗的關聯來自觀察性研究，因果方向尚未確認，不能直接倒推成「補充 BCAA 會造成胰島素阻抗」。 <a href="#ref-6">[6]</a>
