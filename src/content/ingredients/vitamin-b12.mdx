## 30 秒認識

- 維生素B12（鈷胺素）結構核心是一個以鈷為中心的咕啉環，自然界只有特定細菌與古菌能從頭合成，植物與多數動物都做不到；動物能取得B12，是透過腸道菌或食物鏈間接累積而來。 <a href="#ref-2">[2]</a>
- B12要被人體用到，得先靠胃酸與胃蛋白酶把食物中結合的B12游離出來，再與胃壁細胞分泌的內在因子結合，最後在迴腸末端被吸收，這條路徑任何一段卡關都會影響吸收效率。 <a href="#ref-2">[2]</a>
- 體內只有兩個反應真正用到B12：甲硫胺酸合成酶（影響同半胱胺酸代謝與DNA甲基化）與甲基丙二酸輔酶A變位酶（影響脂肪酸代謝與髓鞘形成），這是B12缺乏會同時牽動血液與神經系統的生化基礎。 <a href="#ref-3">[3]</a>
- 市售補充品常見氰鈷胺、甲基鈷胺、氫氧鈷胺、腺苷鈷胺四種形式，行銷話術常主張某形式「更好吸收」，但目前人體吸收率與臨床效果的頭對頭比較證據仍有限。 <a href="#ref-6">[6]</a>
- 即使沒有內在因子協助，口服高劑量B12仍可能靠被動擴散吸收到約1%的劑量，這是「每日口服1000到2000微克」在臨床上對多數人有效的生理基礎。 <a href="#ref-7">[7]</a>

## 基本介紹

維生素B12常被簡化成「補充就有精神」的保健食品成分，它在生化學上的角色其實具體而明確：是甲硫胺酸合成酶與甲基丙二酸輔酶A變位酶這兩個酵素反應不能缺少的輔酶。這篇文章從B12本身出發，談它的化學結構、人體怎麼把它吸收進來並送到該去的地方、補充品常見的幾種劑型差在哪裡，以及安全性上該留意什麼。

本站另一篇〈維生素B12缺乏：吃素、年長、長期吃胃藥者的神經警訊與檢測〉整理了缺乏的高風險族群、症狀警訊、抽血怎麼驗、口服與注射的臨床選擇，如果想知道「我是不是該去檢查」，建議直接看那篇。這篇定位在成分本身的機制與補充品選購判讀，兩篇內容互補，不重複鋪陳同一組臨床細節。

## 這是什麼？

化學上，維生素B12屬於咕啉類（corrinoid）化合物，結構中心是一個鈷離子，被咕啉環的四個氮原子包圍，環上再依不同形式接上不同的軸向配體，氰鈷胺、甲基鈷胺等不同劑型名稱，就是依配體種類命名的結果，配體換了，化合物名稱與性質也跟著變。 <a href="#ref-2">[2]</a>

B12的合成能力在自然界中相當侷限。StatPearls的資料說明，只有特定的細菌與古菌具備完整的生合成路徑，能把簡單的前驅物一步步組裝成完整的咕啉環結構；植物、真菌與多數動物都沒有這套酵素系統，無法自行製造B12。 <a href="#ref-2">[2]</a> 動物能在體內累積B12，靠的是腸道內共生菌的合成、或透過攝食鏈一路往上傳遞（例如草食動物的瘤胃菌合成後被吸收利用，肉食動物再吃下這些動物），這也解釋了為什麼B12天然集中在動物性食物中，而植物性食物本身不含有效的B12。

市售標示的「97% 純度」「5000微克高單位」等字樣，指的是化合物本身的重量規格，不是人體實際能吸收利用的比例，選購時這兩件事不宜混為一談。

B12的發現過程與惡性貧血（pernicious anemia）這個疾病緊緊綁在一起。二十世紀初，醫界觀察到部分嚴重貧血患者吃動物肝臟後病情明顯改善，當時還不知道背後的活性成分是什麼，直到後續研究才逐步分離、純化出B12這個化合物，並確認惡性貧血的根本原因是胃壁細胞自體免疫受損、無法分泌足量內在因子，導致B12吸收管道中斷。這段歷史也是「內在因子」這個吸收路徑中的關鍵角色，為什麼會被特別命名與研究的由來。

## 在身體裡做什麼？／主要作用機制

B12從食物進到細胞可以使用，要走過一條環環相扣的吸收路徑。食物中的B12多半與蛋白質結合，進入胃部後，胃酸與胃蛋白酶先把這層蛋白質結合關係拆開，讓B12游離出來；游離的B12接著與唾液及胃液中分泌的R-蛋白（又稱haptocorrin）結合，形成複合物通過胃部。進入十二指腸後，胰臟分泌的胰蛋白酶把R-蛋白分解掉，釋放出的B12改與胃壁細胞（壁細胞）分泌的內在因子（intrinsic factor）結合；這個B12–內在因子複合物一路前進到小腸末端的迴腸，被該處黏膜上專一的受器辨識並吸收進入血液。 <a href="#ref-2">[2]</a>

這條路徑任何一段出狀況，都會讓B12吸收打折扣：胃酸分泌不足（如萎縮性胃炎、長期使用抑酸藥物）影響游離步驟，胰臟功能不全影響R-蛋白分解，內在因子缺乏（如惡性貧血、胃切除）影響結合步驟，迴腸發炎或切除則直接少了吸收的場所。這也是為什麼「吃得夠不代表吸收得到」在B12身上格外成立。

簡單說：B12缺了，血液和神經會同時出問題，原因就在接下來這兩個酵素反應上。吸收進入血液後，B12真正發揮作用的地方是甲硫胺酸合成酶與甲基丙二酸輔酶A變位酶這兩個酵素反應。第一個是甲硫胺酸合成酶，以甲基鈷胺為輔酶，把同半胱胺酸甲基化成甲硫胺酸，這個反應同時牽動一碳單位代謝與DNA甲基化，B12不足時同半胱胺酸會堆積，骨髓製造紅血球所需的DNA合成也會受阻，產生體積過大但功能不良的紅血球，也就是巨球性貧血。 <a href="#ref-3">[3]</a> 第二個是甲基丙二酸輔酶A變位酶，以腺苷鈷胺為輔酶，參與特定支鏈胺基酸與奇數鏈脂肪酸的代謝，B12不足時代謝中間產物甲基丙二酸會堆積；這條代謝路徑與神經髓鞘的脂質合成之間的關聯，目前仍屬於機制假說層級，推測異常的脂肪酸代謝產物可能影響髓鞘的脂質組成，但因果關係不像同半胱胺酸堆積那樣證據確立。 <a href="#ref-3">[3]</a> 兩個反應分別卡在不同的代謝節點，這是B12缺乏會同時出現血液學異常與神經學症狀的生化背景，臨床細節與警訊症狀本站已有專文整理，這裡只談機制本身。 <a href="#ref-8">[8]</a>

## 食物來源／常見來源

天然含有效B12的食物集中在動物性來源：內臟（尤其是肝臟）、貝類（蛤蜊、牡蠣）、魚類、蛋與乳製品，含量依部位與種類差異很大，整體上動物性食物是B12的主要天然來源。 <a href="#ref-1">[1]</a> 植物性食物本身不含B12，這是純素飲食必須額外留意的原因。

市面上常被拿來宣稱「含B12」的植物性食材，如螺旋藻、海苔、特定發酵食品，情況比較複雜。Watanabe與同僚1999年發表於《Journal of Agricultural and Food Chemistry》的研究分析市售螺旋藻錠劑後發現，其中的鈷胺素化合物主要是偽維生素B12（pseudovitamin B12），這種類似物無法被人體的B12依賴酵素利用，吃下去不等於補到有效的B12，部分檢驗方法甚至可能把這類類似物也算進「B12含量」，造成標示與實際生物活性脫節。 <a href="#ref-5">[5]</a> Watanabe與同僚後續2014年發表於《Nutrients》的回顧也指出，海苔等部分藻類食品中確實測得到具生物活性的B12，但含量與穩定性受加工方式影響大，不宜單靠這類食材作為素食者的主要B12來源。 <a href="#ref-4">[4]</a>

對素食者而言，較可靠的來源是B12強化食品，例如強化營養酵母、強化豆漿或植物奶、部分強化穀物早餐，這類產品在製造過程中額外添加人工合成的B12（多半是氰鈷胺），生物活性明確,可作為飲食規劃的一部分。 <a href="#ref-4">[4]</a> 選購強化食品時，建議直接看營養標示上的B12含量數字，而不是只看「含B12」這類文字宣稱。

## 建議攝取量／常見攝取建議

一般成人每日建議攝取量落在2.4微克左右，懷孕與哺乳期婦女需求略高，實際數字依年齡、生理狀態與各國訂定標準略有差異，詳細對照建議以衛生福利部國民健康署公告的國人膳食營養素參考攝取量，或NIH ODS的對照表為準。 <a href="#ref-1">[1]</a>

劑量上其實分成兩種完全不同的情境，容易被混在一起看。單純因為飲食型態（如全素、動物性食物攝取偏少）想日常保養、沒有抽血確認缺乏的人，對應的是前段提到的一般建議攝取量（2.4微克），市售綜合維生素或單方補充品常見的每日數十到數百微克劑量，已遠超過這個保養需求，吃這個區間多半足夠；這種情況下不需要比照治療劑量服用。已經抽血確認缺乏、或醫師評估需要積極矯正者，才會用到下面這種治療型高劑量，兩者的出發點與劑量級距不同，混用容易誤判「要補就要補到治療劑量」。

臨床研究與補充品市場上，「每日口服1000至2000微克」是常見的治療型高劑量做法，遠高於一般建議攝取量，這個劑量設計是為了讓即使沒有足量內在因子協助的人，也能靠被動擴散吸收到足夠的量，詳細機制見下一節。 <a href="#ref-7">[7]</a> 一般飲食已能攝取足量B12、也沒有吸收障礙的人，額外補充高劑量不會帶來已知的生理優勢，只是因為B12是水溶性維生素、多餘部分可經腎臟排出，這種「補多了也排掉」的特性讓高劑量補充品在市場上較少引發立即的安全疑慮。實際該落在保養劑量還是治療劑量，建議依抽血結果與醫師或營養師討論，不要自行比照治療劑量長期服用。

這裡有個常被忽略的生理限制：內在因子協助的主動吸收路徑，單次能處理的B12量其實有上限，一般估計一餐大約只能吸收1.5到2微克左右，就算一次吃進大量天然食物來源的B12，這條路徑也無法全部吸收利用，多出的部分多半隨糞便排出。 <a href="#ref-2">[2]</a> 這也是為什麼透過食物補足B12需要靠日常規律攝取而非單次吃到飽，而高劑量口服補充品則是刻意繞過這個單次吸收上限，改走不依賴內在因子、沒有這類飽和限制的被動擴散路徑來達到效果。

## 缺乏風險或攝取不足問題

B12缺乏的高風險族群（長期全素者、65歲以上長者、長期使用metformin或PPI類胃藥者、胃切除或減重手術後族群）、典型症狀、以及該怎麼抽血檢測（血清B12、甲基丙二酸、同半胱胺酸），本站〈維生素B12缺乏：吃素、年長、長期吃胃藥者的神經警訊與檢測〉一文已完整整理，這裡不重複鋪陳臨床細節。

這裡補充的是機制面的背景：B12主要儲存在肝臟，正常情況下儲存量可以支撐身體使用好幾年，這也是為什麼飲食型態改變後，缺乏往往不會立刻顯現，而是拖了一兩年甚至更久才被發現。了解這個儲存特性，有助於理解「為什麼要主動檢查、不要等症狀出現才驗」這個建議背後的邏輯。

## 補充品常見形式

市售B12補充品常見四種化合物形式，差異在於咕啉環上接的軸向配體不同：

- **氰鈷胺（cyanocobalamin）**：最常見、生產成本低、化學性質穩定、保存期限長，是多數綜合維生素與單方B12補充品的預設形式。人體吸收後需要先代謝移除氰基，才能轉換成甲基鈷胺或腺苷鈷胺等活性輔酶形式使用。 <a href="#ref-6">[6]</a>
- **甲基鈷胺（methylcobalamin）**：本身就是甲硫胺酸合成酶反應所需的輔酶形式之一，省去氰鈷胺需要的轉換步驟，近年在行銷上常被包裝成「活性形式、吸收更好」的賣點。
- **氫氧鈷胺（hydroxocobalamin）**：臨床上肌肉注射常用的劑型之一，在體內的半衰期較長，部分治療方案選用這個形式來拉長兩次注射間的間隔。
- **腺苷鈷胺（adenosylcobalamin）**：甲基丙二酸輔酶A變位酶反應所需的輔酶形式之一，單方補充品市面上較少見，多半出現在強調「雙輔酶形式」的複方產品中。

Paul與Brady 2017年發表於《Integrative Medicine》的回顧整理了這幾種形式的藥物動力學與臨床資料後指出，雖然甲基鈷胺與腺苷鈷胺理論上省去了體內轉換步驟，但目前頭對頭比較各形式人體吸收率與臨床效果（例如症狀改善程度、血清濃度回升速度）的隨機對照試驗數量仍有限，難以直接斷言某一種形式全面優於氰鈷胺。 <a href="#ref-6">[6]</a> 對多數單純飲食攝取不足、吸收功能正常的人來說，氰鈷胺累積的臨床使用資料最完整；少數帶有特定代謝路徑相關基因變異、或對氰基代謝途徑有疑慮的族群，可能是臨床上考慮使用甲基鈷胺或腺苷鈷胺等形式的情境，但這類決定建議與醫師或營養師討論，不是自行比對行銷文案就能判斷。

## 安全性與注意事項

維生素B12是水溶性維生素，多餘的量主要經腎臟隨尿液排出，NIH ODS的資料顯示目前沒有訂出明確的可耐受攝取上限（UL），無論口服或注射途徑，都未觀察到具一致性、劑量相關的毒性反應。 <a href="#ref-1">[1]</a> 這不代表補充品可以毫無節制地疊加，尤其複方B群產品常把B12和B6、葉酸等其他成分一起放大劑量，B6長期過量本身有周邊神經病變的風險，選購與服用時應整體檢視每日總攝取量，而不是只看B12這一項。

一個容易被忽略的交互影響是B12與葉酸的關係。單獨大量補充葉酸，可能讓B12缺乏引起的巨球性貧血血液指標被矯正、看起來改善，但甲基丙二酸輔酶A變位酶那條路徑不受葉酸影響，神經系統的損傷可能持續進行而不自知。Miller與同僚2024年發表於《Food and Nutrition Bulletin》的回顧整理了這個現象在葉酸強化政策下的臨床意涵，提醒高劑量葉酸補充者，若同時有B12缺乏風險因子，宜一併檢測兩者而非只看血液常規數值。 <a href="#ref-9">[9]</a>

長期使用metformin或PPI類胃藥會降低B12吸收效率，這部分的風險數據、機轉與追蹤建議，本站〈維生素B12缺乏：吃素、年長、長期吃胃藥者的神經警訊與檢測〉一文已詳細整理，這裡不重複列出數字，有需要請直接參考該篇。

孕期與哺乳期婦女B12需求略高於一般成人，若飲食中動物性食物攝取有限，建議與醫師或營養師討論是否需要額外補充，實際劑量不建議自行判斷。

## 常見迷思

- **「B12補充劑是提神、增加體力的保健品」**：B12參與的兩個酵素反應，角色是讓特定代謝步驟得以進行，不是讓代謝加速運轉。體內B12已經充足的人額外補充，目前缺乏對照試驗支持能帶來體感精力提升；真正感受到疲勞改善的，多半是原本已經缺乏、補充後矯正回正常值的族群。把「有感」直接等同於「B12有提神效果」是把因果關係講反了。
- **「吃素就一定要補B12，不補就一定會出問題」**：天然食物中的B12只存在動物性來源，這件事在機制上成立；但實際風險程度因人而異。蛋奶素者可透過蛋、奶、乳製品取得一定量B12；全素者若規律吃強化食品（強化穀物、強化豆奶、強化營養酵母）且攝取量足夠，風險也會比完全不吃任何強化來源的人低。該看的是實際飲食內容裡有沒有可靠的B12來源，用「有沒有吃素」這個單一標籤來套所有人，容易高估或低估個別風險，這點更適合逐案評估。

## 常見問題

### 螺旋藻、海苔這類植物性食物真的能補到B12嗎？

情況因食材而異，不能一概而論。Watanabe與同僚對市售螺旋藻錠劑的分析發現，裡面的鈷胺素化合物主要是人體無法利用的偽維生素B12，吃下去不等於補到有效的B12。 <a href="#ref-5">[5]</a> 部分藻類（如特定處理方式的海苔）測得到具生物活性的B12，但含量與穩定性受加工影響大，不建議把這類食材當成素食者唯一或主要的B12來源，強化食品與補充劑是較可靠的做法。 <a href="#ref-4">[4]</a>

### 甲基鈷胺真的比氰鈷胺「更好吸收」嗎？

目前證據不足以支持這個斷言。甲基鈷胺本身就是甲硫胺酸合成酶反應的輔酶形式之一，理論上省去了氰鈷胺需要的體內轉換步驟，但現有頭對頭比較各形式人體吸收率與臨床效果的隨機對照試驗數量仍有限。 <a href="#ref-6">[6]</a> 對多數人而言，選哪種形式的實際差異可能沒有行銷文案講得那麼大，特定代謝相關考量建議與醫師或營養師討論，而不是只看產品標榜的關鍵字。

### 舌下錠或滴劑，真的比一般口服錠「直接吸收、不用經過腸胃」嗎？

這個說法在機制上站不住腳。B12補充品不論做成錠劑、舌下錠還是滴劑，只要吞下去或在口腔停留後多半仍被吞下，最終吸收的場域還是腸道。高劑量口服能發揮效果，靠的是前面提過的被動擴散路徑，這條路徑本來就不挑特定劑型。Paul與Brady 2017年發表於《Integrative Medicine》的回顧整理各劑型的藥物動力學資料後指出，目前缺乏高品質頭對頭試驗證實舌下錠或滴劑的人體吸收率明顯優於一般吞服錠劑。 <a href="#ref-6">[6]</a> 「舌下含服能跳過腸胃道」比較接近行銷話術，挑哪種劑型可以依個人吞嚥習慣與使用方便度決定，不必為了「吸收更好」的宣稱多付價差。

### 沒有內在因子還能靠口服補到B12嗎？

可以靠被動擴散吸收到一部分。B12的吸收主要路徑需要內在因子協助，但還有一條不依賴內在因子的被動擴散路徑，即使完全沒有內在因子，口服劑量夠高時仍可能吸收到約1%的量。Cochrane 2018年的系統性回顧整合多篇試驗後指出，這也是為什麼每日口服1000到2000微克B12，在臨床上對多數人（包括部分吸收功能受損者）有效的生理基礎。 <a href="#ref-7">[7]</a> 但胃切除、嚴重吸收不良或已有明顯神經症狀者，是否適合單靠口服治療，仍需由醫師評估，不是所有情況都適用。

### 吃高劑量B12會不會中毒或有副作用？

目前沒有明確的可耐受攝取上限（UL），B12是水溶性維生素，多餘的量主要由腎臟排出，無論口服或注射途徑都未觀察到具一致性的劑量相關毒性反應。 <a href="#ref-1">[1]</a> 比較需要留意的是複方產品常把B12和其他有明確上限的成分（如B6、葉酸）一起放大劑量，B12本身雖然安全餘裕大，選購與服用時仍建議整體檢視每日總攝取量，而非只看B12這一項數字。

### 要怎麼知道自己是不是真的缺B12？

單純從「吃不吃素」或「有沒有疲勞感」沒辦法準確判斷，需要抽血檢測。血清B12是第一線篩檢項目，但敏感度有限，必要時會加驗甲基丙二酸或同半胱胺酸提高判讀準確度；誰該優先檢查、怎麼解讀報告、確診後口服或注射怎麼選，本站〈維生素B12缺乏：吃素、年長、長期吃胃藥者的神經警訊與檢測〉一文有完整整理，建議直接參考那篇。

### 煮熟或久放會把食物中的B12破壞掉嗎？

B12對熱比部分水溶性維生素（如維生素C）穩定，一般家常烹調方式（煎、煮、蒸、炒）不會把肉、魚、蛋、乳製品中的B12完全破壞，但長時間高溫烹煮或反覆加熱，仍會讓一部分B12流失，流失比例依食材種類與烹調方式而不同。 <a href="#ref-1">[1]</a> 對一般均衡飲食、規律吃到動物性食物的人來說，正常烹調造成的流失不至於造成缺乏；真正決定攝取是否足夠的，還是飲食型態本身有沒有固定來源，而不是某一餐煮太久會不會「把B12煮光」。

### B12補充劑要跟食物一起吃，還是空腹吃比較好？

目前沒有一致的證據顯示空腹或隨餐服用會讓B12吸收率有明顯差異，這和部分需要搭配油脂吸收的脂溶性維生素不同。 <a href="#ref-1">[1]</a> 實務上多數人選擇隨餐服用是為了方便記得、減少漏吃，而非基於吸收率考量；若服用後出現腸胃不適，改成隨餐吃通常能緩解，這屬於耐受度調整，不代表吸收效果因此變差。
