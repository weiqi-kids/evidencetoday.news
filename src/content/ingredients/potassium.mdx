## 30 秒認識

- 國健署第八版膳食營養素參考攝取量首次訂出鉀的足夠攝取量：19 歲以上男性每天 2,800 毫克、女性 2,500 毫克，哺乳期 2,900 毫克；因證據不足沒有訂上限，原文也寫明這個數字只適用於健康人 <a href="#ref-1">[1]</a>
- 2013 到 2016 年的國民營養調查，19 歲以上國人平均每天吃進 2,555 毫克鉀，鈉鉀莫耳比 2.57；世界衛生組織建議成人每天至少 3,510 毫克 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- 健康的人從食物多吃鉀，沒有證據顯示有害；風險集中在腎臟排鉀能力變差的人，例如慢性腎臟病，以及正在吃 ACEI、ARB、保鉀利尿劑的人 <a href="#ref-1">[1]</a> <a href="#ref-4">[4]</a>
- 低鈉鹽每 1 公克約含 260 毫克鉀，超過半根香蕉的量；食藥署說明腎臟病人不建議食用 <a href="#ref-1">[1]</a> <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a>
- 台灣仍有效的單方口服鉀製劑，不論氯化鉀、葡萄糖酸鉀或檸檬酸鉀，全部登記為須由醫師處方使用 <a href="#ref-5">[5]</a>

## 基本介紹

藥袋上印著 losartan 或 spironolactone 的人，在超市拿起一包標示「低鈉」的鹽，那包鹽每公克大約含 260 毫克的鉀 <a href="#ref-1">[1]</a>。同一包鹽，對腎功能正常、沒吃升鉀藥物的高血壓病人可能是好選擇，對洗腎病人則是食藥署明說不建議的東西 <a href="#ref-4">[4]</a>。

這一頁處理的是鉀這個營養素本身：台灣官方建議一天吃多少、台灣人實際吃多少、鉀集中在哪些食物，以及哪些人不能自己補鉀、不能自己換低鈉鹽。依降壓藥類別逐一分流的完整說明，在〈[吃降血壓藥的人，低鈉鹽、香蕉、鉀補充品要不要避開？](/articles/blood-pressure-meds-potassium-low-sodium-salt/)〉；eGFR 分期怎麼看，在〈[慢性腎臟病完整指南](/articles/chronic-kidney-disease-egfr-guide/)〉；冬天火鍋與補湯的鈉怎麼算，在〈[羊肉爐、薑母鴨一鍋湯的鈉，超過一整天的量了嗎？](/articles/hotpot-tonic-sodium/)〉。

## 這是什麼？在身體裡做什麼？

**鉀是細胞內最主要的陽離子，全身約 98% 的鉀待在細胞裡。** 國健署第八版鉀章節整理的數字是：細胞內液的鉀濃度約每公升 145 毫莫耳，血漿與組織間液只有 3.8 到 5 毫莫耳，肌肉存放了全身約七成的鉀 <a href="#ref-1">[1]</a>。這個內高外低的落差，由細胞膜上的鈉鉀幫浦耗能維持，每次把三個鈉離子送出細胞、兩個鉀離子送進細胞 <a href="#ref-1">[1]</a>。

這個濃度差是神經傳導與肌肉收縮的基礎，心肌尤其敏感。章節原文寫得直接：鉀缺乏時心肌興奮性增高，鉀過高時心肌的自律性、傳導性和興奮性受抑制，兩種情況都可能引起心律失常 <a href="#ref-1">[1]</a>。這也是為什麼鉀的問題同時有兩個方向，吃太少與排不掉都會出事。

**吸收幾乎全收，排出幾乎全靠腎臟。** 健康的人對食物中的鉀吸收率至少 85%，吃進去的鉀約 77% 到 90% 從尿液排出，其餘主要經糞便，少量經汗液 <a href="#ref-1">[1]</a>。血鉀升高時，腎上腺會分泌醛固酮，讓腎臟集尿管把更多鉀排進尿裡 <a href="#ref-1">[1]</a>。所以鉀的安全性幾乎等於腎臟的排鉀能力：腎臟正常時多吃的鉀會被排掉，章節引述的研究中大幅增加攝取量，血漿濃度仍幾乎不變；腎臟或醛固酮這條路被疾病或藥物卡住時，同樣的量就可能堆在血液裡 <a href="#ref-1">[1]</a>。

血清鉀的正常範圍是每公升 3.5 到 5.5 毫莫耳，低於 3.5 稱為低鉀血症 <a href="#ref-1">[1]</a>。各醫院檢驗科的參考值略有不同，以報告上的範圍為準。章節也提醒，血鉀受身體恆定機制調控，不是反映平常吃多少鉀的敏感指標 <a href="#ref-1">[1]</a>，抽血正常不代表飲食的鉀夠，抽血偏高也不一定只是吃太多。

## 一天要多少：國健署的原文怎麼寫

**台灣第一次有鉀的建議量，是 2022 年公告的第八版膳食營養素參考攝取量。** 章節前言寫明，過去的版本沒有鉀，這次新增；因為缺乏足夠證據訂平均需要量與建議攝取量，只訂足夠攝取量，也暫不訂慢性疾病風險降低攝取量與上限攝取量 <a href="#ref-1">[1]</a>。

足夠攝取量的訂法，是用 2013 到 2016 年國民營養調查中「健康者」的攝取量中位數。成年男性取 50 到 70 歲無高血壓等疾病者的中位數，四捨五入為 2,800 毫克；女性取 19 到 70 歲中位數的最大值，訂為 2,500 毫克 <a href="#ref-1">[1]</a>。兒童與青少年則依熱量需要量，由成人數字推算 <a href="#ref-1">[1]</a>。

| 年齡 | 男性（毫克／天） | 女性（毫克／天） |
|---|---|---|
| 0–6 個月 | 400 | 400 |
| 7–12 個月 | 900 | 900 |
| 1–3 歲 | 1,500 | 1,500 |
| 4–6 歲 | 2,100 | 1,900 |
| 7–9 歲 | 2,400 | 2,200 |
| 10–12 歲 | 2,700 | 2,500 |
| 13 歲以上（含 71 歲以上） | 2,800 | 2,500 |
| 懷孕期 |  | 2,500 |
| 哺乳期 |  | 2,900 |

（資料：國健署第八版膳食營養素參考攝取量鉀章節 <a href="#ref-1">[1]</a>）

有三句原文，比表格上的數字更重要：

- **只適用於健康人。** 章節寫明，因為高鉀血症可能對心臟造成嚴重不利影響，足夠攝取量不適用於患有會損害鉀排泄之疾病或使用相關藥物的人，尤其老年人更需注意 <a href="#ref-1">[1]</a>
- **沒有上限不等於沒有風險。** 不訂上限，是因為健康族群中鉀中毒的證據不足；原文接著寫，腎功能受損或高風險的人仍應避免補充過多鉀，鉀補充劑建議在醫療監督下使用 <a href="#ref-1">[1]</a>
- **鉀與鈉要一起看。** 章節引用世界衛生組織的看法，鈉鉀莫耳比接近 1 被認為對健康較有益 <a href="#ref-1">[1]</a>

世界衛生組織 2012 年的指引分兩層：以食物增加鉀攝取來降低血壓與心血管疾病風險是強建議；成人每天至少 90 毫莫耳，也就是 3,510 毫克，是條件式建議 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>。台灣的足夠攝取量比這個數字低，因為它是依台灣健康成人的實際攝取量訂的，兩者回答的問題不同。

## 台灣人實際吃多少

**多數台灣成人沒有吃到世界衛生組織的建議量，女性也大多低於自己的足夠攝取量。** 依 2013 到 2016 年國民營養調查的 24 小時飲食回憶，19 歲以上全體平均每天 2,555 毫克鉀，男性 2,737 毫克、女性 2,379 毫克 <a href="#ref-1">[1]</a>。

| 族群 | 平均鉀攝取（毫克／天） | 鈉鉀莫耳比 |
|---|---|---|
| 19–50 歲男性 | 2,724 | 2.88 |
| 51–64 歲男性 | 2,792 | 2.35 |
| 65 歲以上男性 | 2,701 | 2.40 |

鈉鉀莫耳比在每一個成人族群都超過 2，離章節引述的理想值 1 有段距離；年輕男性最高，到 2.88 <a href="#ref-1">[1]</a>。章節也提到，1988 年的國際比較研究 INTERSALT 用 24 小時尿液測量 32 國 52 個族群，台灣是鉀攝取最低的地區之一 <a href="#ref-1">[1]</a>。

台灣人的鉀從哪裡來？19 到 64 歲成人第一名是深色蔬菜，每天提供 381 毫克，占 15%；第二是新鮮水果 260 毫克，第三是豬肉及其製品 247 毫克 <a href="#ref-1">[1]</a>。和 2005 到 2008 年相比，深色蔬菜與水果提供的鉀減少，豬肉略增 <a href="#ref-1">[1]</a>。

**第一，鹽與醬油的鉀密度遠超過蔬果。** 資料庫的低鈉鹽樣品，內容物寫的是氯化鉀、氯化鈉與其他添加物，每 100 公克含鉀 26,007 毫克、鈉 18,341 毫克 <a href="#ref-3">[3]</a>，與國健署章節「1 克含鉀減鈉鹽約含 260 毫克鉀」的說法一致，章節也提醒不同產品的置換比例不同，鉀含量會有差異 <a href="#ref-1">[1]</a>。同樣叫薄鹽醬油，資料庫裡一個標示低鈉高鉀的樣品每 100 公克 2,676 毫克，另一個只標低鈉的樣品是 372 毫克 <a href="#ref-3">[3]</a>，差了七倍。包裝上的「低鈉」「薄鹽」不會告訴你用的是減量還是以鉀代鈉，要看成分欄有沒有「氯化鉀」。

**第二，乾豆與乾貨的數字是生重，煮過會少很多。** 國健署章節整理的烹調研究：水煮豆類的鉀含量會降到未烹煮時的 50% 以下，白米洗過再蒸煮約剩 50%；蔬菜加熱 1 分鐘與 3 分鐘，葉菜類鉀流失分別約 10% 到 20% 與 30% 到 50%，瓜果類 1% 到 10% 與 10% 到 20%，根莖類 5% 到 10% 與 10% 到 20%，菇蕈類 20% 到 30% 與 30% 到 40% <a href="#ref-1">[1]</a>。鉀溶進了水裡，所以湯與菜汁才是鉀集中的地方。冷凍蔬菜在殺菁時也會流失部分鉀，見〈[冷凍蔬菜營養比新鮮的差嗎？](/myths/frozen-vegetables-nutrition-myth/)〉。

## 哪些人不能自己補鉀，也不能自己換低鈉鹽

**判斷的核心只有一個：你的腎臟還能不能把多吃的鉀排掉。** 會讓這條路變窄的，是疾病與藥物。下面幾類人，鉀的多寡要跟醫師或營養師一起依抽血數字決定。

| 族群 | 為什麼 | 官方或研究依據 |
|---|---|---|
| 慢性腎臟病、洗腎病人 | 腎臟是排鉀的主要器官，排鉀能力較差，易造成高血鉀 | 食藥署：腎臟疾病病人不建議食用低鈉鹽 <a href="#ref-4">[4]</a>；KDIGO 2024 <a href="#ref-6">[6]</a> |
| 吃 ACEI（-pril）、ARB（-sartan）的人 | 藥物有保鉀作用，高鉀飲食可能提高高血鉀風險 | 國健署鉀章節 <a href="#ref-1">[1]</a>；食藥署 <a href="#ref-4">[4]</a> |
| 吃保鉀利尿劑的人（spironolactone 等） | 直接減少腎臟排鉀 | 國健署 <a href="#ref-1">[1]</a>；食藥署 <a href="#ref-4">[4]</a>；SSaSS 排除 <a href="#ref-9">[9]</a> |
| 吃心律不整用藥的高血壓病人 | 食藥署點名換低鈉鹽可能造成血鉀堆積 | 食藥署 <a href="#ref-4">[4]</a> |
| 糖尿病、心臟衰竭、腎上腺功能不全 | 鉀攝取量要依腎功能、合併症、用藥與血鉀個別調整 | 國健署鉀章節 <a href="#ref-1">[1]</a> |
| 長者，尤其同時吃多種藥 | 足夠攝取量不適用於有排鉀障礙的人，老年人更需注意 | 國健署鉀章節 <a href="#ref-1">[1]</a> |

### 為什麼低鈉鹽的好結果，不能直接套用到這幾群人

含鉀代鹽在試驗裡的結果很好。台灣自己的證據來自中研院團隊：Chang 等 2006 年在一所榮民之家，把五個廚房隨機分組，一組改用 49% 氯化鉀的代鹽，約 31 個月後，代鹽組心血管疾病死亡的年齡校正風險比是 0.59，心血管住院支出也較少 <a href="#ref-7">[7]</a>。規模最大的 SSaSS 試驗收了 20,995 人，代鹽組的中風、心血管事件與死亡都比較少 <a href="#ref-8">[8]</a>。

但 SSaSS 的收案條件寫明排除三種人：本人或同住家人在用保鉀利尿劑、在吃鉀補充品，或有嚴重腎功能障礙 <a href="#ref-9">[9]</a>。最該問「我能不能換低鈉鹽」的人，正好是試驗刻意不收的人。食藥署的說法也是同一個方向：任何病人改用低鈉鹽前，先詢問專業醫療人員 <a href="#ref-4">[4]</a>。依藥物類別逐一怎麼處理，見〈[吃降血壓藥的人，低鈉鹽、香蕉、鉀補充品要不要避開？](/articles/blood-pressure-meds-potassium-low-sodium-salt/)〉。

### 看病拿到抗生素時，多說一句

長期吃 ACEI 或 ARB 的長者，還有一個容易被忽略的組合。Antoniou 等 2010 年分析加拿大安大略省 66 歲以上、持續使用這兩類降壓藥的人，開立 trimethoprim-sulfamethoxazole（一種磺胺類複方抗生素，常用於泌尿道感染）後 14 天內因高血鉀住院的勝算，是開立 amoxicillin 的 6.7 倍；其他幾種對照抗生素沒有看到這個風險 <a href="#ref-10">[10]</a>。這是加拿大的資料，台灣的處方習慣不一定相同，但做法很簡單：在診所或急診拿到抗生素時，把自己吃的降壓藥告訴醫師或藥師。

### 腎臟病人的飲食，方向在調整

KDIGO 2024 慢性腎臟病指引對第 3 到 5 期、曾經高血鉀的人，建議限制「高生物可利用鉀」的食物，舉的例子是加工食品，並建議由腎臟營養師做個別評估 <a href="#ref-6">[6]</a>。指引的執行摘要也提到，高血鉀的飲食建議轉向避開高度加工食品，而非一律避開蔬果 <a href="#ref-6">[6]</a>。蔬菜要不要先燙過、水果一天幾份，答案取決於每次抽血的數字，這一頁給不出通用規則。eGFR 落在哪一期代表什麼，見〈[腎絲球過濾率落在 60 到 90，算腎臟病嗎？](/articles/egfr-60-90-kidney-function-what-it-means/)〉。

## 鉀太低的那一邊：誰會流失

**鉀不夠的問題，在台灣多半是吃得少，但也有一群人是被藥物或狀況帶走。** 國健署章節列出的情況包括：

- **吃非保鉀利尿劑的人**：thiazide 類與環利尿劑會增加尿鉀流失、降低血鉀，章節寫明這類用藥者可能需要增加鉀的攝取 <a href="#ref-1">[1]</a>
- **長時間在高溫下勞動或劇烈運動的人**：汗液的鉀流失可達每天 390 到 2,300 毫克 <a href="#ref-1">[1]</a>
- **長期大量吃甘草的人**：甘草酸會讓血鉀下降、血壓上升，劑量與族群見〈[甘草](/ingredients/licorice/)〉

低鉀血症可能導致心律不整、肌肉無力與葡萄糖耐受不良，常見原因包括利尿劑、代謝性鹼中毒與醛固酮生成增加 <a href="#ref-1">[1]</a>。即使是吃 thiazide 的人，要補也是醫師依抽血決定：台灣有效的單方口服鉀製劑全部是處方藥 <a href="#ref-5">[5]</a>，第一步是讓醫師知道你在意這件事。

## 鉀補充劑在台灣是什麼身分

**在台灣，單方的口服鉀製劑是處方藥。** 2026 年 11 月 21 日下載食藥署全部藥品許可證開放資料，篩選仍有效、主成分只有一種鉀鹽的口服製劑，氯化鉀持續性藥效錠、葡萄糖酸鉀錠與內服液、檸檬酸鉀錠共 7 張許可證，藥品類別全部是「須由醫師處方使用」 <a href="#ref-5">[5]</a>。其中檸檬酸鉀的適應症與腎結石有關，跟一般想像的「補鉀」用途不同。

這代表兩件事。第一，醫師開的鉀片有特定理由與劑量，吃完要回診抽血。第二，從國外代購、以膳食補充品名義販售的鉀產品，在台灣沒有經過同樣的處方把關；正在吃 ACEI、ARB 或保鉀利尿劑的人，自行加吃鉀補充品，正是 SSaSS 這種大型試驗會直接排除的情境 <a href="#ref-9">[9]</a>。

## 高血鉀的訊號，什麼時候要就醫

**高血鉀常常沒有症狀，抽血是唯一可靠的發現方式。** 美國國家醫學圖書館 MedlinePlus 列出的常見原因，包括 ACEI、ARB 與 spironolactone 這類降壓藥，以及代鹽或補充品帶來的額外鉀 <a href="#ref-11">[11]</a>。

有症狀時可能出現胸痛、呼吸困難、噁心嘔吐、心悸、脈搏變慢變弱或不規則、突然昏倒 <a href="#ref-11">[11]</a>。正在吃上面提到的藥物、有慢性腎臟病，又出現這些症狀，不要等回診，直接就醫或撥 119，並告訴醫師最近有沒有換鹽、吃鉀補充品或大量喝果汁、菜湯。

健檢報告上的血鉀紅字，處理方式取決於你吃什麼藥、腎功能如何；藥要不要調整，一律跟開藥的醫師或藥師確認，不要自己停降壓藥。

## 常見迷思

- **「鉀是好東西，多補一點有益血壓」**：從食物多吃鉀，對健康的人沒有不利影響的證據 <a href="#ref-1">[1]</a>；補充劑則是另一回事，排鉀能力受損的人長期大量使用可能引發高血鉀與心律不整 <a href="#ref-1">[1]</a>
- **「低鈉鹽是健康鹽，人人都該換」**：試驗對象排除了用保鉀利尿劑、鉀補充品與嚴重腎功能障礙的人 <a href="#ref-9">[9]</a>；食藥署說明腎臟病人不建議食用 <a href="#ref-4">[4]</a>
- **「腎不好就不能吃香蕉，但多喝湯沒關係」**：鉀會溶進水裡，煮過的菜湯與肉湯才是鉀集中的地方 <a href="#ref-1">[1]</a>
- **「抽血鉀正常，代表飲食的鉀夠了」**：血鉀受身體恆定機制調控，不是攝取量的敏感指標 <a href="#ref-1">[1]</a>
- **「國健署沒訂上限，所以吃多少都安全」**：不訂上限是因為健康族群的證據不足，原文寫明腎功能受損或高風險的人仍應避免補充過多鉀 <a href="#ref-1">[1]</a>

## 常見問題

### 國健署建議成人一天吃多少鉀？

第八版膳食營養素參考攝取量的足夠攝取量，19 歲以上男性每天 2,800 毫克、女性 2,500 毫克，懷孕期 2,500 毫克、哺乳期 2,900 毫克 <a href="#ref-1">[1]</a>。這個數字只適用於健康人，有慢性腎臟病或吃會影響排鉀藥物的人，要照醫師或營養師依抽血給的目標。

### 我在吃 losartan，可以用低鈉鹽嗎？

先問開藥的醫師，並確認最近一次的血鉀與 eGFR。食藥署點名吃血管張力素轉化酶抑制劑與保鉀利尿劑的高血壓病人，改用低鈉鹽可能造成血鉀堆積 <a href="#ref-4">[4]</a>；losartan 屬於 ARB，國健署鉀章節把 ACEI 與 ARB 一起列為有保鉀作用的藥物 <a href="#ref-1">[1]</a>。換了之後的下一次抽血，也讓醫師知道你換過鹽。

### 洗腎的家人可以用薄鹽醬油嗎？

先看成分欄有沒有氯化鉀。資料庫裡一個標示低鈉高鉀的薄鹽醬油樣品，每 100 公克含鉀 2,676 毫克 <a href="#ref-3">[3]</a>，用的就是以鉀代鈉的做法；食藥署說明腎臟疾病病人不建議食用低鈉鹽 <a href="#ref-4">[4]</a>，同樣原理的調味料也應該先問腎臟科營養師。

### 吃利尿劑抽血發現鉀偏低，可以自己買鉀片嗎？

不建議自己買。台灣有效的單方口服鉀製劑全部是須由醫師處方使用的藥品 <a href="#ref-5">[5]</a>，劑量與要不要補，需要醫師依血鉀、腎功能與你同時吃的其他藥決定。國外代購的鉀補充品沒有經過這道處方把關。

### 流很多汗之後，要喝運動飲料補鉀嗎？

一般人從食物補就夠了。國健署章節提到高溫或高強度活動時汗液的鉀流失可以很大 <a href="#ref-1">[1]</a>，但資料庫裡一個運動飲料樣品每 100 公克只含 18 毫克鉀 <a href="#ref-3">[3]</a>，一根香蕉約 459 毫克 <a href="#ref-3">[3]</a>。有腎臟病、心臟病或在吃升鉀藥物的人，補水補電解質的方式先問醫師。
