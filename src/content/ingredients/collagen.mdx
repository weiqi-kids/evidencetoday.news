## 30 秒認識

- 吃下去的膠原蛋白**不會直接變成皮膚裡的膠原蛋白**。它和其他蛋白質一樣，在腸道被分解成胺基酸與小胜肽才吸收，身體再依自己的需求決定拿去合成什麼。 <a href="#ref-1">[1]</a>
- 這個領域近年討論的重點轉向**特定膠原胜肽（collagen peptides）作為訊號分子**的可能性：某些二肽與三肽（如 Pro-Hyp）可完整吸收進入血液，被推測會刺激纖維母細胞活性。這是假說層級的機制，尚未定論。 <a href="#ref-2">[2]</a>
- 皮膚相關的人體試驗多為業界贊助、樣本數十至數百人、期程 8 至 12 週，測量的是含水量與彈性等儀器指標。統合分析傾向支持小幅改善，但研究品質與發表偏誤的疑慮存在。 <a href="#ref-3">[3]</a>
- 膠原蛋白**缺乏必需胺基酸色胺酸**，蛋白質品質評分低，不適合當作主要蛋白質來源。 <a href="#ref-1">[1]</a>
- 真正確立能影響膠原蛋白合成的營養素是**維生素 C**——它是脯胺酸與離胺酸羥化酶的必需輔因子，缺乏時膠原蛋白結構就不穩定。

## 基本介紹

膠原蛋白是人體含量最多的蛋白質，約佔全身蛋白質的三分之一，構成皮膚真皮層、肌腱、韌帶、軟骨、骨基質與血管壁的結構骨架。它由三條多肽鏈纏繞成三螺旋，特徵是高比例的甘胺酸、脯胺酸與羥脯胺酸。

理解它的結構有助於判讀市場語言：**羥脯胺酸的形成需要維生素 C 作為輔因子**，這是膠原蛋白合成中少數有明確營養依賴性的步驟。相對地，「補充膠原蛋白本身」在生理上要經過完整的消化與重新合成，中間沒有捷徑。

## 這是什麼？

市售產品多為**水解膠原蛋白（hydrolyzed collagen）／膠原胜肽**，即經酵素分解成分子量較小的片段以提高溶解度與吸收。原料來源分：

- **牛源、豬源**：多為第一型與第三型膠原蛋白。
- **魚源（海洋膠原）**：分子量常較小，訴求吸收較佳；素食者仍不適用。
- **雞源（含第二型）**：常用於關節訴求產品，其中未變性第二型膠原（UC-II）走的是免疫耐受機制，與水解膠原的邏輯不同。

「素食膠原蛋白」則是名稱上的行銷用法——植物不含膠原蛋白，這類產品通常是提供合成所需的胺基酸與維生素 C 等輔因子。

## 在身體裡做什麼？／主要作用機制

口服膠原蛋白進入腸道後被蛋白酶分解為胺基酸與小胜肽。 <a href="#ref-1">[1]</a> 一般蛋白質到這裡故事就結束了——身體拿到的是原料，去向由需求決定。

膠原胜肽領域提出的額外假說是：部分含羥脯胺酸的二肽與三肽（如 Pro-Hyp、Hyp-Gly）能以完整形式通過腸道進入血液循環，並在皮膚等組織被偵測到，可能作為**訊號**刺激纖維母細胞增生與細胞外基質合成。 <a href="#ref-2">[2]</a>

這個機制目前的證據等級是：胜肽確實可測得進入血液（藥動學證據較紮實），至於它們是否真的在人體中驅動了臨床上有意義的膠原新生，仍以動物與細胞實驗為主。判讀相關廣告時，區分「胜肽被吸收」與「皮膚變好」這兩件事很重要。

## 食物來源／常見來源

含膠原蛋白的天然食物包括帶皮的肉類、雞爪、豬腳、魚皮、以及長時間熬煮的大骨湯（其中的明膠即為變性膠原蛋白）。

要注意的是：**這些食物同時帶來相當的脂肪與熱量**，而它們提供的胺基酸，其他蛋白質來源同樣提供得到。把豬腳當成護膚食品，營養上並不划算。

從「支持膠原蛋白合成」的角度，更實際的做法是確保**足量的總蛋白質攝取**與**足夠的維生素 C**。

## 建議攝取量／常見攝取建議／研究中常見使用方式

膠原蛋白不是必需營養素，沒有每日建議攝取量。必需的是構成它的胺基酸，而這些由日常蛋白質攝取提供。

人體試驗中，皮膚相關研究常見的劑量是每日 2.5 至 10 公克水解膠原胜肽，連續 8 至 12 週；關節相關研究的劑量範圍類似，UC-II 則使用每日 40 毫克這種明顯較低的量（因為機制不同）。 <a href="#ref-3">[3]</a>

## 缺乏風險或攝取不足問題

膠原蛋白沒有「缺乏症」。與它相關的臨床狀況是**壞血病**——維生素 C 不足導致羥化步驟無法完成，膠原蛋白結構不穩定，表現為牙齦出血、微血管脆弱、傷口難癒。

換言之，會讓膠原蛋白出問題的是**維生素 C 不足或整體蛋白質不足**，而不是「沒有補充膠原蛋白產品」。年齡增長造成的膠原蛋白減少屬於生理老化過程，受紫外線曝曬、吸菸、血糖控制等因素影響更大。

## 補充品常見形式

- **粉狀水解膠原**：最常見，無味者可加入飲品；每份劑量通常較高。
- **飲品型**：便利但常添加糖，且每份劑量差異大。
- **膠囊錠劑**：劑量通常遠低於研究使用量，需看清每日總量。
- **複方**：常與維生素 C、玻尿酸、彈力蛋白同配。維生素 C 的搭配在機制上是合理的（羥化輔因子），但也讓效果歸因變困難。

選購重點：看**每份的膠原胜肽克數**（而非產品總重）、來源（過敏史者留意魚源與牛源）、以及是否有第三方重金屬檢驗。

## 安全性與注意事項

一般使用安全性良好，常見的不適是腹脹、飽足感與口中異味。需要留意的是：

- **過敏**：魚源、牛源、雞源產品對相應過敏者可能引發反應。
- **腎功能不全**：屬蛋白質補充，高劑量時蛋白質總量需納入醫囑管理。
- **痛風／高尿酸**：部分海洋來源產品的普林含量值得留意。
- **重金屬**：來源動物的皮骨可能累積重金屬，第三方檢驗有其意義。
- **蛋白質品質**：膠原蛋白缺乏色胺酸，**不應取代日常蛋白質來源**。 <a href="#ref-1">[1]</a>

## 常見迷思

- **「吃膠原蛋白就能直接補到皮膚」**：口服後會被分解成胺基酸與小胜肽，身體依自身需求重新分配，沒有「哪裡缺就補到哪裡」的機制。 <a href="#ref-1">[1]</a>
- **「喝大骨湯可以補膠原蛋白」**：大骨湯提供的是明膠與胺基酸，同時帶來脂肪與熱量，胺基酸供應並不優於一般蛋白質食物。
- **「有素食膠原蛋白」**：植物不含膠原蛋白，這類產品提供的是合成所需的胺基酸與輔因子，名稱屬行銷用法。
- **「補膠原蛋白比補維生素 C 重要」**：維生素 C 是羥化酶的必需輔因子，缺乏時膠原蛋白結構直接受影響；這是機制上更確立的一環。
