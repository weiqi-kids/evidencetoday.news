## 30 秒認識

- 目前沒有任何人體試驗單獨測過葛花能不能減輕宿醉。唯一含葛花的宿醉試驗是三種植物的複方，主要作者是產品廠商員工 <a href="#ref-7">[7]</a> <a href="#ref-9">[9]</a>
- 葛花和葛根是同一株植物的不同部位，研究方向剛好相反：葛花被宣稱能「解酒」，葛根裡的大豆苷則在實驗室中會抑制分解乙醛的酵素，美國的葛根研究把它當成「讓人少喝一點」的工具在測 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a> <a href="#ref-5">[5]</a>
- 沒有資料顯示吃了葛花能讓酒測值降到標準以下。想開車，唯一可靠的變數是喝了多少與經過多久
- 葛花在人身上證據最多的用途是減重，來自日本同一家原料商的兩篇小型試驗；日本消費者廳 2017 年曾因葛花減重產品的廣告，一次對 16 家業者發出措置命令 <a href="#ref-11">[11]</a> <a href="#ref-23">[23]</a>
- 台灣的規定有三條線：食藥署食品原料平臺把野葛的花列為只能做茶包、調理包或萃取原料，卻把甘葛藤的花列為尚不得使用；中醫藥司 115 年 4 月草案把葛花列入第二類，每人每日 1.5 公克；食品廣告寫「解酒」屬於易生誤解的詞句 <a href="#ref-15">[15]</a> <a href="#ref-17">[17]</a> <a href="#ref-20">[20]</a>

## 基本介紹

尾牙前一週，便利商店結帳櫃檯旁會多出一排小瓶的解酒飲，網購頁面上的「葛花護肝錠」也開始打折。成分表上常見的組合是葛花、枳椇子（拐棗）、薑黃、朝鮮薊，加上幾種胺基酸。葛花出現的頻率高，是因為它在中醫典籍裡一直和「解酒」綁在一起。

這一頁只回答一個問題：葛花在人身上被測過什麼，那些結果能不能支持你在尾牙前買一瓶。酒精在身體裡怎麼代謝不在這裡重講；吃了藥還能不能喝，依藥物分在各自的頁面，例如〈[吃降血糖藥的人，尾牙、春酒可以喝酒嗎](/articles/diabetes-medication-alcohol-year-end-party/)〉與〈[吃抗生素可以喝酒嗎](/articles/antibiotics-alcohol-which-ones/)〉。葛花在減重保健品裡的角色，〈[葛花、白腎豆和甲殼素差在哪](/articles/weight-loss-supplement-evidence-guide/)〉已經比較過，這裡只補那篇沒寫到的法規與後續發展。

## 這是什麼？

葛花是豆科葛屬植物的乾燥花與花蕾。中醫藥司 115 年 4 月預告的草案把兩種基原都收為「葛花」：野葛（*Pueraria montana* var. *lobata*，舊學名 *P. lobata*）與甘葛藤（*P. montana* var. *thomsonii*，舊學名 *P. thomsonii*），使用部位是乾燥花及花蕾 <a href="#ref-17">[17]</a>。同一株植物的根就是葛根，是葛根湯的主藥，日本的葛餅、葛切也用葛根澱粉做。

Chen 等 2023 年在《Journal of Ethnopharmacology》的系統性回顧整理，葛花已分離出 39 種類黃酮、19 種皂苷與 25 種揮發油，含量最高、研究最多的是鳶尾苷（tectoridin）與葛花苷（kakkalide）兩種異黃酮 <a href="#ref-1">[1]</a>。同一篇回顧也坦白寫，葛花大多數純化成分的藥理活性根本沒有人報告過，研究資源集中在少數幾個成分上 <a href="#ref-1">[1]</a>。

這兩種異黃酮本身作用不大，要先被腸道細菌切掉糖基。Shin 等 2006 年用人類糞便菌做實驗，所有檢體都能把葛花苷轉成鳶尾黃素類的 irisolidone、把鳶尾苷轉成鳶尾黃素（tectorigenin）；轉換後的代謝物在乳癌細胞株上刺激增生的作用比原型更強，也能誘導雌激素反應基因表現 <a href="#ref-2">[2]</a>。這是體外實驗，但它解釋了後面安全性一節為什麼會提到荷爾蒙。

## 葛花和葛根，在酒精這件事上可能方向相反

**市面上的「葛」系解酒產品，有些放的是花，有些放的是根，兩者的研究方向並不一致。**

葛根的代表成分是大豆苷（daidzin）。Keung 與 Vallee 1993 年在《PNAS》發表，從葛根分離出的大豆苷能強力而有選擇性地抑制人類粒線體乙醛去氫酶（ALDH2），這個酵素負責把乙醛轉成醋酸；它對另一型乙醛去氫酶的作用弱了近千倍，對酒精去氫酶則沒有影響 <a href="#ref-3">[3]</a>。這是試管裡的酵素實驗，人體吃進一般劑量的葛根後效果多大，這篇沒有回答。

墨爾本大學的 McGregor 2007 年在《Alcohol》期刊整理既有資料後提出警告：葛花才是傳統用來處理宿醉的部位，葛根卻被西方許多解酒產品登記為主成分；葛根抑制 ALDH2、可能讓乙醛增加，長期在大量飲酒時使用，理論上可能提高乙醛相關疾病的風險，他建議比照戒酒藥 disulfiram 的方式看待葛根 <a href="#ref-4">[4]</a>。這是一篇論述型回顧，沒有新的人體數據，但它點出一個買解酒產品時很實際的問題：包裝上寫「葛」，要看清楚是花還是根。

美國哈佛麥克林醫院的團隊確實把葛根萃取物當成「減少喝酒量」的工具在研究。Lukas 等 2013 年的試驗中，17 名每週平均喝 27.6 杯的年輕男性每天服用萃取物 4 週，每週飲酒杯數比安慰劑組少 34% 至 57%，渴求感沒有改變 <a href="#ref-5">[5]</a>；Penetar 等 2015 年讓 20 名男性在喝酒前 2.5 小時吃單劑萃取物，自由飲用的啤酒從平均 3.0 罐降到 1.9 罐，喝得也比較慢 <a href="#ref-6">[6]</a>。這兩篇量的是「喝了多少」，與宿醉輕重、酒精代謝快慢都無關，而且部分作者持有這個萃取物的專利或商業利益 <a href="#ref-5">[5]</a>。

把這幾篇放在一起，可以確定的只有一件事：「葛」這個字不能讓你推論產品對酒精做了什麼。葛花本身有沒有加速乙醛清除，目前只有動物與細胞實驗，人體資料在下一節。

## 葛花的人體試驗：一張表看完

**直接在人身上測葛花的試驗很少，能查到的都在下表，查不到的就不列。**

| 試驗 | 受試者 | 給什麼 | 期間 | 主要結果 | 限制 |
|---|---|---|---|---|---|
| Jung 2023，韓國 <a href="#ref-7">[7]</a> | 80 名有宿醉經驗者 | 冰花、葛花、艾草三種萃取的複方飲品，喝酒前 30 分鐘 | 單次 | 宿醉量表總分 5.24 對 18.54 分；複方組血中酒精、乙醛下降較快 | 複方無法分出葛花貢獻；多數作者是廠商員工；單次飲酒情境 |
| Kamiya 2011，日本 <a href="#ref-10">[10]</a> | 80 名輕度肥胖者 | 每日 100、200、300 毫克葛花萃取物或安慰劑 | 8 週 | 300 毫克組 BMI 與體重下降 | 同時限制總熱量；身體測量只分析初始 BMI 超過 24 的男性；作者來自原料廠商 |
| Kamiya 2012，日本 <a href="#ref-11">[11]</a> | 81 名肥胖成人（BMI 25 以上） | 每日 200 或 300 毫克甘葛藤花萃取物或安慰劑 | 12 週 | BMI 與內臟脂肪面積下降，皮下脂肪無差異 | 樣本小；作者來自原料廠商；未測飲酒相關指標 |

表格外還有兩篇常被引用、但對象不是葛花的試驗：前一節的葛根萃取物減少飲酒量試驗 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>，以及兩篇韓國以枳椇子為主、搭配葛根的飲品試驗。Wang 等 2026 年在《Frontiers in Pharmacology》的範圍性回顧，搜尋八個中英文資料庫到 2025 年 7 月，納入 15 篇植物性宿醉介入的人體研究，其中含葛屬植物的只有 3 篇，三篇都是複方；用葛根搭配枳椇子的兩篇，一篇宿醉總分沒有差異、一篇只有腸胃症狀單項有差 <a href="#ref-9">[9]</a>。

再往上一層看，King's College London 的 Roberts 等 2022 年在《Addiction》期刊做的系統性回顧，納入 21 篇安慰劑對照的宿醉試驗、共 386 人，沒有兩篇測同一種東西，所有療效結果的證據等級都被評為「極低」，作者的結論是現有證據不足以推薦任何一種解酒或預防宿醉的成分 <a href="#ref-8">[8]</a>。那份清單裡沒有葛花。

## 解酒產品宣稱，對照證據能證明什麼

**包裝上的句子，大多可以對回某一篇動物實驗或某一個複方試驗，但對不回「你吃了會怎樣」。**

| 常見宣稱 | 現有證據實際測了什麼 | 能不能推論到你身上 |
|---|---|---|
| 「喝酒前吃，加速代謝酒精」 | 一篇三種植物的複方試驗，抽血量到酒精下降較快 <a href="#ref-7">[7]</a> | 不能歸功於葛花；沒有測呼氣酒精，也沒有測反應時間或駕駛能力 |
| 「減輕隔天宿醉」 | 同一篇複方試驗的主觀量表；葛根加枳椇子的兩篇結果一篇無效、一篇只有單項 <a href="#ref-9">[9]</a> | 葛花單方沒有人體資料 |
| 「傳統解酒聖品」 | 典籍記載與動物實驗 <a href="#ref-1">[1]</a> | 傳統用法不等於人體試驗 |
| 「護肝」 | 台灣核准的護肝健康食品，酒精相關的宣稱全部寫明「經動物實驗結果」；61 筆護肝許可裡沒有一筆以葛花為功效成分 <a href="#ref-22">[22]</a> | 沒有健康食品字號的「護肝」只是廣告用語 |
| 「葛萃取」「葛根葛花」並列 | 葛根的大豆苷在試管中會抑制分解乙醛的酵素 <a href="#ref-3">[3]</a> | 花與根的研究方向不同，看清楚是哪一個 |

**「護肝」這兩個字在台灣有法定的位置。** 食藥署《健康食品之護肝保健功效評估方法》105 年修正後，酒精性脂肪肝這個動物模式的試驗產品，通過後可以寫「經動物實驗結果，攝取本產品有助於延緩經酒精誘導所引起之脂肪肝」，同一段緊接著規定：本方法之試驗產品不得宣稱或擴大解釋其具有「解酒」之功效 <a href="#ref-21">[21]</a>。連拿到國家字號的產品都不能說解酒，一般食品更不能。蜆精是另一個常被當成解酒用的產品，它的護肝認證到底證明了什麼，〈[蜆精](/ingredients/clam-extract/)〉有逐條拆解。

## 吃了葛花再喝，酒測會比較低嗎

**沒有資料支持這件事。** 目前查得到的人體研究裡，沒有一篇單獨給葛花、再量呼氣酒精濃度的。

Jung 2023 是唯一報告「血中酒精下降較快」的含葛花試驗，但它有三個地方讓這個結果不能拿來當開車的依據 <a href="#ref-7">[7]</a>：第一，產品是冰花、葛花、艾草三種萃取的複方，沒有葛花單方組；第二，量的是抽血數值，台灣路檢用的是呼氣；第三，研究目的在宿醉症狀，沒有測反應時間、注意力這類跟駕駛有關的能力。主要作者是產品廠商的研發人員，論文聲明他們的角色是研究者，這一點讀者可以自己判斷。

台灣的酒駕門檻比多數人想像的低，前一晚喝了加米酒的麻油雞補湯，隔天騎車就可能被測出超標，法規門檻與實例整理在〈[麻油雞的酒「煮過就沒了」是真的嗎](/articles/sesame-oil-chicken-alcohol/)〉第四節。那篇的結論對葛花一樣適用：能改變酒測結果的只有你喝了多少酒精、以及喝完之後過了多久。

## 台灣怎麼管葛花：食品原料、中藥材、廣告三條線

同一朵葛花在台灣的法規身分，取決於它是哪一種、做成什麼、怎麼宣傳。

**食品原料平臺：野葛的花可以，甘葛藤的花尚不得使用。** 2026 年 11 月 21 日下載食藥署食品原料整合查詢平臺開放資料比對，野葛（Kudzu）的葉與花列在「草、木本植物類（1）供茶包、膳食調理包或萃取後作為原料」，備註寫根可以當一般食品原料；野葛的根另列在「可供直接食用」。甘葛藤（*Pueraria thomsonii* Benth.）的根可以做茶包或萃取原料，花卻列在「未確認安全性尚不得使用之原料」，備註是未經確認其食用安全性前，不得供為食品原料使用 <a href="#ref-15">[15]</a>。

這裡有一個讀者自己很難發現的細節。野葛那一筆的學名欄同時列了 *Pueraria lobata* (Willd.) Ohwi subsp. *thomsonii*，也就是把甘葛藤當成野葛的亞種寫進可用清單；另一筆用 *P. thomsonii* Benth. 這個學名，卻把花列為尚不得使用 <a href="#ref-15">[15]</a>。而日本那兩篇減重試驗用的，正是甘葛藤的花 <a href="#ref-11">[11]</a> <a href="#ref-12">[12]</a>。進口的日本葛花減重產品在台灣能不能當食品賣，要看實際基原，本頁無法替業者判定；這個問題目前也查不到食藥署的公開函釋。

**中藥材：草案把葛花列入「食用時須注意安全性」的第二類。** 中醫藥司 107 年 2 月生效的「可同時提供食品使用之中藥材」37 項清單，葛花與葛根都不在內 <a href="#ref-18">[18]</a>。115 年 4 月 13 日以衛部中字第1151860670號預告的認定基準草案，把葛花放在第二類第 10 項，與粉葛、葛根同一格，每人日食用限量 1.5 公克（葛根與粉葛是 4.5 公克） <a href="#ref-16">[16]</a> <a href="#ref-17">[17]</a>。依草案的計算規則，第二類中藥材任一品項換算的每日食用量超過臺灣中藥典所載最低用量的一半，就以藥品管理，附表的每人日食用限量就是那個一半的數字 <a href="#ref-17">[17]</a>。草案另規定，茶包型態、藥膳調理包與糖果餅乾等不以藥品管理 <a href="#ref-17">[17]</a>。截至 2026 年 11 月 21 日，中醫藥司網頁上仍是預告草案，最終條文以正式公告為準。

**廣告：「解酒」兩個字本身就是問題。** 依《食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則》第 4 條，宣傳內容涉及維持或改變人體器官、組織、生理功能者，認定為涉及不實、誇張或易生誤解 <a href="#ref-19">[19]</a>。衛福部 108 年 8 月 9 日的準則問答在這一條下面列了一串例句，「解酒」就在裡面，和「增強抵抗力」「排毒素」「減肥」同一行 <a href="#ref-20">[20]</a>。所以台灣合法上架的食品，包裝多半只寫「應酬族」「飲宴前後」，把解酒留給你自己聯想。

## 葛花和減重保健品的關係

**葛花在人身上證據最多的用途是內臟脂肪，不是酒。** 兩篇試驗的設計與限制已經放在上面的表格，〈[葛花、白腎豆和甲殼素差在哪](/articles/weight-loss-supplement-evidence-guide/)〉也逐一比較過，這裡補兩件那篇沒寫到的事。

**日本的監管後果。** 葛花萃取物在日本以「機能性表示食品」上市，申報的功能是幫助減少內臟脂肪。2017 年 11 月 7 日，日本消費者廳對 16 家業者、19 項含葛花異黃酮的機能性表示食品發出景品表示法措置命令，理由是網路廣告讓人以為不必運動或控制飲食就能輕易瘦下來，業者提出的資料都不被認為是合理根據；這是機能性表示食品第一次被處以措置命令 <a href="#ref-23">[23]</a>。這一筆來源是日本商業新聞的報導，消費者廳的原始公告頁面我們無法直接取得。

**政府研究機構的動物實驗沒有重現減脂效果。** 日本國立健康營養研究所 Tousen 等 2019 年在摘除卵巢的小鼠身上，比較人體建議量與 20 倍建議量的葛花異黃酮，兩種劑量都沒有改變體重、肝臟重量或內臟脂肪重量；20 倍劑量的大豆異黃酮能抑制骨質流失，葛花異黃酮不能 <a href="#ref-13">[13]</a>。小鼠結果不能直接否定人體試驗，但它和廠商試驗的方向不一致，而且作者在摘要第一段就寫明，市售產品並未經過類雌激素活性與肝臟藥物代謝酵素影響的完整安全性評估 <a href="#ref-13">[13]</a>。

## 安全性與注意事項

**短期、少量的毒性訊號不多，但人體長期資料是空白。** Takano 等 2013 年的大鼠 90 天試驗，飼料添加到 5% 甘葛藤花萃取物，血液生化、血液學、尿液與病理切片都沒有毒性變化，推估的無不良反應劑量約為每公斤體重每日 3 公克 <a href="#ref-12">[12]</a>。這篇的作者同樣來自原料廠商。人體部分只有前面表格裡 8 到 12 週的試驗，Kamiya 2011 報告各組都沒有不良反應 <a href="#ref-10">[10]</a>。

**類雌激素作用是主要的理論疑慮。** 葛花代謝物在細胞實驗中有類雌激素活性 <a href="#ref-2">[2]</a>；Tousen 2019 在人體建議量下沒有測到小鼠的類雌激素反應 <a href="#ref-13">[13]</a>。紀念斯隆凱特琳癌症中心的葛屬植物條目，花與根並列，建議荷爾蒙敏感型癌症患者、正在用 tamoxifen 的人避免使用 <a href="#ref-14">[14]</a>。

**可能的藥物交互作用多半來自動物實驗。** 同一份條目列出 methotrexate（動物實驗中排除變慢、血中濃度升高）與降血糖藥（動物實驗中作用增強），並註明臨床意義尚未確立 <a href="#ref-14">[14]</a>。正在用這些藥的人，使用含葛花或葛根的產品前，跟開藥的醫師或藥師確認。

**最大的風險可能是行為。** 以為吃了葛花就能多喝幾杯、或隔天就能開車，這個誤解造成的傷害遠大於葛花本身。

## 常見迷思

- **「葛花是中藥，天然的所以沒有副作用」**：葛花的代謝物在細胞實驗中有類雌激素活性 <a href="#ref-2">[2]</a>，人體長期使用的安全資料查無；中醫藥司草案也把它放在「食用時須注意安全性」的第二類 <a href="#ref-17">[17]</a>
- **「解酒飲裡有葛花，所以喝酒前喝一瓶比較安全」**：唯一含葛花的宿醉試驗是三種植物的複方 <a href="#ref-7">[7]</a>，系統性回顧給所有解酒成分的證據等級都是極低 <a href="#ref-8">[8]</a>
- **「葛根和葛花是一樣的東西」**：葛根的大豆苷在試管中抑制分解乙醛的酵素 <a href="#ref-3">[3]</a>，被研究成減少喝酒量的工具 <a href="#ref-5">[5]</a>，跟葛花的傳統用途方向不同
- **「有護肝認證就能解酒」**：食藥署的護肝評估方法明文禁止通過酒精性脂肪肝模式的產品宣稱或擴大解釋具有解酒功效 <a href="#ref-21">[21]</a>
- **「日本藥妝店賣的葛花錠可以瘦肚子」**：日本消費者廳曾因這類廣告一次處分 16 家業者 <a href="#ref-23">[23]</a>；在台灣，甘葛藤的花在食品原料平臺上列為尚不得使用 <a href="#ref-15">[15]</a>

## 常見問題

### 尾牙前一天吃葛花錠，隔天早上開車會比較安全嗎？

不會因此比較安全。沒有任何研究單獨給葛花、再量呼氣酒精濃度或駕駛能力。唯一報告血中酒精下降較快的試驗，用的是三種植物的複方，量的是抽血數值 <a href="#ref-7">[7]</a>。隔天能不能開車，取決於前一晚喝了多少、睡了多久，〈[麻油雞的酒「煮過就沒了」是真的嗎](/articles/sesame-oil-chicken-alcohol/)〉有台灣酒駕門檻的整理。

### 葛花和葛根做成的茶包，一天喝多少算合理？

台灣目前沒有正式的數字。中醫藥司 115 年 4 月的草案訂的是葛花每人每日 1.5 公克、葛根 4.5 公克，但草案同時規定茶包型態不以藥品管理，也沒有另外為茶包訂上限 <a href="#ref-17">[17]</a>。草案尚未正式公告。孕婦、哺乳中、荷爾蒙敏感型癌症患者，以及正在用 methotrexate 或降血糖藥的人，喝之前先問過醫師或藥師 <a href="#ref-14">[14]</a>。

### 為什麼解酒飲的包裝上很少直接寫「解酒」？

因為寫了就可能違規。衛福部的廣告認定準則問答把「解酒」列為涉及改變生理功能、屬於易生誤解的例句 <a href="#ref-20">[20]</a>，所以合法上架的產品多半改寫成「應酬前後」「飲宴好夥伴」。看到包裝或廣告直接寫解酒、醒酒，可以當成一個警訊。

### 健康食品的護肝字號，跟解酒有關嗎？

沒有直接關係。食藥署的護肝評估方法用的是大鼠模式，酒精相關的那一項測的是「延緩酒精誘導的脂肪肝」，同一份文件規定這類產品不得宣稱或擴大解釋具有解酒功效 <a href="#ref-21">[21]</a>。2026 年 11 月下載的健康食品開放資料中，61 筆護肝許可沒有一筆以葛花為功效成分 <a href="#ref-22">[22]</a>。

### 日本買回來的葛花減重錠，在台灣可以吃嗎？

個人吃不吃是自己的決定，但有兩件事要知道。日本的人體試驗用的是甘葛藤的花，而台灣食品原料平臺把甘葛藤的花列為「未確認安全性尚不得使用」 <a href="#ref-11">[11]</a> <a href="#ref-15">[15]</a>；日本官方研究機構的小鼠實驗沒有重現減少內臟脂肪的效果，作者也指出這類產品沒有經過完整的安全性評估 <a href="#ref-13">[13]</a>。有在吃荷爾蒙相關藥物的人，先問過醫師。
