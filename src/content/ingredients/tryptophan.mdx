## 30 秒認識

- 色胺酸（L-Tryptophan）是必需胺基酸，人體無法自行合成，只能從蛋白質食物攝取；它是血清素與褪黑激素合成路徑最上游的原料。 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- 與 [5-HTP](/ingredients/5-htp) 最根本的不同：色胺酸要先經色胺酸羥化酶（TPH）轉換成 5-HTP，才能再轉成血清素；這一步是整條路徑的限速反應，也是身體吃進色胺酸後「不一定變得出血清素」的關鍵。 <a href="#ref-1">[1]</a>
- 色胺酸進入腦部要跟白胺酸、纈胺酸、酪胺酸等其他中性胺基酸競爭同一個血腦屏障運輸通道，這也是「吃火雞肉助眠」常被誤解的地方，火雞的色胺酸含量並不特別突出。 <a href="#ref-4">[4]</a>
- 吃進體內的色胺酸，只有極小一部分會走向血清素路徑，絕大多數其實流向另一條代謝路徑，最終合成菸鹼酸（維生素 B3）。 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- 安全性事件：1989 年美國曾爆發與受污染色胺酸批次有關的嗜伊紅性肌痛症候群（EMS），CDC 全國通報統計至 1990 年 8 月已累計 1,536 例、27 例死亡，問題出在特定廠商的製造雜質，而非色胺酸分子本身。 <a href="#ref-8">[8]</a> <a href="#ref-10">[10]</a>

## 基本介紹

色胺酸是組成人體蛋白質所需的九種必需胺基酸之一，「必需」代表身體無法從其他物質自行合成，缺了它，日常飲食就得補上。 <a href="#ref-2">[2]</a> 一般均衡飲食中，肉類、蛋、乳製品、豆類、堅果種子都含有色胺酸，正常攝取量遠高於維持基本生理機能所需的最低量。 <a href="#ref-1">[1]</a> 色胺酸在體內的角色除了蛋白質建材，也是合成血清素與褪黑激素的起點原料，這條路徑正是色胺酸被做成單方補充品、訴求助眠與情緒的主要理由。 <a href="#ref-1">[1]</a> 這類補充品在歐美市場流通已久，1989 年曾因受污染批次引發大規模安全事件，美國食品藥物管理局（FDA）一度限制其以非處方形式販售，直到 2001 年逐步鬆綁、2005 年才完全解除限制；歐洲食品安全局（EFSA）則在 2011 年審查色胺酸相關的助眠、情緒、認知功能與體重管理健康聲明申請，結論是現有人體證據不足以建立因果關係，未通過核准。 <a href="#ref-9">[9]</a>

## 這是什麼？

色胺酸、5-HTP、血清素、褪黑激素，是同一條代謝路徑上前後相連的四個站，但角色各不相同。色胺酸是食物裡就有的必需胺基酸，5-HTP 是身體依需求自行製造的中間產物，血清素是神經傳導物質本身，褪黑激素則是血清素在特定條件下（如夜間、光線變暗）進一步轉換的產物。 <a href="#ref-1">[1]</a> 色胺酸沒辦法用「吃了就等於補到血清素」這種簡化邏輯理解，中間隔著至少兩個酵素反應，也隔著一個競爭激烈的運輸瓶頸。想了解睡眠補充品整體怎麼選、除了色胺酸還有哪些常見成分，可以參考[睡眠保健品怎麼挑，才不是白吃一場](/articles/sleep-supplements-find-root-cause)。

## 與 5-HTP 的差異

色胺酸與 5-HTP 常被市場當成同一種東西行銷，兩者其實站在代謝路徑的不同位置，補充邏輯也不一樣。色胺酸是必需胺基酸，身體無法自行製造，一定要從食物或補充品攝取；5-HTP 不是必需營養素，身體會依血清素合成需求，用手邊的色胺酸自行製造出所需的量，沒有「吃不夠」的問題。 <a href="#ref-1">[1]</a>

補充色胺酸之後，要先經過色胺酸羥化酶（TPH）這一步限速反應轉成 5-HTP，TPH 的活性和飽和狀態會決定轉換效率，並非吃進去的色胺酸都能順利往下游走。 <a href="#ref-1">[1]</a> 補充 5-HTP 則是直接跳過這一步限速反應，理論上能更有效率地把原料送進轉換血清素的下一階段，這也是坊間認為「5-HTP 比色胺酸有效」的機制依據，但機制上的效率優勢並不等於臨床上更好的效果，兩者的人體證據都同樣薄弱。

兩者還有一層差異在血腦屏障：色胺酸進入腦部要和白胺酸、異白胺酸、纈胺酸、酪胺酸、苯丙胺酸等多種大型中性胺基酸（LNAA）競爭同一個運輸通道，攝取蛋白質時因為這些胺基酸同時上升，色胺酸占比不一定跟著提高，實際進腦量因此變得難以預測。 <a href="#ref-4">[4]</a> 5-HTP 的日常食物來源極少，補充品形式的血中濃度波動相對單純，較不受同餐蛋白質組成干擾。後面「常見迷思」拆解的「吃火雞助眠」說法，問題就出在這層運輸競爭上。

## 在身體裡做什麼？／主要作用機制

色胺酸在體內主要走兩條代謝路徑。第一條是犬尿胺酸路徑（kynurenine pathway），佔飲食攝入色胺酸的絕大部分，最終生成菸鹼酸（維生素 B3）與其他代謝物；第二條是血清素路徑，僅佔一小部分，須先經 TPH 轉成 5-HTP，再經芳香族胺基酸脫羧酶（AADC）轉成血清素，腦中的血清素在夜間可再轉換成褪黑激素。 <a href="#ref-1">[1]</a> <a href="#ref-3">[3]</a>

色胺酸要從血液進入腦部，得通過血腦屏障上的 LNAA 運輸通道，而這個通道同時也被白胺酸、異白胺酸、纈胺酸、酪胺酸、苯丙胺酸等胺基酸共用。攝取高蛋白食物會讓血中所有這些胺基酸一起上升，色胺酸未必能在競爭中佔到便宜；相對地，攝取碳水化合物會刺激胰島素分泌，胰島素會促使其他支鏈胺基酸優先被肌肉組織攝取，色胺酸因為多與白蛋白結合、較不受這個機制影響，血中色胺酸相對其他 LNAA 的比例因此上升，更容易被運進腦部。 <a href="#ref-4">[4]</a> 這也是為什麼部分研究會建議色胺酸搭配碳水化合物攝取，而非單純大量吃蛋白質食物。

急性色胺酸耗竭（acute tryptophan depletion, ATD）是研究這條路徑常用的實驗手法：讓受試者短時間內攝取不含色胺酸的胺基酸混合物，人為壓低腦中色胺酸與血清素合成，藉此觀察情緒與認知的變化，反向證實色胺酸供應對血清素功能的重要性。 <a href="#ref-3">[3]</a> 這類研究建立的是「色胺酸不足會怎樣」的機轉證據，跟「額外補充色胺酸會不會更好」是兩個不同層次的問題，後者的人體證據規模普遍偏小。

## 食物來源／常見來源

色胺酸廣泛存在於各類蛋白質食物中，包括禽肉（雞肉、火雞肉）、紅肉、魚類、蛋、乳製品（牛奶、起司）、大豆製品、南瓜籽等堅果種子，以及部分穀類。 <a href="#ref-2">[2]</a> 以每公克蛋白質換算，色胺酸的含量在不同食物間差異不算懸殊，火雞肉並非特別突出的來源，一般家禽、乳酪、大豆蛋白的色胺酸密度都相近甚至更高。 <a href="#ref-2">[2]</a> <a href="#ref-4">[4]</a>

均衡飲食中，成年人的日常色胺酸攝取量普遍落在每日數百毫克到一公克出頭，一般被認為已經足夠支持蛋白質合成與血清素、菸鹼酸等下游需求，健康人不需要額外留意「有沒有吃到色胺酸」。 <a href="#ref-1">[1]</a> 市售單方色胺酸補充品則多為結晶胺基酸粉劑或膠囊，劑量遠高於單餐食物能提供的量。

## 建議攝取量／常見攝取建議／研究中常見使用方式

色胺酸有官方訂定的每日建議攝取量，美國國家科學院訂出的估計平均需求量約為每公斤體重 4 毫克，建議攝取量約為每公斤體重 5 毫克，換算 70 公斤成人約落在每日 250 到 350 毫克區間；一般均衡飲食的實際攝取量通常明顯高於這個門檻。 <a href="#ref-1">[1]</a> 這是「維持基本生理機能」所需的量，跟保健品訴求助眠、情緒的使用劑量是兩回事。

人體試驗中，睡眠相關研究使用的補充劑量多落在每日 1 公克上下，統合分析也顯示 1 公克以上劑量對縮短夜間清醒時間的效果優於 1 公克以下劑量；經前不悅症研究則使用到每日 6 公克的高劑量，且限定在月經週期的特定階段給藥。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a> 這些劑量都遠高於一般飲食能提供的量，且分屬不同研究情境，並不存在一個放諸四海皆準的「建議劑量」，自行使用者應對市售產品標示的高劑量保持保留態度。

## 缺乏風險或攝取不足問題

色胺酸是必需胺基酸，飲食長期攝取不足確實可能出現生理影響，但在正常均衡飲食的族群中相當罕見，多半只出現在整體蛋白質攝取嚴重不足（如嚴重營養不良、極端限制型飲食）的情況下。 <a href="#ref-2">[2]</a> 研究上常用的急性色胺酸耗竭實驗，是在短時間內人為刻意壓低色胺酸攝取，藉此觀察情緒與認知變化，這是實驗操作手法，不代表日常生活中容易出現類似程度的「不足」。 <a href="#ref-3">[3]</a> 情緒低落、睡不好等困擾成因多元，包括壓力、作息、其他營養狀況與潛在疾病，不應直接歸因於「色胺酸不夠」，更不宜以此作為自行大量補充的理由。

## 補充品常見形式

市售色胺酸補充品多為 L-色胺酸結晶粉末製成的膠囊或錠劑，也有品牌做成搭配維生素 B6（AADC 反應輔酶）或碳水化合物的複方產品，呼應前述「搭配碳水更利於通過血腦屏障」的機制討論。 <a href="#ref-4">[4]</a> 1989 年 EMS 事件的根源就出在單一廠商特定批次的發酵純化製程雜質，這代表原料端的品管紀錄與批次可追溯性，是色胺酸這個成分挑選產品時最該優先確認的項目，重要性甚至高於單看劑量數字或行銷訴求。 <a href="#ref-8">[8]</a> <a href="#ref-10">[10]</a> 在台灣，色胺酸屬於胺基酸類原料，實際能否作為保健食品上市、標示訴求是否合規，仍須留意衛生福利部對於單方胺基酸類保健品的相關規範。

## 安全性與注意事項

色胺酸站在血清素合成路徑的最上游，理論上要先通過 TPH 限速反應才會影響下游血清素濃度，風險機轉不像 5-HTP 那樣直接，但臨床上仍被視為需要留意的交互作用來源。正在服用 SSRI、SNRI、MAOI 等抗憂鬱藥，或曲普坦類（triptan）偏頭痛藥的族群，若額外大量補充色胺酸，仍可能拉高體內血清素相關訊號、增加血清素症候群風險；這是一種可能危及生命的急症，症狀包括躁動不安、心跳過快、體溫升高、肌肉僵硬與抽搐。正在服用抗憂鬱藥或其他血清素相關藥物者，不應自行併用色胺酸補充品，需由醫師評估。

**歷史上有明確記載的重大污染事件。**1989 年美國多州陸續出現嗜伊紅性肌痛症候群（EMS）病例，調查發現絕大多數患者使用的色胺酸來自單一廠商、以特定發酵菌株與簡化純化製程生產的批次，該批次中一項雜質（研究文獻稱為「peak E」）與發病風險高度相關；CDC 全國通報統計至 1990 年 8 月已累計 1,536 例、27 例死亡。 <a href="#ref-8">[8]</a> <a href="#ref-10">[10]</a> 這起事件的結論是問題出在特定批次的製造雜質，而非色胺酸分子本身，FDA 隨後限制其販售，直到確認污染源、改善製程後才逐步解禁。 <a href="#ref-8">[8]</a>

其他注意事項：常見副作用包括噁心、腸胃不適、頭暈與嗜睡；孕婦、哺乳者的安全性資料有限，不建議自行使用；EFSA 審查現有證據後，認為色胺酸與助眠、情緒、認知功能、體重管理之間的因果關係尚未被充分證實，市售產品的相關訴求應保守看待。 <a href="#ref-9">[9]</a>

## 常見迷思

- **「吃火雞肉助眠，是因為色胺酸含量特別高」**：火雞的色胺酸含量以每公克蛋白質計算並不特別突出，雞肉、乳酪、大豆蛋白的密度相近甚至更高；感恩節大餐後的睏意，更可能與整體攝食量大、碳水與酒精一起下肚、餐後副交感神經活躍有關，不能簡化成「因為吃了火雞」。 <a href="#ref-2">[2]</a> <a href="#ref-4">[4]</a>

- **「單獨吃高蛋白食物就能提高腦中血清素」**：色胺酸進腦要跟其他大型中性胺基酸競爭運輸通道，高蛋白食物會讓所有這些胺基酸同時上升，色胺酸占比不一定提高，實際效果可能與直覺相反；文獻上反而是搭配碳水化合物的攝取方式，較容易提高色胺酸相對其他胺基酸的比例。 <a href="#ref-4">[4]</a>
- **「色胺酸跟 5-HTP 效果一樣，選哪個都行」**：兩者在代謝路徑上位置不同，色胺酸多一道 TPH 限速反應，且要跟其他胺基酸競爭進腦，5-HTP 則跳過這一步；機制不同也代表補充後的體感與人體試驗結果不能直接互相套用，各自的證據都需要獨立看待，可參閱[5-HTP 的完整介紹](/ingredients/5-htp)。
- **「這是胺基酸，天然又安全，可以隨意長期大量吃」**：1989 年的 EMS 事件就是因為特定批次原料污染造成上千人受害、數十人死亡，「胺基酸」不等於「沒有品管風險」，與血清素相關藥物併用也有明確的交互作用疑慮，不宜自行大量長期使用。 <a href="#ref-8">[8]</a> <a href="#ref-10">[10]</a>
