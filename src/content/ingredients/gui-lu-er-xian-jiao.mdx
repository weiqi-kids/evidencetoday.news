## 30 秒認識

- 龜鹿二仙膠是由龜板（龜的腹甲與背甲）、鹿角、人參、枸杞四味熬煉成的膠塊。國家中醫藥研究所的專文考證指出，此方最晚不會晚於 16 世紀初，見於《蒼生司命》與《脈因症治》；龜板膠正式出現在本草文獻則要到 1624 年的《本草正》。 <a href="#ref-16">[16]</a>
- 人體證據不是零，但也撐不起廣告詞。目前規模最大的一份是 Liao 等人 2022 年的系統性回顧與統合分析，納入 8 篇膝關節退化研究，「總有效率」的風險比 1.20（95% 信賴區間 1.06 至 1.35）達顯著，但疼痛分數與 Lequesne 功能指數兩項硬指標都沒有組間差異。 <a href="#ref-1">[1]</a>
- 台灣本地的資料有兩筆。一筆是 42 人的高齡男性膝關節研究（有對照但未隨機分派）， <a href="#ref-2">[2]</a> 另一筆是長庚研究資料庫的病例對照研究：85 名骨質疏鬆患者對上 425 名配對對照，五年整體骨折率沒有差異。 <a href="#ref-3">[3]</a>
- 機制研究幾乎全在細胞與動物層級。龜板與鹿角膠水解出的五胜肽 TSKYR 及其片段 TSK，在人類成骨細胞培養皿裡把礦化結節密度推高約 50 倍，這是很漂亮的數字，但它發生在培養皿。 <a href="#ref-6">[6]</a><a href="#ref-7">[7]</a>
- 腎功能不好的人要特別小心。亞洲大學附屬醫院通報過一名 50 歲女性因自行加量服用，出現便祕與心悸，檢查發現血鉀高達 6.8，需緊急透析以避免致命心律不整。 <a href="#ref-18">[18]</a>
- 龜板的物種來源是真實的法律問題。台灣市售龜板多來自印尼、泰國、馬來西亞、緬甸等地， <a href="#ref-16">[16]</a> 而龜類依種別分別受《野生動物保育法》與華盛頓公約管制，輸出入需要出口國許可證。 <a href="#ref-23">[23]</a>
- 偽品有官方紀錄。衛生福利部在 2008 年 1 月 31 日發過專門針對「龜鹿二仙膠」偽藥的警示，起因是刑事局破獲四個在醫院內假冒醫師與病患兜售偽造中藥的集團。 <a href="#ref-17">[17]</a>

## 基本介紹

走進台灣任何一家傳統中藥行，玻璃櫃裡那一塊塊深褐色、切成方磚的膠，價格標籤上的數字通常是四位數起跳。中秋與農曆年前，同樣的東西會換上絨布禮盒，出現在百貨公司的專櫃。買的人多半說不清楚它到底是什麼做的，只知道「補骨頭」「長輩吃的」。

這個品類在英語世界沒有對應概念。Examine.com、美國國家衛生研究院膳食補充品辦公室、歐洲食品安全局的資料庫裡都查不到它。想查證的台灣讀者，能找到的中文資料幾乎全部來自藥商、中藥行與電商頁面，少數例外是中醫診所的衛教文章，而那些文章的證據標準與商業頁面差距不大。

這一頁把能查到的東西全部列出來，包含一份統合分析、兩筆台灣本地研究、一份眼科不良事件報告、一份消基會的市售品檢測，以及龜板來源的法規現實。也把查不到的東西列出來：哪些是本站真的檢索過、確認沒有資料的。

## 這是什麼？

**「二仙」指的是龜與鹿。** 方名裡的二仙，說的是龜與鹿這兩種在傳統觀念中長壽的動物，取其一陰一陽的象徵；人參與枸杞是後來加進去的配伍，用意在補氣與養血，讓整方不只補精髓。國家中醫藥研究所的專文把這一方歸在「異類有情」這個範疇，也就是動物性藥材。 <a href="#ref-16">[16]</a>

**四味藥各自的角色。** 依同一份專文的整理，鹿角膠性溫，傳統定位是補肝腎、益精血兼止血，常用劑量為每日 5 至 10 公克；龜板膠性偏陰，滋陰養血止血的藥性強於未熬膠的龜板本身，傳統用於肺熱咳血與婦科帶下。兩者合用取的是「陰陽並補」與補骨的共性。 <a href="#ref-16">[16]</a>

**製法是這一味最貴的原因。** 《醫便》記載的作法是：鹿角與龜板水浸三日後置於容器中，放進大鍋以桑柴火煮七晝夜，過程保持微溫而不沸騰；取汁後再分別熬煉人參與枸杞三次，合併清汁，文火熬到「水成珠不散」才算成膠。 <a href="#ref-16">[16]</a> 七天七夜的柴火與大量原料的損耗，加上龜板與鹿角本身每斤上千元的成本，讓真品的價格很難壓下來。這件事直接決定了下游的市場生態：偽品的誘因非常高。

**古法裡有一個現代人該注意的細節。** 同一份古方記載的容器材質是鉛壇。今天的合法製劑當然不會這樣做，但這個細節說明了一件事：傳統製程的安全性假設與現代重金屬標準之間，需要靠法規與檢驗來補。台灣現行的把關方式是中藥材與中藥製劑的重金屬限量與 GMP 藥廠製造規範。

**本質上是什麼分子。** 龜板膠與鹿角膠的主體是動物骨骼與甲殼中的膠原蛋白，經長時間高溫水解後轉成明膠與更小的胜肽，另外帶有相當比例的鈣、鎂等礦物鹽。從分子組成看，它與市售的〈[膠原蛋白](/ingredients/collagen/)〉補充品屬於同一個大類，差別在來源物種、水解程度與伴隨的礦物質。

## 在身體裡做什麼？／主要作用機制

現有的機制資料分成三層，三層的距離要先講清楚。

**第一層是特定胜肽的成骨活性，這是目前最具體的一條。** 花蓮慈濟與相關團隊的研究從龜板與鹿角膠的胃蛋白酶水解物中分離出一段五胜肽 TSKYR，並推測它在小腸會進一步被切成 TSKY、TSK 與 YR。把這幾段胜肽化學合成後測試，三胜肽 TSK 讓人類成骨細胞的礦化結節面積上升約 30 倍、密度上升約 50 倍，軟骨細胞數量增加 47.5%，並提高 RUNX2、OCN、FGFR2 等骨生成相關基因的表現；龜板中的鈣含量偏高，鈣離子與這些胜肽之間觀察到協同作用。 <a href="#ref-6">[6]</a> 同團隊 2024 年的後續研究再測二胜肽 YR，發現鈣與鍶離子會加強它的效果。 <a href="#ref-7">[7]</a> 2025 年另一組研究比較了龜板膠與鹿角膠各自的抗氧化能力與對成骨細胞、軟骨細胞存活率的影響，結論是兩者搭配各自的胜肽時效果優於單用。 <a href="#ref-8">[8]</a>

這一層資料的限制很明確：全部在培養皿裡完成。口服的膠塊要走完消化、吸收、進入循環、抵達骨骼這一整條路，中間每一步都還沒有人體藥物動力學資料支持。

**第二層是動物模型的整體表型。** Fang 等人 2023 年在《Journal of Food and Drug Analysis》發表的研究，用龜鹿二仙膠水萃物處理 C2C12 肌管細胞，觀察到肌生成分化、IGF-1/IGF-1R/IRS-1/Akt 蛋白合成訊號、Glut4 轉位、肝醣含量與粒線體生合成訊號全面上升；換到 C57BL/6J 小鼠，四週後肌肉體積、相對肌重、肌纖維橫切面積上升，快肌轉向慢肌，握力與自主活動量提高。 <a href="#ref-5">[5]</a> 2025 年還有一組研究把它用在創傷後壓力症候群的大鼠模型，觀察到海馬迴樹突棘形態改變與恐懼記憶泛化被抑制。 <a href="#ref-9">[9]</a>

動物實驗的價值在提出假說。小鼠握力上升與人類長者握力上升之間，隔著劑量換算、物種差異與臨床意義三道關卡。想知道人類肌肉流失該怎麼處理，〈[肌少症完整指南](/articles/sarcopenia-muscle-loss-guide/)〉裡的訓練與蛋白質策略有更直接的人體資料。

**第三層是人體，而這一層薄得多。** 沒有任何一篇研究測過口服龜鹿二仙膠後血中 TSK 或 YR 的濃度，也沒有研究確認過這些胜肽能否完整通過腸道。本站檢索 PubMed、Cochrane Library 與 ClinicalTrials.gov 後，找不到龜鹿二仙膠的人體藥物動力學資料。這一段屬於查無。

## 食物來源／常見來源

龜鹿二仙膠不是營養素，沒有天然食物來源可談，也沒有「日常飲食中攝取到」這回事。它的來源只有兩種：中藥行或藥廠製造的膠塊與衍生劑型，以及中醫師處方。

從成分類別看，構成它主體的膠原蛋白與明膠，在日常飲食中廣泛存在於皮、筋、軟骨與帶骨肉類。就補充膠原蛋白的目的而言，龜鹿二仙膠並沒有提供尋常食物所沒有的胺基酸種類；它的特殊性在於龜板與鹿角帶來的礦物質組成與特定胜肽序列，而這兩者的人體效果都還沒有被驗證。

至於人參與枸杞，兩者都是可以單獨取得的藥材，本站另有〈[人參](/ingredients/ginseng/)〉的獨立整理。

## 建議攝取量／研究中常見使用方式

現有研究使用的劑型與劑量相當分散，這件事本身就是讀這些資料時的一個障礙。

- Tsai 等人 2014 年的台灣研究：42 名高齡男性膝關節退化患者，服用組 21 人、對照組 21 人，療程 12 週。該研究摘要未載明每日劑量與製劑規格。 <a href="#ref-2">[2]</a>
- Lai 等人 2024 年的長庚病例對照研究：以「累積服用顆數」為暴露指標，分析結果指向需累積 600 顆以上才與骨折風險下降有關聯。 <a href="#ref-3">[3]</a> 這是回溯性資料庫研究，不是劑量反應試驗。
- Liao 等人 2022 年統合分析納入的 8 篇研究，介入方式包含口服膠塊、濃縮製劑與合併常規治療，異質性高，作者群因此採隨機效應模型。 <a href="#ref-1">[1]</a>
- 傳統文獻對鹿角膠單味的用量記載是每日 5 至 10 公克。 <a href="#ref-16">[16]</a> 這是單味藥的傳統劑量，不等於複方成膠後的建議量。

正在進行中的試驗有一筆值得追蹤：ClinicalTrials.gov 登錄編號 NCT06980922，在台灣執行，主題是龜鹿二仙膠用於透析中低血壓，預計收案 34 人，登錄狀態為尚未開始收案。 <a href="#ref-25">[25]</a> 小型單一中心試驗，結果出來後仍需要用同樣的標準檢視。

實務上的建議很單純：龜鹿二仙膠在台灣的合法身分是中藥，劑量由中醫師依體質與同時使用的藥物決定，不適合自己去中藥行抓、自己決定吃多少。下一段講的高血鉀案例，起因就是自行加量。

## 缺乏或攝取不足

龜鹿二仙膠沒有缺乏症。它不是人體必需的營養素，不吃它不會造成任何生理缺損，這一點不需要含糊。

真正該處理的是那些讓人想買它的問題。骨質疏鬆有明確的診斷工具與治療藥物，判讀 DXA 骨密度 T 值與 FRAX 骨折風險的方式，見〈[骨質疏鬆完整指南](/articles/osteoporosis-dxa-frax-prevention-guide/)〉；膝關節退化有從運動處方到注射治療的完整階梯，見〈[退化性關節炎的非手術選擇](/articles/knee-osteoarthritis-nonsurgical-options/)〉。這兩條路徑的效果幅度與證據等級，都遠高於目前龜鹿二仙膠能提供的。

順帶一提，長庚研究資料庫另一份針對骨折患者中醫用藥型態的橫斷面研究，分析了 2000 至 2015 年門診處方在骨折早、中、後期的中藥使用分布，可以看出龜鹿二仙膠在台灣臨床實務中被使用的位置。 <a href="#ref-10">[10]</a>

## 補充品常見形式

- **原膠塊**：傳統形式，深褐色方磚，需以黃酒或熱水烊化後服用。龜板膠氣味腥臭，傳統以酒烊化就是為了蓋味。 <a href="#ref-16">[16]</a> 這個劑型最貴，也最難驗真偽。
- **膠囊與錠劑**：把膠粉碎後填充，方便服用，但也讓消費者失去用肉眼與嗅覺判斷的機會。長庚病例對照研究裡以「顆」為單位計算暴露量，指的就是這類劑型。 <a href="#ref-3">[3]</a>
- **濃縮中藥製劑**：衛生福利部中醫藥司公告有基準方劑清單，以濃縮製劑為主，可在該司網站查詢特定方名是否在列。 <a href="#ref-22">[22]</a>
- **加料型與偽稱型**：市面上有名稱近似、成分不同的產品，例如以其他動物皮膠、明膠或麥芽糖為主體再冠上相似名稱。這一類是下一段要談的重點。

一個實務上的判別起點：合法的中藥製劑會有中央主管機關核發的許可證字號（例如「衛部成製字」「衛署成製字」開頭），包裝上找不到字號、或字號查不到對應產品的，先不要買。

## 台灣的法規與市場實況

**它的法定身分是中藥，不是食品。** 衛生福利部中醫藥司在 107 年 2 月 13 日以衛部中字第1071860124號公告「可同時提供食品使用之中藥材」品項，自 107 年 2 月 22 日生效。 <a href="#ref-20">[20]</a> 這份公告的網頁本文並未列出品項，清單以 PDF 附件形式提供，要確認某一味藥材在不在名單上，必須開附件逐項核對。 <a href="#ref-20">[20]</a> 實務上，龜鹿二仙膠在台灣以中藥製劑流通，不是以食品或健康食品的身分販售，因此它沒有小綠人標章，也不能宣稱任何保健功效。

**臺灣中藥典是藥材規格的依據。** 中醫藥司於 110 年 9 月 13 日以衛部中字第1101861154號公告臺灣中藥典第四版，自 111 年 6 月 1 日生效。 <a href="#ref-21">[21]</a> 藥材的基原、性狀、鑑別、重金屬與農藥殘留限量等規格都在這一部典裡，這也是市售中藥材品質查核的法定基礎。

**保育問題是真的，不是行銷話術的反面。** 龜類依種別分別受管制：《野生動物保育法》對保育類野生動物的獵捕、買賣、輸出入設有規範， <a href="#ref-23">[23]</a> 而列入華盛頓公約附錄的物種，其產製品輸出入須檢附出口國核發的許可證。國家中醫藥研究所的專文直接寫明，台灣市場的龜板多來自印尼、泰國、馬來西亞、緬甸等地。 <a href="#ref-16">[16]</a> 「這塊膠裡的龜板是什麼種、怎麼進來的」這個問題，消費者從包裝上看不出來，而它決定了整批貨的合法性。台灣的中醫藥學界對此有過學術回應：《中醫藥雜誌》在 2001 年刊出過〈保育類龜板品種之鑑定〉一文，處理的正是這個鑑別問題。 <a href="#ref-24">[24]</a>

**膠類中藥的真偽鑑別，實驗室做得到，消費者做不到。** 國際上已有多種方法可以區分驢皮膠、鹿角膠與龜板膠：以胰蛋白酶消化後用超高效液相層析搭配飛行時間質譜再做主成分分析，可以分辨五種明膠； <a href="#ref-12">[12]</a> 以酵素消化搭配奈流液相層析與軌道阱質譜，能分辨阿膠、鹿角膠與龜板膠三者。 <a href="#ref-11">[11]</a> 這些方法的存在本身就說明一件事：不同動物來源的明膠在外觀、氣味與口感上難以區分，中國藥典既有的常規檢驗特異性不足，添加標示成分就能通過。消費者在櫃檯前用眼睛判斷，成功率不會高。

**官方警示與偽藥前科。** 衛生福利部在 2008 年 1 月 31 日發布過針對「龜鹿二仙膠」偽藥的公告，起因是刑事局前一天破獲四個詐騙集團，成員在各醫院內假冒醫師與病患身分，向就醫民眾推銷偽造中藥。該公告同時提醒，製造或販售偽藥可處 10 年或 7 年以下有期徒刑，得併科新台幣 1000 萬元或 500 萬元以下罰金，並建議民眾購買前確認產品已經查驗登記領有許可證、優先選擇 GMP 藥廠製造的中藥製劑。 <a href="#ref-17">[17]</a> 這則公告年代較早，但醫院走廊兜售補品的手法並沒有消失。

**通路差異在檢驗數字上看得出來。** 消費者文教基金會 2021 年度的「中藥安全性：含西藥及重金屬」檢測報告收了 45 件委託檢測樣品，其中 38 件檢驗西藥成分、21 件檢驗鉛、汞與鎘各 19 件。結果是：來自國內醫療院所與國內藥商藥局的樣品全部未檢出西藥；來源為「其他或不明管道」的 26 件中有 6 件檢出西藥，檢出率 23.1%，檢出的 7 種西藥成分包含消炎鎮痛劑與壯陽劑。59 項重金屬檢測則全數符合衛福部總重金屬 30 ppm 以下的規定。 <a href="#ref-19">[19]</a> 這組數字的訊息很直接：風險集中在來路不明的通路，不是均勻分布在整個中藥市場。

**價差極大的原因。** 真品的成本結構在前面已經拆過：龜板與鹿角原料每斤上千元、七晝夜熬煉、人工與耗損。 <a href="#ref-16">[16]</a> 當貨架上出現價格只有三分之一的同名產品，最可能的解釋是原料比例、原料種類或製程被更換過，而不是哪一家找到了便宜的進貨管道。

## 安全性與注意事項

**高血鉀是最該優先處理的風險。** 亞洲大學附屬醫院的衛教新聞記錄過一個案例：一名 50 歲女性原本腎功能就不好，因更年期症狀在友人建議下服用龜鹿二仙膠，自覺有效後自行加量，之後出現便祕與心悸，就醫檢查發現血清鉀離子高達 6.8（該院報導標示的單位為 mg/dL，臨床慣用單位為 mEq/L），需立即透析以避免致命性心律不整。該院腹膜透析主任林軒任醫師指出，方中的人參鉀離子含量相當高，腎臟疾病患者必須謹慎使用。 <a href="#ref-18">[18]</a> 判讀自己的腎功能落在哪一期，見〈[慢性腎臟病與 eGFR 分期](/articles/chronic-kidney-disease-egfr-guide/)〉。

**抗凝血與抗血小板藥物。** 這一項的證據來自方中的配伍藥材而非整方。Yuan 等人 2004 年發表於《Annals of Internal Medicine》的隨機雙盲安慰劑對照試驗，20 名健康受試者服用西洋參兩週後，warfarin 的尖峰國際標準化比值（INR）比安慰劑組下降 0.19（95% 信賴區間 -0.36 至 -0.07，p = 0.0012），也就是抗凝血效果被削弱。 <a href="#ref-13">[13]</a> 該試驗用的是西洋參，與方中的人參並非同一物種，但足以說明參類與 warfarin 之間存在可測量的交互作用。枸杞方面，Liu 等人 2016 年的體外實驗測得枸杞果汁與萃取物會抑制 CYP2C9 等第一階段代謝酵素， <a href="#ref-14">[14]</a> 而 warfarin 正是經 CYP2C9 代謝。體外資料不等於臨床事件，但兩個方向相反的訊號同時存在，代表正在服用抗凝血藥的人不該自行加吃這一味。長輩同時吃中藥與西藥時該注意的組合，另見〈[長輩西藥中藥一起吃，哪些組合真的會出事](/articles/elderly-tcm-western-drug-combos-that-matter/)〉。

**眼科的單一不良事件報告。** 高雄榮總團隊 2021 年在《American Journal of Ophthalmology Case Reports》報告一名 55 歲女性，無特殊眼科或內科病史，持續服用龜鹿二仙膠兩年後出現左眼進行性視力模糊，檢查發現為局限性脈絡膜血管瘤續發漿液性視網膜剝離。停用該中藥後，漿液性剝離在未接受其他處置的情況下完全消退。作者群推測與方中成分的血管新生作用有關。 <a href="#ref-4">[4]</a> 單一個案報告不能證明因果，但它是目前文獻中少數具體的不良事件紀錄，值得長期服用者知道。

**鹿角與鹿茸不是同一件事，但市場常混談。** 龜鹿二仙膠用的是鹿角（骨化後的角），不是鹿茸（未骨化的帶絨幼角）。這個區分在運動族群特別重要：Cox 與 Eichner 2013 年檢測六款市售鹿茸（deer antler velvet）補充品，在其中偵測到人類類胰島素生長因子 1（IGF-1），而 IGF-1 屬於世界反運動禁藥組織的禁用清單。 <a href="#ref-15">[15]</a> 有藥檢需求的運動員要把任何含鹿製品的補品當成高風險品項處理。

**孕期、哺乳與兒童**：現有人體研究的受試者是高齡男性與骨質疏鬆患者， <a href="#ref-2">[2]</a><a href="#ref-3">[3]</a> 沒有孕期、哺乳期或兒童的安全性資料。兒童服用補品想促進生長的想法，本站另有〈[轉骨方能不能讓青少年多長高](/myths/height-growth-tonic-myth/)〉。

**手術前**：方中的人參與枸杞都有影響凝血或藥物代謝的訊號， <a href="#ref-13">[13]</a><a href="#ref-14">[14]</a> 排定手術的人應主動向醫師與麻醉科揭露正在服用的所有中藥。

**普林含量**：本站檢索台灣各醫學中心的低普林飲食衛教單張與食藥署資料，沒有找到膠類中藥的普林含量數據。痛風患者常問這件事，但目前查無可引用的本土數值，只能請主治醫師依整體飲食評估。這一項屬於查無。

## 常見迷思

- **「有幾千年歷史所以一定有效」**：國家中醫藥研究所的考證把此方的年代訂在最晚不晚於 16 世紀初。 <a href="#ref-16">[16]</a> 四百多年不算短，但使用時間長度與療效證據是兩套不同的判準。現代的檢驗結果是：整體療效判定有顯著差異，疼痛與功能兩項硬指標沒有。 <a href="#ref-1">[1]</a>
- **「統合分析說有效」**：這份統合分析顯著的那個指標叫「總有效率」，是由研究者依綜合印象判定有效或無效的二分法結果，在中文文獻中很常見，但主觀成分高、容易受未設盲影響。同一份分析中，用量表測量的疼痛分數與 Lequesne 功能指數都沒有達到顯著。 <a href="#ref-1">[1]</a> 讀到「有效率提升」時，要先問有效的定義是誰下的。
- **「吃了骨密度會上升」**：長庚的病例對照研究直接測了這件事，85 名服用者與 425 名配對對照相比，T 值改善沒有組間差異，五年整體骨折率也沒有差異（p = 0.335）。 <a href="#ref-3">[3]</a> 該研究觀察到的唯一正向結果是腰椎骨折較少，且限於累積服用 600 顆以上的族群，屬於次族群分析。
- **「補膠原蛋白就能補到骨頭」**：口服膠原蛋白會在消化道被拆成胺基酸與小胜肽，能否以完整序列抵達骨骼是另一個問題。TSK 與 YR 這兩段胜肽的效果目前只在細胞實驗中被觀察到。 <a href="#ref-6">[6]</a><a href="#ref-7">[7]</a> 同類的推論陷阱在〈[葡萄糖胺與軟骨素能逆轉關節退化嗎](/myths/glucosamine-chondroitin-oa-reversal-myth/)〉裡有更完整的拆解。
- **「越貴越真」**：消基會的檢測顯示，問題集中在來源管道而非價格帶。 <a href="#ref-19">[19]</a> 而衛福部的偽藥公告更直接：假貨的銷售場景可以發生在醫院走廊。 <a href="#ref-17">[17]</a> 價格是成本的線索，不是真偽的證明。

## 常見問題

### 龜鹿二仙膠到底有沒有人體試驗？

有，但數量少且品質參差。目前可查到的包含一份納入 8 篇研究的系統性回顧與統合分析（膝關節退化）、 <a href="#ref-1">[1]</a> 一份 42 人的台灣非隨機對照研究、 <a href="#ref-2">[2]</a> 一份 85 對 425 的長庚病例對照研究。 <a href="#ref-3">[3]</a> 本站在 PubMed、Cochrane Library 與 ClinicalTrials.gov 檢索後，沒有找到以龜鹿二仙膠為介入、設安慰劑對照且樣本超過百人的隨機試驗。這一項屬於查無。

### 它跟市售的膠原蛋白粉有什麼不同？

分子層級的主體是同一類東西：水解後的膠原蛋白與明膠。差別在原料物種（龜甲與鹿角對上豬皮、魚鱗或牛皮）、伴隨的礦物質組成，以及方中另外加入的人參與枸杞。目前沒有任何頭對頭試驗比較過兩者，價格差距則相當可觀。

### 腎功能不好可以吃嗎？

不建議自行服用。亞洲大學附屬醫院通報的案例顯示，腎功能不佳者自行加量服用後出現危險程度的高血鉀，需要緊急透析；該院醫師指出問題出在方中人參的鉀含量。 <a href="#ref-18">[18]</a> 已有慢性腎臟病診斷的人，把它列入「要先問過醫師才決定」的品項。

### 正在吃抗凝血藥可以吃嗎？

在醫師評估前不要自行併用。西洋參在隨機對照試驗中被測出會降低 warfarin 的抗凝血效果， <a href="#ref-13">[13]</a> 枸杞則在體外實驗中抑制 warfarin 的主要代謝酵素 CYP2C9。 <a href="#ref-14">[14]</a> 兩個訊號的方向不同，合併使用後 INR 會往哪邊跑無法預測，這比單一方向的交互作用更難處理。

### 怎麼分辨買到的是不是真品？

外觀與氣味在實務上難以判別，實驗室需要用質譜搭配主成分分析才能區分不同動物來源的明膠。 <a href="#ref-11">[11]</a><a href="#ref-12">[12]</a> 消費者能做的是把關通路與文件：確認產品有中央主管機關核發的許可證字號、由 GMP 藥廠製造、在合法中藥房或醫療院所購買。 <a href="#ref-17">[17]</a> 消基會的檢測結果支持這個順序：醫療院所與藥商藥局來源的樣品未檢出西藥，不明管道的檢出率 23.1%。 <a href="#ref-19">[19]</a>

### 龜板的來源會有法律問題嗎？

會。龜類依種別分別受《野生動物保育法》與華盛頓公約管制，保育類物種與其產製品的輸出入、買賣都有規範。 <a href="#ref-23">[23]</a> 台灣市售龜板的產地包含印尼、泰國、馬來西亞、緬甸等地， <a href="#ref-16">[16]</a> 物種鑑定在學術上是一個被專門研究過的題目。 <a href="#ref-24">[24]</a> 從消費端來說，向有完整進貨憑證的合法業者購買，是唯一可行的自保方式。

### 送禮送這個安全嗎？

先問對方三件事：有沒有腎臟疾病、有沒有在吃抗凝血或抗血小板藥物、近期有沒有排定手術。這三類人都落在需要先諮詢醫師的範圍內。 <a href="#ref-13">[13]</a><a href="#ref-18">[18]</a> 如果問不出來，選一個限制條件少的禮物會比較省事。

### 現在有沒有新的試驗正在進行？

有一筆。ClinicalTrials.gov 登錄編號 NCT06980922，由台灣的團隊執行，主題是龜鹿二仙膠用於血液透析中低血壓，預計收案 34 人，狀態為尚未開始收案。 <a href="#ref-25">[25]</a> 樣本規模很小，結果出來後仍需要以同樣的標準檢視，包含有沒有設盲、主要終點是什麼、是誰資助的。
