## 30 秒認識

- 瑪卡（Maca，學名 Lepidium meyenii）是秘魯安地斯高原海拔 4000 公尺以上生長的十字花科根莖植物，當地人已食用數千年，傳統上是煮湯、磨粉當主食的日常食物，不是藥物。 <a href="#ref-9">[9]</a>
- 一項針對健康男性的隨機對照試驗發現，服用瑪卡 8 週後性慾自我評分提升，但血清睪固酮與雌二醇濃度在瑪卡組與安慰劑組之間沒有差異，效果被判斷與睪固酮無關。 <a href="#ref-1">[1]</a>
- 停經後婦女的小型交叉試驗顯示，瑪卡可降低 Greene 更年期症狀量表中的心理症狀與性功能障礙分數，同樣未觀察到雌激素、黃體生成素等荷爾蒙濃度的改變。 <a href="#ref-3">[3]</a>
- 兩篇系統性回顧都只找到 4 篇符合條件的隨機對照試驗，共同結論是「證據方向偏正向，但試驗數量少、樣本數小、方法學品質不一，不足以下定論」，呼籲更大規模的研究。 <a href="#ref-6">[6]</a><a href="#ref-7">[7]</a>
- 瑪卡不是威而鋼一類的 PDE5 抑制劑，沒有直接改善勃起生理機轉的證據，市面上「壯陽神器」的行銷語言與現有研究證據強度有明顯落差。 <a href="#ref-8">[8]</a>

## 基本介紹

瑪卡是十字花科（Brassicaceae，即芸薹科／甘藍家族）獨行菜屬的根莖植物，外型類似小型的蕪菁或蘿蔔，依顏色可分為黃、紅、黑等品系。它只生長在秘魯中部安地斯山區海拔 3800 至 4500 公尺的高原地帶，當地氣候日夜溫差極大、日照強烈、土壤貧瘠，是少數能在這種環境穩定收成的作物。安地斯原住民將瑪卡塊根煮熟食用、曬乾磨粉，或發酵成傳統飲品「瑪卡奇恰」（chicha de maca），作為高原生活消耗體力後的日常能量補充來源，這個食用傳統至少可追溯兩千年以上。 <a href="#ref-9">[9]</a> 近二十年來，瑪卡從安地斯山區的地方食材，變成全球保健食品市場常見的原料，行銷訴求集中在「提升性慾」「改善更年期不適」「增加體力」，但學術界對這些訴求的系統性回顧，態度普遍比市場行銷謹慎許多。 <a href="#ref-8">[8]</a>

## 這是什麼？

瑪卡是一種食物，不是單一化學成分，因此討論「瑪卡的效果」時，指的其實是整顆乾燥根莖磨粉或萃取後的複合物。它的主要活性成分包括瑪卡醯胺（macamides）、瑪卡烯（macaenes）與硫代葡萄糖苷（glucosinolates，即芥子油苷）。瑪卡醯胺是瑪卡特有的一類脂肪酸醯胺，目前只在瑪卡根中被發現；硫代葡萄糖苷則是十字花科植物常見的含硫化合物，也是花椰菜、甘藍等蔬菜辛辣味與潛在甲狀腺交互作用的來源之一。 <a href="#ref-9">[9]</a> 依照根部顏色，市售瑪卡萃取物常分為黃瑪卡、紅瑪卡、黑瑪卡三種品系，三者的脂肪酸與瑪卡醯胺、γ-胺基丁酸（GABA）等成分比例不同，一項針對高海拔與低海拔居民的隨機對照試驗發現，紅瑪卡與黑瑪卡萃取物在情緒、體力與慢性高山症評分上都有改善，其中紅瑪卡在情緒與體力指標上的效果又略優於黑瑪卡，黑瑪卡則觀察到降低血糖的效果，作者認為這與兩種品系的成分比例差異有關。 <a href="#ref-5">[5]</a>

## 在身體裡做什麼？／主要作用機制

瑪卡對性慾與更年期症狀的作用機制，是目前研究中最常被誤解的部分。多篇隨機對照試驗一致發現，瑪卡介入後的效果改變（性慾評分提升、更年期症狀量表分數下降）與血清睪固酮、雌二醇等性荷爾蒙濃度的變化沒有對應關係，也就是說瑪卡並非透過直接提高睪固酮或雌激素濃度來產生效果。 <a href="#ref-1">[1]</a><a href="#ref-3">[3]</a> 美國紀念斯隆凱特琳癌症中心（Memorial Sloan Kettering Cancer Center）整理的作用機制資料指出，動物與體外實驗提出了幾條可能路徑：瑪卡醯胺被認為可能抑制脂肪酸醯胺水解酶（FAAH），進而調節神經傳導物質的釋放；也有實驗室證據顯示瑪卡可能在標的器官的雄激素受體層次產生作用，而非透過改變循環中的睪固酮濃度；此外瑪卡在動物實驗中也觀察到類似抗憂鬱藥物的行為變化，與正腎上腺素、多巴胺系統的活化有關。 <a href="#ref-10">[10]</a> 這些機制多半來自動物實驗或體外實驗，尚未在人體研究中被直接證實，2024 年一篇彙整瑪卡藥理學研究的回顧也坦言，瑪卡許多提出的作用路徑「因為缺乏足夠資料而無法確認」，仍待更多機制研究補齊。 <a href="#ref-9">[9]</a>

## 食物來源／常見來源

瑪卡本身就是食物，不需要透過其他來源攝取。在秘魯原產地，新鮮瑪卡塊根會經過日曬乾燥數週，乾燥後的瑪卡可以直接水煮成粥狀主食，磨成粉加入湯品、烤餅，或發酵製成微酸帶氣的傳統飲品瑪卡奇恰。 <a href="#ref-9">[9]</a> 台灣消費者接觸到的瑪卡幾乎都是進口乾燥粉末或萃取物，市面上常見的黃、紅、黑三色瑪卡粉，差異來自天然根部顏色而非人工添加，價格與成分濃度也依加工方式（原粉、熱水萃取、酒精萃取）而有落差。由於瑪卡屬於十字花科蔬菜家族，在營養組成上與蕪菁、白蘿蔔等根莖類蔬菜類似，含有澱粉、膳食纖維與微量礦物質；不過保健食品市場的關注焦點通常不在這些基礎營養素，而是前一段提到的瑪卡醯胺、硫代葡萄糖苷等特有活性成分。

## 建議攝取量／常見攝取建議／研究中常見使用方式

目前沒有官方機構針對瑪卡訂出建議攝取量，台灣衛生福利部食品藥物管理署也未將瑪卡列入具有每日攝取上限公告的品項，因此下列數字僅反映臨床試驗中實際使用的劑量，不是官方建議值。研究男性性慾的隨機對照試驗使用每日 1500 毫克或 3000 毫克瑪卡萃取粉，介入 12 週，效果自第 8 週起出現。 <a href="#ref-1">[1]</a> 研究輕度勃起功能障礙的試驗使用每日 2400 毫克瑪卡乾燥萃取物，同樣為期 12 週。 <a href="#ref-2">[2]</a> 研究停經後婦女心理症狀與性功能障礙的交叉試驗，使用劑量是每日 3.5 克瑪卡粉，介入與安慰劑各 6 週交叉進行。 <a href="#ref-3">[3]</a> 研究抗憂鬱藥物引起性功能障礙的試驗，則使用每日 3.0 克瑪卡根粉，介入 12 週。 <a href="#ref-4">[4]</a> 綜合來看，多數人體試驗的劑量落在每日 1.5 至 3.5 克之間，介入期普遍為 8 到 12 週，效果評估也多在這個時間框架內出現，短於 8 週的試驗較難觀察到瑪卡對性慾或更年期症狀的效果，這點在解讀「吃了兩週沒感覺」這類個人經驗時值得留意。

## 缺乏風險或攝取不足問題

瑪卡不是人體必需營養素，沒有「缺乏症」的概念，不攝取瑪卡不會造成生理功能缺損，這點與維生素、礦物質等必需營養素不同。討論瑪卡時比較貼切的問題是「哪些族群的性慾或更年期症狀困擾，可能會考慮把瑪卡當成非荷爾蒙途徑的輔助選項」，而不是「誰缺瑪卡」。停經後出現熱潮紅、情緒波動、性功能困擾又不適合或不願意使用荷爾蒙補充療法的婦女，是現有研究中討論較多的族群之一，但如前述系統性回顧所指出，支持這個用法的試驗數量與樣本數都偏小，Lee 等人 2011 年的系統性回顧只找到 4 篇符合條件的隨機對照試驗，作者明確指出「證據有限」，效果與安全性都需要更大規模的研究驗證，且回顧當時的資料尚不足以確認長期安全性。 <a href="#ref-7">[7]</a>

## 補充品常見形式

市售瑪卡產品常見形式包括原粉（乾燥根莖直接磨粉）、熱水或酒精萃取濃縮粉，以及膠囊、錠劑。原粉保留原始成分比例，但活性成分濃度較低，需要較大劑量才能對應到臨床試驗使用的量；萃取濃縮物標榜活性成分濃度較高，但目前沒有標準化的萃取比例規範，不同品牌的濃縮倍率與檢驗方式不一致，這也是 2018 年一篇檢視瑪卡生殖健康宣稱的回顧特別提出的疑慮之一，作者指出市售產品的品質與活性成分含量落差大，消費者難以從包裝資訊判斷實際劑量是否對應到研究中使用的量。 <a href="#ref-8">[8]</a> 依根部顏色分的黃、紅、黑瑪卡則是另一種分類方式，前述比較黑瑪卡與紅瑪卡萃取物的隨機對照試驗顯示兩者在情緒、體力與血糖等指標上各有側重，選購時可留意產品標示的品系與萃取方式，但不必迷信單一顏色「效果最好」的行銷說法。 <a href="#ref-5">[5]</a>

## 安全性與注意事項

現有短期人體試驗（多為 12 週以內）顯示瑪卡的耐受性良好，多篇隨機對照試驗都未觀察到嚴重不良反應。 <a href="#ref-5">[5]</a> 需要留意的幾個方向：第一，瑪卡屬於十字花科植物，含有硫代葡萄糖苷，這類成分在部分十字花科蔬菜（如高麗菜、花椰菜）中已知可能干擾甲狀腺碘吸收，紀念斯隆凱特琳癌症中心的資料庫將此列為潛在注意事項，甲狀腺功能異常者或正在服用甲狀腺相關藥物者，建議先與醫師討論攝取量。 <a href="#ref-10">[10]</a> 第二，瑪卡可能透過雄激素受體層次產生作用，紀念斯隆凱特琳的資料庫收錄一則案例報告，描述一名女性每日服用約一茶匙瑪卡粉後出現經期間歇性出血與睪固酮濃度上升，提醒荷爾蒙敏感疾病（如乳癌、子宮內膜異位）病史者使用前應與醫師討論。 <a href="#ref-10">[10]</a> 第三，瑪卡可能影響部分睪固酮免疫檢測方法的準確性，若近期有服用瑪卡且需要抽血檢測睪固酮，建議主動告知醫療人員。 <a href="#ref-10">[10]</a> 第四，目前所有人體試驗的追蹤期都在 12 週以內，長期（數月至數年）使用的安全性資料仍不足，Beharry 與 Heinrich 2018 年的回顧與 Lee 等人 2011 年的系統性回顧都明確指出這是現有證據的限制之一，孕婦、哺乳中婦女因缺乏安全性資料，也建議避免自行補充。 <a href="#ref-7">[7]</a><a href="#ref-8">[8]</a>

## 常見迷思

- **「瑪卡是天然壯陽藥，效果跟威而鋼一樣」**：瑪卡不是磷酸二酯酶第五型（PDE5）抑制劑，沒有直接改善勃起生理機轉的證據；現有試驗多測量「主觀性慾評分」或「性滿意度問卷」，與威而鋼一類藥物針對勃起功能障礙的明確臨床療效是不同層次的證據。 <a href="#ref-8">[8]</a>
- **「瑪卡能提升睪固酮，所以有壯陽效果」**：多篇隨機對照試驗都測量了血清睪固酮濃度，結果一致顯示瑪卡組與安慰劑組之間沒有統計差異，效果被判斷與睪固酮無關，這點在 2002 年的原始研究標題就直接寫明「與血清睪固酮濃度無關」。 <a href="#ref-1">[1]</a>
- **「瑪卡只對男性有效，是男性專屬補品」**：現有研究同時涵蓋男性與女性，停經後婦女與抗憂鬱藥物引起性功能障礙的女性受試者，都有小型隨機對照試驗觀察到症狀量表分數改善，市場把瑪卡包裝成「男性專屬」是行銷選擇，不是研究證據的限制。 <a href="#ref-3">[3]</a><a href="#ref-4">[4]</a>
- **「試驗證實有效，代表可以放心大量長期吃」**：兩篇系統性回顧的作者都在結論中強調，現有試驗數量少（各僅 4 篇符合條件）、樣本數小、追蹤期短，這代表「證據方向偏正向」與「證據強度足以下定論」是兩回事，長期安全性資料也還不足。 <a href="#ref-6">[6]</a><a href="#ref-7">[7]</a>

## 常見問題

### 吃瑪卡多久才會有感覺？

現有人體試驗的介入期多在 8 到 12 週之間，其中針對男性性慾的研究觀察到效果從第 8 週開始出現，短於這個時間框架的使用經驗，較難與臨床試驗的效果評估對應。 <a href="#ref-1">[1]</a> 這也代表短期（例如兩週）沒有感覺，不必然代表無效，但也不表示延長使用時間就一定會有效果，畢竟現有試驗規模都不大。

### 瑪卡可以取代荷爾蒙補充療法（HRT）處理更年期症狀嗎？

不建議直接類比。瑪卡相關試驗測量的是 Greene 更年期症狀量表中的心理症狀與性功能障礙分數，且機制上與雌激素濃度改變無關，這與荷爾蒙補充療法透過補充雌激素、黃體素直接調節生理機轉是不同途徑。 <a href="#ref-3">[3]</a> 是否使用荷爾蒙補充療法牽涉個人病史與風險評估，建議與婦產科或更年期門診醫師討論，不宜僅憑瑪卡的初步研究結果自行替代處方治療。

### 甲狀腺功能異常的人可以吃瑪卡嗎？

瑪卡屬於十字花科植物，含有硫代葡萄糖苷，這類成分在部分十字花科蔬菜中已知可能干擾甲狀腺碘的吸收利用。目前沒有針對甲狀腺疾病患者攝取瑪卡的專門研究數據，紀念斯隆凱特琳癌症中心的整理資料建議甲狀腺功能異常者或正在服用甲狀腺相關藥物者，攝取前先與醫師討論較為保守。 <a href="#ref-10">[10]</a>

### 瑪卡有經過台灣食藥署核准的保健功效嗎？

瑪卡目前不是台灣衛生福利部核發「健康食品字號」的品項，市面上標示瑪卡的產品多以一般食品或膳食補充品形式販售，不得宣稱具有醫療效果或健康食品法規範的保健功效；若產品廣告出現「壯陽」「治療勃起功能障礙」等療效字眼，已超出一般食品可合法宣稱的範圍，建議留意產品標示是否誇大。
