## 30 秒認識

- 益生菌的臨床證據綁在**菌株**上，不在菌種、也不在總菌數。標示必須看到完整的三層：屬、種、株編號，例如 *Lacticaseibacillus rhamnosus* GG 的那個 GG。 <a href="#ref-1">[1]</a>
- 2020 年的分類學修訂把原本的 *Lactobacillus* 屬拆成 25 個屬、新增 23 個新屬名。 <a href="#ref-2">[2]</a> 同一株菌在舊標示與新標示上的屬名可能完全不同，看不到株編號的產品現在更難追。
- CFU 要看標的是「出廠時」還是「有效期限內」。52 件市售補充品的檢測中，有 17 件（33%）在效期前就低於標示菌數。 <a href="#ref-16">[16]</a>
- 標示的菌種本身也常錯。同一份檢測中只有 30/52（58%）的產品分類標示正確；另一份針對比菲德氏菌產品的研究中，16 件裡只有 1 件完全符合標示。 <a href="#ref-16">[16]</a><a href="#ref-17">[17]</a>
- 證據最一致的應用是抗生素相關腹瀉的預防：兒童族群的考科藍回顧測得相對風險 0.45（95% CI 0.36 至 0.56），每日 50 億 CFU 以上的次群組為 0.37。 <a href="#ref-5">[5]</a>
- 有些被廣泛宣稱的用途證據反而是否定的。2018 年《NEJM》同期兩篇共 1,857 名兒童的試驗，益生菌對急性腸胃炎都沒有優於安慰劑。 <a href="#ref-9">[9]</a><a href="#ref-10">[10]</a>
- 免疫低下者、重症與早產兒的菌血症是有通報與基因定序佐證的真實風險。美國 FDA 在 2023 年 9 月因一名早產兒死亡發出警示。 <a href="#ref-25">[25]</a><a href="#ref-30">[30]</a>
- 台灣的健康食品現行 13 項保健功效裡有「胃腸功能改善」，取得許可證的產品可以在許可範圍內宣稱；沒有許可證的一般食品不行。 <a href="#ref-34">[34]</a>

## 貨架前的問題：兩罐都寫 300 億

益生菌這一櫃的標示風格大同小異：正面一個很大的數字（三百億、五百億、一千億），底下一行菌種名，背面一串「專利包埋」「耐胃酸」「多國認證」。價差可以從一個月三百元到一個月一千五百元。

菌數那個數字是三項資訊裡最不關鍵的一項。原因在於，臨床試驗做的從來不是「益生菌」這個類別，而每一份有效的試驗都綁定一支特定的菌株、一個特定的劑量、一個特定的適應症。把 A 菌株的試驗結果拿去支持 B 菌株的產品，即使兩者是同一個菌種，也是不成立的推論。 <a href="#ref-1">[1]</a>

這一頁處理五件事。第一，菌株編號的三層結構，以及 2020 年那場分類學大改名讓標示變得多亂。第二，CFU 那個數字的兩種定義，以及市售產品實測到的落差。第三，包埋與耐胃酸技術哪一部分有意義、哪一部分是行銷。第四，哪些適應症有一致的證據、哪些反而有否定的結果。第五，台灣的健康食品制度讓哪些話可以講、哪些話不能講。

益生菌的定義、常見菌屬、發酵食品與補充品的分別，整理在本站的[益生菌成分頁](/ingredients/probiotics/)。這一頁只處理「手上這一罐的標示該怎麼讀」。

## 菌株編號：全篇最重要的那一行字

### 屬、種、株是三層

微生物的命名有三層，而益生菌的標示常常只給你前兩層。

以 *Lacticaseibacillus rhamnosus* GG 為例：*Lacticaseibacillus* 是**屬**（genus），*rhamnosus* 是**種**（species），GG 是**株**（strain）。屬與種是分類學單位，描述這隻菌長什麼樣、代謝什麼；株是同一個種底下基因體有差異的個體，而臨床效果的差異就發生在這一層。

ISAPP 的共識聲明把這件事寫得很直接：益生菌的健康效益必須連結到特定菌株，不可外推到同菌種的其他菌株，也不可外推到整個類別。 <a href="#ref-1">[1]</a> 一份針對 228 篇試驗的系統性回顧也支持同樣的結論：益生菌的效果同時具有菌株專一性與疾病專一性。 <a href="#ref-4">[4]</a>

實務上的判斷很簡單：**成分表上找不到株編號的產品，等於沒有告訴你它用的是什麼**。看到「rhamnosus 菌 100 億」而沒有後面那串編號，你無法對照到任何一份試驗。

### 2020 年的大改名讓標示更亂

這是近年讀益生菌標示最容易踩到的坑。

Zheng 等人 2020 年在《International Journal of Systematic and Evolutionary Microbiology》發表的分類學修訂，依基因體資料把原本龐雜的 *Lactobacillus* 屬拆開，新增 23 個屬名，並把 Lactobacillaceae 與 Leuconostocaceae 兩個科合併。 <a href="#ref-2">[2]</a> 結果是一批熟悉的名字改了姓：

| 舊屬種名 | 現行屬種名 |
|---|---|
| *Lactobacillus rhamnosus* | *Lacticaseibacillus rhamnosus* |
| *Lactobacillus casei* | *Lacticaseibacillus casei* |
| *Lactobacillus paracasei* | *Lacticaseibacillus paracasei* |
| *Lactobacillus plantarum* | *Lactiplantibacillus plantarum* |
| *Lactobacillus reuteri* | *Limosilactobacillus reuteri* |
| *Lactobacillus acidophilus* | 維持 *Lactobacillus acidophilus* |

對消費者的實際影響有兩層。一，同一支菌在不同年份印製的包裝上屬名不同，容易誤以為是兩種東西。二，**株編號在這場改名中沒有變**，GG 還是 GG、DSM 17938 還是 DSM 17938。所以株編號現在是跨版本追蹤同一支菌最可靠的錨點，比屬種名還可靠。

比菲德氏菌那一邊沒有受這次修訂影響，但它有自己的坑：*Bifidobacterium longum* 底下的亞種 subsp. *infantis* 與 subsp. *longum* 用途差很多，標示只寫到種的產品同樣分不出來。

### 同種不同株為什麼不能互相套用

最容易理解的例子在抗生素相關腹瀉。Szajewska 與 Kołodziej 2015 年針對 *Lactobacillus rhamnosus* GG 的統合分析納入 12 篇試驗、1,499 名受試者，抗生素相關腹瀉的風險從 22.4% 降到 12.3%（11 篇、1,308 人，RR 0.49，95% CI 0.29 至 0.83），而分層之後這個效果**只在兒童族群達到統計顯著**（5 篇、445 人，RR 0.48，95% CI 0.26 至 0.89）。 <a href="#ref-7">[7]</a>

同一組作者在同一年發表的布拉氏酵母菌統合分析納入 21 篇試驗、4,780 名受試者，風險從 18.7% 降到 8.5%（RR 0.47，95% CI 0.38 至 0.57，需治療人數 10）。 <a href="#ref-8">[8]</a>

這兩支菌不只是不同株，連界都不同（一個是細菌、一個是酵母），劑量、與抗生素併服的規則也完全不一樣。把它們一起叫做「益生菌」然後說「益生菌可以預防抗生素腹瀉」，聽起來沒錯，但拿去選購時提供不了任何判斷力。與抗生素併用的間隔規則，本站〈[吃抗生素可以吃益生菌嗎](/articles/probiotics-with-antibiotics-spacing/)〉寫得比較細。

## CFU 那個數字怎麼讀

### 出廠保證還是效期末保證

CFU 是菌落形成單位，指的是能長出菌落的活菌數量。同一個數字有兩種標法：

- **出廠時菌數（at time of manufacture）**：包裝當下的數量。之後在倉儲、運送與貨架上的衰減不在保證範圍內。
- **有效期限內保證菌數（at end of shelf life）**：廠商保證到效期最後一天仍達到的數量。

兩者之間的差距不小，而且會隨保存條件放大。ISAPP 相關的品質討論指出，標示方式與第三方驗證是使用者判斷產品品質的關鍵，並建議廠商接受第三方評估以確保菌數與標示的正確性。 <a href="#ref-18">[18]</a>

實務上的讀法：包裝上找「有效期限內」「效期末」「end of shelf life」這類字樣。只寫「出廠含 XXX 億」的產品，你買到的活菌數取決於它在倉庫與貨架上放了多久、放在幾度。

### 標示與實際的落差有實測資料

這不是理論上的擔心。Morovic 等人 2016 年用平板計數、標的基因型定序與高通量定序檢測 52 件市售補充品，結果是 **17 件（33%）在有效期限之前就低於標示的 CFU**，而且只有 30/52（58%）的產品分類標示正確，問題包括菌種標錯、列了卻沒驗到、以及驗到卻沒有標示的菌種。 <a href="#ref-16">[16]</a>

Lewis 等人 2016 年針對含比菲德氏菌的產品做過類似的查核：16 件產品中只有 1 件完全符合標示的比菲德氏菌宣稱，而且同一件產品的不同顆粒之間、不同批號之間都有差異。 <a href="#ref-17">[17]</a> 作者用的字是「令人擔憂」。

這兩份研究檢測的是美國市場、抽樣年份也較早，不能直接推論到今天的台灣貨架。但它們給出一個判斷順序：在比較「這罐 300 億、那罐 500 億」之前，先看有沒有第三方檢驗報告、批號與效期對不對得上手上這一罐。這一項能篩掉的問題，比菌數的差距大得多。

### 高 CFU 等於有效嗎

劑量與效果的關係同樣是菌株專一的，但有一份資料可以當參考。2019 年的考科藍回顧在兒童抗生素相關腹瀉的次群組分析中發現，**每日 50 億 CFU 以上**的劑量組效果較好（8% 對 23%，RR 0.37，95% CI 0.30 至 0.46），整體分析則是 RR 0.45。 <a href="#ref-5">[5]</a>

所以「幾十億到幾百億」這個區間確實是臨床試驗常用的範圍，低到幾億的產品要打問號。但往上堆到一千億、五千億並沒有對應的劑量反應證據，那個數字主要是貨架上的競賽。真正決定效果的順序是：**有沒有對應適應症的菌株 → 該菌株的試驗劑量 → 保證菌數是否落在那個劑量 → 保存條件**。

### 活菌數之外的計數方式

近年有些產品改用 AFU（活性螢光單位）或流式細胞術計數，理由是傳統平板培養會低估那些「活著但暫時長不出菌落」的細胞。這個方法學上的討論是真的，Jackson 等人 2019 年的回顧就把全基因體定序與流式細胞術列為品質評估的新興工具。 <a href="#ref-18">[18]</a>

要留意的地方也在這裡：**AFU 與 CFU 不是同一個單位，不能直接比較**。一罐標 500 億 AFU 與一罐標 500 億 CFU，前者的數字通常會比用平板法測同一批料得到的數字大。看到單位不同的兩罐並排，那個「比較多」是換算方式造成的。

## 包埋與耐胃酸：有意義的部分與誇大的部分

包埋（microencapsulation）是用海藻酸鹽、乳清蛋白、脂質等材料把菌體包起來，目的有二：提高儲存期間的存活率，以及讓菌通過胃酸與膽鹽後仍有足夠活菌抵達腸道。這是有文獻基礎的配方設計，Yao 等人 2020 年的回顧整理了各種包埋材料與製程的進展。 <a href="#ref-19">[19]</a>

誇大的部分出現在兩處。

**第一，多數包埋研究的終點是存活率，不是臨床效果。** 回顧中的資料多來自體外模擬胃腸道消化與儲存穩定性試驗，「包埋後存活率提高幾倍」與「吃了之後症狀改善多少」是兩件不同的事，後者需要該產品自己的臨床試驗。

**第二，某些菌種本來就不太需要包埋。** 芽孢桿菌屬（*Bacillus*）會形成內生孢子，耐熱耐酸耐乾燥，在常溫下本來就穩定；布拉氏酵母菌是酵母，對胃酸的耐受性也比多數乳酸桿菌好。把包埋技術當成這類產品的主要賣點，賣的是它本來就有的性質。

判斷方式：包埋是加分項，不是資格項。一罐標得出菌株編號、標得出效期末菌數的無包埋產品，資訊價值高於一罐只寫「專利四層包埋、五百億」的產品。

## 配方裡的其他名詞

成分表上常跟益生菌一起出現的三個詞，定義各自有共識聲明可以對照。

**益生質（prebiotics，或譯益生元）**：ISAPP 2017 年的定義是「被宿主微生物選擇性利用而帶來健康益處的基質」，常見的有菊糖、果寡醣、半乳寡醣。 <a href="#ref-20">[20]</a> 它是食物，不是活菌。膳食纖維與益生質的關係、每日該吃多少，見本站[益生元](/ingredients/prebiotics/)與〈[膳食纖維一天要吃多少](/articles/dietary-fiber-how-much-soluble-insoluble/)〉。

**合生元（synbiotics）**：ISAPP 2020 年的共識把它定義為「含有活微生物與被宿主微生物選擇性利用的基質、共同帶來健康益處的混合物」，並區分互補型與協同型兩類。 <a href="#ref-21">[21]</a> 邏輯上合理，但一罐合生元的效果仍需要它自己的試驗，不能用其中菌株與益生質各自的試驗相加。

**後生元（postbiotics）**：ISAPP 2021 年的定義是「對宿主帶來健康益處的無生命微生物與/或其成分的製劑」。 <a href="#ref-22">[22]</a> 它不含活菌，因此沒有定殖與菌血症的問題，常溫保存也容易。相對地，它的臨床證據量遠少於活菌益生菌，細節見本站[後生元](/ingredients/postbiotics/)。

## 有證據的適應症與證據薄弱的宣稱

### 抗生素相關腹瀉：證據最一致的一項

2019 年的考科藍回顧納入 33 篇試驗、6,352 名兒童，益生菌組的抗生素相關腹瀉發生率 8%（259/3,232）對照組 19%（598/3,120），相對風險 0.45（95% CI 0.36 至 0.56），需治療人數 9 人，證據確定性中等，且沒有嚴重不良事件通報。 <a href="#ref-5">[5]</a>

具體到菌株，*Lacticaseibacillus rhamnosus* GG 與布拉氏酵母菌是資料最多的兩支。 <a href="#ref-7">[7]</a><a href="#ref-8">[8]</a> 這也是美國胃腸病學會 2020 年指引中少數給出建議的情境之一。 <a href="#ref-14">[14]</a><a href="#ref-15">[15]</a>

### 困難梭狀桿菌相關腹瀉

2017 年的考科藍回顧納入 39 篇研究、9,955 名受試者，完整病例分析（31 篇、8,672 人）測得相對風險 0.40（95% CI 0.30 至 0.52）。效益明顯集中在基礎風險高於 5% 的族群（RR 0.30，95% CI 0.21 至 0.42），整體需治療人數為 42 人。 <a href="#ref-6">[6]</a>

需治療人數 42 這個數字有實務意涵：在低風險族群裡，要 42 個人吃才避免一次事件，成本效益的討論空間比看到 RR 0.40 時想像的小得多。

### 急性腸胃炎：兩篇大型試驗的否定結果

這是最值得單獨寫的一段，因為市場的宣稱與證據方向相反。

2018 年《NEJM》同期刊出兩篇多中心隨機試驗。Schnadower 等人收 971 名學齡前兒童，五天療程的 *L. rhamnosus* GG 對安慰劑，中重度腸胃炎發生率 11.8% 對 12.6%（RR 0.96，95% CI 0.68 至 1.35，P = 0.83）。 <a href="#ref-9">[9]</a> Freedman 等人收 886 名到急診就醫的兒童，*L. rhamnosus* 與 *L. helveticus* 複方一天兩次，中重度腸胃炎 26.1% 對 24.7%（OR 1.06，95% CI 0.77 至 1.46，P = 0.72）。 <a href="#ref-10">[10]</a>

兩篇加起來 1,857 名兒童、兩種不同的產品、兩個國家的急診，都沒有測到優於安慰劑。這組結果不能推翻所有腹瀉相關的應用（預防與治療是兩件事），但它說明「小孩拉肚子就吃益生菌」這個習慣，在目前最高品質的證據裡沒有支撐。

### 旅行者腹瀉

McFarland 2007 年整合 12 篇隨機試驗，益生菌顯著降低旅行者腹瀉風險（RR 0.85，95% CI 0.79 至 0.91，p 小於 0.001），有效的是布拉氏酵母菌與嗜酸乳桿菌加比菲德氏菌的組合，12 篇試驗中沒有嚴重不良反應通報。 <a href="#ref-11">[11]</a>

RR 0.85 的意思是相對風險降低 15%，效果不大，而這份統合分析發表於 2007 年，納入的試驗更早。出國前要不要帶，這個數字提供的是一個小幅的、證據等級中等的理由。

### 腸躁症：統合分析與臨床指引方向相反

Ford 等人 2018 年的統合分析納入 53 篇益生菌試驗、5,545 名腸躁症患者，部分菌株組合對整體症狀與腹痛呈現可能的效益，但作者認為菌株、劑量與試驗品質的異質性太高，無法給出哪一支菌株可以推薦的結論。 <a href="#ref-12">[12]</a>

美國胃腸病學會 2021 年的腸躁症臨床指引據此建議不要使用益生菌治療腸躁症的整體症狀。 <a href="#ref-13">[13]</a> 這種「統合分析看起來有一點效、指引卻不建議」的落差，通常來自品質評估與發表偏差的考量，而不是某一方看漏了資料。腸躁症有證據的處理順序，本站〈[腸躁症完整指南](/articles/ibs-low-fodmap-guide/)〉整理過三階段低 FODMAP 飲食的做法。

### 證據薄弱的宣稱

免疫、過敏、情緒、體重、皮膚這幾類訴求的共同問題是：試驗多為小樣本、終點多為自陳量表或血中指標、菌株之間無法互通，而且多數沒有經過獨立重複。 <a href="#ref-3">[3]</a> 這不等於全部無效，而是目前還無法指著貨架上某一罐說「這一罐對這件事有用」。「免疫力」這個詞本身的問題，見〈[關於免疫力，你需要知道的 5 件事](/articles/immune-regulation-5-things-to-know/)〉。

## 定殖：吃下去不代表住得下來

2018 年《Cell》的兩篇研究用內視鏡直接採黏膜樣本，做了大多數試驗不會做的事。

Zmora 等人發現，同一款 11 株益生菌配方在不同人身上的黏膜定殖情況差很多：有些人的腸道黏膜允許定殖，有些人則會把外來菌排掉，而這個差異可以用宿主本身的菌相與基因表現特徵預測。更關鍵的是，**糞便中的菌量無法反映黏膜的定殖狀況**，也就是說坊間的糞便檢測看不到這一層。 <a href="#ref-23">[23]</a>

Suez 等人在抗生素療程後的研究則測到一個反直覺的結果：相較於自然恢復，補充益生菌反而**延後**了原生菌相回到基線的時間，而自體糞菌移植讓恢復最快。 <a href="#ref-24">[24]</a>

這兩篇的樣本都很小（各數十人），使用的是單一配方，不能推論到所有產品與所有情境。但它們足以說明兩件事：益生菌的作用未必需要定殖（多數效果是過路時產生的），以及「吃益生菌重建腸道菌相」這個說法比實際情況簡化太多。停用後多數菌株會在數週內消失，這也是效果需要持續使用維持的原因。 <a href="#ref-3">[3]</a>

## 安全性：不是人人可吃

一般健康成人使用益生菌的安全紀錄良好，常見的是初期脹氣與排便習慣改變。需要單獨處理的是下面幾類。

### 免疫低下與重症

Yelin 等人 2019 年在《Nature Medicine》報告的資料是目前最硬的一份證據：加護病房中接受益生菌治療的病人，乳酸桿菌菌血症的風險明顯較高，而基因體定序顯示血液中分離出的菌與膠囊裡的菌屬於同一個克隆，也就是**直接從膠囊傳到血流**。 <a href="#ref-25">[25]</a>

接受化療、器官移植後、愛滋病晚期、中心靜脈導管留置、短腸症與腸道屏障受損者，都屬於使用活菌製劑前必須經醫師評估的族群。

### 早產兒

這是安全性議題中最沉重的一段。

2015 年的 MMWR 通報一名早產兒因使用受污染的膳食補充品而發生致命的腸胃道毛黴菌病。 <a href="#ref-26">[26]</a> 2023 年 9 月 29 日，美國 FDA 發出致醫療人員信函，說明一名出生體重低於 1,000 公克的早產兒在住院期間使用某款益生菌後發生 *Bifidobacterium longum* 敗血症並死亡，初步基因定序顯示血中菌與該產品所含菌一致；信中同時提醒早產兒使用益生菌有發生侵襲性、可能致命感染的風險。 <a href="#ref-30">[30]</a>

效果那一邊也不像想像中確定。PiPS 試驗收 1,315 名 23 至 30 週的極早產兒，*Bifidobacterium breve* BBG-001 對安慰劑，壞死性腸炎 9% 對 10%、敗血症 11% 對 12%、死亡 8% 對 9%，主要終點都沒有顯著差異。 <a href="#ref-27">[27]</a> 美國兒科醫學會 2021 年的臨床報告與 ESPGHAN 2020 年的立場文件都對這個議題有專章討論，結論是使用與否應在新生兒科醫療團隊的判斷下進行。 <a href="#ref-28">[28]</a><a href="#ref-29">[29]</a>

給家長的實務結論很直接：**早產兒與新生兒不應由家屬自行給予益生菌製劑。**

### 安全性通報本身有缺口

判讀「安全紀錄良好」這句話時，要知道它建立在什麼樣的資料上。Bafeta 等人 2018 年檢視 384 篇微生物相關介入的隨機試驗，**106 篇（28%）完全沒有報告任何傷害相關資料，375 篇（98%）沒有給出不良事件或嚴重不良事件的定義**。 <a href="#ref-31">[31]</a> Cohen 2018 年在《JAMA Internal Medicine》的評論用的標題是「益生菌安全性：沒有保證」。 <a href="#ref-32">[32]</a>

也就是說，現有文獻裡「沒有通報不良事件」有相當比例其實是「沒有去記錄不良事件」。這對健康成人影響不大，對前述高風險族群則意味著風險可能被低估。

## 台灣的法規：健康食品與一般食品的界線

台灣在這一題上有一個明確的制度可以當判準。

衛福部現行公告的健康食品保健功效項目共 13 項，其中包含**「胃腸功能改善」**（其餘為調節血脂、護肝、免疫調節、骨質保健、不易形成體脂肪、抗疲勞、輔助調整過敏體質、調節血糖、延緩衰老、牙齒保健、促進鐵吸收、輔助調節血壓）。 <a href="#ref-34">[34]</a> 益生菌產品最常申請的就是這一項。

食藥署在 115 年 1 月 20 日公告修正相關評估方法，名稱由「健康食品之胃腸功能改善評估方法」改為「健康食品之胃腸功能改善保健功效評估方法」，並給予在公告前已開始試驗者兩年的過渡期。 <a href="#ref-33">[33]</a> 這套評估方法列出的路徑包括促進消化吸收、改善腸內細菌菌相、幫助胃腸運動、胃黏膜保護、減少胃內幽門螺旋桿菌等方向。幽門螺旋桿菌的除菌與篩檢怎麼做，見〈[幽門螺旋桿菌與胃癌預防](/articles/h-pylori-stomach-cancer-prevention-guide/)〉。

三件事因此可以直接拿來判斷手上這一罐：

1. **有沒有小綠人許可證。** 有的話，核可的是哪一項功效、以哪一株菌與什麼劑量申請的，都可以在食藥署的健康食品查驗登記許可證資料查詢查到。 <a href="#ref-36">[36]</a>
2. **宣稱有沒有超出許可範圍。** 健康食品管理法第 14 條規定，健康食品的標示或廣告不得虛偽不實、誇張，宣稱的保健效能不得超過許可範圍，也不得涉及醫療效能。 <a href="#ref-35">[35]</a> 看到益生菌產品寫「改善過敏」「治療腸躁症」「提升免疫力對抗病毒」，那是法規層級的問題，不只是證據強度的問題。
3. **菌種本身可不可以用。** 可供食品使用的菌種與其使用限制，可以在食藥署的[食品原料整合查詢平臺](https://consumer.fda.gov.tw/Food/Material.aspx?nodeID=160)查現行版本。 <a href="#ref-37">[37]</a> 代購或境外購買的產品不受台灣規定拘束，菌種與標示都可能不同。

辨識誇大療效文案的通則，本站〈[保健食品詐欺防騙指南](/articles/supplement-fraud-exaggerated-claims-guide/)〉整理過。

## 買之前的檢查清單

把前面幾節壓縮成翻到背面就能跑一次的順序：

1. **看得到完整菌株編號嗎？** 屬、種、株三層都要。只有屬種的產品無法對照任何試驗。
2. **那一株對應的是哪一個適應症？** 預防抗生素腹瀉、預防困難梭狀桿菌、旅行者腹瀉，這三項有一致的證據；急性腸胃炎的最高品質證據是否定的。
3. **CFU 標的是效期末還是出廠？** 找「有效期限內」字樣。單位是 CFU 還是 AFU，兩者不能互比。
4. **劑量落在試驗區間嗎？** 抗生素腹瀉的次群組資料支持每日 50 億 CFU 以上；往上堆到千億沒有對應證據。
5. **有沒有第三方檢驗報告，批號對不對得上？** 實測研究中三分之一的產品在效期前就低於標示菌數。
6. **保存條件與你的生活對得上嗎？** 需冷藏的產品放在包包裡帶一整天，標示的保證就不成立。
7. **你屬於需要先問醫師的族群嗎？** 免疫低下、重症、中心靜脈導管、短腸症、早產兒與新生兒。

優格與膠囊在這幾項上的差別，本站〈[益生菌優格和膠囊差在哪](/articles/yogurt-vs-probiotic-capsules-comparison/)〉有逐項比較。

## 常見迷思

- **「菌數越多越好」**：劑量與效果的關係是菌株專一的。考科藍的次群組資料支持每日 50 億 CFU 以上，往上到千億沒有對應的劑量反應證據。 <a href="#ref-5">[5]</a>
- **「同一個菌種效果就一樣」**：ISAPP 共識明確指出效益不可外推到同菌種的其他菌株，228 篇試驗的系統性回顧也支持菌株專一性。 <a href="#ref-1">[1]</a><a href="#ref-4">[4]</a>
- **「標示寫幾億就一定有幾億」**：52 件產品的檢測中，17 件（33%）在效期前就低於標示菌數，只有 58% 的分類標示正確。 <a href="#ref-16">[16]</a>
- **「有包埋技術就比較有效」**：包埋的資料多為存活率與儲存穩定性，與臨床效果是兩件事；芽孢桿菌與布拉氏酵母菌本來就耐酸耐熱。 <a href="#ref-19">[19]</a>
- **「小孩拉肚子吃益生菌好得快」**：2018 年《NEJM》兩篇共 1,857 名兒童的試驗，兩種產品對急性腸胃炎都沒有優於安慰劑。 <a href="#ref-9">[9]</a><a href="#ref-10">[10]</a>
- **「吃益生菌可以重建腸道菌相」**：黏膜定殖因人而異且糞便驗不出來，抗生素後補充益生菌還可能延後原生菌相的恢復。 <a href="#ref-23">[23]</a><a href="#ref-24">[24]</a>
- **「天然的活菌對誰都安全」**：加護病房病人的乳酸桿菌菌血症有基因定序證實來自膠囊，FDA 在 2023 年因早產兒死亡發出警示。 <a href="#ref-25">[25]</a><a href="#ref-30">[30]</a>
- **「小綠人代表這罐能改善我的症狀」**：許可證核可的是特定功效項目與特定配方，宣稱不得超過許可範圍，也不得涉及醫療效能。 <a href="#ref-35">[35]</a><a href="#ref-36">[36]</a>

## 常見問題

### 標示只寫「rhamnosus 菌 100 億」，可以買嗎？

資訊不足以判斷。*rhamnosus* 是種名，臨床證據綁在株上，同一個種底下的不同株效果可能完全不同。 <a href="#ref-1">[1]</a> 沒有株編號的產品，你無法對照到任何一份試驗，也無法確認它用的劑量是否落在試驗區間。價格相近時，優先選標得出完整編號的。

### 2020 年改名之後，我怎麼知道新舊名字是同一支菌？

看株編號。Zheng 等人 2020 年的修訂只動屬名，株編號沒有變。 <a href="#ref-2">[2]</a> 所以 *Lactobacillus rhamnosus* GG 與 *Lacticaseibacillus rhamnosus* GG 是同一支菌，*Lactobacillus plantarum* 299v 與 *Lactiplantibacillus plantarum* 299v 也是。反過來說，只有屬種名而沒有編號的產品，在這次改名之後更難追溯。

### CFU 和 AFU 差在哪？可以直接比嗎？

不能。CFU 是平板培養長得出菌落的數量，AFU 是用螢光染色與流式細胞術計數的活細胞數。後者會納入「活著但暫時長不出菌落」的細胞，所以同一批原料用 AFU 計出的數字通常比 CFU 大。 <a href="#ref-18">[18]</a> 兩罐標示單位不同時，那個「比較多」有一部分來自量測方法。

### 吃抗生素的時候要間隔多久？

細菌型益生菌會被抗生素殺死，一般建議與抗生素間隔兩小時以上；布拉氏酵母菌屬於酵母，對抗細菌的抗生素不敏感，可以同時服用，但不能與抗黴菌藥物併用。預防抗生素相關腹瀉的證據以 *L. rhamnosus* GG 與布拉氏酵母菌最多。 <a href="#ref-7">[7]</a><a href="#ref-8">[8]</a> 詳細的時間安排見〈[吃抗生素可以吃益生菌嗎](/articles/probiotics-with-antibiotics-spacing/)〉。

### 益生菌需要冷藏嗎？

看菌種與配方。芽孢桿菌屬會形成孢子，常溫穩定；許多乳酸桿菌與比菲德氏菌製劑仍建議冷藏，包埋與凍乾技術可以改善常溫穩定性。 <a href="#ref-19">[19]</a> 判斷方式是看包裝標示的保存條件，並且照著做：需冷藏的產品在室溫下帶一整天，效期末的保證菌數就不再成立。

### 腸躁症可以靠益生菌處理嗎？

目前的臨床指引不建議。53 篇試驗、5,545 名患者的統合分析中，部分組合有可能的效益，但異質性太高而無法指出該用哪一支菌株 <a href="#ref-12">[12]</a>；美國胃腸病學會 2021 年的指引因此建議不要用益生菌治療腸躁症的整體症狀。 <a href="#ref-13">[13]</a> 有證據的做法是分階段的低 FODMAP 飲食與症狀導向的藥物，見〈[腸躁症完整指南](/articles/ibs-low-fodmap-guide/)〉。

### 免疫力不好的人可以吃嗎？

活菌製劑對免疫功能嚴重低下者有菌血症或真菌血症的風險，加護病房的研究以基因定序證實血中的菌來自膠囊。 <a href="#ref-25">[25]</a> 接受化療、器官移植後、愛滋病晚期、中心靜脈導管留置、短腸症與腸道屏障受損者，使用前必須經醫師評估。這類族群若要補充，後生元這種不含活菌的製劑在安全性上的疑慮較小，但臨床證據量也少很多。 <a href="#ref-22">[22]</a>

### 家裡有早產兒，醫院沒給我可以自己買嗎？

不要。美國 FDA 在 2023 年 9 月因一名早產兒使用益生菌後發生 *Bifidobacterium longum* 敗血症死亡而發出警示，並提醒早產兒使用益生菌有侵襲性、可能致命感染的風險。 <a href="#ref-30">[30]</a> 效果那一邊，收 1,315 名極早產兒的 PiPS 試驗在壞死性腸炎、敗血症與死亡率上都沒有測到顯著差異。 <a href="#ref-27">[27]</a> 要不要用、用哪一支、用多少，屬於新生兒科團隊的臨床決定。 <a href="#ref-28">[28]</a><a href="#ref-29">[29]</a>
