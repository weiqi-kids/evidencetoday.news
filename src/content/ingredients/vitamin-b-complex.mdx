## 30 秒認識

- 「B 群」是**八種化學結構與功能各異的水溶性維生素**的合稱，並非單一營養素：B1 硫胺、B2 核黃素、B3 菸鹼素、B5 泛酸、B6 吡哆醇、B7 生物素、B9 葉酸、B12 鈷胺素。 <a href="#ref-1">[1]</a>
- 它們的共同點是多半擔任**代謝反應的輔酶**，尤其在能量代謝路徑上。這是「B 群提神」說法的機制起點，但**輔酶充足時再補並不會加速反應**。
- 八種之中，**只有 B6、B3 與葉酸訂有上限攝取量**——B6 長期過量會造成周邊神經病變，B3 高劑量會潮紅與肝毒性。水溶性不等於無上限。 <a href="#ref-1">[1]</a>
- **B12 是唯一需要胃內因子才能吸收的維生素**，也是素食者、長期使用 PPI 或 metformin 者最需要留意的一項。
- **高劑量生物素（B7）會干擾多種免疫分析檢驗**，包括甲狀腺功能與心肌酵素，可能造成誤判，抽血前需告知。 <a href="#ref-2">[2]</a>

## 基本介紹

八種 B 群維生素被歸為一類，是歷史因素多於化學因素——它們最初被當成單一「維生素 B」，後來才逐一分離。實際上它們的結構、來源與缺乏症都不同。

理解這一點很重要，因為市場上的「B 群」產品把八種綁在一起販售，容易讓人以為它們必須一起補、或缺乏時會一起缺。實際情況是：**特定族群缺的往往是特定幾種**，例如素食者的 B12、酒精使用者的 B1、長期使用某些藥物者的 B6。

## 這是什麼？

| 維生素 | 別名 | 主要角色 |
|---|---|---|
| B1 | 硫胺 | 醣類代謝、神經傳導 |
| B2 | 核黃素 | FAD/FMN 輔酶、能量代謝 |
| B3 | 菸鹼素 | NAD/NADP 前驅物 |
| B5 | 泛酸 | 輔酶 A 組成 |
| B6 | 吡哆醇 | 胺基酸代謝、神經傳導物質合成 |
| B7 | 生物素 | 羧化酶輔酶、脂肪酸合成 |
| B9 | 葉酸 | 一碳單位轉移、DNA 合成 |
| B12 | 鈷胺素 | 甲基化反應、神經髓鞘維持 |

補充品的差異主要在**劑量倍數**（常見標示為每日建議量的數倍到數十倍）、**是否為活性形式**（如 P5P 之於 B6、甲鈷胺之於 B12），以及**是否為緩釋劑型**。

## 在身體裡做什麼？／主要作用機制

多數 B 群作為輔酶參與代謝：B1、B2、B3、B5 集中在把醣類與脂肪轉為 ATP 的路徑上；B6 主導胺基酸代謝與血清素、多巴胺、GABA 等神經傳導物質的合成；B9 與 B12 共同參與一碳單位代謝與 DNA 合成。 <a href="#ref-1">[1]</a>

這裡有個關鍵的判讀原則：**輔酶的作用是「使反應能夠發生」，不是「使反應加速」**。當體內輔酶已經充足，額外補充並不會讓能量代謝跑得更快。因此「吃 B 群變有精神」在缺乏者身上有生理基礎，在不缺的人身上則更可能來自其他因素（例如產品中的咖啡因、心理預期，或同時改善的作息）。

## 食物來源／常見來源

- **廣泛分布**：全穀、瘦肉、蛋、乳製品、豆類、深綠色蔬菜、堅果。
- **B12 例外**：**幾乎只存在於動物性食物**（肉、魚、蛋、奶）與強化食品。植物性食物基本不含可利用的 B12，這是純素飲食必須額外補充的原因。 <a href="#ref-1">[1]</a>
- **B1 與精製**：白米精製過程會去除大部分 B1，這是歷史上腳氣病與白米飲食關聯的由來。

B 群多半怕熱、溶於水，過度烹煮與大量水煮會流失。

## 建議攝取量／常見攝取建議／研究中常見使用方式

八種各有自己的建議攝取量，依年齡、性別與生理狀態不同。 <a href="#ref-4">[4]</a>

市售「高單位 B 群」常提供數倍至數十倍於建議量的劑量。對水溶性維生素而言，多餘部分多由尿液排出（B2 造成尿液呈亮黃色即為此），但**這不代表可以無限制**：

- **B6**：長期高劑量與**周邊感覺神經病變**相關，是三者中最需要警覺的一項。 <a href="#ref-1">[1]</a>
- **B3（菸鹼酸形式）**：高劑量造成皮膚潮紅、搔癢，更高劑量有肝毒性風險。
- **葉酸**：上限與掩蓋 B12 缺乏的診斷風險有關。

## 缺乏風險或攝取不足問題

各有典型缺乏症：B1 缺乏造成腳氣病與韋尼克氏腦病變；B2 造成口角炎、舌炎；B3 造成癩皮病；B6 造成皮膚炎、貧血、癲癇；B12 造成巨球性貧血與**不可逆的神經病變**；葉酸造成巨球性貧血與神經管缺陷風險。

實務上最需要留意的高風險族群：

- **純素與長期素食者**：B12。
- **慢性酒精使用者**：B1（韋尼克氏腦病變屬醫療急症）。
- **長期使用 metformin 者**：B12 吸收下降。
- **長期使用質子幫浦抑制劑（PPI）者**：胃酸不足影響 B12 從食物中釋出。
- **胃切除、萎縮性胃炎、惡性貧血**：內因子不足導致 B12 吸收障礙。
- **年長者**：胃酸分泌下降，食物來源 B12 的吸收效率降低。

## 補充品常見形式

- **綜合 B 群**：八種一起，劑量倍數差異大。
- **單方**：針對特定缺乏（如 B12 舌下錠、孕期葉酸）。
- **活性形式**：P5P、甲鈷胺、5-MTHF，訴求不需經體內轉換；對一般人是否有實質優勢，證據有限。
- **與能量飲料／提神產品併用**：這類產品常同時含咖啡因，「有感」可能來自咖啡因而非 B 群，選購時應看清完整成分。

## 安全性與注意事項

- **B6 上限**：長期超量與周邊神經病變相關，症狀為手腳麻木、感覺異常，停用後未必完全恢復。**高單位 B 群長期服用者應特別留意 B6 的每日總量**。 <a href="#ref-1">[1]</a>
- **B3 潮紅**：菸鹼酸形式常見，菸鹼醯胺形式較少；高劑量的肝毒性風險需醫師監測。
- **生物素干擾檢驗**：高劑量會干擾採用生物素-鏈黴親和素技術的免疫分析，使甲狀腺功能、心肌旋轉蛋白等數值失真。**抽血前應主動告知並依建議停用一段時間。** <a href="#ref-2">[2]</a>
- **葉酸與 B12**：單獨補充高劑量葉酸可能掩蓋 B12 缺乏，兩者宜一併評估。
- **藥物交互作用**：B6 高劑量可能降低 levodopa 效果；抗癲癇藥物與葉酸互相影響。

## 常見迷思

- **「B 群是提神用的，累了就吃」**：B 群作為輔酶讓能量代謝**能夠**進行，在已經充足的人身上補充並不會讓代謝更快。持續疲倦應先找原因（睡眠、貧血、甲狀腺、情緒），而非加碼補充。
- **「水溶性所以吃多少都安全」**：B6、B3 與葉酸都訂有上限，B6 的周邊神經病變是實際發生過的傷害。 <a href="#ref-1">[1]</a>
- **「B 群一定要八種一起補」**：八種的來源與缺乏風險族群不同，特定族群缺的往往是特定幾種，未必需要高單位綜合配方。
- **「素食只要吃夠深綠色蔬菜就不會缺 B 群」**：B12 幾乎只存在於動物性食物與強化食品，深綠色蔬菜補不到。 <a href="#ref-1">[1]</a>
