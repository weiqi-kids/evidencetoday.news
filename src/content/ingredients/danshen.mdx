## 30 秒認識

- 丹參是唇形科植物丹參的根與根莖。台灣健保資料中，丹參最常開給月經異常、一般症狀與心血管症狀，女性使用的勝算是男性的 1.75 倍 <a href="#ref-3">[3]</a>
- 和 warfarin 一起吃，可能讓 INR 大幅上升。已發表的個案中，有人每天喝丹參煎劑兩週後 INR 超過 8.4、出現血胸 <a href="#ref-4">[4]</a> <a href="#ref-10">[10]</a>
- Ge 等 2014 年的回顧把丹參與 warfarin 列為「高度可能」的交互作用，建議避免併用 <a href="#ref-9">[9]</a>
- 跟抗血小板藥的方向不一定一樣：Zhou 等 2018 年的健康受試者試驗中，丹參膠囊反而讓 clopidogrel 的血中濃度下降約一半 <a href="#ref-14">[14]</a>
- 在台灣，丹參的根、莖可以當食品原料，但不得單一原料使用；做為中藥材另有重金屬限量，鎘不得超過 0.3 ppm <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>

## 基本介紹

調經的中藥處方、更年期的調理方，丹參在台灣的中醫處方裡很常見 <a href="#ref-3">[3]</a>。對一般人來說它是常見藥材；對每天吃 warfarin 的人來說，它是一個會讓凝血數字失控的變數。

這一頁只回答一個問題：**正在吃抗凝血藥或抗血小板藥的人，遇到含丹參的處方、科學中藥或補品，可以一起吃嗎？** 當歸、人參、甘草這些其他補湯藥材各自跟西藥的關係，整理在〈[中藥補湯與西藥的交互作用](/articles/herbal-tonic-drug-interactions/)〉；長輩同時看中西醫、整體該怎麼管理用藥清單，見〈[長輩西藥中藥一起吃，哪些組合真的會出事](/articles/elderly-tcm-western-drug-combos-that-matter/)〉。

這一頁不評估丹參對心臟、中風或婦科問題的療效值不值得吃，也不提供用量建議。中藥處方由中醫師開立，抗凝血藥由西醫開立，本頁要做的是讓兩邊的醫師都知道對方開了什麼。

## 這是什麼？

丹參是唇形科鼠尾草屬植物丹參（*Salvia miltiorrhiza* Bge.）的乾燥根與根莖 <a href="#ref-4">[4]</a>，中醫用它來活血化瘀 <a href="#ref-9">[9]</a>。交互作用研究常提到的成分有兩類：脂溶性的丹參酮類（例如丹參酮 IIA），以及水溶性的丹參素 <a href="#ref-9">[9]</a> <a href="#ref-13">[13]</a>。

Chan 2001 年的回顧整理了丹參影響止血的幾條路：抑制血小板凝集、干擾外源性凝血路徑、類似抗凝血酶 III 的作用，以及促進纖維蛋白溶解 <a href="#ref-4">[4]</a>。這幾條加起來，解釋了為什麼中醫用它來「活血」，也解釋了為什麼它跟抗凝血藥放在一起會出問題。

在台灣，丹參主要以中藥的身分出現在中醫診所的科學中藥與中藥房的飲片裡；食品也可以把它當成原料之一，但規則不同，下一節說明。

## 在台灣怎麼管：中藥材、科學中藥與食品三條線

**同樣叫丹參，進了中醫診所是中藥，做成茶包是食品，兩邊的規矩不同。**

**食品這一側。** 2026 年 11 月 22 日下載食藥署食品原料整合查詢平臺的開放資料，丹參（*Salvia miltiorrhiza* Bge.）的根、莖列在「可供食品使用之原料」中的「草、木本植物類（2）可供直接食用」，備註是「不得單一原料使用」 <a href="#ref-1">[1]</a>。白話說，食品可以加丹參，但不能做成只有丹參一種原料的食品；單味丹參要走中藥的路。

**中藥材這一側。** 衛福部的「中藥材含重金屬限量基準」以砷 3.0 ppm、鉛 5.0 ppm、鎘 1.0 ppm、汞 0.2 ppm 為通則，丹參與甘草、白芍、赤芍、黃耆、紅耆被另外點名，鎘的限量收緊到 0.3 ppm <a href="#ref-2">[2]</a>。中藥材的清洗與重金屬問題，另見〈[中藥材、乾貨要先洗嗎](/articles/herbal-dried-goods-wash-first/)〉。

**健保處方。** Tseng 等 2021 年用健保研究資料庫 100 萬人的抽樣檔分析丹參處方，最常見的診斷群是月經異常與女性生殖道其他原因出血（9.48%），其次是一般症狀（9.46%）與心血管症狀（4.18%）；35 到 49 歲的使用者最多，佔 30.1%，最常一起出現在處方裡的是延胡索與加味逍遙散 <a href="#ref-3">[3]</a>。這個結果有一個實際意義：在台灣，拿到丹參處方的人多半是因為婦科或更年期問題去看中醫，而這群人裡也有因為心律不整、人工瓣膜、靜脈血栓在吃抗凝血藥的人。

## 丹參與 warfarin：個案、機轉與為什麼結果不一致

**早期發表的個案多來自香港，模式相似：原本穩定的 INR，在加了丹參之後幾天到兩週內衝高。**

1995 到 1998 年間陸續有幾份個案報告，其中 Yu 等與 Izzat 等的兩份都來自香港威爾斯親王醫院。Yu 等 1997 年報告一名風濕性心臟病患者，併用丹參後出現嚴重而危險的凝血異常 <a href="#ref-5">[5]</a>；Izzat 等 1998 年報告一名二尖瓣置換術後的病人，因丹參與 warfarin 的交互作用出現顯著抗凝過度，作者提醒吃 warfarin 的人不要吃這種藥材 <a href="#ref-6">[6]</a>；Tam 等 1995 年也有一份通訊報告 <a href="#ref-7">[7]</a>。

後來的回顧整理了個案細節。Chua 等 2015 年的整理中，一名 62 歲男性每天喝丹參煎劑，兩週後 INR 超過 8.4 並出現血胸，停用丹參、恢復原本的 warfarin 劑量後 INR 回到治療範圍 <a href="#ref-10">[10]</a>。Ge 等 2014 年的回顧另列了一名 66 歲男性，每天服用 warfarin 2 到 2.5 毫克將近一年，加用丹參 3 天後因出血住院，INR 從 2 升到 5.5 <a href="#ref-9">[9]</a>。

機轉有兩層。藥效學上，丹參本身抑制血小板、影響凝血，跟 warfarin 的抗凝作用疊加 <a href="#ref-4">[4]</a>。藥動學上，Chan 等 1995 年的大鼠實驗中，連續 3 天給予丹參萃取物，R 型與 S 型 warfarin 的血中濃度、曲線下面積與半衰期都上升，清除率下降，凝血酶原時間延長 <a href="#ref-8">[8]</a>。Chua 等也整理到，丹參酮 IIA 的衍生物在體外會把 warfarin 從白蛋白上置換下來，讓游離的 warfarin 變多 <a href="#ref-10">[10]</a>。

為什麼有些研究看不到交互作用？Lv 等 2019 年追蹤同時服用 warfarin 與複方丹參滴丸的冠心病合併心房顫動病人，多數人的 warfarin 劑量與 INR 沒有明顯改變，研究期間也沒有出血，只有 CYP4F2 特定基因型的人血中濃度有差異 <a href="#ref-12">[12]</a>。這說明交互作用的大小跟丹參的劑型、劑量、複方組成與個人體質都有關，煎煮的單味丹參與標準化的滴丸不能互相推論。Chua 等也指出，文獻中同時存在增強與拮抗兩種方向的報告 <a href="#ref-10">[10]</a>。

對吃 warfarin 的人來說，這種不確定性本身就是問題：你無法事先知道自己是哪一種反應。Chan 2001 年回顧的結論是兩者應避免併用 <a href="#ref-4">[4]</a>，Ge 等 2014 年把它評為「高度可能」的交互作用並建議不要併用 <a href="#ref-9">[9]</a>。

## 新型口服抗凝血藥呢？

**本頁沒有找到丹參與 dabigatran、rivaroxaban、apixaban、edoxaban 這類新型口服抗凝血藥的人體交互作用研究。**

沒有研究不等於沒有風險。丹參抑制血小板的藥效學作用，對任何抗凝血藥都會疊加；Qiu 等 2010 年的研究則顯示丹參可能誘導 CYP3A4 <a href="#ref-15">[15]</a>，而部分新型抗凝血藥的代謝會經過這個酵素。兩個方向可能相互抵消，也可能各自造成問題，目前的資料無法回答。實務上的處理跟 warfarin 一樣：讓開藥的醫師知道。

## 抗血小板藥、aspirin 與 digoxin 檢驗

**丹參跟抗血小板藥的研究很少，而且方向不一定是「加強」。**

Zhou 等 2018 年讓 20 名健康男性先單用 clopidogrel，再連續 7 天服用丹參膠囊後重測。併用後 clopidogrel 的清除率上升 96.5%，曲線下面積下降 50.3%，活性代謝物也下降 41.8%，抗血小板作用比單用時弱 <a href="#ref-14">[14]</a>。研究者推測丹參誘導了代謝酵素。對裝了冠狀動脈支架、靠 clopidogrel 預防血栓的人來說，藥效變弱同樣是風險。

aspirin 的方向則是加成。Zhang 等 2020 年的 14 人研究中，丹參葛根複方與 aspirin 併用後，aspirin 的暴露量中度上升，血栓素 B2 下降，研究者認為丹參素與 aspirin 在抑制環氧化酶上有協同作用 <a href="#ref-13">[13]</a>。

**digoxin 是另一種問題：檢驗數字被干擾。** Datta 與 Dasgupta 2002 年把丹參萃取物加進血清樣本，四種 digoxin 檢測方法中，螢光偏極化免疫分析法的數值受到干擾，另外三種沒有；不同品牌丹參的干擾程度差異很大，作者認為反映了產品品質控制不一 <a href="#ref-16">[16]</a>。吃 digoxin 又吃丹參的人，抽血時告訴醫療人員，數字跟症狀對不上時，醫院可以換檢測方法。

## 正在吃抗凝血藥，遇到丹參怎麼辦

**原則只有一條：不要自己加，也不要自己停，讓兩邊的醫師都知道。**

- 看中醫時，主動說出正在吃的抗凝血藥或抗血小板藥名稱，請中醫師評估處方裡要不要避開丹參
- 回西醫門診時，把中藥處方或藥袋帶去，包含科學中藥的品名
- 已經在吃含丹參的中藥、INR 一直很穩定，不要因為看到這一頁就自己停掉；停用同樣會讓 INR 變動，先問開 warfarin 的醫師要不要提早驗 INR
- 買養生茶包、藥膳包之前看成分表，含丹參的產品同樣告知醫師
- 出現牙齦出血不止、不明瘀青、黑便、血尿、流鼻血止不住，直接就醫並說明正在吃的中藥

冬令進補的整體注意事項，見〈[哪些人不適合冬令進補](/articles/who-should-avoid-winter-tonic/)〉；準備開刀的人，術前停用的安排見〈[開刀前要停哪些保健品](/articles/stop-supplements-before-surgery/)〉。

## 安全性與注意事項

**丹參的主要風險來自交互作用，單獨使用的安全性資料相對有限。**

Cochrane 回顧納入的 6 項中風試驗，只有 2 項報告了不良事件 <a href="#ref-17">[17]</a>，所以「丹參單獨吃安不安全」這一題，現有的高品質資料並不多。本頁能確定的是三件事：與 warfarin 併用有一致的出血警訊 <a href="#ref-4">[4]</a> <a href="#ref-9">[9]</a>；它會影響部分藥物的代謝 <a href="#ref-14">[14]</a> <a href="#ref-15">[15]</a>；不同產品的成分含量差異可能很大 <a href="#ref-16">[16]</a>。

懷孕、哺乳中的人，本頁沒有找到足以評估丹參安全性的人體研究，請由中醫師與產科醫師共同判斷，不要自行服用。

## 常見迷思

- **「丹參是天然藥材，跟西藥不會衝突」**：丹參與 warfarin 是中藥交互作用裡證據最一致的組合之一 <a href="#ref-9">[9]</a>
- **「丹參會活血，所以吃抗血小板藥的人效果會更好」**：Zhou 等 2018 年的健康受試者試驗中，丹參反而讓 clopidogrel 的濃度與作用下降 <a href="#ref-14">[14]</a>
- **「複方丹參滴丸的研究說沒影響，所以丹參都沒關係」**：那是特定產品、特定族群的結果，煎煮的丹參與其他製劑不能直接套用 <a href="#ref-12">[12]</a>
- **「茶包裡的丹參是食品，量很少不用講」**：食品可以用丹參但不得單一原料使用 <a href="#ref-1">[1]</a>，含量多少從標示上通常看不出來，吃抗凝血藥的人一樣要告知醫師
- **「丹參治中風有考科藍實證」**：Cochrane 回顧的結論是試驗品質全部偏差，無法得出可靠結論 <a href="#ref-17">[17]</a>

## 常見問題

### 我在吃 warfarin，中醫開的藥裡有丹參，可以吃嗎？

先不要自己決定。把這個處方帶給開 warfarin 的醫師看，也讓中醫師知道你在吃 warfarin。多份回顧建議避免兩者併用 <a href="#ref-4">[4]</a> <a href="#ref-9">[9]</a>，中醫師通常可以調整處方；如果評估後仍要使用，醫師可能會安排比較密集的 INR 檢查。

### 吃 warfarin 的人喝一次含丹參的補湯，會出事嗎？

本頁沒有找到「單次少量」的人體資料，無法給出安全劑量。已發表的個案多半是連續服用數天到兩週 <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>。已經喝了也不必恐慌，留意有沒有出血徵象，下次驗 INR 時告訴醫師。

### 我吃的是新型抗凝血藥，不是 warfarin，也要注意嗎？

要。目前沒有找到丹參與新型口服抗凝血藥的人體研究，但丹參抑制血小板的作用對任何抗凝血藥都可能疊加 <a href="#ref-4">[4]</a>。告訴開藥的醫師與中醫師，是最簡單也最有用的一步。

### 裝了心臟支架在吃 clopidogrel，可以吃丹參嗎？

這一題的資料很少。Zhou 等 2018 年 20 名健康男性的試驗中，丹參讓 clopidogrel 的濃度下降約一半、抗血小板作用變弱 <a href="#ref-14">[14]</a>。支架術後的抗血小板治療很重要，加用任何中藥前，先跟心臟科醫師討論。

### 開刀前要停丹參嗎？

要讓手術團隊知道。丹參有抑制血小板凝集的作用 <a href="#ref-4">[4]</a>，停用時間由醫師依手術種類決定。中醫師開的長期處方不要自己突然停，先問開藥的醫師。

### 食品裡可以加丹參嗎？

食品可以用丹參的根、莖當原料，但不得單一原料使用 <a href="#ref-1">[1]</a>。只有丹參一種原料的產品，就不是食品能賣的範圍。含丹參的複方食品合法，不代表適合每個人，吃抗凝血藥的人要先問醫師。
