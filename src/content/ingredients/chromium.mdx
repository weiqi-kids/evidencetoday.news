## 30 秒認識

- 鉻是必需微量礦物質，天然存在於全穀類、綠色蔬菜、堅果與肉類中。食品與補充劑用的是三價鉻（Cr3+），與工業廢料、皮革鞣製過程中的六價鉻（Cr6+）是完全不同的化學型態，六價鉻對人體有毒，三價鉻則是正常飲食的一部分，兩者不能混為一談。 <a href="#ref-7">[7]</a>
- 美國食品營養委員會（Food and Nutrition Board）只為鉻訂出「足夠攝取量」（AI），沒有訂出建議攝取量（RDA）：19–50歲男性每天35微克、女性25微克，51歲以上男性30微克、女性20微克，這反映科學界對人體確切需求量仍缺乏足夠精確的數據來訂出RDA。 <a href="#ref-6">[6]</a>
- Balk等人2007年發表於《Diabetes Care》的系統性回顧統合41篇隨機對照試驗，發現鉻補充劑能讓第二型糖尿病患者的糖化血色素平均下降0.6個百分點、空腹血糖下降1.0 mmol/L；但這批正面結果有相當比例來自中國進行的試驗，作者也提醒若受試者基礎鉻營養狀況原本偏低，補充後的反應可能被放大。 <a href="#ref-1">[1]</a>
- 吡啶甲酸鉻（chromium picolinate）是被研究最多的補充劑型。歐洲食品安全局（EFSA）2010年的意見書把每日鉻總攝取上限訂在250微克，同時指出這個型態在體外高濃度下可能造成DNA損傷，但體內研究證據並不一致。 <a href="#ref-5">[5]</a>
- 明確可歸因於鉻缺乏的病例，幾乎只出現在配方中未添加鉻的長期全靜脈營養（TPN）患者身上；在一般能正常進食的人口中，鉻缺乏並不是常被檢出的問題。 <a href="#ref-11">[11]</a>

## 基本介紹

鉻在1959年由Schwarz與Mertz的動物實驗中首次被指出與葡萄糖耐受度有關，當時他們把這個尚未確認結構的活性因子稱為「葡萄糖耐受因子」（glucose tolerance factor, GTF），後續數十年間，這個因子始終沒有被純化出單一、明確的化學結構，「GTF」一詞也因此逐漸被視為歷史名詞而非確立的化合物。 <a href="#ref-6">[6]</a> 鉻是人體需要量極微的元素，每天飲食吸收進體內的比例通常低於2%，多數攝取的鉻會直接隨糞便排出，這也是它與鈣、鐵等其他礦物質相比研究進度明顯落後的原因之一——需要量太小，血液或尿液中的濃度變化很難精確測量，也難以建立一致的營養狀態指標。 <a href="#ref-7">[7]</a> 近年也有學者對鉻是否真的符合「必需營養素」的嚴格定義提出質疑，理由是除了少數TPN病例外，一般人群中始終沒有找到可重複驗證的缺乏症生化指標。 <a href="#ref-6">[6]</a>

## 這是什麼？

自然界中的鉻主要以兩種氧化態存在：三價鉻（Cr3+）與六價鉻（Cr6+）。三價鉻是食品、補充劑與人體代謝中作用的型態，性質相對穩定；六價鉻則主要來自不鏽鋼焊接、皮革鞣製、電鍍等工業製程，具有明確的致癌性與毒性，兩者的健康意義完全相反，不應該因為名字裡都有「鉻」字就混淆。 <a href="#ref-7">[7]</a> 市售鉻補充劑幾乎都以三價鉻為原料，常見型態包括吡啶甲酸鉻、菸酸鉻（chromium nicotinate）、氯化鉻（chromium chloride）與鉻酵母（chromium-enriched yeast），彼此在吸收率與研究證據量上有明顯差異，後面「補充品常見形式」段落會逐一說明。 <a href="#ref-5">[5]</a>

## 在身體裡做什麼？／主要作用機制

三價鉻被認為透過一種稱為低分子量鉻結合物質（low-molecular-weight chromium-binding substance, LMWCr，也稱chromodulin）的胜肽發揮作用。當血中胰島素濃度上升時，鉻會從血液移入胰島素敏感細胞內，與LMWCr結合形成holoLMWCr，後者接著與胰島素受體結合，增強受體上酪胺酸激酶（tyrosine kinase）的活性，放大胰島素訊息傳遞的效果。 <a href="#ref-6">[6]</a> 這個機制的推論主要建立在動物實驗與細胞實驗，人體內鉻濃度、LMWCr活性與胰島素敏感度三者之間的定量關係，目前仍缺乏可在活體直接測量、並跨研究一致重現的方法，這也是鉻的作用機制常被寫成「被認為」而非「已確認」的原因。 <a href="#ref-6">[6]</a>

## 食物來源／常見來源

鉻廣泛但微量地存在於多種食物中，沒有單一「超級食物」能大幅超越其他來源。全穀類製品、花椰菜、四季豆、馬鈴薯泥、葡萄汁與柳橙汁、牛肉、火雞胸肉與蛋黃都含有可測得的鉻，其中花椰菜的鉻含量在常見蔬菜中相對突出。 <a href="#ref-7">[7]</a> 精製與加工程度較高的食品（如白麵粉、精製糖）在製程中會流失部分鉻，這也是部分研究者主張「現代飲食鉻攝取量可能低於過去」的論點來源之一，但這個論點目前仍以間接推論為主，沒有大型族群層級的長期追蹤資料直接證實現代人普遍鉻攝取不足。 <a href="#ref-6">[6]</a> 由於單一食物的鉻含量偏低，且容易受到土壤、加工與烹調用具（部分不鏽鋼鍋具在酸性條件下會釋出微量鉻）等因素影響，食品鉻含量資料庫的數字本身就存在較大變異，這是解讀「每份食物含多少鉻」時要留意的限制。 <a href="#ref-7">[7]</a>

## 建議攝取量／常見攝取建議／研究中常見使用方式

美國食品營養委員會於2001年訂出的鉻足夠攝取量，19–50歲男性為每天35微克、女性25微克，51歲以上因基礎代謝與活動量下降而略微調降，男性30微克、女性20微克。 <a href="#ref-6">[6]</a> 這個數字是以健康人群觀察到的一般飲食攝取量為基礎推估，而非依照明確的缺乏症門檻計算，所以只稱為「足夠攝取量」而非「建議攝取量」。台灣衛生福利部國民健康署現行公告的「國人膳食營養素參考攝取量」第八版章節表，並未單獨列出鉻的足夠攝取量或上限攝取量數字，國內若需要參考基準，多直接引用美國或歐盟的資料。 <a href="#ref-6">[6]</a>

臨床研究中使用的鉻劑量，與前述的一般飲食足夠攝取量落差相當大。Balk等人統合的41篇試驗中，介入劑量從每天50微克到1000微克不等，介入期間4到25週，其中介入期在12週以上的試驗，對血糖指標的改善幅度通常較明顯。 <a href="#ref-1">[1]</a> 這代表研究中測試的「治療性劑量」與日常飲食可攝取到的「營養性劑量」是兩個不同量級的概念，不宜把研究中使用的高劑量直接當成日常保健的參考值。

## 缺乏風險或攝取不足問題

鉻缺乏在有正常進食能力的一般人口中極為少見，目前文獻中被廣泛引用、症狀描述最完整的案例，是1977年Jeejeebhoy等人報告的一名長期接受全靜脈營養、配方中未添加鉻的病患：在營養治療進行三年半後出現無法解釋的體重下降、周邊神經病變與葡萄糖耐受不良，靜脈注射葡萄糖耐受測試的下降速率明顯偏低，且胰島素濃度正常，補充鉻之後上述異常在數週內逆轉。 <a href="#ref-11">[11]</a> 這個案例常被視為鉻具有生理必要性的關鍵證據，但也正因為類似案例數量稀少，且幾乎全部發生在長期TPN、完全依賴靜脈營養的特殊族群，才讓部分學者對「鉻在一般飲食族群中是否真的存在具臨床意義的缺乏狀態」持保留態度。 <a href="#ref-6">[6]</a> 現行TPN配方多已依循相關準則常規添加微量鉻，也讓這類經典案例在臨床上已相對少見。對於一般能正常飲食的成人，除非有嚴重腸道吸收不良、長期完全依賴靜脈營養等特殊狀況，否則透過均衡飲食通常足以涵蓋身體需要的微量鉻，不需要另外以補充劑刻意「補足」。

## 補充品常見形式

市售鉻補充劑常見型態包括：

- **吡啶甲酸鉻（chromium picolinate）**：鉻與兩分子吡啶甲酸結合而成，是目前被研究最多、市面上最常見的型態，多數統合分析引用的臨床試驗也以這個型態為主，優勢是廠商宣稱吸收率較高，但也是安全性爭議（genotoxicity、罕見腎損傷案例）集中討論的型態。 <a href="#ref-5">[5]</a>
- **菸酸鉻（chromium nicotinate）**：鉻與菸鹼酸結合，部分動物實驗顯示吸收率不亞於吡啶甲酸鉻，但人體臨床試驗數量遠少於吡啶甲酸鉻，實證基礎相對薄弱。
- **氯化鉻（chromium chloride）**：無機鹽類型態，成本最低，但腸道吸收率是幾種常見劑型中最低的，多用於較早期的臨床試驗，是後續劑型比較研究常拿來當作「吸收率基準」的對照組。
- **鉻酵母（chromium-enriched yeast）**：讓酵母在培養過程中富集鉻，鉻與酵母中的胺基酸、胜肽形成天然複合物，廠商常以「天然來源」作為行銷訴求，但這不等於它已被證實比吡啶甲酸鉻更安全或更有效，目前直接比較不同劑型療效與安全性的頭對頭試驗數量仍然有限。

挑選劑型時，吸收率數據與人體臨床試驗證據量的多寡，會比「天然來源或合成製造」這種行銷分類，提供更具體可查核的判斷依據。

## 安全性與注意事項

Suksomboon等人2014年的統合分析在納入試驗中比較鉻補充劑組與安慰劑組的不良反應通報率，兩組沒有具統計意義的差異，這批試驗的介入劑量多落在每天200至1000微克這個臨床常用範圍內。 <a href="#ref-2">[2]</a> 不過，這不代表沒有攝取上限的考量。EFSA的2010年意見書以世界衛生組織訂出的參考基準為依據，建議來自補充劑與強化食品的鉻總攝取量不應超過每天250微克；意見書同時檢視了吡啶甲酸鉻的基因毒性資料，指出在體外高濃度環境下，這個劑型有造成DNA損傷的證據，但長期動物致癌性試驗中觀察到的病變沒有明確的劑量相關性，雄性大鼠出現等量的致癌活性證據，雌性大鼠與小鼠則沒有觀察到，EFSA據此判斷現有證據不足以支持下修更嚴格的上限。 <a href="#ref-5">[5]</a>

極端過量攝取的案例則提供了另一種警訊。Cerulli等人1998年報告一名33歲女性，為了減重連續4到5個月每天服用1200至2400微克吡啶甲酸鉻（約為足夠攝取量的35到70倍），出現體重減輕、貧血、血小板低下、溶血、肝功能異常（轉胺酶為正常值的15到20倍）與急性腎衰竭（血肌酸酐5.3 mg/dL），住院接受血液透析與支持性治療後，肝功能約一週內恢復，腎功能於發病後第12天開始回升，一年後各項數值恢復正常。 <a href="#ref-8">[8]</a> Wasser等人1997年也報告過一名因長期服用市售吡啶甲酸鉻而出現慢性腎衰竭的病例。 <a href="#ref-9">[9]</a> 這兩起案例的共同點是攝取劑量遠高於臨床試驗常用範圍，不能直接類比一般建議劑量下的風險，但足以說明「非處方保健品」不等於「無上限安全」，長期自行大幅超量服用仍有明確的器官損傷風險。

其他需要留意的情況：鉻主要經腎臟排出，腎功能不全者可能較難清除體內鉻，NIH膳食補充品辦公室建議這類族群使用前先與醫療團隊討論是否需要調整劑量或避免使用。 <a href="#ref-7">[7]</a> 鉻可能與甲狀腺素藥物（levothyroxine）產生交互作用：一篇小型研究讓7名健康受試者同時服用高劑量甲狀腺素與吡啶甲酸鉻，發現血中甲狀腺素濃度下降約17%，推測機轉與鉻在腸道中與甲狀腺素形成不易溶解的複合物、影響吸收有關，建議兩者服用時間至少間隔數小時。 <a href="#ref-7">[7]</a> 服用胰島素或磺醯脲類（sulfonylurea）等降血糖藥物者，理論上有鉻與藥物加成造成血糖過低的風險，若要同時使用，建議與醫師討論並加強血糖監測，而不是自行調整藥物劑量。 <a href="#ref-7">[7]</a>

## 常見迷思

- **「鉻補充劑可以取代糖尿病藥物」**：Balk等人統合的41篇試驗顯示，鉻補充劑對糖化血色素與空腹血糖有統計上顯著但幅度有限的改善（HbA1c平均下降0.6個百分點），對血脂沒有明顯效果，這樣的幅度遠不足以作為藥物治療的替代方案，糖尿病用藥調整仍須由醫師依整體病情決定。 <a href="#ref-1">[1]</a>
- **「吃鉻就能明顯瘦身」**：Onakpoya等人的統合分析顯示吡啶甲酸鉻使體重平均只多減少0.5公斤，對BMI與腰臀比沒有影響；更早一篇統合分析的體重效果，在排除單一大型試驗後就不再具有統計意義，兩篇結論都指向效果幅度小且不夠穩固。 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a>
- **「天然來源的鉻酵母一定比合成的吡啶甲酸鉻安全」**：目前沒有充分的頭對頭人體試驗直接比較兩者的安全性差異，「天然」與「合成」的行銷分類，不等於已被證實的安全性等級落差。
- **「六價鉻有毒，所以所有含鉻的東西都要避免」**：食品與補充劑中使用的三價鉻與工業六價鉻是不同的化學型態，三價鉻是正常飲食的一部分，健康疑慮主要集中在補充劑的過量使用，而不是食物中天然存在的微量三價鉻。 <a href="#ref-7">[7]</a>
- **「劑量吃得越高，血糖控制效果越好」**：Balk等人的分析指出，介入期間長短（12週以上）比單次劑量高低更能預測血糖改善幅度，且EFSA已針對過量攝取設下每天250微克的參考上限，自行拉高劑量並非有效或安全的做法。 <a href="#ref-1">[1]</a> <a href="#ref-5">[5]</a>

## 常見問題

### 健康檢查發現血糖偏高，可以先吃鉻補充劑代替就醫嗎？

不建議把鉻補充劑當成就醫前的替代方案。空腹血糖或糖化血色素偏高，需要先由醫師確認是屬於糖尿病前期還是已達糖尿病診斷標準，兩者的追蹤頻率與處置方式不同；鉻補充劑在臨床試驗中對血糖指標的改善幅度有限，且多數研究對象是已確診的第二型糖尿病患者，尚未確立在糖尿病前期族群中的效果與長期安全性。發現血糖數值異常，建議先與醫師討論後續檢查與追蹤計畫。 <a href="#ref-1">[1]</a>

### 一般飲食均衡的人，需要額外補充鉻嗎？

多數能正常進食、飲食型態多元的成人，不需要特別額外補充。鉻缺乏在有正常進食能力的人口中相當罕見，目前有明確病例紀錄的族群集中在長期完全依賴靜脈營養、配方中未添加鉻的患者。 <a href="#ref-11">[11]</a> 若飲食長期高度精緻化、蔬菜穀類攝取量極低，或有特殊代謝疾病，可以與醫師或營養師討論是否需要調整飲食組成，而不是直接以補充劑取代飲食評估。

### 吡啶甲酸鉻的DNA損傷疑慮，代表一般劑量使用也不安全嗎？

不完全等同。EFSA的意見書指出，DNA損傷的證據來自體外實驗在「高濃度」條件下觀察到的結果，動物體內的長期致癌性研究並未呈現一致的劑量相關性；EFSA最終仍以每天250微克作為建議上限，而不是全面禁止使用。 <a href="#ref-5">[5]</a> 這代表在建議劑量範圍內使用，與體外高濃度實驗條件下觀察到的訊號，兩者的風險意義並不相同，但也說明長期自行大幅超量服用（如前述案例報告中每天超過1000微克）確實有實際發生過的器官損傷紀錄。 <a href="#ref-8">[8]</a>

### 正在服用甲狀腺素藥物，還可以吃鉻補充劑嗎？

可以，但建議與服藥時間錯開。已有小型研究觀察到吡啶甲酸鉻與高劑量甲狀腺素同時服用時，血中甲狀腺素濃度下降約17%，機轉與腸道內形成不易吸收的複合物有關。 <a href="#ref-7">[7]</a> 若正在服用甲狀腺素藥物又想使用鉻補充劑，建議兩者間隔至少數小時服用，並與開立甲狀腺素藥物的醫師討論，必要時可透過定期甲狀腺功能檢查確認劑量是否需要調整。
