## 30 秒認識

- 酸棗仁的人體試驗不多，品質最好的是 4 篇安慰劑對照試驗，合併 406 人，短期主觀睡眠品質有改善，停用幾週後效果就看不到了 <a href="#ref-5">[5]</a>
- 最接近睡眠軟糖配方的一篇試驗，把酸棗屬成分和乳蛋白水解物、啤酒花、鎂、維生素 B6 做成複方，吃 2 週後跟安慰劑沒有差別 <a href="#ref-8">[8]</a>
- 台灣食藥署平臺把酸棗仁種子列為可直接食用的食品原料，但備註不得單一原料使用 <a href="#ref-1">[1]</a>；中醫藥司 115 年 4 月的草案把它列進第二類，每人每日 1.5 公克，並要求標示孕婦慎用、避免開車或操作機械 <a href="#ref-3">[3]</a>
- 正在吃安眠藥或抗憂鬱藥的人，問題在嗜睡疊加與可能的交互作用，先問開藥的醫師或藥師 <a href="#ref-12">[12]</a>

## 基本介紹

韓國藥妝店的睡眠軟糖翻到背面，成分表常寫著「산조인」，那就是酸棗仁。泰國的助眠軟糖、台灣電商的「晚安」系列飲品也常放它，通常排在 GABA、南非醉茄或乳蛋白水解物後面當配角。

這一頁只處理酸棗仁本身。軟糖能不能帶回台灣、韓國怎麼認定睡眠機能原料，在〈[韓國睡眠軟糖可以帶回台灣嗎](/articles/korea-sleep-gummies-bring-back-taiwan/)〉；泰國軟糖的成分濃度與實際劑量，在〈[泰國睡眠軟糖到底有沒有用](/articles/thailand-sleep-gummies-does-it-work/)〉；褪黑激素、鎂、GABA 這些成分該怎麼挑，要先從自己為什麼睡不好開始，見〈[睡眠補充品這麼多種，你有沒有想過自己睡不好的原因是什麼](/articles/sleep-supplements-find-root-cause/)〉。

## 這是什麼？

酸棗仁是鼠李科酸棗（*Ziziphus jujuba* Mill. var. *spinosa*，也寫作 *Z. spinosa* Hu）乾燥成熟的種子 <a href="#ref-1">[1]</a> <a href="#ref-3">[3]</a>。酸棗是紅棗的近親，果肉薄而酸，中藥用的是果核裡扁圓、紅褐色的種仁。

同一個屬裡還有兩樣東西容易混在一起。紅棗（大棗）是果實，食藥署平臺列為可直接食用，沒有任何備註；台灣市場上的青棗（印度棗，*Z. mauritiana*）果實也可以吃，但它的葉子列在未確認安全性、不得作為食品原料的清單裡 <a href="#ref-1">[1]</a>。產品寫「棗」或「jujube」時，先分清楚是果實還是種子。

He 等 2020 年的整理指出，酸棗仁已鑑定出超過 150 種化合物，包括皂苷類（酸棗仁皂苷）、黃酮類（斯皮諾素等）、生物鹼、脂肪酸與多醣 <a href="#ref-11">[11]</a>。萃取物與純化成分在實驗中有鎮靜與助眠作用，這部分大多是動物與細胞研究，用來解釋「為什麼有人覺得有效」，不能當成吃軟糖會有效的證據。

## 人體證據做到哪裡

**酸棗仁是中藥助眠研究中最常被用到的單味藥，但能回答「吃了會不會睡得比較好」的高品質試驗只有少數幾篇。**

Yeung 等 2012 年回顧中藥治療失眠的 217 篇隨機試驗，酸棗仁是最常用的單味藥；但 217 篇裡只有 8 篇方法學評分達到 3 分以上，其中 7 篇至少一個面向有高偏誤風險，作者的結論是現有證據不足以支持中藥治療失眠的效果 <a href="#ref-10">[10]</a>。

十年後的資料多了一些，結論仍然保守：

| 研究 | 對象與做法 | 結果 | 限制 |
|---|---|---|---|
| Yang 等 2023 統合分析 <a href="#ref-5">[5]</a> | 9 篇英文發表的隨機試驗、905 人，以酸棗仁為主要成分的單方或複方 | 對安慰劑：短期主觀睡眠品質改善（標準化平均差 -0.58）；對安眠藥或認知行為治療：4 週時效果相近 | 安慰劑組合併的異質性 80%；兩篇共 256 人的試驗停用後 3 到 8 週已無差別 |
| Liu 等 2022 統合分析 <a href="#ref-9">[9]</a> | 12 篇試驗、1,311 名慢性失眠者，酸棗仁湯單用或合併西藥 | 臨床有效率較高、復發率較低 | 收入中文資料庫試驗，作者自承品質參差 |
| Chan 等 2015，台灣 <a href="#ref-7">[7]</a> | 90 名接受美沙冬治療、有睡眠困擾的病人，酸棗仁湯或安慰劑 4 週 | 睡眠品質量表與睡眠效率改善較多 | 特定族群；酸棗仁湯是五味藥的複方 |
| Shergis 等 2021，澳洲 <a href="#ref-6">[6]</a> | 12 名失眠者交叉試驗，每天 2 公克酸棗仁顆粒 4 週 | 睡眠品質量表改善（p = 0.046），其他結果無差異 | 可行性試驗，人數太少 |
| Scholey 等 2017，澳洲 <a href="#ref-8">[8]</a> | 171 名輕度失眠成人，含酸棗屬的五成分複方 2 週 | 與安慰劑沒有差別，兩組都改善 | 安慰劑反應大、療程短 |

這張表要看兩件事。

第一，**有效的訊號多半來自複方與藥用劑量。** 酸棗仁湯由酸棗仁、茯苓、川芎、知母、甘草五味藥組成 <a href="#ref-12">[12]</a>，Chan 2015 與 Liu 2022 測的都是這個方劑，效果無法單獨算在酸棗仁頭上。單味酸棗仁只有 Shergis 那 12 個人。

第二，**最像市售軟糖的那篇是陰性結果。** Scholey 2017 的配方把乳蛋白水解物、酸棗屬、啤酒花、鎂、維生素 B6 放在一起，結構跟韓國軟糖很像，2 週後跟安慰劑沒有差別 <a href="#ref-8">[8]</a>。作者提到安慰劑組也進步很多，療程短可能掩蓋了效果，這是公平的保留；但就現有資料，說不出「吃含酸棗仁的軟糖會睡得比較好」。

Yang 2023 的作者把酸棗仁定位成「短期改善睡眠品質的選項之一」，前提是失眠認知行為治療拿不到、或安眠藥不耐受的情況 <a href="#ref-5">[5]</a>。這個定位跟台灣的實際處境一致：長期失眠的第一線治療是認知行為治療，做法整理在〈[失眠的認知行為治療（CBT-I）完整指南](/articles/insomnia-cbti-guide/)〉。

## 台灣怎麼管：食品、中藥材、方劑

**酸棗仁在台灣同時是食品原料和中藥材，兩套規定各管一段，草案生效後會再多一層限量。**

**食品原料：能放，不能單獨賣。** 2026 年 11 月 21 日下載食藥署食品原料整合查詢平臺開放資料比對，酸棗仁的種子列在「草、木本植物類（2）可供直接食用」，備註一句：不得單一原料使用 <a href="#ref-1">[1]</a>。依這個備註，酸棗仁可以跟其他原料一起做成食品，只含酸棗仁一種原料的產品就不符合使用條件。這也解釋了為什麼市面上看到的都是複方軟糖、複方茶包。

**中藥材：舊清單沒有，新草案列入第二類。** 中醫藥司 107 年 2 月生效的「可同時提供食品使用之中藥材」37 項清單沒有酸棗仁 <a href="#ref-4">[4]</a>。115 年 4 月 13 日預告的認定基準草案，把酸棗仁列在第二類「食用時須注意安全性者」第 46 項，部位是乾燥成熟種子，備註兩點：外包裝須標示「孕婦慎用，另應避免從事開車或操作機械等需要警覺性的工作」，每人日食用限量 1.5 公克 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>。

草案還有幾條規則會影響含酸棗仁的產品 <a href="#ref-3">[3]</a>：

- 第二類中藥材占產品總量一半以上，或任一品項換算每日食用量超過附表的限量，以藥品管理
- 糖果、餅乾、蜜漬品、果凍、烘焙食品、甜味料或調味醬，以及滷包、燉包、茶包型態，列在「不以藥品管理」的例外
- 中藥材本身的批發零售，除附表備註寫明可依食品安全衛生管理法辦理的品項外，要符合藥事法，酸棗仁的備註沒有這一句

第二點跟睡眠軟糖直接相關。依草案文字，糖果與果凍型態屬於例外，軟糖是否全數比照、外包裝警語怎麼搭配，要看正式公告與主管機關的解釋。截至 2026 年 11 月 21 日，中醫藥司網頁上仍是預告草案 <a href="#ref-2">[2]</a>。

**方劑：酸棗仁湯是藥。** 中醫師開的酸棗仁湯是五味藥的方劑 <a href="#ref-12">[12]</a>，Chan 等 2015 年的論文形容它是治療失眠最常開的中藥處方之一 <a href="#ref-7">[7]</a>。其中川芎在同一份草案也是第二類，要求標示孕婦慎用，限量 1.5 公克 <a href="#ref-3">[3]</a>；甘草的血壓與血鉀問題見〈[甘草](/ingredients/licorice/)〉。

## 安全性與注意事項

**一般人短期吃到軟糖裡的量，目前沒有明確的毒性訊號；要注意的是嗜睡疊加、孕期與抗憂鬱藥。**

Yang 2023 的統合分析中，酸棗仁沒有增加嚴重不良反應，回報的多是輕微反應，例如睡眠中斷、頭暈、口乾、臉部皮疹、尿急、腸胃不適、疲倦與出汗；兩篇試驗沒有看到腎臟或肝臟毒性 <a href="#ref-5">[5]</a>。MSKCC 對酸棗仁湯的整理另列便祕、腹瀉與倦怠，並寫明沒有已知的禁忌症 <a href="#ref-12">[12]</a>。這些資料都來自幾週的試驗，長期每天吃的安全性沒有人系統性研究過。

**跟藥一起吃。** MSKCC 指出酸棗仁湯因為有鎮靜作用，可能與 SRI 類、MAOI 類藥物交互作用，也可能加重某些處方藥的嗜睡作用 <a href="#ref-12">[12]</a>。在台灣，常見的情境是已經在吃 zolpidem 或苯二氮平類安眠藥，覺得「藥效不夠」又自己加一顆軟糖；或正在吃抗憂鬱藥，看到朋友推薦的韓國軟糖。這兩種情況都先問開藥的醫師或藥師，藥要不要調整也由他們判斷。

**誰要特別留意：**

- **孕婦**：中醫藥司草案要求含酸棗仁的食品標示孕婦慎用 <a href="#ref-3">[3]</a>，孕期的人體資料很少
- **隔天要開車或操作機械的人**：草案的警語寫明避免從事需要警覺性的工作 <a href="#ref-3">[3]</a>
- **正在吃安眠藥、抗焦慮藥或抗憂鬱藥的人**：嗜睡疊加與可能的交互作用 <a href="#ref-12">[12]</a>
- **長期失眠的人**：停用後效果就看不到 <a href="#ref-5">[5]</a>，三個月以上的失眠需要找出原因

**藥材本身的品質。** 自己到中藥行買酸棗仁回家煮的人，種子類藥材要留意的是黃麴毒素與保存條件，台灣中藥材的污染物限量、抽驗結果與清洗做法整理在〈[中藥材、乾貨要先洗過再用嗎](/articles/herbal-dried-goods-wash-first/)〉。

## 常見迷思

- **「酸棗仁是天然的安眠藥」**：四篇安慰劑對照試驗合併後只有短期的主觀改善，停用後 3 到 8 週效果消失 <a href="#ref-5">[5]</a>；Yeung 2012 回顧兩百多篇中藥失眠試驗，結論是證據不足 <a href="#ref-10">[10]</a>
- **「軟糖裡有酸棗仁，所以有效」**：最接近軟糖配方的複方試驗，2 週後與安慰劑沒有差別 <a href="#ref-8">[8]</a>；軟糖通常也不標示酸棗仁的含量
- **「中醫開酸棗仁湯，所以單吃酸棗仁也一樣」**：酸棗仁湯是五味藥的方劑 <a href="#ref-12">[12]</a>，台灣的試驗測的是整個方劑 <a href="#ref-7">[7]</a>
- **「天然的東西不會跟藥衝突」**：MSKCC 列出酸棗仁湯與抗憂鬱藥的可能交互作用 <a href="#ref-12">[12]</a>，草案也要求標示避免開車 <a href="#ref-3">[3]</a>
- **「紅棗跟酸棗仁一樣助眠」**：紅棗是果實，酸棗仁是另一個變種的種子，兩者在平臺上的分類不同 <a href="#ref-1">[1]</a>，紅棗沒有助眠的人體試驗

## 常見問題

### 吃安眠藥的人，可以再加含酸棗仁的軟糖嗎？

不建議自己加。MSKCC 提醒酸棗仁湯可能加重某些處方藥的嗜睡作用 <a href="#ref-12">[12]</a>，中醫藥司草案也要求含酸棗仁的食品標示避免開車與操作機械 <a href="#ref-3">[3]</a>。安眠藥吃了還是睡不好，表示需要回診重新評估，加產品之前先跟開藥的醫師或藥師確認。

### 睡眠軟糖裡的酸棗仁，量夠嗎？

多數軟糖不標示酸棗仁的毫克數，所以無從判斷。可以拿來對照的數字有兩個：澳洲單味試驗用的是每天 2 公克顆粒 <a href="#ref-6">[6]</a>，中醫藥司草案對食品訂的上限是每天 1.5 公克 <a href="#ref-3">[3]</a>。顆粒與種子原料怎麼換算，論文摘要沒有交代。

### 懷孕時睡不好，可以喝酸棗仁茶嗎？

先問產科醫師。中醫藥司草案要求含酸棗仁的食品外包裝標示孕婦慎用 <a href="#ref-3">[3]</a>，孕期的人體安全資料很少。酸棗仁湯裡的川芎同樣被草案列為孕婦慎用。

### 市面上的酸棗仁膠囊、酸棗仁粉算什麼？

看成分表與字號。食藥署平臺規定酸棗仁不得單一原料使用 <a href="#ref-1">[1]</a>，當食品賣的應該是複方；只含酸棗仁一種成分的產品，依這個備註不符合食品原料的使用條件。有中藥製劑許可證字號的，就是藥品。

### 酸棗仁湯可以自己去中藥行抓來喝嗎？

酸棗仁湯是中醫方劑，含川芎、甘草等藥材 <a href="#ref-12">[12]</a>，川芎在草案中標示孕婦慎用 <a href="#ref-3">[3]</a>，甘草長期大量會影響血壓與血鉀。要用方劑處理失眠，請中醫師依體質與用藥情況開立，並讓開西藥的醫師知道。
