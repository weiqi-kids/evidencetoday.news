## 30 秒認識

- 鳳梨酵素是鳳梨（Ananas comosus）所含的一組硫醇蛋白酶，商業原料以莖部為主。農業部農業知識入口網由農業試驗所嘉義分所撰寫的問答寫得很直白：市售產品經冷凍、榨汁、離心、超過濾、冷凍乾燥後得到淡黃色粉末，再做成粉包、錠劑或膠囊。 <a href="#ref-29">[29]</a>
- 食藥署食藥闢謠專區 2017 年 8 月 17 日的回覆把落差講清楚了：「鳳梨果實內的鳳梨酵素含量不高，鳳梨酵素主要從非食用部位的鳳梨莖中萃取濃縮而來」，而酵素本身是蛋白質、容易被胃的酸鹼環境破壞，「從飲食中能獲得的酵素量相當有限，無法達到抗發炎的效果」。 <a href="#ref-1">[1]</a>
- 證據最集中的場景是口腔外科。兩篇 2019 年統合分析各收 6 篇隨機試驗，術後第 7 天疼痛的標準化平均差分別是 -0.54 與 -0.52，方向一致；但臉部腫脹與開口受限這兩項，兩篇的結論剛好相反。 <a href="#ref-7">[7]</a><a href="#ref-8">[8]</a>
- 標示上的活性單位比毫克數重要，卻最少人看得懂。GDU、MCU、BTU、CDU、FIP、Rorer units 都在用，各自的受質不同（明膠、酪蛋白、脫脂奶、血紅素），沒有一組跨廠通用的換算表。 <a href="#ref-33">[33]</a>
- 劑量堆高不一定更有效。Bormann 等人 2016 年的三臂交叉試驗比較每日 1000、3000、4500 FIP，結果是 3000 與 4500 FIP 都沒有勝過 1000 FIP。 <a href="#ref-9">[9]</a>
- 台灣沒有把鳳梨酵素當保健成分的專屬法規。它在食品端屬於酵素製劑類的食品添加物，在藥品端則有多張經核准的處方藥許可證，全部做成腸溶錠。 <a href="#ref-1">[1]</a><a href="#ref-31">[31]</a>
- 抗凝血與抗血小板藥物使用者要另外評估。體外與動物實驗一致指向血小板凝集下降，Gläser 與 Hilberg 2006 年的實驗中 ADP 誘發凝集率由 81.4% 掉到 5.0%。 <a href="#ref-25">[25]</a><a href="#ref-26">[26]</a>

## 基本介紹

台灣一年產出三十幾萬公噸鳳梨，高屏、台南、嘉義、南投是主要產區，台農 17 號金鑽鳳梨在高雄區農業改良場的統計中占栽培品種的多數。 <a href="#ref-30">[30]</a> 產地優勢讓「吃鳳梨消腫」「鳳梨幫助消化」變成餐桌上不需要解釋的常識，也讓鳳梨酵素膠囊在藥妝店與電商裡賣得順理成章。

問題出在這兩件事被當成同一件事。餐後那塊鳳梨與貨架上那顆 500 毫克膠囊，在原料部位、劑量級距、抵達腸道的比例上都不一樣，而且差距不是幾成，是好幾個數量級。這一頁把可查證的部分整理出來：哪些用途有隨機對照試驗、哪些只有體外數據、標示上那串英文縮寫該怎麼讀、什麼人不該自己買來吃。

## 這是什麼？

鳳梨酵素這個名稱指的是一群混合物，主成分為含硫醇活性中心的半胱胺酸蛋白酶，另外還帶有磷酸酶、葡萄糖苷酶、過氧化酶、纖維素酶與蛋白酶抑制劑。 <a href="#ref-3">[3]</a><a href="#ref-2">[2]</a>

依取材部位分成兩類，這是理解整個品類的關鍵分界：

- **莖鳳梨酵素（stem bromelain）**：從採收後留下的莖部萃取，是商業原料的主流。Varilla 等人 2021 年的回顧引用 1957 年的觀察指出，鳳梨莖裡的鳳梨酵素明顯多於果實本身，莖鳳梨酵素的蛋白酶活性也高於果實型。 <a href="#ref-6">[6]</a>
- **果鳳梨酵素（fruit bromelain）**：存在於果肉與果汁，含量低，工業上很少作為原料來源。

台灣消費者最常誤解的一句話就藏在這裡。市場上有些「鳳梨酵素」商品其實是鳳梨果實加糖發酵的酵素液，跟臨床試驗用的莖部萃取濃縮物是兩種東西。農業試驗所嘉義分所的說明也特別把這條線畫出來，指出相關研究鎖定的是莖部萃取物。 <a href="#ref-29">[29]</a>

**活性單位怎麼讀。** 鳳梨酵素的效力不用毫克表示，因為同樣重量的粉末，純化程度不同活性可以差好幾倍。業界至少有六種單位在流通：GDU（gelatin digestion units，明膠消化單位）、MCU（milk clotting units，凝乳單位）、BTU（bromelain tyrosine units）、CDU（casein digestion units）、FIP 單位（國際藥學聯合會方法）與 Rorer units。GDU 的定義是在 pH 4.5、45°C 下 20 分鐘內從明膠水解出 1.0 毫克胺基氮的酵素量；供應商給的近似關係是 1200 GDU/g 大約相當於 2.4 FIP 單位/毫克，1 BTU 約等於 1.1 GDU。 <a href="#ref-33">[33]</a> 這些數字之所以只能說「大約」，是因為每種測定法用的受質不一樣，測到的並不是同一種蛋白水解活性。

實務上的讀法是：先看有沒有標活性單位，再看單位是哪一種，然後才看每份含幾毫克。只寫「鳳梨酵素 500 毫克」而沒有活性標示的產品，你無法從標示推算它跟試驗用量的關係。劑型設計的影響同樣容易被忽略，這方面的通則可以參考〈[換了劑型好吞就等於有效](/articles/dosage-form-swallowing-vs-efficacy/)〉。

## 在身體裡做什麼？／主要作用機制

被提出的機制有幾條，強度差異很大，這裡按證據等級由高到低排。

**口服後真的會進入血液，但比例有限。** Castell 等人 1997 年在《American Journal of Physiology》發表的人體試驗，19 名健康男性每天口服 3 公克鳳梨酵素，血漿中偵測到具生物活性的完整酵素，半衰期 6 至 9 小時，48 小時後血漿濃度約 5000 pg/mL，第 3 至 51 小時期間血漿中平均存在 10.8 微克。 <a href="#ref-24">[24]</a> 這是少數直接測到「吃下去的蛋白酶以未被完全分解的形式出現在血中」的資料，也是後續全身性抗發炎假說的立足點。要留意的是，每天 3 公克遠高於一般膠囊的建議量。

**胃酸會擋掉一部分，但不是全部。** Varilla 等人 2021 年的回顧引述的實驗指出，鳳梨酵素在人工胃液中放置 4 小時後仍約有 30% 維持穩定，而由腸道吸收的部分中約 40% 保持高分子量形式。 <a href="#ref-6">[6]</a> 這個數字解釋了兩件看似矛盾的事：食藥署說飲食中攝取的量不足以抗發炎是對的（果肉裡本來就沒多少），而口服補充品仍有部分能到達腸道也是對的（劑量高出好幾個級距）。台灣核准的鳳梨酵素處方藥全部做成腸溶錠，目的就是讓有效成分越過胃再釋放。 <a href="#ref-1">[1]</a>

**抗發炎與抗水腫。** 回顧文獻歸納的路徑包括抑制前列腺素 E2 與血栓素合成、下調 COX-2 與 NF-κB 訊息、影響白血球表面黏附分子、促進纖維蛋白降解與血漿激肽釋放酶系統。 <a href="#ref-2">[2]</a><a href="#ref-4">[4]</a><a href="#ref-5">[5]</a> Henrotin 等人 2025 年發表於《RMD Open》的交叉試驗提供了目前最直接的人體機轉證據：43 名膝關節炎患者服用鳳梨酵素、胰蛋白酶與芸香苷的複方 8 週，α2-巨球蛋白上升（p = 0.038）、IL-10 上升（p < 0.0001）、尿中軟骨降解指標 CTX-II 下降（p = 0.038）。 <a href="#ref-22">[22]</a> 這是複方試驗，無法把效果單獨歸給鳳梨酵素。

**抗血小板。** Metzig 等人 1999 年的實驗中，10 µg/mL 預處理可完全阻斷凝血酶誘發的人類血小板凝集；大鼠口服 60 mg/kg 後，小動脈血栓形成減少 11%、小靜脈減少 6%。 <a href="#ref-25">[25]</a> Gläser 與 Hilberg 2006 年取 10 名健康男性的血液做體外實驗，加入 5 mg/mL 後血小板數由每奈升 277±17 降到 247±19，ADP 誘發凝集率由 81.4±5.0% 降到 5.0±4.6%，TRAP-6 誘發者由 77.4±10.4% 降到 9.0±4.9%。 <a href="#ref-26">[26]</a> 這兩篇的濃度都是直接加在血液或動物身上，人口服後血中能達到的濃度低很多，所以這條線只能當作「需要警覺」的訊號，不能當作「等同抗凝血藥」的結論。

**幫助消化。** 這是台灣最常聽到的用途，卻是證據最薄的一條。鳳梨酵素確實能在體外水解蛋白質，食品工業拿它嫩肉、做水解蛋白，農業知識入口網也列了嫩化肉類、脹氣時幫助消化這些日常用法，但同一份問答直接註明多數宣稱缺乏完整科學驗證。 <a href="#ref-29">[29]</a> 目前沒有以「改善消化不良症狀」為主要指標的隨機對照試驗可以引用。

## 食物來源／常見來源

鳳梨酵素不屬於必需營養素，講「食物來源」的意義有限，但幾個實用資訊仍值得知道：

- **鳳梨果肉與果汁**：含果鳳梨酵素，濃度低。這也是吃了新鮮鳳梨會「咬舌」的原因之一，果肉中的蛋白酶與草酸鈣針晶會共同刺激口腔黏膜。
- **加熱過的鳳梨**：罐頭、烤鳳梨、鳳梨炒飯裡的酵素已經失活，所以不會咬舌，也不會有酵素相關的作用。
- **鳳梨心與莖**：活性高於果肉，但莖不是一般食用部位。
- **其他含蛋白酶的水果**：木瓜（木瓜酵素）、奇異果（獼猴桃蛋白酶）、無花果。這些在體外都能分解蛋白質，人體口服後的證據同樣有限。

一個容易被忽略的細節：新鮮鳳梨加進牛奶或吉利丁做的甜點會出現苦味或無法凝固，就是蛋白酶在作用。這個現象反過來說明果肉裡確實有活性酵素，但它離「吃到能抗發炎的劑量」還很遠。 <a href="#ref-1">[1]</a> 攤位上切好放著的鳳梨還有另一層食安考量，見〈[攤位上切開放著的西瓜、鳳梨能買嗎](/articles/cut-watermelon-at-stall/)〉。

## 建議攝取量／研究中常見使用方式

各研究的劑量標示方式並不統一，這裡按原文獻的寫法列出，不做換算：

- **Bormann 2016（拔智齒，德國）**：三臂交叉設計，75 人納入、68 人分析，比較每日 1000 FIP、3000 FIP、4500 FIP。合併分析下鳳梨酵素在各項評估都有優於安慰劑的趨勢，但 3000 與 4500 FIP 沒有勝過 1000 FIP。 <a href="#ref-9">[9]</a>
- **Majid 與 Al-Mashhadani 2014（拔智齒，伊拉克）**：45 人，每日 4 次、每次 250 毫克，與每日 4 次、每次 25 毫克 diclofenac 及安慰劑比較。鳳梨酵素與 diclofenac 在各時間點的止痛效果都優於安慰劑（p < 0.05），生活品質指標兩組相當。 <a href="#ref-10">[10]</a>
- **Ordesi 2014（拔智齒，義大利）**：80 人，鳳梨酵素組在術後 3 小時、48 小時與第 7 天的疼痛、水腫與紅斑都低於對照組，止痛藥使用量略減。 <a href="#ref-11">[11]</a>
- **de la Barrera-Núñez 2014（拔智齒，西班牙）**：34 人，前 3 天每日 150 毫克、第 4 至 7 天每日 100 毫克。這篇的結果是沒有統計顯著差異，只在發炎與開口度上看到偏向鳳梨酵素的趨勢。 <a href="#ref-12">[12]</a>
- **Gupta 2022（拔智齒，印度）**：72 人三盲隨機，鳳梨酵素在術後第 2 天與第 7 天的腫脹與開口受限優於 aceclofenac（p < 0.001），止痛效果兩者相當（p > 0.05）。 <a href="#ref-13">[13]</a>
- **Büttner 2013（慢性鼻竇炎術後，德國）**：12 人開放式試驗，每錠 500 FIP，平均每天 6 錠（合計 3000 FIP），連續 3 個月。無對照組，只能當作安全性與可行性的初步資料。 <a href="#ref-15">[15]</a>
- **Kasemsuk 2016（膝關節炎，泰國）**：40 人，每天 500 毫克，16 週。 <a href="#ref-17">[17]</a>
- **Brien 2006（膝關節炎，英國）**：47 人，每天 800 毫克，12 週，主要指標無顯著差異。 <a href="#ref-18">[18]</a>
- **Walker 2002（輕度膝痛，英國）**：77 名健康成人的開放式劑量探索，每天 200 毫克組症狀總分下降 41%，400 毫克組下降 59%。開放式設計沒有安慰劑組，這個幅度不能直接視為藥效。 <a href="#ref-19">[19]</a>
- **Castell 1997（吸收試驗）**：每天 3 公克，用於藥動學測定而非療效評估。 <a href="#ref-24">[24]</a>

**空腹吃還是隨餐吃。** 市面上普遍的說法是：想要抗發炎就空腹吃，想要幫助消化就隨餐吃。這個分法的邏輯站得住腳，隨餐吃時酵素會忙於分解食物蛋白，空腹吃才有機會被吸收進入循環，但沒有任何一篇人體試驗做過兩種吃法的頭對頭比較。上面列出的抗發炎試驗多數未在摘要中載明服用時間，所以「空腹吃比較有效」目前是機轉推論，不是被驗證過的結論。把推論當成結論，正好是保健品資訊最常出錯的環節，這種落差在〈[保健食品的體感到底是什麼](/articles/supplement-felt-effect-vs-efficacy/)〉裡有更完整的討論。

## 缺乏風險或攝取不足問題

鳳梨酵素沒有缺乏症，人體不需要它，不吃鳳梨也不會造成任何營養素不足。如果有廠商用「現代人酵素不足」當賣點，那是行銷語言，不屬於生理學描述。

比較該處理的是「為什麼會腫、為什麼會痛」。術後腫脹有其自然病程，退化性關節炎的疼痛則牽涉軟骨、滑膜、肌力與體重多個環節，這些各有處置順序，效果幅度也遠大於一顆酵素膠囊。膝關節不適的非手術選項可以看〈[退化性關節炎一定要開刀嗎](/articles/knee-osteoarthritis-nonsurgical-options/)〉；鼻塞流鼻水長期不好，先分清楚是過敏還是感染，見〈[過敏性鼻炎完整指南](/articles/allergic-rhinitis-guide/)〉。

## 補充品常見形式

- **腸溶錠與腸溶膠囊**：讓成分越過胃酸再於腸道釋放。台灣核准的含鳳梨酵素處方藥都採這個劑型。 <a href="#ref-1">[1]</a> 一般食品類的鳳梨酵素則不一定有腸溶設計，包裝上會寫「腸溶」或「enteric coated」。
- **一般膠囊或錠劑**：以 GDU 或毫克標示，常見的是每份 500 毫克搭配 2400 GDU/g 的原料規格。沒有腸溶設計時，抵達腸道的比例會低於腸溶劑型。
- **複方酵素製劑**：鳳梨酵素加胰蛋白酶、芸香苷（rutoside）的組合在歐洲有較長的使用史，Akhtar 2004、Klein 2006 與 Henrotin 2025 用的都是這類複方。 <a href="#ref-20">[20]</a><a href="#ref-21">[21]</a><a href="#ref-22">[22]</a> 複方試驗的結果不能拿來支持單方鳳梨酵素產品的訴求。
- **與薑黃、槲皮素同包的配方**：常見於關節或抗發炎類產品。這類配方的訴求來自各成分的個別資料，購買前要分開評估，相關整理見〈[薑黃](/ingredients/turmeric/)〉與〈[槲皮素](/ingredients/quercetin/)〉。
- **鳳梨發酵液與酵素飲**：以果實加糖發酵製成，與莖部萃取濃縮物不同，臨床試驗資料無法套用。 <a href="#ref-29">[29]</a>

## 台灣的法規與市場實況

**在台灣，鳳梨酵素同時活在食品與藥品兩套規則裡。**

食品端，酵素製劑列在《食品添加物使用範圍及限量暨規格標準》的其他類，限於食品製造或加工必須時，於各類食品中視實際需要適量使用。 <a href="#ref-31">[31]</a> 這是把它當加工助劑管理，跟保健功效無關。

藥品端，食藥署在闢謠專區的回覆中明確寫到，該署已核准多項含鳳梨酵素的處方藥品，皆為腸溶衣錠劑型。 <a href="#ref-1">[1]</a> 這代表兩件事：其一，台灣的醫療體系承認這個成分在特定適應症下有用；其二，那些用途要由醫師開立，跟自己去藥妝店買一瓶不是同一件事。

**沒有小綠人。** 鳳梨酵素目前不屬於食藥署公告的健康食品規格標準品項，市售鳳梨酵素保健食品若沒有個案審查取得許可證，就不能宣稱保健功效。包裝上出現「消腫」「消炎」「改善關節疼痛」這類敘述，已經落入《食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則》要處理的範圍，而該準則的判斷方式是看整體表現，不是只看單一詞句。 <a href="#ref-32">[32]</a>

**德國的位置很不一樣。** 鳳梨酵素在德國是註冊藥品，核准用於耳鼻喉手術後鼻部與鼻竇的腫脹與發炎。 <a href="#ref-2">[2]</a> Braun 等人 2005 年的兒童急性鼻竇炎研究用的 Bromelain-POS 就屬於這類藥品。 <a href="#ref-14">[14]</a> 台灣讀者在國外藥局貨架上看到的鳳梨酵素，跟在台灣電商買到的膳食補充品，法規身分並不相同。

**選購時實際可以做的檢查。** 看有沒有標活性單位以及是哪一種單位；看是不是腸溶劑型；看是單方還是複方，若是複方，想要的效果是哪個成分帶來的；看有沒有標示原料取自莖部萃取。這四項在正面包裝上通常看不到，要翻到背面成分欄。

## 安全性與注意事項

**抗凝血與抗血小板藥物。** 這是鳳梨酵素最需要事先確認的一件事。體外與動物實驗一致指向血小板凝集下降與抗血栓傾向。 <a href="#ref-25">[25]</a><a href="#ref-26">[26]</a> 回顧文獻也提醒，正在治療血液或出血相關疾病者應在醫療評估後才使用。 <a href="#ref-2">[2]</a> 正在服用 warfarin、抗血小板藥或新型口服抗凝血劑的人，把鳳梨酵素當成需要先問過醫師或藥師的品項處理。判斷這類交互作用的思路，可以參考〈[慢性病藥和保健食品並用](/articles/chronic-disease-drug-supplement-interaction/)〉與〈[在吃抗凝血劑可以吃黑木耳嗎](/articles/black-fungus-anticoagulant-bleeding-risk/)〉。

**手術前。** 因為上述的抗血小板傾向，術前應把鳳梨酵素列進要停用的補充品清單，停多久依手術類型與醫師指示，作法見〈[開刀前要停哪些保健食品](/articles/stop-supplements-before-surgery/)〉。有些拔智齒試驗確實在術前就開始給藥，那是在牙科醫師規劃下的用法，跟自行服用不同。 <a href="#ref-9">[9]</a><a href="#ref-10">[10]</a>

**抗生素的血中濃度。** 回顧文獻提到鳳梨酵素可能提高部分藥物的吸收，包括 amoxicillin 與四環黴素類抗生素、部分化療藥與 ACE 抑制劑。 <a href="#ref-2">[2]</a> 這類交互作用在治療期間有臨床意義，正在服藥的人不要自己疊加。

**鳳梨過敏。** Braun 等人 2005 年的德國世代研究中，唯一一例過敏反應發生在已知鳳梨過敏的兒童身上。 <a href="#ref-14">[14]</a> 對鳳梨有過敏史的人不應該使用鳳梨酵素補充品。

**乳膠與水果交叉過敏。** 乳膠過敏者對特定水果的交叉反應是有名的臨床現象。Brehler 等人 1997 年檢驗 136 名乳膠過敏患者，69.1% 驗得到水果特異性 IgE，42.5% 主訴吃了香蕉、奇異果、酪梨等水果後出現過敏症狀；不過在自述有症狀的患者中，只有 32.1% 的血清驗得到對應的特異性 IgE，作者群因此指出血清學檢驗的預測價值有限。 <a href="#ref-28">[28]</a> Blanco 2003 年的回顧把交叉反應歸因於第一類幾丁質酶與乳膠過敏原 hevein 的結構相似，最常被點名的水果是香蕉、酪梨、奇異果與栗子。 <a href="#ref-27">[27]</a> 鳳梨本身不在最常見的名單上，但有乳膠過敏史的人在嘗試任何新的水果來源補充品前，先與過敏科醫師確認比較妥當。

**腸胃道反應。** 各試驗通報的不良反應以腸胃不適、噁心、腹瀉、月經量增加為主，多屬輕度。Bormann 2016 的三臂交叉試驗中，鳳梨酵素組的不良事件沒有多於安慰劑組。 <a href="#ref-9">[9]</a> Büttner 2013 的 3 個月試驗未觀察到不良事件。 <a href="#ref-15">[15]</a>

**孕婦、哺乳與兒童。** 現有試驗的受試者以成人為主，Braun 2005 是少數的兒童資料，且屬觀察性設計。 <a href="#ref-14">[14]</a> 孕期與哺乳期缺乏安全性試驗，屬於資料空白。

**胃部不適者。** 蛋白酶對胃黏膜的刺激個別差異大，有消化性潰瘍病史者若要使用，選腸溶劑型並在醫療人員指導下進行較合理。

## 常見迷思

- **「多吃鳳梨就能消腫止痛」**：食藥署闢謠專區已經直接回答過，鳳梨果實內的鳳梨酵素含量不高，主要原料來自非食用的莖部，而且酵素容易被胃的酸鹼環境破壞，飲食中能獲得的量無法達到抗發炎效果。 <a href="#ref-1">[1]</a> 鳳梨仍是好水果，但理由是纖維、維生素 C 與水分，跟抗發炎無關。
- **「GDU 數字越大越好」**：GDU 是活性單位，不同單位系統測的受質不同、不能互換比較，而 Bormann 2016 的劑量探索也顯示 4500 FIP 沒有比 1000 FIP 更有效。 <a href="#ref-9">[9]</a><a href="#ref-33">[33]</a> 把數字當競賽會付更多錢，卻換不到多出來的效果。
- **「鳳梨酵素可以取代消炎止痛藥」**：Majid 2014 與 Gupta 2022 兩篇試驗中，鳳梨酵素在拔牙後的止痛效果與 NSAID 相當。 <a href="#ref-10">[10]</a><a href="#ref-13">[13]</a> 但那是特定手術、特定療程、在醫療團隊安排下的比較，樣本分別是 45 人與 72 人。把它推廣成「任何疼痛都能用鳳梨酵素代替止痛藥」超出資料範圍，而且延誤診斷的風險是食藥署那則闢謠特別提醒的重點。 <a href="#ref-1">[1]</a>
- **「酵素飲跟鳳梨酵素膠囊差不多」**：果實發酵液與莖部萃取濃縮物的原料與製程都不同，臨床試驗用的是後者。 <a href="#ref-29">[29]</a><a href="#ref-6">[6]</a>
- **「天然的所以不用擔心交互作用」**：抗血小板傾向、可能提高抗生素吸收、鳳梨過敏者的過敏風險，這三項都寫在回顧文獻與試驗紀錄裡。 <a href="#ref-2">[2]</a><a href="#ref-14">[14]</a><a href="#ref-25">[25]</a>
- **「膝蓋痛吃鳳梨酵素就會好」**：兩篇規模最接近的試驗結論相反，Kasemsuk 2016 的 40 人試驗是正向的，Brien 2006 的 47 人安慰劑對照試驗主要指標沒有差異。 <a href="#ref-17">[17]</a><a href="#ref-18">[18]</a> Brien 等人自己在 2004 年的回顧裡也把當時的資料定位為需要更嚴謹試驗驗證。 <a href="#ref-23">[23]</a>

## 常見問題

### 吃鳳梨跟吃鳳梨酵素補充品，差別到底有多大？

差在原料部位與劑量兩層。商業原料取自莖部，果肉裡的含量低；臨床試驗常用的每日量是 500 至 800 毫克的濃縮萃取物，Castell 的吸收試驗甚至用到每天 3 公克。 <a href="#ref-6">[6]</a><a href="#ref-24">[24]</a> 食藥署的說法是飲食中獲得的量「無法達到抗發炎的效果」。 <a href="#ref-1">[1]</a> 想從水果得到抗發炎效果，這條路在數量級上就走不通。

### 標示上的 GDU 和 FIP 怎麼換算？

沒有跨廠通用的公式。GDU 的定義是 pH 4.5、45°C 下 20 分鐘從明膠水解出 1.0 毫克胺基氮所需的酵素量；供應商提供的近似關係是 1200 GDU/g 約相當於 2.4 FIP 單位/毫克。 <a href="#ref-33">[33]</a> 各測定法用的受質不同（明膠、酪蛋白、脫脂奶、血紅素），測到的活性面向也不同，所以換算結果只能參考。要比較兩瓶產品，最實際的做法是找同一種單位系統的標示來比。

### 什麼時候該去看醫生，而不是自己買鳳梨酵素？

關節腫痛持續超過兩週、關節紅熱或發燒、單側關節突然劇痛、鼻涕帶血或伴隨臉部劇烈疼痛與視力變化、術後傷口紅腫熱痛加劇。這些都需要診斷而不是補充品。食藥署在闢謠內容中也提醒關節不適應先就醫，避免自行使用而延誤診斷。 <a href="#ref-1">[1]</a>

### 拔智齒前後可以自己買來吃嗎？

現有試驗中的用法是在牙科團隊規劃下，於術前或術後依固定療程給藥，例如每日 4 次每次 250 毫克連續數天。 <a href="#ref-10">[10]</a><a href="#ref-9">[9]</a> 由於鳳梨酵素有抗血小板的傾向，術前是否使用、使用多久，應由執刀的牙科醫師決定，自行添加可能與醫師的止血規劃衝突。 <a href="#ref-26">[26]</a>

### 慢性鼻竇炎吃鳳梨酵素有幫助嗎？

急性鼻竇炎方面，Guo 等人 2006 年的系統性回顧納入 3 篇鳳梨酵素試驗，全部通報了部分正向結果，合併其中兩篇的急性鼻竇炎資料後，作者群認為輔助使用可改善部分症狀。 <a href="#ref-16">[16]</a> 慢性鼻竇炎的資料就弱得多，Büttner 2013 只有 12 人、開放式、無對照組，且效果在無鼻息肉的患者身上較明顯。 <a href="#ref-15">[15]</a> 慢性鼻竇炎的處置仍以耳鼻喉科的診斷與治療為主。

### 吃了以後嘴巴痛、舌頭麻，是過敏嗎？

新鮮鳳梨造成的口腔刺痛多半來自果肉中的蛋白酶與草酸鈣針晶，屬於局部刺激，通常在停止進食後緩解。但如果出現嘴唇腫、喉嚨緊、蕁麻疹、呼吸困難，那是過敏反應的表現，要立刻就醫。對鳳梨有過敏史的人不應使用鳳梨酵素補充品。 <a href="#ref-14">[14]</a>

### 已知乳膠過敏，能吃鳳梨酵素嗎？

乳膠與水果的交叉過敏確實存在，Brehler 等人在 136 名乳膠過敏患者中測到 69.1% 有水果特異性 IgE、42.5% 有進食後症狀。 <a href="#ref-28">[28]</a> 最常牽涉的水果是香蕉、酪梨、奇異果與栗子，鳳梨不在最前面的名單上。 <a href="#ref-27">[27]</a> 由於血清學檢驗的預測力有限，這類判斷交給過敏免疫科評估會比自行嘗試安全。
