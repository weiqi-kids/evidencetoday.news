## 30 秒認識

- 黃耆的人體研究不少，品質卻普遍偏低。Cochrane 回顧慢性腎臟病的 22 篇試驗，沒有一篇報告是否延後洗腎或降低死亡 <a href="#ref-3">[3]</a>；NCCIH 的結論是現有證據不足以判斷它對任何疾病有沒有用 <a href="#ref-1">[1]</a>
- 常被引用的「抗癌」「抗疲勞」資料，多數來自複方、注射劑或化療合併治療，不能套用到一碗燉雞湯 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>
- 交互作用最需要注意的是抗排斥與免疫抑制藥物：一篇個案報告中，加入含黃耆的中藥顆粒後 tacrolimus 濃度掉了將近一半 <a href="#ref-7">[7]</a>
- 降血糖藥、降血壓藥、利尿劑的交互作用屬於理論推論，人體資料很少 <a href="#ref-2">[2]</a> <a href="#ref-4">[4]</a>
- 台灣同一根黃耆有三種身分：食藥署平臺列為可直接食用但不得單一原料使用；中醫藥司 115 年 4 月草案列入第二類，每人每日 4.5 公克、須標示過敏體質者慎用；黃耆多醣則是限由醫師使用的注射劑 <a href="#ref-8">[8]</a> <a href="#ref-10">[10]</a> <a href="#ref-12">[12]</a>

## 基本介紹

十二月的傳統市場，中藥行門口會掛出「冬至補冬」的藥膳包，打開來幾乎都有幾片切成斜片、淡黃色帶纖維的黃耆。它在台灣的使用頻率高到很少人會把它當成「藥」，多半當成跟紅棗、枸杞同一類的湯料。

這一頁只回答一件事：正在吃藥的人，冬天燉補要不要放黃耆、放了要注意什麼。黃耆在中醫理論中的補氣作用不在本頁範圍。藥材要不要先洗、重金屬與二氧化硫怎麼管，整理在〈[中藥材、乾貨要先洗過再用嗎](/articles/herbal-dried-goods-wash-first/)〉；當歸、黃耆、甘草與各類西藥的整體對照，在〈[補湯裡的當歸、黃耆，會跟你正在吃的西藥衝突嗎](/articles/herbal-tonic-drug-interactions/)〉；哪些人根本不適合吃薑母鴨、羊肉爐，見〈[立冬進補前先確認：哪些人不該吃](/articles/who-should-avoid-winter-tonic/)〉。

## 這是什麼？

黃耆是豆科黃耆屬植物的乾燥根。中醫藥司 115 年 4 月預告的草案列出兩種基原：蒙古黃耆（*Astragalus mongholicus*，舊稱 *A. membranaceus* var. *mongholicus*）與膜莢黃耆（*A. membranaceus*） <a href="#ref-10">[10]</a>，食藥署食品原料平臺收的也是這兩種 <a href="#ref-8">[8]</a>。

市場上另有一種「紅耆」（又稱晉耆），來自多序岩黃耆（*Hedysarum polybotrys*），是不同屬的植物。中醫藥司草案把它和黃耆分開列，每人日食用限量同樣是 4.5 公克 <a href="#ref-10">[10]</a>；食藥署平臺則把紅耆限定在滷汁（包）或調味粉裡當膳食調味，外包裝要寫明與食材一起燉煮，不能讓人誤認為藥品 <a href="#ref-8">[8]</a>。兩者外觀相近，藥膳包上寫「耆」時，可以問店家是哪一種。

黃耆研究最多的成分有三類：多醣、皂苷（黃耆甲苷，astragaloside）與異黃酮（芒柄花素等）。MSKCC 指出芒柄花素在體外實驗有類雌激素活性 <a href="#ref-2">[2]</a>。這幾類成分在熱水裡溶出的比例各不相同，一碗燉湯裡到底有多少，查不到可靠數據。

## 證據等級：一張表看清楚

**黃耆的人體試驗數量不少，但能回答「我喝燉湯會怎樣」的幾乎沒有。**

| 宣稱 | 最好的證據 | 結果 | 為什麼不能直接套到燉湯 |
|---|---|---|---|
| 保護腎臟 | Cochrane 回顧，22 篇試驗、1,323 人 <a href="#ref-3">[3]</a> | 尿蛋白減少、血紅素與白蛋白上升 | 沒有一篇報告洗腎或死亡；試驗品質低；多為萃取物或注射劑合併西藥 |
| 幫助控制血糖 | 統合分析，20 篇試驗、953 人 <a href="#ref-4">[4]</a> | 糖化血色素多降 0.93 個百分點 | 作者自評確定性不理想；都是合併降血糖藥的輔助治療 |
| 抗癌、提升化療效果 | 統合分析，34 篇試驗、2,815 人 <a href="#ref-5">[5]</a> | 12 個月死亡風險比 0.67 | 含黃耆的複方，部分為注射劑；試驗設計不夠嚴謹 |
| 改善疲勞 | 台灣第四期試驗，310 人 <a href="#ref-6">[6]</a> | 超過 65% 疲勞分數改善至少 10% | 靜脈注射的黃耆多醣；兩種劑量互比，沒有安慰劑組；藥廠出資 |
| 增強免疫、預防感冒 | MSKCC 整理的健康志願者研究與實驗室資料 <a href="#ref-2">[2]</a> | 免疫細胞指標有變化 | 沒有以「少感冒」為結果的可靠人體試驗 |

把這張表看完，比較誠實的說法是：黃耆在某些疾病的輔助治療上有訊號，但訊號來自品質不高的試驗，而且多半是萃取物、複方或注射劑。NCCIH 2025 年的頁面寫得直接，三篇近期回顧都顯示可能有益，但大多數研究規模小或品質低，現有證據不足以知道黃耆對任何健康狀況是否有用 <a href="#ref-1">[1]</a>。

**台灣有一個值得知道的特例。** 懷特血寶凍晶注射劑（PG2）是台灣核准的西藥，主成分是從黃耆萃取的多醣，許可證字號衛部藥製字第058837號，適應症是「適用於癌症末期因疾病進展所導致中重度疲勞症狀之改善」，藥品類別限由醫師使用 <a href="#ref-12">[12]</a>。它的上市後試驗用的是每週三次靜脈注射 <a href="#ref-6">[6]</a>，給藥途徑、劑量與純度都跟燉湯差很遠。家人在做化療、想自己加黃耆或其他保健品時，〈[家人在做化療，可以吃牛樟芝、靈芝或高劑量維他命 C 嗎](/articles/chemotherapy-antrodia-reishi-supplements/)〉有整理怎麼跟腫瘤科團隊溝通。

## 正在吃藥的人：哪幾類要先講一聲

**黃耆的交互作用資料大多停在理論與動物實驗，唯一有人體個案的是免疫抑制劑。**

| 正在用的藥 | 可能的問題 | 證據來源與強度 | 建議 |
|---|---|---|---|
| tacrolimus、cyclosporine 等抗排斥藥 | 血中濃度可能下降 | 單一個案報告，合併多種新藥 <a href="#ref-7">[7]</a>；NCCIH 提醒 <a href="#ref-1">[1]</a> | 燉補前先問移植團隊或藥師；如果已經吃了，下次抽血監測濃度時告訴醫師 |
| 自體免疫疾病用藥 | 理論上方向相反 | NCCIH 建議自體免疫疾病患者避免 <a href="#ref-1">[1]</a> | 先問風濕免疫科醫師 |
| 降血糖藥 | 可能加成 | 統合分析的血糖效果，查無低血糖個案 <a href="#ref-4">[4]</a> | 燉補當天照常監測血糖，記錄下來回診時看 |
| 降血壓藥、利尿劑 | 可能加成 | 健康男性小型研究、2 篇腎臟病試驗 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a> | 量居家血壓時注意有沒有偏低 |
| warfarin 等抗凝血藥 | 出血風險 | 細胞與動物實驗 <a href="#ref-2">[2]</a> | 黃耆常和當歸一起燉，當歸的個案證據更明確 |

**抗排斥藥這一格為什麼特別放大。** Yang 等 2021 年報告的女孩，tacrolimus 劑量沒有改變，血中濃度卻降了將近一半；那段期間新增的只有霧化治療、cyclophosphamide 與一包中藥複方顆粒，作者判斷最可能的原因是顆粒裡的黃耆 <a href="#ref-7">[7]</a>。一個個案不能證明因果，同一時間還加了別的藥。但 tacrolimus 的濃度太低可能增加排斥風險，太高又傷腎，治療區間很窄；在台灣，器官移植後與狼瘡腎炎的病人都可能長期用這類藥，冬天家裡燉一鍋黃耆雞湯是很常見的情境。站上舊文寫過黃耆與免疫抑制劑的人體資料「很少」，這篇個案是目前查得到的一筆，仍不足以下定論。

**降血糖藥這一格要看兩面。** 統合分析的數字若成立，代表黃耆可能讓血糖多降一點 <a href="#ref-4">[4]</a>；但燉補時通常同時吃進大量米飯、麵線與湯裡的糖分，那一餐的血糖多半是往上走。與其猜方向，不如在燉補的日子照平常的頻率測血糖、記下來。正在吃胰島素或磺醯尿素類的人，冬天同時碰到補酒與藥膳，可以先看〈[吃降血糖藥的人，尾牙、春酒可以喝酒嗎](/articles/diabetes-medication-alcohol-year-end-party/)〉。

藥要不要停、劑量要不要調，一律跟開藥的醫師或藥師確認，不要因為「今天有喝補湯」就自己少吃一顆。

## 台灣的三套管理：食品、中藥材、西藥

**食品原料：可以吃，但不能單獨賣。** 2026 年 11 月 21 日下載食藥署食品原料整合查詢平臺開放資料比對，黃耆的根列在「草、木本植物類（2）可供直接食用」，備註只有一句：不得單一原料使用 <a href="#ref-8">[8]</a>。依這個備註，黃耆可以當配料加進食品，只含黃耆一種原料的產品則不符合這個使用條件。

**中藥材：草案放進第二類，並附一條標示要求。** 中醫藥司 107 年 2 月生效的「可同時提供食品使用之中藥材」37 項清單沒有黃耆 <a href="#ref-11">[11]</a>。115 年 4 月 13 日以衛部中字第1151860670號預告的認定基準草案，把黃耆列在第二類「食用時須注意安全性者」第 13 項，部位是乾燥根，備註兩點：外包裝須標示「過敏體質者慎用」，每人日食用限量 4.5 公克 <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>。依草案的計算規則，任一第二類品項換算的每日食用量超過臺灣中藥典所載最低用量的一半，就以藥品管理 <a href="#ref-10">[10]</a>。

草案還有兩個跟家庭燉補直接相關的條文。第一，滷包、燉包、藥膳調理包，外包裝寫明與食材燉煮方式的，不以藥品管理 <a href="#ref-10">[10]</a>，所以市場上的藥膳包大多落在這個例外裡。第二，附表 2 列出 38 個中醫典籍方劑，食品的組成不得與它們相同，其中含黃耆的有當歸補血湯（黃耆、當歸）、黃耆建中湯、黃耆五物湯、十全大補湯、聖愈湯等 <a href="#ref-10">[10]</a>。舉例來說，一包只有黃耆加當歸的「補血茶」，組成就跟當歸補血湯一樣，依草案要以藥品管理。截至 2026 年 11 月 21 日，中醫藥司網頁上仍是預告草案，最終條文以正式公告為準 <a href="#ref-9">[9]</a>。

**西藥：黃耆多醣注射劑。** 前面提到的懷特血寶凍晶注射劑，是以黃耆多醣為主成分、查驗登記核准的處方藥 <a href="#ref-12">[12]</a>。同一份西藥許可證資料中，主成分含黃耆萃取物的口服製劑，只查到一張仍有效的多成分複方處方藥，黃耆只是其中十幾種成分之一 <a href="#ref-12">[12]</a>。

三套規定放在一起看，台灣的邏輯是：份量小、跟食材一起燉的，當食品；份量大到接近藥用、或配方跟傳統方劑一樣的，當中藥；萃取純化成特定成分、做成注射劑的，當西藥。

## 安全性與注意事項

**一般人燉補吃到的量，目前沒有明確的毒性訊號，但也沒有完整的安全評估。** NCCIH 的說法是黃耆口服可能是安全的，同時強調從未做過徹底的安全性評估 <a href="#ref-1">[1]</a>。MSKCC 整理的人體不良反應以疲倦、頭痛、血壓下降為主，在一篇研究中多在 24 小時內消退 <a href="#ref-2">[2]</a>。Cochrane 慢性腎臟病回顧的 22 篇試驗中，6 篇報告沒有觀察到不良反應，其餘 16 篇根本沒有報告 <a href="#ref-3">[3]</a>，沒報告和沒發生是兩回事。

**誰要特別留意。**

- **器官移植後、使用免疫抑制劑的人**：唯一有人體個案的交互作用就在這裡 <a href="#ref-7">[7]</a>
- **自體免疫疾病患者**：NCCIH 建議避免 <a href="#ref-1">[1]</a>
- **孕婦與哺乳中的人**：安全資料很少，NCCIH 引述的動物研究中，孕期使用可能對胎兒有毒性 <a href="#ref-1">[1]</a>
- **過敏體質的人**：中醫藥司草案要求含黃耆食品標示過敏體質者慎用 <a href="#ref-10">[10]</a>
- **荷爾蒙敏感型癌症患者**：芒柄花素在體外有類雌激素活性，臨床意義未知 <a href="#ref-2">[2]</a>

**感冒發燒時要不要喝。** 這是中醫理論的判斷，不在本頁範圍；中醫的「閉門留寇」說法與現代解讀，整理在〈[立冬進補前先確認：哪些人不該吃](/articles/who-should-avoid-winter-tonic/)〉第八節。

黃耆在台灣幾乎不會單獨出現，最常見的搭檔是當歸。當歸與 warfarin 的交互作用有較明確的個案，見〈[當歸](/ingredients/dong-quai/)〉；藥膳包裡的甘草如果天天喝，血壓與血鉀的問題見〈[甘草](/ingredients/licorice/)〉。

## 常見迷思

- **「黃耆能增強免疫力，冬天每天泡水喝可以少感冒」**：沒有以「少感冒」為結果的可靠人體試驗；NCCIH 認為現有證據不足以判斷黃耆對任何健康狀況是否有用 <a href="#ref-1">[1]</a>
- **「醫院也在用黃耆治療癌症疲勞，所以自己燉湯也有效」**：醫院用的是靜脈注射的黃耆多醣處方藥，適應症限癌症末期疲勞 <a href="#ref-12">[12]</a>，給藥途徑與劑量都不同
- **「黃耆是食材，不會跟藥衝突」**：抗排斥藥 tacrolimus 已有一筆濃度下降的個案 <a href="#ref-7">[7]</a>；NCCIH 也提醒可能與免疫抑制藥物交互作用 <a href="#ref-1">[1]</a>
- **「黃耆和紅耆一樣」**：兩者是不同屬的植物，食藥署平臺把紅耆限定在滷包與調味粉 <a href="#ref-8">[8]</a>
- **「腎臟不好的人喝黃耆可以保腎」**：Cochrane 回顧找不到任何一篇報告延後洗腎或降低死亡的試驗 <a href="#ref-3">[3]</a>；慢性腎臟病人的湯品還有鉀與蛋白質的問題要另外算

## 常見問題

### 我換過腎、在吃抗排斥藥，家人燉的黃耆雞湯可以喝嗎？

先問移植團隊或藥師。目前人體資料只有一筆個案，tacrolimus 濃度在合併含黃耆的中藥顆粒後掉了將近一半 <a href="#ref-7">[7]</a>，證據不強，但抗排斥藥的治療區間很窄。如果已經喝了，下一次抽血監測藥物濃度時把燉補的頻率一起告訴醫師，比瞞著不說安全。

### 吃降血糖藥的人，黃耆會讓血糖太低嗎？

目前查無因黃耆造成低血糖的個案報告。統合分析顯示黃耆輔助治療可能讓糖化血色素再降一些 <a href="#ref-4">[4]</a>，理論上有加成的可能；但燉補那一餐的米飯與湯料通常讓血糖往上走。燉補的日子照平常的頻率測血糖並記錄下來，回診時讓醫師看。

### 一天放多少黃耆算正常？

台灣目前沒有正式的數字。中醫藥司 115 年 4 月草案對含黃耆的食品訂每人每日 4.5 公克，但滷包、燉包與藥膳調理包另有例外 <a href="#ref-10">[10]</a>。草案尚未正式公告。中藥房開給你的處方量，依中醫師的判斷為準。

### 市售黃耆膠囊、黃耆萃取液算什麼？

看它有沒有藥品許可證字號。食藥署平臺規定黃耆不得單一原料使用 <a href="#ref-8">[8]</a>，所以當食品賣的通常是複方；有「衛部藥製字」或中藥製劑字號的，就是藥品。草案生效後，第二類中藥材含量超過限量的產品會被當成藥品管理 <a href="#ref-10">[10]</a>。

### 黃耆跟當歸一起燉，要注意什麼？

組合本身是台灣最常見的燉補搭配。需要注意的是兩件事：正在吃 warfarin 或其他抗凝血藥的人，當歸的交互作用證據比黃耆明確，見〈[當歸](/ingredients/dong-quai/)〉；另外，只有黃耆加當歸兩味的沖泡產品，組成與當歸補血湯相同，依中醫藥司草案要以藥品管理 <a href="#ref-10">[10]</a>。
