## 30 秒認識

- α-硫辛酸（Alpha-Lipoic Acid, ALA）是人體粒線體天然合成的小分子，罕見同時具有水溶性與脂溶性 <a href="#ref-6">[6]</a>，能在細胞膜內外兩側都發揮抗氧化作用。 <a href="#ref-10">[10]</a>
- 人體證據最扎實的用途是**糖尿病周邊神經病變**：靜脈注射每日 600 毫克、連續 3 週對疼痛、麻木等症狀有臨床上明確的短期改善。 <a href="#ref-1">[1]</a>
- 口服的效果較不確定：一項 7 個月試驗顯示口服 6 個月未能讓症狀評分優於安慰劑，但對神經學檢查測得的功能缺損仍有幫助。 <a href="#ref-2">[2]</a>
- 「降血糖」「減脂」這類訴求證據薄弱且不一致：體重僅平均多減約 1.2 公斤，糖化血色素在不同統合分析中結論不一。 <a href="#ref-3">[3]</a><a href="#ref-4">[4]</a>
- 服用降血糖藥物者要留意低血糖風險；因結構與生物素相似、可能干擾生物素相關檢驗，長期高劑量使用者若近期要抽血檢驗，建議告知醫療人員正在補充的所有保健品。 <a href="#ref-5">[5]</a><a href="#ref-7">[7]</a>

## 基本介紹

α-硫辛酸是含硫的短鏈脂肪酸衍生物，人體可利用辛酸（octanoic acid）為原料，在粒線體內自行合成，並以「硫辛醯基」的形式接在特定酵素複合體上，參與能量代謝中丙酮酸去氫酶等關鍵反應。 <a href="#ref-6">[6]</a> 保健品中的 α-硫辛酸多為化學合成，劑量遠高於人體自行合成或飲食可提供的量，屬於藥理劑量的抗氧化補充，而非「補充不足」的營養素。

## 這是什麼？

標示常見 Alpha-Lipoic Acid、ALA，或舊稱硫辛酸（thioctic acid）；在歐洲，硫辛酸長期以處方藥形式用於糖尿病神經病變，台灣與美國則多以保健食品形式販售。天然存在的形式是 R-硫辛酸，人體酵素只能利用這個立體結構；市售合成品多為 R 型與 S 型各半的消旋混合物（DL-α-lipoic acid），兩者的人體吸收與活性並不相同，選購時可留意標示。 <a href="#ref-6">[6]</a>

## 在身體裡做什麼？／主要作用機制

α-硫辛酸的還原型（二氫硫辛酸）能直接清除自由基，並協助再生體內其他抗氧化系統（如維生素 C、麩胱甘肽），因此常被稱為「抗氧化網絡的再生者」。 <a href="#ref-10">[10]</a> 在糖尿病神經病變的研究脈絡中，主要假說是它能減輕高血糖造成的氧化壓力，進而保護周邊神經的微血管血流與神經纖維功能；這解釋了為何靜脈注射劑型效果較明確——注射能快速達到足夠的組織濃度，口服則受限於吸收率與首渡代謝，血中濃度波動較大。 <a href="#ref-1">[1]</a> 這些是機制層面的推論，實際能否轉化為「血糖」「減脂」等其他訴求的臨床效益，仍需個別療效的人體證據支持，不能用同一套機制直接類推。

## 食物來源／常見來源

α-硫辛酸廣泛存在於動植物細胞中，但食物裡幾乎都是與蛋白質共價鍵結的「硫辛醯離胺酸」形式，需先經消化分解才可能釋出游離型硫辛酸，實際生物利用率很低。相對含量較高的食物包括紅肉（尤其內臟如肝、腎、心）、菠菜、花椰菜等深綠色蔬菜，以及米糠、番茄、豌豆等。由於食物來源的吸收效率遠低於保健品所用的合成游離型 ALA，飲食幾乎無法達到臨床試驗使用的劑量，這類研究基本上是補充品議題，而非飲食調整能取代的範疇。

## 建議攝取量／常見攝取建議／研究中常見使用方式

α-硫辛酸沒有訂定每日必需攝取量或上限值。糖尿病神經病變的臨床試驗中，靜脈注射劑量多為每日 600 毫克、連續 2–3 週；後續銜接口服維持時，常見劑量為每日 600–1800 毫克，分次服用。 <a href="#ref-1">[1]</a><a href="#ref-2">[2]</a> 體重與代謝指標相關研究使用的口服劑量則多落在每日 300–1800 毫克，療程數週至數月不等。 <a href="#ref-3">[3]</a><a href="#ref-4">[4]</a> 保健品常建議空腹服用以提高吸收率，但這也可能增加腸胃不適的機率，實務上仍以產品標示與醫療人員建議為準。

## 缺乏風險或攝取不足問題

由於人體能自行合成 α-硫辛酸，且日常飲食中的微量攝取已足夠供應其在能量代謝中的原始生理角色，目前並沒有已知的「缺乏症」。保健品中討論的效益，指的是遠高於生理需求的藥理劑量所產生的額外抗氧化作用，而非彌補營養缺口，這一點與多數維生素、礦物質的補充邏輯不同。

## 補充品常見形式

市售產品多為口服膠囊或錠劑，劑量從 100 毫克到 600 毫克不等；醫療院所使用的靜脈注射劑型則屬於藥品等級，僅在特定臨床情境下由醫療人員給予，一般消費者無法自行取得。選購口服產品時，可留意是否標示為 R-硫辛酸（活性型）或消旋的 DL 型混合物、是否建議空腹服用，以及單顆劑量是否與研究使用的範圍相近；坊間也常見與 B 群、輔酶 Q10 等成分做成複方，複方會讓效果歸因變得困難。

## 安全性與注意事項

口服 α-硫辛酸在多數健康成人中耐受性良好，常見的輕微副作用包括腸胃不適、噁心、皮疹與頭痛。較需留意的風險有兩項：第一，它可能增強胰島素敏感性與葡萄糖攝取，與胰島素、磺醯脲類等降血糖藥物併用時可能增加低血糖風險，用藥者宜與醫師討論並加強血糖監測。 <a href="#ref-5">[5]</a> 第二，官方安全審查指出，α-硫辛酸曾在帶有特定基因體質的個案中誘發「胰島素自體免疫症候群」，造成反覆性低血糖，停用後多可緩解；出現冒汗、發抖、意識不清等低血糖症狀應立即停用並就醫。 <a href="#ref-5">[5]</a> 此外，α-硫辛酸的分子結構與生物素相似，兩者共用腸道的鈉依賴型多重維生素轉運蛋白（SMVT）<a href="#ref-8">[8]</a>；大鼠實驗中，高劑量硫辛酸使肝臟丙酮酸羧化酶等生物素依賴酵素活性下降約三成 <a href="#ref-9">[9]</a>；生物素本身已知會干擾多種免疫檢驗（如甲狀腺功能、心肌指標）的準確性，長期高劑量使用相關補充品者，安排抽血檢驗前宜主動告知醫療人員，避免檢驗結果被誤判。 <a href="#ref-7">[7]</a> 孕婦、哺乳者與孩童的安全性資料有限，不建議自行使用。

## 常見迷思

- 「α-硫辛酸能治好神經病變」：證據支持的是**症狀與部分神經功能指標的改善**，並非逆轉或治癒神經損傷，且效果因劑型（注射 vs. 口服）與療程長短而異。 <a href="#ref-1">[1]</a><a href="#ref-2">[2]</a>
- 「天然的抗氧化力所以吃越多越好」：目前沒有訂出上限值不代表沒有風險，過量可能增加低血糖與胃腸不適等副作用，尤其與降血糖藥併用時更要注意。 <a href="#ref-5">[5]</a>
- 「可以取代醫師開立的糖尿病神經病變治療」：多數研究是在既有藥物治療基礎上加做輔助評估，並非取代降血糖或止痛等既有處方。 <a href="#ref-2">[2]</a>
- 「吃 ALA 就能明顯減重」：統合分析顯示的體重差異平均僅約 1 公斤上下，屬小幅效果，不應視為減重方案的主力。 <a href="#ref-3">[3]</a>
