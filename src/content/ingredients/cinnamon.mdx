## 30 秒認識

- 想用肉桂控糖，證據撐不起來：Leach 與 Kumar 2012 年的 Cochrane 回顧納入 10 項試驗、577 人，糖化血色素沒有顯著改善 <a href="#ref-16">[16]</a>
- 肉桂真正要算的是香豆素：中國肉桂每公斤平均約含 3,000 毫克，60 公斤成人一天約 2 公克就到德國 BfR 的每日容許量 <a href="#ref-7">[7]</a>
- 錫蘭肉桂的香豆素很低，捷克一份 60 件市售肉桂粉的檢測中，斯里蘭卡錫蘭肉桂樣本驗不到香豆素 <a href="#ref-12">[12]</a>
- 在台灣，肉桂（桂皮）可以當食品原料但不得單一原料使用，標示每日建議食用量的膠囊、錠劑、茶包要加標「孕婦忌食」 <a href="#ref-1">[1]</a>
- 衛福部 115 年 4 月預告的草案，把肉桂（桂皮）列為「食用時須注意安全性」的中藥材，每人每日食用限量 0.5 公克 <a href="#ref-3">[3]</a>

## 基本介紹

冬至的湯圓、聖誕節的肉桂捲、過年的甜點一路吃到二月，血糖報告上的紅字也在這段時間最常被看見。肉桂膠囊在這個時候特別好賣，標籤多半寫「維持醣類代謝」，網路上也流傳每天一匙肉桂粉可以降血糖的說法。

這一頁只回答一個問題：**想控制血糖，要不要每天吃肉桂膠囊或加一匙肉桂粉？** 答案分兩半。效果那一半，人體試驗結果不一致，最嚴謹的 Cochrane 回顧看不到糖化血色素的改善 <a href="#ref-16">[16]</a>。風險那一半，取決於你吃的是哪一種肉桂、吃多少：中國肉桂的香豆素含量，讓「每天固定吃」這件事有了上限 <a href="#ref-7">[7]</a>。

小檗鹼、桑葉、白腎豆這些控糖保健品的整體比較，在〈[桑葉萃取、小蘗鹼和白腎豆：控糖補充品怎麼選](/articles/mulberry-berberine-white-bean-blood-sugar/)〉；保健品包裝上的血糖字眼怎麼讀，見〈[調節血糖等於降血糖嗎？](/articles/blood-sugar-health-claim-guide/)〉。這一頁只談肉桂。

## 這是什麼？錫蘭肉桂與中國肉桂

**市面上叫「肉桂」的東西至少來自幾種不同的樹，最重要的分界是錫蘭肉桂與中國肉桂（cassia），兩者的香豆素含量差距很大。**

錫蘭肉桂（*Cinnamomum verum*，舊名 *C. zeylanicum*）原產斯里蘭卡，常被稱為「真肉桂」；中國肉桂（*C. cassia*，又作 *C. aromaticum*）與印尼肉桂（*C. burmannii*）、越南肉桂（*C. loureirii*）合稱 cassia 類 <a href="#ref-1">[1]</a> <a href="#ref-13">[13]</a>。食藥署平臺的「肉桂（桂皮）」條目，把這五種學名列在同一條裡 <a href="#ref-1">[1]</a>，中藥材的肉桂、桂枝則是中國肉桂的樹皮與嫩枝 <a href="#ref-3">[3]</a>。

外觀上，BfR 提供了一個分辨方法：中國肉桂的肉桂棒是一層較厚的樹皮捲成一小捲；錫蘭肉桂的橫切面像切開的雪茄，由好幾層薄樹皮緊密捲在一起。磨成粉之後，消費者幾乎無法分辨，只能看包裝有沒有寫明「Ceylon cinnamon」 <a href="#ref-7">[7]</a>。

這個分辨在市場上不容易。Lungarini 等 2008 年在義大利市場採集 34 件肉桂樣本，約 51% 是 cassia、10% 疑似兩者混合，真正是錫蘭肉桂的只有 39% <a href="#ref-13">[13]</a>。

台灣還有一種本土的土肉桂（*C. osmophloeum*），用的是葉子。台大森林系 Yeh 等 2014 年分析土肉桂葉的精油，所有測試品系的香豆素都遠低於中國肉桂，桂皮醛約佔 80% <a href="#ref-14">[14]</a>。不過中興大學 Wang 等 2024 年分析土肉桂純露，香豆素佔揮發性成分的 4.31% <a href="#ref-15">[15]</a>，加工方式與品系不同，結果也會不同，不宜一概當成「零香豆素」。

## 在台灣怎麼管：食品、中藥材與草案

**肉桂在台灣同時是食品原料、辛香料與中藥材，三條線各有規矩；最直接影響保健品的是「不得單一原料使用」與「孕婦忌食」兩條。**

**食品原料平臺。** 2026 年 11 月 22 日下載食藥署食品原料整合查詢平臺的開放資料，「肉桂（桂皮）」的樹皮與「桂枝」的嫩枝都列在「草、木本植物類（2）可供直接食用」，備註相同：不得單一原料使用；標示有每日建議食用量的茶包、錠狀、膠囊、粉末狀、液狀等產品，販售時應加標「孕婦忌食」字樣 <a href="#ref-1">[1]</a>。肉桂的葉與葉柄另列在「供香辛調味使用」；土肉桂的葉也要加標孕婦忌食，但沒有不得單一原料使用的限制 <a href="#ref-1">[1]</a>。

白話說：做成膠囊、標了每天吃幾顆的肉桂產品，包裝上應該看得到孕婦忌食；只含肉桂一種原料的膠囊，依備註不符合食品的使用條件。這條規定不分錫蘭或中國肉桂，五種學名適用同一條 <a href="#ref-1">[1]</a>。

**中藥材的現行規定。** 衛福部中醫藥司 107 年 2 月生效的「可同時提供食品使用之中藥材」清單沒有肉桂與桂枝 <a href="#ref-4">[4]</a>。重金屬方面，衛福部「中藥材含重金屬限量基準」以砷 3.0、鉛 5.0、鎘 1.0、汞 0.2 ppm 為通則，桂皮與桂枝被點名適用另一個鉛限量 15.0 ppm；這份基準也寫明，衛生署 93 年那份把肉桂、桂枝、桂皮列入的「杜仲等七種中藥材」重金屬公告，與它牴觸的部分停止適用 <a href="#ref-5">[5]</a>。食品端的邊境查驗也會攔：食藥署 2025 年 11 月公布一批中國大陸出口的肉桂，檢出鉛 1.4 mg/kg 不符規定，退運或銷毀 <a href="#ref-6">[6]</a>。

**115 年的草案。** 中醫藥司 115 年 4 月 13 日預告「得供食品原料使用之中藥材品項及其產品屬性認定基準」草案 <a href="#ref-2">[2]</a>，對肉桂的處理分成幾塊 <a href="#ref-3">[3]</a>：

| 品項 | 部位 | 草案分類 | 每人日食用限量 | 標示要求 |
|---|---|---|---|---|
| 肉桂（桂皮） | 乾燥樹皮 | 第二類：食用時須注意安全性者 | 0.5 公克 | 胃炎病人及孕婦慎用；辛香調味用途免標含量，可為單一成分產品 |
| 桂枝 | 乾燥嫩枝 | 第二類 | 1.5 公克 | 胃炎病人及孕婦慎用 |
| 桂子 | 乾燥果實 | 第一類：辛香調味料 | 無 | 萃取或濃縮僅限食品原料，不得供民眾直接食用 |
| 桂智（蒂） | 乾燥葉柄 | 第一類：辛香調味料 | 無 | 同上 |

草案第五點寫明，第二類中藥材任一品項換算的每日食用量，超過臺灣中藥典所載該品項最低用量的一半（也就是表上的日限量），產品就以藥品管理 <a href="#ref-3">[3]</a>。附表 2 列出 38 個不得與食品組成相同的典籍方劑，其中含肉桂的是十全大補湯 <a href="#ref-3">[3]</a>。截至 2026 年 11 月 22 日，這份基準仍是預告草案，正式條文以公告為準 <a href="#ref-2">[2]</a>。

0.5 公克這個數字值得記住。把下一節的香豆素數字代進去，它大約是 BfR 說 60 公斤成人達到容許量那 2 公克的四分之一 <a href="#ref-7">[7]</a>。

## 香豆素：吃多少會到上限

**香豆素的每日容許攝取量是每公斤體重 0.1 毫克；用中國肉桂的平均含量換算，60 公斤成人約 2 公克、15 公斤幼兒約 0.5 公克就會到頂。**

香豆素是一種天然香味物質，聞起來像乾草。BfR 的說明是，它在少數特別敏感的人身上，即使相對低的劑量也可能造成肝損傷，輕則肝指數上升，重則肝炎、黃疸，通常可逆 <a href="#ref-7">[7]</a>。Abraham 等 2010 年整理香豆素過去作為藥物使用時的臨床資料，確認人群中有一群人比實驗動物更敏感，用人體資料推得的每日容許攝取量同樣是每公斤體重 0.1 毫克，與歐洲食品安全局的數字一致 <a href="#ref-10">[10]</a>。

肉桂裡的香豆素並不會因為包在植物組織裡就比較難吸收。Abraham 等 2011 年讓 24 名健康志願者在四種情境下吃同樣 12 毫克的香豆素，肉桂膠囊的相對吸收量是 56.0%、肉桂茶 66.1%、肉桂米布丁 54.7%，純香豆素膠囊是 62.8%，差距不大；肉桂茶吸收最快 <a href="#ref-11">[11]</a>。所以用容許量來評估肉桂的風險是合理的。

含量的數字如下。BfR 的食品監測資料顯示，中國肉桂每公斤平均約含 3,000 毫克香豆素，最高測到 10,000 毫克 <a href="#ref-7">[7]</a>；捷克 Blahová 等 2012 年檢測 12 個品牌、60 件市售肉桂粉，平均值落在每公斤 2,650 到 7,017 毫克，而一件直接從斯里蘭卡莊園取得的錫蘭肉桂驗不到香豆素 <a href="#ref-12">[12]</a>。

### 每日上限試算表

以 BfR 的容許量（每公斤體重 0.1 毫克）與上述含量試算 <a href="#ref-7">[7]</a> <a href="#ref-12">[12]</a>：

| 情境 | 每日香豆素上限 | 中國肉桂（平均 3,000 mg/kg） | 中國肉桂（高值 10,000 mg/kg） |
|---|---|---|---|
| 60 公斤成人 | 6 毫克 | 約 2 公克到頂 | 約 0.6 公克到頂 |
| 15 公斤幼兒 | 1.5 毫克 | 約 0.5 公克到頂 | 約 0.15 公克到頂 |
| 草案日限量 0.5 公克肉桂（成人） | 6 毫克 | 約 1.5 毫克，為上限的四分之一 | 約 5 毫克，接近上限 |

一茶匙肉桂粉的重量隨填裝鬆緊差很多，本頁不換算成茶匙。比較穩的做法是看克數：吃的是中國肉桂，每天固定吃 2 公克以上，就已經在 BfR 劃的線上。

BfR 也說明，短期一兩週略超過容許量不構成健康風險；需要擔心的是長期、每天、大量吃高香豆素的中國肉桂 <a href="#ref-7">[7]</a>。這正好描述了「每天吃肉桂膠囊控糖」的情境。Cochrane 回顧納入的試驗，平均劑量是每天 2 公克、多數用中國肉桂 <a href="#ref-16">[16]</a>，剛好落在成人容許量的邊界。BfR 特別提醒，肉桂膠囊的香豆素含量取決於用了哪一種肉桂與加工方式，吃中國肉桂粉做的膠囊，依建議劑量可能超過容許量 <a href="#ref-7">[7]</a>。

## 降血糖的證據：分級表

**肉桂的控糖試驗結果分歧：越新的統合分析越常報告有效，但最嚴謹的 Cochrane 回顧看不到糖化血色素的改善，各家共同的問題是試驗品質與異質性。**

| 研究 | 納入 | 主要結果 | 限制 |
|---|---|---|---|
| Leach 與 Kumar 2012，Cochrane <a href="#ref-16">[16]</a> | 10 項試驗、577 人，第一型與第二型糖尿病 | 空腹血糖無法下結論；糖化血色素、胰島素、飯後血糖無顯著差異 | 8 項試驗偏差風險高或不明 |
| Allen 等 2013 <a href="#ref-17">[17]</a> | 10 項試驗、543 名第二型糖尿病 | 空腹血糖下降 24.59 mg/dL；糖化血色素無顯著變化 | 異質性 I² 66.5% 至 94.72%，劑量 120 mg 到 6 g 不等 |
| Moridpour 等 2024 <a href="#ref-18">[18]</a> | 24 項試驗，第二型糖尿病 | 空腹血糖、HOMA-IR 與糖化血色素皆顯著下降 | 以標準化均差呈現，無法直接換算成 mg/dL 或百分點 |
| NCCIH 2024 <a href="#ref-19">[19]</a> | 官方整理 | 不清楚肉桂補充品對糖尿病是否有幫助 | 許多研究未說明使用的品種或部位 |

為什麼結果會這樣？NCCIH 的說明是，很多研究沒有寫清楚用的是哪一種肉桂、哪個部位，而不同品種的化學組成不同 <a href="#ref-19">[19]</a>。Allen 等也承認最佳劑量與療程不明 <a href="#ref-17">[17]</a>。Moridpour 等 2024 年的結果最正面，但它以標準化均差報告效果，讀者無法從摘要知道糖化血色素實際降了幾個百分點 <a href="#ref-18">[18]</a>。

對讀者的意義是：就現有資料看，肉桂沒有到可以拿來取代降血糖藥、或因此減藥的程度。糖化血色素是糖尿病治療最看重的指標，而最嚴謹的那份回顧在這一項看不到差異 <a href="#ref-16">[16]</a>。冬至吃湯圓前該怎麼算份量，見〈[冬至吃湯圓，有糖尿病的人可以吃幾顆？](/articles/winter-solstice-tangyuan-diabetes/)〉，那比一匙肉桂粉實際。

## 肝毒性：個案與機轉

**香豆素的肝毒性在藥物使用時期就有紀錄；肉桂補充品引起肝炎的報告目前只有零星個案。**

BfR 2012 年的說明寫，香豆素作為藥物使用時，少數敏感的人在服用數週後出現肝損傷，但當時的科學文獻還沒有吃肉桂造成肝損傷的病例 <a href="#ref-7">[7]</a>。之後有個案出現：Brancheau 等 2015 年報告一名 73 歲女性，因冠心病長期服用 statin，開始吃肉桂補充品約一週後腹痛、嘔吐、腹瀉，檢查確診肝炎，找不到其他原因；停用肉桂與 statin 後好轉，幾週後恢復 statin 沒有再發，作者推論是兩者合併所致 <a href="#ref-20">[20]</a>。

一個個案無法證明因果。它的實際意義是給同時在吃 statin 的人：加了肉桂補充品之後出現腹痛、嘔吐，或皮膚、眼白變黃，就醫時要說出這個組合。NCCIH 的提醒也是同一個方向，長期使用中國肉桂，對肝病患者等敏感族群可能是問題 <a href="#ref-19">[19]</a>。健檢肝指數已經偏高的人，GOT、GPT 怎麼判讀與下一步，見〈[健檢肝指數（GOT、GPT）偏高，要先複檢還是直接看肝膽科？](/articles/liver-enzymes-got-gpt-high-next-step/)〉。

## 正在吃降血糖藥或降血脂藥的人

**本頁沒有找到肉桂與降血糖藥併用造成低血糖的人體個案；實務上的處理是開始或停止前讓醫師知道，不要用肉桂取代或減少處方藥。**

邏輯很簡單：如果肉桂真有降空腹血糖的作用，疊在胰島素或 sulfonylurea 類這種直接讓血糖下降的藥上，方向是更低；如果沒有作用，就是白花錢。兩種情況都不支持自己減藥。

- 開始吃肉桂膠囊前，把產品帶給開降血糖藥的醫師或藥師看，問清楚要不要調整自我監測的頻率
- 有在家量血糖的人，開始後一兩週多留意數字；出現發抖、冒冷汗、心悸等低血糖症狀，先依醫師教的方式處理
- 同時在吃 statin 的人，告訴醫師你加了肉桂補充品，下次抽血時一起看肝指數
- 選產品時看包裝有沒有寫品種；寫明錫蘭肉桂的，香豆素顧慮較小
- 不要因為吃了肉桂就自己減少降血糖藥或降血脂藥，劑量調整一律跟開藥的醫師或藥師確認

杜仲等其他常被拿來談血壓、血糖的中藥材，各自的證據與交互作用見[杜仲成分頁](/ingredients/eucommia-du-zhong/)；同樣主打控糖、證據相對多的成分，見[小檗鹼成分頁](/ingredients/berberine/)。

## 安全性與注意事項

**料理調味的肉桂量，對一般人不構成問題；需要注意的是每天固定吃膠囊或大量肉桂粉的人，以及孕婦、幼兒與肝病患者。**

- **孕婦**：台灣食品平臺要求標示每日建議量的肉桂產品加標孕婦忌食 <a href="#ref-1">[1]</a>；NCCIH 寫懷孕期間大量吃錫蘭肉桂被認為不安全，哺乳期大量使用的安全性所知甚少 <a href="#ref-19">[19]</a>
- **幼兒**：15 公斤幼兒約 0.5 公克中國肉桂就到容許量 <a href="#ref-7">[7]</a>
- **肝病或肝指數異常**：長期使用中國肉桂可能是問題 <a href="#ref-19">[19]</a>
- **胃炎病人**：草案要求肉桂與桂枝食品標示胃炎病人慎用 <a href="#ref-3">[3]</a>
- **一般副作用**：NCCIH 提到大量或長期使用有時與腸胃不適或過敏反應有關；外用肉桂油或粉可能刺激皮膚 <a href="#ref-19">[19]</a>
- **身上也擦含香豆素的產品**：BfR 提醒香豆素也會從含香豆素的乳液、身體油進入人體 <a href="#ref-7">[7]</a>

## 常見迷思

- **「肉桂是天然香料，吃多少都沒關係」**：中國肉桂每公斤平均約含 3,000 毫克香豆素，成人一天約 2 公克就到容許量 <a href="#ref-7">[7]</a>
- **「肉桂可以取代降血糖藥」**：Cochrane 回顧看不到糖化血色素的改善 <a href="#ref-16">[16]</a>
- **「有標錫蘭肉桂就一定是錫蘭肉桂」**：義大利的市場調查中，標示為肉桂的樣本約一半是 cassia <a href="#ref-13">[13]</a>；本頁沒有台灣市售品的同類調查
- **「台灣土肉桂完全不含香豆素」**：土肉桂葉精油的香豆素遠低於中國肉桂 <a href="#ref-14">[14]</a>，但純露的分析中香豆素佔揮發性成分 4.31% <a href="#ref-15">[15]</a>
- **「肉桂膠囊在台灣是合法保健食品，所以安全」**：食品平臺規定肉桂不得單一原料使用 <a href="#ref-1">[1]</a>，合法上架與適合每天吃是兩件事

## 常見問題

### 每天一茶匙肉桂粉會不會傷肝？

看品種與重量。中國肉桂每公斤平均約含 3,000 毫克香豆素，60 公斤成人一天約 2 公克就到 BfR 的容許量 <a href="#ref-7">[7]</a>；一茶匙肉桂粉的重量隨填裝差異很大，最好用廚房秤量一次。偶爾一兩週超過不構成風險，長期每天大量吃中國肉桂才需要擔心 <a href="#ref-7">[7]</a>。習慣每天吃的人，BfR 建議改用錫蘭肉桂。

### 錫蘭肉桂和中國肉桂怎麼分？

肉桂棒比較好分：中國肉桂是一層厚樹皮捲成的一小捲，錫蘭肉桂的橫切面像雪茄，由多層薄皮捲成 <a href="#ref-7">[7]</a>。磨成粉之後外觀幾乎無法分辨，只能看包裝是否標明 Ceylon cinnamon 或學名 *Cinnamomum verum*。

### 肉桂膠囊包裝上寫孕婦忌食，是什麼意思？

這是食藥署平臺對肉桂（桂皮）產品的標示規定：標示每日建議食用量的茶包、錠狀、膠囊、粉末或液狀產品，販售時要加標「孕婦忌食」 <a href="#ref-1">[1]</a>。它管的是保健品型態，料理用的肉桂粉不在此列。

### 吃 metformin 的人可以吃肉桂嗎？

本頁沒有找到肉桂與 metformin 併用出問題的人體個案。料理用量一般不需擔心；想每天吃肉桂膠囊的人，先讓開藥的醫師知道，並且不要因此自行調整藥量。用胰島素或 sulfonylurea 類藥物的人更要留意低血糖症狀。

### 中藥裡的肉桂、桂枝跟香料肉桂一樣嗎？

來源植物相同，都是中國肉桂，肉桂是樹皮、桂枝是嫩枝 <a href="#ref-3">[3]</a>。中醫處方的用量由中醫師決定；衛福部草案則把它們做成食品時的每人日限量分別訂在 0.5 公克與 1.5 公克 <a href="#ref-3">[3]</a>。

### 土肉桂茶比較安全嗎？

土肉桂葉精油的香豆素含量遠低於中國肉桂 <a href="#ref-14">[14]</a>，但不同加工方式的結果不一，純露中仍測得香豆素 <a href="#ref-15">[15]</a>。土肉桂葉的產品同樣要加標孕婦忌食 <a href="#ref-1">[1]</a>。
