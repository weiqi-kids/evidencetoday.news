## 30 秒認識

- 芝麻素（Sesamin）是芝麻中含量最高的木酚素（lignan），屬於脂溶性的呋喃木酚素（furofuran lignan），與同屬芝麻木酚素家族的芝麻酚林（sesamolin）、芝麻素醇（sesaminol）並列為芝麻的代表性活性成分。 <a href="#ref-1">[1]</a>
- 在台灣與日本，芝麻素常做成與**維生素E併用**的複方錠劑（如坊間熟知的「芝麻明」系列產品），主打助眠、抗疲勞、抗氧化。這個併用設計本身就有研究依據：芝麻木酚素能提升維生素E在血中與組織中的活性。 <a href="#ref-1">[1]</a>
- 一項 8 週雙盲對照試驗顯示，**40 歲以上族群**併用芝麻木酚素與維生素E後，睡眠與外觀相關的主觀量表分數顯著優於安慰劑組；但全體受試者的睡眠改善僅是組內「前後比較」顯著，並未明確優於安慰劑組，證據仍屬初步。 <a href="#ref-4">[4]</a>
- 統合分析（7 項隨機對照試驗、212 人）顯示芝麻素補充可降低總膽固醇、低密度脂蛋白膽固醇與收縮壓，但對高密度脂蛋白膽固醇、三酸甘油酯、舒張壓與體重沒有顯著影響。 <a href="#ref-3">[3]</a>
- 護肝效果目前主要來自**囓齒動物研究**，顯示芝麻素可能促進酒精代謝、減少脂肪肝，但缺乏對應的人體臨床試驗，不能直接套用到人身上。 <a href="#ref-1">[1]</a>

## 基本介紹

芝麻素是芝麻籽與芝麻油中最主要的木酚素，含量通常占芝麻總木酚素的一半左右。 <a href="#ref-2">[2]</a> 木酚素是植物為了自我保護所合成的多酚類化合物，芝麻的木酚素家族除了芝麻素，還有芝麻酚林、芝麻素醇等，彼此結構相近但活性略有差異。芝麻素本身脂溶性高，須隨含脂肪的食物或油脂一起攝取才利於吸收。 <a href="#ref-1">[1]</a>

## 這是什麼？

芝麻素屬於「呋喃木酚素」（furofuran-type lignan），化學上與木質素前驅物相關，是芝麻油、芝麻籽榨油後的殘渣中都能萃取到的成分。它既非維生素，也非必需營養素，本質上屬於**植物次級代謝物**，被歸類在「多酚類抗氧化物」的討論範疇。市售保健品的芝麻素多以芝麻油萃取物或芝麻粕萃取物的形式，標準化為特定比例的芝麻素／芝麻素醇（例如常見的 1:1 比例），再與維生素E等成分複方化。 <a href="#ref-1">[1]</a>

## 在身體裡做什麼？／主要作用機制

芝麻素的機轉研究主要圍繞抗氧化與抗發炎：實驗顯示它能降低活性氧（ROS）與丙二醛（MDA）等氧化壓力指標，並透過抑制 NF-κB 等發炎相關訊息路徑減少促發炎細胞激素的釋放。 <a href="#ref-1">[1]</a> 在肝臟代謝方面，動物實驗發現芝麻素可調節與酒精、脂質代謝相關的肝臟酵素轉錄，這是「護肝」訴求的理論基礎，但多數證據仍停留在囓齒動物層級。 <a href="#ref-1">[1]</a> 另一個常被引用的機制是與維生素E的協同作用：芝麻木酚素能提升 α-生育醇（維生素E的活性形式）在血液與組織中的濃度，這也是市售產品把兩者做成複方的原因。 <a href="#ref-1">[1]</a> 需要強調的是，這些多屬細胞或動物層級的機轉觀察，**不等同於人體臨床療效**；人體研究多以疲勞量表、睡眠主觀評分、血脂與血壓等指標為終點，樣本數普遍偏小。

## 食物來源／常見來源

芝麻素天然存在於芝麻籽與芝麻油中，含量因品種、產地、氣候與加工方式差異極大：研究測得的芝麻籽芝麻素含量從每 100 公克數毫克到數百毫克不等，黑芝麻的木酚素含量通常高於白芝麻；芝麻油（尤其熱榨、小磨香油）的木酚素含量也高於精製或冷壓芝麻油。 <a href="#ref-2">[2]</a> 這也代表：光靠日常吃芝麻醬、香油、芝麻糊，攝取到的芝麻素劑量與濃度很難與臨床試驗使用的萃取物劑量相提並論，實務上仍偏向補充品議題。日常飲食中適量使用芝麻油、芝麻粉的價值，更多在於整體油脂與礦物質（如鈣、鎂）的攝取，而非單一追求芝麻素含量。

## 建議攝取量／常見攝取建議／研究中常見使用方式

芝麻素沒有官方訂定的每日建議攝取量。人體研究中常見的用法是「芝麻木酚素（芝麻素／芝麻素醇各半）約 10 毫克，併用維生素E約 55 毫克」，連續食用 8 週；也有以血脂、血壓為終點的試驗使用較高劑量（多數試驗劑量在每日 200 毫克以下），介入期約 4 到 8 週（28 到 60 天）不等。 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a> 各研究使用的萃取物來源、標準化比例、劑型都不同，很難直接類推「吃多少芝麻素等於研究劑量」；選購產品時建議以「每份芝麻素或芝麻木酚素毫克數」為準，而非只看複方總重量。

## 缺乏風險或攝取不足問題

芝麻素不是必需營養素，**沒有「缺乏症」的概念**。不吃芝麻或不補充芝麻素，並不會造成任何已知的健康缺損。把睡眠不佳、疲勞或肝功能問題直接歸因於「缺芝麻素」並不合理——這些狀況更常與作息、飲酒量、整體飲食型態與睡眠環境有關，補充芝麻素不能取代這些基本調整。

## 補充品常見形式

市售芝麻素產品多為軟膠囊或錠劑，來源是芝麻油或芝麻粕的萃取物，常標示芝麻素與芝麻素醇的比例（如 1:1），並與維生素E、輔酵素Q10或其他抗氧化成分做成複方。 <a href="#ref-1">[1]</a> 複方雖然方便，但也讓效果歸因變得複雜：使用後若感覺睡眠或精神變好，很難判斷是芝麻木酚素還是維生素E（或兩者協同）的貢獻；選購時可留意每份芝麻素的實際毫克數、萃取來源與是否有第三方檢驗，避免只被「熬夜救星」「天然安神」等行銷詞主導判斷。

## 安全性與注意事項

目前人體臨床試驗（多為 4 到 8 週的短期試驗）尚未觀察到明顯的安全疑慮，但長期、大規模的人體安全性資料仍然有限。 <a href="#ref-3">[3]</a> 有幾點需要特別留意：第一，**芝麻是美國 FDA 公告的九大主要食物過敏原之一**（自 2023 年起強制標示），對芝麻過敏者使用芝麻萃取物補充品前應格外謹慎，並向醫師或藥師確認產品的過敏原殘留風險。 <a href="#ref-6">[6]</a> 第二，實驗室研究發現芝麻素可能透過抑制孕烷 X 受體（PXR）而降低 CYP3A4 酵素的活性，而 CYP3A4 是許多常用藥物（如部分降血脂藥、免疫抑制劑）代謝的主要酵素，理論上存在交互作用的可能性，正在服用慢性病藥物者若要長期補充，建議先諮詢藥師或醫師。 <a href="#ref-5">[5]</a> 第三，孕婦、哺乳者與孩童的人體資料極為有限，不建議在缺乏醫療建議下自行使用。

## 常見迷思

- 「芝麻素就是芝麻，過敏的人吃萃取物一定安全」：萃取物仍可能含有殘留蛋白，芝麻過敏者應格外小心，這與「芝麻素本身有無療效」是兩回事。 <a href="#ref-6">[6]</a>
- 「助眠效果等於安眠藥替代品」：目前證據僅來自特定年齡層（40 歲以上）的小型試驗中的主觀量表改善，不是治療失眠的藥物，也不建議拿來取代正規睡眠問題的評估與治療。 <a href="#ref-4">[4]</a>
- 「天然萃取物不會和藥物產生交互作用」：實驗室研究發現芝麻素可能影響 CYP3A4 這個重要的藥物代謝酵素，「天然」不代表沒有交互作用風險。 <a href="#ref-5">[5]</a>
- 「抗氧化指標變好＝實際變健康」：多數研究測的是血中氧化壓力或發炎指標的變化，這類生化指標的改善與心血管疾病、老化等實際健康結果之間，目前還沒有直接的因果證據。 <a href="#ref-1">[1]</a>
