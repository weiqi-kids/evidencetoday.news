## 30 秒認識

- 卵磷脂是磷脂質的混合物，主成分磷脂醯膽鹼，常見大豆、葵花與蛋黃來源 <a href="#ref-1">[1]</a> <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>
- 降膽固醇：1989 年檢視 24 篇研究後的結論是，卵磷脂沒有獨立於其中亞麻油酸之外的作用 <a href="#ref-10">[10]</a>
- 顧記憶：Cochrane 回顧 12 篇隨機試驗，不支持用卵磷脂治療失智 <a href="#ref-12">[12]</a>
- 防塞奶：美國母乳醫學會指引列為強度 C 的建議，依據是試管實驗；LactMed 指出沒有具科學效度的臨床研究 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>
- 台灣把卵磷脂當一般食品原料，沒有任何一張卵磷脂健康食品許可，宣稱降膽固醇或防塞奶屬於醫療效能宣稱 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a> <a href="#ref-4">[4]</a>
- 大豆卵磷脂依台灣規定要標示大豆過敏原 <a href="#ref-5">[5]</a>

## 基本介紹

產後回家第二週，媽媽群組裡最常被轉貼的購物清單上，常有一罐卵磷脂；健檢報告 LDL 紅字的長輩，也可能從親友那裡收到同一罐。同一個成分被期待做兩件幾乎無關的事，這本身就是先停下來查證的理由。

美國國家醫學圖書館的 LactMed 資料庫把卵磷脂描述為膽鹼、膽鹼酯、脂肪酸、甘油、醣脂、三酸甘油酯、磷酸與磷脂質（例如磷脂醯膽鹼）的混合物，這些都是母乳本來就有的成分 <a href="#ref-7">[7]</a>。

這一頁談卵磷脂本身的證據與台灣的管理方式。哺乳期塞奶的照護細節與就醫時機，寫在〈[關於卵磷脂防塞奶，你需要知道的 5 件事](/articles/lecithin-clogged-duct-evidence/)〉；膽鹼的建議量與食物來源，見[膽鹼成分頁](/ingredients/choline/)。這一頁不提供補充劑量。

## 這是什麼？

**卵磷脂是一類磷脂質的混合物，食品工業拿它當乳化劑，讓油和水混在一起。**

食品工業把卵磷脂當作油脂的乳化劑使用 <a href="#ref-9">[9]</a>，保健品則常見大豆與葵花來源 <a href="#ref-8">[8]</a>。台灣食藥署食品原料整合查詢平臺把「卵磷脂」同時列在動物來源與植物來源製取的原料，兩者都是可供食品使用的原料 <a href="#ref-1">[1]</a>。

卵磷脂、膽鹼、磷脂絲胺酸三個名字常被放在一起賣，關係是這樣：

| 成分 | 是什麼 | 跟卵磷脂的關係 | 主要宣稱的證據 |
|---|---|---|---|
| 卵磷脂 | 磷脂質混合物，主成分磷脂醯膽鹼 | 本頁主角 | 降膽固醇、顧記憶都缺乏獨立證據 <a href="#ref-10">[10]</a> <a href="#ref-12">[12]</a> |
| 膽鹼 | 必需營養素，國健署訂有足夠攝取量 | 磷脂醯膽鹼分解後提供膽鹼 <a href="#ref-7">[7]</a> | 缺乏時才需要補，孕期與哺乳期需求較高 <a href="#ref-6">[6]</a> |
| 磷脂絲胺酸 | 細胞膜上的另一種磷脂質 | 台灣的原料由大豆卵磷脂加絲胺酸經酵素反應製成 <a href="#ref-1">[1]</a> | 另見[磷脂絲胺酸成分頁](/ingredients/phosphatidylserine/) |

國健署第八版的膽素（膽鹼）足夠攝取量，19 歲以上男性每天 450 毫克、女性 390 毫克，懷孕各期加 20 毫克，哺乳期加 140 毫克 <a href="#ref-6">[6]</a>。卵磷脂罐子上的毫克數是磷脂質混合物的重量，不能直接當成膽鹼的量看。

## 卵磷脂能降膽固醇嗎？

**目前的證據不支持。早期看到的下降，多半能用研究設計、熱量改變或卵磷脂裡的亞麻油酸解釋。**

荷蘭的 Knuiman、Beynen 與 Katan 1989 年在《美國臨床營養學期刊》檢視了 24 篇卵磷脂與血清膽固醇的研究 <a href="#ref-10">[10]</a>。他們發現多數研究缺乏適當對照組、樣本太小，或者受試者因為多吃卵磷脂而改變了其他飲食；只有 4 篇試驗試著讓兩組的脂肪酸攝取一致 <a href="#ref-10">[10]</a>。結論是沒有證據顯示卵磷脂有獨立於其中亞麻油酸之外的降膽固醇作用 <a href="#ref-10">[10]</a>。也就是說，吃卵磷脂得到的效果，換成等量的植物油大概也一樣。

之後仍有小型研究報告驚人的數字。Mourad 等 2010 年在巴西讓 30 名高膽固醇志願者參加雙盲研究，其中 20 人每天吃一顆 500 毫克大豆卵磷脂，兩個月後報告總膽固醇下降 42%、LDL 下降 56% <a href="#ref-11">[11]</a>。每天半公克的磷脂質帶來這種幅度，樣本又只有 30 人，跟 Knuiman 指出的設計問題放在一起看，很難當作依據；本頁沒有查到後續的大型試驗複製這個結果。

在台灣，這件事有清楚的法規界線：

- 健康食品資料集 570 筆許可證紀錄中，沒有任何一張以卵磷脂為保健功效成分 <a href="#ref-2">[2]</a>
- 依《健康食品管理法》，沒有取得許可的食品不得標示或廣告為健康食品 <a href="#ref-3">[3]</a>
- 一般食品宣稱「降膽固醇」，依認定準則第 5 條屬於「涉及減輕或降低導致疾病有關之體內成分」的醫療效能宣稱 <a href="#ref-4">[4]</a>

健檢報告上的 LDL 怎麼看，見〈[膽固醇報告 4 大指標怎麼看](/articles/cholesterol-report-ldl-hdl-triglycerides/)〉；同樣常被拿來「先吃吃看」的紅麴，風險另有一篇〈[膽固醇偏高可以吃紅麴嗎](/articles/cholesterol-red-yeast-rice-guide/)〉。

## 卵磷脂能顧記憶、預防失智嗎？

**Cochrane 的系統性回顧不支持用卵磷脂治療失智，對記憶的正面結果只有一篇小試驗。**

這個說法的推理是：阿茲海默症患者腦中把膽鹼轉成乙醯膽鹼的酵素不足，卵磷脂是膽鹼的飲食來源，多吃也許能延緩退化 <a href="#ref-12">[12]</a>。

Higgins 與 Flicker 2003 年的 Cochrane 回顧納入 12 篇隨機試驗，對象包括 265 名阿茲海默症患者、21 名巴金森氏症失智患者與 90 名主觀記憶問題者 <a href="#ref-12">[12]</a>。阿茲海默症與巴金森氏症失智都沒有任何試驗報告明確的臨床效益；唯一出現戲劇性正面結果的，是一篇針對主觀記憶問題的試驗 <a href="#ref-12">[12]</a>。作者的結論是隨機試驗證據不支持用卵磷脂治療失智，也不認為值得優先投入大型試驗 <a href="#ref-12">[12]</a>。

在台灣，產品若宣稱「預防失智」，同樣屬於涉及預防疾病的醫療效能宣稱 <a href="#ref-4">[4]</a>。中年以後能做的失智預防，證據比較完整的方向見〈[失智症可以預防嗎](/articles/dementia-prevention-midlife-guide/)〉。

## 哺乳防塞奶：指引寫了什麼、根據是什麼

**美國母乳醫學會 2022 年指引列了口服卵磷脂，推薦強度是最低的 C 級，引用的依據是把卵磷脂加進母乳的試管實驗。**

美國母乳醫學會（Academy of Breastfeeding Medicine）2022 年修訂的第 36 號臨床指引，把過去說的「塞奶」重新定義為乳管發炎與水腫造成的一系列狀況 <a href="#ref-8">[8]</a>。在「減輕發炎與疼痛」的醫療處置中，指引寫到可以口服大豆或葵花卵磷脂，用來減輕乳管發炎並讓乳汁乳化；證據等級 1 到 3，推薦強度 C <a href="#ref-8">[8]</a>。指引採用 SORT 分級 <a href="#ref-8">[8]</a>，在這套系統裡，C 級代表依據是共識、慣例、專家意見、以疾病指標為主的證據或病例系列 <a href="#ref-15">[15]</a>。

指引為這一條引用的實驗，是 Chan 等 2003 年的研究 <a href="#ref-9">[9]</a>：

- 對象是 6 位媽媽捐出的母乳，不是媽媽本人吃卵磷脂
- 把母乳用灌食幫浦慢慢輸送 4 小時以上，模擬管灌餵食，對照組脂肪平均損失 58%，研究者認為是脂肪黏在管路上
- 每 50 毫升母乳直接加 1 公克大豆卵磷脂，脂肪損失降到約 2%；加 0.5 公克則跟沒加差不多

這個實驗回答的是「卵磷脂加進母乳能不能減少脂肪黏管」，跟「媽媽吃卵磷脂能不能讓乳管不發炎」是兩個問題。LactMed 2026 年 7 月的版本寫得很直接：高劑量卵磷脂在哺乳媽媽或嬰兒身上的安全性與效果，沒有具科學效度的臨床研究 <a href="#ref-7">[7]</a>。LactMed 另外提到，補充磷脂醯膽鹼會提高母乳中的膽鹼，但母乳中的磷脂醯膽鹼濃度沒有跟著上升 <a href="#ref-7">[7]</a>。

同一份指引在一般處置裡強調的，是依寶寶需求哺餵、減少使用擠乳器、避免深層按摩、冰敷與止痛藥 <a href="#ref-8">[8]</a>，這些比卵磷脂更優先。乳房紅腫熱痛加劇、發燒或畏寒時要就醫，細節見〈[關於卵磷脂防塞奶，你需要知道的 5 件事](/articles/lecithin-clogged-duct-evidence/)〉。

哺乳期真正可能不足的是膽鹼。LactMed 指出多數哺乳媽媽的膽鹼攝取不足 <a href="#ref-7">[7]</a>，國健署的哺乳期足夠攝取量比平常多 140 毫克 <a href="#ref-6">[6]</a>。蛋黃、黃豆等食物來源，見[膽鹼成分頁](/ingredients/choline/)。

## 台灣怎麼管卵磷脂

**卵磷脂在台灣是一般食品原料，沒有健康食品許可；能怎麼宣稱，看法規不看廣告。**

| 項目 | 台灣的規定 |
|---|---|
| 原料身分 | 可供食品使用之原料，動物與植物來源都列入 <a href="#ref-1">[1]</a> |
| 健康食品許可 | 2026-11-22 下載的資料集中為零 <a href="#ref-2">[2]</a> |
| 宣稱降膽固醇、防塞奶、預防失智 | 屬醫療效能宣稱，一般食品不得使用 <a href="#ref-4">[4]</a> |
| 標示為健康食品 | 須依《健康食品管理法》取得許可 <a href="#ref-3">[3]</a> |
| 大豆來源 | 大豆及其製品為應標示過敏原，豁免清單沒有卵磷脂 <a href="#ref-5">[5]</a> |
| 衍生的磷脂絲胺酸原料 | 由大豆卵磷脂經酵素反應製得，每日食用限量 500 毫克 <a href="#ref-1">[1]</a> |

「通乳」「防塞奶」「清血管」這類字眼出現在卵磷脂產品頁，依認定準則屬於涉及預防、改善症狀的表述 <a href="#ref-4">[4]</a>，看到就該打個問號。

## 大豆過敏的人可以吃卵磷脂嗎？

**大豆卵磷脂的蛋白質極少，但台灣法規仍要求標示大豆；嚴重過敏的人先問過敏科醫師。**

衛福部 2018 年公告、2020 年 7 月起施行的《食品過敏原標示規定》，把大豆及其製品列為 11 項應標示的過敏原之一，豁免項目只有高度提煉或純化的大豆油、混合形式的生育醇及其衍生物、植物固醇與植物固醇酯 <a href="#ref-5">[5]</a>。卵磷脂不在豁免清單裡，所以大豆卵磷脂產品要標示含大豆。

過敏者自己的做法也不一致。Simons 等 2005 年調查美國食物過敏病友會議的參加者，避免大豆的人裡有 38% 連大豆卵磷脂也一併避開；作者把大豆油與大豆卵磷脂歸在「蛋白質含量極少或無關」的成分，提醒標示方式可能讓這些人面臨不必要的飲食限制 <a href="#ref-14">[14]</a>。

實際的做法：對大豆嚴重過敏、曾經休克的人，先問過敏科醫師；想避開大豆的人，可以看標示上的來源，葵花或蛋黃來源的卵磷脂也在市面上 <a href="#ref-1">[1]</a> <a href="#ref-8">[8]</a>。

## 安全性與注意事項

**一般食品裡的卵磷脂沒有安全疑慮；高劑量長期吃的資料少，要注意的是過敏、哺乳期，以及用它取代該做的治療。**

LactMed 指出卵磷脂通常耐受良好，美國 FDA 將其列為一般認為安全的食品成分，但膳食補充品上市前不需要證明安全與有效，標示與實際含量也可能有落差 <a href="#ref-7">[7]</a>。

一個常被問到的疑慮是氧化三甲胺（TMAO）。Tang 等 2013 年在《新英格蘭醫學期刊》發表，健康受試者吃下兩顆水煮蛋與標記的磷脂醯膽鹼後，腸道菌會把其中的膽鹼代謝成 TMAO；在 4,007 名接受心導管檢查的病人中，血中 TMAO 最高四分之一的人，3 年內發生死亡、心肌梗塞或中風的風險是最低組的 2.54 倍 <a href="#ref-13">[13]</a>。這是關聯，不能推論吃卵磷脂補充品會增加心血管風險；但它也提醒，膽固醇偏高、心血管風險高的人沒有理由為了「保護血管」額外吃高劑量卵磷脂。

## 常見迷思

- **「卵磷脂能把血管裡的膽固醇乳化掉」**：檢視 24 篇研究後，沒有證據顯示卵磷脂有獨立的降膽固醇作用 <a href="#ref-10">[10]</a>
- **「卵磷脂是補腦的」**：Cochrane 回顧不支持用卵磷脂治療失智 <a href="#ref-12">[12]</a>
- **「哺乳指引有寫，所以已經證實能防塞奶」**：指引的推薦強度是 C，引用的是試管實驗，LactMed 指出缺乏臨床研究 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a> <a href="#ref-9">[9]</a>
- **「吃卵磷脂等於補膽鹼」**：罐子上的毫克數是磷脂質混合物的重量，不是膽鹼量；補磷脂醯膽鹼主要提高的是母乳中的膽鹼 <a href="#ref-7">[7]</a>
- **「大豆卵磷脂不含大豆，過敏的人不用看標示」**：台灣規定大豆卵磷脂要標示大豆過敏原 <a href="#ref-5">[5]</a>

## 常見問題

### 哺乳期可以吃卵磷脂預防塞奶嗎？

證據很弱。美國母乳醫學會的指引列為推薦強度 C <a href="#ref-8">[8]</a>，依據是把卵磷脂加進母乳的試管實驗 <a href="#ref-9">[9]</a>，LactMed 指出沒有具科學效度的臨床研究 <a href="#ref-7">[7]</a>。哺餵方式、減少擠乳器使用與避免深層按摩是指引更優先的處置 <a href="#ref-8">[8]</a>。想吃之前，可以跟泌乳顧問或婦產科醫師討論。

### 膽固醇高，吃卵磷脂可以代替降血脂藥嗎？

不行。卵磷脂沒有獨立的降膽固醇證據 <a href="#ref-10">[10]</a>，台灣也沒有任何一張卵磷脂健康食品許可 <a href="#ref-2">[2]</a>。要不要吃藥，請醫師依你的整體心血管風險判斷，不要自行用卵磷脂取代或延後。

### 卵磷脂跟膽鹼有什麼不一樣？

膽鹼是營養素，國健署訂有建議量 <a href="#ref-6">[6]</a>；卵磷脂是含有膽鹼的磷脂質混合物 <a href="#ref-7">[7]</a>。想知道自己吃夠沒，看的是膽鹼，見[膽鹼成分頁](/ingredients/choline/)。

### 大豆卵磷脂和葵花卵磷脂哪個比較好？

就降膽固醇、顧記憶、防塞奶來說，兩者都沒有被證實有效，也沒有比較兩種來源的臨床研究；母乳醫學會指引把兩者並列 <a href="#ref-8">[8]</a>。主要差別在過敏：大豆來源要標示大豆過敏原 <a href="#ref-5">[5]</a>。

### 宣稱「通乳」「清血管」的卵磷脂合法嗎？

一般食品宣稱預防、改善疾病或症狀，或宣稱降低膽固醇這類與疾病有關的體內成分，依認定準則屬於醫療效能宣稱 <a href="#ref-4">[4]</a>。台灣目前沒有卵磷脂健康食品，所以也沒有可以合法宣稱保健功效的卵磷脂產品 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>。
