## 30 秒認識

- 攝護腺癌：觀察型研究裡吃得多的人風險低約 12%；隨機試驗太少太小，無法證明吃了能預防 <a href="#ref-6">[6]</a> <a href="#ref-8">[8]</a>
- 美國 FDA 2007 年的審查結論是，茄紅素與降低攝護腺癌風險之間沒有可信證據，番茄則有「非常有限」的證據 <a href="#ref-11">[11]</a>
- 攝護腺肥大：一篇 40 人的小試驗有正面結果，統合分析沒有看到發生率下降 <a href="#ref-7">[7]</a> <a href="#ref-13">[13]</a>
- 番茄糊、番茄醬汁的茄紅素比生番茄高好幾倍，吸收也比較好，搭配油脂吃更好 <a href="#ref-16">[16]</a> <a href="#ref-17">[17]</a> <a href="#ref-22">[22]</a>
- 台灣以添加物形式加入膠囊錠狀食品的茄紅素，每天最多 20 毫克；宣稱預防或改善攝護腺疾病屬於醫療效能宣稱 <a href="#ref-1">[1]</a> <a href="#ref-5">[5]</a>
- PSA 紅字的人吃茄紅素，不能取代複查與泌尿科的判斷

## 基本介紹

藥局架上的「男性保養」複方，成分表常是同一組：鋸棕櫚、南瓜籽、鋅，再加一行茄紅素。PSA 報告拿到紅字的人，常在回診前先買一罐來吃，心想先補著總沒壞處。

茄紅素是讓番茄、西瓜、木瓜變紅的色素，屬於類胡蘿蔔素家族，番茄與番茄製品是最主要的來源 <a href="#ref-6">[6]</a>。

這一頁只談茄紅素。PSA 介於 4 到 10 之間要不要切片，見〈[PSA 驗出 4 到 10 該不該做切片](/articles/psa-4-to-10-gray-zone-biopsy-decision/)〉；攝護腺肥大的分級與治療，見〈[良性攝護腺肥大完整指南](/articles/bph-enlarged-prostate-guide/)〉；同一類複方裡的另外兩個成分，見[鋸棕櫚](/ingredients/saw-palmetto/)與[南瓜籽](/ingredients/pumpkin-seed/)成分頁。這一頁不提供補充劑量。

## 這是什麼？

茄紅素是類胡蘿蔔素的一員，大量存在於番茄與番茄製品、草莓與西瓜中，它被研究的主要理由是推測中的抗氧化作用 <a href="#ref-6">[6]</a>。它跟其他類胡蘿蔔素一樣需要油脂幫忙吸收，同一餐有沒有油，吸收量差好幾倍 <a href="#ref-17">[17]</a>。

在台灣，茄紅素有兩種法規身分：

- **食品原料**：食藥署食品原料整合查詢平臺把番茄果實列為可供食品使用的原料，平臺上沒有單獨以「茄紅素」為名的品項 <a href="#ref-2">[2]</a>
- **營養添加劑**：《食品添加物使用範圍及限量暨規格標準》第八類列有「合成番茄紅素」與「來自 Blakeslea trispora 黴菌發酵的番茄紅素」兩項，限用在補充食品中不足的營養素，膠囊錠狀食品每日不得超過 20 毫克 <a href="#ref-1">[1]</a>

## 攝護腺癌：證據分成兩層

**吃得多的人風險略低，這是觀察到的關聯；吃補充品能預防攝護腺癌，目前沒有隨機試驗證明。**

觀察型研究這一層，最常被引用的是哈佛的醫療專業人員追蹤研究。Giovannucci 等 2002 年分析 47,365 名男性 12 年的資料，2,481 人罹患攝護腺癌；茄紅素攝取最高五分之一的人，風險比最低組低 16%，每週吃兩份以上番茄醬汁的人，比一個月吃不到一份的人低 23% <a href="#ref-10">[10]</a>。

Rowles 等 2017 年把 42 項研究、692,012 名參與者、43,851 例攝護腺癌放在一起：飲食茄紅素高與血中茄紅素高的人，風險都低約 12%，每多吃 2 毫克茄紅素，風險下降約 1% <a href="#ref-8">[8]</a>。但同一份分析裡，茄紅素跟晚期攝護腺癌沒有顯著關聯 <a href="#ref-8">[8]</a>。Chen 等 2015 年的統合分析結果類似，攝取量與風險的負相關要在排除一篇研究或只看高品質研究後才達到統計顯著 <a href="#ref-9">[9]</a>。

隨機試驗這一層薄得多。Cochrane 2011 年的系統性回顧只找到 3 篇試驗、共 154 人，其中兩篇偏誤風險高，茄紅素組跟對照組的 PSA 沒有差異，結論是證據不足以支持或否定 <a href="#ref-6">[6]</a>。Ilic 與 Misso 2012 年把範圍擴大到 8 篇試驗，其中 4 篇可以合併分析，茄紅素沒有顯著降低攝護腺癌的診斷率 <a href="#ref-7">[7]</a>。

美國 FDA 在 2004 年收到兩份健康宣稱申請後做了完整審查，Kavanaugh 等 2007 年發表的結果是：茄紅素與降低攝護腺癌等八種癌症風險之間沒有可信證據；番茄與攝護腺癌、卵巢癌、胃癌、胰臟癌之間有非常有限的證據 <a href="#ref-11">[11]</a>。美國國家癌症研究所 2024 年更新的病友版資料，結論同樣是證據不足以判斷茄紅素能否預防或治療攝護腺癌 <a href="#ref-12">[12]</a>。

| 證據類型 | 代表研究 | 結果 |
|---|---|---|
| 世代研究 | Giovannucci 2002 | 茄紅素最高組風險低 16% <a href="#ref-10">[10]</a> |
| 觀察型研究統合分析 | Rowles 2017 | 低約 12%，晚期癌無顯著關聯 <a href="#ref-8">[8]</a> |
| 隨機試驗系統性回顧 | Cochrane 2011 | 3 篇 154 人，證據不足 <a href="#ref-6">[6]</a> |
| 隨機試驗統合分析 | Ilic 2012 | 8 篇，診斷率無顯著下降 <a href="#ref-7">[7]</a> |
| 監管機關審查 | 美國 FDA 2007 | 茄紅素無可信證據；番茄非常有限 <a href="#ref-11">[11]</a> |

觀察型研究的限制在於，常吃番茄料理的人，其他飲食與生活習慣也可能不同；Giovannucci 的分析雖然校正了蔬果攝取與橄欖油使用 <a href="#ref-10">[10]</a>，仍無法排除所有干擾。這也是為什麼「番茄吃得多」跟「吃茄紅素膠囊」不能畫上等號。

## 攝護腺肥大：一篇小試驗撐起的說法

**支持茄紅素改善攝護腺肥大的人體證據，主要是一篇 40 人、6 個月的試驗。**

Schwarz 等 2008 年在德國讓 40 名經切片確認為良性攝護腺肥大、沒有攝護腺癌的男性，每天吃 15 毫克茄紅素或安慰劑 6 個月 <a href="#ref-13">[13]</a>。結果茄紅素組 PSA 下降，安慰劑組沒變；超音波與肛門指診顯示安慰劑組攝護腺持續變大，茄紅素組沒有；國際攝護腺症狀分數兩組都改善，茄紅素組改善得多 <a href="#ref-13">[13]</a>。作者自己把它定位為先導研究。

Ilic 與 Misso 2012 年統合多篇試驗，茄紅素組攝護腺肥大的發生率跟對照組沒有顯著差異 <a href="#ref-7">[7]</a>。一篇小型正面試驗加上一份陰性統合分析，還不足以讓茄紅素成為攝護腺肥大的治療選項。夜尿、解尿困難的人，評估與藥物選擇見〈[良性攝護腺肥大完整指南](/articles/bph-enlarged-prostate-guide/)〉。

## PSA 偏高的人，吃茄紅素會怎樣

**部分試驗中茄紅素讓 PSA 下降，這是數字的變化；它不會告訴你攝護腺裡有沒有癌。**

Ilic 與 Misso 2012 年的統合分析中，兩篇針對已診斷攝護腺癌男性的試驗合併後，茄紅素組 PSA 平均低 1.58 ng/mL <a href="#ref-7">[7]</a>；Schwarz 2008 年的攝護腺肥大患者 PSA 也下降 <a href="#ref-13">[13]</a>。Cochrane 2011 年的預防試驗則沒有看到 PSA 差異 <a href="#ref-6">[6]</a>。美國國家癌症研究所的整理同樣是「部分研究有、部分沒有」 <a href="#ref-12">[12]</a>。

對拿到 PSA 紅字的人，實際的意思是：

- 吃茄紅素不能取代複查 PSA、肛門指診、影像或切片，泌尿科醫師怎麼安排，照醫師的安排走
- 開始吃含茄紅素的產品、換產品或停吃，回診時說出來，因為 PSA 的變化會被拿來判斷下一步
- 不要因為「已經在補了」就把回診往後延

## 番茄怎麼吃，茄紅素才吃得到

**加工過的番茄製品含量高、吸收好，跟油脂一起吃吸收更多。**

台灣食藥署的食品營養成分資料集沒有茄紅素這個分析項目，下表用美國農業部 FoodData Central 的資料，產品配方與品種跟台灣市售可能不同，看相對高低就好：

| 食物（每 100 公克） | 茄紅素 | 一般份量換算 |
|---|---|---|
| 番茄糊（罐裝，無鹽） | 28.8 毫克 <a href="#ref-22">[22]</a> | 1 大匙約 15 公克，約 4.3 毫克 |
| 番茄醬汁（罐裝） | 13.9 毫克 <a href="#ref-23">[23]</a> | 半杯約 120 公克，約 16.7 毫克 |
| 番茄醬（沾醬） | 12.1 毫克 <a href="#ref-24">[24]</a> | 1 大匙約 15 公克，約 1.8 毫克 |
| 番茄汁（罐裝） | 9.0 毫克 <a href="#ref-25">[25]</a> | 一瓶 280 毫升約 25 毫克 |
| 西瓜 | 4.5 毫克 <a href="#ref-26">[26]</a> | 一片 200 公克約 9 毫克 |
| 生番茄（紅熟） | 2.6 毫克 <a href="#ref-21">[21]</a> | 一顆 120 公克約 3.1 毫克 |
| 木瓜 | 1.8 毫克 <a href="#ref-27">[27]</a> | 一碗 150 公克約 2.7 毫克 |

份量換算是本頁依每 100 公克數值推算的示範，番茄汁以密度接近水估算。台灣那張茄紅素健康食品許可是一款番茄檸檬汁，標示每 280 毫升含 22.8 到 34.2 毫克 <a href="#ref-3">[3]</a>，跟上表的推算落在同一個範圍。

吸收的差異有兩份人體試驗可以參考：

- Gärtner 等 1997 年讓受試者分別吃一份生番茄或番茄糊，番茄糊組的茄紅素高峰濃度是 2.5 倍，總吸收量（曲線下面積）是 3.8 倍 <a href="#ref-16">[16]</a>
- Unlu 等 2005 年在番茄莎莎醬裡加入 150 公克酪梨，茄紅素吸收量是不加酪梨時的 4.4 倍，作者認為主要來自酪梨裡的油脂 <a href="#ref-17">[17]</a>

所以番茄炒蛋、番茄燉牛肉、加了橄欖油的番茄醬汁，茄紅素比生吃番茄片吃得到更多。Giovannucci 的世代研究裡，風險較低的也是番茄醬汁攝取組 <a href="#ref-10">[10]</a>。

## 血壓與血脂：番茄跟膠囊不一樣

**茄紅素補充品有小幅降低收縮壓的證據；降 LDL 的是番茄製品，茄紅素膠囊沒有。**

Cheng 等 2017 年統合 21 項介入試驗，番茄製品讓 LDL 下降 0.22 mmol/L（約 8.5 mg/dL），血管內皮功能也有改善；茄紅素補充品則讓收縮壓平均下降 5.66 mmHg，對血脂沒有顯著效果 <a href="#ref-14">[14]</a>。Li 與 Xu 2013 年統合 6 項試驗，收縮壓下降約 4.95 mmHg、舒張壓沒有顯著變化，次群組分析中每天超過 12 毫克、起始收縮壓高於 120 或亞洲受試者效果較明顯 <a href="#ref-15">[15]</a>。兩份分析的試驗間差異都大，數字要保守看。

台灣唯一有效的茄紅素健康食品許可（衛部健食字第 A00427 號），核可的保健功效是「調節血脂」，宣稱內容是「經動物實驗結果」有助於降低總膽固醇、三酸甘油酯與 LDL <a href="#ref-3">[3]</a>。依《健康食品管理法》，宣稱的保健效能不得超過許可範圍 <a href="#ref-4">[4]</a>；也就是說，這張許可涵蓋的是那一款番茄汁的血脂功效，不延伸到攝護腺，也不延伸到其他茄紅素產品。拿到血脂紅字怎麼看，見〈[膽固醇報告 4 大指標怎麼看](/articles/cholesterol-report-ldl-hdl-triglycerides/)〉。

## 台灣市售茄紅素產品的法規界線

**一般食品不能宣稱顧攝護腺，添加用茄紅素在膠囊錠狀食品每天最多 20 毫克，健康食品要另外取得許可。**

| 產品類型 | 能怎麼標示 | 依據 |
|---|---|---|
| 一般食品、膠囊錠狀食品 | 不得宣稱預防、改善、減輕或治療疾病；以合成或黴菌發酵茄紅素添加時，膠囊錠狀每日 20 毫克以下 | 醫療效能認定準則第 5 條 <a href="#ref-5">[5]</a>、添加物規格標準 <a href="#ref-1">[1]</a> |
| 健康食品 | 只能宣稱核可的保健功效，不得超過許可範圍 | 健康食品管理法第 6、14 條 <a href="#ref-4">[4]</a> |
| 目前有效的茄紅素健康食品 | 1 張，番茄汁，調節血脂 | 健康食品資料集 <a href="#ref-3">[3]</a> |

「保護攝護腺」「改善頻尿」這類字眼出現在一般食品上，依認定準則屬於涉及醫療效能 <a href="#ref-5">[5]</a>。在網路上看到這種宣稱，本身就是一個需要保留的訊號。

## 安全性與注意事項

**從番茄吃到的茄紅素沒有已知的安全疑慮；補充品要注意總量、孕期，以及 PSA 追蹤中的溝通。**

美國國家癌症研究所整理的臨床試驗中，茄紅素的副作用很少，主要是腹瀉、噁心、嘔吐、脹氣與胃部不適，有試驗改成隨餐吃後症狀消失 <a href="#ref-12">[12]</a>。

歐洲食品安全局 2008 年把所有來源（含番茄等天然食物）合計的每日可接受攝取量訂為每公斤體重 0.5 毫克，並指出學齡前與學齡兒童中的高攝取者可能超過 <a href="#ref-18">[18]</a>。以 60 公斤成人換算約每天 30 毫克；如果每天吃一顆 20 毫克的膠囊、再喝一瓶番茄汁，就會超過這條線 <a href="#ref-1">[1]</a> <a href="#ref-25">[25]</a>。

孕期要特別保守。Banerjee 等 2009 年在印度讓 159 名健康初產婦從懷孕 12 到 20 週開始，每天吃 2 毫克茄紅素或安慰劑直到生產：子癲前症沒有減少（兩組都約 18%），茄紅素組早產 10.39%、安慰劑組 1.22%，低出生體重 22.08% 對 9.76% <a href="#ref-19">[19]</a>。這是單一試驗，但足以讓孕婦避開茄紅素補充品。

長期大量吃番茄製品，皮膚可能變橘黃，手掌腳底最明顯。法國 1987 年的病例報告中，一名 21 歲女性吃大量番茄後出現手掌與腳底橘色，作者推測與血中茄紅素過高有關，報告中的病人都沒有通常會造成皮膚變黃的疾病 <a href="#ref-20">[20]</a>。皮膚變黃也可能是肝膽疾病，分不清楚時就醫。

## 常見迷思

- **「茄紅素可以預防攝護腺癌」**：觀察型研究有關聯，隨機試驗證據不足，美國 FDA 認為茄紅素沒有可信證據 <a href="#ref-6">[6]</a> <a href="#ref-8">[8]</a> <a href="#ref-11">[11]</a>
- **「吃了茄紅素 PSA 降下來，就代表沒事」**：PSA 下降不等於排除攝護腺癌，複查與檢查照醫師安排 <a href="#ref-7">[7]</a> <a href="#ref-12">[12]</a>
- **「番茄生吃最營養」**：就茄紅素而言，番茄糊的吸收量是生番茄的好幾倍 <a href="#ref-16">[16]</a>
- **「有健康食品認證的茄紅素顧攝護腺」**：台灣唯一有效的茄紅素健康食品許可是番茄汁，核可功效是調節血脂 <a href="#ref-3">[3]</a>
- **「天然色素，吃多少都沒差」**：歐洲訂有每日可接受攝取量，孕期補充的試驗出現早產增加 <a href="#ref-18">[18]</a> <a href="#ref-19">[19]</a>

## 常見問題

### PSA 偏高，可以先吃茄紅素再回診嗎？

可以吃番茄料理，回診不能延。茄紅素在部分試驗中讓 PSA 下降 <a href="#ref-7">[7]</a>，這會讓數字看起來好一點，但不代表攝護腺裡的狀況改變。回診時把正在吃的保健品都告訴泌尿科醫師。

### 攝護腺肥大，茄紅素跟鋸棕櫚要一起吃嗎？

茄紅素支持攝護腺肥大的人體證據只有一篇 40 人的小試驗 <a href="#ref-13">[13]</a>，統合分析沒有看到發生率下降 <a href="#ref-7">[7]</a>。鋸棕櫚的證據與台灣法規另有一頁說明。複方吃多罐時，記得把茄紅素加總，對照歐洲食品安全局 60 公斤成人約每天 30 毫克的可接受攝取量 <a href="#ref-18">[18]</a>，多罐疊吃怎麼算，見〈[保健品清單成分重疊怎麼檢查](/articles/supplement-list-ingredient-overlap/)〉。

### 吃番茄跟吃茄紅素膠囊，哪個好？

證據比較一致的是番茄製品。觀察到風險較低的是番茄醬汁攝取多的人 <a href="#ref-10">[10]</a>，降 LDL 的也是番茄製品 <a href="#ref-14">[14]</a>；美國 FDA 認為番茄有非常有限的證據，茄紅素沒有 <a href="#ref-11">[11]</a>。番茄還有其他營養素，膠囊只有一種。

### 番茄要煮熟吃嗎？

想吃到茄紅素的話，煮過、加油的番茄料理吸收比較多。番茄糊的吸收量是生番茄的 3.8 倍 <a href="#ref-16">[16]</a>，加入油脂可以再提高 <a href="#ref-17">[17]</a>。

### 女性或孕婦可以吃茄紅素嗎？

一般女性從食物攝取沒有問題。孕期不建議吃補充品，印度的隨機試驗中，孕婦每天 2 毫克茄紅素組的早產與低出生體重比例較高 <a href="#ref-19">[19]</a>。
