## 30 秒認識

- 蜂王乳是工蜂下咽頭腺與大顎腺分泌、用來哺育幼蟲與蜂王的乳白色物質。農業部農業知識入口網蜜蜂主題館由苗栗區農業改良場提供的資料寫出成分比例：新鮮蜂王漿含水 65 至 68%、蛋白質 11 至 14%、脂質 6%、碳水化合物 14 至 17%、灰分 1%、未確定物質 3%。 <a href="#ref-1">[1]</a>
- 品質指標是 10-HDA（10-羥基-2-癸烯酸，俗稱王漿酸或癸烯酸）。同一份官方資料指出它在蜂王漿中的含量介於 1.4 至 2.2%，且是相當穩定的物質。 <a href="#ref-1">[1]</a>
- 新鮮蜂王乳在常溫下極易變質，必須冷凍保存。這一條決定了你在冷凍櫃、冷藏櫃與常溫貨架上看到的產品，本質上是不同的東西。 <a href="#ref-1">[1]</a>
- 效果證據最集中的是血脂。台灣中山醫學大學團隊的 Chiu 等人 2017 年試驗中，40 名輕度高膽固醇成人每天 3150 毫克連續 3 個月，總膽固醇由 207.05 降到 183.15 mg/dL。 <a href="#ref-7">[7]</a>
- 血糖方面兩篇統合分析都是陰性。Mahboobi 2019 算出空腹血糖差異 -0.95 mg/dL（p = 0.69），Bahari 2023 納入 10 篇後整體同樣沒有顯著效果。 <a href="#ref-11">[11]</a><a href="#ref-12">[12]</a>
- 安全性的重點不在肝腎，在過敏。澳洲在 1990 年代通報過蜂王乳誘發氣喘致死的個案，同一群研究者後續追蹤了 7 名服用後出現氣喘或過敏性休克的患者，確認是 IgE 媒介的真過敏反應。 <a href="#ref-20">[20]</a><a href="#ref-17">[17]</a><a href="#ref-18">[18]</a>
- 台灣的品質驗證主要靠台灣養蜂協會的「國產蜂產品證明標章」，該協會於民國 91 年訂定驗證標章管理辦法、94 年取得證明標章註冊，品質檢測項目與標準須符合國家標準與協會自訂的蜂產品審核標準。 <a href="#ref-2">[2]</a>

## 基本介紹

蜂王乳在台灣的消費場景很集中：母親節、更年期、五十歲以後的保養。它同時具備幾個讓人願意付錢的特徵，包括產量稀少（一群蜂一次約產 30 至 50 公克，一年約 3 公斤）、必須冷凍、有一個聽起來很專業的品質指標。 <a href="#ref-1">[1]</a>

蜂王乳的人體試驗數量在天然保健成分中不算少，血脂、血糖、更年期症狀、內皮功能、傷口癒合都有隨機對照試驗，但幾乎全部落在數十人的規模，療程多為 8 週至 6 個月，且分散在伊朗、日本、希臘、斯洛維尼亞與台灣等不同族群。這一頁把可以查證的數字整理出來，同時把兩件本地資訊比較缺乏的事情講清楚：10-HDA 這個指標在實務上怎麼用，以及氣喘與蜂產品過敏者為什麼要把它當成高風險品項。

## 這是什麼？

蜂王乳（royal jelly，中文也寫作蜂王漿、蜂皇漿）由工蜂的下咽頭腺與大顎腺分泌，用於餵養所有幼蟲的頭三天，以及終生餵養蜂王。同樣的受精卵，吃蜂王乳的變成蜂王，吃花粉花蜜的變成工蜂，這個發育差異是蜂王乳所有行銷語言的源頭。要提醒的是，這個現象發生在蜜蜂身上，不能直接推論到人類的生理反應。

成分結構依農業知識入口網蜜蜂主題館的資料：水 65 至 68%、蛋白質 11 至 14%、脂質 6%、碳水化合物 14 至 17%、灰分 1%、未確定物質 3%。 <a href="#ref-1">[1]</a> 蛋白質部分以主要蜂王漿蛋白（major royal jelly proteins，MRJPs）為主，這一群蛋白同時是它的功能成分與主要過敏原，Li 等人 2021 年通報的過敏性休克個案就是由 62 kDa 的 MRJP3 引起。 <a href="#ref-23">[23]</a>

**10-HDA 是怎麼回事。** 10-HDA 的全名是 10-hydroxy-2-decenoic acid，中文寫成 10-羥基-2-癸烯酸，習慣簡稱癸烯酸或王漿酸。它是蜂王乳裡的特徵性中鏈脂肪酸，天然食物中幾乎只在蜂王乳出現，因此被各國拿來當作真偽與品質的判定基準。農業知識入口網給的天然含量範圍是 1.4 至 2.2%，並指出它是非常穩定的物質。 <a href="#ref-1">[1]</a>

實務上這個數字有兩種用途。第一種是判斷有沒有摻假：含量遠低於 1.4% 的產品，可能被稀釋或摻入其他物質。第二種是換算劑型：凍晶（冷凍乾燥）產品因為脫水，重量濃縮，10-HDA 的百分比會高於新鮮品，所以看百分比比較高低沒有意義，要換算成每日實際攝入的毫克數才能比。市售產品若只標「高濃度 10-HDA」而沒有給百分比或每份毫克數，這串文案無法查核。

需要誠實交代的一點：10-HDA 是品質與真偽的指標，它與臨床效果的關係並沒有被劑量效應試驗確立過。上面列出的人體試驗多以「蜂王乳幾毫克」為劑量單位，而不是以 10-HDA 毫克數分組，所以「10-HDA 越高效果越好」目前缺乏直接的人體證據。

## 在身體裡做什麼？／主要作用機制

**類雌激素作用。** 這是討論度最高、也最需要小心的一條。Mishima 等人 2005 年發表於《Journal of Ethnopharmacology》的實驗指出蜂王乳在體外與活體都表現出雌激素樣作用。 <a href="#ref-25">[25]</a> Suzuki 等人 2008 年進一步從蜂王乳分離出數種脂肪酸與一種固醇，測得它們具有雌激素活性。 <a href="#ref-26">[26]</a> 這些成分與雌激素受體的結合力遠低於人體自身的雌二醇，而且相關資料停在細胞與動物層級。Aavani 等人 2024 年的回顧文章整理了蜂王乳與乳癌的荷爾蒙關係，提到較低劑量（低於每公斤體重 200 毫克）可能降低雌激素、提高黃體素，作者群同時指出需要臨床研究來確認安全劑量。 <a href="#ref-27">[27]</a> 用一句話總結目前的位置：機轉上存在雌激素樣活性的訊號，人體上沒有足以判斷風險或效益的資料。

**血脂調節。** 提出的路徑包括抑制腸道膽固醇吸收、影響膽酸排泄、以及蜂王乳脂肪酸本身的作用。Lambrinoudaki 等人 2016 年的研究提到所用的希臘蜂王乳富含中鏈脂肪酸，占乾重脂肪成分的 63%，而中鏈脂肪酸具有降血脂特性。 <a href="#ref-6">[6]</a> 這篇是開放、無對照的前瞻追蹤，36 名停經後健康女性每天 150 毫克連續 3 個月，高密度脂蛋白上升 7.7%、低密度脂蛋白下降 4.1%、總膽固醇下降 3.09%。沒有對照組時，季節、飲食、回歸平均都可能貢獻這些變化。

**抗氧化與抗發炎。** Petelin 等人 2019 年的 60 人試驗測到 C 反應蛋白下降 19%（p = 0.027）與脂聯素上升 34%（p = 0.011）。 <a href="#ref-9">[9]</a> 發炎指標的改變屬於中間指標，它與心血管事件之間還隔著沒有被試驗驗證的距離。

**內皮功能。** Fujisue 等人 2022 年的 100 人雙盲試驗，每天 690 毫克連續 4 週後，反應性充血末梢動脈張力指數上升 21.4%±53.1%，安慰劑組 0.05%±40.9%（p = 0.037）。 <a href="#ref-10">[10]</a> 標準差比平均值還大，代表有些人上升很多、有些人下降，平均值不能當成「每個人都會這樣」。

**促進纖維母細胞遷移。** Kim 等人 2010 年的體外傷口癒合模型觀察到蜂王乳促進人類真皮纖維母細胞遷移，並改變細胞內膽固醇與鞘胺醇含量。 <a href="#ref-16">[16]</a> 這條線在人體試驗上沒有得到支持：Siavash 等人 2015 年以 5% 外用蜂王乳處理 60 個糖尿病足潰瘍，3 個月後各項癒合指標與安慰劑沒有顯著差異。 <a href="#ref-15">[15]</a>

## 食物來源／常見來源

蜂王乳沒有其他天然食物來源，唯一的來源就是養蜂人從王台採收。這也是它價格高的結構性原因：採收必須在幼蟲孵化後約 72 小時內完成，而一群蜂一次只產 30 至 50 公克。 <a href="#ref-1">[1]</a>

要區分的是同一個蜂箱出來的幾種產品：

- **蜂王乳**：工蜂腺體分泌物，含 10-HDA，需冷凍保存。
- **蜂蜜**：花蜜經工蜂轉化與脫水，主成分是糖，不含 10-HDA。
- **花粉**：植物雄蕊產生、由蜜蜂採集，蛋白質與類胡蘿蔔素較高。
- **蜂膠**：蜜蜂採集樹脂加工而成，主要成分是類黃酮與酚酸。
- **蜂王乳凍晶**：新鮮蜂王乳冷凍乾燥後的粉末，做成膠囊或錠劑，可常溫流通。

這五種在過敏原上有部分重疊。Li 等人 2021 年的個案顯示蜂王乳的 MRJP3 與蜂巢有交叉反應。 <a href="#ref-23">[23]</a> 對蜂產品曾有反應的人，把整組產品當作同一個風險群比較安全。

## 建議攝取量／研究中常見使用方式

人體試驗的劑量跨度很大，從每天 150 毫克到 3150 毫克都有，這也是各家產品標示落差極大的原因：

- **Lambrinoudaki 2016（停經後女性血脂）**：每天 150 毫克，3 個月，開放無對照。 <a href="#ref-6">[6]</a>
- **Fujisue 2022（健康志願者內皮功能）**：每天 690 毫克，4 週。 <a href="#ref-10">[10]</a>
- **Sharif 與 Darsareh 2019（更年期症狀）**：每天 1000 毫克，8 週。 <a href="#ref-4">[4]</a>
- **Pourmoradian 2014（第二型糖尿病女性）**：每天 1000 毫克軟膠囊，8 週。 <a href="#ref-13">[13]</a>
- **Khoshpey 2016（第二型糖尿病）**：每天 3 次、每次 1000 毫克，8 週。空腹血糖下降 9.4 mg/dL，安慰劑組上升 4 mg/dL；ApoA-I 上升、ApoB 與 ApoA-I 比值改善。 <a href="#ref-14">[14]</a>
- **Morita 2012（健康志願者長期安全性）**：每天 3000 毫克，6 個月。61 名 42 至 83 歲受試者中 30 人服用蜂王乳、26 人為對照，紅血球數上升（每微升 +0.16×10⁶ 對 -0.01，p = 0.0134），心理健康量表分數改善（+4 對 -7，p = 0.0276）。 <a href="#ref-8">[8]</a>
- **Chiu 2017（台灣，輕度高膽固醇）**：每天 3150 毫克（9 顆 350 毫克膠囊），3 個月，另追蹤 1 個月。 <a href="#ref-7">[7]</a>

**怎麼把產品標示換算成試驗劑量。** 新鮮蜂王乳含水約三分之二，凍晶粉幾乎脫水，同樣寫「1000 毫克」時，兩者的乾物質量相差好幾倍。比較的做法是先看產品標的是新鮮重還是凍晶重，再看有沒有標 10-HDA 的每份毫克數，最後對照上面試驗的劑量級距。廠商標示不足時，這個換算做不出來，這本身就是一項可以拿來比較產品的資訊。

**服用時間。** 傳統建議是早上空腹含在舌下，理由是避免胃酸破壞活性蛋白。沒有任何一篇人體試驗比較過不同服用時間或途徑的效果差異，所以這屬於使用習慣，不是被驗證過的結論。上面列出的試驗多以膠囊口服，Seyyedi 2016 則是陰道用乳膏，兩種途徑的資料不能互相套用。 <a href="#ref-5">[5]</a>

## 缺乏風險或攝取不足問題

蜂王乳沒有缺乏症。它不是人體必需的營養素，長期不吃不會造成任何缺乏。廠商如果暗示「年紀大了就該補」，那是行銷框架，不屬於營養學上的缺乏概念。

更值得先處理的，是被歸因於「需要蜂王乳」的那些症狀本身。四十幾歲開始的月經紊亂、睡不好、關節痛、情緒起伏，可能來自更年期前期，也可能來自甲狀腺、貧血、睡眠呼吸中止或憂鬱，這些各有檢查與處置路徑，判斷順序見〈[四十幾歲月經變亂、睡不好、關節痛，是更年期前期嗎](/articles/perimenopause-or-something-else-in-your-40s/)〉。膽固醇偏高的處理順序同樣有既定作法，可看〈[膽固醇報告 4 大指標怎麼看](/articles/cholesterol-report-ldl-hdl-triglycerides/)〉。想比較各種更年期保健成分的證據強弱，〈[更年期保健食品哪些真的有幫助](/articles/menopause-supplements-what-works/)〉與〈[更年期前中後期的補充需求差異](/articles/menopause-supplement-stages-guide/)〉整理得比較完整。

## 補充品常見形式

- **新鮮蜂王乳（生鮮王乳）**：乳白色膏狀，必須全程冷凍，解凍後盡快用完。 <a href="#ref-1">[1]</a> 活性成分保存最完整，但保存條件最嚴格，運送過程斷鏈的風險也最高。
- **冷凍乾燥凍晶（膠囊或粉末）**：脫水後常溫可流通，10-HDA 的百分比會比新鮮品高，因為分母的水分被移除。比較兩種劑型時要換算成每日實際攝取的毫克數。
- **蜂王乳口服液**：加水稀釋並常添加蜂蜜或糖調味，含糖量需要看營養標示，血糖控制中的人尤其要注意。
- **複方膠囊**：與大豆異黃酮、月見草油、膠原蛋白等成分同包的更年期配方很常見。這類產品的訴求來自各成分的個別資料，要分開評估，相關整理見〈[大豆異黃酮](/ingredients/soy-isoflavones/)〉與〈[月見草油](/ingredients/evening-primrose-oil/)〉。
- **外用製劑**：Siavash 2015 用的是 5% 外用蜂王乳，市售保養品也常添加。外用與口服的證據不能互通。 <a href="#ref-15">[15]</a>

## 台灣的法規與市場實況

**驗證主力在產業自主管理。** 台灣養蜂協會自民國 91 年 3 月 18 日訂定國產蜂產品驗證標章管理辦法，94 年 6 月 1 日取得證明標章註冊。依農糧署中區分署的說明，申請者的所有蜂群須在國內蜜粉源植物地區採集，品質檢測項目、方法及標準須符合國家標準與該協會自訂的蜂產品審核標準，通過資格審查與產品抽驗後才核發。 <a href="#ref-2">[2]</a> 這個標章解決的是產地與基本品質的問題，跟保健功效無關。

**保健功效受《健康食品管理法》管。** 沒有取得健康食品許可證的蜂王乳產品，不能宣稱調節血脂、免疫調節這類保健功效。手上這瓶到底有沒有，可以到食藥署健康食品查驗登記許可證資料查詢輸入產品名稱核對，字號格式與雙軌審查制度在食藥署的健康食品導覽頁有說明。 <a href="#ref-30">[30]</a><a href="#ref-31">[31]</a>

**廣告用語有明確界線。** 「改善更年期不適」「調節荷爾蒙」「抗老回春」這類敘述落在《食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則》要處理的範圍，主管機關的判斷方式是把品名、文字、圖案、影像整體合起來看，不是只挑單一詞句。 <a href="#ref-32">[32]</a> 消費端可以用的檢查法很簡單：包裝正面講得越像藥，越該去查它有沒有許可證。

**冷鏈是台灣通路的實際變數。** 新鮮蜂王乳必須冷凍保存，這一點在官方資料上寫得很清楚。 <a href="#ref-1">[1]</a> 網購與宅配的溫層是否全程維持、到貨時是否仍為凍結狀態，是消費者少數能自己確認的品質環節。到貨已軟化或有水痕的產品，冷鏈很可能斷過。

## 安全性與注意事項

**氣喘與過敏是最重要的一條。** 澳洲在 1994 年通報過蜂王乳誘發氣喘致死的個案。 <a href="#ref-20">[20]</a> 同一時期的《Medical Journal of Australia》也刊出蜂王乳誘發氣喘的報告。 <a href="#ref-21">[21]</a> Leung 等人 1995 年與 Thien 等人 1996 年追蹤了 7 名服用蜂王乳後出現氣喘、部分合併過敏性休克的患者，以蛋白質印跡法測到 18 種不同的 IgE 結合成分，25 至 55 kDa 區帶反應最強，55 kDa 成分在所有反應血清中都出現，確認屬於 IgE 媒介的真過敏反應。 <a href="#ref-17">[17]</a><a href="#ref-18">[18]</a> Rocha Filho 等人 2026 年以藥物警戒資料庫做的系統性回顧同樣指出，蜂產品的不良反應以過敏最常見，其中包含服用蜂王乳後的嚴重氣喘。 <a href="#ref-29">[29]</a> 已知有氣喘、異位性體質或蜂產品過敏史的人，不建議自行嘗試。氣喘本身的控制與急救用藥怎麼分，見〈[氣喘完整指南](/articles/asthma-inhaler-guide/)〉。

**沒有症狀不代表沒有致敏。** Leung 等人 1997 年在香港調查 1472 名醫院員工，461 人（31.3%）曾食用蜂王乳，9 人通報 14 次不良反應；受測的 476 人中有 36 人皮膚試驗陽性，約占 7.4%，作者群指出異位性體質者屬於高致敏風險族群。 <a href="#ref-19">[19]</a> 皮膚試驗陽性的比例明顯高於實際出現症狀的比例，代表致敏是沉默發生的。

**個案的樣貌。** Katayama 等人 2008 年通報一名 26 歲日本女性，本身有氣喘、過敏性鼻炎、結膜炎、異位性皮膚炎與食物過敏史，飲用生蜂王乳飲料後發生過敏性休克，點刺試驗只對蜂王乳有反應、對蜂蜜沒有。 <a href="#ref-22">[22]</a> Li 等人 2021 年通報一名 56 歲女性在一個月內兩次過敏性休克，鑑定出的過敏原是 62 kDa 的 MRJP3，並與蜂巢有交叉反應。 <a href="#ref-23">[23]</a> 主要過敏原的鑑定另見 Rosmilah 等人 2008 年的研究。 <a href="#ref-24">[24]</a> 這些個案的共同點是：多數人有過敏體質背景，而反應可以在第一次或第二次服用時出現。

**荷爾蒙敏感族群。** 蜂王乳在體外與動物實驗表現出雌激素樣活性。 <a href="#ref-25">[25]</a><a href="#ref-26">[26]</a> 有乳癌、子宮內膜癌、子宮肌瘤等荷爾蒙相關病史或正在治療中的人，現有資料無法回答「安全劑量是多少」這個問題，Aavani 等人 2024 年的回顧文章也把確認安全劑量列為待解問題。 <a href="#ref-27">[27]</a> 在這種資料狀態下，把它列入需要先與主治醫師討論的品項比較合理。

**抗凝血藥。** Lee 與 Fermo 2006 年在《Pharmacotherapy》通報一名 87 歲病人在開始服用蜂王乳後 INR 升高到 7.29 並出現出血，作者群認為最可能的解釋是蜂王乳與 warfarin 的交互作用，並指出這是首例報告。 <a href="#ref-28">[28]</a> 單一個案不足以確立因果，但正在服用 warfarin 的人若要加用，應該讓醫師知道並安排 INR 追蹤。這類判斷的通則見〈[慢性病藥和保健食品並用](/articles/chronic-disease-drug-supplement-interaction/)〉。

**手術前。** 因為上述的出血個案報告，術前把蜂王乳一併列入要跟醫師確認的補充品清單較穩妥，作法見〈[開刀前要停哪些保健食品](/articles/stop-supplements-before-surgery/)〉。

**血糖控制中的人。** 蜂王乳本身的統合分析結果是陰性，但口服液型產品常添加糖，這部分要看營養標示的糖量欄位。 <a href="#ref-11">[11]</a>

**孕婦、哺乳與嬰幼兒。** 現有試驗的受試者以成人為主，Morita 2012 的年齡範圍是 42 至 83 歲。 <a href="#ref-8">[8]</a> 孕期、哺乳期與嬰幼兒缺乏安全性資料，加上蜂產品與嬰兒肉毒桿菌症的既有疑慮，一歲以下嬰兒不應餵食任何蜂產品。

**長期服用的資料。** Morita 等人 2012 年的 6 個月試驗是目前少數的長期安全性資料，未通報嚴重不良反應。 <a href="#ref-8">[8]</a> 超過 6 個月的連續服用沒有對應的試驗可以參考。

## 常見迷思

- **「蜂王能活好幾年，所以吃蜂王乳可以抗老」**：同樣的受精卵因為食物不同而發育成蜂王或工蜂，這件事發生在蜜蜂的發育生物學裡。人類服用後的抗老效果沒有對應的人體試驗，現有的長期資料只有 Morita 2012 的 6 個月觀察。 <a href="#ref-8">[8]</a>
- **「10-HDA 百分比越高的產品越好」**：10-HDA 是真偽與品質指標，凍晶產品因為脫水，百分比天然就高於新鮮品。 <a href="#ref-1">[1]</a> 跨劑型比較百分比會得到錯誤結論，要換算成每日毫克數。而且沒有人體試驗以 10-HDA 劑量分組驗證效果。
- **「蜂王乳能調節荷爾蒙、取代荷爾蒙治療」**：雌激素樣活性的資料停在細胞與動物層級。 <a href="#ref-25">[25]</a><a href="#ref-26">[26]</a> 更年期症狀的人體試驗測的是自填量表分數，不是荷爾蒙數值。 <a href="#ref-4">[4]</a> 荷爾蒙治療的評估邏輯完全不同，見〈[美國把荷爾蒙治療的黑框警語拿掉了](/articles/menopause-hormone-therapy-fda-warning-removed/)〉。
- **「天然的蜂產品很安全」**：蜂王乳有記錄在案的氣喘致死個案與多起過敏性休克報告。 <a href="#ref-20">[20]</a><a href="#ref-22">[22]</a><a href="#ref-23">[23]</a> 天然來源與安全性之間沒有必然關係。
- **「蜂王乳可以降血糖」**：兩篇統合分析的整體結果都是陰性，Bahari 2023 只在特定次族群的探索性分析中看到 4.28 mg/dL 的下降。 <a href="#ref-11">[11]</a><a href="#ref-12">[12]</a> 單篇小型試驗的正向結果（例如 Khoshpey 2016 的 50 人）在合併分析後沒有留下來。 <a href="#ref-14">[14]</a>
- **「傷口擦蜂王乳好得比較快」**：體外的纖維母細胞遷移資料是正向的，但唯一一篇人體隨機試驗在糖尿病足潰瘍上得到陰性結果。 <a href="#ref-16">[16]</a><a href="#ref-15">[15]</a>

## 常見問題

### 新鮮蜂王乳跟凍晶膠囊，哪一種比較好？

從活性保存角度，新鮮品沒有經過乾燥加工；從流通穩定角度，凍晶不必依賴冷鏈，斷鏈風險低。官方資料明確寫出新鮮王漿在常溫下極易變質、必須冷凍保存。 <a href="#ref-1">[1]</a> 目前沒有頭對頭比較兩種劑型臨床效果的試驗，所以選擇的依據是你能不能穩定維持冷凍條件，以及產品有沒有揭露每日的 10-HDA 毫克數。

### 有氣喘可以吃蜂王乳嗎？

現有的通報包括致死個案。 <a href="#ref-20">[20]</a> 追蹤研究確認蜂王乳誘發的氣喘與過敏性休克屬於 IgE 媒介的真過敏反應。 <a href="#ref-17">[17]</a><a href="#ref-18">[18]</a> 香港的社區調查也顯示異位性體質者致敏風險較高。 <a href="#ref-19">[19]</a> 有氣喘病史的人不建議自行嘗試；若基於個人理由仍想使用，應該先與過敏免疫科或胸腔科醫師討論。

### 更年期不舒服，吃蜂王乳有用嗎？

Sharif 與 Darsareh 2019 年的 200 人安慰劑對照試驗中，每天 1000 毫克連續 8 週後更年期評分顯著下降，安慰劑組的下降未達顯著。 <a href="#ref-4">[4]</a> 這是目前規模最大的一篇，主要指標是自填量表，觀察期 8 週。陰道用劑型另有 Seyyedi 2016 的 90 人試驗，生活品質面向蜂王乳優於陰道雌激素乳膏，但細胞學上的陰道萎縮改善仍以雌激素較好。 <a href="#ref-5">[5]</a> 把它當成可以嘗試的選項合理，把它當成療效確立的治療則超出資料範圍。

### 有乳癌病史或子宮肌瘤，可以吃嗎？

蜂王乳的雌激素樣活性有體外與動物資料支持，人體上則沒有能回答安全劑量的試驗。 <a href="#ref-25">[25]</a><a href="#ref-26">[26]</a><a href="#ref-27">[27]</a> 在資料空白的情況下，這類決定應該交給正在追蹤你病情的醫師，而不是依產品文案判斷。

### 每天吃多少才夠？

人體試驗的用量從每天 150 毫克到 3150 毫克都有，各自針對不同指標。 <a href="#ref-6">[6]</a><a href="#ref-7">[7]</a> 血脂相關的兩篇試驗劑量差了 21 倍，卻都報告了下降，這代表劑量與效果之間的關係還沒有被釐清。實務上先確認產品標的是新鮮重還是凍晶重，再對照試驗劑量的級距，比看包裝上的建議份量有參考價值。

### 蜂蜜過敏的人一定會對蜂王乳過敏嗎？

不一定。Katayama 等人 2008 年通報的個案，點刺試驗只對蜂王乳有反應、對蜂蜜沒有。 <a href="#ref-22">[22]</a> 但反過來說也成立：對蜂王乳過敏的人可能與蜂巢有交叉反應。 <a href="#ref-23">[23]</a> 蜂王乳的主要過敏原是主要蜂王漿蛋白這一群，跟蜂蜜的成分結構不同。 <a href="#ref-24">[24]</a> 有任何一種蜂產品的反應史，都建議由過敏免疫科釐清致敏對象。

### 買回來要怎麼保存？

新鮮蜂王乳必須放冷凍庫，官方資料寫得很明確。 <a href="#ref-1">[1]</a> 冷藏或常溫存放會加速變質。凍晶膠囊依產品標示保存即可，但要避開高溫與潮濕。收到宅配時如果新鮮品已經軟化或包裝有水痕，代表冷鏈可能中斷過，可以直接向賣方反映。

### 台灣買得到有健康食品認證的蜂王乳嗎？

要自己查才知道。市面上大量蜂王乳產品屬於一般食品，包裝上的「頂級」「純淨」「高濃度」屬於一般食品標示用語，跟功效試驗無關。取得健康食品許可證的產品會有「衛部健食字」或「衛部健食規字」的字號，可以到食藥署的查詢系統輸入產品名稱核對。 <a href="#ref-30">[30]</a><a href="#ref-31">[31]</a> 另外可以看產品有沒有台灣養蜂協會的國產蜂產品證明標章，那處理的是產地與基本品質，跟保健功效是兩件事。 <a href="#ref-2">[2]</a>
