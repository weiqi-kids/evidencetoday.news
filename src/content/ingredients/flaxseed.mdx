## 30 秒認識

- 亞麻仁籽提供的 Omega-3 是 ALA，每 100 公克磨碎的生籽約 21.7 公克；EPA 與 DHA 是零 <a href="#ref-2">[2]</a>
- 人體把 ALA 轉成 DHA 的能力很低：同位素研究在年輕男性身上幾乎測不到，年輕女性估計約 9% <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>
- 想用它取代魚油裡的 DHA 行不通；吃素的人要補 DHA，人體試驗支持的是微藻油 <a href="#ref-12">[12]</a>
- 對血脂、血壓有小幅效果，來自整粒或磨碎的籽，亞麻仁油降膽固醇的效果不明顯 <a href="#ref-14">[14]</a> <a href="#ref-15">[15]</a>
- 整粒吞下去多半原封不動排出；磨碎才吸收得到 ALA <a href="#ref-13">[13]</a>
- 生籽含氰苷，一次大量吃磨碎的生籽要避免；吞嚥困難、腸道狹窄的人不適合，吃藥的人錯開時間 <a href="#ref-5">[5]</a> <a href="#ref-18">[18]</a>

## 基本介紹

素食早餐店的燕麥杯上撒一匙亞麻仁籽粉，常被當成「素食版魚油」。這個說法只對了一半：亞麻仁籽確實是植物裡 Omega-3 含量最高的食物之一，可是它給的是 ALA，魚油給的是 EPA 與 DHA，兩者在身體裡的去處不同。

台灣食藥署的食品營養成分資料集裡，磨碎的生亞麻仁籽每 100 公克含次亞麻油酸 21,744 毫克、膳食纖維 23.1 公克，熱量 524 大卡；同一份資料裡，亞麻仁籽的 EPA 與 DHA 欄位沒有數值，鮭魚與鯖魚才有 <a href="#ref-2">[2]</a>。

這一頁只談亞麻仁籽與亞麻仁油。魚油的 EPA、DHA 怎麼挑，見 [Omega-3 成分頁](/ingredients/omega-3/)；吃素的人還容易缺哪些營養素，見〈[素食者最容易漏掉的 5 個關鍵營養](/articles/plant-based-diet-nutrients-beyond-b12/)〉。這一頁不給補充劑量。

## 這是什麼？

亞麻仁籽是亞麻科植物亞麻的成熟種子，外殼光滑、顏色有褐色與金黃色兩種。台灣食藥署食品原料整合查詢平臺把「亞麻仁」（種子）列在可供直接食用的植物類原料，把「亞麻仁油」列在植物來源製取的原料，兩者都可以當一般食品販售 <a href="#ref-1">[1]</a>。

亞麻仁籽裡跟健康宣稱有關的成分有三類：

- **α-次亞麻油酸（ALA）**：18 個碳的 Omega-3 脂肪酸，人體不能自己合成，屬於必需脂肪酸
- **膳食纖維**：外殼含有大量遇水會變黏的黏質（mucilage），也就是它泡水後滑滑的原因
- **木酚素（lignans）**：植物雌激素的一種，歐洲藥品管理局提到長期食用可能有類雌激素作用 <a href="#ref-18">[18]</a>

另外它含有天然的氰苷，這是植物用來防禦的成分，後面另有一節說明 <a href="#ref-7">[7]</a>。

## 亞麻仁籽能取代魚油嗎？

**取代不了 DHA。ALA 在人體轉成 EPA 有一些，轉成 DHA 極少，男性幾乎測不到。**

Burdge 團隊 2002 年用碳十三標記的 ALA 追蹤 21 天。年輕女性的估計淨轉換比例是 EPA 21%、DPA 6%、DHA 9% <a href="#ref-9">[9]</a>；年輕男性的血漿裡，在 21 天內任何時間點都看不到被標記的 DHA，第一天就有約 33% 的 ALA 直接被當成能量燒掉，從呼氣排出 <a href="#ref-10">[10]</a>。作者比較過去的研究後認為女性的轉換能力可能高於男性，這對懷孕與哺乳時供應胎兒、嬰兒 DHA 可能有意義 <a href="#ref-9">[9]</a>。

國際脂肪酸與脂質研究學會 2009 年的立場回顧結論相同：多吃 ALA 會讓血中與母乳中的 EPA、DPA 上升，對 DHA 幾乎沒有影響，想提高血中 DHA，有效的方法是直接吃現成的 DHA <a href="#ref-11">[11]</a>。

最直接回答「素食者能不能靠植物油補」的是 Lane 等 2022 年的範疇回顧。它納入 2010 到 2020 年的 13 篇隨機試驗，用紅血球裡 EPA 加 DHA 的比例（Omega-3 指數）做比較：高劑量亞麻仁油或藍薊籽油補充品都沒有讓指數上升，部分試驗甚至下降；微藻油則在每一篇試驗中都讓指數上升 <a href="#ref-12">[12]</a>。

| 大西洋鮭魚平均值（去皮，生） | 279 毫克 | 893 毫克 | 1,270 毫克 |
| 鯖魚（生） | 745 毫克 | 2,851 毫克 | 4,503 毫克 |

資料來源是食藥署食品營養成分資料集 <a href="#ref-2">[2]</a>。看這張表要分兩件事：亞麻仁籽的 ALA 是鮭魚的幾十倍，所以要補「Omega-3 總量」很有效率；但它在 EPA、DHA 欄位一片空白，人體轉換又有限，所以它跟魚油是兩種東西。不吃魚的人，每週吃魚的情況怎麼盤點，見〈[魚油與每週吃魚的飲食盤點](/articles/fish-oil-weekly-fish-check/)〉。

## 吃多少算多：拿國健署的範圍來對照

**國健署建議 n-3 脂肪酸占總熱量 0.6% 到 1.2%；一天吃 2,000 大卡的人，大約是 1.3 到 2.7 公克。**

國健署第八版膳食營養素參考攝取量，把 n-3 多元不飽和脂肪酸（含次亞麻油酸、EPA、DHA）的可接受範圍訂為總熱量的 0.6% 到 1.2%，各年齡層一樣 <a href="#ref-3">[3]</a>。以每天 2,000 大卡換算，脂肪每公克 9 大卡，範圍大約落在 1.3 到 2.7 公克。

用食藥署的成分數字推算 <a href="#ref-2">[2]</a>：

| 食物份量 | ALA 約略 | 膳食纖維約略 | 熱量約略 |
|---|---|---|---|
| 磨碎亞麻仁籽 10 公克 | 2.2 公克 | 2.3 公克 | 52 大卡 |
| 亞麻仁油 5 公克 | 2.7 公克 | 0 | 41 大卡 |
| 奇亞子 10 公克 | 2.0 公克 | 3.0 公克 | 48 大卡 |

這張表是換算示範，說明一小份就落在國健署的範圍裡，不是建議每天要吃多少。國健署的範圍把 ALA 與 EPA、DHA 合在一起算，所以就算 ALA 吃夠了，DHA 的缺口仍然存在。

## 磨碎、整粒、榨油，差在哪

**整粒吞下去，ALA 幾乎吸收不到；磨碎或榨油才會讓血中 ALA 上升。**

Austria 等 2008 年讓健康成人每天吃烤進瑪芬裡的亞麻仁籽 3 個月，分成整粒 30 公克、磨碎 30 公克、亞麻仁油（含 6 公克 ALA）三組。一個月後，磨碎組與油組的血漿 ALA 明顯上升，油組更高；整粒組沒有顯著變化 <a href="#ref-13">[13]</a>。三組的 EPA、DHA 都沒有上升 <a href="#ref-13">[13]</a>。腸胃不適在前幾週三組都有，磨碎組後來消失、沒有人退出，整粒組則有服從度問題 <a href="#ref-13">[13]</a>。

| 型態 | 血中 ALA 有沒有上升 | 纖維 | 要留意 |
|---|---|---|---|
| 整粒 | 沒有顯著上升 <a href="#ref-13">[13]</a> | 有 | 沒咬碎多半原粒排出 |
| 磨碎（亞麻仁粉） | 有 <a href="#ref-13">[13]</a> | 有 | 歐盟認為磨碎後直接吃，氫氰酸的暴露較高 <a href="#ref-5">[5]</a> |
| 亞麻仁油 | 有，升幅最大 <a href="#ref-13">[13]</a> | 無 | 降膽固醇的統合分析中效果不顯著 <a href="#ref-14">[14]</a> |

## 血脂與血壓的證據到哪裡

**有小幅下降的證據，幅度遠小於藥物；拿到健檢紅字的人，它可以是飲食的一部分，取代不了醫師的處置。**

血脂方面，Pan 等 2009 年在《美國臨床營養學期刊》統合 28 項隨機試驗。整體來看，總膽固醇下降 0.10 mmol/L、LDL 下降 0.08 mmol/L；拆開看，吃亞麻仁籽本身（原文為 whole flaxseed，相對於油與萃取物）的 LDL 下降 0.16 mmol/L（約 6 mg/dL），木酚素補充品也有效，亞麻仁油沒有顯著效果 <a href="#ref-14">[14]</a>。效果在女性（尤其停經後）與起始膽固醇較高的人比較明顯，HDL 與三酸甘油酯沒有變化 <a href="#ref-14">[14]</a>。報告上 LDL 數字的意義，見〈[膽固醇報告 4 大指標怎麼看](/articles/cholesterol-report-ldl-hdl-triglycerides/)〉。

血壓方面，兩份統合分析的方向一致、幅度不大：

- Ursoniu 等 2016 年：15 項試驗、1,302 人，收縮壓平均下降 2.85 mmHg，舒張壓下降 2.39 mmHg <a href="#ref-15">[15]</a>
- Khalesi 等 2015 年：11 篇研究、14 項試驗，收縮壓下降 1.77 mmHg，舒張壓下降 1.58 mmHg；吃亞麻仁籽本身（相對於油或萃取物）、吃 12 週以上，舒張壓下降較多 <a href="#ref-16">[16]</a>

單一試驗裡效果最大的是加拿大的 FLAX-PAD 研究。Rodriguez-Leyva 等 2013 年讓 110 名周邊動脈疾病患者每天從食物吃進 30 公克磨碎亞麻仁籽，6 個月後收縮壓比安慰劑組低約 10 mmHg；起始收縮壓 140 以上的人，收縮壓下降 15 mmHg <a href="#ref-17">[17]</a>。這是單一族群、每天 30 公克的試驗，不能直接套到一般人一天撒一小匙的情況。

在台灣，食品若在包裝或廣告上宣稱「降血壓」「降膽固醇」，依《食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則》第 5 條屬於涉及醫療效能 <a href="#ref-21">[21]</a>。食藥署健康食品資料集裡，目前沒有任何一張許可證的品名是亞麻仁籽或亞麻仁油 <a href="#ref-20">[20]</a>。

## 生吃亞麻仁籽的氰苷問題

**亞麻仁籽含氰苷，磨碎、咀嚼後會釋出氰化物；要避免的是一次大量吃磨碎的生籽。**

氰苷本身無毒，植物組織被弄破後，裡面的酵素會把它分解出氫氰酸。香港食物安全中心 2007 年檢驗生苦杏仁、竹筍、木薯與亞麻籽，可釋出的氰化物在每公斤 9.3 到 330 毫克之間；切小塊徹底煮沸可以減少九成以上的氰苷，但亞麻籽多半生吃，所以建議只吃少量 <a href="#ref-6">[6]</a>。美國國家輔助與整合健康中心也提醒不要吃生的或未成熟的亞麻仁籽 <a href="#ref-19">[19]</a>。

亞麻仁籽的氰化物釋放比其他高氰苷食物慢。德國聯邦風險評估研究所的 Abraham 等 2016 年讓 12 名健康成人分別吃下含相同 6.8 毫克氰化物當量的木薯、苦杏仁、亞麻仁籽與杏仁糖膏，血中氰化物平均高峰分別是：木薯 15.4 μM、苦杏仁 14.3 μM、亞麻仁籽 5.7 μM <a href="#ref-8">[8]</a>。作者據此認為用同一把尺評估亞麻仁籽可能過度保守 <a href="#ref-8">[8]</a>。

歐洲食品安全局 2019 年的評估，把氰化物的急性參考劑量訂為每公斤體重 20 微克，並針對不同食物的生體可用率另設係數；一般民眾的平均暴露沒有超過，至於長期吃的慢性風險，資料不足無法評估 <a href="#ref-7">[7]</a>。

各地的管理方式差很多：

| 地區 | 亞麻仁籽的氫氰酸規定 |
|---|---|
| 歐盟 | 直接賣給消費者的未加工整粒或磨碎亞麻仁籽，每公斤不得超過 150 毫克；其他 250 毫克；標示「只供烹調烘焙，不得生食」的小包裝可豁免前者 <a href="#ref-5">[5]</a> |
| 香港 | 2007 年風險評估建議生食亞麻籽只吃少量 <a href="#ref-6">[6]</a> |
| 台灣 | 《食品中污染物質及毒素衛生標準》的氫氰酸限量只列木薯粉、即食木薯片與 Gari，沒有亞麻仁籽；亞麻籽另有鎘限量每公斤 0.5 毫克 <a href="#ref-4">[4]</a> |

歐盟在法規前言特別寫到，磨碎後直接吃的亞麻仁籽，氫氰酸的生體可用率與暴露量較高 <a href="#ref-5">[5]</a>。在台灣，市售產品的氰苷含量消費者無從得知，實際做法是：磨粉的量以一小匙為單位、混進食物裡吃，不要一次吞下好幾大匙生粉；加進要煮的粥或湯裡，比直接乾吃生粉保險 <a href="#ref-6">[6]</a>。

## 吞嚥困難與腸阻塞：最容易被忽略的風險

**亞麻仁籽遇水膨脹，水喝不夠可能卡在食道或造成腸阻塞；吞嚥困難、食道疾病、腸道狹窄的人不應該吃。**

歐洲藥品管理局把亞麻仁籽列為治療慣性便秘的草藥，2015 年的專論寫得很具體 <a href="#ref-18">[18]</a>：

- 不應使用：吞嚥困難或喉嚨有問題、食道與賁門疾病、腸道異常狹窄、腸阻塞或腸麻痺、巨結腸
- 服用時配足量液體，之後持續補充水分；水分不足可能在喉嚨或食道膨脹造成噎嗆，也可能腸阻塞
- 吃完出現胸痛、嘔吐、吞嚥或呼吸困難，要立刻就醫
- 不建議 12 歲以下兒童，年長與身體虛弱者使用時要有人照看
- 不要在睡前馬上吃

長輩吞嚥功能退化時，家人常把亞麻仁粉加進流質或直接用湯匙餵，這是風險最高的吃法。長者的食物質地要怎麼調整，見〈[長者吞嚥困難完整指南](/articles/dysphagia-elderly-food-texture-nutrition/)〉。

## 正在吃藥的人要注意什麼

**跟藥物錯開半小時到一小時；吃抗凝血藥的人，要大量固定吃之前先告訴醫師。**

歐洲藥品管理局指出，膨脹性纖維可能延遲同時服用藥物的吸收，建議跟其他藥物間隔半小時到一小時；跟鴉片類止痛藥或止瀉藥 loperamide 這類會減慢腸道蠕動的藥併用，要在醫療監督下進行 <a href="#ref-18">[18]</a>。

抗凝血藥的部分，美國國家輔助與整合健康中心的說法是「理論上」可能與抗凝血或抗血小板藥有交互作用 <a href="#ref-19">[19]</a>。本頁查到的人體資料中，Austria 2008 年的試驗讓健康成人吃 3 個月亞麻仁籽或亞麻仁油，沒有測到血小板凝集改變 <a href="#ref-13">[13]</a>，目前沒有查到亞麻仁籽造成出血的人體試驗或個案。風險看起來不高，但資料也少，吃 warfarin 或抗血小板藥的人要開始固定大量吃之前，跟開藥的醫師或藥師說一聲即可。魚油跟抗凝血藥的狀況不同，見〈[阿斯匹靈和魚油可以一起吃嗎](/articles/aspirin-fish-oil-together-bleeding-risk/)〉。

## 安全性與注意事項

**一般人在菜餚裡少量吃，問題不大；風險集中在一次大量吃生粉、水喝不夠、吞嚥有困難，以及特定疾病與藥物。**

歐洲藥品管理局列出的常見副作用是脹氣，極少數會有過敏反應 <a href="#ref-18">[18]</a>。纖維量一下子增加太多也會腹脹，Austria 2008 年的試驗裡，各組在前幾週都有腸胃不適 <a href="#ref-13">[13]</a>。

孕期與哺乳期的安全性，歐洲藥品管理局認為尚未確立，不建議當藥用 <a href="#ref-18">[18]</a>；美國國家輔助與整合健康中心表示部分研究認為孕期使用可能不安全，但證據不一致 <a href="#ref-19">[19]</a>。荷爾蒙依賴型腫瘤的女性，歐洲藥品管理局不建議長期使用 <a href="#ref-18">[18]</a>。

## 常見迷思

- **「亞麻仁油就是素食魚油」**：亞麻仁油只有 ALA，沒有 EPA 與 DHA，亞麻仁油補充品在試驗中沒有提高 Omega-3 指數 <a href="#ref-2">[2]</a> <a href="#ref-12">[12]</a>
- **「整粒比較天然，營養比較完整」**：整粒常常原粒排出，血中 ALA 沒有上升 <a href="#ref-13">[13]</a>
- **「女性轉換率比較高，吃亞麻仁籽就夠」**：年輕女性的 DHA 轉換估計約 9% <a href="#ref-9">[9]</a>，懷孕哺乳需要 DHA 的階段，國際脂肪酸學會的結論仍是直接吃現成 DHA 才能提高血中濃度 <a href="#ref-11">[11]</a>
- **「天然食物，吃再多都沒關係」**：生籽有氰苷，歐盟為此訂了上限 <a href="#ref-5">[5]</a>；水分不夠還可能卡住食道或腸道 <a href="#ref-18">[18]</a>
- **「亞麻仁油降膽固醇」**：Pan 2009 年的統合分析裡，亞麻仁油組沒有顯著降低膽固醇，有效的是亞麻仁籽本身與木酚素 <a href="#ref-14">[14]</a>

## 常見問題

### 吃素的人，靠亞麻仁籽就能補足 Omega-3 嗎？

ALA 可以補到，DHA 補不到。磨碎亞麻仁籽一小份就有約 2 公克 ALA <a href="#ref-2">[2]</a>，但人體轉成 DHA 的比例很低，男性幾乎測不到 <a href="#ref-10">[10]</a>。人體試驗中能提高血中 EPA 加 DHA 的植物性來源是微藻油 <a href="#ref-12">[12]</a>。素食者其他容易缺的營養素，見〈[「多吃天然蔬食就夠了」是真的嗎](/articles/vegetarian-nutrient-deficiency-guide/)〉。

### 亞麻仁籽要磨碎嗎？

要。Austria 2008 年的試驗中，吃整粒的那組血中 ALA 沒有顯著上升，磨碎組有 <a href="#ref-13">[13]</a>。磨碎後也代表氰苷比較容易釋出，所以一次的量不要多 <a href="#ref-5">[5]</a>。

### 亞麻仁籽可以生吃嗎？會不會氰化物中毒？

偶爾在優格或燕麥裡撒一點，風險低：歐洲食品安全局評估一般民眾的平均暴露沒有超過急性參考劑量 <a href="#ref-7">[7]</a>，德國的人體試驗也顯示亞麻仁籽的氰化物釋放比木薯、苦杏仁慢得多 <a href="#ref-8">[8]</a>。要避免的是一次吃下大量磨碎生粉。歐盟對直接賣給消費者的亞麻仁籽設了氫氰酸上限 <a href="#ref-5">[5]</a>，台灣目前沒有這項限量 <a href="#ref-4">[4]</a>，加進要煮的食物裡吃比較保險 <a href="#ref-6">[6]</a>。

### 在吃抗凝血藥，可以吃亞麻仁籽嗎？

目前只有理論上的疑慮，沒有查到出血的人體證據 <a href="#ref-13">[13]</a> <a href="#ref-19">[19]</a>。飲食中少量吃通常不必改變；要開始每天固定吃大量亞麻仁籽或亞麻仁油時，告訴開藥的醫師或藥師。

### 便秘可以吃亞麻仁籽嗎？

歐洲藥品管理局把它列為可用於慣性便秘的草藥，前提是配足夠的水，並且沒有吞嚥困難、腸道狹窄或阻塞 <a href="#ref-18">[18]</a>。便秘超過三天沒改善，或排便習慣突然改變超過兩週、有不明出血，要先就醫 <a href="#ref-18">[18]</a>。

### 長輩吞嚥不好，可以把亞麻仁粉加進流質裡嗎？

不建議自己決定。歐洲藥品管理局把吞嚥困難列為不應使用的情況，水分不足時可能在食道膨脹 <a href="#ref-18">[18]</a>。有吞嚥問題的長輩，飲食調整請語言治療師或營養師評估。
