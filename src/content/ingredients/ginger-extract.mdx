## 30 秒認識

- 薑萃取物來自薑（Zingiber officinale）的根莖，含薑辣素（gingerols）、薑烯酚（shogaols）等活性成分，是全球最常見的辛香料之一，也長期做為傳統藥用植物使用。 <a href="#ref-1">[1]</a>
- 止吐是薑證據相對集中的用途，但依情境強弱不一：**孕吐**有統合分析支持能改善噁心程度，但對嘔吐次數的幫助不明顯 <a href="#ref-2">[2]</a>；**術後噁心**能降低噁心分數，卻不一定減少實際嘔吐發生 <a href="#ref-4">[4]</a>；**化療所致噁心嘔吐**的研究結果不一致，尚不足以做臨床常規建議 <a href="#ref-3">[3]</a>；**暈車暈船**則多數研究未證實有幫助。 <a href="#ref-1">[1]</a>
- 退化性膝關節炎疼痛與原發性經痛都有正向的統合分析結果，但研究者原文用字都偏保守（如「效果幅度小」「初步性證據」），不宜過度解讀為明確療效。 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>
- 薑可能影響凝血功能：一篇系統性回顧把薑列入可能增加服用**華法林（warfarin）**等抗凝血藥物者出血風險的食物與藥用植物名單之一，服用相關藥物或準備接受手術者，使用高劑量薑萃取物前應與醫療人員討論。 <a href="#ref-7">[7]</a>
- 薑（Zingiber officinale）與薑黃（Curcuma longa）雖同屬薑科（Zingiberaceae），卻是不同屬的不同植物，活性成分（薑辣素／薑烯酚 vs. 薑黃素）與主要研究方向也不同，不宜混為一談。

## 基本介紹

薑原產於熱帶亞洲，現今廣泛栽培於中國、印度、東南亞與非洲等地，食用與入藥的部位是地下根莖。 <a href="#ref-1">[1]</a> 它同時是常見食材與傳統藥用植物：在台灣與東亞飲食中用於去腥、調味、煮薑茶；在傳統醫學脈絡中則長期用於消化不適、感冒與噁心相關的調理。 <a href="#ref-1">[1]</a> 「薑萃取物」通常指以特定溶劑或製程從薑根莖濃縮而成的產品，保留較高濃度的薑辣素、薑烯酚等活性物，濃度遠高於日常食用份量，因此補充品的效果與風險評估，不能直接類比「吃薑」的經驗。

## 這是什麼？

薑的辛辣氣味與活性主要來自兩類相關成分：新鮮薑以「薑辣素（gingerols）」為主，經乾燥或加熱（如曬乾、久煮）後，部分薑辣素會轉化為「薑烯酚（shogaols）」，兩者化學結構相近，但生物活性略有差異，這也是新鮮薑與乾薑、薑粉在傳統用法上有別的原因之一。 <a href="#ref-1">[1]</a> 補充品標示的「薑萃取物」「Ginger extract」多以總薑辣素、薑烯酚或揮發油含量做規格化，市售產品間濃度差異可以很大，選購時需看清楚每份標示濃度與含量，不能只看到「薑萃取物」四個字就假設效果相同。

## 在身體裡做什麼？／主要作用機制

薑的止噁作用被認為與腸胃道及中樞神經的血清素受體調節、促進胃排空有關；對疼痛相關用途，則多聚焦在薑辣素、薑烯酚抑制前列腺素等發炎介質合成路徑的觀察。 <a href="#ref-3">[3]</a> 這些多屬藥理與體外研究層級的機制觀察，實際能否轉化成一致、具臨床意義的止吐或止痛效果，仍要看個別研究的族群、劑量與對照設計，不能直接從「機制上說得通」推論效果一定存在。

## 食物來源／常見來源

新鮮薑、乾薑粉、薑茶、醃薑（如壽司薑片）、薑汁飲品等都含薑的活性成分，但濃度與加工方式差異很大——例如多數市售薑汽水的實際薑含量極低，不能等同研究中使用的濃縮劑量。日常飲食攝取薑的份量通常遠低於臨床試驗所用劑量，兩者效果不宜直接類比。

## 建議攝取量／常見攝取建議／研究中常見使用方式

薑沒有官方訂定的每日建議攝取量。研究中使用的劑量依用途不同差異頗大：孕吐相關試驗多數使用低於每日 1500 毫克的劑量 <a href="#ref-2">[2]</a>；經痛相關試驗多在經期前 3 至 4 天、每日服用 750 至 2000 毫克薑粉 <a href="#ref-6">[6]</a>；關節炎相關試驗雖未有統一劑量報告，但同時觀察到劑量較高的族群較容易因腸胃不適而中途停用試驗。 <a href="#ref-5">[5]</a> 短期、中低劑量的口服使用在多數健康成人中耐受性尚可，但目前沒有一致證據支持「劑量越高效果越好」。

## 缺乏風險或攝取不足問題

薑不是人體必需營養素，不存在「缺乏症」。不攝取薑不會造成任何已知的健康缺損，它的定位始終是辛香料與可選的傳統藥用植物，而不是「缺了就要補」的營養素。把疲勞、消化不良或經痛直接歸因於「缺薑」並不合理。

## 補充品常見形式

市售常見形式包括薑萃取物膠囊、薑粉錠劑、薑萃取液（滴劑），也常與其他消化道保健成分（如薄荷、洋甘菊）做成複方。選購時可留意每份的薑辣素／薑烯酚含量或萃取物標準化比例、劑型是否對應想改善的情境（孕吐、關節不適、經痛等研究多用不同劑量與劑型），以及是否有第三方檢驗；複方產品若出現效果或不適，較難歸因於薑本身。

## 安全性與注意事項

短期口服薑一般被認為耐受性良好，常見副作用是輕微腸胃不適、火燒心、腹瀉與口腔咽喉刺激感。 <a href="#ref-1">[1]</a> 需要特別留意抗凝血／抗血小板交互作用：一篇涵蓋 149 篇文獻、78 種食物與藥用植物的系統性回顧，將薑列入可能增加服用**華法林（warfarin）**者出血風險的名單之一，同時列出的還有銀杏、蔓越莓、綠茶等常見保健品或食物。 <a href="#ref-7">[7]</a> 因此正在服用抗凝血劑、抗血小板藥物，或即將接受手術者，使用高劑量薑萃取物前應告知醫師或藥師。孕期使用少量薑（如緩解孕吐）的相關研究多數未觀察到流產風險明顯升高 <a href="#ref-2">[2]</a>，但哺乳期間的安全資料仍有限，建議先諮詢醫療人員；有膽結石病史者、糖尿病或血壓用藥調整期間也建議留意身體反應，並與醫療人員討論。

## 常見迷思

- 「薑萃取物就是薑黃素」：兩者是不同植物、不同屬的不同成分——薑（Zingiber officinale，薑科薑屬）與薑黃（Curcuma longa，薑科薑黃屬）僅同科不同屬，活性成分與主要研究證據方向都不同，不能互相替代。
- 「吃薑能治好孕吐、根治暈車」：止吐證據因情境而異，孕吐與術後噁心有統合分析支持但效果幅度小、證據品質偏低，暈車相關證據則相對薄弱，不宜期待「吃了就不吐」。 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- 「天然辛香料無限量吃都安全」：日常飲食份量的薑風險低，但高劑量補充品仍有腸胃副作用，也可能與抗凝血藥物產生交互作用，並非「天然就沒有上限」。 <a href="#ref-7">[7]</a>
- 「薑能取代止吐藥或消炎止痛藥」：目前證據多屬輔助、小幅改善層級，沒有研究支持它能取代醫師處方的止吐劑或消炎止痛藥，出現嚴重噁心嘔吐或劇烈疼痛仍應就醫評估，而非自行以薑萃取物替代治療。
