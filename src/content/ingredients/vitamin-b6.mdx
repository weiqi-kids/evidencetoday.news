## 30 秒認識

- 國健署第八版建議量：19 到 50 歲每天 1.5 毫克、51 歲以上 1.6 毫克，懷孕與哺乳各加 0.4 毫克；成人上限攝取量 80 毫克 <a href="#ref-1">[1]</a>
- 食物裡的 B6 以毫克的零點幾計：葵瓜子每 100 公克 1.5 毫克，雞胸肉 0.56 毫克。吃到上限的人，幾乎都是靠補充品 <a href="#ref-5">[5]</a>
- 過量會傷感覺神經：手腳麻、刺痛、走路不穩，停用後恢復緩慢、有時不完全 <a href="#ref-7">[7]</a>
- 上限各國差很多：台灣 80 毫克，歐盟 2023 年降到 12 毫克，澳洲監管機關認為每天 50 毫克甚至更低就可能出現神經病變 <a href="#ref-1">[1]</a> <a href="#ref-6">[6]</a> <a href="#ref-14">[14]</a>
- 在台灣，膠囊錠狀食品每天最多 80 毫克；宣稱療效的藥品，指示藥上限 100 毫克，仿單要寫神經病變風險 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>

## 基本介紹

B 群一罐、綜合維他命一罐、經前保健一罐，晚上再加一包助眠軟糖。每一罐單獨看都合法，標示上的 B6 也都沒超過規定，問題出在沒有人幫你把它們加起來。

維生素 B6 在水溶性維生素裡是個例外。多數人對水溶性維生素的印象是「多的會尿掉」，B6 卻是少數有明確過量傷害的一個：長期吃太多會造成周邊神經病變，症狀跟缺乏時很像 <a href="#ref-7">[7]</a> <a href="#ref-11">[11]</a>。

這一頁只談 B6，重點放在「疊吃」這件事。經前症候群該選 B6、月見草油還是其他方法，比較在〈[月見草油和維生素 B6 差在哪](/articles/pms-vitamin-b6-evening-primrose-guide/)〉；八種 B 群各自做什麼，見[維生素 B 群成分頁](/ingredients/vitamin-b-complex/)；同一個系列裡的 B1，見[維生素 B1 成分頁](/ingredients/vitamin-b1/)。本頁不提供補充劑量建議。

## 這是什麼？

維生素 B6 是一群結構相近的化合物的總稱，包括吡哆醇（pyridoxine）、吡哆醛（pyridoxal）、吡哆胺（pyridoxamine）與它們的磷酸化形式 <a href="#ref-2">[2]</a>。身體真正拿來用的活性形式是磷酸吡哆醛（PLP），它是胺基酸代謝等許多酵素反應的輔酶 <a href="#ref-11">[11]</a>。

補充品與藥品最常用的是鹽酸吡哆辛，也就是吡哆醇的鹽類 <a href="#ref-2">[2]</a> <a href="#ref-4">[4]</a>。台灣《食品添加物使用範圍及限量暨規格標準》列出的 B6 形式至少有十種，從鹽酸吡哆辛、吡哆醛、磷酸吡哆醛到吡哆醇-5-磷酸，在膠囊錠狀食品裡的每日總量上限都是 80 毫克 <a href="#ref-2">[2]</a>。

**成人每天 1.5 毫克，51 歲以上 1.6 毫克；成人上限攝取量 80 毫克，兒童更低。**

國健署第八版膳食營養素參考攝取量總表 <a href="#ref-1">[1]</a> 中，維生素 B6 的數字如下：

| 年齡 | 建議量（男） | 建議量（女） | 上限攝取量 |
|---|---|---|---|
| 0 至 6 月 | 足夠攝取量 0.1 毫克 | 同左 | 未訂 |
| 7 至 12 月 | 足夠攝取量 0.3 毫克 | 同左 | 未訂 |
| 1 至 3 歲 | 0.5 毫克 | 0.5 毫克 | 30 毫克 |
| 4 至 6 歲 | 0.6 毫克 | 0.6 毫克 | 40 毫克 |
| 7 至 9 歲 | 0.8 毫克 | 0.8 毫克 | 40 毫克 |
| 10 至 12 歲 | 1.3 毫克 | 1.3 毫克 | 60 毫克 |
| 13 至 15 歲 | 1.4 毫克 | 1.3 毫克 | 60 毫克 |
| 16 至 18 歲 | 1.5 毫克 | 1.3 毫克 | 80 毫克 |
| 19 至 50 歲 | 1.5 毫克 | 1.5 毫克 | 80 毫克 |
| 51 歲以上 | 1.6 毫克 | 1.6 毫克 | 80 毫克 |

建議量與上限之間差了五十倍，看起來空間很大。但這個「上限」各國的判斷差異極大，下一節會談到。

## 台灣常見食物的 B6 含量

**一般飲食的 B6 以零點幾毫克計，靠吃飯不可能吃到上限。**

下表取自食藥署食品營養成分資料集的分析值 <a href="#ref-5">[5]</a>：

| 食物（每 100 公克） | 維生素 B6 |
|---|---|
| 原味葵瓜子（去殼，熟） | 1.50 毫克 |
| 開心果（熟） | 1.20 毫克 |
| 豬肝（生） | 0.78 毫克 |
| 黃豆（乾） | 0.72 毫克 |
| 鮪魚生魚片 | 0.63 毫克 |
| 大西洋鮭魚（平均值，生） | 0.62 毫克 |
| 虱目魚（平均值，去皮，生） | 0.57 毫克 |
| 去皮雞胸清肉（平均值，生） | 0.56 毫克 |
| 鷹嘴豆（乾） | 0.55 毫克 |
| 豬小里肌（生） | 0.47 毫克 |
| 糙稉米（平均值，生） | 0.14 毫克 |
| 雞蛋（平均值，生） | 0.11 毫克 |

雞胸肉、鮭魚各吃 100 公克，大約是 1.2 毫克，接近成人一天建議量的八成。反過來看，要從食物吃到 80 毫克，得吃下五公斤以上的葵瓜子。歐盟食品安全局 2023 年的評估也是同一個結論：一般歐洲人的飲食不太可能超過上限，例外是固定服用高劑量 B6 補充品的人 <a href="#ref-6">[6]</a>。

## 上限為什麼各國差這麼多

**台灣的成人上限是 80 毫克，歐盟是 12 毫克，差了將近七倍，差別來自對「多少劑量開始傷神經」的判斷。**

1983 年，Schaumburg 等人在《新英格蘭醫學期刊》報告 7 名長期每天服用高劑量 B6 的成人，出現步態不穩與嚴重的感覺神經功能障礙，其中 4 人嚴重失能，停用後全部好轉，作者呼籲為這種被大量濫用的維生素訂出安全使用準則 <a href="#ref-9">[9]</a>。MSD Manual 至今仍把每天超過 500 毫克列為造成毒性的大劑量 <a href="#ref-7">[7]</a>。

之後的爭議集中在低劑量。歐盟食品安全局 2023 年重新評估，認為人體資料無法定出「最低觀察到傷害的劑量」，於是從一份病例對照研究取每天 50 毫克為參考點，再除以 4 的不確定係數，算出 12.5 毫克；另以狗的實驗推算出 11.7 毫克，取兩者中間值向下取整，訂出成人（含孕婦與哺乳婦女）上限 12 毫克 <a href="#ref-6">[6]</a>。兒童上限依體型縮放：4 到 11 個月 2.2 到 2.5 毫克、1 到 6 歲 3.2 到 4.5 毫克、7 到 17 歲 6.1 到 10.7 毫克 <a href="#ref-6">[6]</a>。

澳洲的監管機關 TGA 走得更遠。RACGP 新聞報導，TGA 2025 年 11 月的最終決定是，每日建議劑量 50 到 200 毫克的 B6 產品自 2027 年 6 月起只能在藥師諮詢後購買，超過 200 毫克維持處方藥，50 毫克以下才能在一般通路販售；TGA 的報告寫到「部分人每天攝取 50 毫克甚至更低，就可能出現周邊神經病變」，截至 2025 年 10 月 31 日已累計 250 件神經病變相關通報，其中 130 件在 2025 年 <a href="#ref-14">[14]</a>。澳洲自 2022 年起已要求每日超過 10 毫克的產品標示神經病變警語 <a href="#ref-14">[14]</a>。

荷蘭的通報系統同樣自 2014 年起累積了超過 50 起補充 B6 後出現感覺神經疼痛的個案 <a href="#ref-11">[11]</a>。

| 規範 | 成人每日 B6 | 依據 |
|---|---|---|
| 國健署建議量 | 1.5 至 1.6 毫克 | 第八版 DRIs <a href="#ref-1">[1]</a> |
| 歐盟食品安全局上限 | 12 毫克 | 2023 年評估 <a href="#ref-6">[6]</a> |
| 澳洲一般通路可販售 | 50 毫克以下（2027 年 6 月起） | TGA 最終決定 <a href="#ref-14">[14]</a> |

| 台灣膠囊錠狀食品上限 | 80 毫克 | 食品添加物規格標準 <a href="#ref-2">[2]</a> |
| 台灣「不以藥品列管」上限 | 80 毫克，不得宣稱療效 | 口服藥品基準表 <a href="#ref-3">[3]</a> |
| 台灣指示藥上限 | 100 毫克，仿單須加註神經病變風險 | 口服藥品基準表 <a href="#ref-3">[3]</a> |

## 為什麼吃太多 B6，症狀反而像缺乏

**目前最被接受的解釋是：大量的吡哆醇會卡住身體把 B6 轉成活性形式的那一步。**

Vrolijk 等 2017 年的細胞實驗，把五種 B6 形式分別加到神經細胞株，只有吡哆醇造成濃度相關的細胞死亡，其他形式沒有；吡哆醇同時抑制了兩種需要活性 B6 的酵素 <a href="#ref-11">[11]</a>。作者的解讀是，沒有活性的吡哆醇跟活性的磷酸吡哆醛互相競爭，所以補太多的結果，看起來像 B6 不夠。

Hadtstein 與 Vrolijk 2021 年的回顧進一步整理機轉，認為高濃度的吡哆醇可能抑制吡哆醛激酶，進而干擾周邊感覺神經的 GABA 訊號傳遞，最終造成神經退化 <a href="#ref-10">[10]</a>。吡哆醇不容易通過血腦屏障，這可以解釋為什麼受傷的是周邊的感覺神經，中樞神經相對不受影響 <a href="#ref-10">[10]</a>。這套機轉還在研究中，但它說明了一件實用的事：手腳麻的人自己加吃 B 群想「補神經」，有可能讓問題更嚴重。

## 疊吃試算：把家裡每一罐加起來

**每一罐標示上的 B6 乘上每日份數，全部相加，再跟 80 毫克與 12 毫克兩條線對照。**

下表是示範用的假設數字，不代表任何特定產品。請把右邊兩欄換成你手上產品的標示：

| 產品類型（示範） | 每份 B6 | 每日份數 | 每日 B6 | 你的產品 |
|---|---|---|---|---|
| 高單位 B 群 | 50 毫克 | 1 | 50 毫克 | |
| 綜合維他命 | 2 毫克 | 1 | 2 毫克 | |
| 經前保健複方 | 25 毫克 | 1 | 25 毫克 | |
| 助眠或舒壓軟糖 | 5 毫克 | 2 | 10 毫克 | |
| **合計** | | | **87 毫克** | |

這個示範組合裡，沒有一罐超過台灣食品 80 毫克的上限，加起來卻超過了國健署的上限攝取量，是歐盟上限的七倍多。看標示時注意三件事：

- 標示可能寫「維生素 B6」「吡哆醇」「鹽酸吡哆辛」「pyridoxine HCl」「P-5-P」或「磷酸吡哆醛」，都要算進去
- 看清楚是「每份」還是「每日」，一天吃兩顆的產品要乘以二
- 國外買的產品依當地規定生產，劑量可能高於台灣食品的 80 毫克上限。澳洲高劑量 B 群的情況整理在〈[澳洲保健品帶回台灣](/articles/australia-supplements-bring-back-taiwan/)〉

家裡的保健品清單怎麼整理、哪些成分最容易重複，見〈[保健品清單成分重疊怎麼檢查](/articles/supplement-list-ingredient-overlap/)〉。

## 神經病變的早期症狀清單

**出現下列任何一項，而你正在吃含 B6 的補充品，先把所有產品帶給醫師看，不要自己再加量。**

- 腳底或手指麻木、刺痛、灼熱感，兩側大致對稱
- 感覺範圍像穿了襪子、戴了手套 <a href="#ref-7">[7]</a>
- 走路不穩，醫學上稱為感覺性運動失調 <a href="#ref-7">[7]</a> <a href="#ref-9">[9]</a>
- 對腳趾位置、震動的感覺變遲鈍 <a href="#ref-7">[7]</a>

MSD Manual 寫明 B6 毒性的治療就是停用，但恢復緩慢、有時不完全 <a href="#ref-7">[7]</a>。

劑量不高也不代表一定沒事。Paluszny 與 Qiu 2023 年報告一名 73 歲男性，神經病變持續惡化 3 年，血中 B6 濃度 259.9 nmol/L（參考範圍 20 到 125），他只吃一顆含 6 毫克 B6 的綜合維他命 <a href="#ref-12">[12]</a>。這是單一個案，無法推論多少比例的人會這樣，但它提醒醫師與病人，手腳麻找不到原因時，補充品清單值得被問到。

## 誰可能真的需要 B6

**缺 B6 的情況集中在特定藥物、酒精與透析，處理方式是醫師處方，不是自己挑一罐 B 群。**

MSD Manual 列出的缺乏原因包括：會讓 B6 失去活性的藥物，例如抗癲癇藥、結核病藥 isoniazid、cycloserine、hydralazine、皮質類固醇與 penicillamine；酒精使用疾患；血液透析時的流失；以及營養不良與吸收不良 <a href="#ref-8">[8]</a>。缺乏時會出現周邊神經病變、皮膚炎、舌炎、口角炎，成人也可能出現意識混亂與癲癇 <a href="#ref-8">[8]</a>。

服用 isoniazid 的人，MSD Manual 建議多數同時口服 B6 每日 30 到 50 毫克 <a href="#ref-8">[8]</a>。在台灣，這通常已經包含在結核病的處方裡，不需要另外買 B 群疊上去。

## 台灣藥局的 B6：食品、指示藥、處方藥三條線

**同樣是 B6，每天 80 毫克以下、不宣稱療效可以當食品賣；宣稱療效就是藥品，指示藥上限 100 毫克。**

食藥署 2024 年 4 月修正發布的「含維生素或礦物質之口服藥品基準表」把 B6 分成三段：每日用量不超過 80 毫克的產品得不以藥品管理，但不得宣稱療效；宣稱療效、每日不超過 100 毫克的列為指示藥，仿單應加註「潛在周圍神經病變風險」的警語；超過 100 毫克列為處方藥 <a href="#ref-3">[3]</a>。

2026 年 11 月 22 日下載食藥署全部藥品許可證資料集，未註銷且未逾有效期、主成分含吡哆醇或吡哆醛的許可證有 440 張，其中指示藥 253 張、須由醫師處方使用 85 張、限由醫師使用 100 張，絕大多數是複方；B6 單方只有 22 張，口服錠多為 50 毫克，核准適應症常見「維生素 B6 缺乏症」與「妊娠嘔吐」 <a href="#ref-4">[4]</a>。另有 2 張是 doxylamine 合併 pyridoxine 的膜衣錠，適應症是妊娠婦女噁心嘔吐的緩解，兩張都是處方藥 <a href="#ref-4">[4]</a>。

這裡有一個容易被忽略的落差：藥局裡宣稱療效的 B6 單方指示藥錠多為 50 毫克，而一罐不宣稱療效的食品膠囊，每日可以合法裝到 80 毫克 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>。法規管的是「能不能說它治病」，不是「吃多少比較安全」。

## 安全性與注意事項

**B6 的風險幾乎全部來自補充品，而且是累積出來的。**

國健署的成人上限是 80 毫克 <a href="#ref-1">[1]</a>，歐盟是 12 毫克 <a href="#ref-6">[6]</a>，澳洲監管機關認為 50 毫克以下也可能出現神經病變 <a href="#ref-14">[14]</a>。各國劃線不同，方向一致：長期、高劑量、多產品疊加，是神經病變的主要背景。

懷孕初期噁心嘔吐，台灣有核准妊娠嘔吐適應症的 B6 藥品 <a href="#ref-4">[4]</a>，劑量與療程由產科醫師決定。兒童的上限比成人低得多，1 到 3 歲只有 30 毫克 <a href="#ref-1">[1]</a>，成人 B 群不適合分給孩子吃。

## 常見迷思

- **「B6 是水溶性的，吃多會尿掉」**：B6 是少數有明確過量傷害的水溶性維生素，長期過量會造成感覺神經病變 <a href="#ref-7">[7]</a> <a href="#ref-9">[9]</a>
- **「手腳麻就是缺 B 群，多吃一點就好」**：B6 過量的症狀就是手腳麻，加量可能讓情況更糟 <a href="#ref-7">[7]</a> <a href="#ref-11">[11]</a>
- **「每一罐都合法，一起吃就沒問題」**：台灣管的是單一產品的上限 <a href="#ref-2">[2]</a>，疊加的總量要自己算
- **「經前症候群吃 B6 有實證，劑量越高越好」**：Wyatt 1999 年的回顧納入的試驗品質偏低，推論上限是每日 100 毫克 <a href="#ref-13">[13]</a>，已經是歐盟成人上限的八倍多 <a href="#ref-6">[6]</a>
- **「活性型 P-5-P 比較安全，不用算」**：細胞實驗中造成神經毒性的是吡哆醇 <a href="#ref-11">[11]</a>，但人體上限是以 B6 總量訂的，台灣食品標準也把磷酸吡哆醛一起算進 80 毫克 <a href="#ref-2">[2]</a>

## 常見問題

### 我同時吃 B 群和綜合維他命，B6 會超標嗎？

要看標示上的數字。把兩罐的 B6 毫克數各自乘上每天吃的份數再相加，跟國健署的成人上限 80 毫克 <a href="#ref-1">[1]</a> 比較；想保守一點，可以參考歐盟的 12 毫克 <a href="#ref-6">[6]</a>。

### 經前症候群吃 B6，要吃多少？

本頁不提供劑量建議。Wyatt 1999 年的系統性回顧顯示 B6 對經前症狀有改善訊號，但試驗品質偏低，推論的劑量上限是每日 100 毫克 <a href="#ref-13">[13]</a>，高於歐盟 12 毫克與台灣 80 毫克的上限 <a href="#ref-1">[1]</a> <a href="#ref-6">[6]</a>。要長期吃之前先跟醫師討論，選擇比較見經前症候群那一篇。

### 已經手腳麻了，停掉 B6 就會好嗎？

有機會好轉，但不保證。Schaumburg 1983 年的 7 名患者停用後全部好轉 <a href="#ref-9">[9]</a>，MSD Manual 則提醒恢復緩慢、有時不完全 <a href="#ref-7">[7]</a>。手腳麻的原因很多，糖尿病、B12 缺乏、甲狀腺問題都可能，請帶著所有補充品去看神經內科或家醫科，讓醫師一起評估。

### 可以抽血驗 B6 嗎？

可以，MSD Manual 提到最常用的是血中磷酸吡哆醛濃度 <a href="#ref-8">[8]</a>，但一般健康檢查通常不包括。懷疑過量時，醫師會依症狀、補充品清單與檢驗一起判斷。

### 懷孕想吐，可以自己買 B6 來吃嗎？

台灣有核准妊娠嘔吐適應症的 B6 單方藥品，也有 B6 合併 doxylamine 的處方藥 <a href="#ref-4">[4]</a>。孕期用藥請由產科醫師決定，並且讓醫師知道你還吃了哪些孕婦維他命，避免重複。

### 小孩可以吃大人的 B 群嗎？

不建議。國健署的兒童上限，1 到 3 歲 30 毫克、4 到 9 歲 40 毫克 <a href="#ref-1">[1]</a>，歐盟的兒童上限更低，1 到 6 歲只有 3.2 到 4.5 毫克 <a href="#ref-6">[6]</a>。一顆成人高單位 B 群就可能超過。
