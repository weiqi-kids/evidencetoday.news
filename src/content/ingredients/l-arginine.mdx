## 30 秒認識

- 精胺酸（L-Arginine）是一氧化氮合成酶（NOS）的受質，被轉換成一氧化氮後能促使血管平滑肌放鬆、血管擴張，這是它被包裝成循環保健品的理論基礎。 <a href="#ref-2">[2]</a>
- 它屬於條件必需胺基酸：健康成人體內能自行合成，壓力、創傷、感染或某些疾病狀態下需求量上升，才會出現「體內合成不夠用」的情況。 <a href="#ref-1">[1]</a>
- 口服精胺酸在到達血液循環前，有相當比例會被腸道與肝臟中的精胺酸酶分解掉，真正發揮作用的量打了折扣，這也是「瓜胺酸」被提出作為替代路線的原因。 <a href="#ref-5">[5]</a>
- 運動表現上，統合分析顯示對有氧表現的效應量中大、對無氧表現的效應量偏小；但另一篇針對力量訓練急性補充的統合分析找不到顯著效果，兩者結論不一致，跟運動類型與補充方式有關。 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a>
- 安全性上多數人耐受良好，但皰疹病史者、急性心肌梗塞後患者、準備手術者有具體需要留意的風險，不是「保健食品不是藥，隨便吃都沒事」。 <a href="#ref-9">[9]</a> <a href="#ref-11">[11]</a>

## 基本介紹：必需胺基酸，還是條件必需？

精胺酸不在「九種必需胺基酸」名單裡，教科書上的分類是條件必需胺基酸（conditionally essential amino acid）。健康成人的腸道與腎臟能透過鳥胺酸循環自行合成足夠的精胺酸，日常飲食正常就不會缺乏。 <a href="#ref-1">[1]</a> 它會從「可自行合成」變成「需要額外攝取」的情況，常見於嬰兒期（代謝路徑尚未成熟）、嚴重創傷、燒傷、感染，或某些先天代謝疾病，這些情境下身體需求量超過自行合成的速度。 <a href="#ref-1">[1]</a> 一般健康成人想靠補充品把精胺酸拉高到超越正常生理濃度，目的通常是想追求血管擴張或運動表現這類「額外效果」，而非補足生理上的不足，這跟「補充必需營養素」是兩件不同的事，評估的角度也不一樣。

標示上常見 L-Arginine 或 L-Arginine HCl（鹽酸鹽形式），兩者提供的都是精胺酸本身，差異主要在穩定性與溶解度，不影響它在體內的作用路徑。

## 在身體裡做什麼：一氧化氮路徑

精胺酸最常被討論的角色是作為一氧化氮合成酶（NOS）的受質。NOS 把精胺酸氧化，產物是一氧化氮與瓜胺酸；一氧化氮擴散進入血管平滑肌細胞後，活化可溶性鳥苷酸環化酶，提高細胞內環磷酸鳥苷（cGMP）濃度，促使平滑肌放鬆，達到血管擴張效果。 <a href="#ref-2">[2]</a> 這條路徑同時受到精胺酸酶（arginase）的競爭：精胺酸酶把精胺酸轉成尿素與鳥胺酸，跟 NOS 搶同一批受質，精胺酸酶活性較高時，能轉入一氧化氮路徑的精胺酸比例就會下降。 <a href="#ref-5">[5]</a> 這也解釋了為什麼口服精胺酸後，血中一氧化氮相關指標的變化往往不如直接推算的那麼大，原因是腸道與肝臟的精胺酸酶會先分解掉一部分。 <a href="#ref-5">[5]</a>

除了一氧化氮路徑，精胺酸也是尿素循環的中間產物、多胺類（polyamine）與肌酸合成的原料，在細胞增生與組織修復相關的代謝網路裡都有參與，但保健食品市場幾乎只強調血管擴張這一條路徑。 <a href="#ref-1">[1]</a>

## 食物來源

精胺酸廣泛存在於蛋白質含量高的食物中，紅肉、禽肉、海鮮、蛋、乳製品都含有精胺酸；植物性來源則以堅果（南瓜子、核桃、杏仁）、種子、黃豆與其他豆類、全穀類為主。 <a href="#ref-1">[1]</a> 由於精胺酸的合成與攝取管道同時存在（飲食攝取＋體內自行合成），健康、飲食均衡的人幾乎不需要特別計算「吃了多少精胺酸」，這跟維生素 C 這類人體完全無法自行合成、必須靠飲食補足的營養素是不同的處境。

素食者不用特別擔心精胺酸不足：黃豆、南瓜子、花生等植物性食物本身的精胺酸含量就不低，純素飲食只要整體蛋白質攝取足夠，通常不會出現精胺酸相關的缺損。真正會讓人考慮額外補充的，是前面提到的功能性訴求（運動表現、血管擴張），而不是飲食缺口。

## 研究中常見的補充劑量與實證強弱

精胺酸沒有每日必需攝取量，補充品的劑量設計幾乎都是對應特定研究目的：

運動表現方面，Viribay 等 2020 年的統合分析納入 15 篇研究，發現急性劑量（運動前單次服用，約每公斤體重 0.15 公克，運動前 60 至 90 分鐘服用）與慢性劑量（有氧表現取向每日 1.5 至 2 公克、連續 4 到 7 週；無氧表現取向每日 10 到 12 公克、連續 8 週）都有研究支持，整體對有氧表現的效應量達中大程度，對無氧表現的效應量較小。 <a href="#ref-3">[3]</a> 但這個正面結果跟另一篇只看「運動前單次服用 6 到 8 公克」這個特定情境的統合分析結論不一樣。Pasa 等 2022 年僅納入 3 篇小型隨機試驗、合計約 30 人，合併結果顯示對肌耐力與最大扭力沒有顯著幫助。 <a href="#ref-4">[4]</a> 兩篇統合分析看的是不同的補充方式（急性單次 vs. 混合急性與慢性）與不同的體能指標，差異來自這些設計上的分岔，提醒「精胺酸對運動表現有效」這句話需要先問清楚是哪一種劑量、哪一種運動類型。

心血管方面，Dong 等 2011 年合併 11 項隨機對照試驗、387 人，各試驗劑量落在每日 4 到 24 公克之間，結果平均降低收縮壓 5.39 mmHg、舒張壓 2.66 mmHg。 <a href="#ref-7">[7]</a> 但若把對象限定在心血管或代謝疾病患者、看的是血管內皮功能這個更直接的生理指標，Rodrigues-Krause 等 2018 年統合 13 項試驗後，血流介導血管擴張（FMD）在精胺酸組與安慰劑組之間沒有顯著差異。 <a href="#ref-8">[8]</a> 這兩篇統合分析合起來的訊息是：精胺酸對血壓數字可能有小幅、不穩定的影響，但沒有足夠證據支持它能改善血管內皮這個更根本的功能指標。

## 缺乏風險：健康人幾乎用不到這個問題

因為精胺酸屬於條件必需胺基酸，健康成人飲食正常的情況下不會出現「精胺酸缺乏症」。 <a href="#ref-1">[1]</a> 會真正談到精胺酸需求量超過自行合成能力的情境，是嬰兒（代謝路徑未成熟）、嚴重燒傷、創傷、敗血症等高度分解代謝的臨床狀態，這些都是醫療團隊在加護病房或臨床營養情境下評估的問題，不是一般人日常飲食需要擔心的事。把疲倦、循環不佳或運動表現停滯直接歸因於「精胺酸不足」，在健康成人身上多半找不到對應的生理基礎。

## 補充品常見形式：精胺酸、AAKG、瓜胺酸的差別

市面上的精胺酸產品常見三種形式：游離的 L-Arginine 或鹽酸鹽形式 L-Arginine HCl、精胺酸α-酮戊二酸鹽（arginine alpha-ketoglutarate, AAKG，常見於健身補給品，結合精胺酸與三碳酮酸鹽 α-酮戊二酸）、以及瓜胺酸（L-Citrulline，嚴格來說是另一個胺基酸，而非精胺酸的形式）。 <a href="#ref-6">[6]</a>

這三者的差異值得分清楚：AAKG 的訴求是α-酮戊二酸可能提供額外的能量代謝好處，但目前沒有足夠證據證明 AAKG 比單純的精胺酸更能提升一氧化氮濃度或運動表現，多數是行銷語言而非額外的實證支持。瓜胺酸則因為不會被腸道精胺酸酶大量分解，改走腎臟轉換為精胺酸的路徑，Schwedhelm 等 2008 年的交叉試驗顯示瓜胺酸拉高血中精胺酸濃度的效果比直接口服精胺酸更好，Allerton 等 2018 年的回顧也把這個生體可用率上的差異列為瓜胺酸被重新重視的主要理由。 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a> 瓜胺酸是另一個完整的成分主題，這裡只點出它跟精胺酸在吸收路徑上的根本差異，細節不在本篇展開。

## 安全性與禁忌族群

多數健康成人短期口服精胺酸的耐受性良好，常見副作用是腸胃不適，劑量超過每日 10 公克時腹瀉、脹氣的機率明顯上升。 <a href="#ref-12">[12]</a> 下面幾個族群的風險，各有具體研究或機轉作為根據：

**急性心肌梗塞後或嚴重心血管疾病患者**：Schulman 等 2006 年於 JAMA 發表的 VINTAGE MI 隨機對照試驗，讓心肌梗塞後患者每日服用 9 公克精胺酸達 6 個月，精胺酸組六個月死亡率 8.6%、安慰劑組 0%，差異達統計顯著（P=0.01），試驗提前終止，作者結論是精胺酸補充未改善血管硬化程度或心臟射出分率，且可能與心肌梗塞後較高死亡率有關。 <a href="#ref-11">[11]</a> 這個試驗樣本不大，不能視為因果定論，但足以說明這個族群不該把精胺酸當成心臟保養品自行使用。

**有口唇或生殖器皰疹病史者**：皰疹病毒複製需要大量精胺酸作為原料，Griffith 等 1981 年的細胞培養實驗顯示，精胺酸缺乏時病毒複製受到抑制，補充精胺酸則促進病毒生長；相對地，離胺酸（Lysine）與精胺酸競爭吸收，能抑制病毒複製。 <a href="#ref-9">[9]</a> 這是細胞層級的證據，沒有試驗直接測過「吃精胺酸補充品會不會讓皰疹更常發作」，Mailoo 與 Rampes 2017 年整理離胺酸預防皰疹復發的臨床試驗，結論是仍需要更長期的對照試驗才能定論。 <a href="#ref-10">[10]</a> 這一條屬於機轉上說得通、保守起見建議避開的風險，不是已經證實的因果關係，有皰疹病史者補充前宜先諮詢醫師。

**同時使用硝酸鹽類藥物或 PDE5 抑制劑者**：硝化甘油、硝酸異山梨酯等心絞痛用藥，以及西地那非（Sildenafil）等 PDE5 抑制劑，都是透過一氧化氮路徑擴張血管，與精胺酸併用等於疊加同一條路徑，血壓過度下降的風險是真實的。 <a href="#ref-12">[12]</a>

**正在服用降血壓藥物者**：精胺酸本身有輕度降壓效果，疊加在既有藥物治療上，有可能讓血壓降幅超出預期控制範圍，開始補充前宜告知醫師並留意血壓變化。 <a href="#ref-7">[7]</a>

**準備接受手術者**：精胺酸影響血壓調節路徑，可能與麻醉期間的血壓管理互相干擾，實際停用時間建議與主治醫師或麻醉科確認，不要自行判斷。

依台灣《健康食品管理法》，精胺酸相關產品若未取得許可證（俗稱小綠人），不得宣稱保健功效，任何產品一律不得宣稱治療或矯正疾病的醫療效能。 <a href="#ref-13">[13]</a>

## 常見迷思

- 「精胺酸是必需胺基酸，每個人都該補」：精胺酸屬於條件必需胺基酸，健康成人能自行合成，飲食正常不會缺乏，這跟維生素 C 這類人體完全無法自行合成的必需營養素是不同的分類。 <a href="#ref-1">[1]</a>
- 「吃進去多少精胺酸，一氧化氮就會等比例增加」：口服精胺酸在到達血液循環前，有相當比例會被腸道與肝臟的精胺酸酶分解，真正能用於一氧化氮合成的量打了折扣，這也是瓜胺酸被提出作為替代路線的原因。 <a href="#ref-5">[5]</a>
- 「AAKG 效果比一般精胺酸更好」：目前沒有足夠證據證明精胺酸α-酮戊二酸鹽比單純的 L-Arginine 更能提升一氧化氮濃度或運動表現，這主要是行銷包裝上的差異。 <a href="#ref-6">[6]</a>
- 「心血管不好的人補精胺酸只有好處」：VINTAGE MI 試驗顯示急性心肌梗塞後患者補充精胺酸，六個月死亡率顯著較高於安慰劑組，一氧化氮機轉能解釋血管擴張，不代表對所有心血管病人都安全。 <a href="#ref-11">[11]</a>
