## 30 秒認識

- 紅景天（Rhodiola rosea）是生長在高海拔寒冷地區的多年生草本，傳統上被北歐、俄羅斯與中亞居民用來對抗高山環境的體力消耗與寒冷。 <a href="#ref-6">[6]</a>
- 現代研究把它歸類為「適應原」（adaptogen）：主張能幫助身體對抗生理與心理壓力，而不是針對單一疾病的藥物。 <a href="#ref-6">[6]</a>
- 抗疲勞的證據以小型隨機對照試驗為主：一項系統性回顧顯示，評估身體疲勞的 6 篇試驗中僅 2 篇顯示正向效果，評估心理疲勞的 5 篇中有 3 篇顯示正向效果，且研究間所用的疲勞指標互不相同，無法合併做統合分析。 <a href="#ref-1">[1]</a>
- 一項針對「壓力相關疲勞」族群的隨機對照試驗顯示，每日 576 毫克標準化萃取、連續 4 週，能改善疲勞程度與注意力測驗表現，並降低晨間清醒後的皮質醇反應，但樣本僅 60 人。 <a href="#ref-2">[2]</a>
- 常見的標準化萃取以「rosavins」與「salidroside」兩類成分的比例做品管指標（如 3% rosavins、1% salidroside），但不同品牌的萃取來源與比例差異大，研究結果不能直接套用到任意市售產品。 <a href="#ref-3">[3]</a>

## 基本介紹

紅景天屬於景天科（Crassulaceae）植物，主要生長在歐洲、亞洲與北美洲的高海拔寒冷地帶（如西伯利亞、斯堪地那維亞山區、青藏高原）。傳統上，當地居民會用其根部沖泡飲用，作為對抗嚴寒與高山勞動疲勞的民俗用法。 <a href="#ref-6">[6]</a> 現代保健品多使用根部萃取，並以「rosavins」（含 rosavin、rosin、rosarin 等）與「salidroside」兩類成分作為品質標準化的指標成分，但這兩類成分是否等同「有效成分」，學界仍在研究中。 <a href="#ref-3">[3]</a>

## 這是什麼？

標示常見 Rhodiola rosea、Rhodiola、金根（golden root）或北極根（arctic root）。它屬於「適應原」這個較新的分類概念——泛指一群被認為能提升身體對多重壓力源（生理、心理、環境）耐受度的天然物質，而非針對特定病症的藥物。要注意的是，「適應原」目前不是各國法規認可的正式療效分類，多數宣稱仍停留在傳統用法與初步臨床觀察階段。 <a href="#ref-6">[6]</a>

## 在身體裡做什麼？／主要作用機制

紅景天的機制研究多聚焦於下視丘-腦垂體-腎上腺軸（HPA 軸）與神經傳導物質系統：動物與細胞實驗顯示 salidroside、rosavin 等成分可能影響皮質醇、血清素與正腎上腺素相關路徑，並具有抗氧化特性。 <a href="#ref-6">[6]</a> 在人體研究中，前述隨機對照試驗觀察到補充後晨間皮質醇反應下降、疲勞量表分數改善，這類生理指標變化被視為支持「調節壓力反應」假說的初步證據。 <a href="#ref-2">[2]</a> 但機制層面的觀察不等於臨床療效：多數人體試驗規模小（數十人）、追蹤時間短（數週），且不同研究採用的疲勞、壓力量表不一致，難以互相比較或合併證據。 <a href="#ref-1">[1]</a>

## 食物來源／常見來源

紅景天不是常見食物成分，一般飲食中幾乎不會攝取到。它主要以根部曬乾後製成茶飲、酊劑或萃取物補充品的形式取得，在原生地（如西伯利亞、北歐）有沖泡飲用的傳統，但在其他地區的食物系統中並不存在。因此討論紅景天的攝取，實務上等同討論補充品的使用，而非日常飲食調整。

## 建議攝取量／常見攝取建議／研究中常見使用方式

紅景天沒有官方訂定的每日建議攝取量。臨床試驗中常見劑量為每日 200–600 毫克標準化萃取（多標準化為含 3% rosavins、1% salidroside），療程從單次急性使用到連續 4–12 週不等。 <a href="#ref-3">[3]</a> <a href="#ref-2">[2]</a> 前述壓力相關疲勞試驗使用的是每日 576 毫克、分兩次服用，連續 4 週。 <a href="#ref-2">[2]</a> 由於不同研究使用的萃取來源、標準化比例、劑量與療程差異頗大，目前無法歸納出單一「有效劑量」，購買與使用前應留意產品標示的標準化資訊是否與研究所用萃取相近。

## 缺乏風險或攝取不足問題

紅景天不是人體必需的營養素，**不存在「缺乏症」**。不使用紅景天不會造成任何已知的健康缺損。它的定位是「可選的適應原補充品」，而非缺了就要補的必需成分；長期疲勞、壓力大或情緒低落更需要優先檢視睡眠、工作負荷、運動與心理健康等基本面，而不是預設為「缺紅景天」。

## 補充品常見形式

市售常見膠囊、錠劑、液態酊劑與茶包，多標示為「標準化萃取」並註明 rosavins 與 salidroside 的含量比例。部分產品會與人參、刺五加（西伯利亞人參）等其他適應原草本組成複方，訴求「全面抗壓」。複方雖然行銷上看似完整，但會讓效果歸因變得困難：若使用後有變化，難以判斷是哪個成分起作用；若出現不適，也較難鎖定來源。選購時可留意萃取來源、標準化比例、每份實際劑量，以及是否有第三方檢驗，而非只看「適應原」這類統稱式行銷詞彙。

## 安全性與注意事項

現有臨床試驗中，紅景天的短期（最長約 12 週）安全性資料相對良好，回報的不良反應多為輕微，包括頭暈、口乾或唾液分泌增加、頭痛與失眠等，高劑量時較常見。 <a href="#ref-5">[5]</a> 在與 sertraline 的比較試驗中，紅景天組回報副作用的比例（30%）低於 sertraline 組（63%），但此試驗規模小，不能直接推論為「紅景天比抗憂鬱藥更安全」的定論。 <a href="#ref-4">[4]</a> 其他須留意之處：紅景天可能與降血壓藥（如 losartan）產生交互作用，理論上也可能影響血糖與血壓，正在服用相關藥物或有精神科用藥（如抗憂鬱藥）者應諮詢醫師；孕婦、哺乳者與兒童因研究資料不足，不建議自行使用；目前也缺乏連續使用超過 12 週的長期安全性資料。 <a href="#ref-5">[5]</a>

## 常見迷思

- 「紅景天是天然藥物，可以取代抗憂鬱藥或抗焦慮藥」：與 sertraline 比較的試驗規模小、屬概念驗證性質，紅景天改善憂鬱量表分數的幅度小於藥物，不能作為停藥或替代用藥的依據，調整精神科用藥須經醫師評估。 <a href="#ref-4">[4]</a>
- 「適應原對任何人、任何壓力都有效」：「適應原」是研究者提出的作用假說分類，不是法規認可的療效類別，人體證據仍以小型、短期試驗為主，效果因人而異。 <a href="#ref-6">[6]</a>
- 「劑量越高、效果越好」：現有試驗多集中在每日 200–600 毫克區間，並未有證據顯示更高劑量效果更佳，高劑量反而較常出現頭暈、失眠等不適。 <a href="#ref-5">[5]</a>
- 「所有紅景天產品效果一樣」：不同品牌萃取的原料來源與 rosavins／salidroside 標準化比例差異很大，研究結果無法直接套用到任意市售產品。 <a href="#ref-7">[7]</a>
