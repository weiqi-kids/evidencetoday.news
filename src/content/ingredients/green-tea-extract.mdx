## 30 秒認識

- 綠茶萃取物是把茶葉中的兒茶素（catechins）濃縮而成的補充品，主要活性成分是 EGCG（表沒食子兒茶素沒食子酸酯），常見膠囊、錠劑形式，濃度遠高於一般泡茶。 <a href="#ref-1">[1]</a>
- 減重訴求證據薄弱：考科藍系統性回顧顯示綠茶對過重／肥胖成人的減重效果平均僅約零點零幾公斤，統計上不顯著，作者認為**不具臨床意義**。 <a href="#ref-4">[4]</a>
- 另一篇統合分析看到小幅、統計上顯著的 BMI 與血糖改善，但效果量小，且血壓等其他代謝指標未見顯著差異——證據方向不一致。 <a href="#ref-5">[5]</a>
- 最關鍵的差異在安全性：**日常喝綠茶做為飲品未見安全疑慮**，但濃縮萃取的膠囊、錠劑已有多起肝損傷通報，機轉推測與部分人的基因體質有關。 <a href="#ref-3">[3]</a>
- 歐洲食品安全局（EFSA）2018 年的科學意見指出，補充品形式**每日攝取達 800 毫克以上 EGCG**，臨床試驗中觀察到受試者血中轉胺酶（肝功能指標）有統計上顯著的上升。 <a href="#ref-1">[1]</a>

## 基本介紹

綠茶（*Camellia sinensis*）葉片未經發酵，保留大量多酚類的兒茶素，其中 EGCG 含量最高、活性也研究最多。綠茶萃取物是把這些兒茶素從茶葉中純化、濃縮製成的補充品，每份劑量常是一般泡茶難以達到的濃度。 <a href="#ref-1">[1]</a> 它主打的訴求包括抗氧化、輔助代謝與體重管理，但整理現有的人體研究後，減重效果普遍偏小且不一致，安全性也是萃取品特有、喝茶不會遇到的課題。 <a href="#ref-2">[2]</a>

## 這是什麼？

市售產品常見標示為「Green Tea Extract」「EGCG」或「綠茶多酚」，多以綠茶葉萃取物膠囊或錠劑呈現，也常混入複方燃脂或運動補給品中。需先分清兩個概念：一是「喝綠茶」這個飲食習慣，二是「服用高濃度綠茶萃取物補充品」。兩者所含的兒茶素劑型、吸收速度與人體反應並不相同，安全性的結論也不能互相套用。 <a href="#ref-3">[3]</a>

## 在身體裡做什麼？／主要作用機制

EGCG 在體外與動物實驗中展現多重生化活性：清除自由基的抗氧化作用、影響脂肪與醣類代謝的酵素路徑、改善血管內皮功能等，這些機制研究多被引用來支持「抗氧化」「護心血管」等訴求。 <a href="#ref-6">[6]</a> 但機制證據屬於細胞與動物層級的觀察，要推論到人體臨床效益仍有落差：目前針對代謝症候群相關指標的統合分析雖看到部分小幅改善，效果量普遍不大，且並非每個結果指標都達到統計顯著。 <a href="#ref-5">[5]</a>

## 食物來源／常見來源

兒茶素天然存在於各類茶葉中，綠茶因製程未發酵，兒茶素保留最完整；紅茶、烏龍茶在發酵過程中，部分兒茶素會氧化轉變為茶黃素等其他多酚，含量型態不同。一般泡的綠茶每杯所含的兒茶素濃度遠低於萃取補充品，且喝茶時同時攝取水分、咖啡因與其他茶多酚，吸收與代謝模式也和空腹服用高濃度膠囊不同。 <a href="#ref-3">[3]</a> 目前沒有證據支持「每天要喝到幾杯茶」才能達到研究中補充品的效果，也不建議用大量喝茶來模擬萃取品劑量。

## 建議攝取量／常見攝取建議／研究中常見使用方式

綠茶萃取物沒有官方訂定的每日建議攝取量。體重與代謝相關的臨床試驗中，兒茶素劑量差異很大，統合分析涵蓋的試驗多在每日數百毫克等級。 <a href="#ref-5">[5]</a> 安全性方面，EFSA 的科學意見特別區分「傳統泡茶飲用」與「補充品形式」：以補充品形式空腹或短時間內攝取達每日 800 毫克以上 EGCG，臨床試驗觀察到肝功能指標上升的訊號；低於此劑量、或作為飲品攝取的兒茶素則未見同樣疑慮。 <a href="#ref-1">[1]</a> 這個 800 毫克是研究文獻中常被引用的示警門檻，不是「安全上限」的保證，實務上仍建議從低劑量開始、避免空腹服用濃縮萃取品。

## 缺乏風險或攝取不足問題

兒茶素不是人體必需營養素，**不存在「缺乏症」**。不攝取綠茶萃取物不會造成任何已知的健康缺損，把疲勞、代謝變差直接歸因於「沒吃兒茶素」並不合理——這些狀況更常與整體飲食型態、活動量、睡眠品質有關。

## 補充品常見形式

市售常見綠茶萃取物膠囊、錠劑，標示常註明兒茶素總量與 EGCG 含量；也常見於複方「燃脂」「代謝加強」錠劑中，與咖啡因、左旋肉鹼等成分並列。複方產品的問題在於難以判斷效果或不適究竟來自哪個成分。選購時可留意每份的 EGCG 毫克數是否揭露、是否建議隨餐服用（而非空腹），以及是否有第三方檢驗，而非被「燃脂」「代謝加速」等行銷字眼主導判斷。 <a href="#ref-3">[3]</a>

## 安全性與注意事項

這是綠茶萃取物與一般喝茶差異最大的地方。系統性回顧 34 項人體隨機對照試驗後認為，綠茶萃取物相關的肝臟不良事件並不常見，多數觀察到的是輕度、可逆的肝功能指標變化。 <a href="#ref-2">[2]</a> 但另一方面，美國國家補充暨整合健康中心（NCCIH）明確指出：以飲品形式喝綠茶未見安全疑慮，而**部分使用者服用濃縮萃取品（膠囊、錠劑）後曾發生肝損傷通報**，風險與特定基因變異（約 5–15% 的美國人帶有）有關。 <a href="#ref-3">[3]</a> EFSA 的科學意見則具體指出每日達 800 毫克以上 EGCG 的補充品劑量，臨床試驗中觀察到轉胺酶顯著上升的訊號。 <a href="#ref-1">[1]</a> 實務建議：避免空腹服用高劑量濃縮萃取品；選擇劑量標示清楚的產品，不隨意疊加多種含兒茶素的複方；有肝臟疾病史、服用其他藥物、孕婦哺乳者，使用前應諮詢醫療專業人員；若服用期間出現食慾不振、噁心、皮膚或眼白發黃等症狀應立即停用並就醫。

## 常見迷思

- 「喝綠茶跟吃綠茶萃取物一樣安全」：官方資料明確區分兩者——喝茶未見安全疑慮，濃縮萃取品才有肝損傷通報。 <a href="#ref-3">[3]</a>
- 「兒茶素能有效燃脂減重」：考科藍系統性回顧顯示減重效果平均僅約零點零幾公斤，統計上不顯著，不具臨床意義；另一篇統合分析雖看到小幅顯著改善，效果量仍小。 <a href="#ref-4">[4]</a><a href="#ref-5">[5]</a>
- 「天然萃取物不會傷肝」：多起肝損傷案例正是來自「天然」濃縮萃取品，天然不等於零風險。 <a href="#ref-2">[2]</a>
- 「劑量越高效果越好」：EFSA 示警的正是高劑量（每日 800 毫克以上 EGCG）與肝功能指標上升有關，並非劑量越高越有益。 <a href="#ref-1">[1]</a>
