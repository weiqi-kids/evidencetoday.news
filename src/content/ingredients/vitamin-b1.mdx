## 30 秒認識

- 國健署第八版建議量：19 歲以上男性每天 1.2 毫克、女性 0.9 毫克，懷孕第二、三期各加 0.2 毫克，哺乳期加 0.3 毫克；上限攝取量表沒有列 B1 <a href="#ref-2">[2]</a>
- 一般台灣飲食吃得到。豬小里肌每 100 公克約 1.2 毫克，白米只有糙米的五分之一左右 <a href="#ref-5">[5]</a>
- 缺 B1 的人集中在幾種情況：長期大量飲酒、長期用 furosemide 的心衰竭患者、減重手術後持續嘔吐、用 GLP-1 藥物後吃不下又一直吐 <a href="#ref-7">[7]</a> <a href="#ref-12">[12]</a> <a href="#ref-15">[15]</a> <a href="#ref-16">[16]</a>
- 最急的後果是韋尼克腦病變。一份 131 例的解剖研究中，八成病人生前沒有被診斷出來，只有 16% 有教科書上的三大徵象 <a href="#ref-9">[9]</a>
- 台灣規定膠囊、錠狀食品每天的 B1 不得超過 50 毫克；藥局的「合利他命」類是藥品，其中兩張是處方藥 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a>

## 基本介紹

尾牙、春酒一攤接一攤的季節，「喝酒傷肝要補 B 群」是很常聽到的一句話。這句話裡藏著一個真實的醫學問題，只是被說得太籠統：長期大量喝酒的人確實容易缺維生素 B1，而 B1 缺乏最嚴重時會傷到腦，跟肝沒有直接關係。

這一頁只談 B1。B 群複方要不要吃、八種 B 群各自做什麼，請看[維生素 B 群成分頁](/ingredients/vitamin-b-complex/)；手腳麻、記性變差也可能是 B12 的問題，那是另一套機轉，見〈[維生素 B12 缺乏](/articles/vitamin-b12-deficiency-guide/)〉。這一頁也不提供補充劑量建議，高風險的人該補多少、用口服還是注射，由醫師依狀況決定。

台灣一般人缺 B1 的機會不高，值得花時間了解的是那幾種「明明有在吃飯，B1 還是會掉下去」的情況。

## 這是什麼？

維生素 B1 的化學名是硫胺（thiamine），是水溶性維生素。食品與藥品標示上常見的形式包括鹽酸硫胺明、硝酸硫胺明，以及幾種化學修飾過的衍生物，例如呋喃硫胺（fursultiamine）、苯磷硫胺（benfotiamine）、丙硫硫胺（prosultiamine） <a href="#ref-3">[3]</a>。台灣藥局常見的「合利他命」，主成分就是呋喃硫胺或它的鹽類 <a href="#ref-4">[4]</a>。

MSD Manual 的整理是：B1 參與醣類、脂肪、胺基酸、葡萄糖與酒精的代謝 <a href="#ref-7">[7]</a>。用比較好懂的話說，細胞把吃進來的醣類轉成能量，中間需要 B1 幫忙；B1 不夠時，受影響最明顯的是神經系統與心臟，下面的乾性與濕性腳氣病就是這兩條線。

這也解釋了一個臨床上很重要的現象：對已經缺 B1 的人輸注葡萄糖，可能誘發或加重症狀，因為葡萄糖的代謝需要 B1 <a href="#ref-7">[7]</a>。

## 每天要多少：國健署的建議量

**成人男性每天 1.2 毫克、女性 0.9 毫克，51 歲以上不變；國健署沒有訂上限攝取量。**

國健署[國人膳食營養素參考攝取量專區](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4248&pid=12285)的第八版總表 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>，維生素 B1 的數字如下：

|---|---|---|
| 0 至 6 月 | 足夠攝取量 0.3 毫克 | 同左 |
| 7 至 12 月 | 足夠攝取量 0.3 毫克 | 同左 |
| 1 至 3 歲 | 0.6 毫克 | 0.6 毫克 |
| 4 至 6 歲 | 0.9 毫克 | 0.8 毫克 |
| 7 至 9 歲 | 1.0 毫克 | 0.9 毫克 |
| 10 至 12 歲 | 1.1 毫克 | 1.1 毫克 |
| 13 至 15 歲 | 1.3 毫克 | 1.1 毫克 |
| 16 至 18 歲 | 1.4 毫克 | 1.1 毫克 |
| 19 歲以上（含 71 歲以上） | 1.2 毫克 | 0.9 毫克 |
| 懷孕第一期／第二期／第三期 | | 加 0／加 0.2／加 0.2 毫克 |

## 台灣常見食物的 B1 含量

**豬肉是台灣飲食裡最集中的 B1 來源，精製白米的 B1 只剩糙米的一小部分。**

下表取自食藥署[食品營養成分資料庫](https://consumer.fda.gov.tw/Food/TFND.aspx?nodeID=178)的生鮮食材分析值 <a href="#ref-5">[5]</a>：

| 食物（生，每 100 公克） | 維生素 B1 |
|---|---|
| 豬小里肌 | 1.20 毫克 |
| 豬大里肌 | 0.88 毫克 |
| 豬後腿瘦肉 | 0.76 毫克 |
| 綠豆（乾） | 0.60 毫克 |
| 燕麥 | 0.50 毫克 |
| 紅豆（乾） | 0.41 毫克 |
| 黃豆（乾）、毛豆仁 | 0.39 毫克 |
| 糙稉米（台稉 9 號） | 0.33 毫克 |
| 胚芽稉米（平均值） | 0.28 毫克 |
| 去皮雞胸清肉（肉雞） | 0.20 毫克 |
| 白稉米（台稉 9 號） | 0.06 毫克 |

同一個品種台稉 9 號，糙米 0.33 毫克、白米 0.06 毫克，碾掉的部分帶走了大半的 B1。MSD Manual 把以精製白米、白麵粉、白糖為主的飲食列為原發性 B1 缺乏的常見原因 <a href="#ref-7">[7]</a>。現在的台灣飲食有肉、有豆，單靠白飯導致缺乏的情況少見，問題多半出在下面幾種「攝取、吸收或流失」被打亂的人身上。

## 缺乏會怎樣：腳氣病與韋尼克腦病變

**B1 缺乏主要傷神經與心臟，最急的是韋尼克腦病變，而它很常在生前被漏掉。**

**乾性腳氣病。** 周邊神經病變，雙側大致對稱、呈手套襪子狀分布，以下肢為主，表現是麻木、刺痛、無力 <a href="#ref-7">[7]</a>。

**濕性腳氣病。** 心肌受影響，後期出現心臟衰竭，有端坐呼吸、肺水腫與周邊水腫，最終可能變成高輸出型心衰竭 <a href="#ref-7">[7]</a>。

**嬰兒腳氣病。** 發生在由 B1 缺乏的母親哺乳的嬰兒，通常在 3 到 4 週大時出現 <a href="#ref-7">[7]</a>。國健署的哺乳期建議量比一般成人多 0.3 毫克 <a href="#ref-2">[2]</a>，哺乳媽媽的飲食值得多留意這一項。

**韋尼克腦病變與高沙可夫症候群。** MSD Manual 描述韋尼克腦病變的表現包括精神運動遲緩或淡漠、眼球震顫、步態不穩、眼肌麻痺；高沙可夫症候群則是意識混亂、虛構與近期記憶受損 <a href="#ref-7">[7]</a>。

教科書常寫「三大徵象」：意識改變、眼球動作異常、步態不穩。實際上三者齊全的人很少。Harper 等 1986 年分析 131 例死後解剖才確診的病例，80% 生前沒有被診斷，只有 16% 有完整的三大徵象，19% 病歷上完全沒有記錄到相關徵象 <a href="#ref-9">[9]</a>。Sechi 與 Serra 2007 年在《Lancet Neurology》的回顧也指出，依解剖研究，這個疾病在成人與兒童身上都仍嚴重低估 <a href="#ref-11">[11]</a>。正因為如此，歐洲神經學會 2010 年指引把飲酒者的臨床診斷門檻放寬為四項中出現兩項：飲食不足、眼睛徵象、小腦功能異常、意識改變或輕度記憶障礙 <a href="#ref-8">[8]</a>。

英國皇家內科醫師學會 2002 年的建議特別提到一個情境：長期酗酒、飲食可能不良的人到急診時，臨床徵象往往被酒醉掩蓋，應一開始就給予靜脈或肌肉注射的 B 群維生素 <a href="#ref-10">[10]</a>。這也是為什麼家屬在急診說出「他長期喝很多、最近吃很少」這句話，對醫療端很有用。

### 長期飲酒：尾牙季最需要知道的一件事

長期大量飲酒是韋尼克腦病變最常見的背景，MSD Manual 整理的機轉有四個：吃得少、吸收與利用受損、需求增加，以及可能的酵素缺陷 <a href="#ref-7">[7]</a>。喝酒的人常把正餐省掉，酒精本身又干擾腸道吸收，兩者疊在一起。

偶爾參加尾牙、一年醉一兩次，和每天喝、喝了幾年，是完全不同的風險等級。前者需要擔心的是當晚的事，例如正在吃降血糖藥的人喝酒會不會低血糖，那一題整理在〈[吃降血糖藥能喝尾牙的酒嗎](/articles/diabetes-medication-alcohol-year-end-party/)〉。後者才是 B1 這一頁要談的對象。

「喝酒前先吃 B 群」並不能讓長期大量飲酒變安全。B1 缺乏只是長期飲酒的眾多後果之一，處理的起點是飲酒本身。

### 利尿劑：心衰竭患者的隱形流失

Seligmann 等 1991 年的研究，23 名每天服用 80 到 240 毫克 furosemide、持續 3 到 14 個月的心衰竭患者，有 21 人的紅血球 B1 檢測呈缺乏，年齡相當、沒用利尿劑的對照組 16 人中只有 2 人；這些患者雖然已經缺乏，尿中 B1 排出量反而偏高，研究者認為是利尿造成的流失 <a href="#ref-12">[12]</a>。

同一團隊 1995 年的雙盲試驗中，30 名長期用 furosemide 的中重度心衰竭患者，接受一週靜脈 B1 的那一組，左心室射出分率從 0.28 升到 0.32，尿量與尿鈉排出也增加；完成 7 週療程的 27 人，射出分率上升 22% <a href="#ref-13">[13]</a>。Jain 2015 年的統合分析確認心衰竭患者缺 B1 的勝算是對照組的 2.53 倍，但也說明補充能否改善長期結局還需要更多研究 <a href="#ref-14">[14]</a>。

這些研究的對象是心衰竭患者、劑量是每天 80 毫克以上的 furosemide。用小劑量利尿劑控制血壓的人，不能直接套用。正在吃利尿劑的人不要自己停藥或改劑量，有疑慮就問開藥的醫師或藥師。

### 減重手術後：前 6 個月最危險

Aasheim 2008 年整理的 84 例減重手術後韋尼克腦病變，94% 在術後 6 個月內住院，90% 有頻繁嘔吐、住院時已經吐了中位數 21 天；18% 曾在沒有補 B1 的情況下接受靜脈葡萄糖 <a href="#ref-15">[15]</a>。後果並不輕微，49% 沒有完全恢復，常見後遺症是記憶障礙與走路困難 <a href="#ref-15">[15]</a>。歐洲神經學會指引建議減重手術後至少追蹤 B1 狀態 6 個月 <a href="#ref-8">[8]</a>。

### GLP-1 藥物：新的族群，資料還在累積

GLP-1 類藥物讓食慾大幅下降，部分人還有持續的噁心嘔吐，條件和減重手術後有幾分相似。Lev 等 2026 年分析美國 FDA 不良事件通報系統並回顧文獻，找到 15 例與 GLP-1 藥物相關的韋尼克腦病變，8 例用 semaglutide、6 例用 tirzepatide，14 例發生在 2023 至 2024 年，13 例有體重下降、嘔吐、食慾喪失或營養不良；有追蹤資料的 11 人中 7 人留下長期神經後遺症，通報比例高於其他藥物（報告勝算比 2.35） <a href="#ref-16">[16]</a>。Bidesie 與 Oudman 2026 年整理 6 例 semaglutide 減重後的病例，全部都先有長時間腸胃症狀與明顯體重下降 <a href="#ref-17">[17]</a>。

通報資料只能顯示訊號，算不出發生率，絕大多數使用者不會遇到。2025 年美國四個學會的聯合建議也把 B1 列在 GLP-1 使用者熱量攝取大降時要留意的微量營養素之一 <a href="#ref-18">[18]</a>。用藥期間的整體營養安排，見〈[GLP-1 瘦瘦針完整指南：營養篇](/articles/glp1-wegovy-complete-guide-nutrition/)〉。

### 長者：台灣唯一的全國性資料已經很舊

1999 至 2000 年的台灣老人營養健康調查，對 2,379 名長者以紅血球轉酮酶活性係數評估 B1 狀態：男性 16.5%、女性 14% 屬缺乏，另有 14.7% 與 11.9% 處於邊緣缺乏 <a href="#ref-6">[6]</a>。同一份研究算出的平均攝取量其實達到當時建議量的 146% 到 164%，但男性約三成、女性約四成的攝取低於平均需要量 <a href="#ref-6">[6]</a>。平均值好看，掩蓋了一群吃得不夠的人。這份資料距今二十多年，本頁沒有找到更新的全國性 B1 生化調查。

## 台灣藥局的 B1：食品 50 毫克封頂，藥品走另一條線

**同樣叫 B1、同樣是呋喃硫胺，做成膠囊食品每天最多 50 毫克，超過就是藥品。**

**食品這一側。** 《食品添加物使用範圍及限量暨規格標準》第（八）類營養添加劑列了十幾種 B1 形式，規定一致：錠狀、膠囊狀且標示每日食用限量的食品，每日食用量中 B1 總含量不得高於 50 毫克；一般食品每日食用量或每 300 公克不得高於 1.95 毫克；嬰兒食品 0.9 毫克 <a href="#ref-3">[3]</a>。呋喃硫胺、鹽酸呋喃硫胺、苯磷硫胺、丙硫硫胺這些衍生物也在名單裡，限用於錠狀膠囊狀食品、同樣每日 50 毫克，且都附註「限於補充食品中不足之營養素時使用」 <a href="#ref-3">[3]</a>。

**藥品這一側。** 2026 年 11 月 21 日下載食藥署全部藥品許可證資料集，主成分含硫胺或其衍生物的有效許可證有 556 張，其中醫師藥師藥劑生指示藥品 310 張、須由醫師處方使用 137 張、限由醫師使用 95 張，絕大多數是複方，以 B1 為唯一主成分的只有 36 張 <a href="#ref-4">[4]</a>。

以「合利他命」為品名的有效許可證有 5 張 <a href="#ref-4">[4]</a>：

| 品名 | B1 形式 | 藥品類別 | 核准適應症 |
|---|---|---|---|
| 合利他命 F50 糖衣錠 | 呋喃硫胺（thiamine tetrahydrofurfuryl disulfide）＋B2 | 須由醫師處方使用 | 神經炎、維生素 B1 缺乏諸症、神經痛等 |
| 合利他命 F100 糖衣錠 | 同上 | 須由醫師處方使用 | 腳氣、神經炎、維生素 B1 缺乏症等 |
| 合利他命-愛 糖衣錠 25 毫克 | 鹽酸呋喃硫胺＋B2、B6、B12 | 指示藥 | B1、B6、B12 缺乏所引起之神經痛、肌肉痛、腳氣病等 |
| 合利他命強效錠 | 鹽酸呋喃硫胺＋B6、B12、泛酸、維生素 E 等 | 指示藥 | 維生素 B1、B6、B12、泛酸及維生素 E 缺乏症 |
| 合利他命金強效錠 | 鹽酸呋喃硫胺＋B6、B12、葉酸、維生素 E 等 | 指示藥 | 維生素 B1、B6、B12、維生素 E、葉酸及 γ 穀維素缺乏症 |

這張表要說的是兩件事。第一，藥局架上那幾盒是藥品，有核准的適應症，買之前藥師有責任問你用途。第二，同一個品牌系列裡有處方藥也有指示藥，劑量與成分組合不同，不能互相替代。要不要吃、吃哪一種，問藥師或醫師，本頁不替讀者挑。

醫院裡的 B1 則是另一個世界：限由醫師使用的許可證中，有 15 張是 B1 單方注射劑，適應症多寫腳氣病與維生素 B1 缺乏症 <a href="#ref-4">[4]</a>。懷疑韋尼克腦病變時，歐洲神經學會指引建議在給任何醣類之前給予 B1，最好以靜脈方式 <a href="#ref-8">[8]</a>。

## 安全性與注意事項

**B1 本身很安全，風險在於缺乏時被漏看，以及把「補 B1」當成高風險行為的保險。**

國健署沒有訂 B1 的上限攝取量 <a href="#ref-2">[2]</a>，MSD Manual 形容它基本上沒有毒性 <a href="#ref-7">[7]</a>，歐洲神經學會指引評估 B1 的整體安全性非常好 <a href="#ref-8">[8]</a>。B1 這一頁真正要處理的安全問題有三個。

**早期症狀不明顯。** 腳麻、疲倦、食慾差、記性變差，每一個都可以有很多解釋。在 Harper 1986 年分析的 131 例解剖病例中，八成的韋尼克腦病變在生前沒有被認出來 <a href="#ref-9">[9]</a>。

**症狀被酒醉掩蓋。** 長期飲酒的人走路不穩、講話混亂，旁人第一個念頭是「又喝醉了」。英國皇家內科醫師學會的建議正是針對這個情境寫的 <a href="#ref-10">[10]</a>。如果家人長期大量飲酒，最近又吃得很少，出現意識混亂、眼睛看東西異常、走路歪斜，要直接送急診並說明飲酒與飲食狀況。

**用補充品掩蓋真正的問題。** 減重手術後一直吐、GLP-1 藥物用了吃不下，自己買 B 群來吃，處理的是後果，不是原因。這幾種情況都需要回到開藥或開刀的醫師那裡。

## 常見迷思

- **「喝酒前吃 B 群就不會傷身」**：B1 缺乏只是長期大量飲酒的後果之一，補 B1 不會減少酒精對身體其他部位的影響 <a href="#ref-7">[7]</a>
- **「韋尼克腦病變一定會有意識混亂、眼球異常、走路不穩三個症狀」**：解剖研究中只有 16% 三者齊全 <a href="#ref-9">[9]</a>
- **「B1 是水溶性的，吃多會尿掉，所以多吃無妨」**：國健署確實沒有訂上限 <a href="#ref-2">[2]</a>，但多吃不會帶來額外好處，高風險族群真正需要的是醫師評估與追蹤
- **「我吃很多白飯，應該不缺 B1」**：白稉米每 100 公克只有 0.06 毫克，B1 主要來自豬肉、豆類與全穀 <a href="#ref-5">[5]</a>
- **「合利他命就是比較貴的 B 群保健品」**：在台灣它們是藥品，其中兩張是處方藥，有各自核准的適應症 <a href="#ref-4">[4]</a>

## 常見問題

### 我每週都會喝幾次酒，需要補 B1 嗎？

先看量與時間，不是看有沒有喝。B1 缺乏與韋尼克腦病變的高風險族群是長期大量飲酒、而且飲食不足的人 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>。如果你擔心自己的飲酒量，最有用的一步是跟醫師談飲酒本身，醫師會依你的狀況判斷需不需要檢查或補充。正在吃慢性病藥的人，喝酒還有藥物交互作用的問題，例如降血糖藥那一篇整理的情況。

### 長期吃利尿劑會缺 B1 嗎？

目前的證據集中在每天 furosemide 80 毫克以上、持續數月的心衰竭患者，這群人缺 B1 的比例偏高 <a href="#ref-12">[12]</a> <a href="#ref-14">[14]</a>。用低劑量利尿劑控制血壓的人，本頁沒有找到相同程度的資料。有疑慮就把用藥清單帶給開藥的醫師或藥師討論，不要自己停藥或改劑量。

### 打 GLP-1 減重針後一直吐，跟 B1 有關嗎？

有可能，但不常見。通報資料中與 GLP-1 藥物相關的韋尼克腦病變，大多數都先有嘔吐、食慾喪失或體重快速下降 <a href="#ref-16">[16]</a> <a href="#ref-17">[17]</a>。持續嘔吐本身就是該回診的理由，讓醫師評估脫水、營養與藥物劑量。

### B1 可以驗血嗎？

可以，但一般健康檢查通常不包括。歐洲神經學會指引建議懷疑韋尼克腦病變時，在給 B1 之前先抽血驗總 B1 <a href="#ref-8">[8]</a>；MSD Manual 提到紅血球轉酮酶活性與 24 小時尿中 B1 也可以用來確認 <a href="#ref-7">[7]</a>。但臨床上常常是依症狀與補充後的反應來判斷，不會等報告才治療。

### 懷孕或哺乳要多補 B1 嗎？

國健署建議懷孕第二、三期每天多 0.2 毫克、哺乳期多 0.3 毫克 <a href="#ref-2">[2]</a>，這個量從飲食調整就能補上，例如多一份豬肉或豆類。妊娠劇吐、長時間吃不下的孕婦是另一回事，要讓產科醫師評估。

### 合利他命和超商買的 B 群有什麼差別？

法律身分不同。合利他命系列在台灣是藥品，有處方藥也有指示藥 <a href="#ref-4">[4]</a>；超商或網路買的 B 群多半是食品，膠囊錠狀食品每天的 B1 不得超過 50 毫克 <a href="#ref-3">[3]</a>。要選哪一種、需不需要，問藥師最快。
