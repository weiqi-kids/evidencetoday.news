## 30 秒認識

- 川芎是川芎（*Ligusticum chuanxiong*）的乾燥根莖，在台灣最常出現在四物湯、八珍湯、十全大補湯與治頭痛的川芎茶調散裡 <a href="#ref-3">[3]</a> <a href="#ref-7">[7]</a>
- 食品可以用川芎的根莖，但不得單一原料使用；外觀相近的「日本川芎」（*Cnidium officinale*）在台灣列為不得作食品原料 <a href="#ref-1">[1]</a>
- 衛福部 115 年 4 月預告的草案，把川芎列為「食用時須注意安全性」的中藥材：每人每日食用限量 1.5 公克，外包裝要標示孕婦慎用 <a href="#ref-3">[3]</a>
- 跟抗凝血藥的交互作用沒有人體資料：大鼠併用 warfarin 時暴露量變成 2.42 倍，另一份大鼠研究的方向卻相反 <a href="#ref-14">[14]</a> <a href="#ref-15">[15]</a>
- 療效證據普遍品質偏低：急性中風的 Cochrane 回顧只找到 2 項低品質試驗 <a href="#ref-17">[17]</a>

## 基本介紹

月經結束後喝一週四物、冬至燉一鍋十全大補、頭痛時中醫開一包川芎茶調散，很多台灣人一年會吃到好幾次川芎，卻很少有人單獨問過它。

這一頁只回答一個問題：**經期、懷孕、準備開刀、或正在吃抗凝血藥的人，要不要避開含川芎的四物、補湯與中藥處方？** 四物湯整方的試驗、市售四物飲與處方的差距，已經整理在[四物飲成分頁](/ingredients/si-wu-decoction/)；當歸跟 warfarin 的關係在[當歸成分頁](/ingredients/dong-quai/)。這裡只談川芎這一味。

先講結論：川芎被中醫歸在活血藥，主要成分在實驗室裡有抑制血小板的作用 <a href="#ref-13">[13]</a>，但它跟抗凝血藥併用的後果，目前只有方向互相矛盾的動物研究 <a href="#ref-14">[14]</a> <a href="#ref-15">[15]</a>。資料不足的時候，合理的做法是讓開藥的人知道，而非自己決定加或停。

## 這是什麼？川芎與日本川芎

**台灣中藥房的川芎是 *Ligusticum chuanxiong* 的根莖；日本漢方的「川芎」（センキュウ）是另一種植物 *Cnidium officinale*，兩者漢字相同、外觀相似，台灣的食品規定卻完全不同。**

Chen 等 2018 年的系統性回顧整理，川芎根莖已分離出約 174 種化合物，以苯酞類（例如藁本內酯）與生物鹼（例如川芎嗪，即四甲基吡嗪）為主要活性成分，實驗研究涵蓋抗血栓、抗血小板、降血壓等方向 <a href="#ref-8">[8]</a>。四物湯裡的當歸也含藁本內酯與阿魏酸，兩味藥的化學成分有部分重疊 <a href="#ref-11">[11]</a>。

日本這一側，日本藥局方第十八版收載的 Cnidium Rhizome（センキュウ）來自 *Cnidium officinale* <a href="#ref-10">[10]</a>。富山大學的 Zhu 等 2007 年指出，日本川芎與中國川芎的藥名漢字相同、外觀相似，但植物來源不同，並建立了用葉綠體基因序列區分兩者的方法；他們也發現中國東北栽培的「東芎」來源其實是 *C. officinale* <a href="#ref-9">[9]</a>。化學上兩者很接近，Lu 等 2005 年的層析指紋圖譜中，除了部分成分的相對含量，兩者沒有明顯差異 <a href="#ref-11">[11]</a>。

這個區別在台灣有法規後果，下一節說明。順帶一提，名字很像的蛇床子（*Cnidium monnieri* 的果實）是另一種藥材，平臺列在可供茶包、膳食調理包使用的原料 <a href="#ref-1">[1]</a>，與川芎無關。

## 在台灣怎麼管：食品原料、中藥材與草案

**川芎的根莖可以當食品原料，但不得單一原料使用；日本川芎不能當食品原料；中藥材端則有重金屬與二氧化硫限量。**

**食品原料平臺。** 2026 年 11 月 22 日下載食藥署食品原料整合查詢平臺開放資料，川芎（*Ligusticum chuanxiong* Hortorum、*L. wallichii* Franch）的根莖列在「草、木本植物類（2）可供直接食用」，備註是「不得單一原料使用」 <a href="#ref-1">[1]</a>。同一份資料裡，日本川芎（*Cnidium officinale*）列在「未確認安全性尚不得使用之原料」，備註是未經確認其食用安全性前，不得供為食品原料使用 <a href="#ref-1">[1]</a>。

白話說，含川芎的茶包、藥膳包作為食品是合法的，但只有川芎一味的產品不符合使用條件；用日本川芎做的食品則不行。日本藥妝店買到的漢方藥如果含センキュウ，它在日本是以醫藥品身分販售，食品原料的規定管不到它；帶回台灣該怎麼算，整理在〈[日本的漢方藥帶回台灣，算中藥還是西藥？](/articles/japan-kampo-medicine-bring-back-taiwan/)〉。

**中藥材的現行規定。** 中醫藥司 107 年 2 月生效的「可同時提供食品使用之中藥材」清單沒有川芎 <a href="#ref-4">[4]</a>。重金屬方面，「中藥材含重金屬限量基準」以砷 3.0、鉛 5.0、鎘 1.0、汞 0.2 ppm 為通則，芎藭（川芎）被點名適用砷 5.0 ppm 的個別限量 <a href="#ref-5">[5]</a>。二氧化硫方面，川芎不在 400 ppm 的品項名單內，適用其餘中藥材的 150 ppm <a href="#ref-6">[6]</a>。根莖類藥材下鍋前怎麼洗、泡多久，見〈[中藥材、乾貨要先洗嗎](/articles/herbal-dried-goods-wash-first/)〉。

| 以藥品管理的情形 | 第二類中藥材總量占比達 50% 以上，或任一品項換算每日食用量超過臺灣中藥典最低用量的一半（即日限量） |
| 例外 | 滷包、燉包、藥膳調理包等以食材為主體、外包裝寫明與食材燉煮方式的產品；粗碎後以棉紙袋或不織布袋包裝的茶包 |
| 不得與食品組成相同的方劑 | 附表 2 的 38 首方劑中，含川芎的有 10 首：七補丸、人參丸、八珍益母丸、八珍湯、十全大補湯、四物理中湯、四物湯、芎歸膠艾湯、參仲四物湯、聖愈湯 |

最後一列對讀者最實際。依草案，一包組成跟四物湯完全一樣的「食品」，要以藥品管理；藥膳燉包則因為寫明與食材燉煮，落在例外裡 <a href="#ref-3">[3]</a>。截至 2026 年 11 月 22 日，這份基準仍是預告草案，正式條文以公告為準 <a href="#ref-2">[2]</a>。

## 川芎與抗凝血、抗血小板藥：證據到哪裡

**機轉上有疊加出血風險的理由，動物資料的方向卻不一致，人體個案本頁一筆都沒找到。**

機轉的部分來自川芎嗪。Liu 與 Sylvester 1990 年在大鼠動脈與靜脈血栓模型中，看到川芎嗪有抗血栓作用，且能抑制 ADP、膠原蛋白、凝血酶誘發的血小板凝集 <a href="#ref-12">[12]</a>；1994 年改用人類血小板做體外實驗，發現它會抑制細胞內鈣離子釋放、提高 cAMP，並減少活化血小板表面的 GP IIb/IIIa <a href="#ref-13">[13]</a>。這些是用純化成分做的實驗，一碗四物湯裡的川芎嗪有多少、吸收後能不能達到同樣濃度，本頁沒有找到可靠的人體數字。

動物藥動學有兩份方向不同的研究。Li 等 2016 年給大鼠每公斤 10 公克的川芎煎劑，併用 warfarin 後，warfarin 的曲線下面積是單用組的 2.42 倍 <a href="#ref-14">[14]</a>。Xiao 等 2019 年讓大鼠連續 14 天接受 aspirin 合併 clopidogrel 的雙重抗血小板治療，併用川芎的組別凝血酶原時間反而有縮短的趨勢，作者認為川芎可能抵銷部分抗凝作用，但整體沒有看到增加出血的風險 <a href="#ref-15">[15]</a>。

台灣中部的 Tsai 等 2013 年系統性比對交互作用資料庫，90 種單味中藥共牽涉 306 筆與抗凝血、抗血小板藥的交互作用紀錄，被特別點名的是丹參、當歸、薑、銀杏、甘草與薑黃 <a href="#ref-16">[16]</a>，川芎不在點名名單上。對照[丹參](/ingredients/danshen/)已有多起人體出血個案，川芎的資料層級明顯較低。

所以本頁的判讀是：**川芎與抗凝血藥的風險，目前是「無法排除、也無法量化」。** 對吃 warfarin、新型口服抗凝血藥或抗血小板藥的人，實務上的處理跟丹參、當歸一樣：

- 看中醫時說出正在吃的抗凝血藥或抗血小板藥名稱，請中醫師評估處方要不要調整
- 回西醫門診時帶著中藥處方或藥袋，包含科學中藥的品名
- 已經長期吃含川芎的處方、凝血數值一直穩定的人，不要看到這一頁就自己停藥；停用同樣可能讓數值變動，先問開藥的醫師要不要提早抽血
- 出現牙齦出血不止、不明瘀青、黑便、血尿時就醫，並說明正在吃的中藥

當歸、黃耆等其他補湯藥材與西藥的關係，見〈[補湯裡的當歸、黃耆，會跟你正在吃的西藥衝突嗎？](/articles/herbal-tonic-drug-interactions/)〉。

## 經期、懷孕與開刀前

**三種情境裡，證據最明確的是懷孕：草案要求標示孕婦慎用，動物實驗在高劑量看到胚胎毒性；經期能不能喝則沒有人體研究可以回答。**

**懷孕。** 衛福部草案要求含川芎的食品標示孕婦慎用 <a href="#ref-3">[3]</a>。Wang 等 2019 年的小鼠實驗中，懷孕小鼠每天口服每公斤 2、8、32 公克的川芎煎劑，高劑量組被吸收的胎數明顯增加，胚胎幹細胞模型把川芎歸為弱胚胎發育毒性；作者認為一般劑量在一定程度內安全，但劑量過高時有風險 <a href="#ref-21">[21]</a>。這是動物資料，無法直接換算成人的安全量，但足以支持「懷孕期間不要自己喝四物湯或含川芎的補湯」。懷孕期間的中藥處方，由中醫師與產科醫師共同評估。

**經期。** 本頁沒有找到川芎讓經血量增加的人體研究。民間「經期中不要喝四物、經後才喝」的說法，喝的時機與四物湯的試驗證據，整理在[四物飲成分頁](/ingredients/si-wu-decoction/)。經血量本來就多、經期拉長或經痛越來越嚴重的人，該處理的是原因，見〈[經痛止痛藥越吃越沒效，什麼時候該懷疑子宮內膜異位症？](/articles/menstrual-pain-painkillers-losing-effect-endometriosis/)〉，不要用調整四物湯的時間來代替就醫。

**開刀前。** 川芎嗪有抗血小板作用 <a href="#ref-13">[13]</a>，雖然沒有人體出血資料，術前仍要把四物、補湯與中藥處方告訴手術團隊，由醫師決定停用時間。術前保健品與中藥的整體安排見〈[開刀前要停哪些保健食品？停多久才安全？](/articles/stop-supplements-before-surgery/)〉。

## 安全性與注意事項

**川芎單獨使用的人體安全資料很少；目前能確定的是孕期要謹慎、與抗凝血藥的關係不確定、中藥材有重金屬與二氧化硫的品質規範。**

- **孕婦**：草案要求標示孕婦慎用 <a href="#ref-3">[3]</a>；動物實驗高劑量有胚胎毒性 <a href="#ref-21">[21]</a>
- **吃抗凝血或抗血小板藥的人**：動物資料方向不一 <a href="#ref-14">[14]</a> <a href="#ref-15">[15]</a>，讓兩邊醫師都知道
- **術前**：告知手術團隊 <a href="#ref-13">[13]</a>
- **買藥材的人**：中藥材有砷 5.0 ppm 的個別限量與 150 ppm 的二氧化硫限量 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>；來源不明、顏色異常鮮豔的藥材不要買
- **日本漢方**：含センキュウ的日本漢方用的是日本川芎，在台灣不能當食品原料 <a href="#ref-1">[1]</a>，作為藥品使用前先問藥師或中醫師
- **失眠吃酸棗仁湯的人**：這個方劑也含川芎，見[酸棗仁成分頁](/ingredients/sour-jujube-seed/)

## 常見迷思

- **「川芎是燉湯常用的食材，所以沒有限制」**：食品可以用川芎，但不得單一原料使用 <a href="#ref-1">[1]</a>；草案進一步訂了每日 1.5 公克的限量與孕婦慎用標示 <a href="#ref-3">[3]</a>
- **「日本川芎和中國川芎是同一種」**：植物來源不同，台灣把日本川芎列為不得作食品原料 <a href="#ref-1">[1]</a> <a href="#ref-9">[9]</a>
- **「川芎活血，所以一定會讓吃 warfarin 的人出血」**：目前只有大鼠資料，而且兩份研究方向相反 <a href="#ref-14">[14]</a> <a href="#ref-15">[15]</a>；不確定的意思是要告知醫師，不是確定會出事
- **「川芎嗪可以預防中風，所以多吃川芎有好處」**：中風相關的 Cochrane 回顧結論是證據不足 <a href="#ref-17">[17]</a>，預防中風那份回顧已在 2016 年撤回 <a href="#ref-18">[18]</a>
- **「市售四物飲是食品，含川芎也沒差」**：草案規定組成跟四物湯相同的產品要以藥品管理 <a href="#ref-3">[3]</a>，食品身分本身就有條件

## 常見問題

### 我在吃 warfarin，中醫開的藥裡有川芎，可以吃嗎？

先讓開 warfarin 的醫師與中醫師都知道。川芎跟 warfarin 的交互作用沒有人體資料，大鼠研究中 warfarin 的暴露量變成 2.42 倍 <a href="#ref-14">[14]</a>，另一份研究的方向卻相反 <a href="#ref-15">[15]</a>。醫師可能會安排比較密集的凝血檢查，或請中醫師調整處方。

### 月經來的時候可以喝四物湯嗎？

本頁沒有找到川芎讓經血量增加的人體研究，也沒有找到經期喝四物湯會出事的試驗。經期中要不要喝、怎麼喝，由中醫師依你的狀況判斷；經血量多或經痛加劇，先找婦產科查原因。四物湯本身的試驗結果見[四物飲成分頁](/ingredients/si-wu-decoction/)。

### 懷孕可以吃含川芎的補湯嗎？

不要自己吃。衛福部草案要求含川芎食品標示孕婦慎用 <a href="#ref-3">[3]</a>，小鼠實驗在高劑量看到胚胎毒性 <a href="#ref-21">[21]</a>。懷孕期間需要中藥調理，請中醫師與產科醫師一起評估。

### 開刀前要停四物湯嗎？

要讓手術團隊知道。川芎嗪有抗血小板作用 <a href="#ref-13">[13]</a>，四物湯裡的當歸另有與 warfarin 併用的個案報告（見[當歸成分頁](/ingredients/dong-quai/)）；停用時間由醫師依手術種類決定，中醫師開的長期處方不要自己突然停。

### 日本藥妝店買的當歸芍藥散、四物湯錠，裡面的川芎一樣嗎？

不一樣。日本藥局方的センキュウ來自 *Cnidium officinale* <a href="#ref-10">[10]</a>，台灣食品原料平臺把它列為不得作食品原料 <a href="#ref-1">[1]</a>。這類產品在日本是醫藥品，帶回台灣的規定見日本漢方藥那篇；吃之前讓藥師或中醫師看過成分。

### 家裡燉湯放一兩片川芎，會超過限量嗎？

草案訂的是食品業者的每人日食用限量 1.5 公克，並把以食材為主體、寫明燉煮方式的藥膳燉包列為例外 <a href="#ref-3">[3]</a>。家庭燉湯不是這份草案管的範圍，本頁也沒有找到家庭用量的安全研究。一般燉湯的量不必擔心；懷孕、吃抗凝血藥或準備開刀的人，則照前面的原則先問醫師。
