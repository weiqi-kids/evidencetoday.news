## 30 秒認識

- 洛神葵（*Hibiscus sabdariffa* L.）是錦葵科一年生草本，吃的是花謝之後肥厚的肉質花萼，不是花瓣。臺東是主產地，佔全臺洛神葵栽培面積的 78%，全臺栽培面積約 146 公頃。 <a href="#ref-21">[21]</a>
- 在英文文獻裡它叫 sour tea 或 karkade，被做最多次的題目是降血壓。Serban 等人 2015 年在《Journal of Hypertension》彙整 5 篇隨機對照試驗、390 人，收縮壓加權平均差 −7.58 mmHg（95% 信賴區間 −9.69 至 −5.46）、舒張壓 −3.53 mmHg。 <a href="#ref-1">[1]</a>
- Ellis 等人 2022 年納入 17 篇慢性介入試驗，對安慰劑的收縮壓差為 −7.10 mmHg，但異質性 I² 高達 95%。 <a href="#ref-2">[2]</a> Abdelmonem 等人 2022 年以 13 篇試驗、1,205 人重算，得到 −6.67／−4.35 mmHg。 <a href="#ref-3">[3]</a> 三份分析納入的試驗不完全相同，答案卻落在同一個區間。
- 頭對頭比較的結果比較能說明它的位置：對上 captopril 25 毫克一日兩次沒有顯著差異，對上 lisinopril 10 毫克則明顯落後。 <a href="#ref-7">[7]</a><a href="#ref-8">[8]</a>
- 台灣人最熟悉的形式是蜜餞，而蜜餞把上面那些數字的前提整個換掉：市售洛神花蜜餞的糖含量常在每 100 公克 60 公克上下，衛福部的建議是每日添加糖不宜超過總熱量的 10%，以 2,000 大卡計約 50 公克。 <a href="#ref-23">[23]</a><a href="#ref-24">[24]</a>
- 最少被提、卻最該提的是藥物交互作用。洛神花水飲在六名健康人身上讓 simvastatin 的清除率增加 44.6%、AUC 幾何平均比降到 0.646（90% 信賴區間 0.564 至 0.758），落在生體相等範圍之外。 <a href="#ref-11">[11]</a> 與抗瘧藥 chloroquine 併服時，血中 AUC 從 7.52 掉到 2.16 mg·h/L。 <a href="#ref-12">[12]</a>

## 基本介紹

秋天到臺東，路邊會出現一整攤深紅色、看起來像小燈籠的東西，論斤賣。買回家的人多半拿去做蜜餞、煮果醬，或是丟幾顆進冷水瓶泡成粉紅色的飲料。在台灣的日常語境裡，洛神花是一種零食原料、一種伴手禮、一種夏天解渴的酸味來源。

同一種植物在 PubMed 上的身分完全不同。以 Hibiscus sabdariffa 為關鍵字檢索，出現最多的主題是高血壓、血脂與代謝指標，介入品是沖泡的花萼茶或標準化萃取膠囊，對照組是安慰劑、綠茶、紅茶，或是真正的降壓藥。多份統合分析已經對它的降壓效果給出方向一致的估計值，而這些論文的作者群來自伊朗、墨西哥、埃及、英國、泰國，幾乎沒有台灣人。

這一頁要處理的就是這個落差：台灣人吃了幾十年的東西，證據其實不算薄弱；但支撐那些數字的用量與形式，跟貨架上的蜜餞、跟一個茶包泡一整壺水，是兩回事。

## 這是什麼？

洛神葵屬於錦葵科（Malvaceae），台灣常見的中文名還有洛神花、洛神果、山茄。可食用的部位是花朵凋謝後包住蒴果的肉質花萼，去籽後乾燥、糖漬或直接沖泡。它的酸來自有機酸（檸檬酸、蘋果酸、氫氧檸檬酸等），紅色來自花青素。

被點名的活性成分主要是兩種花青素：delphinidin-3-O-sambubioside 與 cyanidin-3-O-sambubioside。Ojeda 等人 2010 年把這兩種化合物從花萼分離出來，測到它們能抑制血管收縮素轉換酶（ACE）的活性。 <a href="#ref-9">[9]</a> 除此之外還有多酚、黃酮類、沒食子酸與果膠。

台灣的育種資料在這裡剛好能派上用場。臺東區農業改良場育成的洛神葵新品種「臺東6號－黑晶」，乾果萼總花青素含量達 30.6 mg/g，是主要栽培品種「臺東3號」的 7.7 倍，單位面積乾果萼產量每公頃 1,200 公斤、約為臺東3號的 4 倍。 <a href="#ref-21">[21]</a> 這組數字說明一件對消費者很實際的事：不同品種、不同乾燥方式的花萼，花青素含量可以差好幾倍，而包裝上通常不會標。想比較兩包洛神花乾，看得到的資訊往往只有產地與重量。

## 在身體裡做什麼？／主要作用機制

被提出的機制有三條，強度不一樣。

**第一條是 ACE 抑制。** 這是三條裡人體佐證最直接的一條。Ojeda 2010 的實驗確認兩種花青素會抑制 ACE 活性 <a href="#ref-9">[9]</a>；Herrera-Arellano 等人 2007 年那份 lisinopril 對照試驗，在受試者身上量到血漿 ACE 活性由 44.049 單位降到 30.1 單位（p = 0.0001）。 <a href="#ref-8">[8]</a> 用白話說：洛神花走的路徑，跟 ACE 抑制劑類降壓藥有部分重疊。這解釋了它為什麼會降血壓，也預告了它為什麼跟降壓藥併用要當心。

**第二條是利尿與排鈉。** Herrera-Arellano 2004 年的 captopril 對照試驗觀察到洛神花組出現排鈉作用 <a href="#ref-7">[7]</a>；2007 年那份試驗則測到血氯上升、血鈉有下降趨勢，血鉀沒有改變。 <a href="#ref-8">[8]</a> 動物實驗方面，Ndu 等人 2011 年讓大鼠與兔子併用洛神花萃取物與利尿劑 hydrochlorothiazide，尿量顯著增加、尿液 pH 與鈉、碳酸氫根、氯離子濃度下降。 <a href="#ref-15">[15]</a>

**第三條是抗氧化與代謝改善，證據層級最低。** 台灣的中山醫學大學團隊做過幾份相關研究：Peng 等人 2011 年在第二型糖尿病大鼠模型觀察到洛神花多酚萃取物改善胰島素抗性、降低血脂與糖化氧化壓力指標 <a href="#ref-19">[19]</a>；Kao 等人 2016 年在動物與前脂肪細胞模型看到抑制肝臟脂質新生與脂肪細胞成熟。 <a href="#ref-20">[20]</a> 這兩篇都是動物與細胞層級，沒有在台灣人身上重複驗證過。把它們當成「機制有跡可循」是合理的，當成「已證實能減脂」就超出資料範圍了。

## 食物來源／常見來源

洛神花不是必需營養素，沒有每日建議攝取量這件事，來源就是花萼本身與各種加工品。以成分類別來說，花青素在台灣人的日常飲食裡並不稀有：紫地瓜、紫高麗菜、桑椹、藍莓、黑豆皮都有；抑制 ACE 這件事則不是花青素的通性，是洛神花特定花青素被測到的性質。想理解花青素與其他植化素的整體定位，可以看〈[洋蔥植化素與槲皮素](/articles/onion-phytochemicals-quercetin-heart/)〉與〈[OPC 寡聚原花青素](/ingredients/opc/)〉。

台灣的花萼採收期集中在 10 月到 12 月，臺東的產季市集與網購是最常見的取得管道；乾燥花萼與茶包則全年都買得到。 <a href="#ref-22">[22]</a>

## 建議攝取量／研究中常見使用方式

這一段是全篇最實用的部分，因為研究用量跟一般人泡的濃度差距很大。

- **Herrera-Arellano 2004**：10 公克乾燥花萼，泡 0.5 公升水，總花青素含量 9.6 毫克，每天早餐前喝一次，連續 4 週。 <a href="#ref-7">[7]</a>
- **Herrera-Arellano 2007**：標準化乾燥萃取製劑，每劑總花青素 250 毫克，每天一次，連續 4 週。 <a href="#ref-8">[8]</a>
- **McKay 2010**：每天 3 份、每份 240 毫升的沖泡茶，連續 6 週。 <a href="#ref-6">[6]</a>
- **Norouzzadeh 2025** 的次族群分析：療程超過 4 週、受試者年齡 50 歲以上、偏誤風險低的試驗，降壓幅度較明顯。 <a href="#ref-4">[4]</a>

把 2004 那份試驗換算成日常操作：一天 10 公克乾花萼，而市售花草茶包一包大約 2 到 3 公克。等於試驗劑量接近三到四個茶包的量、泡成 500 毫升，而且每天喝、連喝一個月。用一個茶包泡一大壺水、想到才喝一次，濃度與頻率都離試驗條件很遠。

還有兩件事必須誠實交代。第一，異質性極高。Ellis 2022 的收縮壓合併分析 I² = 95% <a href="#ref-2">[2]</a>，代表各試驗之間的結果差異遠超過隨機誤差能解釋的範圍，來源可能是品種、花青素含量、沖泡方式與基線血壓都沒有統一。第二，效果量與基線血壓有關。Serban 2015 的統合迴歸指出降幅與基線血壓成反比 <a href="#ref-1">[1]</a>，McKay 2010 也記到基線收縮壓越高者反應越大（r = −0.421，p = 0.010）。 <a href="#ref-6">[6]</a> 血壓本來就正常的人，能拿到的幅度會比這些數字更小。

## 缺乏風險或攝取不足問題

洛神花沒有缺乏症，不喝它不會造成任何營養素不足。這一段真正該處理的問題是：如果你是為了血壓而來，優先順序該放在哪裡。

以現行的 130/80 判定標準來看，一個人如果居家血壓長期落在 140/90 以上，需要的是完整的評估與處置，而 6 至 8 mmHg 的幅度只能算輔助。台灣的居家血壓量測有既定做法（連續 7 天、早晚各 2 次、每次間隔 1 分鐘），先把自己的真實數字量清楚，比先決定要喝什麼更有用，做法見〈[高血壓完整指南與居家血壓 722](/articles/hypertension-130-80-home-bp-guide/)〉。血脂與血糖的紅字怎麼排序處理，可參考〈[代謝症候群五項指標該先改哪一項](/articles/metabolic-syndrome-which-marker-to-fix-first/)〉。

## 補充品常見形式

- **蜜餞**：台灣最普及的形式，也是離研究條件最遠的一種。花萼要經過反覆糖漬才能去澀、定色，成品的糖占比高。要看實際數字，直接讀包裝背面營養標示的「糖」那一欄，或到食藥署的食品營養成分資料庫查同類品項。 <a href="#ref-24">[24]</a>
- **乾燥花萼與茶包**：接近試驗介入品的形式。差別在每包的公克數與品種，濃度得自己控制。
- **濃縮汁與糖漿**：多半已經加糖調味，稀釋倍數各家不同，同樣要看營養標示。
- **果醬與果乾**：糖量與蜜餞同一個量級。
- **膠囊與錠劑**：臺東6號被明確定位為機能性產品原料，適合做成茶包、萃取飲品與錠劑。 <a href="#ref-21">[21]</a> 這類產品的重點是有沒有標示每份的總花青素毫克數，因為 2007 年那份試驗用的正是以總花青素定量的製劑。 <a href="#ref-8">[8]</a>

## 台灣的法規與市場實況

**它是食品，不是藥。** 洛神花在台灣以一般食品流通，包裝上不得標示或廣告療效。市面上偶爾出現「天然降壓」的說法，那屬於違法宣稱，不代表產品取得了什麼許可。

**「輔助調節血壓」是有法定管道的，但要個別產品去申請。** 食藥署公告的健康食品保健功效共 14 項，輔助調節血壓是其中一項。取得許可的產品會有「衛部健食字第A00000號」或「衛部健食規字第000000號」字號並印上小綠人，沒有字號的就只是一般食品。 <a href="#ref-25">[25]</a> 買之前把字號抄下來去核對，比看包裝正面的形容詞可靠。

**蜜餞這個品類的加工端風險，跟洛神花本身無關，但買的人躲不掉。** 醃漬與脫水蔬果類產品的常見不合格項目是防腐劑與漂白劑。臺北市政府衛生局曾抽驗醃漬及脫水蔬果（含蜜餞）40 件，5 件不符規定、不合格率 12.5%，項目包含苯甲酸與二氧化硫超標。 <a href="#ref-26">[26]</a> 這類產品的挑選邏輯與乾貨相通，見〈[金針、白木耳顏色太漂亮是不是有二氧化硫](/articles/dried-goods-sulfur-dioxide/)〉。

**產地資訊在台灣是可查的。** 臺東佔全臺栽培面積 78%、全臺約 146 公頃 <a href="#ref-21">[21]</a>，農業知識入口網有洛神葵的栽培與加工利用資料可對照。 <a href="#ref-22">[22]</a> 對想避開高糖形式的人，直接買乾燥花萼自己泡，是成本與可控性都比較好的選項。

## 安全性與注意事項

**與降壓藥、利尿劑併用。** 這是最需要警覺的一組。洛神花的兩條機制（ACE 抑制、排鈉利尿）跟 ACE 抑制劑、血管收縮素受體阻斷劑與利尿劑的作用方向相同，理論上會疊加。Ndu 2011 的動物實驗顯示併用 hydrochlorothiazide 後尿量增加，而且 hydrochlorothiazide 的血中濃度、AUC 與分布體積上升、清除率與排除速率常數下降。 <a href="#ref-15">[15]</a> Ahad 等人 2020 年在高血壓大鼠模型觀察到洛神花會影響 losartan 的降壓表現與藥動學。 <a href="#ref-16">[16]</a> 這兩篇都是動物資料，人體對應的試驗還沒有。正在服藥又打算每天喝濃洛神茶的人，務實作法是把血壓量起來、記錄下來，出現頭暈、站起來眼前發黑、疲倦感明顯增加時回診討論，而不是自行加減藥。

**與 statin 併用。** Showande 等人 2017 年在 6 名健康志願者做的兩期隨機交叉試驗，洛神花水飲讓單劑 40 毫克 simvastatin 的清除率增加 44.6%、尖峰濃度下降 18%，AUC 幾何平均比 0.646、90% 信賴區間 0.564 至 0.758，落在生體相等範圍之外。 <a href="#ref-11">[11]</a> 方向是「藥效可能被打折」，不是「更危險」，但對正在控制膽固醇的人來說，藥吃了卻沒到位同樣是問題。降血脂藥與保健品併用的整體判斷，可看〈[正在吃降血脂藥還能同時吃紅麴嗎](/articles/red-yeast-rice-with-statin/)〉。

**與其他藥物。** Mahmoud 等人 1994 年在健康男性身上比較 chloroquine 配水與配洛神花飲（當地稱 Karkadi），AUC 由 7.52 降到 2.16 mg·h/L、尖峰濃度由 553 降到 148。 <a href="#ref-12">[12]</a> Kolawole 與 Maduenyi 2004 年讓 6 名男性在服用 1 公克 acetaminophen 前 1.5 小時先喝洛神花飲，吸收相關參數沒有顯著改變，但排除速率常數與排除半衰期出現顯著差異、總清除率增加 11.69%。 <a href="#ref-13">[13]</a> Fakeye 等人 2007 年則測到洛神花飲品會減少 diclofenac 在 8 小時尿液中的排出量。 <a href="#ref-14">[14]</a> 這幾份試驗的樣本都只有 6 到 10 人、方法學也不強，單獨看每一篇都不足以下結論；但它們指向同一件事：洛神花水飲不是中性的白開水，跟藥同時下肚時會動到藥的處置。把它跟藥錯開至少一到兩小時，是成本很低的保守作法。整體原則見〈[慢性病藥和保健食品並用的 5 件事](/articles/chronic-disease-drug-supplement-interaction/)〉與〈[長輩西藥中藥一起吃，哪些組合真的會出事](/articles/elderly-tcm-western-drug-combos-that-matter/)〉。

**懷孕與哺乳。** 人體資料是空白的。動物層面，Iyare 與 Adegoke 2008 年在大鼠觀察到母鼠孕期飲用洛神花水萃取物後，子代青春期起始延後 <a href="#ref-18">[18]</a>；de Arruda 等人 2016 年評估母體暴露對雄性子代生殖參數的影響。 <a href="#ref-17">[17]</a> 動物結果不能直接外推到人，但在沒有人體安全資料的情況下，孕期把濃度高的洛神花茶當日常飲品並不是必要的選擇。偶爾吃幾顆蜜餞與每天喝 500 毫升濃茶，是不同量級的暴露。

**肝指數。** Norouzzadeh 2025 的綜合回顧記到天門冬胺酸轉胺酶有輕微上升，作者判定為臨床上不顯著，且未伴隨不良事件風險增加。 <a href="#ref-4">[4]</a> 已知肝功能異常又打算長期高劑量使用的人，把它列入回診時要主動告知的品項。

**腸胃。** 洛神花的酸度高，空腹大量飲用容易造成上腹不適或反酸，胃食道逆流症狀明顯的人可以改成餐後喝、或降低濃度。

**糖。** 蜜餞、果醬、濃縮汁的糖是實際會吃進去的熱量。以每日添加糖不超過總熱量 10%（2,000 大卡約 50 公克）計 <a href="#ref-23">[23]</a>，一份高糖蜜餞就可能吃掉一天配額的一大半。看懂成分表與代糖標示的方法，見〈[無糖飲料的成分表怎麼看](/articles/sugar-free-label-identify-sweeteners-taiwan/)〉。

## 常見迷思

- **「洛神花是天然的，不會跟藥衝突」**：現有人體藥動學資料剛好相反。simvastatin 的 AUC 幾何平均比落在生體相等範圍外 <a href="#ref-11">[11]</a>，chloroquine 的 AUC 掉到不到三分之一 <a href="#ref-12">[12]</a>。「天然」描述的是來源，跟藥物交互作用的有無無關。
- **「喝洛神茶可以取代降壓藥」**：2007 年那份直接對照 lisinopril 的雙盲試驗，洛神花組的血壓降幅與治療有效率都顯著低於藥物組。 <a href="#ref-8">[8]</a> 它可以是飲食調整的一部分，取代藥物則沒有試驗支持。
- **「蜜餞跟茶一樣有效」**：目前被統合分析納入的介入品都是沖泡花萼茶或標準化萃取物，沒有一篇用蜜餞。 <a href="#ref-1">[1]</a><a href="#ref-2">[2]</a> 蜜餞的糖負荷方向與血壓管理相反，兩者不能互相代換。
- **「洛神花可以消脂減重」**：Dilokthornsakul 等人 2024 年的統合分析收到 6 篇試驗、339 人，體重差 −0.27 公斤、95% 信賴區間橫跨 0，身體質量指數與腰圍同樣不顯著。 <a href="#ref-10">[10]</a> 台灣人比較常看到的消脂說法，來源多半是動物與細胞研究。 <a href="#ref-20">[20]</a>
- **「顏色越紅代表花青素越多」**：品種之間的花青素含量可以差 7.7 倍 <a href="#ref-21">[21]</a>，而糖漬、加熱與長時間光照都會影響顏色。肉眼判斷顏色深淺，推不出花青素的實際毫克數。
- **「血壓正常的人喝了可以預防」**：兩份分析都記到降幅與基線血壓成反比。 <a href="#ref-1">[1]</a><a href="#ref-6">[6]</a> 基線越低、可拿到的幅度越小，這類外推屬於把觀察到的關聯過度延伸，判讀方式見〈[什麼是觀察性研究](/articles/observational-study-nutrition-research-trap/)〉。

## 常見問題

### 一天要喝多少，才接近研究裡的量？

以 2004 年那份試驗為準，是 10 公克乾燥花萼泡 0.5 公升水、每天早餐前喝完，連續 4 週。 <a href="#ref-7">[7]</a> 換算成茶包大約三到四包。McKay 2010 用的則是每天 3 份、每份 240 毫升。 <a href="#ref-6">[6]</a> 兩份試驗的共同點是「每天」與「連續數週」，單次喝濃一點並不能替代。

### 我正在吃降血壓藥，還能喝嗎？

機制上兩者方向相同，動物實驗也看到與利尿劑併用時的疊加與藥動學改變。 <a href="#ref-15">[15]</a> 沒有人體試驗可以給出安全上限，比較務實的處理是：把它當成會影響血壓的東西看待，開始固定喝之後每天量血壓並記錄，帶著記錄回診讓醫師判斷，而不是自己憑感覺調整藥量。

### 蜜餞跟茶包，哪一個比較有意義？

從證據角度，被研究的是茶與萃取物，蜜餞完全沒有試驗資料。 <a href="#ref-1">[1]</a> 從糖的角度，蜜餞的糖含量常在每 100 公克 60 公克上下，而不加糖的茶幾乎是零。 <a href="#ref-24">[24]</a> 想吃蜜餞當零食沒問題，但別把它算進「為了血壓做的事」那一欄。

### 冷泡跟熱泡差在哪？

沒有頭對頭的臨床試驗比較過兩種沖泡方式對血壓的效果。可以說的是，被納入分析的試驗都用熱水沖泡或標準化萃取物 <a href="#ref-2">[2]</a>，而冷泡的溶出速度較慢、同樣重量的花萼需要更長時間才能達到相近濃度。想接近試驗條件的人，熱泡比較單純。

### 孕婦可以喝嗎？

人體安全資料是空白的，動物研究則觀察到孕期暴露與子代發育指標的變化。 <a href="#ref-17">[17]</a><a href="#ref-18">[18]</a> 在沒有人體資料的情況下，孕期不建議把高濃度洛神茶當作每日固定飲品；已經在喝而且擔心的人，把實際的量與頻率告訴產檢醫師，會比自行查資料判斷有用。

### 胃不好可以喝嗎？

洛神花的酸度高，空腹喝容易誘發上腹灼熱與反酸。胃食道逆流症狀明顯的人，可以先試著改成餐後喝、把濃度降低，症狀仍持續就該處理逆流本身，判斷方式見〈[胃食道逆流完整指南](/articles/gerd-acid-reflux-guide/)〉。

### 買回來的乾花萼要怎麼保存？

乾燥花萼怕潮也怕光，受潮後容易發霉並影響顏色。密封、避光、放陰涼處是基本做法；若包裝上標示需冷藏或冷凍，以標示為準。臺東區農業改良場的加工研究也指出乾燥方式會影響機能性成分的保留程度，這是同樣重量的花萼實際含量會差很多的原因之一。 <a href="#ref-21">[21]</a>
