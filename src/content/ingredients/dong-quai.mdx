## 30 秒認識

- 當歸是繖形科植物當歸（Angelica sinensis）的乾燥根，主產於中國甘肅、雲南等地，台灣市售當歸多為進口乾燥根或飲片，是四物湯、十全大補湯、當歸羊肉爐等藥膳的常見材料。 <a href="#ref-1">[1]</a>
- 主要活性成分是藁本內酯（ligustilide）等揮發性酞內酯類（phthalides）、阿魏酸（ferulic acid）與多醣體，其中揮發性成分不耐久煮，這也是不同煎煮方式會影響當歸實際攝入成分的原因之一。 <a href="#ref-1">[1]</a>
- 單方當歸對更年期熱潮紅等症狀的研究證據並不支持效果：1997 年一項雙盲安慰劑對照試驗發現，單獨服用當歸 24 週在子宮內膜厚度、陰道細胞成熟度與熱潮紅日誌上都與安慰劑無顯著差異。 <a href="#ref-3">[3]</a>
- 當歸最明確的安全性議題是與抗凝血藥物的交互作用：含有天然香豆素衍生物，個案報告與系統性回顧都指出可能增強 warfarin 的抗凝血效果、提高出血風險。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a>
- 孕婦、備孕與哺乳期婦女、準備接受手術者、正在服用抗凝血或抗血小板藥物者，使用當歸相關補品或藥方前都應先與醫師或藥師確認。

## 基本介紹

當歸原生於中國西北與西南高海拔地區，甘肅岷縣、雲南等地是傳統主要產區，栽培已有上千年歷史。 <a href="#ref-1">[1]</a> 入藥入膳的部位是曬乾或烘乾的根，依部位不同傳統上再細分為「歸頭」「歸身」「歸尾」，坊間常說歸頭偏補血、歸尾偏活血，但這種部位區分多屬經驗傳承，缺乏對應的現代對照試驗支持效果差異。在台灣，當歸幾乎不會被當成單方藥物使用，最常見的形式是藥膳湯品裡的一味材料，或中藥方（四物湯、八珍湯、十全大補湯）裡的成分之一，單獨標榜「當歸萃取物」「當歸精華」的保健食品在市面上相對少見。

## 這是什麼？

當歸的氣味與活性主要來自兩大類成分：一類是揮發油裡的酞內酯類化合物，其中藁本內酯是含量最高、研究最多的成分，具有揮發性、不耐長時間高溫久煮；另一類是水溶性的酚酸類與多醣體，阿魏酸是代表性成分之一，同時也是川芎、白芷等同科植物的共同成分。 <a href="#ref-1">[1]</a> 這也是為什麼「當歸」與「川芎」「白芷」在傳統藥膳配伍裡常一起出現的化學基礎：它們同屬繖形科，成分結構有部分重疊。當歸還含有天然香豆素及其衍生物，這類成分與部分光敏感反應、以及後面會談到的抗凝血交互作用都有關聯。市售當歸片、當歸粉的品質差異，很大程度來自產地、乾燥方式與儲存條件對揮發性成分的保存程度，這也是傳統市場師傅強調「當歸要選斷面油潤、香氣足」的原因，而非單純的外觀好看。

## 在身體裡做什麼？主要作用機制

當歸在動物與體外研究中觀察到的作用方向相當分散：藁本內酯與阿魏酸在細胞與動物實驗裡被觀察到抗發炎、抗氧化、影響血管平滑肌張力等作用；多醣體成分則多在免疫調節相關的體外實驗中被討論。 <a href="#ref-1">[1]</a> 針對婦科與雌激素相關的機制，Circosta 等人 2006 年在切除卵巢的大鼠身上給予標準化當歸萃取物，觀察到子宮組織增生、陰道上皮角質化、血清黃體生成素濃度下降，這些指標合起來顯示萃取物在這個動物模型裡有雌激素樣活性。 <a href="#ref-5">[5]</a> 這類機制研究能說明「當歸為什麼在傳統上被歸類為婦科用藥」，但機制觀察與臨床效果是兩件事：同一批研究者用的萃取濃度、給藥途徑，跟一般人喝一碗當歸湯或吃幾片當歸的實際攝取量差距很大，不能直接類推。

## 常見來源與怎麼買到

台灣市面上的當歸多以乾燥飲片、藥燉包、藥膳湯底的形式販售，中藥行、超市藥膳專區、電商平台都能買到。選購時可留意幾個實務指標：斷面顏色偏黃棕、油潤有光澤、聞起來有明顯辛香氣味，通常代表揮發性成分保存較好；表面發黑、有蟲蛀痕跡或潮濕發霉氣味的則應避免。當歸屬於根莖類藥材，衛生福利部訂有中藥材重金屬與農藥殘留限量基準，根莖類藥材因為生長在地下、直接接觸土壤，是需要清洗處理的類別之一，實際限量數字與清洗步驟在〈[中藥乾貨買回家要先沖洗嗎](/articles/herbal-dried-goods-wash-first/)〉整理得更完整。 <a href="#ref-8">[8]</a> 需要提醒的是，當歸本身的鈉含量很低，藥膳湯頭如果偏鹹，鹹味來源通常是米酒、醬油、沙茶醬包等調味料，而不是當歸這類藥材，這一點在〈[薑母鴨、羊肉爐的鈉都藏在哪裡](/articles/hotpot-tonic-sodium/)〉裡有更完整的鈉來源拆解。

## 常見使用方式與份量

當歸沒有官方訂定的每日建議攝取量，因為它在台灣的使用情境幾乎都是藥膳或中藥方裡的複方成分，而非單方定量的保健食品。中醫師開立處方時會依體質、季節與其他藥材搭配決定用量，一般藥膳湯品裡加入的當歸份量通常是個位數的克重。研究層級的資料多半也是複方試驗：Zhu 等人 2016 年的 Cochrane 回顧涵蓋的 22 項試驗，測試的是含當歸的各種複方，各方劑量、配伍與煎煮方式差異很大，難以整理出一個「當歸有效劑量」的共識數字。 <a href="#ref-4">[4]</a> 想知道自己一個冬天喝了多少含當歸的湯品是否適合，比起計算克數，更實際的作法是留意體質反應與是否落在下面「安全性」提到的特殊族群裡，必要時由中醫師依個人狀況評估份量，相關的族群篩選邏輯可參考〈[冬令進補前先確認自己適不適合](/articles/who-should-avoid-winter-tonic/)〉。

## 缺乏風險

當歸不是人體必需的營養素，不吃當歸不會造成任何已知的營養缺損。它的定位始終是傳統藥膳與中藥方的其中一味材料，不存在「當歸攝取不足」這種問題，也不需要為了預防某種缺乏症而刻意補充。把經期不適、疲勞、氣色不好直接歸因於「沒有補當歸」並不成立，這類症狀的成因複雜，需要的是釐清實際原因，而不是加重藥膳份量。

## 補充品常見形式

市面上以「當歸」為主打的獨立保健食品相對少見，多數是複方形式：常與黃耆、枸杞、紅棗一起做成藥膳湯包，或是與川芎、白芍、熟地一起做成四物湯相關的沖泡包、錠劑。少數標榜「當歸萃取物」的膠囊或滴劑會標示總酞內酯或藁本內酯含量做為規格化指標，但目前沒有足夠的人體臨床劑量反應資料可以判斷「含量越高效果越好」。選購複方產品時，效果或不良反應都難以歸因給當歸單一成分，這也是為什麼本篇會建議把當歸放進「整體藥膳與用藥紀錄」裡一起看待，而不是單獨追蹤某一種成分。

## 安全性與注意事項

短期、少量做為藥膳材料食用的當歸，對多數健康成人風險不高，常見的不良反應包括少數人出現的腸胃不適。當歸真正需要被認真對待的風險，是與抗凝血、抗血小板藥物的交互作用：Page 與 Lawrence 1999 年報告的個案顯示，一名 warfarin 治療穩定的患者併用當歸數週後凝血指標明顯上升，停用當歸後恢復；Tan 與 Lee 2021 年的系統性回顧把當歸列入可能增強 warfarin 作用的食物與藥用植物名單。 <a href="#ref-7">[7]</a> <a href="#ref-6">[6]</a> 這組交互作用的機轉、與丹參等其他活血藥材的比較，在〈[補湯裡的當歸、黃耆會不會跟你正在吃的西藥衝突](/articles/herbal-tonic-drug-interactions/)〉、〈[魚油跟抗凝血藥能不能一起吃](/articles/fish-oil-blood-thinner-interaction/)〉裡有更完整的整理，這裡只強調結論：正在服用抗凝血或抗血小板藥物、近期要驗 INR，或準備接受手術者，使用當歸相關藥膳或補充品前都應主動告知醫師與藥師，術前停用的實際作法可參考〈[排定手術前，這些保健食品建議先停用](/articles/stop-supplements-before-surgery/)〉。孕婦與備孕婦女因為當歸傳統上被歸類為活血、可能刺激子宮收縮的藥材，孕期安全性缺乏設計良好的人體對照試驗資料，多數執業建議孕期避免自行服用；哺乳期資料同樣有限。長者若同時服用多種慢性病用藥，交互作用風險的判斷邏輯與族群篩選可對照〈[長者常喝的中藥補湯要注意哪些西藥併用](/articles/elderly-tcm-western-drug-combos-that-matter/)〉。

## 常見迷思

- 「當歸能治好經痛、調好月經」：目前針對當歸單方設計的隨機對照試驗證據薄弱，多數傳統用法是複方，效果無法歸因於當歸單一成分，也沒有足夠人體證據支持它能「治好」特定婦科症狀，出現持續性經痛或月經異常仍應就醫檢查原因。 <a href="#ref-4">[4]</a>
- 「當歸是天然食材，藥膳裡加多少都安全」：日常藥膳份量對多數健康成人風險有限，但當歸所含的香豆素類成分與抗凝血藥物的交互作用是有實際個案報告支持的風險，服用相關藥物者不能用「天然」當作沒有上限的理由。 <a href="#ref-7">[7]</a> <a href="#ref-6">[6]</a>
- 「當歸能補雌激素、幫助更年期症狀」：動物實驗觀察到當歸萃取物具有雌激素樣活性，但 1997 年的人體雙盲試驗顯示單方當歸連續服用 24 週，在子宮內膜厚度、陰道細胞成熟度與熱潮紅緩解上都不優於安慰劑，動物層級的機制觀察不能直接套用到人身上的效果預期。 <a href="#ref-5">[5]</a> <a href="#ref-3">[3]</a>
- 「歸頭補血、歸尾活血，效果差很多」：這種部位區分是傳統經驗分類，目前沒有現代對照試驗針對當歸不同根部位做過效果比較，選購與使用上不必為了追求特定部位而額外增加成本。
