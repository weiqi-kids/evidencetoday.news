## 30 秒認識

- 白藜蘆醇（Resveratrol）是葡萄皮、紅酒與部分莓果、花生中天然存在的多酚類化合物（芪類，stilbene），也是植物受感染或紫外線壓力時分泌的防禦物質。 <a href="#ref-4">[4]</a>
- 它因「活化 sirtuin（如 SIRT1）長壽基因」的機制假說聲名大噪：2006 年一項指標性動物實驗顯示，餵食高油脂飲食的小鼠補充白藜蘆醇後健康與存活情形明顯改善——但這個效果主要出現在「吃很差」的小鼠身上，對正常飲食小鼠的最長壽命並沒有延長作用。 <a href="#ref-1">[1]</a>
- 人體研究的結果遠不如動物實驗亮眼：2026 年一篇涵蓋多篇統合分析的傘型回顧發現，補充白藜蘆醇對多數健康指標的效果小且不一致，僅在肥胖相關指標與部分發炎指標觀察到較明確、但幅度有限的改善。 <a href="#ref-6">[6]</a>
- 白藜蘆醇口服後吸收率其實不低，但吃下去大部分很快被肝腸代謝成硫酸化與葡萄糖醛酸化的產物，能維持在血中的原型白藜蘆醇極少，生體可用率常低於百分之一，這是它效果難以在人體穩定重現的核心限制。 <a href="#ref-2">[2]</a>
- 「喝紅酒有益健康、能抗老」是常見誤讀：一杯紅酒中的白藜蘆醇含量遠低於研究使用的劑量，酒精本身的健康風險又早有明確證據，不宜倒果為因。

## 基本介紹

白藜蘆醇最早因「法國悖論（French Paradox）」的討論受到矚目：學者觀察到法國人飲食中飽和脂肪攝取量不低，心血管疾病死亡率卻相對偏低，紅酒中的多酚成分因此被拿來當作可能的解釋之一，白藜蘆醇是討論度最高的成分之一。它主要存在於紅葡萄與紫葡萄的果皮（果肉幾乎沒有），紅酒因帶皮發酵而含量高於白酒；花生（尤其帶皮）、蔓越莓、藍莓、桑椹等也含有少量。 <a href="#ref-4">[4]</a> 市售保健食品中的白藜蘆醇多萃取自虎杖（Polygonum cuspidatum）根部，因為萃取濃度遠高於葡萄皮，是目前原料的主流來源。

## 這是什麼？

白藜蘆醇屬於芪類（stilbene）多酚，化學結構上有順式（cis）與反式（trans）兩種異構物，研究與保健食品討論的多是活性較穩定的反式白藜蘆醇（trans-resveratrol）。它不是人體必需營養素，也沒有法定每日建議攝取量；市面上常把它與「NAD+ 前驅物」（如 NMN、菸鹼醯胺核糖）並列行銷為「長壽科學」的一員，但兩者作用機制不同，不能混為一談。

## 在身體裡做什麼？／主要作用機制

白藜蘆醇最受矚目的機制假說是活化 sirtuin 家族酵素（尤其 SIRT1），這類酵素被認為與粒線體功能、代謝調節及老化過程有關；它同時也被觀察到能活化 AMPK（能量代謝的關鍵酵素），並具有抗氧化、抗發炎的生化活性。 <a href="#ref-1">[1]</a> 2006 年那項小鼠實驗中，補充白藜蘆醇的高脂飲食小鼠出現胰島素敏感度提升、粒線體數量增加、運動能力改善等變化，整體生理狀態更接近吃正常飲食的小鼠。 <a href="#ref-1">[1]</a> 但這些是動物與細胞層次的機制觀察，人體是否能穩定重現同樣的 sirtuin 活化效果、進而轉換成具體的健康結果，證據仍相當有限；2018 年一篇彙整人體介入試驗的回顧就指出，不同研究結果彼此矛盾，可能與劑量、腸道菌相狀態、健康狀況、吸收與代謝速率等因素高度相關。 <a href="#ref-4">[4]</a>

## 食物來源／常見來源

天然食物中，白藜蘆醇含量最高的是紅葡萄與紫葡萄的果皮，其次是以帶皮發酵工序製成的紅酒；花生（尤其帶皮生食或水煮）、蔓越莓、藍莓、桑椹、開心果等也含有少量。 <a href="#ref-4">[4]</a> 要特別留意「劑量落差」：多數人體研究使用的劑量落在每日 150 毫克到數公克之間，而一杯紅酒中的白藜蘆醇含量普遍只有零點幾毫克，兩者差距達數百倍——靠喝紅酒攝取到研究劑量並不現實，還會同時攝入酒精，得不償失。這也是「喝紅酒有益健康」說法最常見的誤讀來源：法國悖論的討論從來不是「紅酒因為含白藜蘆醇所以對健康好」這麼單純的因果關係，充其量只是觀察性資料衍生出的假說之一。

## 建議攝取量／常見攝取建議／研究中常見使用方式

白藜蘆醇沒有官方訂定的每日建議攝取量。人體研究使用的劑量差異很大，從每日約 150 毫克到 5 公克都有，多數短期試驗顯示每日達 5 公克仍屬可耐受範圍。 <a href="#ref-4">[4]</a> 但劑量越高不代表效果越好或越安全：一篇安全性回顧指出，對六十公斤成人而言，每日 450 毫克大致落在安全範圍，一旦達到每日 1000 毫克以上，就可能開始出現抑制肝臟代謝酵素（CYP3A4、CYP2C9、CYP2D6 等）的現象，進而影響其他藥物的代謝。 <a href="#ref-5">[5]</a> 市售補充品常見劑量落在每日 100 到 500 毫克之間，遠低於這個警戒帶，但也代表它多半達不到動物實驗或高劑量人體試驗中觀察到的效果幅度。

## 缺乏風險或攝取不足問題

白藜蘆醇不是必需營養素，人體不會因為「沒有攝取白藜蘆醇」而出現任何已知的缺乏症狀。不吃葡萄、不喝紅酒、不額外補充，都不會造成健康缺損。把老化或慢性病風險歸因於「白藜蘆醇攝取不足」並不成立——老化是多重因素交互作用的結果，遠比補充單一多酚複雜。

## 補充品常見形式

市售白藜蘆醇多為膠囊或錠劑，原料常標示萃取自虎杖根或葡萄籽／葡萄皮，並會註明反式白藜蘆醇的純度百分比。由於口服後生體可用率低是它最大的先天限制，部分產品會添加胡椒鹼（黑胡椒萃取）宣稱能延緩代謝、拉長作用時間，或做成微脂粒、微粒化等劑型嘗試提升吸收；但這些技術是否能真正轉換成人體可感受到的健康效益，目前仍缺乏高品質的長期人體證據。 <a href="#ref-2">[2]</a> 選購時可留意標示的萃取來源、反式白藜蘆醇純度、每份劑量，而不是被「奈米」「微脂粒」「生物利用度提升數倍」這類文案主導判斷。

## 安全性與注意事項

短期使用下，白藜蘆醇的耐受性整體良好：一項針對健康成人的開放標籤單次劑量試驗顯示，單次口服 500 毫克白藜蘆醇並未觀察到明顯不良反應。 <a href="#ref-3">[3]</a> 但研究回顧也提醒，達到每日 1000 毫克以上時，可能開始出現腸胃不適（腹瀉、噁心）、白血球數變化、肝功能指數波動等狀況，且因為會抑制或誘導多種肝臟代謝酵素，可能提高與其他藥物的交互作用風險，包括增加抗凝血劑（如 warfarin）的出血風險，並影響他汀類降血脂藥、部分免疫抑制劑與抗組織胺藥物的血中濃度。 <a href="#ref-5">[5]</a> 目前針對長期（數月以上）高劑量使用的人體安全資料仍有限；孕婦、哺乳者與正在服用處方藥物者，建議諮詢醫療專業人員後再考慮是否使用高劑量補充品，不宜自行大量服用。

## 常見迷思

- 「喝紅酒能抗老、對心血管好」：一杯紅酒的白藜蘆醇含量遠低於研究劑量，酒精本身的健康風險已有明確證據，靠喝酒攝取白藜蘆醇並不划算，也不是官方建議的健康做法。
- 「動物實驗證明能延壽，人吃了也會延壽」：2006 年那項指標性小鼠實驗的效果主要出現在飲食極不健康的小鼠身上，對正常飲食小鼠的最長壽命並沒有延長；動物模型與人體老化機制存在明顯差異，目前沒有人體證據支持「補充白藜蘆醇能延長壽命」。 <a href="#ref-1">[1]</a>
- 「活化 sirtuin 等於一定會抗老、延壽」：sirtuin 活化是機制假說，多來自動物與細胞實驗；人體臨床試驗對各項健康指標的結果不一致，2026 年的傘型回顧也顯示多數效果小且證據等級有限，不能直接畫上等號。 <a href="#ref-6">[6]</a>
- 「劑量越高效果越好、越天然越安全」：生體可用率低不代表可以無限加量彌補，過高劑量反而可能干擾藥物代謝酵素、增加交互作用風險；補充品不是劑量越高越有效。 <a href="#ref-5">[5]</a>
