## 30 秒認識

- TUDCA 是熊去氧膽酸（UDCA）接上牛磺酸的膽汁酸。吃進去之後，有一部分會在腸道被拆開再重新結合，結果是膽汁裡的 UDCA 比例上升 <a href="#ref-6">[6]</a>
- 台灣沒有任何一張主成分為 TUDCA 的藥品許可證，食藥署食品原料整合查詢平臺也查不到它；平臺聲明「非正面表列」，所以查不到代表沒有公開答案，不能解讀成可以或不可以 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- 它的近親 UDCA 在台灣是醫師處方藥，適應症是膽固醇結石溶解與原發性膽汁性膽管炎 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>
- 證據最完整的用途是原發性膽汁性膽管炎：一項 199 人的隨機試驗中，TUDCA 降鹼性磷酸酶的效果與 UDCA 相當 <a href="#ref-4">[4]</a>
- 健身圈最常見的用法，也就是搭配類固醇或高強度訓練「護肝」，本頁查不到任何人體試驗
- 膽道阻塞的人不該用，和降膽固醇的樹脂類藥物、含鋁制酸劑一起吃會互相干擾 <a href="#ref-14">[14]</a>

## 基本介紹

健檢報告上 GPT 一欄出現紅字，很多人的下一步是打開購物網站搜尋「護肝」。TUDCA 這幾年從歐美健身社群傳進台灣，在跨境電商上一瓶 250 毫克、60 顆的膠囊不難買到，產品頁寫著支持肝功能與膽汁流動。

這一頁只回答 TUDCA 本身的三件事：它在台灣算什麼、它在哪些情況下有人體證據、誰不該自己買來吃。肝指數紅字該先複檢還是看診，請看〈[健檢肝指數（GOT、GPT）偏高，要先複檢還是直接看肝膽科？](/articles/liver-enzymes-got-gpt-high-next-step/)〉；水飛薊素、朝鮮薊與 TUDCA 三者怎麼選，〈[如何選對護肝保健品](/articles/liver-supplement-comparison-silymarin-artichoke-tudca/)〉已經比較過。UDCA 的處方用途只在需要對照時簡單帶過。

先說一件常被忽略的事：健檢 GPT 偏高的人，最常見的原因是脂肪肝，而重量訓練本身就能讓肝指數升高好幾天。在原因還沒找到之前吃任何護肝產品，最可能的結果是把一個數字壓下來、讓原因更難被看見。脂肪肝的處理方向見〈[脂肪肝完整指南](/articles/fatty-liver-masld-reversal-guide/)〉。

## 這是什麼？

膽汁酸是肝臟用膽固醇做出來的分子，存進膽囊，吃飯時排進小腸幫忙消化脂肪，大部分再被小腸吸收回肝臟，這個來回叫腸肝循環。肝臟會把膽汁酸接上甘胺酸或牛磺酸，讓它更容易溶在水裡，牛磺結合型就是其中一種。

UDCA（ursodeoxycholic acid，熊去氧膽酸）是一種親水性高的膽汁酸，名字裡的 urso 來自拉丁文的熊。TUDCA 就是 UDCA 的牛磺結合型，人體膽汁裡本來只有很少的量。

吃進去的 TUDCA 不會原封不動待在體內。Setchell 等 1996 年在《Gut》分析原發性膽汁性膽管炎患者口服 TUDCA 半年後的膽汁組成：每日 500、1,000、1,500 毫克三種劑量下，膽汁中 UDCA 類佔總膽汁酸的比例平均達 34.4%、32.8% 與 41.6%，而且這些 UDCA 有的接甘胺酸、有的接牛磺酸，代表 TUDCA 在腸肝循環中經歷了拆開再重新結合 <a href="#ref-6">[6]</a>。作者認為 TUDCA 在腸道被細菌轉化的比例比 UDCA 低，所以讓膽汁變得更親水的效果可能更明顯 <a href="#ref-6">[6]</a>。

這解釋了 TUDCA 和 UDCA 為什麼總被放在一起討論：吃 TUDCA 的結果有很大一部分是增加體內的 UDCA。

## 在身體裡做什麼？／主要作用機制

**取代比較傷細胞的膽汁酸。** 膽汁酸的親水性差異很大，疏水性高的膽汁酸在膽汁淤積時對肝細胞與膽管細胞有傷害。補充 UDCA 或 TUDCA，會讓膽汁酸池往親水那一端移動，原本的疏水性膽汁酸比例下降 <a href="#ref-6">[6]</a>。這是它用在膽汁淤積性肝病的主要理由。

**被當成「化學伴護分子」研究。** 細胞內的內質網負責摺疊蛋白質，摺疊出錯累積太多時稱為內質網壓力。動物實驗發現 TUDCA 能減輕內質網壓力，研究者因此把它拿去測胰島素阻抗、神經退化疾病 <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>。要分清楚的是，這條路徑在人體的證據還很薄：Kars 2010 年的人體試驗看到胰島素敏感度改善，但肌肉與脂肪組織的內質網壓力指標並沒有改變 <a href="#ref-9">[9]</a>。

**肝指數會降，不代表肝變好。** 這一點對想「把紅字壓下來」的讀者最重要。Lindor 等 2009 年讓 150 名原發性硬化性膽管炎患者服用高劑量 UDCA（每公斤體重每日 28 至 30 毫克）或安慰劑，UDCA 組的 AST 與鹼性磷酸酶降得比較多，可是到研究結束時，達到肝硬化、靜脈曲張、膽管癌、肝移植或死亡等終點的比例是 39% 對 26%，調整後風險為安慰劑組的 2.3 倍，嚴重不良事件也較多（63% 對 37%），試驗因無效提前終止 <a href="#ref-13">[13]</a>。膽汁酸類的東西能讓生化數字好看，那是另一件事，和肝臟的長期結局要分開看。

## 在台灣是藥還是食品？

**目前沒有公開答案：TUDCA 沒有藥證，也不在食品原料平臺上，而它的近親 UDCA 是處方藥。**

**食品這一側查不到。** 2026 年 11 月 21 日下載食藥署食品原料整合查詢平臺開放資料，以 tauroursodeoxycholic、ursodeoxycholic、熊去氧膽酸、牛磺熊去氧膽酸與 TUDCA 檢索，都沒有條目 <a href="#ref-1">[1]</a>。同一份資料裡有「牛、羊、豬膽汁」，列在可供食品使用之原料的禽畜類 <a href="#ref-1">[1]</a>，但那是膽汁本身，和純化或合成的單一膽汁酸是不同的東西。平臺使用說明第 1 點寫明「本平臺非正面表列，並非平臺未載列品項即不得供為食品原料使用」，第 4 點又說產品屬性若經中醫藥司或食藥署藥品組評估應以藥品管理，就要符合藥事法 <a href="#ref-1">[1]</a>。兩點合起來的意思是：查不到 TUDCA，不能推論它可以當食品賣，也不能推論它不行，要由主管機關個案認定。

**藥品這一側只有 UDCA。** 同日下載的全部藥品許可證資料集，主成分含 tauroursodeoxycholic acid 的許可證是 0 張 <a href="#ref-2">[2]</a>。含 ursodeoxycholic acid 的有效許可證有 35 張，分成三類 <a href="#ref-2">[2]</a>：

| 類型 | 張數 | 藥品類別 | 核准適應症 |
|---|---|---|---|
| UDCA 單方錠劑、膠囊（100 至 300 毫克） | 20 | 須由醫師處方使用 | 膽固醇系膽結石之溶解、原發性膽道肝硬化之肝功能改善（1 張僅膽結石） |
| 含 UDCA 的複方（6 張胃腸藥、1 張維生素製劑） | 7 | 醫師藥師藥劑生指示藥品 | 消化不良、食慾不振、胃酸過多等；維生素缺乏症 |
| UDCA 原料藥 | 8 | 製劑原料 | 利膽藥 |

單方 UDCA 全部是處方藥，這個安排可以追到 96 年 12 月 19 日衛署藥字第0960339440號的預告，把含 UDCA 的單方製劑適應症統一為膽結石溶解與原發性膽道肝硬化的肝功能改善，藥品類別統一為醫師處方用藥 <a href="#ref-3">[3]</a>。

**對讀者的實際意義。** 在跨境電商買 TUDCA，台灣這一端沒有可以引用的核准或禁止文件，本頁也查不到食藥署針對 TUDCA 的函釋或邊境查驗案例。若產品標示宣稱治療或改善肝病，就落入藥品範圍。想得到正式答案的業者或民眾，可以向食藥署提出成分屬性的個案詢問。同一個 UDCA 在不同國家的分級可以差很多：韓國把 100 毫克的 UDCA 錠列為一般醫藥品，台灣是處方藥，〈[在韓國藥局買的藥，哪些不能帶回台灣？](/articles/korea-drugstore-medicine-bring-back-taiwan/)〉有整理。

## TUDCA、UDCA、水飛薊素對照

| | TUDCA | UDCA（熊去氧膽酸） | 水飛薊素（乳薊萃取） |
|---|---|---|---|
| 台灣法規位置 | 無藥證；食品原料平臺查無條目 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a> | 單方為處方藥；含 UDCA 的複方有 7 張指示藥 <a href="#ref-2">[2]</a> | 乳薊列「未確認安全性尚不得使用之原料」，平臺註明有含其萃取物之藥品許可證 <a href="#ref-1">[1]</a> |
| 證據最強的用途 | 原發性膽汁性膽管炎（與 UDCA 相當的 24 週生化效果） <a href="#ref-4">[4]</a> | 膽固醇結石溶解、原發性膽汁性膽管炎 <a href="#ref-14">[14]</a> | 見[水飛薊素成分頁](/ingredients/milk-thistle/) |
| 健身、護肝宣稱 | 查無人體試驗 | 不適用（處方藥） | 見成分頁 |
| 主要禁忌與交互作用 | 比照 UDCA：膽道阻塞、膽酸結合樹脂、含鋁制酸劑 | 完全性膽道阻塞為禁忌 <a href="#ref-14">[14]</a> | 見成分頁 |

這張表的重點在第一列。三個常被放在同一個「護肝」貨架上的成分，在台灣沒有一個是可以合法當一般食品原料販售的單純情況：一個沒有公開答案，一個是處方藥，一個在食品端被擋下、在藥品端有許可證。

## 證據怎麼看：各用途的證據等級

**TUDCA 有人體隨機試驗的用途，幾乎都是醫師在處理的疾病；保健品行銷最常提的用途，證據最少。**

| 用途 | 最好的人體證據 | 結果 | 本頁判讀 |
|---|---|---|---|
| 原發性膽汁性膽管炎 | Ma 2016，199 人隨機雙盲，24 週 <a href="#ref-4">[4]</a> | 鹼性磷酸酶改善與 UDCA 相當 | 有對照試驗，但只看生化指標，且這是需要醫師追蹤的疾病 |
| 原發性膽汁性膽管炎劑量 | Crosignani 1996，24 人 <a href="#ref-5">[5]</a> | 三種劑量都讓肝酵素下降，劑量間無顯著差異 | 小型劑量研究 |
| 肝硬化 | Pan 2013，23 人隨機，最後分析 18 人 <a href="#ref-7">[7]</a> | 肝酵素下降，纖維化指標沒有顯著改變 | 樣本太小，無法下結論 |
| C 型肝炎 | Cochrane 2003 回顧，含 4 篇 TUDCA 試驗 <a href="#ref-8">[8]</a> | 膽汁酸類讓轉胺酶改善，病毒、肝硬化、組織學沒有足夠證據 | 方法學品質都不高 |
| 胰島素阻抗 | Kars 2010，20 名肥胖成人，4 週 <a href="#ref-9">[9]</a> | 肝與肌肉胰島素敏感度約升 30% | 有趣但太小、太短 |
| ALS | Elia 2016 先導試驗 34 人；CENTAUR 137 人；PHOENIX 第 3 期 <a href="#ref-10">[10]</a> <a href="#ref-11">[11]</a> <a href="#ref-12">[12]</a> | 第 3 期未達主要終點，複方撤回上市許可 | 早期正面、後期失敗的典型例子 |
| 健身、類固醇護肝、運動恢復 | 本頁在 PubMed 查無人體試驗 | 無 | 沒有證據可評 |

ALS 這一列最能說明早期研究與最終答案的距離。Elia 2016 年的 34 人試驗中，TUDCA 組的反應者比例 87%、安慰劑組 43% <a href="#ref-10">[10]</a>；苯丁酸鈉與 TUDCA 的複方在 CENTAUR 試驗裡，功能量表每月下降 1.24 分，安慰劑組下降 1.66 分 <a href="#ref-11">[11]</a>，之後在美國獲准上市 <a href="#ref-12">[12]</a>。到了規模更大的第 3 期 PHOENIX 試驗，48 週的功能量表總分沒有差異，原廠向美國 FDA 與加拿大衛生部申請撤回上市許可 <a href="#ref-12">[12]</a>。一個成分在小型試驗看起來很有希望，在大型試驗被推翻，這在藥物開發裡很常見；把小型試驗的結果寫成產品頁上的功效，跳過的正是後面那一步。

**健身用途為什麼查不到。** 健身社群使用 TUDCA，常見的說法是在服用口服合成代謝類固醇的期間拿來減輕肝臟負擔。本頁在 PubMed 以 TUDCA 搭配類固醇、健美等關鍵字檢索，沒有找到任何評估它能否預防這類肝損傷的人體試驗。這不代表一定無效，只代表沒有人做過能回答這個問題的研究。用類固醇的人真正需要的是定期抽血追蹤肝功能，補充品替代不了這件事。

## 安全性與注意事項

**一般劑量的耐受性不差，但有兩類人不該自己用：膽道阻塞的人，以及正在用膽汁酸相關藥物或已在治療肝病的人。**

**腹瀉是最常見的副作用。** Crosignani 1996 年的劑量研究中，每日 500 至 1,500 毫克的 TUDCA 唯一出現的副作用就是腹瀉 <a href="#ref-5">[5]</a>；Ma 2016 年的 199 人試驗中，TUDCA 組與 UDCA 組的不良事件率相近 <a href="#ref-4">[4]</a>。URSO 仿單列出的常見不良反應包括腹部不適、腹痛、腹瀉、噁心、皮膚癢與皮疹 <a href="#ref-14">[14]</a>。

**膽道阻塞是禁忌。** URSO 仿單把完全性膽道阻塞列為禁忌，並寫明服藥者需要維持膽汁流動，出現阻塞性症狀時先停藥評估 <a href="#ref-14">[14]</a>。TUDCA 作用在同一條膽汁路徑，沒有理由例外。右上腹劇痛、皮膚或眼白變黃、大便顏色變淺、尿色變深，這些是要先就醫的訊號。

**和幾類常用藥會互相干擾。**

| 正在用的藥 | 可能的問題 | 依據 |
|---|---|---|
| 膽酸結合樹脂（cholestyramine、colestipol） | 在腸道結合膽汁酸，干擾作用 | URSO 仿單 <a href="#ref-14">[14]</a> |
| 含鋁制酸劑 | 體外會吸附膽汁酸 | URSO 仿單 <a href="#ref-14">[14]</a> |
| 雌激素、口服避孕藥、clofibrate，可能包括其他降血脂藥 | 增加膽固醇分泌，抵消溶石作用 | URSO 仿單 <a href="#ref-14">[14]</a> |

這些交互作用寫在 UDCA 的仿單上，TUDCA 沒有自己的處方藥仿單可查，本頁以同類膽汁酸比照。正在吃降血脂藥或制酸劑的人，想加用 TUDCA 之前，先讓開藥的醫師或藥師知道，服藥時間怎麼錯開由他們安排。

**已經在治療肝病的人，不要自己疊加。** Lindor 2009 的高劑量 UDCA 試驗說明膽汁酸類的劑量有上限，超過之後在某些疾病反而有害 <a href="#ref-13">[13]</a>。正在服用 UDCA 處方藥的人再自己買 TUDCA，等於在醫師不知情的情況下增加了膽汁酸總量。

**產品品質沒有人把關。** 在台灣，TUDCA 沒有藥證、也沒有食品原料登載，代表沒有任何一套台灣的品質規格適用在它身上。跨境購買時，每顆實際含量與純度只能依賴國外廠商的標示。

## 常見迷思

- **「GPT 降下來就代表肝變好了」**：高劑量 UDCA 在原發性硬化性膽管炎讓肝指數下降，同時讓臨床終點事件增加 <a href="#ref-13">[13]</a>。數字和結局要分開看
- **「TUDCA 是天然的，人體本來就有」**：人體膽汁確實有少量 TUDCA，但補充品每天幾百毫克到一兩公克，研究裡改變的是整個膽汁酸池的組成 <a href="#ref-6">[6]</a>，這是藥理劑量
- **「在美國是補充品，所以在台灣也是保健食品」**：台灣食品原料平臺查不到它，藥品許可證也沒有它 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>，美國的分類不會自動延伸到台灣
- **「有 ALS 的研究，所以對神經有保護作用」**：含 TUDCA 的複方在第 3 期試驗失敗、已撤回上市許可 <a href="#ref-12">[12]</a>
- **「健身吃類固醇，配 TUDCA 就能護肝」**：本頁查不到支持這句話的人體試驗

## 常見問題

### 健檢 GPT 偏高，可以先吃 TUDCA 看看嗎？

順序反了。肝指數升高要先找原因，脂肪肝、病毒性肝炎、飲酒、藥物與保健品、重量訓練都可能是答案，有些需要治療，有些只需要複檢。先吃護肝產品把數字壓下來，可能讓原因更難被找到。TUDCA 有證據的用途是原發性膽汁性膽管炎這類需要醫師追蹤的疾病 <a href="#ref-4">[4]</a>，健檢紅字的處理流程請看[肝指數偏高的那一篇](/articles/liver-enzymes-got-gpt-high-next-step/)。

### TUDCA 和醫師開的熊去氧膽酸（UDCA）有什麼不同？

TUDCA 是 UDCA 接上牛磺酸的形式，吃進去後有一部分會轉成 UDCA <a href="#ref-6">[6]</a>。兩者在原發性膽汁性膽管炎的 24 週生化效果相當 <a href="#ref-4">[4]</a>。法規上差很多：UDCA 在台灣有 20 張單方處方藥證 <a href="#ref-2">[2]</a>，TUDCA 一張都沒有。正在吃 UDCA 的人不要自己再加 TUDCA。

### 在台灣網購 TUDCA 合法嗎？

本頁查不到明確答案。食藥署食品原料平臺沒有它的條目，平臺又聲明不是正面表列；藥品許可證資料集也沒有它 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>。本頁沒有找到食藥署針對 TUDCA 的函釋、處分或邊境查驗案例。可以確定的是，若產品宣稱治療肝病，就屬藥品範圍；買回來轉賣則另有食品或藥品的販售責任。

### 有膽結石可以吃 TUDCA 嗎？

先問醫師。UDCA 在台灣的適應症之一是膽固醇結石溶解，但不是每一種結石都適用，醫師會先確認結石種類、膽囊功能與有沒有阻塞 <a href="#ref-3">[3]</a> <a href="#ref-14">[14]</a>。完全性膽道阻塞是禁忌，正在膽絞痛或有黃疸的人更不能自己吃。

### 一天吃多少 TUDCA？

本頁不提供自行補充的劑量。研究裡用過的劑量從每日 500 毫克到 2 公克都有，對象是原發性膽汁性膽管炎、肥胖或 ALS 患者 <a href="#ref-4">[4]</a> <a href="#ref-5">[5]</a> <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>，這些劑量是在醫療監測下使用的，不能直接搬到一般人身上。

### 吃 TUDCA 會拉肚子嗎？

可能會。腹瀉是 TUDCA 劑量研究中唯一回報的副作用 <a href="#ref-5">[5]</a>，UDCA 仿單也把腹瀉列在常見不良反應 <a href="#ref-14">[14]</a>。持續腹瀉的人應該停用並告訴醫師。
