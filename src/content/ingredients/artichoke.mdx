## 30 秒認識

- 朝鮮薊的花苞、花托和葉，都列在食藥署食品原料整合查詢平臺的「可供食品使用之原料」，沒有限量或警語 <a href="#ref-1">[1]</a>
- 台灣沒有任何一張藥品許可證以朝鮮薊為成分，570 筆健康食品資料裡也沒有一筆用到它 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>。市售朝鮮薊膠囊都是一般食品，依法不能宣稱護肝或降膽固醇 <a href="#ref-4">[4]</a>
- 降血脂的統合分析：LDL 平均下降約 15 到 17 mg/dL，試驗多為數十人、幾個月以內，沒有追蹤心血管事件 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>
- 肝指數的統合分析：ALT、AST 下降，但納入的多是伊朗的小型試驗，2026 年一篇德國試驗看到 AST 反而上升 <a href="#ref-9">[9]</a> <a href="#ref-13">[13]</a>

## 基本介紹

健檢報告上 GPT 和 LDL 同時亮紅字，是很多人第一次在藥妝店或電商搜尋「護肝」「降膽固醇」的時刻。朝鮮薊萃取常跟水飛薊、薑黃、B 群放在同一顆複方膠囊裡，包裝寫著「養護」「代謝」「順暢」。

這一頁只談朝鮮薊本身。三種常見護肝成分怎麼選，〈[如何選對護肝保健品：水飛薊素、朝鮮薊、TUDCA 各適合誰](/articles/liver-supplement-comparison-silymarin-artichoke-tudca/)〉已經比較過；水飛薊與 TUDCA 各自的法規與證據，見[水飛薊素](/ingredients/milk-thistle/)與 [TUDCA](/ingredients/tudca/) 兩頁。肝指數紅字的第一步是複檢還是看診，請先讀〈[健檢肝指數（GOT、GPT）偏高，要先複檢還是直接看肝膽科？](/articles/liver-enzymes-got-gpt-high-next-step/)〉。

先把兩件事分開。菜市場或進口超市買得到的朝鮮薊是蔬菜，煮來吃的是花苞與花托；保健品用的多半是葉子做的乾燥萃取物，濃縮倍數從 2 倍到 35 倍都有 <a href="#ref-5">[5]</a>。下面講的試驗與禁忌，幾乎都是葉萃取，不能直接套到餐桌上的那顆朝鮮薊。

## 這是什麼？

朝鮮薊屬於菊科，學名有兩種寫法：Cynara scolymus L. 是較常見的舊名，歐洲藥品管理局的專論採用 Cynara cardunculus L.，並把前者列為同物異名 <a href="#ref-5">[5]</a>。台灣平臺登載的中文名有朝鮮薊、菜薊、食用薊、洋菜薊四個 <a href="#ref-1">[1]</a>。

名字裡有 artichoke 的植物不只一種。平臺上的菊芋（Jerusalem artichoke）吃的是塊莖，草石蠶（Japanese artichoke）吃的是根莖，兩者都和朝鮮薊不同屬 <a href="#ref-1">[1]</a>。看英文標籤時要確認學名是 Cynara。

葉萃取最常被拿來標示的成分是洋薊酸（cynarin），Kirchhoff 1994 年的試驗把它當成萃取物的主成分 <a href="#ref-16">[16]</a>；Santos 等 2018 年的回顧認為，降血脂作用可能主要來自其中的木犀草素與綠原酸 <a href="#ref-18">[18]</a>。朝鮮薊另外含有倍半萜內酯，這是菊科植物常見的致敏成分，和後面的過敏風險直接相關 <a href="#ref-17">[17]</a>。

## 在身體裡做什麼？／主要作用機制

**最確定的作用是讓膽汁分泌變多。** Kirchhoff 等 1994 年做了一個 20 人的隨機雙盲交叉試驗，把 1.92 公克標準化朝鮮薊萃取直接送進十二指腸，用多通道管量膽汁分泌：30 分鐘後比基準增加 127.3%，60 分鐘後 151.5%，再過 60 分鐘仍有 94.3%，和安慰劑的差異達統計顯著 <a href="#ref-16">[16]</a>。這是它被用在油膩飯後脹氣、消化不良的主要理由。

這個作用同時是禁忌症的來源。膽汁從肝臟出來、經膽管進入十二指腸，膽結石卡住膽管、膽管發炎或狹窄時，出口本來就不順，再把膽汁量往上推，方向是錯的。歐洲藥品管理局因此把膽道阻塞、膽管炎、膽結石與需要醫療監督的膽道疾病列為禁忌 <a href="#ref-5">[5]</a>。

**降血脂的機制還停在推論。** Santos 等 2018 年只納入人體介入研究做回顧，整理出每日 2 到 3 公克葉萃取時，各試驗的 LDL 下降範圍從 8 到 49 mg/dL，差距很大；作者把可能的作用歸給木犀草素與綠原酸，煮熟的朝鮮薊心則主要歸給可溶性纖維菊糖，並寫明仍需要長期臨床試驗確認對心血管結局的影響 <a href="#ref-18">[18]</a>。人體試驗量到的，到目前為止只有血中數字的變化。

**肝指數下降，不等於肝臟結局改善。** 目前朝鮮薊的肝臟試驗，看的是 ALT、AST、超音波或 FibroScan 的脂肪變性指標，追蹤 6 週到 2 個月 <a href="#ref-11">[11]</a> <a href="#ref-12">[12]</a> <a href="#ref-13">[13]</a>。沒有任何一篇看到纖維化進展、肝硬化或肝癌這些長期結局。

## 在台灣是食品、藥品，還是健康食品？

**三條路查下來，它只有一個身分：一般食品原料。**

**食品端：可以用，沒有附加限制。** 2026 年 11 月 22 日下載食藥署食品原料整合查詢平臺開放資料，朝鮮薊列在「可供食品使用之原料」的草、木本植物類(2)可供直接食用，部位是花苞、花托、葉，備註欄沒有食用限量、限用型態或警語 <a href="#ref-1">[1]</a>。這和水飛薊的處境相反，水飛薊在同一個平臺被列為未確認安全性、尚不得使用的原料，詳見[水飛薊素成分頁](/ingredients/milk-thistle/)。平臺使用說明第 4 點另外寫明，產品屬性若經衛福部中醫藥司或食藥署藥品組評估應以藥品管理，就要符合藥事法 <a href="#ref-1">[1]</a>。

**藥品端：沒有。** 同日下載的全部藥品許可證資料集，含已註銷的共 72,129 筆，以 cynara、artichoke、朝鮮薊、菜薊檢索主成分、品名與適應症，結果都是 0 筆 <a href="#ref-2">[2]</a>。歐洲有朝鮮薊葉的草藥製劑，台灣沒有。

**健康食品端：也沒有。** 健康食品資料集共 570 筆，保健功效含「護肝」的有 61 筆、含「調節血脂」的有 232 筆，但全部欄位都找不到朝鮮薊 <a href="#ref-3">[3]</a>。換一個角度講，台灣核准過的護肝與調節血脂健康食品，沒有一張是靠朝鮮薊拿到的。

**這對貨架上的產品代表什麼。** 衛福部的〈食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則〉第 4 條規定，表述內容涉及維持或改變人體器官、組織、生理功能的，認定為不實、誇張或易生誤解；第 5 條規定，涉及減輕或降低導致疾病有關之體內成分的，認定為涉及醫療效能 <a href="#ref-4">[4]</a>。一般食品寫「護肝」「保肝」碰到前者，寫「降膽固醇」「降血脂」碰到後者。朝鮮薊膠囊合法地在架上賣，可以；包裝或直播講它能護肝、降膽固醇，不可以。看到這類字眼，本頁的建議是把它當成一個警訊。

## 證據怎麼看：試驗一覽

**降血脂與肝指數都有統合分析，但底下是同一批小型、短期、地區集中的試驗；能稱得上被官方接受的用途，只有消化不良。**

**降血脂：幅度有，但量級要看清楚。** LDL 下降 15 到 17 mg/dL，以 LDL 160 的人來算大約一成 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>。Sahebkar 的分析看到，基線 LDL 越高的試驗，降得越多 <a href="#ref-7">[7]</a>。這些試驗沒有一篇追蹤到心肌梗塞、中風或死亡，所以「吃朝鮮薊可以減少心血管疾病」這句話，目前沒有直接證據。已經在吃降血脂藥的人，用藥的決定以醫師評估的心血管風險為準，朝鮮薊不能拿來換藥。

**肝指數：統合分析的結論比底下的試驗看起來樂觀。** Amini 2022 年的分析中，為期 8 週以內的試驗效果比較大 <a href="#ref-9">[9]</a>。本頁的解讀是，這比較可能反映短期小型試驗容易高估效果，不宜解讀成「短期吃比較有效」。Panahi 的試驗同時看到 HDL 下降 <a href="#ref-11">[11]</a>，Holländer 2026 年的德國試驗則是 AST 上升 <a href="#ref-13">[13]</a>，作者推測肥胖族群的肝臟反應可能不同，需要更多研究。兩個結果都提醒同一件事：這些數字會被朝鮮薊改變，但改變的方向和意義還沒有定論。

**消化不良：證據最穩，也是歐洲唯一接受的用途。** 歐洲藥品管理局 2018 年的專論把朝鮮薊葉登記為傳統草藥，用途是緩解消化不良的飽脹、脹氣與排氣，依據是長期使用經驗；專論沒有接受降血脂或護肝的用途 <a href="#ref-5">[5]</a>。專論也寫明，症狀持續超過 2 週要看醫師 <a href="#ref-5">[5]</a>。2024 年起，這份專論進入第二次定期審查，正在徵求新的科學資料 <a href="#ref-6">[6]</a>。

## 安全性與注意事項

**一般人短期吃的副作用以腸胃不適為主；真正要擋的是三群人：膽道有問題的人、已有肝病的人、菊科過敏的人。**

**常見副作用。** 歐洲藥品管理局專論列出輕微腹瀉伴隨腹部痙攣、噁心、胃灼熱等上腹不適，以及過敏反應，發生頻率不明 <a href="#ref-5">[5]</a>。Panahi 2018 年的試驗沒有回報副作用 <a href="#ref-11">[11]</a>。

**膽結石與膽道疾病。** 專論的禁忌症原文列出膽道阻塞、膽管炎、肝病、膽結石，以及任何需要醫療監督與建議的膽道疾病 <a href="#ref-5">[5]</a>。台灣健檢腹部超音波常順帶看到膽結石，很多人沒有症狀、也不知道自己有。準備吃朝鮮薊之前，先翻一下最近一次的超音波報告。

**肝病本身就在禁忌清單上。** 這是本頁最想讓讀者看到的一句。買朝鮮薊護肝的人，很大一部分是因為肝指數異常；歐洲藥品管理局的專論卻把「肝病」寫進禁忌症，理由是這類情況需要醫療監督 <a href="#ref-5">[5]</a>。脂肪肝怎麼追蹤、何時要做纖維化評估，見〈[脂肪肝完整指南](/articles/fatty-liver-masld-reversal-guide/)〉。

**菊科過敏。** 專論的第一條禁忌症就是對朝鮮薊或其他菊科植物過敏 <a href="#ref-5">[5]</a>。Deydier 等 2023 年整理法國 2001 到 2018 年的職業病資料，找到 10 例朝鮮薊引起的接觸性皮膚炎，其中 7 例是過敏性接觸性皮膚炎，患者包括農民、食品加工人員、菜農與收銀員 <a href="#ref-17">[17]</a>。這些是皮膚接觸，不是口服，但說明朝鮮薊的致敏成分確實存在。對菊花、豚草、萬壽菊、洋甘菊過敏的人，連帶要小心同一顆複方裡的水飛薊等其他菊科成分。

**孕婦、哺乳者與兒童。** 專論認為孕期與哺乳期安全性沒有建立，不建議使用；12 歲以下缺乏資料 <a href="#ref-5">[5]</a>。

| 誰 | 為什麼要先停 | 依據 |
|---|---|---|
| 膽結石、膽道阻塞、膽管炎 | 會增加膽汁分泌，出口卡住時方向錯誤 | 歐洲藥品管理局專論禁忌症 <a href="#ref-5">[5]</a>；Kirchhoff 1994 <a href="#ref-16">[16]</a> |
| 已確診肝病、正在追蹤 | 列為禁忌症，需要醫療監督 | 歐洲藥品管理局專論禁忌症 <a href="#ref-5">[5]</a> |
| 菊科植物過敏 | 列為禁忌症，含致敏的倍半萜內酯 | 專論 <a href="#ref-5">[5]</a>；Deydier 2023 <a href="#ref-17">[17]</a> |
| 正在吃降血脂藥 | 會干擾醫師判讀血脂變化 | Sahebkar 2018 <a href="#ref-7">[7]</a> |
| 孕婦、哺乳者、12 歲以下 | 安全性資料不足 | 專論 <a href="#ref-5">[5]</a> |

## 怎麼看貨架上的朝鮮薊產品

- **先看學名與部位**：確認是 Cynara scolymus 或 Cynara cardunculus 的葉萃取，菊芋、草石蠶是不同植物
- **看是單方還是複方**：複方裡常同時有水飛薊，水飛薊在台灣不得作為食品原料使用，詳見水飛薊素成分頁
- **看宣稱用語**：一般食品寫護肝、降膽固醇、降血脂，依認定準則屬於不實誇張或醫療效能 <a href="#ref-4">[4]</a>
- **看自己的超音波報告**：報告寫到膽結石、膽管擴張，或醫師說過肝臟有狀況，先問醫師
- **吃了兩週沒改善就停**：歐洲專論對消化不良症狀的建議是超過 2 週要看醫師 <a href="#ref-5">[5]</a>

## 常見迷思

- **「朝鮮薊是蔬菜，萃取物一定也很安全」**：餐桌上吃的是花苞與花托，保健品多半是葉的濃縮萃取，歐洲專論的禁忌症是針對葉製劑寫的 <a href="#ref-5">[5]</a>
- **「有統合分析，所以降膽固醇效果確定」**：統合分析的量級是 LDL 下降十多 mg/dL，底下是小型短期試驗，沒有心血管事件的資料 <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>
- **「肝指數不好就該吃朝鮮薊」**：歐洲藥品管理局把肝病列為禁忌症 <a href="#ref-5">[5]</a>，肝指數異常要先找原因
- **「台灣可以合法賣，代表官方認可它護肝」**：可以當食品原料，跟能不能宣稱功效是兩回事；台灣沒有任何一張朝鮮薊健康食品許可 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a>

## 常見問題

### 朝鮮薊真的能護肝嗎？

目前的證據只到肝指數與脂肪變性指標的短期變化。Amini 2022 與 Kamel 2022 兩篇統合分析都看到 ALT、AST 下降 <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>，但試驗多為伊朗的小型研究、追蹤 2 個月左右，2026 年的德國試驗還看到 AST 上升 <a href="#ref-13">[13]</a>。沒有試驗追蹤到肝纖維化、肝硬化等長期結局。歐洲藥品管理局沒有接受護肝用途，還把肝病列為禁忌 <a href="#ref-5">[5]</a>。

### 有膽結石可以吃朝鮮薊嗎？

不建議自己吃。朝鮮薊萃取會讓膽汁分泌明顯增加 <a href="#ref-16">[16]</a>，歐洲藥品管理局把膽結石、膽道阻塞與膽管炎都列為禁忌症 <a href="#ref-5">[5]</a>。有膽結石的人想處理消化不良，先讓醫師評估症狀是不是膽結石本身造成的。

### 朝鮮薊可以取代降膽固醇藥嗎？

不行。統合分析中 LDL 平均下降 15 到 17 mg/dL <a href="#ref-7">[7]</a> <a href="#ref-8">[8]</a>，而且沒有任何試驗證明它能減少心肌梗塞或中風。正在吃降血脂藥的人想加用，先告訴開藥的醫師或藥師，讓他們判讀後續的血脂數字。

### 在台灣買朝鮮薊膠囊合法嗎？

朝鮮薊的花苞、花托、葉是可供食品使用的原料，當一般食品賣是合法的 <a href="#ref-1">[1]</a>。不合法的是宣稱：一般食品標示或廣告「護肝」「降膽固醇」，依衛福部認定準則屬於不實誇張或醫療效能 <a href="#ref-4">[4]</a>。另外要看複方裡有沒有平臺列為不得使用的原料，例如水飛薊。

### 對菊花過敏，可以吃朝鮮薊嗎？

不建議。朝鮮薊屬菊科，歐洲藥品管理局把菊科植物過敏列為第一條禁忌症 <a href="#ref-5">[5]</a>。曾經對菊花茶、洋甘菊或豚草花粉有明顯過敏反應的人，避開朝鮮薊萃取與含其他菊科成分的複方。

### 直接吃朝鮮薊這種蔬菜，有一樣的效果嗎？

不能直接比較。上面的試驗用的都是葉萃取，濃縮倍數從 2 倍到 35 倍都有 <a href="#ref-5">[5]</a>。Santos 2018 年的回顧把煮熟朝鮮薊心對血脂的可能作用，主要歸給它的可溶性纖維菊糖，和葉萃取是不同的成分路線 <a href="#ref-18">[18]</a>。當成一般蔬菜吃沒有問題，它提供的是膳食纖維，不需要期待它有膠囊宣稱的效果。
