## 30 秒認識

- HMB（β-羥基-β-甲基丁酸）是白胺酸代謝後的中間產物，人體會自行合成，但量非常少，補充品是唯一能吃到研究常用劑量的實際做法。 <a href="#ref-1">[1]</a>
- 國際運動營養學會（ISSN）立場聲明指出，HMB可能減緩劇烈或不熟悉的運動造成的骨骼肌損傷，搭配阻力訓練時對肌力與肌肉量有幫助。 <a href="#ref-2">[2]</a>
- 針對50歲以上族群的多篇統合分析發現，補充HMB對除脂體重與握力等肌力指標有正向效果。一篇彙整9篇研究、448人的統合分析顯示除脂體重顯著增加、但對脂肪量沒有影響，整體效應量普遍偏小，比較合適的定位是搭配蛋白質與阻力訓練的輔助選項。 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a>
- HMB有兩種型態：鈣鹽（HMB-Ca）與游離酸（HMB-FA）。2023年一項16人的人體交叉試驗發現鈣鹽型態的吸收率其實優於游離酸，和過去廠商行銷話術的說法相反。 <a href="#ref-4">[4]</a>
- 短期到中期使用在健康成人身上耐受性良好，但HMB常搭配精胺酸、麩醯胺酸用於住院、癌症惡病質或術前營養不良病人的臨床試驗，這類特殊族群使用前應與醫療團隊討論。 <a href="#ref-9">[9]</a>

## 基本介紹

HMB全名β-羥基-β-甲基丁酸（β-Hydroxy β-Methylbutyrate），是必需胺基酸白胺酸（leucine）代謝路徑上的中間產物。人體攝取的白胺酸約有5%會經由這條路徑轉化為HMB，其餘則直接參與蛋白質合成或走其他代謝路徑。 <a href="#ref-1">[1]</a> 它在運動營養領域被討論的歷史約三十年，最早的研究方向是肌力訓練與肌肉損傷恢復，近十年則有相當比例的試驗轉向高齡族群的肌肉量與肌力維持，以及住院、臥床等營養不良風險族群的肌肉保存。

## 這是什麼？

HMB的身分是白胺酸代謝路徑上的下游產物，不算原型營養素，這個定位和肌酸有點類似，肌酸同樣是人體自行合成、也能從補充品攝取的含氮化合物。差別在於，肌酸主要儲存在骨骼肌、直接參與能量代謝，HMB的作用路徑則被認為與肌肉蛋白質的合成和分解平衡較相關。市售產品標示常見「HMB」或全名縮寫，化學型態上分成鈣鹽（HMB-Ca，calcium HMB）與游離酸（HMB-FA，free acid），兩者在人體內最終代謝的物質相同，差別在吸收速率與型態。 <a href="#ref-4">[4]</a>

## 在身體裡做什麼？／主要作用機制

HMB的作用機制目前仍在累積證據，兩個較常被引用的方向是：其一，作為細胞膜膽固醇合成路徑上的輔助原料，運動造成肌纖維膜受損時，理論上能協助修復結構；其二，透過影響mTOR訊號路徑促進肌肉蛋白質合成，同時抑制泛素蛋白酶體系統（ubiquitin-proteasome）減少肌肉蛋白質分解。 <a href="#ref-1">[1]</a> 這兩個方向合起來的假說是：HMB同時從「多合成」與「少分解」兩端，讓肌肉蛋白質的淨平衡往正向移動。這仍是機制層級的推論，實際能不能轉化成可測得的肌肉量或肌力變化，要看後面統合分析的結果，機制合理不等於效果一定明顯。

## 食物來源／常見來源

超過600克的優質蛋白質，是理論上換算出每日3克HMB所需白胺酸攝取量，這在日常飲食中並不切實際。 <a href="#ref-1">[1]</a> 天然食物中的HMB含量也極低，苜蓿芽、鯰魚、葡萄柚等食物曾被測出微量HMB，但每份食物提供的量以毫克計，距離研究劑量差距懸殊。 <a href="#ref-1">[1]</a> 也因為如此，市面上討論HMB幾乎不談「食物來源」，直接鎖定合成補充品，多數試驗設計也直接用萃取純化的HMB介入，而不是嘗試從飲食調整著手。

## 建議攝取量／常見攝取建議／研究中常見使用方式

研究文獻最常使用的劑量是每日3克，多分2到3次於餐間或運動前後服用。 <a href="#ref-1">[1]</a> ISSN的立場聲明建議，若要用於減緩運動造成的肌肉損傷，在運動前至少提前兩週開始補充效果較穩定，單次臨時服用較難看到明顯差異。 <a href="#ref-2">[2]</a> 高齡族群的統合分析多半也採每日3克、為期8到24週不等的介入設計。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a> 型態選擇上，過去業界曾宣稱游離酸吸收更快、效果更好，但2023年一項16人的交叉設計人體試驗發現，鈣鹽型態（不論裝入膠囊或溶於水中）的相對生體可用率都優於游離酸膠囊，鈣鹽溶於水的達峰時間也最短，等於推翻了游離酸較優的舊說法。 <a href="#ref-4">[4]</a> 兩種型態的消除動力學相近，差別主要出現在吸收階段而非後續代謝。這項試驗的受試者是16位健康年輕成人（8男8女，平均28歲），測的是吸收速率等藥物動力學指標，不是高齡肌少症族群的實際肌肉功能結果，兩種型態哪個對長期效果更有利，還待更多研究驗證。

## 缺乏風險或攝取不足問題

健康人不會因為沒有額外補充HMB而生病，它不是傳統定義下會出現「缺乏症」的營養素。人體每天內生合成的量極少，但正常生理狀況下並不需要靠外源HMB維持基本機能。目前的研究焦點集中在特定情境下「額外補充是否有加分」，而不是「不補充會不會出問題」，這個框架上的差異很關鍵：使用者若把HMB當成必需品看待、擔心不吃會缺乏，是對它性質的誤解。真正累積出效果證據的族群，是高齡肌少症患者、臥床或住院的營養不良風險者，以及訓練負荷驟增的運動員，這些情境下肌肉分解速率本來就偏高，額外補充HMB的邊際效益才比較容易被試驗觀察到。 <a href="#ref-8">[8]</a> 一篇彙整3項隨機對照試驗、203位高齡肌少症或衰弱者（平均67至85歲）的系統性回顧也發現，HMB補充能增加或維持除脂體重，並保留肌力與功能表現，不過作者也指出研究數量與樣本數偏小，證據等級屬於低確定性。 <a href="#ref-12">[12]</a>

## 補充品常見形式

市售HMB主要有兩種型態：鈣鹽（HMB-Ca）與游離酸（HMB-FA）。鈣鹽是最早商業化、研究資料最多的型態，通常以粉末或膠囊販售；游離酸多做成液態或膠囊，訴求吸收更快。前一節提到的2023年交叉試驗結果顯示，鈣鹽型態的實際吸收表現並不輸游離酸，甚至在部分指標上更好，選購時不必因為「游離酸」標示而多花錢。 <a href="#ref-4">[4]</a> 也有廠商把HMB和精胺酸、麩醯胺酸做成複方，這個組合多半沿用臨床營養不良族群的試驗配方（如癌症惡病質、術前營養支持），一般健康使用者不一定需要這種複方濃度。 <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a>

## 安全性與注意事項

短期（3至8週）每日3克劑量的耐受性資料相當紮實，未見明顯的肝腎功能異常或嚴重不良反應；另有兩項併用精胺酸/離胺酸或維生素D3的複方研究，長達一年未觀察到不良反應，但單方HMB的一年期安全性資料仍有限。 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a> 常見的輕微副作用包括腸胃不適，多出現在劑量偏高或空腹服用時。孕婦、哺乳者與慢性疾病患者（尤其肝腎功能異常者）目前缺乏足夠的長期安全性資料，建議使用前先諮詢醫師或藥師。 <a href="#ref-1">[1]</a> 臨床上用於癌症惡病質、心臟手術前後或肝硬化營養不良患者的HMB劑量與搭配成分（常合併精胺酸、麩醯胺酸），是在醫療團隊監控下的營養處方，不能直接套用一般保健品的用法用量。 <a href="#ref-9">[9]</a> <a href="#ref-10">[10]</a> <a href="#ref-11">[11]</a>

## 常見迷思

- 「HMB和肌酸是同一種東西」：錯誤。兩者都是人體能自行合成、也能從補充品攝取的成分，但代謝來源與作用機制不同，肌酸來自精胺酸等三種胺基酸並直接參與能量供應，HMB則是白胺酸的代謝物，作用被認為與肌肉蛋白質合成分解平衡較相關。 <a href="#ref-1">[1]</a>
- 「只有健美選手或競技運動員需要HMB」：研究族群其實涵蓋範圍很廣，高齡肌少症、臥床住院的營養不良患者、癌症惡病質病人都是近年試驗的重點對象，不是只鎖定運動表現。 <a href="#ref-6">[6]</a> <a href="#ref-9">[9]</a>
- 「游離酸型態一定比鈣鹽吸收快、效果好」：這個說法是早期基於理論推測的行銷話術，2023年的人體交叉試驗結果剛好相反，鈣鹽型態的整體生體可用率更高。 <a href="#ref-4">[4]</a>
- 「吃了HMB就能取代阻力訓練或蛋白質」：目前的統合分析都把HMB定位為搭配訓練與飲食的輔助角色，效應量普遍不大，單獨使用很難達到訓練帶來的效果。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a>
- 「HMB對所有年齡層效果都一樣明顯」：多篇高齡族群統合分析看到的效應量本來就有限，且部分研究族群鎖定在肌肉量或營養狀況原本較差的長者，效果不能直接類推到營養狀況良好的年輕族群。 <a href="#ref-6">[6]</a>

## 常見問題

**HMB和乳清蛋白該選哪一個？可以一起吃嗎？**
兩者定位不同，不是互斥選項。乳清蛋白本質上是蛋白質來源，補給的是身體合成肌肉蛋白質所需的原料；HMB則被認為在合成與分解平衡上扮演輔助角色，用量遠小於蛋白質。若正餐蛋白質攝取量已達每餐25到30克的建議，額外加HMB是否有加分因人而異；若正餐蛋白質不足，優先把蛋白質補齊，比單獨加HMB更有實證基礎。兩者也可以合併使用，但實際要不要補充、劑量多少，建議與醫師或營養師討論，並以阻力訓練與足量蛋白質作為介入核心。

**吃HMB多久會看到效果？**
多數運動與高齡族群的試驗設計介入期在8週以上，部分統合分析涵蓋到24週。短期（如兩週內）的變化多半難以測得，這也是ISSN建議提前於運動前兩週開始補充的原因之一。 <a href="#ref-2">[2]</a>

**高齡長輩想預防肌少症，可以直接吃HMB取代看醫生嗎？**
目前證據不支持用HMB取代就醫評估。HMB在部分統合分析中對除脂體重與握力有正向效果，但效應量有限，且多數研究族群仍搭配蛋白質或阻力訓練介入，證據還不足以支持把它當成獨立治療方式。長輩若懷疑有肌少症風險，比較穩妥的路徑是先透過小腿圍測量、SARC-F問卷等方式初步篩檢，異常再到醫療院所評估握力與體能表現，由醫師與營養師規劃完整的介入方案。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a>

**HMB可以長期吃嗎？會不會有依賴性？**
目前沒有證據顯示HMB會造成生理依賴。安全性資料多集中在數月到一年的介入期間，長達數年的長期使用資料仍然有限，建議定期評估是否仍有補充需要，而不是無限期持續使用。 <a href="#ref-2">[2]</a>
