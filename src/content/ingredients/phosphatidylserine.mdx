## 30 秒認識

- 磷脂絲胺酸（Phosphatidylserine，簡稱PS）是細胞膜上的一種磷脂質，在神經細胞膜上濃度特別高，最早的臨床試驗證據來自1980年代的牛腦皮質萃取物（BC-PS）。 <a href="#ref-3">[3]</a>
- 1990年代因狂牛症（牛海綿狀腦病，BSE）疑慮，業界全面停用牛腦來源，改以大豆卵磷脂經酵素轉化製成大豆磷脂絲胺酸（S-PS）；但2001年第一篇大豆來源的雙盲試驗，在120名長者身上並沒有觀察到牛腦來源試驗當年看到的認知效果。 <a href="#ref-5">[5]</a>
- FDA在2003年核准磷脂絲胺酸「可能降低老年人認知功能障礙與失智症風險」的合格健康聲明，但依規定必須同時標示「有限且初步的科學研究……FDA的結論是支持此聲明的科學證據很少」這段免責聲明。 <a href="#ref-1">[1]</a>
- 2010年後採用較新配方（大豆磷脂絲胺酸搭配omega-3脂肪酸的PS-DHA複方，或提高純度的大豆磷脂絲胺酸單方）的試驗，重新在特定次族群（如基線認知狀態較好或較差的長者）觀察到記憶測驗上的正向結果。 <a href="#ref-8">[8]</a>
- 磷脂絲胺酸也被用於運動與心理壓力後的皮質醇反應研究：每日400至800毫克、連續10到42天的試驗，在健康男性與長期高壓族群身上觀察到皮質醇與ACTH反應被緩和，但劑量不足（如每日200毫克）時效果不明顯。 <a href="#ref-12">[12]</a>

## 基本介紹

磷脂絲胺酸屬於甘油磷脂質（glycerophospholipid）家族的一員，是構成細胞膜脂雙層的基本成分之一，在腦組織與神經細胞膜上的濃度比其他組織高出許多。它並非維生素或必需營養素，人體本身可以透過絲胺酸交換反應，從磷脂醯膽鹼或磷脂醯乙醇胺合成出磷脂絲胺酸，因此不存在傳統定義下的「缺乏症」。它在保健食品市場上受到關注，主要是因為1980年代一系列使用牛腦皮質萃取物的臨床試驗，在老化相關記憶減退與早期阿茲海默症患者身上觀察到認知測驗表現的改善。 <a href="#ref-3">[3]</a> 但這批早期試驗使用的原料，與今天貨架上多數磷脂絲胺酸保健品的原料來源並不相同，這個「來源換了、證據要不要重新檢視」的問題，正是FDA在後續信函中反覆處理的核心爭議。 <a href="#ref-2">[2]</a>

## 這是什麼？

磷脂絲胺酸的化學結構是甘油骨架接上兩條脂肪酸鏈、一個磷酸根，再連接絲胺酸這個帶負電的胺基酸頭部基團，這個結構讓它在細胞膜脂雙層中主要分布在朝向細胞質那一側（內側），與磷脂醯膽鹼、磷脂醯乙醇胺等磷脂質共同構成膜的結構與訊息傳遞功能。這種「內外不對稱分布」本身就有生理意義：當細胞準備凋亡時，磷脂絲胺酸會翻轉到膜外側，成為吞噬細胞辨識並清除凋亡細胞的訊號分子。 <a href="#ref-3">[3]</a> 市售磷脂絲胺酸依原料來源主要分成三類：最早使用、現已停產的牛腦皮質萃取物（BC-PS）；因狂牛症疑慮改用、目前市場主流的大豆卵磷脂酵素轉化製品（S-PS）；以及近年出現、以葵花卵磷脂為原料的無大豆過敏原替代品，2014年已取得FDA的GRAS（一般認為安全）通知認可。 <a href="#ref-14">[14]</a>

## 在身體裡做什麼？／主要作用機制

磷脂絲胺酸作為神經細胞膜的結構成分之一，被認為與神經傳導物質釋放、突觸囊泡融合，以及膜蛋白（包括受體與離子通道）的正常運作有關，這是它被歸類為「神經營養」成分、而非單純能量或結構性營養素的原因。 <a href="#ref-3">[3]</a> 另一條被研究的路徑，是磷脂絲胺酸與下視丘—腦垂體—腎上腺軸（HPA軸）之間的關係：Monteleone等人1992年推測，磷脂絲胺酸可能透過影響糖皮質素受體的負回饋機制，讓身體在承受生理性壓力（如運動）或心理性壓力後，減少ACTH與皮質醇的分泌幅度。 <a href="#ref-10">[10]</a> 這個機制假說目前仍屬理論層次，實際觀察到的現象是「劑量足夠時皮質醇反應被緩和」，至於背後確切的分子路徑，多篇後續試驗（包括Starks等人2008年與Hellhammer等人2014年的研究）都沒有進一步驗證機制細節，只確認了荷爾蒙數值上的變化。 <a href="#ref-11">[11]</a>

## 食物來源／常見來源

磷脂絲胺酸存在於所有動物組織的細胞膜中，理論上內臟類（腦、肝、腎）與部分油脂含量較高的魚類（如鯖魚）是天然食物中相對集中的來源，但這類食物在台灣一般飲食中的攝取頻率偏低，且腦部等內臟因狂牛症相關的食品安全考量，並非日常飲食的常見選項。黃豆本身的磷脂絲胺酸天然含量並不高，市售大豆磷脂絲胺酸保健品其實是先萃取大豆卵磷脂（主要成分是磷脂醯膽鹼），再透過酵素反應把絲胺酸接上去，人工轉化成磷脂絲胺酸，而不是直接從黃豆中萃取濃縮而成。 <a href="#ref-14">[14]</a> 這也是為什麼臨床試驗使用的劑量（每日100至800毫克）會被視為需要透過「補充品」形式攝取的量——一般飲食結構能提供的磷脂絲胺酸，遠低於這個範圍。

## 建議攝取量／常見攝取建議／研究中常見使用方式

磷脂絲胺酸不是台灣衛生福利部訂有每日參考攝取量的必需營養素，市面上也沒有單一「官方建議劑量」，實務上劑量選擇高度取決於想達到的目的與參考的臨床試驗。認知功能相關試驗最常見的劑量落在每日100至300毫克：Kato-Kataoka等人2010年的試驗比較每日100毫克與300毫克的大豆磷脂絲胺酸，兩組都於6個月後在延遲語言回憶測驗上優於安慰劑組，但300毫克組的效果較一致。 <a href="#ref-7">[7]</a> 較早的牛腦皮質萃取物試驗則多採每次100毫克、一天三次（合計每日300毫克）的給法，療程為12週。 <a href="#ref-3">[3]</a> 兒童ADHD相關試驗多落在每日200至300毫克。 <a href="#ref-13">[13]</a> 運動或心理壓力相關的皮質醇研究則使用較高劑量，Monteleone等人1992年使用每日800毫克（牛腦皮質來源）、Starks等人2008年使用每日600毫克（大豆來源）、Hellhammer等人2014年比較每日200毫克與400毫克後發現只有400毫克這個劑量對長期高壓族群有統計上顯著的效果。 <a href="#ref-12">[12]</a> 這些劑量之間沒有一套統一的換算邏輯，選擇哪個劑量，取決於想解決的問題比較接近哪一批試驗設計的族群與目標。

## 缺乏風險或攝取不足問題

因為人體可以自行從其他磷脂質（磷脂醯膽鹼、磷脂醯乙醇胺）經絲胺酸交換反應合成磷脂絲胺酸，臨床上沒有定義明確的「磷脂絲胺酸缺乏症」，這點與維生素或必需胺基酸的邏輯不同。保健食品行銷中常見的「大腦磷脂絲胺酸隨年齡下降、需要補充」的說法，背後的生理觀察（動物與人體組織研究確實觀察到腦部磷脂質組成會隨老化改變）與「補充磷脂絲胺酸能逆轉或預防這個變化並改善認知」之間，中間還缺乏直接的因果證據串連；目前的臨床試驗設計多半是「在有記憶抱怨或認知障礙的族群中測試補充效果」，而不是「證明補充能預防健康人腦部磷脂質流失」。這個區別在解讀「磷脂絲胺酸能不能顧記憶力」這類問題時經常被行銷語言模糊掉。

## 補充品常見形式

市售磷脂絲胺酸主要有四種型態，彼此的證據強度與適用情境不完全相同：

- **牛腦皮質萃取物（BC-PS）**：1980至1990年代初期主要試驗使用的原料，臨床證據最早也最集中在阿茲海默症與老化相關記憶減退族群，但因狂牛症疑慮，FDA在2003年的核准函中明確要求，若使用牛源產品，牛隻不得來自曾出現狂牛症案例的國家，目前市場上已幾乎看不到這個型態的產品。 <a href="#ref-1">[1]</a>
- **大豆磷脂絲胺酸（S-PS）**：目前市場主流，由大豆卵磷脂經酵素轉化而成。早期（2001年）的試驗未能複製牛腦來源試驗的效果，但2010年後的多篇試驗（Kato-Kataoka等人、Vakhapova等人）在調整劑量與族群篩選後，觀察到部分認知測驗指標的改善。 <a href="#ref-7">[7]</a>
- **PS-DHA複方**：大豆磷脂絲胺酸的絲胺酸骨架上額外接有omega-3長鏈多元不飽和脂肪酸（主要是DHA），Vakhapova等人2010年與2011年的兩篇試驗都使用這個配方，14週安全性追蹤沒有觀察到顯著不良反應。 <a href="#ref-9">[9]</a>
- **葵花卵磷脂來源磷脂絲胺酸**：近年出現的無大豆過敏原替代品，2014年取得FDA GRAS通知認可，臨床試驗數量目前仍少於大豆來源產品。 <a href="#ref-14">[14]</a>

## 安全性與注意事項

Jorissen等人2002年針對120名長者進行的安全性試驗，比較每日300毫克與600毫克的大豆磷脂絲胺酸與安慰劑，追蹤12週的生化與血液學安全指標、血壓、心率與不良事件通報，經Bonferroni校正後三組之間沒有顯著差異，作者的結論是大豆磷脂絲胺酸在每日最高600毫克（每次200毫克、一天三次）的劑量下對長者是安全的。 <a href="#ref-6">[6]</a> Vakhapova等人2011年針對PS-DHA複方的追蹤研究，在雙盲試驗後銜接開放標示延伸期，同樣沒有觀察到顯著的安全疑慮。 <a href="#ref-9">[9]</a> 這些安全性資料多集中在3到6個月的療程，超過半年的長期使用資料仍然有限；懷孕、哺乳族群與磷脂絲胺酸的交互作用研究也不足，這類族群若考慮補充，建議先與醫師討論。目前已停產的牛腦皮質來源產品，其安全疑慮特別集中在狂牛症的理論風險，這也是FDA在2003年核准函中額外對牛源產品設下產地限制的原因；如果選購來源不明的磷脂絲胺酸產品，建議優先確認標示的原料來源（大豆、葵花或其他），而不是只看「磷脂絲胺酸」這個成分名稱。慢性病患者若同時服用其他藥物，保健食品與藥物之間的交互作用整體原則可參考本站〈[關於慢性病藥和保健食品並用，你需要知道的5件事](/articles/chronic-disease-drug-supplement-interaction/)〉一文，磷脂絲胺酸雖然目前沒有被列為高風險交互作用成分，但個別身體狀況仍建議與醫師或藥師確認。

## 常見迷思

- **「吃了磷脂絲胺酸，記憶力馬上會變好」**：Jorissen等人2001年的雙盲試驗顯示，120名長者服用大豆磷脂絲胺酸12週後，各項認知測驗與安慰劑組沒有顯著差異；後續觀察到效果的試驗，多半集中在特定次族群（基線認知狀態特別好或特別差的長者），不是普遍族群都會有感的效果。 <a href="#ref-5">[5]</a>
- **「FDA核准的健康聲明代表科學證據很紮實」**：FDA核准磷脂絲胺酸這項合格健康聲明時，同時要求業者必須在標示上附上「有限且初步的科學研究……FDA的結論是支持此聲明的科學證據很少」這段文字，這是FDA健康聲明分級中證據強度偏低的一類，與許多消費者以為「FDA核准＝證據充分」的認知有落差。 <a href="#ref-1">[1]</a>
- **「現在市售的磷脂絲胺酸跟以前研究用的一樣有效」**：FDA在2004年更新核准函時，明確指出牛腦皮質來源與大豆來源磷脂絲胺酸「對降低失智症與認知功能障礙風險的效果是否相似或不同，仍存在相當的不確定性」，當時審查到的唯一一篇大豆來源人體試驗（即Jorissen等人2001年的研究）並未顯示顯著效果，這代表把牛腦來源年代的正向結果直接套用在今天的大豆或葵花來源產品上，中間有一段沒有被完整驗證的推論落差。 <a href="#ref-2">[2]</a>
- **「磷脂絲胺酸可以取代失智症的醫療處置」**：目前所有相關試驗都是在既有診斷或治療架構之外測試補充效果，沒有一篇支持用磷脂絲胺酸取代醫師的診斷與處方；失智症風險因子與整體預防策略，可參考本站〈[失智症可以預防嗎？從中年開始的護腦指南](/articles/dementia-prevention-midlife-guide/)〉一文。
- **「食物長得像某個器官，吃了就能補那個器官」**：這種「以形補形」的推論邏輯，與磷脂絲胺酸這類有實際人體試驗數據（即使證據強度有限）的成分，是完全不同層次的兩件事，相關的核桃補腦說法查核可參考本站〈[多吃核桃能補腦、增強記憶力嗎？](/myths/walnut-brain-food-myth/)〉一文。

## 常見問題

### 磷脂絲胺酸該選牛腦、大豆還是葵花來源？

牛腦皮質來源（BC-PS）目前在市場上已幾乎絕跡，主要是狂牛症疑慮讓多數國家的原料供應商停止生產；如果看到標示來源不明或宣稱「牛腦萃取」的產品，建議先確認來源國是否曾出現牛海綿狀腦病案例。 <a href="#ref-1">[1]</a> 目前市場主流是大豆卵磷脂酵素轉化製成的大豆磷脂絲胺酸，累積的安全性與部分認知功能試驗數據相對較多；對大豆過敏者，可考慮近年出現的葵花卵磷脂來源產品，但這類產品的臨床試驗數量還比大豆來源少。 <a href="#ref-14">[14]</a>

### 運動員或健身族群補充磷脂絲胺酸有幫助嗎？

現有證據集中在「緩和運動後的皮質醇上升幅度」這個荷爾蒙指標，Starks等人2008年的試驗顯示每日600毫克連續10天能讓運動後的皮質醇高峰下降39%，但這篇試驗並沒有同時證實肌力、恢復速度或運動表現有對應的提升，皮質醇數值改善與實際訓練效果之間不能直接畫上等號。如果補充的目的是想緩解慢性心理壓力對生活的影響，可以參考本站〈[「自律神經失調」是不是一種病？](/articles/autonomic-nervous-dysfunction-anxiety-guide/)〉一文，了解找不到明確原因的身體壓力症狀還有哪些面向值得先釐清。 <a href="#ref-11">[11]</a>

### 小孩ADHD可以用磷脂絲胺酸取代藥物治療嗎？

不建議。Bruton等人2021年的統合分析雖然發現每日200至300毫克磷脂絲胺酸對「不專注」症狀有小幅、統計上顯著的效果，但對整體ADHD核心症狀與過動—衝動症狀都沒有觀察到顯著效果，作者也將整體證據品質評為低，並非可以取代現行治療的資料強度。 <a href="#ref-13">[13]</a> 是否調整或搭配治療方式，需要由兒童精神科或小兒神經科醫師評估。

### 補充磷脂絲胺酸要吃多久才知道有沒有效？

多數陽性結果的試驗療程落在12週到6個月之間，例如Crook等人1991年的試驗是12週、Kato-Kataoka等人2010年的試驗是6個月加3個月追蹤，短於這個時間框架的自我評估可能還沒到觀察窗口。同時要注意，部分試驗（如Jorissen等人2001年）用同樣長度的療程卻沒有觀察到效果，療程夠長不等於保證有效，個別反應仍有落差。 <a href="#ref-7">[7]</a>
