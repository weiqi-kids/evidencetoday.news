## 30 秒認識

- 假馬齒莧（Bacopa monnieri）是印度阿育吠陀醫學傳統使用的藥用植物，市售商品名常見「Brahmi（婆羅米）」，多為標準化萃取物膠囊或錠劑，而非日常食材。 <a href="#ref-12">[12]</a>
- 一篇納入 9 篇隨機對照試驗、437 人的統合分析顯示，補充假馬齒莧與注意力速度相關測驗（Trail B、選擇反應時間）表現改善有關，但作者同時強調證據仍需更嚴謹的大型試驗補強。 <a href="#ref-1">[1]</a>
- 效果不是吃了當下就有感覺。急性單次服用試驗未觀察到立即效果，多篇慢性補充試驗則要規律服用 8 至 12 週才觀察到記憶與注意力測驗分數的組間差異。 <a href="#ref-10">[10]</a> <a href="#ref-3">[3]</a>
- 常見標準化萃取物規格不只一種，之間的「含量百分比」不能直接互相比較，因為各品牌採用的成分定量方法不同。 <a href="#ref-9">[9]</a>
- 腸胃道副作用（排便次數增加、噁心、腹部絞痛）是臨床試驗中最常被記錄的不良反應，多屬輕度、停用可恢復。 <a href="#ref-7">[7]</a>

## 基本介紹

假馬齒莧是車前科（Plantaginaceae）多年生匍匐性草本植物，原生於印度及東南亞的濕地、稻田與沼澤環境，台灣的溝渠與濕地也可見其蹤跡，早期植物誌多將它歸入玄參科。它在印度阿育吠陀醫學中被歸類為「Medhya Rasayana」——直譯為「促進智力的滋補劑」，傳統上用於記憶、專注與部分神經系統相關的調理，使用歷史可追溯數百年以上。 <a href="#ref-12">[12]</a> 現代研究對它的興趣主要集中在標準化萃取物對健康成人與年長者認知功能的影響，這也是它與多數傳統藥用植物不同之處：市面上流通的臨床試驗多數使用特定廠牌的標準化萃取物，而非曬乾植株或自製茶飲，兩者的成分濃度與試驗結果不能直接劃上等號。

## 這是什麼？

假馬齒莧全株含有多種化學成分，被認為與認知效果最相關的是一群三萜皂苷類化合物，統稱「bacosides（巴克皂苷）」，其中巴克皂苷 A3（bacoside A3）、bacopaside II、bacopasaponin C 等是常被個別列出的活性成分。 <a href="#ref-11">[11]</a> 市售標準化萃取物之間的差異，主要出在「用什麼方法、量哪幾種成分」：以 CDRI-08（也常見於商品名 Synapsa、KeenMind）為例，多篇研究採用的規格是總巴克皂苷約占 55%；以 Bacognize 為例，一篇針對醫學生的試驗中，該萃取物以高效液相層析法（HPLC）逐一定量已知的四種巴克皂苷，加總約占 11.4%，若計入未逐一鑑定的成分則約 15.6%。 <a href="#ref-9">[9]</a> 兩個數字看起來差距很大，但代表的是不同的計算基準，不是效力差三倍，這是消費者比較不同品牌時最容易誤讀的地方。

## 在身體裡做什麼？／主要作用機制

假馬齒莧的作用機制研究多數來自動物與細胞實驗，人體機制證據相對少。目前被提出的路徑包括：促進膽鹼乙醯基轉移酶（choline acetyltransferase）活性、影響乙醯膽鹼相關的訊息傳遞；提升體內麩胱甘肽（GSH）、超氧化物歧化酶（SOD）等內生性抗氧化系統的活性，減少海馬迴等腦區的氧化壓力；以及調節血清素與多巴胺系統的訊號傳遞。 <a href="#ref-11">[11]</a> Calabrese 等人 2008 年的試驗中，假馬齒莧組除了記憶測驗表現優於安慰劑組，憂鬱量表（CESD-10）分數與焦慮量表分數也雙雙下降，這與部分研究者提出的「適應原（adaptogen）」假說相呼應——即透過調節壓力荷爾蒙相關路徑，間接改善與壓力相關的認知表現，而非單純的膽鹼系統作用。 <a href="#ref-6">[6]</a> 值得留意的是，這些機制多半建立在動物實驗或體外細胞模型，人體研究通常只能觀察最終的認知測驗分數變化，無法直接驗證是哪一條路徑在起作用，機制的合理性不等於已被證實的因果關係。

## 食物來源／常見來源

假馬齒莧在台灣不是常見食材，日常飲食幾乎沒有天然攝取來源。在印度部分地區，新鮮葉片會被當作綠色蔬菜入菜（有時稱為「Brahmi saag」），但這類傳統食用方式的攝取量與成分濃度，跟臨床試驗使用的標準化萃取物完全不是同一回事，兩者的證據基礎也不能互相套用。市面上能買到的假馬齒莧產品幾乎全部是萃取後的膠囊、錠劑或液態萃取液，原料多來自栽培植株的地上部（莖葉），而非台灣野外濕地自然生長的族群——自行採集野外植株沒有品質管控，不建議作為攝取來源。

## 建議攝取量／常見攝取建議／研究中常見使用方式

假馬齒莧不是必需營養素，沒有官方訂定的每日建議攝取量。研究中最常見的劑量是每日 300 毫克標準化萃取物，部分試驗以每日 300 至 450 毫克為區間，急性測試則用到單次 320 或 640 毫克。 <a href="#ref-3">[3]</a> <a href="#ref-10">[10]</a> 比劑量更關鍵的是時間軸：Benson 與 Downey 等人 2014 年的交叉設計試驗中，受試者在單次服用 320 毫克或 640 毫克後 1 至 2 小時內接受多工測驗，結果並未觀察到立即的認知表現提升。 <a href="#ref-10">[10]</a> 相對地，Kumar 等人 2016 年針對醫學生的六週試驗，使用 Bacognize 每日 300 毫克，在數字廣度倒背測驗與邏輯記憶測驗上已觀察到統計上顯著的進步；而 Stough 等人 2001 年、Calabrese 等人 2008 年與 Morgan 及 Stevens 2010 年的多篇十二週試驗，普遍在第 12 週左右才觀察到較一致的記憶與注意力測驗改善，且部分試驗指出效果在第 12 週比第 5 週更明顯。 <a href="#ref-9">[9]</a> <a href="#ref-3">[3]</a> <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a> 綜合這些試驗設計，市面上常見的「建議至少規劃 8 至 12 週」說法有研究依據，但這是試驗觀察到差異出現的時間點，不是保證每個人都會在特定週數感受到主觀變化。

## 缺乏風險或攝取不足問題

假馬齒莧不是人體必需的營養素，沒有「缺乏症」的概念，不服用也不會產生生理上的匱乏狀態，停用後也沒有已知的戒斷反應。會主動尋找這類補充品的族群，多半是準備考試的學生、工作記憶負荷大的上班族，或擔心記憶力隨年齡下降的中高齡者。若記憶力減退是主觀或客觀上明顯變化，值得留意的是：甲狀腺功能異常、維生素 B12 缺乏、睡眠品質不佳（包括睡眠呼吸中止）、憂鬱情緒與部分藥物副作用都可能表現為記憶力或專注力下降，這些原因多數可以透過檢查與治療處理，不宜在未釐清成因前，僅以補充品自行因應，本站在〈[熟齡認知功能與失智症預防怎麼做？](/articles/dementia-prevention-midlife-guide/)〉一文有更完整的整理。

## 補充品常見形式

市售假馬齒莧產品的差異主要落在萃取物的標準化方式與劑型：常見標示為 CDRI-08（商品名如 Synapsa、KeenMind）的萃取物多標準化為總巴克皂苷約 55%；BacoMind 是另一種以多重成分（約九種活性標記物）做定量的萃取物；Bacognize 則以 HPLC 個別鑑定四種巴克皂苷、加總約一成出頭。 <a href="#ref-9">[9]</a> <a href="#ref-11">[11]</a> 這幾種萃取物在不同臨床試驗中各自有正面結果，但彼此之間缺乏頭對頭比較，無法斷言哪一種效果更好，選購時建議認明產品是否標示具體的萃取物來源與定量方法，而不是只看「假馬齒莧萃取物」幾個字。除了膠囊與錠劑，市面也有液態酊劑與複方產品（常與人參、紅景天或銀杏等成分並列），複方產品出現效果或副作用時較難歸因於單一成分，選購前可先確認自己是否已在服用其他含重疊成分的產品，避免重複攝取。

## 安全性與注意事項

多篇隨機對照試驗一致記錄到腸胃道相關的不良反應，包括排便次數增加、噁心、腹部絞痛與口乾，這是假馬齒莧目前證據最一致的副作用類別。 <a href="#ref-7">[7]</a> <a href="#ref-4">[4]</a> Calabrese 等人 2008 年的試驗中，不良反應以腸胃不適為主，假馬齒莧組與安慰劑組通報人數相近（9 人對 10 人），整體耐受性尚可；但 Morgan 與 Stevens 2010 年使用 BacoMind 的試驗則觀察到假馬齒莧組的腸胃道副作用（排便次數增加、腹部絞痛、噁心）發生率高於安慰劑組。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a> 這類差異可能與萃取物種類、劑量或受試族群不同有關，目前尚無法歸納出單一「安全劑量上限」的定論。多數試驗追蹤期落在 12 週左右，缺乏一年以上的長期安全性資料，長期使用者的風險仍不完全清楚。

其他需要留意的面向：動物實驗觀察到假馬齒莧可能提高血中甲狀腺素（T4）濃度，雖然人體證據有限，甲狀腺疾病患者或服用甲狀腺素製劑者，考慮補充前建議先與醫師討論；體外實驗顯示假馬齒莧所含成分可能抑制 CYP3A4、CYP2C9、CYP2C19、CYP1A2 等藥物代謝酵素，理論上可能提高經這些酵素代謝之藥物（部分抗凝血劑、抗癲癇藥、鎮靜安眠藥等）的血中濃度，正在服用治療濃度範圍狹窄藥物者應提高警覺。 <a href="#ref-12">[12]</a> 假馬齒莧本身具溫和促膽鹼作用，與抗膽鹼類藥物（部分抗組織胺、三環抗憂鬱劑）併用時作用方向可能相反，建議一併告知處方醫師目前服用的所有補充品。孕期與哺乳期由於安全性資料不足，一般不建議使用；本身有腸躁症或慢性腸胃疾病者，因腸胃副作用發生率較高，建議由較低劑量開始並觀察身體反應，如廚房分次拆解成低於研究常用劑量的份量，逐步觀察耐受度後再決定是否維持。

## 常見迷思

- **「吃了當下就會感覺變聰明、跟提神飲料一樣」**：交叉設計試驗顯示單次服用 320 或 640 毫克後 1 至 2 小時內，並未觀察到多工表現立即提升，急性效果與慢性規律服用後觀察到的效果不同，不能相提並論。 <a href="#ref-10">[10]</a>
- **「萃取物標示的百分比數字越高，效力就一定越強」**：不同品牌採用的成分定量方法不同，CDRI-08 系列標示的總巴克皂苷約 55%，Bacognize 以 HPLC 逐一鑑定後加總僅約一成出頭，兩者計算基準不同，數字不能直接比較高低。 <a href="#ref-9">[9]</a>
- **「天然草本藥用植物，安全性一定優於藥物、幾乎沒有副作用」**：多篇試驗一致記錄到腸胃道不良反應，部分試驗中發生率明顯高於安慰劑組，天然來源不等於沒有副作用或沒有藥物交互作用風險。 <a href="#ref-7">[7]</a>
- **「隨機對照試驗都證實對記憶力有效，效果放諸四海皆準」**：個別試驗結果並不一致，部分試驗在特定測驗項目上未觀察到組間差異（如數字廣度測驗），統合分析作者也明確指出仍需要更大規模、方法學更嚴謹的試驗確認效益，不宜過度解讀為「已經證實」。 <a href="#ref-1">[1]</a> <a href="#ref-6">[6]</a>
- **「跟銀杏、人參等其他草本記憶保健成分效果一樣，可以互相取代」**：假馬齒莧的臨床證據基礎（受試族群、劑量、追蹤週數）與〈[銀杏](/ingredients/ginkgo-biloba/)〉等其他成分並不相同，兩者在大型預防性試驗上的結果也不一致，不能假設效果可以互相替代或加成。

## 常見問題

### 吃了好幾週還是沒感覺，是不是要加量？

多數支持假馬齒莧的試驗使用的是每日 300 毫克左右的標準化萃取物、持續 8 至 12 週，而非更高劑量能更快看到效果。急性單次高劑量（320、640 毫克）的試驗反而沒有觀察到立即效果。 <a href="#ref-10">[10]</a> 若規律服用滿 12 週仍無感受，貿然提高劑量並不會讓證據基礎改變，且可能提高腸胃副作用發生的機會，較合理的做法是重新評估是否要繼續使用，而非持續加量。

### 假馬齒莧可以跟銀杏、紅景天等其他認知保健成分一起吃嗎？

目前沒有足夠的人體試驗資料評估假馬齒莧與其他草本成分併用的效果或安全性，多數臨床試驗都是評估單一成分。若同時服用多種含重疊活性機轉（如影響膽鹼系統、抗氧化路徑）的產品，理論上可能增加不良反應風險，也難以判斷效果或副作用來自哪一項成分，建議避免自行疊加多種複方產品，如有需要可與醫師或藥師討論。

### 腸胃副作用一直沒有改善，該怎麼辦？

假馬齒莧相關的腸胃道副作用多數程度輕微，且在停用後可以恢復。 <a href="#ref-7">[7]</a> 若症狀持續超過一至兩週未改善，或伴隨明顯腹瀉、體重下降等情況，建議先暫停服用並與醫師討論，而不是自行忍耐或搭配其他腸胃藥物繼續使用；本身有腸躁症或慢性腸胃疾病者，出現症狀的機率原本就較高，更需要提高警覺。

### 沒有明顯記憶力問題，可以當作日常保健品長期吃嗎？

目前的臨床試驗多數以 12 週左右為觀察期，缺乏長期（一年以上）使用的安全性與效果資料，「長期規律服用是否持續有益」尚未被充分研究。如果只是日常保健、沒有明確的認知功能疑慮，建議把重點放在有更強證據支持的介入，例如規律運動、充足睡眠與慢性病控制；若考慮長期使用假馬齒莧，建議設定明確的觀察期與停用時機，而不是無限期持續服用。
