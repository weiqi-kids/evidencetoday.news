## 30 秒認識

- 硒（Selenium）是人體必需的微量礦物質，主要以「硒半胱胺酸」形式嵌入至少 25 種含硒蛋白質（selenoprotein）中，包括麩胱甘肽過氧化酶（抗氧化）與去碘酶（甲狀腺激素代謝）。 <a href="#ref-1">[1]</a>
- 它的安全攝取範圍相對窄：成人建議攝取量（RDA）每日 55 微克，可耐受攝取上限（UL）為每日 400 微克，兩者相差不到十倍，比多數必需礦物質都窄。 <a href="#ref-1">[1]</a>
- 缺乏在台灣、歐美一般飲食中極少見，歷史上最著名的缺乏症是中國東北到西南「硒帶」地區流行的克山病（一種地方性心肌病），已因土壤硒改良與補充大幅減少。 <a href="#ref-6">[6]</a>
- 巴西堅果是天然硒含量最高的食物之一，但依產地土壤不同，每顆含量可從幾微克到近百微克，吃太多顆反而容易單日超過安全上限。 <a href="#ref-1">[1]</a>
- 飲食均衡者額外補充硒，多數情況對健康沒有實質好處：大型統合分析與臨床試驗都未能證實硒補充能預防癌症，部分試驗甚至觀察到副作用增加。 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>

## 基本介紹

硒是 1817 年由瑞典化學家發現的類金屬元素，直到 1957 年才確認是動物的必需營養素；1970 年代進一步證實與中國克山病等地方性疾病相關，讓硒的營養角色受到重視。 <a href="#ref-6">[6]</a> 它主要透過「硒半胱胺酸」嵌入蛋白質，構成一群稱為「含硒蛋白質」的功能性蛋白，目前已知人體有超過 25 種，分工涵蓋抗氧化防禦、甲狀腺激素活化、DNA 合成與部分免疫調節。 <a href="#ref-1">[1]</a> 食物中的硒含量高度取決於土壤硒濃度，因此同一種作物在不同地區的硒含量可能差異數十倍，這也是全球硒營養狀況差異懸殊的主因。 <a href="#ref-1">[1]</a>

## 這是什麼？

硒在化學上是類金屬元素，但在營養學上被歸類為「必需微量礦物質」，代表人體需要量極少（微克等級），但對維持健康很重要。 <a href="#ref-1">[1]</a> 它與碘、鋅等其他微量礦物質類似，它的作用不在供給能量，主要是構成抗氧化酵素與相關蛋白質的必要成分——缺了它，相關酵素就無法正常摺疊與運作。 <a href="#ref-1">[1]</a> 常見形式包括食物中天然存在的「硒半胱胺酸」「硒甲硫胺酸」（有機態），以及補充品額外添加的「亞硒酸鈉」（無機態），三者的吸收率與體內利用方式略有不同。 <a href="#ref-1">[1]</a>

## 在身體裡做什麼？／主要作用機制

硒最核心的功能是構成「麩胱甘肽過氧化酶」家族，這群酵素能分解細胞內的過氧化氫與脂質過氧化物，是身體對抗氧化壓力的關鍵防線之一。 <a href="#ref-1">[1]</a> 另一組重要的含硒蛋白質是「去碘酶」，負責把甲狀腺分泌的 T4（相對不活化）轉換成 T3（活化型甲狀腺素），因此甲狀腺是全身硒濃度最高的器官之一，硒營養狀況會直接牽動甲狀腺代謝。 <a href="#ref-5">[5]</a> 其餘含硒蛋白質還參與精子生成、DNA 修復與部分免疫細胞功能，但多數細節證據來自生化與動物研究，人體層級「硒補充能實際改善哪些健康結果」的證據遠比機制研究薄弱，兩者不能直接畫等號。 <a href="#ref-2">[2]</a>

## 食物來源／常見來源

海鮮、內臟與肉類是硒的主要來源，巴西堅果則是含量最高、也最極端的例外——依產地土壤不同，每顆巴西堅果的硒含量差異可達十倍以上，換算下來一天吃好幾顆就可能逼近甚至超過每日上限。 <a href="#ref-1">[1]</a> 統合分析也證實，規律食用巴西堅果確實能有效提升人體硒營養狀況（血中硒濃度與麩胱甘肽過氧化酶活性），效果相當明確，這也是它容易被拿來作為「天然硒補充品」的原因。 <a href="#ref-7">[7]</a> 其他常見來源包括鮪魚、沙丁魚等海鮮、雞蛋、葵花籽與全穀類，但穀類與蔬菜的硒含量高度受栽種土壤影響，同一種食物在不同地區的含量可能差異數倍甚至數十倍。 <a href="#ref-1">[1]</a> 飲食均衡、規律攝取海鮮與蛋白質來源的人，通常不需要特別留意硒的攝取量。

## 建議攝取量／常見攝取建議／研究中常見使用方式

美國國家醫學院訂定成人建議攝取量（RDA）為每日 55 微克，懷孕期建議增加至 60 微克、哺乳期 70 微克；可耐受攝取上限（UL）則是每日 400 微克。 <a href="#ref-1">[1]</a> 這代表硒「有效與有害」之間的安全範圍，比多數維生素礦物質都窄，不宜自行大幅超量。臨床試驗中，橋本氏甲狀腺炎相關研究常用每日約 200 微克的劑量，統合分析也指出使用每日 100 微克以上、硒甲硫胺酸形式時，降低甲狀腺過氧化酶抗體（TPOAb）的效果較一致。 <a href="#ref-5">[5]</a> 一般成人若飲食正常，不建議自行比照這類臨床試驗劑量長期補充。

## 缺乏風險或攝取不足問題

硒缺乏在已開發國家的一般飲食中相當罕見，但在土壤硒濃度極低的地區曾造成嚴重疾病。最著名的案例是中國東北到西南「硒帶」地區流行的克山病——一種以心臟擴大、心律不整與心衰竭為表現的地方性心肌病，好發於兒童與育齡婦女，在硒缺乏最嚴重的年代曾造成大量死亡。 <a href="#ref-6">[6]</a> 後續研究認為硒缺乏是必要但可能不是唯一病因（部分研究指出特定腸病毒感染也參與其中），透過補硒與改善土壤硒濃度，克山病的發生率已大幅下降，不再是主要公共衛生問題。 <a href="#ref-6">[6]</a> 台灣一般飲食型態下，單純硒缺乏極少見，較可能出現在長期完全腸道外營養、嚴重腸胃道吸收不良或極端限制飲食的族群。

## 補充品常見形式

市售硒補充品常見形式包括「硒甲硫胺酸」（selenomethionine，有機態，常來自硒酵母）與「亞硒酸鈉」（sodium selenite，無機態），兩者吸收率與體內滯留時間不同，硒酵母形式的生物利用率通常較高。 <a href="#ref-1">[1]</a> 常見劑型為每錠 50 至 200 微克的膠囊或錠劑，可單方使用，也常與碘、鋅等甲狀腺相關營養素做成複方。選購時應留意「每份劑量」是否已逼近或超過每日上限 400 微克，尤其若同時常吃巴西堅果、海鮮又額外補充，加總後容易在不自知的情況下超量。 <a href="#ref-1">[1]</a>

## 安全性與注意事項

硒中毒（selenosis）的初期徵兆包括口中金屬味、呼氣有蒜味，慢性過量最常見的表現是落髮與指甲變脆、出現白斑。 <a href="#ref-1">[1]</a> 一起因誤用配方錯誤的保健食品導致急性硒中毒的案例系列中，患者估計累積攝取硒總量平均約 1.3 克（遠超建議量）、平均攝取期間約一個多月，出現落髮、指甲營養不良、腸胃症狀與記憶力減退等表現；停用供應品後以支持性治療觀察，皆未惡化到需住院，但追蹤抽血顯示體內硒濃度消退較慢，停用後平均 27 天血中濃度仍高於參考值上限。 <a href="#ref-4">[4]</a> 大型臨床試驗也顯示，額外補充硒並非「有益無害」：SELECT 攝護腺癌預防試驗中，硒補充並未降低攝護腺癌風險，糖尿病風險呈非顯著上升趨勢，是試驗因無效性提前終止的次要觀察之一 <a href="#ref-3">[3]</a>；後續以硒基礎值（toenail 生物標記）分層的案例世代分析發現，硒基礎值偏高者硒補充後高惡性度攝護腺癌風險顯著上升。 <a href="#ref-8">[8]</a> 正在服用抗凝血藥物、接受化學治療者，以及孕婦、哺乳者若考慮額外補充，應與醫療專業人員討論劑量與必要性，避免自行長期高劑量使用。

## 常見迷思

- 「硒是抗氧化聖品，補越多越好」：硒的安全範圍窄，補充超過需求量不會帶來額外抗氧化效果，反而可能升高中毒與其他代謝風險。 <a href="#ref-3">[3]</a>
- 「硒補充品能預防癌症」：Cochrane 系統性回顧涵蓋數萬人的隨機對照試驗，並未發現硒補充能降低癌症發生率或死亡率，這與部分觀察性研究看到的相關性不同——相關不等於因果，補充介入試驗的結果才是判斷依據。 <a href="#ref-2">[2]</a>
- 「巴西堅果一定要多吃幾顆才有效」：巴西堅果硒含量因產地土壤差異極大，少數幾顆可能已達每日建議量甚至逼近上限，並非吃越多越安全。 <a href="#ref-1">[1]</a>
- 「甲狀腺有狀況就該自行補硒」：硒補充對橋本氏甲狀腺炎患者的甲狀腺過氧化酶抗體（TPOAb）有統計上的下降效果，但多數個別試驗未達顯著、結果並不一致，統合分析作者也指出證據品質仍有限，是否補充應由醫師依甲狀腺功能與硒營養狀況評估，而非自行認定。 <a href="#ref-5">[5]</a>
