## 30 秒認識

- 規模最大的檢驗給了否定答案。2012 年 Cochrane 回顧納入 32 項隨機對照試驗、5666 名男性，其中兩項高品質長期試驗（582 人）的統合分析顯示，鋸棕櫚在 AUA 症狀評分上並未優於安慰劑。 <a href="#ref-1">[1]</a>
- 加量也沒用。同一份回顧指出，即使使用常規劑量的兩倍與三倍，夜尿次數、最大尿流速與症狀評分都沒有改善。 <a href="#ref-1">[1]</a>
- 早年印象有出處。2002 年較早版本的 Cochrane 回顧曾報告較正向的結果 <a href="#ref-3">[3]</a>，當時納入的研究多為小型、療程短、方法學品質不一。
- 2023 年更新版持續評估鋸棕櫚對攝護腺良性增生所致下泌尿道症狀的效果，延續療效有限的整體判斷。 <a href="#ref-2">[2]</a>
- 安全性不是主要問題，不良反應發生率與安慰劑接近。 <a href="#ref-1">[1]</a> 較實際的風險是把攝護腺癌或膀胱問題的症狀當成單純肥大，靠補充品拖延就醫。

## 基本介紹

鋸棕櫚是原生於美國東南部的矮生棕櫚，果實自北美原住民時期即被用於泌尿道相關症狀。1990 年代起，以脂溶性萃取物形式（歐洲最知名的製劑為 Permixon）在德國、法國、義大利等地被廣泛用於攝護腺肥大 <a href="#ref-4">[4]</a>，並隨保健食品市場擴散至全球。台灣的男性保健產品中，鋸棕櫚幾乎是標準配方成分，常與茄紅素、南瓜籽油、鋅組合。它的證據演變是保健成分中相當完整的一個案例：從小型試驗的正向結果，到大型嚴謹試驗逐步推翻。

## 這是什麼？

鋸棕櫚果實的活性訴求集中在脂溶性部分，包含游離脂肪酸（月桂酸、油酸、肉豆蔻酸等）、植物固醇（以 β-谷固醇為主）與少量黃酮類。商業製劑多以己烷或超臨界二氧化碳萃取，標準化指標通常是總脂肪酸含量達 85% 以上。 <a href="#ref-4">[4]</a> 值得區分的是，市售產品若以果實粉末（而非脂溶性萃取物）製成，成分組成與研究用製劑差距很大，兩者不應視為等效。

## 在身體裡做什麼？／主要作用機制

假設中的機制有三條：抑制 5α-還原酶（把睪固酮轉為活性更強的二氫睪固酮 DHT，與 finasteride 同一標的）、抗發炎作用，以及對 α1 腎上腺素受體的影響。 <a href="#ref-4">[4]</a> 這些多來自體外與動物研究。人體試驗的結果顯示這些機制推論並未轉化成臨床效益 <a href="#ref-1">[1]</a>，其中一個可能的解釋是鋸棕櫚對 5α-還原酶的抑制強度遠低於處方藥。與 finasteride 相比還有一點實務差異：就現有資料看，鋸棕櫚並不會明顯改變 PSA 數值，因此使用它一般不影響 PSA 篩檢的判讀，這與會使 PSA 降低約一半的 finasteride 不同。

## 食物來源／常見來源

鋸棕櫚果實在台灣沒有食用習慣，也不是飲食來源，全部以萃取後的補充品形式流通。市面產品多為軟膠囊，標示劑量常見每日 320 毫克（分一次或兩次服用），這個數字來自歐洲製劑的傳統用法。

## 建議攝取量／常見攝取建議／研究中常見使用方式

鋸棕櫚不是營養素，沒有建議攝取量。臨床試驗最常使用的劑量是每日 320 毫克脂溶性萃取物，療程從數週到超過一年 <a href="#ref-1">[1]</a>。Cochrane 回顧另外檢驗了兩倍與三倍劑量，同樣未見改善 <a href="#ref-1">[1]</a>，因此「效果不好就加量」在這個成分上缺乏依據。基於現有證據，較合理的做法是先由泌尿科醫師評估症狀來源與嚴重度，再決定是否需要 α 阻斷劑、5α-還原酶抑制劑或其他處置；把鋸棕櫚當成第一步並期待它取代這些選項，與證據不符。

## 缺乏風險或攝取不足問題

鋸棕櫚不是必需營養素，沒有缺乏症。攝護腺隨年齡增生是常見的生理變化，與是否攝取鋸棕櫚無關。排尿變慢、夜尿增加、餘尿感這些症狀需要的是評估與分級處置，而非補位某個「缺乏的成分」。

## 補充品常見形式

台灣市面以軟膠囊為主，單方與複方都常見。複方最常搭配茄紅素、南瓜籽油、鋅、蕁麻根與 β-谷固醇。選購時可留意是否為脂溶性萃取物並標示總脂肪酸百分比、每日劑量是否為研究常用的 320 毫克，以及複方中各成分的實際含量。複方產品若出現效果或不良反應，難以歸因於單一成分；部分產品同時添加多種訴求相近的植物萃取，實際上並未提高證據強度。

## 安全性與注意事項

鋸棕櫚在試驗中的耐受性良好，不良反應發生率與安慰劑接近，常見為輕微腸胃不適與頭痛。 <a href="#ref-1">[1]</a> <a href="#ref-5">[5]</a> 曾有零星與出血相關的個案報告，正在服用抗凝血劑、抗血小板藥物或準備接受手術者，使用前宜告知醫師或藥師。真正需要重視的風險偏向臨床判斷面：下泌尿道症狀可能來自攝護腺癌、膀胱功能異常、神經系統疾病或糖尿病，自行以補充品處理可能延誤診斷。出現血尿、無法排尿、發燒合併腰痛、體重不明原因下降，或症狀在數週內明顯惡化時，應立即就醫。女性、孕期與哺乳期因涉及荷爾蒙相關機制且缺乏安全資料，一般不建議使用。

## 常見迷思

- 「鋸棕櫚是攝護腺保健的必備成分」：目前最高層級的證據顯示它相較安慰劑並未帶來有意義的症狀改善 <a href="#ref-1">[1]</a>，「必備」的定位來自市場慣例而非研究結果。
- 「吃了沒感覺就再加量」：Cochrane 回顧已檢驗兩倍與三倍劑量，夜尿、尿流速與症狀評分皆未改善。 <a href="#ref-1">[1]</a>
- 「以前的研究說有效」：2002 年較早的回顧確實較正向 <a href="#ref-3">[3]</a>，但當時納入的研究品質參差，後續加入嚴謹試驗後結論改變，較新的回顧應優先採信。
- 「鋸棕櫚可以取代攝護腺藥物」：α 阻斷劑與 5α-還原酶抑制劑有明確的療效證據，兩者的證據等級並不對等，是否用藥應由泌尿科醫師決定。
- 「吃鋸棕櫚會讓 PSA 失準、影響篩檢」：就現有資料看，鋸棕櫚並不會明顯改變 PSA 數值，這與會讓 PSA 約降一半的 finasteride 不同；不過看診時仍應主動告知所有使用中的補充品。
