## 30 秒認識

- β-丙胺酸是丙胺酸的一種異構物，體內用途和構成蛋白質的丙胺酸不同，主要功能是與組胺酸結合成雙肽「肌肽」（carnosine），補充後能不能提高肌肽合成，取決於身體能取得多少β-丙胺酸，這也是它被拿來研究的核心理由。 <a href="#ref-1">[1]</a>
- 國際運動營養學會（ISSN）2015年立場聲明整理指出，每日補充4到6克、持續至少2到4週，能提升高強度運動表現，效果在開放式終點的計時測驗、時間落在1到4分鐘之間較明顯。 <a href="#ref-1">[1]</a>
- Hobson等人2012年的統合分析納入15篇試驗、360名受試者，發現β-丙胺酸對60到240秒的運動測驗有提升效果（P=0.001），但對60秒以下的運動沒有觀察到效果（P=0.312），時間長度是決定會不會有效的關鍵變數。 <a href="#ref-2">[2]</a>
- 皮膚刺痛感（醫學上稱感覺異常）是目前唯一被記錄到的副作用。彙整安全性數據的風險評估分析算出勝算比8.9，補充組出現比例18.6%、安慰劑組5.7%，症狀通常在服用後10到20分鐘出現，屬短暫且未觀察到健康危害。 <a href="#ref-6">[6]</a>
- 素食者的肌肉基礎肌肽濃度通常低於葷食者，補充後的濃度增幅相對較大，這點在評估自己是否需要、要補多少時可以列入考量。 <a href="#ref-1">[1]</a>

## 基本介紹

β-丙胺酸（beta-alanine）是一種非必需胺基酸，人體可以自行合成，也能透過飲食中的肉類與家禽攝取。它在化學結構上屬於「非蛋白質性」胺基酸，胺基不接在alpha碳上，因此不會像丙胺酸（alanine）一樣被用來組裝人體蛋白質，而是專門作為合成雙肽「肌肽」（carnosine）的兩個原料之一，另一個原料是組胺酸（histidine）。 <a href="#ref-1">[1]</a> 由於組胺酸在肌肉細胞內的濃度相對充足，β-丙胺酸的供應量才是決定肌肽合成速度的限制因子，這也是運動營養研究把焦點放在β-丙胺酸補充、而不是直接補充肌肽本身的原因——直接口服肌肽會在腸道被水解酶分解成兩個胺基酸，效率不如直接補β-丙胺酸。它不是維生素，也不是藥品，本質上是一種胺基酸類的運動營養補充品，在健身房、格鬥、划船、游泳等訓練圈流通已有二十年以上的歷史。 <a href="#ref-4">[4]</a>

## 這是什麼？

丙胺酸家族裡最常聽到的其實有兩種，容易被混淆。alpha-丙胺酸（L-alanine）是二十種標準胺基酸之一，胺基接在alpha碳上，會被用來組裝肌肉與其他組織的蛋白質；β-丙胺酸的胺基則接在beta碳上，結構上多了一個碳的距離，這個差異讓它無法被核糖體辨識、用來合成蛋白質，卻剛好符合肌肽合成酶（carnosine synthase）的受質需求，能與組胺酸結合成肌肽這種雙肽分子。 <a href="#ref-1">[1]</a> 肌肽本身自1900年代初期就被發現存在於骨骼肌與腦組織中，濃度在快縮肌纖維（第二型肌纖維）中特別高，這也解釋了為什麼β-丙胺酸補充對爆發力與高強度運動的相關研究特別多。 <a href="#ref-4">[4]</a>

## 在身體裡做什麼？／主要作用機制

高強度運動仰賴無氧醣解提供能量，這個過程會讓氫離子（H+）在肌肉細胞內快速堆積，造成肌肉內部環境酸化，一般認為這是導致肌肉疲勞、力量與速度下降的重要原因之一。肌肽是肌肉細胞內主要的細胞內酸鹼緩衝物質之一，能夠結合多餘的氫離子、延緩pH值下降的速度，理論上讓肌肉在酸化環境中能多撐一段時間。 <a href="#ref-1">[1]</a> β-丙胺酸補充能提高肌肉中的肌肽存量，等於是增加了這套緩衝系統的原料庫存；Hobson等人的統合分析發現效果集中在60到240秒等中長時間的高強度運動，這個時間範圍剛好對應無氧醣解占能量供應主導地位、氫離子堆積最明顯的區間。 <a href="#ref-2">[2]</a> ISSN立場聲明另外整理指出，β-丙胺酸對神經肌肉疲勞也有延緩效果，且在年長受試者身上的改善幅度更大，聲明中引用的一篇研究記錄到，年長者在特定的疲勞閾值測驗（physical working capacity at fatigue threshold, PWCFT）上出現37.3%的改善幅度，推測與年長者第二型肌纖維流失、基礎緩衝能力下降有關，但這類研究樣本數通常不大，仍需要更多驗證。 <a href="#ref-1">[1]</a> 值得分開理解的是，補充後常見的皮膚刺痛感和上述的酸鹼緩衝機制是兩條完全不同的路徑——刺痛感是β-丙胺酸直接與皮膚感覺神經元上的MrgprD受體結合所引發，這條路徑不需要組胺酸參與、也和肌肽合成無關，詳見下方「安全性與注意事項」段落。 <a href="#ref-7">[7]</a>

## 食物來源／常見來源

自然界中，β-丙胺酸本身以游離胺基酸的型態存在於食物中的量很少，人體主要的膳食來源其實是肉類、家禽與魚肉中的肌肽與鵝肌肽（anserine）——這兩種雙肽在消化過程中會被水解酶分解，釋放出β-丙胺酸與組胺酸，再被肌肉細胞吸收利用。雞胸肉、牛肉、豬肉、鮪魚等紅肉與白肉都是常見來源，這也是為什麼長期葷食者的肌肉基礎肌肽濃度，平均會高於長期素食或全素者。 <a href="#ref-1">[1]</a> 這個差異不代表素食者「缺乏」β-丙胺酸，而是反映飲食型態帶來的基礎濃度差異；ISSN立場聲明整理的資料也顯示，基礎濃度較低的素食族群，補充後肌肽濃度的增幅反而比雜食者更大。 <a href="#ref-1">[1]</a> 由於天然食物中游離型態的β-丙胺酸含量有限，光靠飲食很難達到研究中常用的每日4到6克劑量，這也是補充品形式（見下方段落）被廣泛使用的原因。

## 建議攝取量／常見攝取建議／研究中常見使用方式

ISSN 2015年的立場聲明給出的核心建議是：每日補充4到6克β-丙胺酸，持續至少2到4週，能夠有效提升運動表現；補充2週左右，肌肉肌肽濃度可提高約20%到30%，補充滿4週則可提高約40%到60%。 <a href="#ref-1">[1]</a> Harris等人2006年的劑量反應試驗提供了更精確的數字：每日補充3.2克、連續4週，肌肉肌肽濃度平均增加42.1%；補充6.4克4週，增加64.2%；補充等莫耳量的L-肌肽本身則增加65.8%，三組增幅接近，顯示直接補充β-丙胺酸與補充肌肽本身在提升肌肉肌肽濃度上的效率相近，但β-丙胺酸的成本通常較低。 <a href="#ref-4">[4]</a> 這篇試驗同時發現，補充後尿液中流失的β-丙胺酸不到5%，代表大部分劑量確實被身體保留利用。 <a href="#ref-4">[4]</a>

不過2025年一篇針對肌力與爆發力表現的劑量策略系統性回顧指出，口服β-丙胺酸大約只有6%最終真正進入肌肉、合成為肌肽，其餘會被其他組織代謝或排出，這是因為負責運送β-丙胺酸進入肌肉細胞的載體蛋白容量有限、容易飽和。 <a href="#ref-8">[8]</a> 這篇回顧建議把每日總劑量拆成多次、每次約0.8克服用，而不是一次吃完，除了能降低下方會提到的皮膚刺痛感，也能減少單次載體飽和造成的浪費；針對肌力與爆發力目標，回顧中納入的有效方案負荷期多落在5到8週之間，且在合併短休息、多組數、代謝壓力較高的訓練型態（例如高反覆次數的重量訓練或反覆衝刺）中，效果較容易顯現。 <a href="#ref-8">[8]</a>

哪些運動類型比較可能受益，兩篇大型統合分析給出了一致的輪廓。Hobson等人的分析顯示效果集中在60到240秒、以及240秒以上的運動，60秒以下（例如短跑衝刺、單次最大重量的重量訓練）沒有觀察到顯著效果。 <a href="#ref-2">[2]</a> Saunders等人2017年納入40篇試驗、65種運動測驗、共1461名參與者的統合分析進一步發現，在30秒到10分鐘的區間內，運動類型是效果量的顯著調節因子（P=0.013），對「運動能力」（撐到力竭為止的時間）的效果量0.4998明顯大於對「運動表現」（固定距離或固定時間的成績）的效果量0.1078；這份分析也發現，補充總量的多寡並不會顯著改變效果（P=0.438），而合併小蘇打（碳酸氫鈉）補充的組別，效果量達到0.43，是所有子分析中最大的。 <a href="#ref-3">[3]</a> 綜合來看，划船、游泳中短距離項目、格鬥運動的回合制對抗、反覆衝刺型的團隊運動（如足球、籃球的間歇跑動）這類落在1到4分鐘、且會反覆累積氫離子的運動型態，證據支持度相對較高；單次最大力量或爆發力測驗（如1RM深蹲、100公尺短跑）目前證據較弱。

## 缺乏風險或攝取不足問題

β-丙胺酸不是必需營養素，體內可以自行合成，目前沒有已知的臨床「缺乏症」。飲食中長期攝取較少肉類、家禽的族群（如素食者、全素者），肌肉基礎肌肽濃度會相對較低，但這是飲食型態帶來的基礎值差異，不是病理性的缺乏，日常生活功能也不會因此受影響。 <a href="#ref-1">[1]</a> 比較值得留意的是年長族群：隨著年齡增加，第二型（快縮）肌纖維會優先流失，這類肌纖維原本肌肽濃度較高，流失後連帶影響整體緩衝能力，可能是ISSN立場聲明中提到年長受試者補充後神經肌肉疲勞改善幅度較大的部分原因。 <a href="#ref-1">[1]</a> 這個現象與肌肉量隨年齡下降的機制有部分重疊，本站在〈[肌少症與肌肉流失完整guide](/articles/sarcopenia-muscle-loss-guide/)〉一文有更完整的整理，兩者的共同重點都是及早透過阻力訓練搭配足夠的營養介入來延緩流失，而不是單靠某一種胺基酸補充品解決。

## 補充品常見形式

市售β-丙胺酸補充品主要分成兩種釋放型態，差異集中在服用後的血中濃度曲線與副作用感受。 <a href="#ref-5">[5]</a>

- **一般（速釋）粉末或錠劑**：吸收速度快，單次劑量超過800毫克通常就會引發程度不等的皮膚刺痛感，是市面上最常見、價格也最低的型態。
- **緩釋錠劑**：透過緩慢釋放技術延後吸收速度。Décombaz等人2012年的隨機對照試驗比較同樣1.6克劑量的純溶液與緩釋錠劑，發現緩釋錠劑的血中峰值濃度明顯較低（82對248微莫耳/公升，p&lt;0.001），達到峰值的時間也較晚（1.0小時對0.5小時，p&lt;0.01），但兩者的總吸收量（曲線下面積）沒有差異，緩釋錠劑的尿液流失量更低、保留率更高（98.9%對96.3%，p&lt;0.001）。這代表緩釋劑型能在不犧牲吸收總量的前提下，降低刺痛感的強度。

市售產品也常見把β-丙胺酸和肌酸、碳酸氫鈉（小蘇打）一起放進同一份「訓練前補給品」（pre-workout）配方中。本站在〈[肌酸完整介紹](/ingredients/creatine/)〉一文整理了肌酸的證據；就β-丙胺酸而言，目前沒有直接比較「單獨補充β-丙胺酸」與「β-丙胺酸加肌酸」的頭對頭試驗，但Saunders等人2017年的分析顯示，合併碳酸氫鈉補充的效果量在所有子分析中最大（0.43，95% CI 0.22–0.68），這比較像是兩種各自獨立的緩衝機制疊加，而不是β-丙胺酸本身的效果被放大。 <a href="#ref-3">[3]</a>

## 安全性與注意事項

目前累積的安全性資料以Dolan等人2019年的風險評估統合分析最完整，這篇分析彙整了長期試驗（最長追蹤到24週）與急性試驗的副作用數據、血液生化指標、以及動物實驗結果。結果顯示皮膚刺痛感（感覺異常）是唯一被明確記錄到的副作用，勝算比8.9（95% CI 2.2–32.6），補充組發生率18.6%、安慰劑組5.7%；Dolan等人指出，決定症狀出現與否、強度大小的因素，主要是血中β-丙胺酸濃度上升的速度與峰值高低，總劑量的影響相對次要，這也是前面提到緩釋劑型、分次服用能降低刺痛感的原因。 <a href="#ref-6">[6]</a> 症狀本身被歸類為短暫且無害，通常在服用後10到20分鐘出現，會逐漸消退。

刺痛感背後的生理機制，Liu等人2012年在小鼠與人體皮膚細胞的研究中有清楚說明：β-丙胺酸會直接與皮膚感覺神經元表面的MrgprD受體結合，這類神經元的軸突專門分布在有毛與無毛皮膚的表皮層，activated後會引發搔癢與刺痛感的神經訊號；缺乏這個受體的小鼠，對β-丙胺酸幾乎不再出現搔抓反應。 <a href="#ref-7">[7]</a> 這條路徑和典型的組織胺過敏反應不同，屬於「不經組織胺」的獨立搔癢路徑，人體試驗中皮下注射β-丙胺酸也只引發癢感而沒有典型過敏反應會出現的膨疹與紅暈，代表這個症狀本質上是感覺神經被直接活化，而不是免疫系統的過敏反應。 <a href="#ref-7">[7]</a>

血液生化指標方面，Dolan等人的分析發現補充組的肝功能指標ALT（丙胺酸轉胺酶）有小幅上升（效果量0.274），但平均數值仍落在每公升40單位以下的正常參考範圍內；腎功能相關指標（肌酸酐、腎絲球過濾率）與腸胃道副作用則沒有觀察到顯著變化。 <a href="#ref-6">[6]</a> 這些安全性數據多來自健康成人、追蹤時間在24週以內的試驗，孕婦、哺乳中女性，以及已有肝臟或腎臟慢性疾病的族群，目前缺乏專門的安全性研究，建議這些族群在使用前先與醫師討論；正在服用其他可能影響肝腎功能藥物的人，也建議一併告知醫師目前的補充品使用情況。

## 常見迷思

- **「刺痛感越明顯，代表產品越有效、劑量不夠才不會有感覺」**：刺痛感的強弱由血中β-丙胺酸上升速度決定，和肌肉肌肽合成效率是兩條不同機制；緩釋劑型能在幾乎不影響總吸收量的前提下大幅降低刺痛感，代表兩者沒有必然的正相關。 <a href="#ref-5">[5]</a>
- **「隨便什麼運動吃了都會進步」**：Hobson等人的分析顯示60秒以下的運動沒有觀察到效果，效果集中在60到240秒與更長的運動；Saunders等人的分析也指出，「撐到力竭的時間」比「固定距離的成績」更容易看到效果，並非所有運動類型都適用。 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>
- **「劑量吃越多效果越好，沒有上限」**：Saunders等人的統合分析發現，補充總量的多寡並沒有顯著改變效果量（P=0.438），超出研究常用範圍的劑量目前缺乏效果會等比例提升的證據，反而會增加刺痛感風險。 <a href="#ref-3">[3]</a>
- **「素食者不需要，也不適合補充」**：素食者的肌肉基礎肌肽濃度通常較低，補充後的增幅反而比雜食者更大，這點在ISSN立場聲明整理的資料中有明確呈現。 <a href="#ref-1">[1]</a>
- **「刺痛感代表過敏或不安全，要立刻停用」**：這個感覺是β-丙胺酸直接活化皮膚感覺神經元上的MrgprD受體所致，屬於不經組織胺的獨立路徑，不是典型過敏反應；風險評估統合分析將其歸類為短暫、未觀察到健康危害的副作用。 <a href="#ref-6">[6]</a> <a href="#ref-7">[7]</a>

## 常見問題

### 一定要先做「負荷期」嗎？可以直接每天吃固定劑量嗎？

研究中常見的做法確實是先以每日4到6克進行2到4週的負荷期，讓肌肉肌肽濃度先墊高，之後再視訓練目標調整。 <a href="#ref-1">[1]</a> 若不想一次吃到4到6克，把總劑量拆成每次約0.8克、一天多次服用，同樣能達到累積效果，而且可以降低刺痛感發生的機會，是2025年劑量策略回顧建議的做法之一。 <a href="#ref-8">[8]</a>

### 刺痛感真的很不舒服，有什麼方法可以減少？

兩個方向都有實證支持：一是把單次劑量控制在800毫克以下、分成多次服用，二是改用緩釋錠劑。Décombaz等人的試驗顯示，同樣1.6克劑量下，緩釋錠劑的血中峰值濃度只有純溶液的三分之一左右，達到峰值的時間也較晚，但總吸收量沒有減少，等於是用比較平緩的釋放曲線換取比較低的刺痛感。 <a href="#ref-5">[5]</a>

### 哪些運動類型比較可能有效？哪些可能沒什麼幫助？

證據支持度較高的是持續60秒到10分鐘、過程中會反覆或持續累積氫離子的高強度運動，例如划船、游泳中短距離項目、格鬥運動的回合制對抗、team sport裡的反覆衝刺跑動。 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a> 單次最大力量測驗（如1RM深蹲）或60秒以下的短時間全力衝刺，目前的統合分析沒有觀察到顯著效果，這類項目若想採用增補劑，肌酸的證據相對更完整，可參考本站〈[肌酸基礎知識：效果、劑量與服用時機](/articles/creatine-basics-effects-dosage-timing/)〉一文。 <a href="#ref-2">[2]</a>

### 可以跟肌酸一起吃嗎？會不會互相干擾？

目前沒有證據顯示兩者會互相干擾吸收或效果；兩者的作用機制完全不同——肌酸主要影響磷酸肌酸系統與快速能量再生，β-丙胺酸則透過肌肽緩衝酸化，市售訓練前補給品也常把兩者放在同一配方中一起販售。本站另有〈[肌酸完整介紹](/ingredients/creatine/)〉可參考劑量與適用族群的細節。

### 年長者也適合補充β-丙胺酸嗎？

ISSN立場聲明整理的資料顯示，年長受試者補充後在神經肌肉疲勞相關測驗上的改善幅度，往往比年輕受試者更明顯，推測與年長者第二型肌纖維流失、基礎緩衝能力下降有關；但這類研究的樣本數通常不大，實際應用前建議先與醫師或物理治療師討論訓練目標與整體用藥情況，而不是自行套用年輕運動員的劑量。 <a href="#ref-1">[1]</a>
