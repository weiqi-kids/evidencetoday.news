## 30 秒認識

- 《臺灣中藥典》第四版收載的杜仲，只有杜仲科植物 *Eucommia ulmoides* Oliv. 的**乾燥樹皮**。全書沒有「杜仲葉」這一條專論。 <a href="#ref-15">[15]</a> 市售杜仲茶包多半用葉，這代表你泡的那杯和中藥房抓的那包，在藥典上不是同一個東西。
- 樹皮與葉的成分差異是量測得出來的。Yan 等人 2018 年用超快速液相層析串聯質譜同時測定 21 種成分，發現樹皮、葉、雄花的化學組成有顯著差異，關鍵差異成分包括桃葉珊瑚苷、京尼平苷酸、綠原酸、松脂醇二葡萄糖苷、京尼平苷、隱綠原酸、蘆丁與槲皮素。 <a href="#ref-7">[7]</a>
- 降血壓最常被引用的那篇，結果其實一半是失敗的。Greenway 等人 2011 年的試驗裡，500 毫克每日三次連續 8 週（24 人）測不到血壓差異；把劑量提到 1 公克每日三次、療程縮到 2 週（30 人），24 小時動態血壓才降了 7.5/3.9 mmHg。 <a href="#ref-1">[1]</a>
- 最新一篇加成試驗沒有達到主要終點。Tang 等人 2025 年的多中心隨機試驗收 136 人，在原有西藥之外加服全杜仲膠囊 12 週，血壓標準差與變異係數在兩組之間沒有顯著差異。 <a href="#ref-3">[3]</a>
- 這件事是本頁最重要的安全訊息：Greenway 的細胞試驗顯示杜仲萃取物具有 β 腎上腺素阻斷活性，動物實驗則指向一氧化氮上升與腎素-血管張力素系統下降。 <a href="#ref-1">[1]</a><a href="#ref-5">[5]</a> 這三條路徑和常用降壓藥重疊，同時使用等於在同一個方向上疊加。
- 杜仲目前不在現行有效的「可同時提供食品使用之中藥材」215 項清單裡。 <a href="#ref-18">[18]</a> 中醫藥司 115 年 4 月 13 日預告的新草案把它列入第二類（食用時須注意安全性者）第 53 項，基原限乾燥樹皮，每人日食用限量 3 公克。 <a href="#ref-17">[17]</a>

## 基本介紹

杜仲腰花是台灣熱炒店與藥膳店的固定班底，杜仲燉排骨是產後與病後的家常補湯，超市與藥妝店的架上還有一整排杜仲茶包。它的社會定位很穩定：腰痠、產後、年紀大了要補。同時在長輩之間流傳的另一句話是「杜仲降血壓」，於是它常常和降壓藥出現在同一個藥盒旁邊。

這個組合正是需要單獨談一次的理由。杜仲不是一味沒有藥理作用的食材，它有明確的作用方向，而那個方向恰好和降壓藥相同。搭配得當是重複用藥，搭配不當是血壓掉太低。要判斷自己血壓的真實狀況，先照國健署的居家「722」原則量七天再說，方法見〈[高血壓完整指南](/articles/hypertension-130-80-home-bp-guide/)〉。 <a href="#ref-22">[22]</a>

## 這是什麼？

**藥典上的定義。**《臺灣中藥典》第四版對杜仲的規格寫得很細：本品為杜仲科植物 *Eucommia ulmoides* Oliv. 的乾燥樹皮；稀乙醇抽提物不得少於 7.0%，水抽提物不得少於 5.0%，所含松酯醇二葡萄糖苷不得少於 0.1%。性狀描述提到斷面有細密銀白色富彈性的膠絲相連，一般可拉至 1 公分以上才斷，這是辨識杜仲最直觀的特徵。用途分類為補益藥（補陽），性味甘、溫，歸肝、腎經，功能記為補肝腎、壯筋骨、安胎，用法與用量 6 至 15 公克。 <a href="#ref-15">[15]</a>

**三個部位，三種成分輪廓。** 杜仲的樹皮（Eucommiae Cortex）、葉（Eucommiae Folium）與雄花（Eucommiae Flos Male）在傳統上都被使用。Yan 等人 2018 年的比較研究測定了兩種木脂素、六種環烯醚萜、六種苯丙素、六種黃酮與一種酚類，主成分分析可以把三個部位清楚分開。 <a href="#ref-7">[7]</a> 實務上的意義是：以松脂醇二葡萄糖苷為指標成分的品質規格適用於樹皮，套到葉子上並不成立；而綠原酸與京尼平苷酸這類成分在葉與雄花中的比重較高。

**為什麼茶包多用葉。** 樹皮要剝樹，葉子可以年年採收，成本與再生速度差很多。日本把杜仲葉泡成杜仲茶（Tochu 茶）的歷史也很長，Ishimitsu 等人 2021 年的論文開頭就是這句話。 <a href="#ref-4">[4]</a> 所以「杜仲茶」這個品類在多數情況下指的是葉，而不是藥典裡的那味藥材。葉部被研究得最多的成分之一是車葉草苷（asperuloside），Fujikawa 等人 2012 年在高脂飲食大鼠模型中把它定位為杜仲葉抗肥胖活性的主成分。 <a href="#ref-13">[13]</a> 桃葉珊瑚苷（aucubin）則有一篇 2020 年發表於《Fitoterapia》的藥理與毒理回顧可以參考，該文同時整理了它的活性與安全性資料。 <a href="#ref-9">[9]</a>

## 在身體裡做什麼？／主要作用機制

降壓機轉的資料相對集中，可以拆成三條，而這三條都和市售降壓藥的作用點重疊。

**第一條是一氧化氮與血管舒張。** Luo 等人 2010 年在自發性高血壓大鼠身上分離出杜仲的木脂素部位與環烯醚萜部位，發現木脂素部位無論靜脈注射或灌胃都能劑量依賴地降低血壓，環烯醚萜部位則沒有作用，兩者併用也沒有加成。木脂素組的血漿一氧化氮濃度明顯上升，灌流實驗中它可以快速鬆弛腸繫膜動脈，且在有無血管內皮的情況下效果相同。 <a href="#ref-5">[5]</a>

**第二條是腎素-血管張力素系統。** 同一篇研究中，長期口服木脂素部位 150 與 300 mg/kg（每日兩次）後，血漿腎素活性與血管張力素 II 濃度都下降。 <a href="#ref-5">[5]</a> 這條路徑和 ACE 抑制劑、血管張力素受體阻斷劑走的是同一個系統。

**第三條是 β 腎上腺素阻斷。** Greenway 等人 2011 年的子研究二把杜仲萃取物加進人類脂肪細胞，測得它把異丙腎上腺素刺激的脂解由對照的 2.67 倍壓到 1.4 倍（P&lt;0.001），作者據此推論杜仲具有 β 腎上腺素阻斷活性。 <a href="#ref-1">[1]</a> 這一點在後面的安全性段落會再提一次，因為它牽涉到和乙型阻斷劑併用的疊加。

**動物資料裡的性別差異。** Lang 等人 2005 年在自發性高血壓大鼠身上測試杜仲萃取物，最大耐受劑量為 1200 mg/kg，200、600、1200 mg/kg 連續投與 28 天後，臨床外觀、組織病理與血清生化都沒有急性毒性跡象。降壓效果從第 8 天開始出現，但只在公鼠身上觀察到，母鼠沒有；有效的最低劑量是 600 mg/kg。 <a href="#ref-6">[6]</a> 同一種萃取物在不同性別的動物身上結果不同，這件事在推論到人身上時要先放進括號裡。

**腎臟血流。** Ishimitsu 等人 2021 年用食鹽敏感型 Dahl 大鼠測試杜仲茶萃取物與其成分京尼平苷酸，兩者都把高鹽組的血壓由 196 mmHg 分別降到 158 與 162 mmHg，同時抑制腎臟 NADPH 氧化酶、提高內皮型一氧化氮合成酶表現，並改善腎血漿流量。 <a href="#ref-4">[4]</a> 這是大鼠資料，但它解釋了為什麼後來的人體探索性試驗把受試族群設定在慢性腎臟病。

至於安胎、強筋骨這些傳統功能，機轉層級的資料主要是骨代謝方向的動物與細胞研究，Chen 等人 2025 年的系統性回顧與統合分析納入的全部是骨質疏鬆大鼠模型。 <a href="#ref-11">[11]</a> 關節方面，Ahn 等人 2019 年曾在《Medicine》登出一份輕度骨關節炎的 12 週多中心隨機雙盲安慰劑對照試驗計畫書，但 PubMed 上目前檢索不到對應的結果論文。 <a href="#ref-10">[10]</a> 另有一篇 2022 年發表於《Molecules》的回顧，把杜仲在神經內分泌與免疫網絡上的作用整理成一張圖，該文納入的同樣以動物與細胞研究為主。 <a href="#ref-14">[14]</a> 中藥的傳統功能記述與現代藥理機轉是兩套不同的描述系統，混著講很容易讓人以為證據等級比實際高，這個落差在〈[天然草本一定安全嗎](/myths/natural-herbal-safe-myth/)〉裡也出現過。

## 食物來源／常見來源

杜仲不是營養素，沒有膳食來源可以談。台灣人接觸到它的途徑大致是這幾種：

- **藥膳**：杜仲腰花、杜仲燉排骨、杜仲雞湯。中藥房的藥膳包裡杜仲通常和續斷、牛膝、當歸同用，複方的其他成分各有各的注意事項，當歸的部分見〈[當歸](/ingredients/dong-quai/)〉。
- **複方湯劑**：《臺灣中藥典》收載的獨活寄生湯含杜仲 2 錢，一日飲片量 31 公克；三痺湯也含杜仲 1.5 錢。 <a href="#ref-15">[15]</a>
- **杜仲茶包**：多用葉，市售常見於超市與電商。
- **濃縮製劑與膠囊**：包括科學中藥、標準化萃取物（如 Greenway 試驗使用的標準化至 8% 松脂醇二葡萄糖苷的樹皮水萃取物）與保健食品型態產品。 <a href="#ref-1">[1]</a>

## 建議攝取量／研究中常見使用方式

臺灣中藥典記載的杜仲用法與用量是 6 至 15 公克（指飲片，非萃取物）。 <a href="#ref-15">[15]</a> 人體試驗使用的則是萃取物，劑量無法直接換算：

- Greenway 2011 子研究一：標準化萃取物 500 毫克，每日三次，8 週，24 人。血壓無差異。 <a href="#ref-1">[1]</a>
- Greenway 2011 子研究三：同一支萃取物 1 公克，每日三次，2 週，30 人。24 小時動態血壓降 7.5/3.9 mmHg。 <a href="#ref-1">[1]</a>
- Satonaka 2025：含杜仲葉萃取物的錠劑，中位 33 天，17 人單臂。收縮壓由 128.3 降至 123.8 mmHg。 <a href="#ref-2">[2]</a>
- Tang 2025：全杜仲膠囊 1.48 公克，每日兩次，12 週，加在原有西藥之上，136 人。主要終點未達顯著。 <a href="#ref-3">[3]</a>
- Hao 2025：杜仲葉茶每日 10 公克、連續 4 週，30 名高尿酸志願者的單臂觀察，主體仍是小鼠實驗。 <a href="#ref-12">[12]</a>

7.5/3.9 mmHg 這個數字要放進脈絡看。它在流行病學上不算小，但那是在 30 人、2 週、非高血壓患者（血壓 120-160/80-100 mmHg）身上測到的；同一支萃取物在 8 週的較低劑量組測不到差異，且這三個子研究之後沒有更大規模的重複驗證。 <a href="#ref-1">[1]</a> 現有證據的等級離「可以取代降壓藥」還有很長一段距離，該不該用藥的判斷標準見〈[美國高血壓指引大翻修，血壓 130-139 的台灣人現在該不該吃藥](/articles/hypertension-eligibility-us-guideline-taiwan-what-to-do/)〉。

## 缺乏風險或攝取不足問題

杜仲沒有缺乏症。不吃杜仲不會造成任何生理缺損，這類說法沒有立足點。

需要處理的是血壓本身。收縮壓持續偏高的後果是中風、心肌梗塞、腎功能惡化與心衰竭，而這些風險有明確的藥物與生活型態介入可以降低。把降壓的希望放在一杯茶上，實際代價是延後診斷與治療。腎功能的追蹤方式見〈[慢性腎臟病完整指南](/articles/chronic-kidney-disease-egfr-guide/)〉。

## 市售與藥材常見形式

- **生杜仲飲片**：中藥房抓藥時的原型態樹皮，斷面可見膠絲。
- **鹽杜仲（鹽炒杜仲）**：傳統炮製方式，以鹽水炒至膠絲斷裂。炮製對成分的影響有中國大陸的實驗資料，但生品與炮製品在人體上的頭對頭比較，PubMed 上查無。
- **杜仲葉茶包**：使用葉部，成分輪廓與樹皮不同。 <a href="#ref-7">[7]</a>
- **標準化萃取物**：以松脂醇二葡萄糖苷含量標示，Greenway 試驗使用的是標準化至 8% 的樹皮水萃取物。 <a href="#ref-1">[1]</a>
- **複方中成藥**：例如 Tang 2025 試驗使用的全杜仲膠囊，屬於中國大陸核准的中成藥，台灣的核准狀況需個別查證。
- **保健食品**：以杜仲為名的錠劑、飲品在市面上存在，其法規身分取決於原料部位、含量與產品型態，下一段會講。

## 台灣的法規與市場實況

**現行狀態：杜仲不在可食用中藥材清單裡。** 中醫藥司依「酌量分期」原則陸續公告的「可同時提供食品使用之中藥材」共 215 項，清單內容涵蓋蔬菜類、水果果實類、五穀雜糧類、魚蚌蝦蟹類、禽獸類與其他類，杜仲不在其中。 <a href="#ref-18">[18]</a> 107 年 2 月 22 日生效的追加公告收載 37 項（百合、荷葉、陳皮、砂仁、人參花等），同樣沒有杜仲。 <a href="#ref-19">[19]</a> 這代表杜仲原料的批發零售依《藥事法》相關規定辦理，而非依食品法規。 <a href="#ref-23">[23]</a>

**草案要改的是什麼。** 中醫藥司在民國 115 年 4 月 13 日（衛部中字第 1151860670 號）預告《得供食品原料使用之中藥材品項及其產品屬性認定基準》草案，公告翌日起 60 日內開放提出意見。 <a href="#ref-17">[17]</a> 草案把得供食品原料使用的中藥材分成兩類：第一類「具傳統食用文化得供食品原料用途者」共 75 項，第二類「食用時須注意安全性者」共 73 項。杜仲列在**第二類第 53 項**，學名 *Eucommia ulmoides* Oliv.，部位限**乾燥樹皮**，備註欄寫明每人日食用限量 3 公克。 <a href="#ref-17">[17]</a>

這個 3 公克不是隨便訂的。草案第五點規定，第二類中藥材任一品項換算每日食用量超過臺灣中藥典所載該品項最低用量的百分之五十者，以藥品管理；杜仲在中藥典的用量下限是 6 公克，一半就是 3 公克。 <a href="#ref-15">[15]</a><a href="#ref-17">[17]</a>

**杜仲葉沒有被列入。** 草案附表的部位欄只寫乾燥樹皮，臺灣中藥典第四版也沒有杜仲葉的專論。 <a href="#ref-15">[15]</a><a href="#ref-17">[17]</a> 也就是說，用葉子做的杜仲茶既不在藥典規格內，也不在草案的中藥材品項內。

**那為什麼茶包可以滿街賣。** 草案第七點列出三種不以藥品管理的產品型態，其中第三款是「經粗碎後以棉紙袋或不織布袋包裝製成之茶包型態」，第二款是滷包、燉包、藥膳調理包等以食材為主體並在外包裝載明燉煮方式的產品。 <a href="#ref-17">[17]</a> 藥膳包與茶包這兩條路徑，正是杜仲在台灣日常通路上出現的主要形式。草案目前仍在預告階段，最終條文以正式公告為準。

**重金屬與殘留檢驗。** 杜仲是台灣最早被納入重金屬管制的七種中藥材之一。衛生署 93 年 1 月 13 日署授藥字第 093000211 號公告「杜仲等七種中藥材之重金屬限量標準及其相關規定」，七種為杜仲、枇杷葉、肉桂、桂枝、桂皮、白及、五加皮，限量為鎘 2 ppm 以下、鉛 30 ppm 以下、汞 2 ppm 以下，自 93 年 2 月 1 日施行，藥廠與中藥商須保存檢驗合格成績書與購買來源憑證備查。 <a href="#ref-20">[20]</a>

臺灣中藥典第四版對杜仲訂的個別規格比這份公告更嚴：砷限量 3.0 ppm、鎘 1.0 ppm、汞 0.2 ppm、鉛 15.0 ppm、二氧化硫殘留量不得超過 150 ppm，另有乾燥減重不得超過 11.0%、總灰分不得超過 9.0%、酸不溶性灰分不得超過 5.0%。 <a href="#ref-15">[15]</a> 二氧化硫那一項對應的是燻硫處理，中藥材的農藥殘留、黃麴毒素等異常物質另有個別公告，可在中醫藥司的中藥材與飲片專區查詢。 <a href="#ref-21">[21]</a>

**買的時候可以做什麼。** 在中藥房抓杜仲，可以請店家出示該批的檢驗合格成績書；買茶包或膠囊，看包裝上有沒有標明使用部位是樹皮還是葉，以及每日建議量換算成原藥材是多少公克。想核對藥典規格或查中西藥併用的提醒，衛福部設有「臺灣中藥典及中西藥併用查詢系統」可以直接查詢品項。 <a href="#ref-16">[16]</a>長輩同時吃中藥與西藥的組合風險，〈[長輩西藥中藥一起吃，哪些組合真的會出事](/articles/elderly-tcm-western-drug-combos-that-matter/)〉整理過判斷順序。

## 安全性與注意事項

**與降壓藥併用是本頁最重要的一條。** 杜仲被驗證的三個作用方向分別是提高一氧化氮、抑制腎素-血管張力素系統、以及 β 腎上腺素阻斷活性。 <a href="#ref-1">[1]</a><a href="#ref-5">[5]</a> 這三條分別對應到硝酸鹽類與血管擴張劑、ACE 抑制劑與血管張力素受體阻斷劑、以及乙型阻斷劑。已經在服藥的人再加上杜仲，可能出現的是姿勢性低血壓、頭暈、疲倦與跌倒，年長者的跌倒後果尤其嚴重。要加要停都先告訴開藥的醫師，不要自己調整，相關原則見〈[慢性病藥和保健食品並用，你需要知道的 5 件事](/articles/chronic-disease-drug-supplement-interaction/)〉。

**腎毒性訊號。** Luo 等人 2020 年的安全性評估在 Ames 試驗、骨髓微核試驗與染色體異常試驗中均未測到基因毒性，急性毒性也未觀察到，最大耐受劑量不低於 168 g/kg。但 13 週的亞慢性投與出現劑量依賴的腎毒性指標上升與腎組織病理變化；低劑量組（11.2 g/kg）停藥 5 週後改善，高劑量組（56 g/kg）則持續存在。 <a href="#ref-8">[8]</a> 這是大鼠實驗且劑量遠高於人用量，但「長期高劑量可能傷腎」這個方向值得記住，腎功能已經不好的人更該先問過醫師。

**孕婦。** 臺灣中藥典把「安胎」列為杜仲的傳統功能記述。 <a href="#ref-15">[15]</a> 這句話的來源是中醫典籍，不是現代臨床試驗。PubMed 上以杜仲加懷孕、流產為關鍵字檢索不到人體試驗，安全性與有效性都是資料空白。孕期自行服用中藥材補品的風險，和「轉骨方能不能讓青少年長高」屬於同一類問題：傳統用法的普及程度與現代證據的強度是兩回事，見〈[轉骨方真的能讓青少年多長高嗎](/myths/height-growth-tonic-myth/)〉。

**低血壓與姿勢性低血壓者。** 血壓本來就偏低、容易頭暈的人，沒有理由主動使用具降壓方向作用的補品。

**手術前。** 具降壓與 β 阻斷方向作用的補充品，在麻醉期間可能影響血壓與心率反應。手術前應主動向麻醉科告知正在服用的中藥與保健品。

**與鎮靜劑併用。** 這一項要誠實說：在 PubMed 上以杜仲加鎮靜、安眠、GABA 為關鍵字檢索，**查無**直接探討交互作用的研究。理論上具中樞作用的補充品與鎮靜劑併用會加重嗜睡，但就杜仲而言目前沒有可引用的實驗或病例資料，所以本頁不宣稱有此交互作用，也不宣稱沒有。

**兒童與哺乳期。** 現有人體試驗的受試者都是成人，兒童與哺乳期族群沒有對應資料。

**尿酸。** Hao 等人 2025 年的杜仲葉茶研究中，30 名高尿酸志願者每日飲用 10 公克、連續 4 週，主要結果來自小鼠模型，人體部分沒有對照組。 <a href="#ref-12">[12]</a> 高尿酸的處理原則見〈[痛風與高尿酸的成因與飲食](/articles/gout-hyperuricemia-causes-diet/)〉。

## 常見迷思

- **「杜仲茶可以取代降壓藥」**：最強的一筆人體資料是 30 人、2 週、7.5/3.9 mmHg，而同一篇研究的另一組 24 人、8 週測不到差異。 <a href="#ref-1">[1]</a> 加成試驗的主要終點也沒有達標。 <a href="#ref-3">[3]</a> 這個證據量不足以支撐停藥決定。
- **「杜仲茶就是中藥的杜仲」**：藥典收的是樹皮，茶包多半是葉，兩者的成分輪廓在質譜比對下可以清楚分開。 <a href="#ref-7">[7]</a><a href="#ref-15">[15]</a>
- **「安胎的說法有科學根據」**：安胎是中醫典籍的功能記述，臺灣中藥典照錄了這項傳統功能，但沒有現代人體試驗支持，孕期使用的安全性也查無資料。 <a href="#ref-15">[15]</a>
- **「天然藥材不會有劑量問題」**：草案直接把杜仲放進「食用時須注意安全性者」並訂出每人日食用限量 3 公克，這個門檻的計算基礎是臺灣中藥典用量下限的一半。 <a href="#ref-15">[15]</a><a href="#ref-17">[17]</a>
- **「腰痠就是腎虛，喝杜仲就對了」**：下背痛的成因包括肌肉拉傷、椎間盤問題、脊椎狹窄、骨質疏鬆性壓迫性骨折，也可能是泌尿道或婦科疾病的轉移痛。持續超過兩週、夜間痛醒、合併下肢無力或大小便功能改變的腰痛需要就醫，骨質評估的做法見〈[骨質疏鬆完整指南](/articles/osteoporosis-dxa-frax-prevention-guide/)〉。
- **「中藥材沒有重金屬問題」**：杜仲是台灣最早被公告重金屬限量的七種中藥材之一，正因為曾被認定有管制必要。 <a href="#ref-20">[20]</a>

## 常見問題

### 我在吃降壓藥，可以喝杜仲茶嗎？

要先問過開藥的醫師。杜仲的三條作用方向和常見降壓藥重疊，疊加的結果可能是血壓低於目標值、頭暈或跌倒。 <a href="#ref-1">[1]</a><a href="#ref-5">[5]</a> 如果醫師同意試，建議在開始飲用前後各量一週的居家血壓做對照，量法依國健署「722」原則。 <a href="#ref-22">[22]</a>

### 杜仲茶包到底是食品還是藥品？

目前杜仲不在有效的可食用中藥材 215 項清單裡，原料的批發零售依藥事法辦理。 <a href="#ref-18">[18]</a><a href="#ref-23">[23]</a> 115 年 4 月預告的草案若照現行版本通過，杜仲乾燥樹皮將列入第二類，每人日食用限量 3 公克，而粗碎後以棉紙袋或不織布袋包裝的茶包型態不以藥品管理。 <a href="#ref-17">[17]</a> 草案尚未定案，最終以正式公告為準。

### 一天喝多少算安全？

草案訂的參考值是每人日食用限量 3 公克（乾燥樹皮）。 <a href="#ref-17">[17]</a> 中藥典的治療用量是 6 至 15 公克，那屬於醫師處方的範圍。 <a href="#ref-15">[15]</a> 葉部沒有對應的限量規定，只能參考產品標示，這正是葉與皮混用造成的管理空白。

### 孕婦可以喝杜仲茶安胎嗎？

不建議自行使用。安胎是中醫典籍記載的傳統功能，臺灣中藥典照錄了這項功能描述，但現代人體試驗查無。 <a href="#ref-15">[15]</a> 有安胎需求應由產科醫師評估，若想併用中醫治療，請在中醫師與產科醫師都知情的狀況下進行。

### 杜仲會傷腎嗎？

人體上沒有這方面的通報資料。大鼠實驗中，13 週高劑量投與出現劑量依賴的腎毒性指標上升與腎組織病變，低劑量停藥 5 週後部分回復。 <a href="#ref-8">[8]</a> 這個劑量遠高於人的使用量，但長期大量飲用缺乏安全性資料是事實，已有腎功能問題的人更應該先問過醫師。

### 生杜仲和鹽杜仲有差嗎？

炮製會改變成分比例，中國大陸有相關的化學分析文獻，但兩者在人體上的頭對頭比較試驗，PubMed 上**查無**。中醫在不同適應症下選用生品或炮製品，屬於辨證用藥的範疇，不是效力強弱的問題。

### 血壓正常的人喝了會不會太低？

Greenway 試驗的受試者血壓落在 120-160/80-100 mmHg，本來就偏高；Satonaka 試驗中非慢性腎臟病次族群的血壓變化未達顯著。 <a href="#ref-1">[1]</a><a href="#ref-2">[2]</a> 血壓正常者飲用後降到過低的資料目前沒有，但也沒有安全性研究，出現頭暈、站起來眼前發黑就該停用並就醫。
