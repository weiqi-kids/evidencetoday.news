## 30 秒認識

- 台灣食藥署平臺把純化的 DHEA 列為不得用於食品的原料；藥品只有一張有效許可證，是須由醫師處方的陰道栓劑，沒有任何口服 DHEA 的許可證 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>
- 試管療程中卵巢反應不佳的女性，Cochrane 2024 年回顧認為 DHEA 對活產率可能沒有或幾乎沒有差別，歐洲生殖醫學會指引也是「可能不建議」 <a href="#ref-3">[3]</a> <a href="#ref-4">[4]</a>
- 更年期女性吃 DHEA，生活品質沒有改善，青春痘這類雄性素副作用增加 <a href="#ref-5">[5]</a>；老年人吃 2 年，體組成、肌力與生活品質都沒有效果 <a href="#ref-8">[8]</a>
- 乳癌、卵巢癌、攝護腺癌病史或高風險、正在吃 tamoxifen 的人，不建議自行使用 <a href="#ref-11">[11]</a>

## 基本介紹

在美國的量販店與網購平臺，DHEA 跟維生素放在一起賣，本站查過的一款是每顆 25 毫克的膠囊。台灣的讀者通常在三種時候搜尋它：試管療程前看到網路上「吃 DHEA 養卵」的說法、更年期想找荷爾蒙以外的選擇、或是聽說它能抗老。

這一頁只處理 DHEA 該不該吃、吃了會怎樣。美國為什麼能當補充劑賣、在台灣的法規位置怎麼查出來的，已整理在〈[美國 Costco、藥局買的成藥與保健品，哪些帶回台灣會出事](/articles/us-costco-otc-supplements-bring-back-taiwan/)〉；從 iHerb 或亞馬遜寄進台灣會遇到什麼，在〈[iHerb 這類海外網購的保健品寄到台灣，規定跟自己帶回來一樣嗎](/articles/overseas-online-supplements-mail-to-taiwan-rules/)〉；更年期其他補充品的證據，在〈[更年期保健食品這麼多，哪些真的有幫助](/articles/menopause-supplements-what-works/)〉。

## 這是什麼？

**DHEA 是一種荷爾蒙前驅物，吃進去的量會在體內轉成雄性素與雌激素。**

DHEA 全名脫氫表雄固酮（dehydroepiandrosterone），主要由腎上腺分泌，所以腎上腺功能不全的人會缺它 <a href="#ref-10">[10]</a>。Cochrane 的更年期回顧把它描述為雄性素的主要前驅物之一，進一步會轉成睪固酮與雌激素 <a href="#ref-5">[5]</a>。抽血常驗的是它的硫酸鹽形式（DHEA-S），Nair 的抗老試驗就是以 DHEA 硫酸鹽偏低作為收案條件 <a href="#ref-8">[8]</a>。它當藥品時的學名是 prasterone <a href="#ref-2">[2]</a> <a href="#ref-7">[7]</a>。

血中 DHEA 濃度隨年齡下降，這個現象是它被當成「抗老荷爾蒙」行銷的起點 <a href="#ref-6">[6]</a> <a href="#ref-8">[8]</a>。濃度下降是觀察到的事實，補回去能不能逆轉老化是另一個問題，要看試驗結果。

它和一般保健品最大的差別在這裡：轉成哪一種荷爾蒙、轉成多少，取決於個人原本的荷爾蒙環境，同一顆膠囊在停經女性、年輕女性、男性身上的作用並不相同。這也是它的風險與「雄性素」「荷爾蒙相關癌症」綁在一起的原因。

## 台灣怎麼管：食品不行，藥品只有陰道栓劑

**純化 DHEA 在台灣不能當食品原料；唯一有效的藥品許可證是處方用陰道栓劑，口服劑型查不到許可證。**

2026 年 11 月 22 日下載食藥署食品原料整合查詢平臺開放資料比對，脫氫表雄固酮（DHEA）純化物列在「未確認安全性尚不得使用之原料」，備註寫「非屬准用之食品添加物或可供食品使用之原料，尚不得用於食品」 <a href="#ref-1">[1]</a>。依這個分類，標成食品在台灣販售的含 DHEA 產品不合規。

同一天下載的全部藥品許可證開放資料中，主成分含 DHEA 而未註銷的許可證只有一張：衛部藥輸字第028205號「茵若颯陰道栓劑」（INTRAROSA Pessary），類別是須由醫師處方使用，適應症為停經後之外陰陰道萎縮 <a href="#ref-2">[2]</a>。資料上的有效日期是 2026 年 12 月 27 日，之後是否展延以食藥署最新資料為準。另外查到 3 張早已註銷的舊證，全部是注射劑，包括一款 DHEA 與雌二醇的複方 <a href="#ref-2">[2]</a>；口服劑型一張都沒有。

把三個地方放在一起看：

| 劑型或用途 | 在台灣的身分 | 本頁怎麼看 |
|---|---|---|
| 口服 DHEA 膠囊、錠劑 | 不得用於食品，查無藥品許可證 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a> | 證據與風險見下文 |
| 陰道內 DHEA 栓劑 | 處方藥，1 張有效許可證 <a href="#ref-2">[2]</a> | 有第三期試驗支持 <a href="#ref-7">[7]</a>，由醫師評估開立 |
| 試管療程中自行加吃 | 沒有可合法取得的口服產品 | 指引「可能不建議」 <a href="#ref-4">[4]</a> |

美國能開架賣，有它聯邦法上的具體原因，細節見〈[美國 Costco、藥局買的成藥與保健品，哪些帶回台灣會出事](/articles/us-costco-otc-supplements-bring-back-taiwan/)〉。在這一頁要記住的只有一點：美國當補充劑賣，代表它在美國的上市門檻不同，不代表安全性或效果被確認過。

**試管療程、更年期、抗老這三種用法，目前的試驗結果都不支持自行補充；唯一明確有效的是醫師開立的陰道劑型。**

### 試管療程：吃 DHEA 能「養卵」嗎

**Cochrane 2024 年更新的回顧，結論是 DHEA 對卵巢反應不佳女性的活產率可能沒有或幾乎沒有差別** <a href="#ref-3">[3]</a>。

這份回顧收入 28 篇隨機試驗，除了 3 篇以外，對象都是標準試管療程中卵巢反應不佳的女性。用作者自己的換算：如果不用 DHEA 的活產或持續懷孕率是 12%，用 DHEA 落在 12% 到 20% 之間；臨床懷孕率的勝算比 1.18，流產率也沒有下降 <a href="#ref-3">[3]</a>。同一份回顧裡，療程前使用睪固酮反而可能提高活產率，但那是另一種藥，需要醫師處方與監測。

歐洲人類生殖與胚胎學會 2020 年的卵巢刺激指引，對卵巢反應不佳者的建議寫的是：療程前或療程中使用 DHEA 可能不建議，屬條件式建議 <a href="#ref-4">[4]</a>。

所以在台灣的處境是：口服 DHEA 沒有藥品許可證、不能當食品，指引也不建議。看到論壇推薦想自己網購之前，先把這件事跟生殖醫學醫師談，包括自己正在吃或打算吃的所有補充品。

### 更年期：吃了沒有比較舒服，青春痘倒是多了

**口服或全身性 DHEA 沒有改善更年期女性的生活品質，雄性素副作用增加** <a href="#ref-5">[5]</a>。

Scheffers 等整理的 Cochrane 回顧中，熱潮紅、盜汗這些症狀的試驗結果不一致，無法合併出一個結論；性功能有小幅改善，青春痘等雄性素副作用的勝算比是 3.77 <a href="#ref-5">[5]</a>。Elraiyah 等限定腎上腺功能正常的停經女性，連性慾與性功能都沒有顯著改善 <a href="#ref-6">[6]</a>。內分泌學會 2014 年的女性雄性素治療指引，建議不要常規使用 DHEA，理由是對一般女性或腎上腺功能不全者的效果與安全資料都有限 <a href="#ref-9">[9]</a>。

陰道乾澀、性交疼痛是另一回事。Labrie 等 2016 年的第三期試驗中，每天陰道內使用 6.5 毫克 DHEA 12 週，症狀與陰道組織指標都比安慰劑改善，血中性荷爾蒙維持在停經後的正常範圍 <a href="#ref-7">[7]</a>。台灣核准的 DHEA 藥品正是這種陰道劑型，需要醫師處方 <a href="#ref-2">[2]</a>。熱潮紅明顯的人，荷爾蒙治療仍是證據最完整的選項，重新評估的方式見〈[美國把荷爾蒙治療的黑框警語拿掉了](/articles/menopause-hormone-therapy-fda-warning-removed/)〉。

### 抗老：兩年試驗沒有看到效果

Nair 等在梅約診所做的 2 年雙盲試驗，對象是 DHEA 硫酸鹽本來就偏低的長者。吃 DHEA 的人血中濃度確實補上來了，但體脂、肌肉量、最大攝氧量、肌力、胰島素敏感度與生活品質都和安慰劑一樣；骨密度在部分部位有小幅增加 <a href="#ref-8">[8]</a>。作者的結論是，DHEA 與低劑量睪固酮對長者都沒有生理上有意義的好處 <a href="#ref-8">[8]</a>。

## 安全性：荷爾蒙的事，要用荷爾蒙的標準看

**DHEA 的風險跟它的作用是同一件事：它會變成性荷爾蒙。**

最常見的是雄性素副作用，以青春痘為主 <a href="#ref-5">[5]</a>。MSKCC 的整理另外列出高劑量可能誘發躁症 <a href="#ref-11">[11]</a>。

荷爾蒙相關癌症是最需要慎重的部分。MSKCC 整理到停經前女性血中 DHEA 偏高與乳癌、卵巢癌風險較高有關；停經後女性長期使用可能增加乳癌風險，肥胖者尤其明顯；也有晚期攝護腺癌病人使用 DHEA 後病情惡化的病例 <a href="#ref-11">[11]</a>。MSKCC 明確寫出 DHEA 不應與 tamoxifen 併用，因為可能造成抗藥性 <a href="#ref-11">[11]</a>。這些多半是觀察性資料與病例，不能推成「吃了就會得癌」，但對已經有病史或高風險的人，風險方向是清楚的。

**誰不建議自己吃：**

- **乳癌、卵巢癌、攝護腺癌病史或高風險的人**，以及正在吃 tamoxifen 的人 <a href="#ref-11">[11]</a>
- **多囊性卵巢症候群患者**：雄性素偏高本身就是診斷要素之一，見〈[多囊性卵巢症候群（PCOS）完整指南](/articles/pcos-diagnosis-insulin-resistance-guide/)〉
- **懷孕、哺乳中的人與未成年人**：本站在〈[美國 Costco、藥局買的成藥與保健品，哪些帶回台灣會出事](/articles/us-costco-otc-supplements-bring-back-taiwan/)〉查到的一款 DHEA 產品，標示就寫明懷孕、哺乳與未滿 18 歲不得使用
- **正在做試管療程的人**：療程中加任何荷爾蒙相關的東西，都要讓醫師知道

藥物交互作用方面，MSKCC 列出 alprazolam、amlodipine、diltiazem、metformin 可能讓 DHEA 濃度上升，dexamethasone、胰島素、嗎啡可能讓它下降，同時註明臨床意義不明 <a href="#ref-11">[11]</a>。長期吃這些藥的人，把 DHEA 寫進用藥清單，讓醫師或藥師判斷。

**少數有指引支持的情境是腎上腺功能不全的女性。** 內分泌學會 2016 年指引建議，原發性腎上腺功能不全的女性在激素補充最佳化後，仍有性慾低落、憂鬱症狀或倦怠時，可以試用 DHEA 6 個月，沒有持續效果就停；這是弱建議、低品質證據，而且是醫師監測下的治療 <a href="#ref-10">[10]</a>。

## 常見迷思

- **「DHEA 是天然的，比荷爾蒙治療安全」**：DHEA 本身就是荷爾蒙前驅物，會轉成睪固酮與雌激素 <a href="#ref-5">[5]</a>，MSKCC 列出它與荷爾蒙相關癌症的風險訊號 <a href="#ref-11">[11]</a>
- **「試管療程吃 DHEA 可以養卵」**：Cochrane 2024 年回顧認為對活產率可能沒有或幾乎沒有差別 <a href="#ref-3">[3]</a>，歐洲指引寫「可能不建議」 <a href="#ref-4">[4]</a>
- **「DHEA 隨年齡下降，補回來就能抗老」**：2 年雙盲試驗補足了血中濃度，體能、肌力、生活品質都沒有改變 <a href="#ref-8">[8]</a>
- **「美國開架賣，代表安全」**：美國當膳食補充劑賣是上市規則的差別；台灣把它列為不得用於食品 <a href="#ref-1">[1]</a>
- **「醫師開的 DHEA 栓劑跟網購膠囊一樣」**：台灣核准的是陰道內局部用藥，試驗中血中荷爾蒙維持在停經後範圍 <a href="#ref-2">[2]</a> <a href="#ref-7">[7]</a>，跟口服全身性補充是不同的東西

## 常見問題

### 做試管療程，可以自己買 DHEA 來吃嗎？

不建議自己買。Cochrane 2024 年回顧認為 DHEA 對卵巢反應不佳女性的活產率可能沒有或幾乎沒有差別 <a href="#ref-3">[3]</a>，歐洲人類生殖與胚胎學會指引寫「可能不建議」 <a href="#ref-4">[4]</a>，而口服 DHEA 在台灣既不能當食品，也沒有藥品許可證 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>。療程中想嘗試任何補充品，先跟生殖醫學醫師討論。

### 更年期陰道乾澀，DHEA 有用嗎？

陰道內使用的 DHEA 有第三期試驗支持，能改善性交疼痛與陰道組織指標 <a href="#ref-7">[7]</a>，台灣也有核准的處方陰道栓劑 <a href="#ref-2">[2]</a>。這要由婦產科醫師評估開立。口服 DHEA 膠囊對更年期生活品質沒有改善 <a href="#ref-5">[5]</a>，不能拿來替代。

### 有乳癌病史，可以吃含 DHEA 的保健品嗎？

不建議。DHEA 會轉成雌激素與雄性素，MSKCC 整理到它與乳癌風險的關聯，並明寫不應與 tamoxifen 併用 <a href="#ref-11">[11]</a>。任何含荷爾蒙前驅物的產品，先問腫瘤科醫師。

### 吃了一段時間 DHEA，長青春痘、毛髮變多怎麼辦？

青春痘是 DHEA 最常見的雄性素副作用 <a href="#ref-5">[5]</a>。出現這類變化，帶著產品去看醫師，說明吃了多久、每天多少毫克，由醫師判斷要不要抽血檢查荷爾蒙。

### 男性吃 DHEA 能提高睪固酮嗎？

Nair 等的 2 年試驗中，吃 DHEA 的老年男性血中 DHEA 硫酸鹽上升，但肌力、體組成、胰島素敏感度與生活品質都沒有改善 <a href="#ref-8">[8]</a>。覺得自己睪固酮不足，先找泌尿科或內分泌科抽血確認。
