## 30 秒認識

- 甘草本身沒有毒，讓它變成問題的是累積：中藥方、日本漢方、蜜餞、喉糖、感冒糖漿都可能含甘草或甘草酸，每一樣看起來都不多，加起來沒有人算過 <a href="#ref-3">[3]</a> <a href="#ref-8">[8]</a>
- 機轉相當清楚。甘草次酸抑制腎臟的 11β-羥基類固醇脫氫酶第 2 型，讓皮質醇佔據原本留給醛固酮的受體，結果是血壓上升、血鉀下降、代謝性鹼中毒，臨床上叫假性醛固酮症 <a href="#ref-1">[1]</a> <a href="#ref-8">[8]</a>
- 劑量反應已有統合分析：每日至少 100 毫克甘草酸的 18 篇試驗合併後，收縮壓平均上升 5.45 mmHg、血鉀平均下降 0.33 mmol/L <a href="#ref-4">[4]</a>
- 日本的通報資料把高風險族群描得很具體：女性、70 歲以上、體重低於 50 公斤、正在用利尿劑、高血壓、失智症，以及連續使用超過 14 天 <a href="#ref-9">[9]</a>
- 台灣用兩套法規管甘草。食藥署把甘草根莖列為可供食品使用但不得單一原料；中醫藥司 115 年 4 月預告的草案則把它放進「食用時須注意安全性」的第二類，每人每日食用限量 1 公克 <a href="#ref-16">[16]</a> <a href="#ref-18">[18]</a>
- 甘草酸當甜味劑時，台灣的規定是各類食品「視實際需要適量使用」，沒有數字上限，食品包裝也不必標示含量 <a href="#ref-19">[19]</a>

## 基本介紹

冬天吃補、長輩拿慢性病藥、孩子咳嗽喝糖漿、出國帶回一盒日本漢方，這幾件事看似無關，卻可能在同一個人身上把甘草疊起來。甘草在複方中藥裡出現的頻率極高，日本厚生勞動省的副作用對應手冊給了一個數字：日本核准為醫藥品的漢方製劑有七成以上含甘草 <a href="#ref-8">[8]</a>。

台灣人的日常接觸面更廣。蜜餞與梅粉常用甘草調味，八仙果、喉糖、甘草橄欖都以它為名，西藥的感冒糖漿、胃腸藥與眼藥水也有不少把甘草萃取物或甘草酸鹽列為主成分。2026 年 11 月 21 日下載食藥署全部藥品許可證開放資料比對，主成分含甘草、甘草萃取物或甘草酸類的有效西藥許可證共有 382 張，其中 296 張屬指示藥 <a href="#ref-20">[20]</a>。

這一頁只處理一件事：甘草酸吃多了會怎樣、誰要特別小心、跟哪些藥一起最容易出事。甘草在中醫理論中的功效不在本頁範圍；中藥與西藥並用的整體判斷順序，請看〈[長輩西藥中藥一起吃，哪些組合真的會出事](/articles/elderly-tcm-western-drug-combos-that-matter/)〉，當歸、丹參、人參等其他藥材的交互作用整理在〈[補藥和西藥一起吃，哪些組合要小心](/articles/herbal-tonic-drug-interactions/)〉。

## 這是什麼？

甘草是豆科甘草屬植物的乾燥根與根莖。中醫藥司草案附表列出的基原有三種：甘草（*Glycyrrhiza uralensis* Fisch.）、脹果甘草（*G. inflata* Batalin）與光果甘草（*G. glabra* L.） <a href="#ref-16">[16]</a>；食藥署食品原料平臺收的則是光果甘草與甘草兩種 <a href="#ref-18">[18]</a>。

甘草的甜味主要來自甘草酸（glycyrrhizin，又稱甘草甜素），台灣的食品添加物標準把甘草素、甘草萃與幾種甘草酸鹽都列在甜味劑 <a href="#ref-19">[19]</a>。歐盟食品科學委員會 2003 年的意見書整理了它在體內的命運：甘草酸本身幾乎不被腸道吸收，要先被腸道細菌水解成甘草次酸（glycyrrhetinic acid）才會進入血液，而甘草次酸就是產生作用的形式；它還會經由膽汁排出後再被吸收，形成腸肝循環 <a href="#ref-3">[3]</a>。這兩個特性解釋了兩件臨床上常見的事：每個人對同樣劑量的反應差很多（腸道菌與腸道通過時間不同），以及停吃之後症狀不會馬上消失。

換算時常用的基準來自日本厚生勞動省手冊：甘草藥材 1 公克約含 40 毫克甘草酸 <a href="#ref-8">[8]</a>。這只是換算值。東京都藥劑師會實測 47 種醫療用漢方濃縮製劑，只有 8 種的甘草酸量跟甘草配合量呈直線關係，其餘 39 種都低於推算值，小青龍湯只有推算值的 15% <a href="#ref-11">[11]</a>。同一份報告也指出，漢方製劑的包裝只標甘草藥材量，從來不標甘草酸量。

## 在身體裡做什麼？／主要作用機制

**礦物皮質素受體本來就認得皮質醇。** 醛固酮與皮質醇對腎臟礦物皮質素受體的親和力相近，而血中皮質醇的濃度遠高於醛固酮。腎小管細胞靠 11β-羥基類固醇脫氫酶第 2 型（11β-HSD2）把皮質醇轉成不會結合受體的皮質酮，受體才保留給醛固酮使用 <a href="#ref-2">[2]</a> <a href="#ref-8">[8]</a>。

**甘草次酸拆掉了這道保護。** Stewart 等人 1987 年在《Lancet》發表的研究，把甘草的作用從「甘草本身像礦物皮質素」修正為「甘草造成後天的 11β-HSD 缺乏」；隔年同一團隊確認這個酵素是礦物皮質素受體的組織專一保護者 <a href="#ref-1">[1]</a> <a href="#ref-2">[2]</a>。日本厚生勞動省手冊的說明一致：甘草次酸與其代謝物抑制 11β-HSD2，未被轉換的皮質醇經由礦物皮質素受體發揮作用 <a href="#ref-8">[8]</a>。

**結果是一組很好認的檢驗組合。** 鈉與水滯留、鉀從尿中排出，血壓上升、血鉀下降、代謝性鹼中毒；身體為了代償，把腎素與醛固酮都壓低，所以檢驗會看到低腎素、低醛固酮，這一點正好與真正的醛固酮增多症相反，也是醫師鑑別的依據 <a href="#ref-8">[8]</a>。Penninkilampi 2017 的統合分析同樣測到血漿腎素活性與醛固酮顯著下降 <a href="#ref-4">[4]</a>。

**為什麼停了還要等幾週。** 厚生勞動省手冊寫明，停用含甘草的製劑後通常要數週，症狀與血鉀才回復，腎素恢復得更慢 <a href="#ref-8">[8]</a>。腸肝循環讓甘草次酸在體內停留較久，是可能的解釋之一 <a href="#ref-3">[3]</a>。

## 吃多少開始有影響

**沒有一個「低於它就絕對安全」的數字，資料顯示的是一條往上走的斜線。**

- **50 公克甘草糖、兩週。** Sigurjónsdóttir 等 2001 年讓健康志願者每天吃 50 到 200 公克甘草糖二到四週，研究者換算為每日 75 到 540 毫克甘草次酸。收縮壓上升 3.1 到 14.4 mmHg，劑量越高升越多，而且兩週就達到最大效果，個人反應呈常態分布，看不出有一群特別敏感的人 <a href="#ref-5">[5]</a>
- **100 毫克甘草酸、兩週。** af Geijerstam 等 2024 年的隨機交叉試驗，28 名年輕健康志願者吃兩週含 100 毫克甘草酸的甘草糖，居家收縮壓多上升 3.1 mmHg，腎素與醛固酮明顯被壓低 <a href="#ref-7">[7]</a>。100 毫克正是歐盟委員會的規律攝取上限，作者因此建議重新檢討這條線
- **高血壓患者反應更大。** Sigurjonsdottir 等 2003 年讓受試者每天吃 100 公克甘草糖四週，診間收縮壓在血壓正常者上升 3.5 mmHg，在原發性高血壓患者上升 15.3 mmHg，兩組差異達統計顯著 <a href="#ref-6">[6]</a>
- **漢方的甘草量。** Nakao 等 2026 年分析日本 2004 至 2024 年的 537 筆假性醛固酮症通報，通報最多的前 20 種漢方製劑全部含甘草，ROC 曲線找出的甘草日用量切點是 1.125 公克（曲線下面積 0.71） <a href="#ref-10">[10]</a>。厚生勞動省手冊也記錄過甘草日用量只有 1 到 2 公克的醫療用漢方，以及習慣性服用仁丹而發病的個案 <a href="#ref-8">[8]</a>

把這幾項放在一起，台灣草案訂的 1 公克落在日本通報資料切點的附近，並不寬鬆。草案的計算規則是：第二類中藥材任一品項換算每日食用量超過臺灣中藥典所載該品項最低用量的百分之五十，就以藥品管理，附表所載的每人日食用限量就是這個一半的數字 <a href="#ref-16">[16]</a>。

## 台灣的兩套管理：食品與中藥材

同一根甘草在台灣有好幾個法規身分，取決於它被做成什麼、賣在哪裡。

**食品原料。** 食藥署食品原料整合查詢平臺把光果甘草與甘草的根、莖列在「可供食品使用之原料」，分類是「草、木本植物類（2）可供直接食用」，備註只有一句：不得單一原料使用 <a href="#ref-18">[18]</a>。依這個備註，甘草可以當配料加進食品，只含甘草一種原料的產品則不符合這個使用條件。

**可同時提供食品使用之中藥材。** 中醫藥司 107 年 2 月 22 日生效的公告列出 37 項可同時供食品使用的中藥材，涵蓋百合、枸杞子、大棗、菊花、薄荷、決明子等，甘草不在其中 <a href="#ref-17">[17]</a>。

**115 年 4 月的草案要把甘草正式放進去，但附帶條件。** 中醫藥司 115 年 4 月 13 日以衛部中字第1151860670號預告《得供食品原料使用之中藥材品項及其產品屬性認定基準》草案 <a href="#ref-15">[15]</a>。草案把甘草列在第二類「食用時須注意安全性者」第 43 項，部位是乾燥根及根莖，備註有三點：外包裝須標示「肝腎功能不全病人及孕婦慎用」；每人日食用限量 1 公克；作為調味用途者無須標示含量、用法及用量，且得為單一成分產品 <a href="#ref-16">[16]</a>。截至 2026 年 11 月 21 日查詢，中醫藥司網頁上仍是預告草案，最終條文以正式公告為準。

**草案第七點列出的例外，剛好涵蓋台灣人最常吃到甘草的地方。** 糖果、餅乾、蜜餞品、果凍、烘焙食品、甜味料或調味醬；滷包、燉包、藥膳調理包；以及粗碎後以棉紙袋或不織布袋包裝的茶包，這三類型態都不以藥品管理 <a href="#ref-16">[16]</a>。草案沒有在這些例外上另訂甘草酸的上限。

**食品添加物。** 《食品添加物使用範圍及限量暨規格標準》把甘草素（glycyrrhizin）、甘草酸鈉、甘草萃、甘草酸銨與甘草酸一銨列為甜味劑，規定都是「本品可於各類食品中視實際需要適量使用」，唯一的限制是不得用於代糖錠劑及粉末 <a href="#ref-19">[19]</a>。這和歐盟委員會「所有來源合計每日 100 毫克」的思路方向不同，台灣的規定沒有總量概念。

**藥品。** 中藥房販售的甘草飲片、醫師開立的中藥製劑，屬藥事法管理的中藥範圍；西藥那一側則有前面提到的 382 張許可證 <a href="#ref-20">[20]</a>。

**邊境上的實例。** 食藥署 2026 年 10 月 20 日公布一批自中國大陸輸入、1,500 公斤的「甘草片」，以食品報驗後檢出二氧化硫 0.093 g/kg，超過其他加工食品 0.030 g/kg 的限量，依規定退運或銷毀 <a href="#ref-21">[21]</a>。同樣的甘草片，報成食品就用食品的標準驗。

## 與利尿劑、降血壓藥的交互作用

**甘草的交互作用幾乎都繞著血鉀與血壓兩件事打轉，而會出事的組合，正好是台灣長輩藥袋裡最常見的那幾類。**

| 正在用的藥 | 甘草造成的問題 | 可能的後果 | 依據 |
|---|---|---|---|
| 噻嗪類利尿劑、環利尿劑 | 兩邊都讓鉀從尿中流失，效果相加 | 低血鉀、四肢無力、心律不整 | 厚生勞動省手冊 <a href="#ref-8">[8]</a>；Uneda 2024 勝算比 2.1 <a href="#ref-9">[9]</a> |
| 各類降血壓藥 | 鈉與水滯留，方向與藥效相反 | 血壓控制變差，醫師可能因此加藥 | MSD Manual <a href="#ref-13">[13]</a>；Sigurjonsdottir 2003 <a href="#ref-6">[6]</a> |
| 毛地黃（digoxin） | 低血鉀提高毛地黃毒性 | 心律不整 | MSD Manual <a href="#ref-13">[13]</a> |
| 全身性類固醇 | 類固醇本身也會降血鉀，副作用相加 | 低血鉀、水腫、血壓上升 | NCCIH <a href="#ref-12">[12]</a>；MSD Manual <a href="#ref-13">[13]</a>；Liao 2010 <a href="#ref-14">[14]</a> |
| 胰島素 | 胰島素把鉀推進細胞 | 低血鉀加重；低血鉀又可能讓血糖惡化 | 厚生勞動省手冊 <a href="#ref-8">[8]</a> |
| warfarin | MSD Manual 列為可能降低藥效 | 資料有限，機轉未明 | MSD Manual <a href="#ref-13">[13]</a> |

**降血壓藥這一格最容易被誤會。** 吃甘草不會讓降血壓藥「失效」，但它在另一頭推高血壓，血壓量起來控制不好，醫師看到的就是藥量不夠。如果醫師不知道你天天在喝含甘草的藥膳或長期吃某個中藥方，加藥是很合理的決定，只是方向錯了。居家血壓的量法與判讀，可以照〈[血壓 130/80 該不該吃藥](/articles/hypertension-130-80-home-bp-guide/)〉裡的步驟記錄下來，回診時一起帶去。

**利尿劑這一格最容易出事。** 厚生勞動省手冊的「投藥上的風險因子」第一條就是因高血壓或心衰竭使用噻嗪類降壓利尿劑或環利尿劑 <a href="#ref-8">[8]</a>。正在服用降血壓藥的人還會遇到另一個血鉀問題，就是含鉀的低鈉鹽，那一題的方向剛好相反，整理在〈[吃降血壓藥能用低鈉鹽嗎](/articles/blood-pressure-meds-potassium-low-sodium-salt/)〉。

**台灣的健保資料提醒了一個制度面的漏洞。** Liao 等 2010 年用 1997 至 2003 年健保資料分析，經由不同的中醫師與西醫師分別處方，而同時使用全身性類固醇與含甘草中藥製劑的盛行率為 1.495% <a href="#ref-14">[14]</a>。兩張處方都合法，問題出在沒有人同時看到兩張。看中醫時把西藥藥袋帶去，看西醫時說出正在吃的中藥方，是目前最實際的補法。

## 安全性與注意事項

**症狀先從手腳開始。** 日本厚生勞動省手冊整理的初期症狀是手腳發麻、緊繃、僵硬，接著是逐漸加重的四肢無力與肌肉痛；臨床表現中約六成是四肢無力或肌力下降，約 35% 是高血壓，這兩項最常是發現的契機，其他還有全身倦怠（約 20%）、水腫（約 15%）、頭重、口渴、抽筋、心悸 <a href="#ref-8">[8]</a>。嚴重時會無法站立行走、發生致命性心律不整或橫紋肌溶解，尿液可能呈紅褐色 <a href="#ref-8">[8]</a>。

**發病時間沒有規律。** 同一份手冊記錄的個案從開始服用 10 天內到連續使用數年都有，約四成在三個月內發生；日本統計的男女比約 1 比 2，年齡 29 到 93 歲，平均 64 歲 <a href="#ref-8">[8]</a>。手冊建議醫療人員對服用可能引起本症藥品的病人，在開始用藥或改劑量後一個月內、維持期每三到六個月檢查一次血鉀 <a href="#ref-8">[8]</a>。

**手冊裡的一個典型病例。** 一位六十多歲女性因膝關節痛改吃漢方，先用含甘草 1 公克的方劑，兩個月後再併用另一個含甘草 1.3 公克的方劑；又過兩個月，血壓升到 170/100 mmHg，血鉀 3.2 mEq/L，診斷為假性醛固酮症。把第二個方劑換成不含甘草的處方後，兩週內血壓回到 138/96 mmHg、血鉀回到 4.0 mEq/L <a href="#ref-8">[8]</a>。兩個各自「劑量不高」的方劑疊在一起，就是本頁一直在講的累積。

**誰要特別留意。**

- **高血壓、心臟病、腎臟病患者**：NCCIH 指出，即使少量甘草酸也曾在這些族群身上造成嚴重影響 <a href="#ref-12">[12]</a>；Sigurjonsdottir 2003 的高血壓患者升壓幅度是血壓正常者的四倍多 <a href="#ref-6">[6]</a>
- **70 歲以上、女性、體重低於 50 公斤**：Uneda 2024 的勝算比依序為 5.0、1.7、2.2 <a href="#ref-9">[9]</a>
- **失智症患者**：同一份分析的勝算比為 7.0，是所有因子中最高的 <a href="#ref-9">[9]</a>，可能與早期的無力、疲倦不容易被說出來或被注意到有關
- **孕婦**：歐盟委員會引述的芬蘭世代研究中，每週甘草酸攝取超過 499 毫克的孕婦，38 週前分娩的勝算比為低攝取組的 2.5 倍，研究者未能確立因果 <a href="#ref-3">[3]</a>；NCCIH 也把孕期大量食用甘草列為不安全 <a href="#ref-12">[12]</a>

**有沒有不含甘草酸的甘草。** 有，市售稱為去甘草酸甘草（deglycyrrhizinated licorice，DGL）。NCCIH 的說法是不含甘草酸的口服甘草製品可能可以安全使用到四個月 <a href="#ref-12">[12]</a>。台灣市面上的中藥飲片、蜜餞與一般零食都沒有標示是否去除甘草酸，不能自行假設。

冬季進補時同時在吃慢性病藥的人，哪些補方要先問過醫師，〈[冬天進補，哪些人不適合](/articles/who-should-avoid-winter-tonic/)〉有分族群的整理。日本漢方胃腸藥與眼藥水裡的甘草酸鹽，〈[日本藥妝店成分紅線](/articles/japan-otc-ingredient-red-lines/)〉也有對照。

## 常見迷思

- **「甘草是藥引，量很少不用在意」**：單一方劑裡的量可能不多，問題是同時吃好幾種。厚生勞動省手冊的病例就是兩個各含 1 公克多甘草的方劑疊加後發病 <a href="#ref-8">[8]</a>
- **「零食裡的甘草跟中藥不一樣，不會怎樣」**：作用成分都是甘草酸。台灣的甜味劑規定沒有數字上限，也不要求標示含量 <a href="#ref-19">[19]</a>，所以吃了多少更難估
- **「血壓正常的人不用管」**：Sigurjónsdóttir 2001 與 af Geijerstam 2024 的受試者都是健康人，血壓一樣有上升 <a href="#ref-5">[5]</a> <a href="#ref-7">[7]</a>；只是高血壓患者升得更多 <a href="#ref-6">[6]</a>
- **「抽筋就是缺鈣、缺鎂」**：長期吃含甘草製品的人出現抽筋、無力，低血鉀也是要排除的原因之一 <a href="#ref-8">[8]</a>，自行補鈣補鎂不會處理到它
- **「補鉀就好」**：厚生勞動省手冊指出，這類低血鉀單靠補鉀效果有限，因為鉀會繼續從尿中流失，第一步是停用推定的原因藥品 <a href="#ref-8">[8]</a>

## 常見問題

### 我在吃降血壓藥，可以喝含甘草的藥膳或中藥嗎？

先讓開藥的醫師或藥師知道。甘草造成的鈉水滯留會把血壓往上推，和降血壓藥的方向相反 <a href="#ref-13">[13]</a>；如果同時在用噻嗪類或環利尿劑，低血鉀的風險還會疊加 <a href="#ref-8">[8]</a>。偶爾一次藥膳和天天喝同一個中藥方，風險差很多，回診時把頻率與持續多久一起講清楚，比只說「有在吃中藥」有用。

### 一天吃多少甘草算安全？

沒有一個對所有人都安全的數字。歐盟食品科學委員會用每日 100 毫克甘草酸作為多數人的規律攝取上限，並明說高血壓與電解質異常的人可能需要更低 <a href="#ref-3">[3]</a>；2024 年的試驗在 100 毫克就測到健康人的血壓上升 <a href="#ref-7">[7]</a>。台灣草案對食品中的甘草訂每人每日 1 公克藥材 <a href="#ref-16">[16]</a>，但蜜餞、糖果、茶包這些型態另有例外。

### 長期吃梅粉、甘草橄欖會不會出事？

我們查不到台灣這類零食的甘草酸含量資料，無法給出份量換算。能確定的是：甘草酸類甜味劑在台灣可以「視實際需要適量使用」 <a href="#ref-19">[19]</a>，包裝成分欄會寫甘草萃或甘草酸鈉，但不會寫多少。若天天吃，又有高血壓或在用利尿劑，回診時可以請醫師一併確認血鉀。

### 甘草引起的血壓上升，停掉多久會恢復？

依日本厚生勞動省手冊，停用含甘草的製劑後，多數人在數週內症狀消失、血鉀回升，腎素的恢復需要更久 <a href="#ref-8">[8]</a>。Sigurjónsdóttir 2001 的試驗則顯示升壓效果在兩週內就達到高峰 <a href="#ref-5">[5]</a>，所以上升得快、退得慢。

### 中藥方裡的甘草和西藥感冒糖漿裡的甘草，要一起算嗎？

要。作用成分都是甘草酸或它的鹽類。台灣主成分含甘草類的有效西藥許可證有 382 張，劑型涵蓋膠囊、內服液、錠劑、糖漿與點眼液 <a href="#ref-20">[20]</a>。眼藥水的量通常很小，口服的才是累積的主體。

### 為什麼日本的漢方藥對甘草特別小心？

日本醫藥品等級的漢方製劑有七成以上含甘草，厚生勞動省的重篤副作用對應手冊把假性醛固酮症單獨列成一章，並附上各方劑每日甘草酸量與通報件數；2010 至 2020 年通報最多的是芍藥甘草湯（184 件）與抑肝散（126 件） <a href="#ref-8">[8]</a>。醫療用漢方中甘草日用量 2.5 公克以上的品項，仿單把醛固酮症、肌病變與低血鉀患者列為禁忌 <a href="#ref-11">[11]</a>。
