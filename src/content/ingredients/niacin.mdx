## 30 秒認識

- 國健署建議成人男性每天 16 毫克、女性 14 毫克菸鹼素當量，上限 35 毫克；這個上限針對的是補充劑與添加物，依據是潮紅 <a href="#ref-1">[1]</a> <a href="#ref-4">[4]</a>
- 台灣錠狀、膠囊狀食品每天的菸鹼素總量不得超過 100 毫克，比國健署上限高；用來降血脂的高劑量菸鹼酸是處方藥，台灣有一張 500 毫克持續釋放錠的許可證 <a href="#ref-2">[2]</a> <a href="#ref-3">[3]</a>
- 兩個大型試驗在他汀類之外加菸鹼酸，HDL 升高了，心血管事件沒有減少，副作用增加；Cochrane 回顧的結論是預防效益不太可能存在 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a> <a href="#ref-8">[8]</a>
- 跟他汀類一起吃，肌病變風險變成 4.4 倍，中國受試者的比例明顯較高；緩釋劑型有肝毒性問題 <a href="#ref-7">[7]</a> <a href="#ref-10">[10]</a>

## 基本介紹

吃了 B 群或菸鹼酸補充劑之後臉紅發熱，是菸鹼酸最有名的反應，叫潮紅。美國訂維生素 B3 的攝取上限，依據的就是這個反應 <a href="#ref-4">[4]</a>。它常被誤會成過敏，也常被當成「有在作用」的證明。

這一頁只處理菸鹼酸與菸鹼醯胺這兩種維生素 B3。NMN 是菸鹼醯胺再往下合成的分子，法規與證據見〈[NMN](/ingredients/nmn/)〉與〈[NMN 在台灣不能當食品賣，日本卻滿街都是](/articles/nmn-regulation-taiwan-japan-us-eu/)〉；綜合 B 群該怎麼挑，見〈[維生素 B 群](/ingredients/vitamin-b-complex/)〉。同一系列的單一 B 群頁還有〈[維生素 B1](/ingredients/vitamin-b1/)〉與〈[維生素 B6](/ingredients/vitamin-b6/)〉，B6 那一頁談的同樣是疊吃超標的問題。

## 這是什麼？

**維生素 B3 有兩種形式：菸鹼酸會讓人臉紅、也會改變血脂；菸鹼醯胺不會。**

國健署膳食營養素參考攝取量用「菸鹼素」統稱，註明菸鹼素包括菸鹼酸及菸鹼醯胺，以菸鹼素當量（mg N.E.）表示 <a href="#ref-1">[1]</a>。兩者在體內都是合成 NAD 與 NADP 這兩種輔酶的原料，細胞的能量代謝要靠它們 <a href="#ref-11">[11]</a>。

到了高劑量，兩者就分家了。MSD Manual 寫得很直接：立即釋放與緩釋型的菸鹼酸會影響血脂，菸鹼醯胺不會 <a href="#ref-11">[11]</a>。潮紅也是菸鹼酸的反應。所以標示「無潮紅（no-flush）」的產品，要看清楚裡面到底是什麼成分、劑型是不是緩釋。

| 形式 | 常見產品 | 血脂作用 | 主要副作用 | 台灣身分 |
|---|---|---|---|---|
| 菸鹼酸（立即釋放） | B 群、綜合維他命、單方錠 | 有 <a href="#ref-11">[11]</a> | 潮紅、高劑量時血糖上升、痛風 <a href="#ref-11">[11]</a> | 食品每日上限 100 毫克 <a href="#ref-2">[2]</a>；藥品有指示藥與處方藥 <a href="#ref-3">[3]</a> |
| 菸鹼酸（緩釋、持續釋放） | 降血脂處方藥、國外補充劑 | 有 | 潮紅較少，肝毒性風險較高 <a href="#ref-10">[10]</a> <a href="#ref-11">[11]</a> | 台灣有一張 500 毫克處方藥許可證 <a href="#ref-3">[3]</a> |
| 菸鹼醯胺 | B 群、皮膚保健、單方錠 | 無 <a href="#ref-11">[11]</a> | 試驗劑量下與安慰劑相近 <a href="#ref-12">[12]</a> | 食品每日上限 100 毫克 <a href="#ref-2">[2]</a>；藥品有指示藥 <a href="#ref-3">[3]</a> |
| NMN | 抗老補充品 | 本頁未評估 | 見 NMN 頁 | 純化物不得當食品原料，見 NMN 頁 |

體內也能用色胺酸自己做菸鹼酸，相關代謝路徑見〈[色胺酸](/ingredients/tryptophan/)〉。

## 每天要多少、上限多少：國健署的數字

**成人男性每天 16 毫克、女性 14 毫克菸鹼素當量，上限 35 毫克** <a href="#ref-1">[1]</a>。

| 年齡 | 建議攝取量（男／女） | 上限攝取量 |
|---|---|---|
| 1 至 3 歲 | 9 | 10 |
| 4 至 6 歲 | 12／11 | 15 |
| 7 至 9 歲 | 14／12 | 20 |
| 10 至 12 歲 | 15／15 | 25 |
| 13 至 18 歲 | 18／15 | 30 |
| 19 歲以上 | 16／14 | 35 |
| 懷孕第二、三期 | 加 2 | 35 |
| 哺乳期 | 加 4 | 35 |

單位都是毫克菸鹼素當量，依國健署第八版總表與上限攝取量表整理 <a href="#ref-1">[1]</a>。

國健署的上限表沒有交代 35 毫克是怎麼來的。美國醫學研究院 1998 年訂成人上限也是 35 毫克，依據是潮紅：1938 年的研究中，6 人裡有 4 人每天吃 50 毫克菸鹼酸就出現潮紅，以此為最低不良反應劑量，除以 1.5 的不確定係數 <a href="#ref-4">[4]</a>。同一章寫明，這個上限適用於添加在食品裡或當補充劑吃的菸鹼素，食物中天然存在的菸鹼素沒有不良反應的證據 <a href="#ref-4">[4]</a>。

所以從食物吃到的菸鹼素不必擔心上限，要算的是補充劑與強化食品裡添加的量。

## 台灣怎麼管：食品 100 毫克，再往上是藥

**台灣錠狀、膠囊狀食品每天的菸鹼素總量上限是 100 毫克，超過這條線就落到藥品那一側。**

食品添加物使用範圍及限量暨規格標準的營養添加劑表，對菸鹼酸與菸鹼醯胺訂了同一組數字 <a href="#ref-2">[2]</a>：

- 形態屬膠囊狀、錠狀且標示每日食用限量的食品：每日菸鹼素總量不得高於 100 毫克
- 其他一般食品：每日食用量或每 300 公克不得高於 25.5 毫克
- 嬰兒（輔助）食品：每日食用量或每 300 公克不得高於 12 毫克

同一份標準的備註要求，添加菸鹼素等十種維生素的錠狀膠囊食品，包裝上要標明攝取量限制與「多食無益」之類的字句 <a href="#ref-2">[2]</a>。

這裡有一個要自己算的落差：食品的 100 毫克上限，接近國健署 35 毫克上限的三倍。一顆合法的 B 群如果寫著菸鹼酸 50 毫克，吃一顆已經超過國健署的上限，再加一顆綜合維他命就更多。上限不是吃到就會出事的線，但它是依潮紅訂的，臉紅發熱的人可以先回頭算算自己一天疊了幾種含 B3 的產品。

藥品那一側，2026 年 11 月 22 日下載的食藥署藥品許可證資料中，單方菸鹼酸與菸鹼醯胺的有效許可證有幾種 <a href="#ref-3">[3]</a>：

- **指示藥**：菸鹼酸錠、菸鹼醯胺錠多張，適應症都是菸鹼酸缺乏症
- **處方藥**：一款 50 毫克菸鹼酸片，以及脂寧定持續釋放膜衣錠 500 毫克，後者的適應症是高血脂症飲食控制的輔助治療

用來降血脂的劑量是每天上千毫克，在台灣是醫師處方的藥。網購的高劑量或緩釋菸鹼酸，吃的是藥的劑量，卻沒有藥的監測。

## 高劑量降血脂：HDL 上去了，心臟病沒有少

**在他汀類之外加菸鹼酸，HDL 升高、三酸甘油酯下降，但兩個大型試驗都沒有看到心血管事件減少。**

菸鹼酸是很老的降血脂藥，能降 LDL 與三酸甘油酯、拉高 HDL <a href="#ref-8">[8]</a>。問題是數字變好看，有沒有換到少一點心肌梗塞與中風。

AIM-HIGH 試驗收了 3,414 名已有動脈硬化心血管疾病、LDL 已用 simvastatin 控制好的病人，加每天 1,500 至 2,000 毫克緩釋菸鹼酸或安慰劑。2 年時 HDL 從 35 升到 42 mg/dL，三酸甘油酯從 164 降到 122 mg/dL，主要心血管事件卻是 16.4% 對 16.2%，平均追蹤 3 年因為無效提前終止 <a href="#ref-5">[5]</a>。

HPS2-THRIVE 的規模大得多，25,673 名血管疾病病人，每天 2 公克緩釋菸鹼酸加上一種抑制潮紅的藥，追蹤中位數 3.9 年。主要血管事件 13.2% 對 13.7%，沒有顯著差異；嚴重的血糖控制失常、新診斷糖尿病、腸胃、肌肉骨骼、皮膚、感染與出血的嚴重不良反應都增加 <a href="#ref-6">[6]</a>。

Schandelmaier 等 2017 年的 Cochrane 回顧把 23 篇試驗、39,195 人放在一起：菸鹼酸沒有降低總死亡、心血管死亡、心肌梗塞或中風，因副作用停藥的風險是對照組的 2.17 倍，作者的結論是預防心血管事件的效益不太可能存在 <a href="#ref-8">[8]</a>。

血脂報告上 HDL 偏低、三酸甘油酯偏高的意義，以及下一步該做什麼，整理在〈[膽固醇報告 4 大指標怎麼看](/articles/cholesterol-report-ldl-hdl-triglycerides/)〉。

## 安全性：臉紅、肝、肌肉、血糖

**每天幾十毫克的問題是潮紅；每天上千毫克的問題是肝、肌肉、血糖與痛風。**

### 潮紅

MSD Manual 指出，潮紅在立即釋放劑型比較常見，喝酒、運動、曬太陽或吃辣之後可能更明顯 <a href="#ref-11">[11]</a>。處方使用時，醫師通常從低劑量開始、很慢地往上加 <a href="#ref-11">[11]</a>。吃 B 群或菸鹼酸補充劑後臉紅發熱、刺癢，多半就是這個反應；如果同時有喘、嘴唇或眼皮腫、全身蕁麻疹，那是過敏的表現，要立刻就醫。

### 肝臟：緩釋型的風險

**緩釋菸鹼酸的肝毒性比立即釋放型常見。** McKenney 等 1994 年的雙盲試驗，46 名高膽固醇病人分兩組，劑量每 6 週往上加，從每天 500 毫克加到 3,000 毫克。立即釋放組沒有人出現肝毒性，緩釋組 23 人中有 12 人出現，作者建議緩釋劑型應限制使用 <a href="#ref-10">[10]</a>。MSD Manual 也寫到，部分緩釋劑型的肝毒性可能比較常見，處方期間要定期驗肝指數、血糖與尿酸 <a href="#ref-11">[11]</a>。

網購「不臉紅菸鹼酸」要多想一層：潮紅少了，肝臟的問題可能多了，而且沒有人幫你抽血。

### 跟他汀類一起吃：肌肉

**HPS2-THRIVE 在 simvastatin 之外加緩釋菸鹼酸，確定肌病變的風險變成安慰劑組的 4.4 倍** <a href="#ref-7">[7]</a>。

拆開來看，任何肌病變在中國受試者每年 0.66%、安慰劑組 0.13%；歐洲受試者每年 0.07%、安慰劑組 0.04% <a href="#ref-7">[7]</a>。作者指出，中國受試者原本用 simvastatin 的肌病變率就比較高 <a href="#ref-7">[7]</a>。台灣讀者同為東亞族群，就現有資料看，這是一個值得記住的訊號。

他汀類本身的肌肉症狀與 Q10 的問題，見〈[吃降血脂藥（他汀）需要同時補 Q10 嗎](/articles/statin-coq10-need-or-not/)〉；同樣常被拿來跟他汀類疊在一起的紅麴，見〈[正在吃降血脂藥（Statin），還能同時吃紅麴保健品嗎](/articles/red-yeast-rice-with-statin/)〉。正在吃他汀類的人，要不要加菸鹼酸，先跟開藥的醫師或藥師確認。

### 血糖與痛風

Goldie 等 2016 年統合 11 篇試驗、26,340 名原本沒有糖尿病的人，菸鹼酸組新發糖尿病的風險比 1.34，相當於每 43 人治療 5 年多 1 人得糖尿病，有沒有合併他汀類結果都一樣 <a href="#ref-9">[9]</a>。MSD Manual 另指出每天 3,000 毫克可能讓血糖惡化、誘發原有的痛風 <a href="#ref-11">[11]</a>。

## 菸鹼醯胺與皮膚癌：一個有限的例外

**菸鹼醯胺在一群特定的高風險病人身上，有一篇第三期試驗看到皮膚癌減少；換一群人就沒有了。**

Chen 等 2015 年的 ONTRAC 試驗，386 名過去 5 年內至少得過兩次非黑色素瘤皮膚癌的人，每天兩次 500 毫克菸鹼醯胺或安慰劑 12 個月，新發皮膚癌少 23%，副作用與安慰劑沒有明顯差別，停藥之後效果就看不到了 <a href="#ref-12">[12]</a>。Allen 等 2023 年在器官移植受者重做，158 人的試驗中兩組的皮膚癌數目幾乎一樣 <a href="#ref-13">[13]</a>。

這兩篇的對象都是反覆得皮膚癌的人，劑量每天 1,000 毫克，超過台灣錠狀膠囊食品的 100 毫克上限十倍 <a href="#ref-2">[2]</a>。一般人想靠吃菸鹼醯胺預防皮膚癌，目前沒有證據支持；有皮膚癌病史的人，跟皮膚科醫師討論。

## 常見迷思

- **「吃菸鹼酸會臉紅，代表在排毒或有效」**：潮紅是菸鹼酸的已知副作用，美國的上限就是依潮紅訂的 <a href="#ref-4">[4]</a>
- **「HDL 拉高就能保護心臟」**：AIM-HIGH 與 HPS2-THRIVE 的 HDL 都升高了，心血管事件沒有減少 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>
- **「不臉紅的緩釋型比較安全」**：緩釋型的肝毒性在試驗中出現在一半以上的受試者 <a href="#ref-10">[10]</a>
- **「維生素 B3 是水溶性，吃多了會排掉」**：國健署訂有上限 35 毫克 <a href="#ref-1">[1]</a>，高劑量會影響肝臟、血糖與尿酸 <a href="#ref-11">[11]</a>
- **「菸鹼醯胺跟菸鹼酸一樣能降血脂」**：MSD Manual 指出菸鹼醯胺不會影響血脂 <a href="#ref-11">[11]</a>

## 常見問題

### 吃 B 群後臉紅發熱，要緊嗎？

多半是菸鹼酸的潮紅反應，通常會自己退。先看看產品標示的菸鹼酸是多少毫克，再算一天疊了幾種含 B3 的產品；國健署的成人上限是 35 毫克 <a href="#ref-1">[1]</a>，而依潮紅訂出的最低不良反應劑量是 50 毫克 <a href="#ref-4">[4]</a>。如果合併呼吸困難、嘴唇腫或全身蕁麻疹，要立刻就醫。

### 血脂紅字，可以自己買菸鹼酸來降嗎？

不建議。降血脂需要每天上千毫克，在台灣是處方藥 <a href="#ref-3">[3]</a>；兩個大型試驗在他汀類之外加菸鹼酸，心血管事件都沒有減少，副作用增加 <a href="#ref-5">[5]</a> <a href="#ref-6">[6]</a>。血脂異常該不該用藥、用哪一種，請跟醫師討論。

### 正在吃他汀類，B 群裡的菸鹼酸會有問題嗎？

HPS2-THRIVE 觀察到的肌病變，是每天 2 公克緩釋菸鹼酸加 simvastatin <a href="#ref-7">[7]</a>，跟一般 B 群裡幾十毫克的量差很多。不確定自己吃的產品含量高不高，把產品帶去給開藥的醫師或藥師看。

### 菸鹼醯胺和 NMN 有什麼不一樣？

菸鹼醯胺是維生素 B3 的一種形式，在台灣可以當營養添加劑，錠狀膠囊食品每天上限 100 毫克菸鹼素 <a href="#ref-2">[2]</a>。NMN 是再往下合成的分子，純化物在台灣不得當食品原料，細節見〈[NMN](/ingredients/nmn/)〉。

### 常喝酒的人，需要另外補菸鹼酸嗎？

這一頁沒有查到台灣人菸鹼素缺乏的國內調查資料，說不出缺乏有多常見。長期大量飲酒的人比較明確的問題是 B1，機轉見〈[維生素 B1](/ingredients/vitamin-b1/)〉。懷疑營養缺乏，先讓醫師評估、必要時抽血，不要自己買高劑量單方；台灣的菸鹼酸與菸鹼醯胺指示藥，適應症寫的就是菸鹼酸缺乏症 <a href="#ref-3">[3]</a>。
