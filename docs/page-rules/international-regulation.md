# 頁面規則：國際法規落差文

**這是 articles 底下的一個題型，不是新的 collection。** `queryPattern` 一律 `taiwan-regulation-market`。
選題前先讀 [`../playbooks/winning-article-formula.md`](../playbooks/winning-article-formula.md)
的「跨國法規題是本站產能最高的題型」一節（含 GSC 實測數字）。

## 這個題型在做什麼

回答「**同一個東西，為什麼在台灣和在別的國家待遇差這麼多？**」

不是把四個國家的規定並排（那是規格比較表，讀者沒有問題要解決），而是**解釋落差為什麼存在**。
落差的成因通常是三種之一：

1. **歷史路徑**——這個成分最早被當成什麼（例：美國 1994 年 DSHEA 把褪黑激素歸進膳食補充劑，
   不是因為認定它更安全，是因為那部法律的分類方式）。
2. **審查制度的預設方向相反**——一個正面表列（沒列到就不能用），一個負面表列（沒禁就能用）。
   台灣 vs 日本對 NMN 的差別就是這個，不是雙方對安全性看法不同。
3. **分類邊界**——成分處在食品與藥品之間（紅麴的 monacolin K 與 lovastatin 是同一個結構）。

**寫出成因，這篇才有存在價值**；只列現況的話，讀者去看官方網站就好。

## 必備結構

### 七維度對照表（這是最可能被記者與 AI 引用的部分）

| 項目 | 台灣 | 美國 | 日本 | 歐盟 |
|---|---|---|---|---|
| 法規定位（食品／藥品／新穎食品／其他） | | | | |
| 能不能作為一般食品原料販售 | | | | |
| 市面上常見的產品形式 | | | | |
| 官方允許的健康聲稱 | | | | |
| 人體研究常用劑量 vs 市售劑量 | | | | |
| 安全性警語與限量 | | | | |
| 主管機關與查證來源 | | | | |

- 每一格都要能追到官方出處（TFDA／衛福部／FDA／NIH ODS／厚生労働省／消費者庁／EFSA／
  歐盟執委會 Novel Food 目錄），並標明**依據哪份文件、什麼時候發布**。
- **查不到就寫「查無明文」並說明查過哪裡，不要用推測填滿格子。**
  2026-09-01 那批的紅麴篇有 4 格是「查無明文」，那不是缺點——
  「這件事各國都沒有規定」本身就是高引用價值的資訊。
- 表格下方接一段「一句話結論」，把整張表壓成讀者真正要的那一句。

### 有效期限與變動風險（獨立一小節，不可省）

法規資料的半衰期大約一年，而且最值得寫的題目正好變動最劇烈。這一節要告訴讀者
這份對照的時間座標、以及怎麼自己去查最新狀態（給官方查詢頁連結）。
`updatedDate` 就是實際查證日。

## 兩條會出事的紅線

### 1. 不要在同一主題疊第二篇同角度的法規文

站上褪黑激素已有 10 篇，「台灣怎麼管／能不能帶回來」完全飽和；
`import-melatonin-taiwan-customs` 是全站第一名的頁面（2026-09-01 GSC：3,983 曝光／280 點擊）。
再寫一篇同角度的只會蠶食它。

**動筆前先把同主題既有文章讀完，列出它們講過什麼，然後只寫它們沒覆蓋的查詢群。**
2026-09-01 那批的褪黑激素篇是這樣處理的：完全不碰入境限量、代購刑責、劑量建議、
兒童安全（各有專文），改從其他國家的監管邏輯切入。

### 2. 寫錯法規比不寫更糟——這是 YMYL 站

記者會引用、讀者會照做。三件實際發生過的事：

- **法規會反轉**：2026-09-01 那批寫 NMN 時，我給 agent 的指示是「美國 FDA 以 drug preclusion
  排除、至今仍在訴訟」。agent 查證後發現 **FDA 已於 2025-09-29 推翻自己的解釋**
  （卷宗 FDA-2023-P-0872-2754），2025-12-09 起發出恢復函，理由是認定 NMN 2017 年即已在美上市。
  **照我的指示寫會是實質錯誤。** 寫這類文一律以當下查到的官方文件為準，不要採信任何人的記憶，
  包括我的。
- **舊文會變成錯的**：同一批發現 `red-yeast-rice-monacolin-k-safety-guide` 寫小林製藥事件
  「導因是橘黴素污染」，但日本厚生労働省與國立醫藥品食品衛生研究所的結論是
  **工廠混入的青黴產生軟毛青黴酸（puberulic acid）**，動物實驗只有它造成腎小管變性壞死
  （Yoshinari 等人 2025，PMID 40159186）。已更正。**寫新文時順手查同主題舊文有沒有過時。**
- **不要替未定論的事下結論**：小林製藥的死亡個案至今未逐案認定因果，就寫「調查未完成」。
